# **1. Claude Chat의 기본 활용**

Claude Chat은 자연어로 질문하거나 작업을 요청하고 답변을 받을 수 있는 생성형 AI 서비스이다.

단순한 개념 질문뿐만 아니라 데이터 분석, 코드 작성, 머신러닝·딥러닝 학습 등 다양한 작업에 활용할 수 있다.

특히 하나의 Chat에서는 이전에 주고받은 대화 내용을 참고하여 후속 질문을 이어갈 수 있다.

> ## **1-1 ) Claude Chat에서 질문하기**

Claude에게 질문할 때는 자연어로 원하는 작업을 설명하면 된다.

예를 들어 운동역학 데이터를 이용하여 딥러닝 예측모델을 공부한다고 가정해보자.

[Prompt : code] "운동역학 딥러닝 예측모델 개념 질문"

```text
IMU 센서 데이터를 이용해서
보행 중 무릎 관절각을 예측하는 딥러닝 모델을 만들고 싶어.

어떤 딥러닝 모델을 사용할 수 있는지
초보자가 이해하기 쉽게 설명해줘.
```

[ Result ]

```text
IMU 센서 데이터는 시간의 흐름에 따라 값이 변하는 시계열 데이터이므로
LSTM, GRU, 1D-CNN 등의 모델을 사용할 수 있습니다.

예를 들어 LSTM은 이전 시점의 움직임 정보를 기억하면서
현재 움직임을 분석할 수 있기 때문에
보행 중 무릎 관절각과 같은 연속적인 움직임을 예측하는 데 활용할 수 있습니다.
```

즉, Claude에게 단순히 개념을 질문할 수도 있지만 특정 **데이터의 특징과 예측 목적**을 함께 전달하면 더 구체적인 답변을 받을 수 있다.

<br>

> ## **1-2 ) 후속 질문을 이용한 작업 구체화**

Claude Chat의 중요한 특징은 하나의 질문으로 끝나는 것이 아니라 이전 답변을 참고하면서 계속 질문할 수 있다는 것이다.

예를 들어 첫 번째 질문에서 `LSTM`이 추천되었다고 가정하자.

[Prompt : code] "LSTM을 추천한 이유에 대한 후속 질문"

```text
LSTM이 일반적인 신경망보다
보행 데이터 예측에 더 적합한 이유가 뭐야?
```

[ Result ]

```text
보행 데이터는 한 시점의 값만으로 움직임을 설명하기 어렵고
이전 시점의 움직임과 현재 움직임이 서로 연결되어 있습니다.

LSTM은 이전 시점의 정보를 일정 부분 기억할 수 있기 때문에
이러한 시간적 패턴을 학습하는 데 유리합니다.
```

여기서 다시 실제 모델 구현 방법이 궁금하다면 추가 질문을 할 수 있다.

[Prompt : code] "운동역학 LSTM 모델 코드 요청"

```text
그럼 가속도, 각속도 데이터를 입력으로 사용해서
무릎 굴곡각을 예측하는 간단한 LSTM 모델을
Python TensorFlow 코드로 보여줘.
```

Claude는 같은 대화에서 앞서 이야기한 `IMU`, `보행`, `LSTM`, `무릎 관절각 예측`이라는 맥락을 참고하여 답변할 수 있다.

대화 흐름은 다음과 같이 구성할 수 있다.

```text
질문
 ↓
답변 확인
 ↓
이해하지 못한 내용 질문
 ↓
조건 추가
 ↓
코드 요청
 ↓
결과 해석 요청
```

<br>

> ## **1-3 ) 컨텍스트(Context)**

`컨텍스트(Context)`란 생성형 AI가 답변을 만들 때 참고하는 정보와 맥락을 의미한다.

컨텍스트에는 다음과 같은 정보가 포함될 수 있다.

| 컨텍스트 | 예시 |
|---|---|
| 현재 질문 | `LSTM으로 무릎 관절각을 예측하고 싶어` |
| 이전 대화 | LSTM과 시계열 데이터에 대한 설명 |
| 사용자 제공 정보 | 입력 변수, 타깃 변수, 데이터 구조 |
| 파일 | IMU 센서 데이터, 관절각 데이터 |
| 작업 목적 | 운동역학 딥러닝 예측모델 구축 |

같은 질문이라도 제공되는 컨텍스트에 따라 답변이 달라질 수 있다.

예를 들어 다음 두 질문은 결과의 구체성이 다르다.

```text
LSTM 모델 만들어줘.
```

보다 다음과 같이 질문하는 것이 좋다.

```text
100Hz로 측정한 보행 IMU 데이터가 있고
입력 변수는 가속도 X, Y, Z와 각속도 X, Y, Z야.

타깃은 같은 시점의 무릎 굴곡각이고
LSTM을 이용해서 무릎 굴곡각을 예측하고 싶어.

TensorFlow를 이용한 기본 모델 구조를 만들어줘.
```

즉, **좋은 답변을 얻으려면 필요한 컨텍스트를 충분히 제공하는 것이 중요하다.**

# **2. Chat과 Projects의 차이**

Claude에서는 작업 성격에 따라 일반 `Chat`과 `Projects`를 구분하여 사용할 수 있다.

> ## **2-1 ) Chat이 적합한 경우**

Chat은 하나의 독립적인 질문이나 비교적 짧은 작업에 적합하다.

예를 들어 다음과 같은 질문은 일반 Chat으로도 충분하다.

[Prompt : code] "딥러닝 개념 질문"

```text
LSTM과 GRU의 차이를 설명해줘.
```

또는

```text
딥러닝에서 과적합이 발생하는 이유를 설명해줘.
```

또는

```text
RMSE와 MAE의 차이를
회귀모델 평가 관점에서 설명해줘.
```

이처럼 이전 작업의 데이터나 설정을 계속 사용할 필요가 없다면 Chat을 활용하는 것이 간단하다.

<br>

> ## **2-2 ) Projects가 적합한 경우**

같은 데이터와 목적을 이용하여 지속적으로 작업한다면 `Projects`가 적합하다.

예를 들어 다음과 같은 운동역학 프로젝트를 수행한다고 가정한다.

```text
IMU 데이터 확인
        ↓
데이터 전처리
        ↓
보행 구간 분리
        ↓
입력 시퀀스 생성
        ↓
LSTM 모델 생성
        ↓
모델 학습
        ↓
무릎 관절각 예측
        ↓
RMSE / MAE 평가
        ↓
예측 결과 해석
```

이 과정에서는 동일한 데이터와 분석 목적을 계속 사용하게 된다.

따라서 다음과 같은 Project를 구성할 수 있다.

```text
운동역학 딥러닝 예측모델 Project

├─ 지침
│   └─ 운동역학 및 딥러닝 분석 기준
│
├─ 메모리
│   └─ 이전 분석 및 모델링 과정
│
├─ 컨텍스트
│   ├─ imu_data.csv
│   ├─ joint_angle.csv
│   ├─ subject_info.csv
│   └─ variable_description.md
│
└─ Chats
    ├─ 데이터 EDA
    ├─ 전처리
    ├─ LSTM 모델링
    ├─ 모델 평가
    └─ 결과 해석
```

<br>

> ## **2-3 ) Chat과 Projects 비교**

| 구분 | Chat | Projects |
|---|---|---|
| 주요 목적 | 독립적인 질문 | 지속적인 프로젝트 |
| 데이터 사용 | 필요할 때 직접 제공 | 공통 자료를 등록하여 활용 |
| 이전 작업 | 현재 Chat 중심 | Project의 맥락 활용 |
| 여러 작업 관리 | 하나의 대화 중심 | 여러 Chat으로 분리 가능 |
| 적합한 예시 | LSTM 개념 질문 | 보행 예측모델 개발 |
| 작업 연속성 | 상대적으로 낮음 | 높음 |

쉽게 정리하면 다음과 같다.

```text
한 번 질문하고 해결
→ Chat

같은 목적 + 같은 데이터 + 반복 작업
→ Projects
```

# **3. Projects의 지침, 메모리, 컨텍스트**

Claude Projects에서는 `지침`, `메모리`, `컨텍스트`를 이용하여 하나의 작업 환경을 구성할 수 있다.

> ## **3-1 ) 지침(Instructions)**

`지침`은 Claude가 해당 Project에서 **어떤 방식으로 작업할 것인지** 설정하는 영역이다.

운동역학 딥러닝 Project라면 다음과 같이 설정할 수 있다.

[Prompt : code] "운동역학 딥러닝 Project 지침"

```text
이 Project는 운동역학 데이터를 이용하여
딥러닝 기반 예측모델을 개발하기 위한 공간입니다.

Python을 사용하고
데이터 처리는 Pandas와 NumPy,
딥러닝 모델은 TensorFlow/Keras를 기준으로 설명해주세요.

주요 목표는 IMU 센서 데이터를 이용하여
보행 중 무릎 관절각을 예측하는 것입니다.

코드를 작성할 때는
1. 코드의 목적
2. 주요 변수
3. 코드 실행 결과의 의미
순서로 설명해주세요.

처음 배우는 사람도 이해할 수 있도록
복잡한 수식보다는 개념과 예시를 중심으로 설명해주세요.
```

이렇게 설정하면 새로운 Chat을 시작하더라도 Project에서 공통적으로 적용할 기준을 유지할 수 있다.

<br>

> ## **3-2 ) 메모리(Memory)**

`메모리`는 Project에서 지금까지 진행한 대화와 작업의 맥락을 이후 작업에 활용하는 기능이다.

예를 들어 이전 작업에서 다음과 같은 결정을 했다고 가정한다.

```text
입력 데이터
→ IMU 가속도 + 각속도

타깃
→ 무릎 굴곡각

Window Size
→ 100

모델
→ LSTM

평가지표
→ MAE, RMSE
```

이후 다른 Chat에서 모델 성능을 개선할 때 이러한 기존 작업의 맥락을 활용할 수 있다.

즉,

```text
메모리
→ 지금까지 어떻게 작업했는가?
```

를 담당한다고 생각하면 된다.

<br>

> ## **3-3 ) 컨텍스트(Context)**

`컨텍스트`에는 Claude가 반복적으로 참고해야 하는 파일이나 문서를 추가한다.

운동역학 딥러닝 Project에서는 다음과 같은 파일을 등록할 수 있다.

```text
imu_data.csv
joint_angle.csv
subject_info.csv
variable_description.md
experiment_protocol.pdf
```

각 파일의 역할은 다음과 같이 구분할 수 있다.

| 파일 | 역할 |
|---|---|
| `imu_data.csv` | 가속도·각속도 센서 데이터 |
| `joint_angle.csv` | 실제 관절각 데이터 |
| `subject_info.csv` | 피험자 특성 |
| `variable_description.md` | 변수 설명 |
| `experiment_protocol.pdf` | 실험 방법 및 측정 조건 |

<br>

> ## **3-4 ) 지침·메모리·컨텍스트 차이**

세 개념은 다음과 같이 구분하면 이해하기 쉽다.

| 구분 | 핵심 질문 | 예시 |
|---|---|---|
| 지침 | 어떻게 작업할 것인가? | Python 사용, 초보자 수준 설명 |
| 메모리 | 지금까지 어떻게 작업했는가? | LSTM 사용 결정 |
| 컨텍스트 | 어떤 자료를 참고할 것인가? | IMU 데이터, 관절각 데이터 |

```text
지침
→ 어떻게 할 것인가?

메모리
→ 지금까지 무엇을 했는가?

컨텍스트
→ 무엇을 참고할 것인가?
```

# **4. 운동역학 딥러닝 Project 활용**

Projects는 실제 데이터 분석뿐만 아니라 학습 환경을 만드는 데에도 사용할 수 있다.

> ## **4-1 ) 운동역학 딥러닝 학습 Project**

예를 들어 현재 학습 수준을 다음과 같이 설정할 수 있다.

[Prompt : code] "학습 수준을 반영한 Project 지침"

```text
운동역학과 딥러닝을 공부하기 위한 Project입니다.

Python과 Pandas의 기본적인 사용법은 알고 있습니다.

머신러닝에서는
선형회귀, 로지스틱회귀, Decision Tree 정도를 알고 있지만
딥러닝은 처음 공부하고 있습니다.

운동역학에서는
관절각, 지면반력, 보행주기의 기본 개념을 알고 있습니다.

딥러닝을 설명할 때는
수식을 자세히 유도하기보다는
운동역학 데이터를 예시로 사용해서 설명해주세요.

가능하면 Python 예제 코드도 함께 제공해주세요.
```

이후 새로운 Chat에서 다음과 같이 바로 질문할 수 있다.

```text
LSTM이 보행 데이터 분석에 왜 적합한지 설명해줘.
```

또 다른 Chat에서는

```text
1D-CNN과 LSTM을 이용해서
IMU 데이터로 무릎 관절각을 예측한다면
두 모델의 차이를 설명해줘.
```

처럼 질문할 수 있다.

<br>

> ## **4-2 ) Projects는 반드시 파일이 필요한 것은 아니다**

Projects를 사용하는 목적은 파일을 저장하는 것이 아니라 **같은 목적과 맥락을 반복해서 활용할 수 있는 환경을 만드는 것**이다.

예를 들어 두 Project는 다음과 같이 다르게 구성할 수 있다.

| Project | 지침 | 컨텍스트 |
|---|---|---|
| 운동역학 딥러닝 학습 | 현재 학습 수준, 설명 방식 | 없어도 가능 |
| 운동역학 예측모델 개발 | 모델링 규칙, 분석 방법 | IMU, 관절각 데이터 |

즉,

```text
학습 중심 Project
→ 지침 중심

실제 분석 Project
→ 지침 + 데이터 컨텍스트
```

와 같이 필요한 요소만 선택하여 구성하면 된다.

# **5. 운동역학 딥러닝 예측모델 질문 예시**

> ## **5-1 ) 첫 번째 질문 - 문제 정의**

[Prompt : code] "운동역학 예측 문제 정의"

```text
보행 중 허리에 부착한 IMU 센서의
가속도와 각속도를 이용해서
무릎 굴곡각을 예측하는 모델을 만들고 싶어.

이 문제를 머신러닝 관점에서
입력 변수, 타깃 변수, 문제 유형으로 구분해서 설명해줘.
```

[ Result ]

```text
입력 변수
- 가속도 X, Y, Z
- 각속도 X, Y, Z

타깃 변수
- 무릎 굴곡각

문제 유형
- 연속적인 숫자를 예측하므로 회귀 문제
- 시간 순서가 존재하므로 시계열 예측 문제로 볼 수 있음
```

<br>

> ## **5-2 ) 두 번째 질문 - 모델 선택**

앞의 내용을 다시 전부 설명하지 않고 후속 질문을 할 수 있다.

[Prompt : code] "딥러닝 모델 선택"

```text
그 데이터라면
LSTM, GRU, 1D-CNN 중 어떤 모델부터 실험하는 게 좋을까?
각 모델의 장단점도 비교해줘.
```

| 모델 | 장점 | 단점 |

> ## **5-3 ) 세 번째 질문 - 조건 구체화**

[Prompt : code] "모델 구현 조건 추가"

```text
우선 LSTM으로 해볼게.

입력 데이터는
가속도 X, Y, Z와
각속도 X, Y, Z 총 6개 변수이고,

100개의 시점을 하나의 Window로 사용해서
현재 시점의 무릎 굴곡각을 예측하고 싶어.

TensorFlow/Keras 예제 코드를 작성해줘.
```

[Python : code] "IMU 시계열 데이터를 이용한 LSTM 회귀모델 예시"

```python
import tensorflow as tf
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import LSTM, Dense

model = Sequential([
    LSTM(
        units=64,
        input_shape=(100, 6)
    ),
    Dense(32, activation='relu'),
    Dense(1)
])

model.compile(
    optimizer='adam',
    loss='mse',
    metrics=['mae']
)

model.summary()
```

[ Result ]

```text
Input
(100 time steps, 6 features)
        ↓
LSTM
64 units
        ↓
Dense
32 units
        ↓
Output
1 predicted knee angle
```

이 모델에서 입력 데이터의 형태는 다음과 같다.

```text
(samples, time_steps, features)

예:
(5000, 100, 6)
```

각 요소는 다음을 의미한다.

| 요소 | 의미 |
|---|---|
| `5000` | 학습에 사용하는 Window 개수 |
| `100` | 하나의 Window에 포함된 시점 |
| `6` | 가속도 3개 + 각속도 3개 |
| `Dense(1)` | 하나의 무릎 굴곡각 예측 |

**코드 결과 해석**

`LSTM(64)`는 100개 시점의 IMU 움직임 패턴을 학습한다.

이후 `Dense(32)`에서 특징을 조합하고 마지막 `Dense(1)`에서 하나의 연속적인 관절각 값을 예측한다.

전체 흐름은 다음과 같다.

```text
IMU 원본 데이터
       ↓
가속도 + 각속도 선택
       ↓
100개 시점 Window 생성
       ↓
LSTM
       ↓
시간적 움직임 패턴 학습
       ↓
Dense Layer
       ↓
무릎 굴곡각 예측
       ↓
실제 관절각과 비교
       ↓
MAE / RMSE 평가
```

# **6. 효과적으로 Claude에게 질문하는 방법**

> ## **6-1 ) 단순 질문보다 컨텍스트를 포함하기**

다음 질문은 정보가 부족하다.

```text
딥러닝 모델 만들어줘.

다음과 같이 구체적으로 작성하는 것이 좋다.

보행 IMU 데이터를 이용해서

입력 변수는 가속도와 각속도 6개이고,
타깃은 무릎 굴곡각이야.

데이터는 100Hz로 측정됐고
LSTM 기반 회귀모델을 만들어보고 싶어.

먼저 데이터 전처리부터 모델 평가까지
전체 분석 순서를 설명해줘.
```

좋은 프롬프트에는 다음과 같은 정보가 포함될 수 있다.

| 요소 | 예시 |
|---|---|
| 목적 | 무릎 관절각 예측 |
| 데이터 | IMU 센서 |
| 입력 변수 | 가속도, 각속도 |

| 사용 언어 | Python |
| 원하는 결과 | 코드 + 설명 |
| 사용자 수준 | 딥러닝 초보자 |

<br>

> ## **6-2 ) 한 번에 모든 것을 질문할 필요는 없다**

생성형 AI를 사용할 때 처음부터 완벽한 질문을 작성하려고 할 필요는 없다.

다음과 같이 단계적으로 질문하는 것도 좋은 방법이다.

```text
1단계
IMU로 관절각을 예측할 수 있어?

        ↓

2단계
LSTM을 사용하는 이유가 뭐야?

        ↓

3단계
입력 데이터 형태는 어떻게 만들어야 해?

        ↓

4단계
Window Size는 무엇이야?

        ↓

5단계
Python 코드로 만들어줘.

        ↓

6단계
RMSE와 MAE로 평가하는 방법도 알려줘.

        ↓

7단계
성능이 좋지 않으면 무엇을 수정해야 해?
```

즉, Claude Chat은 **질문 → 확인 → 후속 질문 → 조건 구체화** 방식으로 활용하는 것이 효과적이다.

# **8. Advanced 추가 학습**

> ## **8-1 ) 좋은 컨텍스트는 많다고 항상 좋은 것은 아니다**

Claude에게 정보를 많이 제공한다고 항상 더 좋은 결과가 나오는 것은 아니다.

현재 작업과 관련 없는 정보를 너무 많이 제공하면 중요한 정보가 묻힐 수 있다.

따라서 다음과 같이 생각하면 된다.

```text
좋은 컨텍스트
= 필요한 정보 + 명확한 목적 + 적절한 조건
```

<br>

> ## **8-2 ) 운동역학 예측모델에서는 데이터 분할도 중요하다**

운동역학 데이터에서는 같은 피험자의 데이터가 학습 데이터와 테스트 데이터에 동시에 포함되면 모델 성능이 실제보다 높게 평가될 수 있다.

따라서 실제 연구에서는 단순한 무작위 분할뿐만 아니라

```text
Subject-wise Split
Leave-One-Subject-Out
Group K-Fold
```

등 **피험자 단위 데이터 분할 방법**도 함께 공부할 필요가 있다.

# **9. 핵심정리**

1. `Claude Chat`에서는 자연어로 질문하고 답변을 확인하면서 후속 질문을 이어갈 수 있다.

2. 같은 Chat에서는 이전 대화의 내용을 컨텍스트로 활용하므로 매번 모든 내용을 처음부터 다시 설명할 필요가 없다.

3. `Context`는 Claude가 답변할 때 참고하는 현재 대화, 사용자 제공 정보, 파일 등의 전체적인 맥락을 의미한다.

4. 독립적이고 일회성인 질문은 `Chat`, 같은 목적과 데이터를 반복해서 사용하는 작업은 `Projects`가 적합하다.

5. Projects는 `지침`, `메모리`, `컨텍스트`, 여러 `Chat`을 이용하여 하나의 작업 환경을 구성할 수 있다.

6. `지침`은 **어떻게 작업할지**, `메모리`는 **지금까지 어떤 맥락으로 작업했는지**, `컨텍스트`는 **어떤 자료를 참고할지**를 담당한다.

7. Projects는 반드시 파일이 필요한 것은 아니며 학습 수준이나 원하는 설명 방식을 지침으로 설정하는 학습용 Project로도 사용할 수 있다.

8. 운동역학 딥러닝 Project에서는 `IMU → 전처리 → Window 생성 → LSTM → 관절각 예측 → MAE/RMSE 평가`와 같은 전체 분석 과정을 여러 Chat으로 나누어 관리할 수 있다.

9. 좋은 프롬프트를 작성하려면 **목적, 데이터, 입력 변수, 타깃, 분석 방법, 사용 도구, 원하는 결과 형식**을 가능한 한 명확하게 전달하는 것이 좋다.

10. 생성형 AI의 답변과 코드는 항상 정확하다고 볼 수 없으므로 실제 데이터 분석이나 연구에 적용하기 전 반드시 직접 검증해야 한다.
