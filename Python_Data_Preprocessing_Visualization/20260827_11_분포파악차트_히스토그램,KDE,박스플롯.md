# **1. 히스토그램(Histogram)**

히스토그램은 **연속형 수치 데이터를 일정한 구간(Bin)으로 나누고, 각 구간에 데이터가 몇 개 포함되는지 빈도로 나타내는 차트**임.

데이터가 어느 범위에 많이 몰려 있는지, 분포가 한쪽으로 치우쳐 있는지, 봉우리가 하나인지 여러 개인지 등을 확인할 때 유용함.

> ## **1-1 ) 히스토그램의 구조**

히스토그램의 기본 구조는 다음과 같음.

```text
X축
→ 데이터 값의 구간

Y축
→ 각 구간에 포함된 데이터 개수
```

예를 들어 선수들의 주간 훈련시간이 다음과 같다고 가정함.

```text
40, 42, 44, 46, 48,
50, 52, 54, 56, 58
```

이를 구간별로 나누면 다음과 같이 생각할 수 있음.

```text
40 ~ 45 → 3명
45 ~ 50 → 2명
50 ~ 55 → 3명
55 ~ 60 → 2명
```

[ python : code ] "선수들의 주간 훈련시간 분포를 히스토그램으로 시각화"

```python
import matplotlib.pyplot as plt

training_hours = [
    40, 42, 44, 46, 48,
    50, 52, 54, 56, 58
]

plt.hist(
    training_hours,
    bins=[40, 45, 50, 55, 60],
    edgecolor="white"
)

plt.xlabel("Training Hours")
plt.ylabel("Frequency")
plt.title("Weekly Training Hours Distribution")

plt.show()
```

[ Result ]

```text
40 이상 45 미만 → 3명
45 이상 50 미만 → 2명
50 이상 55 미만 → 3명
55 이상 60 이하 → 2명

총 데이터 수
= 3 + 2 + 3 + 2
= 10명
```

히스토그램에서는 막대의 높이를 통해 어떤 구간에 데이터가 많이 몰려 있는지 확인할 수 있음.

<br>

> ## **1-2 ) 히스토그램과 막대그래프 차이**

히스토그램과 막대그래프는 모두 막대를 사용하지만 의미가 다름.

| 구분 | 히스토그램 | 막대그래프 |
| --- | --- | --- |
| 주요 데이터 | 연속형 수치 데이터 | 범주형 데이터 |
| X축 | 수치 구간 | 범주 |
| 막대 의미 | 구간별 빈도 | 범주별 값 |
| 막대 순서 | 수치 순서에 의미 있음 | 필요에 따라 변경 가능 |
| 주요 목적 | 분포 확인 | 그룹 비교 |

예.

```text
선수 체중의 분포
→ 히스토그램

종목별 선수 수
→ 막대그래프
```

<br>

> ## **1-3 ) bins의 의미**

`bins`는 히스토그램에서 데이터를 몇 개의 구간으로 나눌지 결정하는 값임.

```python
plt.hist(
    data,
    bins=20
)
```

이라면 전체 데이터 범위를 20개의 구간으로 나누어 빈도를 계산함.

같은 데이터라도 `bins` 값에 따라 그래프 모양이 달라질 수 있음.

```text
bins 너무 적음
→ 여러 값이 큰 구간 하나에 묶임
→ 세부 패턴이 사라질 수 있음

bins 적절
→ 전체 분포와 세부 형태를 함께 확인

bins 너무 많음
→ 막대가 지나치게 잘게 나뉨
→ 노이즈가 강조될 수 있음
```

`plt.hist()`의 기본 `bins` 값은 `10`이며 다음처럼 자동 규칙을 사용할 수도 있음.

```python
plt.hist(
    data,
    bins="auto"
)
```

따라서 특정 숫자를 항상 사용하는 것이 아니라 **표본 크기와 분석 목적에 맞게 여러 값을 비교해보는 것이 중요함.**

<br>

> ## **1-4 ) bins 값에 따른 차이 비교**

같은 보행속도 데이터를 서로 다른 `bins` 값으로 확인한다고 가정함.

[ python : code ] "같은 보행속도 데이터를 bins=5와 bins=10으로 비교"

```python
import matplotlib.pyplot as plt

gait_speed = [
    0.9, 1.0, 1.0, 1.1, 1.1,
    1.2, 1.2, 1.2, 1.3, 1.3,
    1.4, 1.4, 1.5, 1.5, 1.6
]

fig, axes = plt.subplots(2, 2, figsize=(10, 7))

axes = axes.flatten()

for ax, bins in zip(axes, range(5, 25, 5)):

    ax.hist(gait_speed, bins=bins,edgecolor="white")

    ax.set_title(f"Gait Speed - bins={bins}")
    ax.set_xlabel("Speed")
    ax.set_ylabel("Frequency")

plt.tight_layout()
plt.show()
```

[ Result ]

```text
첫 번째 그래프
→ 5개의 넓은 구간으로 분포가 표현됨
→ 전체적인 분포 형태를 비교적 단순하게 확인 가능

두 번째 그래프
→ 10개의 더 좁은 구간으로 표현됨
→ 값이 어느 위치에 세부적으로 모여 있는지 더 자세히 확인 가능
```

같은 데이터이므로 데이터 자체는 변하지 않고 **구간을 나누는 방식만 달라짐.**

<br>

> ## **1-5 ) 히스토그램에서 확인할 내용**

히스토그램에서는 다음 항목을 중심으로 확인함.

```text
어느 구간에 데이터가 가장 많이 몰려 있는가?

분포가 좌우 대칭인가?

오른쪽 또는 왼쪽으로 꼬리가 긴가?

봉우리가 하나인가?

여러 개의 봉우리가 존재하는가?

극단적으로 떨어진 값이 있는가?
```

예를 들어.

```text
오른쪽으로 긴 꼬리
→ Right Skew 가능성

왼쪽으로 긴 꼬리
→ Left Skew 가능성

봉우리 2개
→ 서로 다른 두 집단이 섞여 있을 가능성 탐색
```

단, 그래프 모양 하나만으로 원인을 확정하지 않고 추가 분석이 필요함.

> ## **1-6 ) Matplotlib 한글 폰트 설정**

Matplotlib 실행 환경의 기본 폰트가 한글 글리프를 지원하지 않으면 제목이나 축 이름이 깨져 보일 수 있음.

Windows와 Mac에서는 다음처럼 기본 한글 폰트를 지정할 수 있음.

[ python : code ] "운영체제에 따라 Matplotlib 한글 폰트 설정"

```python
import matplotlib.pyplot as plt
import platform

if platform.system() == "Windows":
    plt.rcParams["font.family"] = "Malgun Gothic"

elif platform.system() == "Darwin":
    plt.rcParams["font.family"] = "AppleGothic"

plt.rcParams["axes.unicode_minus"] = False
```

`axes.unicode_minus=False`는 음수 기호가 환경에 따라 깨지는 문제를 줄일 때 사용할 수 있음.

# **2. KDE(Kernel Density Estimation)**

KDE는 **데이터 분포를 부드러운 연속 곡선으로 추정하여 표현하는 방법**임.

히스토그램처럼 데이터가 어느 위치에 많이 몰려 있는지 확인할 수 있지만, 막대 대신 곡선을 이용함.

> ## **2-1 ) KDE의 기본 개념**

KDE는 각 데이터 주변에 작은 Kernel을 배치한 뒤 이를 합쳐 전체 분포 형태를 추정함.

개념적으로는 다음처럼 이해할 수 있음.

```text
각 데이터 포인트
      ↓
주변에 작은 곡선 배치
      ↓
모든 곡선을 합침
      ↓
부드러운 밀도 곡선 생성
```

KDE의 Y축은 실제 사람 수나 데이터 개수가 아니라 **확률 밀도(Density)** 를 나타냄.

따라서.

```text
Y축이 10
→ 데이터 10개
```

처럼 해석하면 안 됨.

<br>

> ## **2-2 ) 두 그룹의 분포 비교**

두 육상팀의 훈련시간 분포를 비교한다고 가정함.

[ python : code ] "두 육상팀의 훈련시간 분포를 KDE로 비교"

```python
import seaborn as sns
import matplotlib.pyplot as plt

team_a = [
    40, 42, 44, 45, 46,
    48, 50, 52, 53, 55,
    56, 58, 60, 62, 64
]

team_b = [
    50, 52, 54, 55, 57,
    58, 60, 62, 63, 65,
    67, 68, 70, 72, 75
]

sns.kdeplot(
    team_a,
    label="Team A",
    fill=True
)

sns.kdeplot(
    team_b,
    label="Team B",
    fill=True
)

plt.xlabel("Training Time")
plt.ylabel("Density")
plt.title("Training Time Distribution by Team")
plt.legend()

plt.show()
```

[ Result ]

```text
Team A와 Team B의 훈련시간 분포가
각각 부드러운 KDE 곡선으로 출력됨.

Team A
→ 약 40~64 구간에 데이터 존재

Team B
→ 약 50~75 구간에 데이터 존재

Team B의 실제 관측값 범위가 Team A보다 전반적으로 높은 쪽에 위치함.
```

KDE는 정확한 인원수를 읽기보다 **두 그룹의 전체적인 분포 위치와 형태를 비교**할 때 유용함.

<br>

> ## **2-3 ) 히스토그램과 KDE 비교**

| 구분 | 히스토그램 | KDE |
| --- | --- | --- |
| 표현 | 막대 | 부드러운 곡선 |
| Y축 | 빈도 | 밀도 |
| 구간 설정 | `bins` 필요 | Kernel과 Bandwidth 사용 |
| 실제 개수 확인 | 쉬움 | 어려움 |
| 분포 형태 비교 | 가능 | 특히 편리 |
| 그룹 중첩 비교 | 가능하지만 복잡할 수 있음 | 비교적 직관적 |

```text
"몇 개가 있는가?"
→ 히스토그램

"전체적인 분포 모양이 어떻게 다른가?"
→ KDE
```

<br>

> ## **2-4 ) KDE에서 확인할 내용**

KDE에서는 다음 특징을 확인할 수 있음.

```text
곡선의 봉우리는 어디인가?

봉우리가 하나인가 여러 개인가?

한쪽으로 꼬리가 길게 나타나는가?

두 그룹의 곡선이 얼마나 겹치는가?

어느 그룹이 상대적으로 오른쪽 또는 왼쪽에 위치하는가?
```

단, KDE는 실제 데이터 자체가 아니라 **분포를 추정한 곡선**이라는 점을 기억해야 함.

# **3. 박스플롯(Box Plot)**

박스플롯은 데이터의 **중앙값, 사분위수, 퍼짐 정도, 잠재적 이상치**를 한눈에 확인하기 좋은 차트임.

특히 여러 그룹의 분포를 간결하게 비교할 때 유용함.

> ## **3-1 ) 박스플롯의 구성 요소**

| 구성 요소 | 의미 |
| --- | --- |
| 박스 내부 선 | 중앙값 `Q2` |
| 박스 하단 | `Q1`, 25번째 백분위수 |
| 박스 상단 | `Q3`, 75번째 백분위수 |
| 박스 크기 | `IQR = Q3 - Q1` |
| 수염 | IQR 기준 범위 안에 있는 데이터의 범위 |
| 수염 바깥 점 | 잠재적 이상치 |

IQR은 다음과 같이 계산함.

```text
IQR
= Q3 - Q1
```

일반적인 이상치 후보 경계는 다음과 같음.

```text
하한선
= Q1 - 1.5 × IQR

상한선
= Q3 + 1.5 × IQR
```

<br>

> ## **3-2 ) 박스플롯으로 이상치 후보 확인**

운동 수행시간 데이터가 다음과 같다고 가정함.

[ python : code ] "운동 수행시간의 박스플롯 생성"

```python
import matplotlib.pyplot as plt

work_times = [
    20, 21, 22, 23, 23,
    24, 24, 25, 25, 26,
    26, 27, 27, 28, 29,
    30, 31, 32, 65, 72
]

plt.boxplot(
    work_times
)

plt.ylabel("Time")
plt.title("Performance Time Box Plot")

plt.show()
```

[ Result ]

```text
중앙값을 나타내는 선과
Q1~Q3 범위의 박스가 출력됨.

65와 72는 다른 값들과 크게 떨어져 있어
박스플롯에서 수염 바깥의 점으로 표시됨.
```

실제 사분위수를 계산하면 다음과 같음.

```text
Q1
= 23.75

Median
= 26.00

Q3
= 29.25
```

IQR.

```text
IQR
= 29.25 - 23.75
= 5.5
```

하한선.

```text
23.75 - (1.5 × 5.5)
= 23.75 - 8.25
= 15.5
```

상한선.

```text
29.25 + (1.5 × 5.5)
= 29.25 + 8.25
= 37.5
```

따라서.

```text
65 > 37.5
72 > 37.5

→ IQR 기준 이상치 후보
```

임.

<br>

> ## **3-3 ) 박스플롯의 이상치는 오류값이라는 뜻이 아님**

박스플롯에서 수염 바깥에 점이 나타났다고 해서 반드시 삭제해야 하는 데이터는 아님.

```text
박스플롯 이상치 표시
      ↓
IQR 기준에서 다른 값과 멀리 떨어져 있음
      ↓
오류인지 실제 관측값인지 확인
      ↓
분석 목적에 따라 처리 여부 결정
```

예를 들어 엘리트 선수의 매우 높은 기록이라면 실제로 중요한 데이터일 수 있음.

<br>

> ## **3-4 ) 두 그룹의 박스플롯 비교**

온라인과 오프라인 대신 두 훈련 그룹의 회복일수를 비교한다고 가정함.

[ python : code ] "두 훈련 그룹의 회복일수 분포를 박스플롯으로 비교"

```python
import matplotlib.pyplot as plt

group_a = [
    2, 2, 3, 3, 3,
    4, 4, 4, 5
]

group_b = [
    3, 4, 4, 5, 5,
    5, 6, 6, 7
]

plt.boxplot(
    [
        group_a,
        group_b
    ],
    tick_labels=[
        "Group A",
        "Group B"
    ]
)

plt.ylabel("Recovery Days")
plt.title("Recovery Days by Group")

plt.show()
```

[ Result ]

```text
Group A와 Group B의 박스플롯이
하나의 그래프에 나란히 출력됨.

Group A 중앙값
= 3

Group B 중앙값
= 5

따라서 이 예제에서는 Group B의 중앙값이 더 높음.
```

박스플롯을 여러 그룹으로 그리면 단순 평균뿐 아니라.

```text
중앙값
IQR
전체적인 퍼짐
이상치 후보
```

를 동시에 비교할 수 있음.

# **4. 히스토그램 · KDE · 박스플롯 비교**

세 차트는 모두 데이터의 분포를 확인하지만 **강조하는 정보가 다름.**

> ## **4-1 ) 동일한 데이터를 세 차트로 비교**

다음과 같은 측정시간 데이터가 있다고 가정함.

```python
delivery_times = [
    1.2, 1.5, 1.7, 1.8, 2.0,
    2.0, 2.1, 2.2, 2.3, 2.4,
    2.5, 2.6, 2.7, 2.8, 3.0,
    3.1, 3.2, 3.5, 6.5, 8.0
]
```

대부분 `1.2~3.5` 사이지만 `6.5`, `8.0`이 멀리 떨어져 있음.

[ python : code ] "같은 데이터를 히스토그램·KDE·박스플롯으로 각각 확인"

```python
import matplotlib.pyplot as plt
import seaborn as sns

# 데이터 생성
delivery_times = [
    1.2, 1.5, 1.7, 1.8, 2.0,
    2.0, 2.1, 2.2, 2.3, 2.4,
    2.5, 2.6, 2.7, 2.8, 3.0,
    3.1, 3.2, 3.5, 6.5, 8.0
]

# subplot 생성
fig, axes = plt.subplots(
    nrows=1,
    ncols=3,
    figsize=(12, 4)
)

# 1. Histogram
axes[0].hist(
    delivery_times,
    bins=5,
    edgecolor="white"
)
axes[0].set_title("Histogram")

# 2. KDE
sns.kdeplot(
    delivery_times,
    fill=True,
    ax=axes[1]
)
axes[1].set_title("KDE")

# 3. Box Plot
axes[2].boxplot(
    delivery_times
)
axes[2].set_title("Box Plot")

# 그래프 간격 자동 조절
plt.tight_layout()

plt.show()
```

# **6. Advanced 추가 학습**

> ## **6-1 ) 박스플롯의 수염을 정확하게 해석하기**

IQR에서 계산하는.

```text
Q1 - 1.5 × IQR

Q3 + 1.5 × IQR
```

은 **이상치 판정을 위한 경계값(Fence)** 임.

박스플롯의 수염 자체가 반드시 이 숫자까지 그려지는 것은 아니며 일반적으로 **해당 경계 안에 존재하는 실제 데이터 중 가장 바깥쪽 값까지** 수염이 표시됨.

예.

```text
상한선
= 37.5

실제 경계 안의 가장 큰 값
= 32

→ 위쪽 수염은 32까지 표시
```

그리고 `37.5`를 넘는 `65`, `72`는 별도의 점으로 표시됨.

<br>

> ## **6-2 ) KDE의 모양은 Bandwidth의 영향을 받음**

히스토그램의 모양이 `bins`의 영향을 받는 것처럼 KDE는 **Bandwidth**에 따라 곡선의 부드러움이 달라짐.

```text
Bandwidth 너무 작음
→ 작은 변화까지 크게 표현
→ 곡선이 울퉁불퉁할 수 있음

Bandwidth 너무 큼
→ 지나치게 부드러움
→ 실제 세부 구조가 사라질 수 있음
```

따라서 KDE도 하나의 곡선만 보고 분포를 확정하기보다 원본 데이터와 히스토그램을 함께 확인하는 것이 좋음.

<br>

> ## **6-3 ) 표본이 매우 적은 KDE는 주의**

KDE는 적은 데이터에서도 곡선을 그릴 수 있지만 **관측값이 매우 적으면 실제 데이터보다 매끄러운 분포가 존재하는 것처럼 보일 수 있음.**

따라서 표본이 적다면.

```text
원본 값
+
히스토그램
+
KDE
```

를 함께 확인하는 것이 안전함.

<br>

> ## **6-4 ) 왜도(Skewness) 해석**

분포가 한쪽으로 길게 늘어지는 현상을 왜도라고 함.

```text
오른쪽 꼬리가 길다
→ 오른쪽으로 치우친 분포
→ Right Skew / Positive Skew

왼쪽 꼬리가 길다
→ 왼쪽으로 치우친 분포
→ Left Skew / Negative Skew
```

일반적으로 오른쪽으로 치우친 분포에서는 큰 값들이 평균을 끌어올려.

```text
평균 > 중앙값
```

형태가 나타나는 경우가 많음.

왼쪽으로 치우친 분포에서는 반대로.

```text
평균 < 중앙값
```

형태가 나타나는 경우가 많음.

다만 **평균과 중앙값의 관계만으로 왜도를 확정하는 것은 아니며 분포 그래프와 함께 확인해야 함.**

# **7. 핵심정리**

1. 데이터 분석에서 분포를 확인하면 값이 어디에 모여 있는지, 얼마나 퍼져 있는지, 이상치 후보가 존재하는지 파악할 수 있음.

2. 히스토그램은 **연속형 수치 데이터를 구간으로 나누어 각 구간의 빈도를 표현**함.

3. 히스토그램의 X축은 값의 구간, Y축은 해당 구간에 포함된 데이터 개수를 나타냄.

4. `bins` 값에 따라 같은 데이터도 히스토그램의 모양이 달라질 수 있음.

```text
bins 적음
→ 분포 단순화

bins 많음
→ 세부 표현 증가
→ 지나치면 노이즈 증가
```

5. `plt.hist()`의 기본 `bins`는 `10`이며 `bins="auto"`와 같은 자동 규칙도 사용할 수 있음.

6. KDE는 데이터의 분포를 **부드러운 밀도 곡선으로 추정하여 표현**함.

7. KDE의 Y축은 실제 데이터 개수가 아니라 **Density**이므로 히스토그램의 빈도와 동일하게 해석하면 안 됨.

8. KDE는 여러 그룹의 전체적인 분포 위치와 형태를 비교할 때 유용함.

9. 박스플롯은 다음 정보를 한 번에 확인할 수 있음.

```text
Q1
Median
Q3
IQR
수염
이상치 후보
```

10. IQR은 다음과 같이 계산함.

```text
IQR
= Q3 - Q1
```

11. 일반적인 이상치 후보 경계는 다음과 같음.

```text
하한선
= Q1 - 1.5 × IQR

상한선
= Q3 + 1.5 × IQR
```

12. 박스플롯에서 수염 밖의 점은 잠재적 이상치이지만 **잘못된 데이터라는 의미는 아니므로 실제 데이터의 의미를 추가로 확인해야 함.**

13. 히스토그램, KDE, 박스플롯의 핵심 차이는 다음과 같음.

| 차트 | 가장 확인하기 좋은 정보 |
| --- | --- |
| 히스토그램 | 구간별 빈도 |
| KDE | 전체적인 분포 형태 |
| 박스플롯 | 중앙값·IQR·이상치 후보 |

14. 히스토그램에서는 다음을 확인함.

```text
최빈 구간
분포 형태
봉우리 개수
꼬리 방향
```

15. KDE에서는 다음을 확인함.

```text
봉우리 위치
분포의 부드러운 형태
좌우 비대칭
그룹 간 분포 차이
```

16. 박스플롯에서는 다음을 확인함.

```text
중앙값
IQR
퍼짐 정도
이상치 후보
그룹 간 차이
```

17. 히스토그램은 `bins`, KDE는 Bandwidth의 영향을 받기 때문에 그래프 형태를 절대적인 결과로 생각하면 안 됨.

18. 세 차트는 서로를 대체하는 관계가 아니라 **같은 데이터의 서로 다른 특징을 확인하기 위해 함께 활용할 수 있는 보완적인 시각화 도구**임.

19. 분포 분석에서 가장 중요한 것은 하나의 그래프만 보고 결론을 내리는 것이 아니라 다음처럼 통계량과 여러 차트를 함께 확인하는 것임.

```text
describe()
    ↓
히스토그램
    ↓
KDE
    ↓
박스플롯
    ↓
분포·이상치·그룹 차이 종합 해석
```
