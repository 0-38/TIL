# **1. IQR을 이용한 이상치 탐지**

IQR(Interquartile Range, 사분위 범위)은 데이터의 **가운데 50%가 퍼져 있는 범위**를 이용하여 이상치 후보를 탐지하는 방법임.

평균과 표준편차를 직접 사용하지 않고 `Q1`, `Q3`를 이용하기 때문에 극단적인 값의 영향을 상대적으로 덜 받음.

일반적으로 다음 범위를 벗어난 값을 이상치 **후보**로 판단함.

```text
IQR = Q3 - Q1

하한선 = Q1 - 1.5 × IQR
상한선 = Q3 + 1.5 × IQR
```

```text
값 < 하한선
또는
값 > 상한선

→ 이상치 후보
```

여기서 계산된 하한선과 상한선은 절대적인 정상·비정상 기준이 아니라 **IQR 규칙으로 만든 이상치 탐지 경계선(Fence)** 임.

> ## **1-1 ) Q1 · Q3 · IQR의 의미**

| 용어 | 의미 |
| --- | --- |
| `Q1` | 25번째 백분위수 |
| `Q2` | 중앙값, 50번째 백분위수 |
| `Q3` | 75번째 백분위수 |
| `IQR` | `Q3 - Q1` |
| 하한선 | `Q1 - 1.5 × IQR` |
| 상한선 | `Q3 + 1.5 × IQR` |

데이터를 작은 값부터 정렬했을 때.

```text
최솟값 ── Q1 ───── Median ───── Q3 ── 최댓값
          │                      │
          └──── 가운데 50% ─────┘
                  = IQR
```

IQR이 크면 데이터 가운데 50%가 넓게 퍼져 있다는 의미이고, 작으면 상대적으로 좁게 모여 있다는 의미임.

<br>

> ## **1-2 ) IQR 계산 예제**

사이클 선수의 최대 파워 측정값이 다음과 같다고 가정함.

[ python : code ] "사이클 파워 데이터의 IQR과 이상치 경계값 계산"

```python
import pandas as pd

power = pd.Series([
    250,
    260,
    270,
    280,
    290,
    300,
    310,
    320,
    330,
    900
])

Q1 = power.quantile(0.25)
Q3 = power.quantile(0.75)

IQR = Q3 - Q1

lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR

print("Q1:", Q1)
print("Q3:", Q3)
print("IQR:", IQR)
print("하한선:", lower_bound)
print("상한선:", upper_bound)
```

[ Result ]

```text
Q1: 272.5
Q3: 317.5
IQR: 45.0
하한선: 205.0
상한선: 385.0
```

계산 과정.

```text
Q1 = 272.5
Q3 = 317.5

IQR
= 317.5 - 272.5
= 45.0
```

하한선.

```text
272.5 - (1.5 × 45)
= 272.5 - 67.5
= 205.0
```

상한선.

```text
317.5 + (1.5 × 45)
= 317.5 + 67.5
= 385.0
```

따라서 IQR 규칙에서는.

```text
205W 미만
또는
385W 초과
```

인 값을 이상치 후보로 봄.

<br>

> ## **1-3 ) IQR로 이상치 찾기**

[ python : code ] "IQR 경계값을 이용하여 사이클 파워 이상치 탐지"

```python
outliers = power[
    (power < lower_bound) |
    (power > upper_bound)
]

print(outliers)
```

[ Result ]

```text
9    900
dtype: int64
```

`900W`는 상한선 `385W`보다 크기 때문에 이상치 후보로 탐지됨.

```text
900 > 385
→ True
→ 이상치 후보
```

하지만 이 결과만으로 `900W`를 잘못된 값이라고 판단할 수는 없음.

```text
센서 오류인가?
입력 오류인가?
실제로 가능한 스프린트 최대 파워인가?
측정 조건이 다른가?
```

등을 추가로 확인해야 함.

> ## **1-4 ) DataFrame에서 IQR 이상치 탐지**

[ python : code ] "선수별 사이클 파워 데이터에서 이상치 행 추출"

```python
import pandas as pd

df = pd.DataFrame({
    "athlete": [
        "서윤",
        "도현",
        "하린",
        "민재",
        "유나",
        "태민",
        "시우",
        "다은",
        "건우",
        "예린"
    ],
    "power_w": [
        250,
        260,
        270,
        280,
        290,
        300,
        310,
        320,
        330,
        900
    ]
})

Q1 = df["power_w"].quantile(0.25)
Q3 = df["power_w"].quantile(0.75)

IQR = Q3 - Q1

lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR

outliers = df[
    (df["power_w"] < lower_bound) |
    (df["power_w"] > upper_bound)
]

print(
    outliers.to_string(
        index=False
    )
)
```

[ Result ]

```text
athlete  power_w
     예린      900
```

### 흐름도

```text
[power_w 데이터]
       ↓
Q1 계산
       ↓
Q3 계산
       ↓
IQR = Q3 - Q1
       ↓
하한선 / 상한선 계산
       ↓
값 < 하한선 ?
값 > 상한선 ?
       │
   ┌───┴───┐
   ↓       ↓
  Yes      No
   ↓       ↓
이상치    범위 내
후보
```

# **2. Z-score를 이용한 이상치 탐지**

Z-score는 각 데이터가 **평균으로부터 표준편차 몇 배만큼 떨어져 있는지** 나타내는 값임.

공식은 다음과 같음.

```text
          x - 평균
Z-score = ─────────
           표준편차
```

예를 들어 `z = 2`라면 평균보다 표준편차 2배만큼 큰 위치에 있다는 의미임.

일반적으로.

```text
|z| > 3
```

을 이상치 후보 기준으로 많이 사용하지만 절대적인 규칙은 아님.

> ## **2-1 ) Z-score의 의미**

| Z-score | 의미 |
| ---: | --- |
| `0` | 평균과 동일 |
| `1` | 평균보다 표준편차 1배 높음 |
| `-1` | 평균보다 표준편차 1배 낮음 |
| `3` | 평균보다 표준편차 3배 높음 |
| `-3` | 평균보다 표준편차 3배 낮음 |

정규분포에서는 약 99.7%의 값이 평균 ±3 표준편차 범위 안에 존재한다는 **3-sigma 경험 법칙**을 바탕으로 `|z| > 3`을 이상치 후보 기준으로 자주 사용함.

<br>

> ## **2-2 ) Z-score로 달리기 기록 이상치 탐지**

100m 기록 대부분이 약 12초인데 한 기록만 `30초`라고 가정함.

[ python : code ] "100m 기록의 Z-score를 계산하여 이상치 탐지"

```python
import pandas as pd
import numpy as np
from scipy import stats

running = pd.DataFrame({
    "record_sec": [
        12.1, 11.9, 12.0, 12.2, 11.8,
        12.1, 12.0, 11.9, 12.3, 12.0,
        12.1, 11.8, 12.2, 12.0, 11.9,
        12.1, 12.0, 12.2, 11.9, 12.1,
        12.0, 11.8, 12.2, 12.1, 11.9,
        12.0, 12.1, 11.9, 12.0, 30.0
    ]
})

running["z_score"] = stats.zscore(
    running["record_sec"]
)

outliers = running[
    running["z_score"].abs() > 3
]

print(
    outliers.round(3).to_string(
        index=False
    )
)
```

[ Result ]

```text
 record_sec  z_score
       30.0    5.381
```

`30초` 기록의 Z-score는 약 `5.381`임.

```text
|5.381| > 3
→ 이상치 후보
```

`scipy.stats.zscore()`의 기본 설정은 모집단 표준편차 방식인 `ddof=0`을 사용함.

<br>

> ## **2-3 ) Z-score의 특징**

Z-score는 평균과 표준편차를 이용함.

따라서 극단적인 값 자체가.

```text
평균
표준편차
```

를 변화시킬 수 있다는 특징이 있음.

즉 극단값이 많거나 데이터 분포가 크게 치우친 상황에서는 Z-score 기준이 적절하지 않을 수 있음.

<br>

> ## **2-4 ) IQR과 Z-score 비교**

| 구분 | IQR | Z-score |
| --- | --- | --- |
| 기준 | `Q1`, `Q3` | 평균, 표준편차 |
| 분포 가정 | 특정 분포 가정이 적음 | 정규분포에 가까울 때 해석하기 좋음 |
| 극단값 영향 | 상대적으로 적음 | 상대적으로 큼 |
| 비대칭 데이터 | 비교적 활용하기 좋음 | 주의 필요 |
| 대표 기준 | `1.5 × IQR` | `|z| > 3` |
| 결과 의미 | 경계 밖의 이상치 후보 | 평균에서 매우 먼 이상치 후보 |

```text
분포가 치우쳤거나
극단값이 존재
        ↓
IQR 우선 고려

분포가 대칭적이고
정규분포에 가까움
        ↓
Z-score 고려
```

어느 한 방법이 항상 더 좋은 것은 아니며 **데이터 분포와 분석 목적에 따라 선택**해야 함.

# **3. 이상치 처리 전략**

이상치를 탐지하는 것과 처리하는 것은 서로 다른 단계임.

```text
이상치 탐지
    ↓
정말 이상한 값인가?
    ↓
원인과 의미 확인
    ↓
처리 전략 선택
```

대표적인 처리 전략은 다음 세 가지임.

| 전략 | 의미 |
| --- | --- |
| 제거(Drop) | 이상치 Row 제거 |
| Winsorizing | 경계값보다 큰·작은 값을 경계값으로 제한 |
| 보존(Keep) | 원래 값을 그대로 유지 |

> ## **3-1 ) 제거(Drop)**

이상치가 **명백한 입력 오류나 측정 오류**라고 확인된 경우 제거를 고려할 수 있음.

[ python : code ] "IQR 정상 경계 안에 있는 사이클 파워 데이터만 유지"

```python
df_drop = df[
    (df["power_w"] >= lower_bound) &
    (df["power_w"] <= upper_bound)
]

print(
    df_drop.to_string(
        index=False
    )
)
```

[ Result ]

```text
athlete  power_w
     서윤      250
     도현      260
     하린      270
     민재      280
     유나      290
     태민      300
     시우      310
     다은      320
     건우      330
```

`900W` 행이 제거되어 총 9개의 Row가 남음.

단, 실제 기록인 `900W`를 잘못 제거하면 중요한 정보를 잃을 수 있음.

<br>

> ## **3-2 ) Winsorizing**

Winsorizing은 이상치 Row를 제거하지 않고 극단값을 **정해진 경계값으로 제한하는 방식**임.

Pandas에서는 `clip()`을 이용할 수 있음.

[ python : code ] "IQR 경계값으로 사이클 파워를 Winsorizing"

```python
df["power_w_winsorized"] = df[
    "power_w"
].clip(
    lower=lower_bound,
    upper=upper_bound
)

print(
    df.tail(3).to_string(
        index=False
    )
)
```

[ Result ]

```text
athlete  power_w  power_w_winsorized
     다은      320               320
     건우      330               330
     예린      900               385
```

상한선이 `385W`이므로.

```text
900W
 ↓
385W
```

로 제한됨.

원래 10개의 Row는 모두 유지됨.

Winsorizing은 이상치의 영향은 줄일 수 있지만 원래 값을 변경하므로 **정보 왜곡이 발생할 수 있음.**

<br>

> ## **3-3 ) 보존(Keep)**

이상치가 실제로 발생한 중요한 값이라면 그대로 보존할 수 있음.

예를 들어 `900W`가.

```text
센서 오류 X
입력 오류 X
실제 스프린트 최대 파워
```

라고 확인되었다면 분석 목적에 따라 그대로 유지하는 것이 적절할 수 있음.

특히 다음과 같은 분석에서는 이상한 패턴 자체가 중요할 수 있음.

```text
부상 위험 탐지
부정행위 탐지
센서 이상 탐지
기록적인 경기력 분석
희귀 사건 분석
```

<br>

> ## **3-4 ) 이상치 처리 전략 비교**

| 전략 | 적합한 상황 | 장점 | 주의사항 |
| --- | --- | --- | --- |
| 제거 | 명확한 입력·측정 오류 | 오류 영향 제거 | 데이터 손실 |
| Winsorizing | Row 수는 유지하면서 극단값 영향 완화 | 샘플 수 유지 | 실제 값 변경 |
| 보존 | 실제 의미 있는 극단값 | 정보 보존 | 분석·모델에 큰 영향 가능 |

이상치라는 이유만으로 특정 전략을 자동 적용하기보다는 **왜 그 값이 발생했는지를 먼저 확인**해야 함.

# **4. 복합 예제: IQR 탐지부터 처리까지**

보행 분석에서 `step_length_cm` 측정값 중 하나가 비정상적으로 크게 기록되었다고 가정함.

> ## **4-1 ) IQR로 이상치 탐지**

[ python : code ] "보행 보폭 데이터의 IQR 이상치 탐지"

```python
import pandas as pd

gait = pd.DataFrame({
    "subject": [
        "P01",
        "P02",
        "P03",
        "P04",
        "P05",
        "P06",
        "P07",
        "P08",
        "P09",
        "P10"
    ],
    "step_length_cm": [
        60,
        62,
        64,
        66,
        68,
        70,
        72,
        74,
        76,
        150
    ]
})

Q1 = gait[
    "step_length_cm"
].quantile(0.25)

Q3 = gait[
    "step_length_cm"
].quantile(0.75)

IQR = Q3 - Q1

lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR

outliers = gait[
    (gait["step_length_cm"] < lower_bound) |
    (gait["step_length_cm"] > upper_bound)
]

print("Q1:", Q1)
print("Q3:", Q3)
print("IQR:", IQR)
print("하한선:", lower_bound)
print("상한선:", upper_bound)

print()

print(
    outliers.to_string(
        index=False
    )
)
```

[ Result ]

```text
Q1: 64.5
Q3: 73.5
IQR: 9.0
하한선: 51.0
상한선: 87.0

subject  step_length_cm
    P10             150
```

계산.

```text
IQR
= 73.5 - 64.5
= 9
```

하한선.

```text
64.5 - (1.5 × 9)
= 64.5 - 13.5
= 51
```

상한선.

```text
73.5 + (1.5 × 9)
= 73.5 + 13.5
= 87
```

따라서.

```text
150 > 87
```

이므로 `P10`이 이상치 후보로 탐지됨.

<br>

> ## **4-2 ) 탐지 후 처리 판단**

이상치가 발견된 후 다음처럼 판단해야 함.

```text
P10 = 150cm
      ↓
원본 측정 기록 확인
      ↓
┌──────────────────────┐
│ 입력 오류인가?       │
│ 센서 오류인가?       │
│ 실제 측정값인가?     │
└──────────┬───────────┘
           ↓
처리 방법 결정
```

예를 들어.

```text
센서 오류 확인
→ 수정 가능한 원본이 있으면 수정
→ 수정 불가능하고 오류가 명확하면 제거 고려

실제 측정값
→ 보존 고려

데이터 수 유지 필요 + 분석 목적상 극단값 영향 완화
→ Winsorizing 고려
```

### 전체 흐름도

```text
[원본 데이터]
      ↓
분포 확인
      ↓
IQR 또는 Z-score 선택
      ↓
이상치 후보 탐지
      ↓
원인 확인
      │
      ├── 입력 오류
      │      ↓
      │   수정 / 제거
      │
      ├── 측정 오류
      │      ↓
      │   수정 / 제거
      │
      └── 실제 극단값
             ↓
       보존 / 별도 분석
             │
             ↓
필요하면 Winsorizing 검토
             ↓
처리 후 분포 재확인
```

# **5. Advanced 추가 학습**

> ## **5-1 ) Box Plot과 IQR**

Box Plot은 `Q1`, 중앙값, `Q3`, IQR 등을 이용해 데이터 분포를 시각적으로 확인하는 데 유용함.

IQR 방식으로 탐지된 점이 Box Plot의 Whisker 바깥에 표시될 수 있음.

단, Box Plot 바깥의 점도 **자동으로 오류 데이터가 되는 것은 아님.**

<br>

> ## **5-2 ) 그룹별로 이상치 기준이 달라질 수 있음**

전체 데이터에서 하나의 IQR 기준을 적용하는 것이 항상 적절하지는 않음.

예를 들어.

```text
100m 선수
마라톤 선수
```

의 훈련거리 분포는 매우 다를 수 있음.

따라서 필요하면.

```python
df.groupby("sport")
```

등을 이용하여 **종목·성별·연령대 등 의미 있는 그룹별 분포를 확인한 뒤 이상치를 판단**할 수 있음.

<br>

> ## **5-3 ) 머신러닝에서는 Train 데이터 기준으로 처리**

머신러닝에서 IQR 경계나 Winsorizing 경계값을 전체 데이터에서 계산하면 Test 데이터 정보가 전처리에 반영될 수 있음.

따라서 일반적으로.

```text
Train 데이터
      ↓
Q1 / Q3 계산
      ↓
경계값 결정
      ↓
Train 처리
      ↓
동일한 경계값으로 Test 처리
```

하는 방식이 데이터 누수 방지에 적절함.

# **6. 핵심정리**

1. 이상치(Outlier)는 **전체 데이터 분포에서 다른 관측값들과 크게 차이나는 값**임.

2. 이상치 탐지와 이상치 처리는 서로 다른 단계임.

```text
이상치 후보 탐지
      ↓
원인 확인
      ↓
처리 여부 결정
```

3. IQR은 다음과 같이 계산함.

```text
IQR = Q3 - Q1
```

4. 일반적인 IQR 이상치 후보 기준은 다음과 같음.

```text
하한선
= Q1 - 1.5 × IQR

상한선
= Q3 + 1.5 × IQR
```

5. 다음 조건을 만족하면 IQR 기준의 이상치 후보임.

```text
값 < 하한선
또는
값 > 상한선
```

6. IQR은 `Q1`, `Q3`를 이용하므로 극단적인 값의 영향을 평균·표준편차 기반 방법보다 상대적으로 덜 받음.

7. Z-score는 각 값이 평균에서 **표준편차 몇 배만큼 떨어져 있는지** 나타냄.

```text
          x - 평균
Z-score = ─────────
           표준편차
```

8. `|z| > 3`은 흔히 사용하는 이상치 후보 기준이지만 절대적인 규칙은 아님.

9. Z-score는 평균과 표준편차를 사용하므로 극단값의 영향을 받을 수 있으며, 정규분포에 가까운 데이터에서 해석하기 좋음.

10. IQR과 Z-score는 다음과 같이 비교할 수 있음.

| 구분 | IQR | Z-score |
| --- | --- | --- |
| 기준 | 사분위수 | 평균·표준편차 |
| 분포 가정 | 상대적으로 적음 | 정규분포에 가까울 때 적합 |
| 극단값 영향 | 상대적으로 적음 | 상대적으로 큼 |
| 대표 기준 | `1.5 × IQR` | `|z| > 3` |

11. 이상치 처리 방법은 대표적으로 다음 세 가지임.

| 처리 | 의미 |
| --- | --- |
| 제거 | 이상치 Row 삭제 |
| Winsorizing | 이상치를 경계값으로 제한 |
| 보존 | 원래 값을 유지 |

12. 입력 오류나 측정 오류가 명확하다면 수정 또는 제거를 고려할 수 있음.

13. Winsorizing은 Row 수를 유지하면서 극단값의 영향을 줄일 수 있지만 **원래 값을 변경한다는 단점**이 있음.

14. 실제로 발생한 의미 있는 극단값이라면 이상치라는 이유만으로 삭제하지 않고 보존하거나 별도로 분석할 수 있음.

15. 이상치 판단 기준은 전체 데이터에 하나만 적용하기보다 종목·성별·연령대 등 **분포가 본질적으로 다른 그룹별로 따로 검토해야 하는 경우도 있음.**

16. 머신러닝에서는 IQR이나 Winsorizing의 경계값을 **Train 데이터에서 계산한 후 동일한 기준을 Test 데이터에 적용**하여 데이터 누수를 방지해야 함.

17. 이상치 처리의 핵심은 다음 질문임.

```text
"이 값이 다른 값보다 크거나 작다"
        ↓
바로 제거 X

"왜 이 값이 발생했는가?"
        ↓
입력 오류?
측정 오류?
실제 극단값?
        ↓
분석 목적에 맞는 처리 전략 결정
```

18. 따라서 이상치 처리에서 가장 중요한 것은 **탐지 알고리즘 자체보다 이상치가 가진 의미를 파악하고 근거를 가지고 처리 방법을 선택하는 것**임.
