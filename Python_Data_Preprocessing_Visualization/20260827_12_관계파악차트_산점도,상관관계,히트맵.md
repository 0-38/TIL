# **1. 산점도(Scatter Plot)**

산점도는 **두 수치형 변수의 관계를 X축과 Y축의 점으로 표현하는 차트**임.

각 점은 하나의 관측값을 의미하며, 점이 어떤 방향으로 모이는지를 통해 두 변수의 관계 방향과 강도를 탐색할 수 있음.

산점도에 **회귀선(Regression Line)** 을 함께 표시하면 점들의 전체적인 선형 관계 방향을 더욱 쉽게 확인할 수 있음.

이번 강의에서는 산점도, 회귀선, 피어슨 상관계수, 상관관계 히트맵을 비교하기 위해 **동일한 선수 데이터**를 계속 사용함.

> ## **1-1 ) 공통 실습 데이터**

선수 50명의 주간 훈련시간, 경기력 점수, 회복 점수, 평균 수면시간이 다음과 같다고 가정함.

[ python : code ] "관계 분석에서 공통으로 사용할 선수 데이터 생성"

```python
import pandas as pd
import numpy as np

# 난수 고정
np.random.seed(42)

# 선수 이름
names = [
    "서윤", "도현", "하린", "민재", "유나",
    "태민", "시우", "다은", "건우", "예린",
    "준서", "수빈", "현우", "지민", "채원",
    "성민", "가은", "우진", "나연", "정우",
    "소희", "승현", "지우", "재현", "은서",
    "민준", "서연", "동현", "유진", "지훈",
    "혜원", "준혁", "수아", "태현", "아린",
    "승우", "예원", "현준", "다현", "진우",
    "세은", "윤호", "채영", "준영", "하윤",
    "민호", "소연", "태윤", "은우", "지아"
]

n = len(names)

# 훈련 시간
training_hours = np.round(
    np.random.uniform(2, 12, n),
    1
)

# 훈련 시간이 증가할수록 경기력 증가
performance_score = (
    55
    + training_hours * 3.2
    + np.random.normal(0, 4, n)
)

# 훈련 시간이 증가할수록 회복 점수 감소
recovery_score = (
    92
    - training_hours * 2.2
    + np.random.normal(0, 4, n)
)

# 수면 시간
sleep_hours = np.round(
    np.random.normal(7.3, 0.8, n),
    1
)

# 데이터프레임 생성
athletes = pd.DataFrame({
    "athlete": names,
    "training_hours": training_hours,
    "performance_score": np.round(performance_score, 1),
    "recovery_score": np.round(recovery_score, 1),
    "sleep_hours": sleep_hours
})

# 앞의 5행
athletes.head()
```

| 1 | 도현 | 11.5 | 92.5 | 70.6 | 8.3 |
| 2 | 하린 | 9.3 | 84.3 | 68.7 | 6.0 |
| 3 | 민재 | 8.0 | 79.4 | 73.1 | 7.4 |
| 4 | 유나 | 3.6 | 60.6 | 82.5 | 7.5 |

이 데이터를 이용하여 다음 관계를 탐색함.

```text
training_hours
       ↓
performance_score

training_hours
       ↓
recovery_score

sleep_hours
       ↓

```

> ## **1-2 ) 훈련시간과 경기력의 산점도**

X축에 `training_hours`, Y축에 `performance_score`를 사용함.

산점도에 **선형 회귀선(Regression Line)** 을 함께 표시하여 두 변수의 전체적인 관계 방향을 확인함.

Seaborn의 `sns.regplot()`을 사용하면 **산점도와 회귀선을 한 번에 표현**할 수 있음.

[ python : code ] "훈련시간과 경기력 점수의 관계를 산점도와 회귀선으로 시각화"

```python
import seaborn as sns
import matplotlib.pyplot as plt

sns.regplot(
    data=athletes,
    x="training_hours",
    y="performance_score",
    scatter_kws={
        "alpha": 0.7
    },
    line_kws={
        "linewidth": 2,
        "color":"red"
    },
    ci=None
)

plt.xlabel("Training Hours")
plt.ylabel("Performance Score")
plt.title("Training Hours vs Performance Score")

plt.show()
```

단, 이는 현재 데이터의 선형 관계를 설명하는 것이며.

```text
훈련시간을 1시간 증가시키면
경기력이 반드시 3.11점 증가한다.
```

라는 인과관계를 의미하지는 않음.

> ## **1-3 ) 산점도와 회귀선의 관계 방향 해석**

산점도에서는 먼저 점이 어느 방향으로 분포하는지 확인함.

회귀선을 함께 표시하면 데이터의 **전체적인 선형 관계 방향**을 더 쉽게 확인할 수 있음.

| 점과 회귀선의 패턴 | 해석 |
| --- | --- |
| 왼쪽 아래 → 오른쪽 위 | 양의 관계 |
| 왼쪽 위 → 오른쪽 아래 | 음의 관계 |
| 회귀선이 오른쪽 위로 상승 | 양의 선형 관계 |
| 회귀선이 오른쪽 아래로 하락 | 음의 선형 관계 |
| 회귀선 기울기가 거의 0 | 선형 관계가 약할 가능성 |
| 점들이 회귀선 주변에 좁게 모임 | 강한 선형 관계 가능 |
| 점들이 회귀선 주변에서 넓게 퍼짐 | 약한 선형 관계 가능 |

```text
X 증가
+
Y 증가
+
회귀선 상승

→ 양의 선형 관계
```

```text
X 증가
+
Y 감소
+
회귀선 하락

→ 음의 선형 관계
```

회귀선은 여러 점을 정확히 모두 통과하는 선이 아니라 **전체 데이터의 선형적인 경향을 가장 잘 설명하도록 추정된 선**임.

따라서 실제 데이터 포인트는 회귀선 위아래로 퍼져 있을 수 있음.

# **2. 피어슨 상관계수(Pearson Correlation Coefficient)**

산점도가 관계를 시각적으로 확인하는 방법이라면 피어슨 상관계수는 **두 수치형 변수의 선형 관계 방향과 강도를 하나의 숫자로 나타내는 방법**임.

일반적으로 `r`로 표현하며 범위는 다음과 같음.

```text
-1 ≤ r ≤ 1
```

> ## **2-1 ) 피어슨 상관계수의 의미**

| 값 | 의미 |
| ---: | --- |
| `r = 1` | 완전한 양의 선형 관계 |
| `r > 0` | 양의 선형 관계 |
| `r ≈ 0` | 뚜렷한 선형 관계가 약함 |
| `r < 0` | 음의 선형 관계 |
| `r = -1` | 완전한 음의 선형 관계 |

절댓값.

```text
|r|
```

이 `1`에 가까울수록 강한 **선형 관계**를 의미함.

<br>

> ## **2-2 ) 훈련시간과 경기력의 상관계수**

산점도와 회귀선에서 확인했던 동일한 두 변수를 숫자로 확인함.

[ python : code ] "훈련시간과 경기력 점수의 피어슨 상관계수 계산"

```python
correlation = athletes[
    "training_hours"
].corr(
    athletes["performance_score"]
)

print(
    "상관계수:",
    round(correlation, 3)
)
```

[ Result ]

```text
상관계수: 0.926
```

해석.

```text
r = 0.926

0보다 큼
→ 양의 관계

1에 매우 가까움
→ 매우 강한 양의 선형 관계
```

따라서 이 예제 데이터에서는.

```text
훈련시간 ↑
경기력 점수 ↑
```

라는 강한 선형 패턴이 존재함.

산점도의 상승하는 회귀선과도 같은 방향의 결과임.

> ## **2-4 ) 상관계수 강도 해석 시 주의**

다음과 같은 기준을 사용할 때도 있음.

| `|r|` 범위 | 예시 해석 |
| --- | --- |
| `0.7 ~ 1.0` | 강한 관계 |
| `0.3 ~ 0.7` | 중간 정도 관계 |
| `0.0 ~ 0.3` | 약한 관계 |

하지만 이러한 구간은 **절대적인 통계 법칙이 아니라 분야에 따라 달라질 수 있는 경험적 기준**임.

예를 들어 어떤 분야에서는 `r=0.4`도 중요한 관계일 수 있음.

따라서 상관계수는 숫자 하나만 보고 판단하기보다.

```text
상관계수
+
산점도
+
회귀선
+
데이터의 실제 의미
```

를 함께 확인하는 것이 중요함.

> ## **2-5 ) 표준편차 · 공분산 · 상관계수**

피어슨 상관계수는 두 변수의 공분산을 각 변수의 표준편차로 표준화한 값임.

개념적으로.

```text
               X와 Y의 공분산
상관계수 = ───────────────────────
            X 표준편차 × Y 표준편차
```

관련 개념.

| 개념 | 의미 |
| --- | --- |
| 표준편차 | 한 변수의 값이 평균 주변에서 얼마나 퍼져 있는지 |
| 공분산 | 두 변수가 함께 증가하거나 감소하는 정도 |
| 상관계수 | 공분산을 표준화하여 `-1~1` 범위로 표현 |

공분산은 변수의 단위에 영향을 받지만 상관계수는 표준화되므로 서로 다른 변수 관계를 비교하기 쉬움.

# **3. 상관관계 히트맵(Correlation Heatmap)**

두 변수만 확인한다면 산점도와 `corr()`을 사용할 수 있지만, 수치형 변수가 여러 개라면 변수 조합을 하나씩 확인하기 번거로움.

이때.

```python
DataFrame.corr()
```

으로 상관계수 행렬을 만든 뒤.

```python
sns.heatmap()
```

으로 시각화하면 여러 변수의 관계를 한 번에 확인할 수 있음.

> ## **3-1 ) corr()로 상관계수 행렬 생성**

앞에서 사용한 동일한 선수 데이터에서 수치형 변수 네 개를 선택함.

[ python : code ] "선수 데이터의 상관계수 행렬 계산"

```python
numeric_df = athletes[
    [
        "training_hours",
        "performance_score",
        "recovery_score",
        "sleep_hours"
    ]
]

corr = numeric_df.corr()

print(
    corr.round(3)
)
```

[ Result ]

```text
                   training_hours  performance_score  recovery_score  sleep_hours
training_hours              1.000              0.926          -0.825        0.031
performance_score           0.926              1.000          -0.800       -0.048
recovery_score             -0.825             -0.800           1.000       -0.011
sleep_hours                 0.031             -0.048          -0.011        1.000
```

상관계수 행렬은 대칭 구조를 가짐.

예를 들어.

```text
training_hours
vs
performance_score

= 0.926
```

이고 반대 위치의.

```text
performance_score
vs
training_hours

= 0.926
```

도 동일함.

<br>

> ## **3-2 ) 대각선이 모두 1인 이유**

상관계수 행렬의 대각선은 모두 `1`임.

```text
training_hours
vs
training_hours

= 1
```

처럼 각 변수를 자기 자신과 비교하기 때문임.

```text
자기 자신이 증가
→ 자기 자신도 정확히 같은 비율로 증가

따라서
r = 1
```

# **4. 상관관계 ≠ 인과관계**

상관관계(Correlation)는 두 변수가 함께 움직이는 경향을 의미함.

하지만 상관관계가 높거나 회귀선의 기울기가 뚜렷하다고 해서.

```text
X가 Y의 원인이다.
```

라고 바로 결론 내릴 수는 없음.

> ## **4-1 ) 현재 예제의 잘못된 해석**

현재 데이터에서.

```text
training_hours
vs
performance_score

r = 0.926

회귀선
performance_score
= 3.109 × training_hours + 55.580
```

이라는 결과가 나옴.

올바른 해석.

```text
이 데이터에서는
훈련시간이 긴 선수일수록
경기력 점수가 높은 강한 선형 관계가 나타남.

회귀선 역시 양의 기울기를 나타냄.
```

잘못된 해석.

```text
훈련시간을 1시간 늘리면
경기력이 반드시 약 3.11점 증가한다.
```

상관계수와 회귀선만으로는 두 번째 문장을 증명할 수 없음.

<br>

> ## **4-2 ) 제3의 변수 가능성**

훈련시간과 경기력 모두 다른 변수의 영향을 받을 수 있음.

예.

```text
선수 경력
체력 수준
훈련 강도
수면시간
영양 상태
부상 여부
코칭 수준
```

예를 들어 우수한 선수일수록.

```text
훈련시간도 길고
+
경기력도 높음
```

이라는 상황이라면 단순히 훈련시간만으로 경기력 차이를 설명하기 어려움.

<br>

> ## **4-3 ) 교란 변수(Confounding Variable)**

두 변수 모두에 영향을 주어 관계 해석을 복잡하게 만드는 제3의 변수를 교란 변수라고 함.

개념적으로.

```text
        선수 경력
        ↙      ↘
훈련시간        경기력
```

처럼 다른 변수가 두 변수에 동시에 영향을 줄 수 있음.

따라서.

```text
상관관계 발견
      ↓
관련성 확인
      ↓
가능한 교란 변수 탐색
      ↓
추가 분석 또는 연구 설계
```

과정이 필요함.

<br>

> ## **4-4 ) 상관관계와 인과관계 비교**

| 구분 | 상관관계 | 인과관계 |
| --- | --- | --- |
| 의미 | 두 변수가 함께 변하는 경향 | 한 변수의 변화가 다른 변수의 변화를 일으킴 |
| 산점도·상관계수 | 확인 가능 | 이것만으로 확정 불가 |
| 회귀선 | 선형 경향 설명 가능 | 이것만으로 확정 불가 |
| 교란 변수 | 존재할 수 있음 | 통제가 중요 |
| 판단 | 관계 탐색 | 더 엄밀한 연구 설계 필요 |

상관관계와 회귀선은 **인과관계를 탐색하기 위한 중요한 단서**가 될 수 있지만 그 자체가 인과관계의 증명은 아님.

# **5. 관계 분석 전체 흐름**

> ## **5-1 ) 두 변수 관계를 분석하는 순서**

두 수치형 변수의 관계를 확인할 때는 다음처럼 진행할 수 있음.

```text
[분석 질문]
훈련시간과 경기력은 관련이 있는가?
        ↓
변수 타입 확인
        ↓
둘 다 수치형
        ↓
산점도
        ↓
실제 데이터의 분포 확인
        ↓
회귀선
        ↓
전체적인 선형 방향 확인
        ↓
Pearson correlation
        ↓
선형 관계 방향·강도 수치화
        ↓
다른 변수와 관계도 확인
        ↓
상관관계 히트맵
        ↓
교란 변수 가능성 검토
        ↓
인과관계로 과도하게 해석하지 않기
```

<br>

> ## **5-2 ) 산점도 · 회귀선 · 상관계수를 함께 확인해야 하는 이유**

상관계수 하나만 확인하면 관계의 실제 모양을 놓칠 수 있음.

따라서.

```text

→ 전체적인 선형 관계 방향 확인

상관계수
→ 선형 관계의 방향과 강도를 숫자로 확인
```

세 가지를 함께 사용하는 것이 좋음.

```text
Scatter Plot
      +
Regression Line
      +
Correlation
      ↓
더 정확한 선형 관계 탐색
```

# **6. Advanced 추가 학습**

> ## **6-1 ) 상관계수 0은 아무 관계도 없다는 뜻이 아님**

피어슨 상관계수는 주로 **선형 관계**를 측정함.

따라서 두 변수 사이에 강한 곡선 관계가 있어도 피어슨 상관계수가 작게 나타날 수 있음.

예.

```text
Y = X²
```

처럼 U자 형태의 관계에서는.

```text
선형 관계
→ 약할 수 있음

비선형 관계
→ 강하게 존재할 수 있음
```

따라서 `r ≈ 0`을.

```text
두 변수는 아무 관계도 없다.
```

라고 해석하면 안 됨.

<br>

> ## **6-2 ) 이상치가 상관계수와 회귀선에 영향을 줄 수 있음**

피어슨 상관계수는 평균과 표준편차, 공분산을 이용하기 때문에 극단적인 이상치가 결과에 큰 영향을 줄 수 있음.

회귀선 역시 극단적인 관측값의 영향을 받을 수 있음.

따라서 관계 분석 전.

```text
산점도
↓
이상치 확인
↓
회귀선 확인
↓
상관계수 계산
```

순서가 유용함.

<br>

> ## **6-3 ) 결측값과 corr()**

Pandas의 `corr()`은 기본적으로 각 변수 쌍에서 **두 값이 모두 존재하는 관측값을 이용하여 상관계수를 계산**함.

따라서 Column마다 결측 패턴이 다르면 상관계수별로 실제 사용된 Row 수가 달라질 수 있음.

결측이 많다면 상관계수뿐 아니라 사용된 데이터 수와 결측 패턴도 함께 확인하는 것이 좋음.

<br>

> ## **6-4 ) Pearson 외의 상관계수**

상황에 따라 다른 상관계수도 사용할 수 있음.

```python
df.corr(
    method="spearman"
)
```

`Spearman` 상관계수는 값의 순위를 기반으로 관계를 측정함.

기본적인 EDA에서는 Pearson을 많이 사용하지만 **데이터의 특성과 관계 형태에 따라 다른 방법도 고려할 수 있음.**

<br>

> ## **6-5 ) 히트맵의 색상보다 숫자가 핵심**

히트맵 색상은 관계를 빠르게 찾기 위한 보조 수단임.

실제 해석에서는.

```text
색상이 진하다
```

에서 끝내지 말고.

```text
r = 0.80
```

처럼 실제 상관계수의 **부호와 크기**를 함께 확인해야 함.

또한 `cmap`은 변경할 수 있으므로.

```text
빨간색 = 항상 양의 상관
파란색 = 항상 음의 상관
```

이라고 일반화하면 안 됨.

색상의 의미는 **사용한 Color Map 설정에 따라 달라질 수 있음.**

<br>

> ## **6-6 ) sns.regplot()의 ci 옵션**

`sns.regplot()`은 기본적으로 회귀선 주변에 신뢰구간을 함께 표시할 수 있음.

이번 예제에서는 회귀선 자체에 집중하기 위해.

```python
ci=None
```

을 사용함.

```text
ci=None
→ 회귀선만 표시
→ 신뢰구간 음영 제거
```

신뢰구간까지 함께 확인하고 싶다면 `ci=None`을 제거할 수 있음.
