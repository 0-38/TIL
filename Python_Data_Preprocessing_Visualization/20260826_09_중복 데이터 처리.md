# **1. 중복 데이터의 개념과 발생 원인**

중복 데이터(Duplicate Data)는 **동일하거나 동일하다고 판단되는 데이터가 DataFrame 안에 두 번 이상 기록된 상태**를 의미함.

중복을 처리하지 않으면 `count()`, `sum()` 등의 집계 결과가 실제보다 크게 계산될 수 있음.

스포츠 데이터에서도 다음과 같은 문제가 발생할 수 있음.

```text
같은 경기 기록이 두 번 저장
→ 경기 수 증가

같은 선수의 득점 기록이 중복 저장
→ 총득점 증가

같은 센서 측정값이 반복 저장
→ 평균·분포 왜곡
```

중복 처리에서 가장 중요한 것은 **어떤 컬럼을 기준으로 같은 데이터라고 판단할 것인지 먼저 결정하는 것**임.

> ## **1-1 ) 중복 데이터가 집계 결과에 미치는 영향**

농구 경기 기록에서 동일한 경기 데이터가 두 번 저장되었다고 가정함.

[ python : code ] "중복 경기 기록이 총득점 계산에 미치는 영향 확인"

```python
import pandas as pd

games = pd.DataFrame({
    "game_id": [
        101,
        102,
        102,
        103
    ],
    "player": [
        "서윤",
        "도현",
        "도현",
        "하린"
    ],
    "points": [
        15,
        30,
        30,
        20
    ]
})

print(games)

print(
    "중복 포함 총득점:",
    games["points"].sum()
)
```

[ Result ]

```text
   game_id player  points
0      101     서윤      15
1      102     도현      30
2      102     도현      30
3      103     하린      20

중복 포함 총득점: 95
```

만약 `game_id=102`의 두 번째 행이 실제 경기 기록의 중복 저장이라면 실제 총득점은 다음과 같음.

```text
15 + 30 + 20
= 65점
```

하지만 중복값이 포함되어 있기 때문에.

```text
15 + 30 + 30 + 20
= 95점
```

으로 계산됨.

따라서 중복 데이터는 **집계 결과를 실제보다 크게 만들 수 있음.**

<br>

> ## **1-2 ) 중복 데이터가 발생하는 주요 원인**

| 원인 | 설명 |
| --- | --- |
| ETL 오류 | 동일 데이터가 추출·변환·적재 과정에서 반복 처리됨 |
| 데이터 통합 오류 | 서로 다른 데이터 소스를 합치는 과정에서 같은 레코드가 중복됨 |
| 재시도 로직 | 동일한 요청이나 트랜잭션이 여러 번 저장됨 |
| 수동 입력 오류 | 사람이 같은 데이터를 반복 입력함 |
| 잘못된 `concat()` | 겹치는 데이터셋을 그대로 연결함 |
| 잘못된 `merge()` | 중복 Key로 인해 예상보다 많은 행이 생성됨 |

`concat()`이나 `merge()` 자체가 중복을 만드는 함수라는 의미는 아님.

**결합하려는 데이터나 Key 구조를 제대로 확인하지 않았을 때 중복 행 또는 예상하지 못한 행 증가가 발생할 수 있음.**

<br>

> ## **1-3 ) 전체 행 기준 중복과 특정 컬럼 기준 중복**

중복은 크게 두 방식으로 판단할 수 있음.

| 기준 | 의미 |
| --- | --- |
| 전체 행 기준 | 모든 Column 값이 같은 경우 중복 |
| 특정 Column 기준 | 지정한 Column 값이 같으면 중복으로 판단 |

예를 들어 다음 데이터가 있다고 가정함.

```text
game_id | player | points
101     | 서윤    | 15
102     | 도현    | 20
102     | 도현    | 25
```

전체 Row를 기준으로 보면.

```text
102 | 도현 | 20
102 | 도현 | 25
```

는 `points`가 다르므로 중복이 아님.

하지만 `game_id`를 경기의 고유 식별자로 정의했다면.

```text
game_id = 102
```

가 두 번 등장하므로 **`game_id` 기준으로는 중복**임.

따라서 중복 처리에서는.

```text
"어떤 컬럼이 하나의 사건을 유일하게 식별하는가?"
```

를 먼저 결정해야 함.

# **2. duplicated(): 중복 데이터 판별**

`duplicated()`는 각 Row가 앞에서 등장한 데이터와 중복되는지를 `True`, `False`로 반환함.

기본값은 `keep="first"`이므로 **첫 번째 데이터는 유지하고 이후에 등장한 중복값을 `True`로 표시**함.

> ## **2-1 ) duplicated() 기본 사용**

[ python : code ] "완전히 동일한 경기 기록의 중복 여부 확인"

```python
import pandas as pd

games = pd.DataFrame({
    "game_id": [
        101,
        102,
        102,
        103
    ],
    "player": [
        "서윤",
        "도현",
        "도현",
        "하린"
    ],
    "points": [
        15,
        30,
        30,
        20
    ]
})

print(
    games.duplicated()
)
```

[ Result ]

```text
0    False
1    False
2     True
3    False
dtype: bool
```

Index `1`에서.

```text
102 | 도현 | 30
```

이 처음 등장했으므로 `False`.

Index `2`에서 동일한 데이터가 다시 등장했으므로 `True`.

<br>

> ## **2-2 ) 중복된 행만 선택**

`duplicated()` 결과는 Boolean Series이므로 Boolean Indexing에 사용할 수 있음.

[ python : code ] "중복된 경기 기록만 선택"

```python
duplicate_games = games[
    games.duplicated()
]

print(
    duplicate_games.to_string(
        index=False
    )
)

print(
    "중복 행 개수:",
    len(duplicate_games)
)
```

[ Result ]

```text
 game_id player  points
     102     도현      30
중복 행 개수: 1
```

중복된 Row의 개수만 확인하려면 다음처럼 작성할 수도 있음.

```python
games.duplicated().sum()
```

[ Result ]

```text
1
```

<br>

> ## **2-3 ) subset으로 특정 컬럼 기준 중복 확인**

`subset`을 사용하면 특정 Column만 기준으로 중복을 판단할 수 있음.

[ python : code ] "선수 ID만 기준으로 중복 여부 확인"

```python
import pandas as pd

players = pd.DataFrame({
    "athlete_id": [
        "A01",
        "A02",
        "A02",
        "A03"
    ],
    "test_date": [
        "2026-09-01",
        "2026-09-01",
        "2026-09-08",
        "2026-09-01"
    ],
    "score": [
        88,
        91,
        94,
        86
    ]
})

players["duplicate_id"] = (
    players.duplicated(
        subset=["athlete_id"]
    )
)

print(
    players.to_string(
        index=False
    )
)
```

[ Result ]

```text
athlete_id  test_date  score  duplicate_id
       A01 2026-09-01     88         False
       A02 2026-09-01     91         False
       A02 2026-09-08     94          True
       A03 2026-09-01     86         False
```

`A02` 선수는 측정 날짜가 다르므로 전체 행 기준으로는 중복이 아님.

하지만 `athlete_id`만 기준으로 확인했기 때문에 두 번째 `A02`가 `True`로 표시됨.

이 데이터에서 여러 번의 측정이 정상적인 구조라면 `athlete_id` 하나만으로 중복 제거하면 안 됨.

예를 들어.

```python
subset=[
    "athlete_id",
    "test_date"
]
```

처럼 **실제 중복을 판단할 수 있는 컬럼 조합**을 사용해야 할 수도 있음.

<br>

> ## **2-4 ) keep 파라미터**

`duplicated()`의 `keep`을 사용하면 중복 그룹에서 어떤 Row를 중복으로 표시할지 결정할 수 있음.

| `keep` | 동작 |
| --- | --- |
| `"first"` | 첫 번째 Row를 유지하고 이후 Row를 `True` |
| `"last"` | 마지막 Row를 유지하고 이전 Row를 `True` |
| `False` | 중복 그룹에 속한 모든 Row를 `True` |

[ python : code ] "keep 값에 따른 중복 판별 결과 비교"

```python
import pandas as pd

df = pd.DataFrame({
    "athlete_id": [
        "A01",
        "A02",
        "A02",
        "A03",
        "A03"
    ]
})

df["keep_first"] = df.duplicated(
    subset=["athlete_id"],
    keep="first"
)

df["keep_last"] = df.duplicated(
    subset=["athlete_id"],
    keep="last"
)

df["keep_false"] = df.duplicated(
    subset=["athlete_id"],
    keep=False
)

print(
    df.to_string(
        index=False
    )
)
```

[ Result ]

```text
athlete_id  keep_first  keep_last  keep_false
       A01       False      False       False
       A02       False       True        True
       A02        True      False        True
       A03       False       True        True
       A03        True      False        True
```

동작 방식.

```text
keep="first"

A02 첫 번째 → False
A02 두 번째 → True
```

```text
keep="last"

A02 첫 번째 → True
A02 두 번째 → False
```

```text
keep=False

A02 첫 번째 → True
A02 두 번째 → True
```

<br>

> ## **2-5 ) 중복 그룹 전체 확인**

실제 데이터를 정리하기 전에는 중복 그룹의 모든 행을 확인하는 것이 유용함.

```python
duplicates = df[
    df.duplicated(
        subset=["athlete_id"],
        keep=False
    )
]
```

`keep=False`를 이용하면 첫 번째 Row까지 포함하여 **중복 그룹 전체를 확인**할 수 있음.

# **3. drop_duplicates(): 중복 데이터 제거**

`drop_duplicates()`는 중복된 Row를 제거하고 고유한 데이터만 남기는 메서드임.

일반적으로.

```text
duplicated()
→ 중복 여부 확인

drop_duplicates()
→ 실제 제거
```

순서로 사용하는 것이 안전함.

> ## **3-1 ) 전체 행 기준 중복 제거**

[ python : code ] "완전히 동일한 경기 기록 제거"

```python
import pandas as pd

games = pd.DataFrame({
    "game_id": [
        101,
        102,
        102,
        103
    ],
    "player": [
        "서윤",
        "도현",
        "도현",
        "하린"
    ],
    "points": [
        15,
        30,
        30,
        20
    ]
})

clean_games = (
    games
    .drop_duplicates()
    .reset_index(drop=True)
)

print(
    clean_games.to_string(
        index=False
    )
)
```

[ Result ]

```text
 game_id player  points
     101     서윤      15
     102     도현      30
     103     하린      20
```

동일한 `game_id=102`, `도현`, `30점` Row 중 첫 번째만 유지됨.

<br>

> ## **3-2 ) 특정 컬럼 기준으로 중복 제거**

`subset`을 사용하면 특정 Column을 기준으로 중복 데이터를 제거함.

[ python : code ] "선수 ID별 첫 번째 체력측정 기록만 유지"

```python
import pandas as pd

fitness = pd.DataFrame({
    "athlete_id": [
        "A01",
        "A02",
        "A02",
        "A03"
    ],
    "score": [
        88,
        90,
        94,
        86
    ]
})

clean = fitness.drop_duplicates(
    subset=["athlete_id"],
    keep="first"
)

print(
    clean.to_string(
        index=False
    )
)
```

[ Result ]

```text
athlete_id  score
       A01     88
       A02     90
       A03     86
```

`A02`는 두 번 등장하지만 `keep="first"`이므로 첫 번째 `90점`이 유지됨.

<br>

> ## **3-3 ) 마지막 데이터 유지**

같은 선수의 여러 기록 중 **가장 마지막에 저장된 Row를 유지**하고 싶다면 `keep="last"`를 사용할 수 있음.

[ python : code ] "선수 ID별 마지막 측정 기록 유지"

```python
clean_last = fitness.drop_duplicates(
    subset=["athlete_id"],
    keep="last"
)

print(
    clean_last.to_string(
        index=False
    )
)
```

[ Result ]

```text
athlete_id  score
       A01     88
       A02     94
       A03     86
```

`A02`의 마지막 Row인 `94점`이 유지됨.

단, **마지막 Row가 곧 가장 최신 기록이라는 보장은 없음.**

실제 최신 기록을 남기려면 날짜·시간을 먼저 정렬해야 함.

<br>

> ## **3-4 ) 최신 기록만 남기는 복합 예제**

선수별 체력측정 기록에서 실제 날짜가 가장 최근인 Row만 유지한다고 가정함.

[ python : code ] "측정 날짜를 정렬한 뒤 선수별 최신 기록만 유지"

```python
import pandas as pd

fitness = pd.DataFrame({
    "athlete_id": [
        "A01",
        "A02",
        "A02",
        "A03",
        "A03"
    ],
    "test_date": [
        "2026-09-01",
        "2026-09-08",
        "2026-09-03",
        "2026-09-02",
        "2026-09-10"
    ],
    "score": [
        88,
        94,
        90,
        82,
        89
    ]
})

fitness["test_date"] = pd.to_datetime(
    fitness["test_date"]
)

latest = (
    fitness
    .sort_values("test_date")
    .drop_duplicates(
        subset=["athlete_id"],
        keep="last"
    )
    .sort_values("athlete_id")
    .reset_index(drop=True)
)

print(
    latest.to_string(
        index=False
    )
)
```

[ Result ]

```text
athlete_id  test_date  score
       A01 2026-09-01     88
       A02 2026-09-08     94
       A03 2026-09-10     89
```

### 결과 해석

`A02` 기록.

```text
2026-09-03 → 90점
2026-09-08 → 94점

최신
→ 2026-09-08
→ 94점 유지
```

`A03` 기록.

```text
2026-09-02 → 82점
2026-09-10 → 89점

최신
→ 2026-09-10
→ 89점 유지
```

### 흐름도

```text
[여러 측정 기록]
        ↓
test_date를 datetime으로 변환
        ↓
날짜 오름차순 정렬
        ↓
같은 athlete_id 그룹 확인
        ↓
drop_duplicates(
    keep="last"
)
        ↓
각 선수의 최신 Row 유지
        ↓
최종 데이터
```

<br>

> ## **3-5 ) drop_duplicates() 주요 파라미터**

| 파라미터 | 의미 | 기본값 |
| --- | --- | --- |
| `subset` | 중복 판단에 사용할 Column | 전체 Column |
| `keep` | 어떤 중복 Row를 유지할지 설정 | `"first"` |
| `inplace` | 원본 DataFrame을 직접 수정할지 여부 | `False` |

`subset`을 지정하지 않으면 **모든 Column 값이 동일한 Row만 중복**으로 판단함.

# **4. 중복 데이터 처리 전후 검증**

중복 데이터를 제거한 뒤에는 실제로 원하는 만큼 제거되었는지 반드시 확인해야 함.

중복 제거 코드가 정상 실행되었다고 해서 올바르게 처리되었다는 의미는 아님.

> ## **4-1 ) 처리 전후 행 수 비교**

[ python : code ] "중복 경기 기록 제거 전후 행 수 확인"

```python
import pandas as pd

games = pd.DataFrame({
    "game_id": [
        101,
        102,
        102,
        103,
        104,
        104
    ],
    "points": [
        15,
        20,
        20,
        30,
        25,
        25
    ]
})

before_count = len(games)

clean_games = games.drop_duplicates(
    subset=["game_id"]
)

after_count = len(clean_games)

removed_count = (
    before_count - after_count
)

print(
    "처리 전 행 수:",
    before_count
)

print(
    "처리 후 행 수:",
    after_count
)

print(
    "제거된 행 수:",
    removed_count
)
```

[ Result ]

```text
처리 전 행 수: 6
처리 후 행 수: 4
제거된 행 수: 2
```

계산.

```text
처리 전
= 6행

처리 후
= 4행

제거
= 6 - 4
= 2행
```

<br>

> ## **4-2 ) 중복 비율 계산**

중복이 전체 데이터에서 어느 정도 비율을 차지하는지도 확인할 수 있음.

[ python : code ] "전체 경기 데이터에서 중복 비율 계산"

```python
duplicate_count = games.duplicated(
    subset=["game_id"]
).sum()

duplicate_ratio = (
    duplicate_count
    / len(games)
    * 100
)

print(
    "중복 행:",
    duplicate_count
)

print(
    f"중복 비율: {duplicate_ratio:.1f}%"
)
```

[ Result ]

```text
중복 행: 2
중복 비율: 33.3%
```

계산.

```text
2 / 6 × 100
= 33.333...
≈ 33.3%
```

<br>

> ## **4-3 ) 처리 후 고유값 개수로 검증**

`game_id`가 하나의 경기를 유일하게 식별한다고 가정한다면 중복 제거 후.

```text
전체 행 수
=
고유 game_id 수
```

가 되어야 함.

[ python : code ] "중복 제거 후 행 수와 고유 경기 ID 수 비교"

```python
row_count = len(
    clean_games
)

unique_games = clean_games[
    "game_id"
].nunique()

print(
    "처리 후 행 수:",
    row_count
)

print(
    "고유 game_id 수:",
    unique_games
)

print(
    "검증 결과:",
    row_count == unique_games
)
```

[ Result ]

```text
처리 후 행 수: 4
고유 game_id 수: 4
검증 결과: True
```

> ## **4-4 ) len()과 shape 차이**

| 방법 | 반환 결과 | 사용 상황 |
| --- | --- | --- |
| `len(df)` | 행 수 | 행 수만 확인 |
| `df.shape` | `(행 수, 열 수)` | 행과 열을 함께 확인 |
| `df.shape[0]` | 행 수 | 행 수만 추출 |
| `df.shape[1]` | 열 수 | 열 수만 추출 |

중복 제거 전후의 **행 수만 비교**할 경우 `len(df)`가 간단함.

데이터 구조 전체가 변하지 않았는지도 함께 확인하려면 `shape`를 사용할 수 있음.

# **5. 중복 데이터 처리 전체 흐름**

> ## **5-1 ) 중복 탐지부터 검증까지**

중복 데이터 처리는 다음 순서로 진행하면 이해하기 쉬움.

```text
[원본 데이터]
       ↓
중복 판단 기준 결정
       ↓
전체 Row?
특정 Column?
복합 Key?
       ↓
duplicated()
       ↓
중복 데이터 직접 확인
       ↓
실제 중복인지 의미 확인
       ↓
drop_duplicates()
       ↓
처리 전후 행 수 비교
       ↓
고유 Key 수 확인
       ↓
duplicated().sum() 재확인
       ↓
중복 처리 완료
```

가장 중요한 단계는.

```text
drop_duplicates()
```

자체가 아니라.

```text
무엇을 중복으로 정의할 것인가?
```

를 결정하는 것임.

# **6. Advanced 추가 학습**

> ## **6-1 ) 복합 Key로 중복 확인**

한 선수는 여러 날짜에 정상적으로 반복 측정될 수 있음.

따라서 `athlete_id` 하나만 기준으로 하면 정상 기록까지 중복으로 판단할 수 있음.

이럴 때는 다음처럼 여러 Column을 함께 사용할 수 있음.

```python
df.duplicated(
    subset=[
        "athlete_id",
        "test_date"
    ]
)
```

즉.

```text
athlete_id + test_date
```

조합이 같은 경우에만 중복으로 판단하는 방식임.

<br>

> ## **6-2 ) merge 후 행 수 증가 확인**

`merge()`에서 Key가 양쪽에 중복되어 있으면 모든 조합이 생성되면서 행 수가 증가할 수 있음.

예를 들어.

```text
왼쪽 A01 → 2행
오른쪽 A01 → 3행
```

이면.

```text
2 × 3
= 6행
```

이 만들어질 수 있음.

따라서 데이터 결합 후 갑자기 Row 수가 증가했다면 단순 중복뿐 아니라 **Key의 관계가 1:1인지, 1:N인지, N:M인지 확인**하는 것이 중요함.

<br>

> ## **6-3 ) 원본 데이터 보존**

중복 제거 전에는 원본을 별도로 보존하는 것이 안전함.

```python
df_raw = df.copy()

df_clean = df.drop_duplicates(
    subset=["game_id"]
)
```

잘못된 중복 기준을 사용했더라도 원본에서 다시 전처리를 시작할 수 있음.

# **7. 핵심정리**

1. 중복 데이터는 **동일하거나 분석 기준상 동일한 데이터가 두 번 이상 기록된 상태**를 의미함.

2. 중복 데이터는 `count()`, `sum()` 등의 집계 결과를 실제보다 크게 만들 수 있음.

3. 대표적인 중복 발생 원인은 다음과 같음.

| 원인 | 예 |
| --- | --- |
| ETL 오류 | 동일 데이터 반복 적재 |
| 데이터 통합 | 여러 소스에 같은 레코드 존재 |
| 재시도 오류 | 같은 요청 반복 기록 |
| 수동 입력 | 사용자가 같은 값 반복 입력 |
| 잘못된 데이터 결합 | 중복 Key로 행 수 증가 |

4. 중복 여부는 **전체 행 또는 특정 Column을 기준으로 판단**할 수 있음.

5. `duplicated()`는 각 Row의 중복 여부를 `True`, `False`로 반환함.

```python
df.duplicated()
```

6. 특정 Column만 기준으로 중복을 판단하려면 `subset`을 사용함.

```python
df.duplicated(
    subset=["game_id"]
)
```

7. `keep`의 차이는 다음과 같음.

| `keep` | 동작 |
| --- | --- |
| `"first"` | 첫 번째 Row 유지 |
| `"last"` | 마지막 Row 유지 |
| `False` | 중복 그룹 전체 표시 |

8. 중복 그룹의 모든 Row를 확인하려면 다음과 같이 사용할 수 있음.

```python
df[
    df.duplicated(
        subset=["game_id"],
        keep=False
    )
]
```

9. `drop_duplicates()`는 실제 중복 Row를 제거함.

```python
df.drop_duplicates(
    subset=["game_id"]
)
```

10. `subset`을 생략하면 모든 Column 값이 동일한 Row만 중복으로 제거함.

11. `keep="last"`는 현재 Row 순서상 마지막 값을 유지하는 것이므로 **최신 데이터가 필요하다면 날짜를 먼저 정렬해야 함.**

12. 예를 들어 선수별 최신 측정값을 남기려면 다음 흐름을 사용할 수 있음.

```text
날짜 변환
   ↓
날짜 정렬
   ↓
drop_duplicates(
    subset=["athlete_id"],
    keep="last"
)
   ↓
최신 기록 유지
```

13. 중복 제거 후에는 반드시 처리 전후의 행 수를 비교하는 것이 좋음.

```python
before = len(df)

after = len(df_clean)

removed = before - after
```

14. 중복 기준 Column이 고유 식별자라면 처리 후 다음 조건도 확인할 수 있음.

```text
전체 Row 수
=
고유 Key 수
```

15. 중복 여부를 판단할 때 하나의 Column으로 부족하다면 복합 Key를 사용할 수 있음.

```python
subset=[
    "athlete_id",
    "test_date"
]
```

16. `merge()` 후 행 수가 증가했다면 단순 중복 문제뿐 아니라 **중복 Key로 인한 1:N 또는 N:M 결합**인지도 확인해야 함.

17. 중복 처리의 전체 흐름은 다음과 같음.

```text
중복 기준 결정
     ↓
duplicated()
     ↓
중복 행 확인
     ↓
실제 중복인지 판단
     ↓
drop_duplicates()
     ↓
처리 전후 행 수 검증
     ↓
고유 Key 개수 확인
     ↓
중복 재확인
```

18. 중복 처리에서 가장 중요한 것은 함수를 사용하는 것보다 **"어떤 컬럼 또는 컬럼 조합이 하나의 사건을 유일하게 식별하는가?"를 먼저 정의하는 것**임.
