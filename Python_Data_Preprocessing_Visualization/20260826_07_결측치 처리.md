# **1. 결측치 처리 방법 4가지**

결측치(Missing Value)를 발견했다고 해서 무조건 삭제하거나 하나의 값으로 채우면 안 됨.

결측치 처리 방법은 **데이터의 종류, 분포, 이상치 존재 여부, 결측 비율, 결측 발생 원인** 등을 확인한 후 결정해야 함.

대표적인 결측치 처리 방법은 다음 4가지임.

| 처리 방법 | 핵심 원리 | 적합 상황 | 주의사항 |
| --- | --- | --- | --- |
| 행 삭제 | 결측치가 있는 행 제거 | 결측 비율이 낮고 삭제로 인한 정보 손실이 적을 때 | 데이터 손실·편향 가능 |
| 평균 대체 | 평균값으로 결측치 대체 | 수치형이며 이상치가 적고 분포가 비교적 대칭적일 때 | 이상치에 민감, 분산 감소 |
| 중앙값 대체 | 중앙값으로 결측치 대체 | 수치형이며 이상치가 있거나 분포가 치우친 경우 | 분산 감소 가능 |
| 최빈값 대체 | 가장 자주 등장하는 값으로 대체 | 범주형 데이터 | 특정 범주 비율 증가 가능 |

<br>

> ## **1-1 ) 행 삭제**

결측치가 있는 Row 자체를 제거하는 방법임.

Pandas에서는 `dropna()`를 사용함.

[ python : code ] "VO2max가 결측인 선수의 행 제거"

```python
import pandas as pd
import numpy as np

fitness = pd.DataFrame({
    "athlete": ["서윤", "도현", "하린", "민재"],
    "vo2max": [48.0, 52.0, np.nan, 50.0]
})

result = fitness.dropna(
    subset=["vo2max"]
)

print(result.to_string(index=False))
```

[ Result ]

```text
athlete  vo2max
     서윤    48.0
     도현    52.0
     민재    50.0
```

`하린`의 `vo2max`가 `NaN`이므로 해당 Row가 제거됨.

특정 Column만 기준으로 삭제하려면 `subset`을 사용함.

```python
df.dropna(
    subset=["vo2max"]
)
```

행 삭제는 간단하지만 결측치가 많으면 데이터 자체가 크게 줄어들 수 있음.

<br>

> ## **1-2 ) 평균 대체**

수치형 데이터의 결측값을 해당 Column의 평균으로 채우는 방법임.

[ python : code ] "안정시 심박수의 결측치를 평균으로 대체"

```python
import pandas as pd
import numpy as np

heart_rate = pd.Series(
    [58, 60, np.nan, 62, 64]
)

mean_hr = heart_rate.mean()

filled = heart_rate.fillna(
    mean_hr
)

print("평균:", mean_hr)
print(filled.tolist())
```

[ Result ]

```text
평균: 61.0
[58.0, 60.0, 61.0, 62.0, 64.0]
```

평균 계산.

```text
58 + 60 + 62 + 64
= 244

244 / 4
= 61
```

따라서 결측값이 `61`로 대체됨.

평균은 이상치에 민감하므로 극단적인 값이 존재하거나 분포가 크게 치우친 경우에는 주의해야 함.

<br>

> ## **1-3 ) 중앙값 대체**

중앙값(Median)은 데이터를 크기순으로 정렬했을 때 가운데에 위치하는 값임.

평균보다 이상치의 영향을 상대적으로 적게 받으므로 **이상치가 존재하거나 분포가 치우친 수치형 데이터**에서 고려할 수 있음.

[ python : code ] "주간 훈련거리의 결측치를 중앙값으로 대체"

```python
import pandas as pd
import numpy as np

distance = pd.Series(
    [30, 35, 40, np.nan, 120]
)

mean_distance = distance.mean()
median_distance = distance.median()

filled = distance.fillna(
    median_distance
)

print("평균:", mean_distance)
print("중앙값:", median_distance)
print(filled.tolist())
```

[ Result ]

```text
평균: 56.25
중앙값: 37.5
[30.0, 35.0, 40.0, 37.5, 120.0]
```

평균 계산.

```text
30 + 35 + 40 + 120
= 225

225 / 4
= 56.25
```

중앙값 계산.

```text
30, 35, 40, 120
       ↓
가운데 두 값
35, 40
       ↓
(35 + 40) / 2
= 37.5
```

`120`이라는 큰 값 때문에 평균은 `56.25`까지 증가하지만 중앙값은 `37.5`임.

<br>

> ## **1-4 ) 최빈값 대체**

최빈값(Mode)은 **가장 자주 등장하는 값**임.

종목, 포지션, 지역처럼 범주형 데이터의 결측치를 처리할 때 고려할 수 있음.

[ python : code ] "선수 주종목의 결측치를 최빈값으로 대체"

```python
import pandas as pd

sport = pd.Series([
    "육상",
    "육상",
    None,
    "수영",
    "육상"
])

mode_sport = sport.mode()[0]

filled = sport.fillna(
    mode_sport
)

print("최빈값:", mode_sport)
print(filled.tolist())
```

[ Result ]

```text
최빈값: 육상
['육상', '육상', '육상', '수영', '육상']
```

빈도.

```text
육상 → 3회
수영 → 1회
```

따라서 최빈값은 `육상`임.

단, 결측치를 모두 최빈값으로 채우면 기존에 가장 많았던 범주의 비율이 더 높아질 수 있음.

<br>

> ## **1-5 ) 평균 대체와 중앙값 대체 비교**

| 구분 | 평균 대체 | 중앙값 대체 |
| --- | --- | --- |
| 계산 기준 | 모든 값의 합 ÷ 개수 | 정렬 후 가운데 값 |
| 이상치 영향 | 큼 | 상대적으로 작음 |
| 적합 상황 | 이상치가 적고 분포가 비교적 대칭적 | 이상치 또는 치우친 분포 |
| 데이터 종류 | 수치형 | 수치형 |
| 주의사항 | 평균 왜곡, 분산 감소 | 분산 감소 가능 |

결측치를 처리할 때는 단순히 함수만 선택하는 것이 아니라 **원래 데이터의 분포와 결측 원인도 함께 확인**해야 함.

# **2. Python으로 결측치 처리하기**

Pandas에서 결측치를 처리할 때 대표적으로 사용하는 메서드는 `dropna()`와 `fillna()`임.

```text
dropna()
→ 결측치가 있는 행 또는 열 제거

fillna()
→ 결측치를 다른 값으로 대체
```

> ## **2-1 ) dropna() 기본 사용**

`dropna()`를 옵션 없이 사용하면 기본적으로 결측치가 하나라도 포함된 Row를 제거함.

[ python : code ] "결측치가 존재하는 선수 데이터 행 제거"

```python
import pandas as pd
import numpy as np

players = pd.DataFrame({
    "athlete": [
        "서윤",
        "도현",
        "하린",
        "민재"
    ],
    "training_min": [
        60,
        np.nan,
        75,
        90
    ],
    "position": [
        "Guard",
        "Forward",
        None,
        "Center"
    ]
})

result = players.dropna()

print(result.to_string(index=False))
```

[ Result ]

```text
athlete  training_min position
     서윤          60.0    Guard
     민재          90.0   Center
```

도현은 `training_min`이 결측이고, 하린은 `position`이 결측이므로 제거됨.

<br>

> ## **2-2 ) subset을 이용한 선택적 삭제**

특정 Column의 결측치만 삭제 기준으로 사용하려면 `subset`을 사용함.

[ python : code ] "훈련시간이 결측인 선수만 제거"

```python
result = players.dropna(
    subset=["training_min"]
)

print(result.to_string(index=False))
```

[ Result ]

```text
athlete  training_min position
     서윤          60.0    Guard
     하린          75.0     None
     민재          90.0   Center
```

`training_min`만 삭제 기준으로 사용했으므로 `position`이 결측인 하린은 유지됨.

<br>

> ## **2-3 ) fillna()로 평균 대체**

[ python : code ] "경기 점수의 결측치를 평균값으로 대체"

```python
import pandas as pd
import numpy as np

scores = pd.DataFrame({
    "athlete": [
        "서윤",
        "도현",
        "하린",
        "민재"
    ],
    "score": [
        80,
        90,
        np.nan,
        70
    ]
})

mean_score = scores[
    "score"
].mean()

scores["score"] = scores[
    "score"
].fillna(
    mean_score
)

print("평균:", mean_score)
print(scores.to_string(index=False))
```

[ Result ]

```text
평균: 80.0
athlete  score
     서윤   80.0
     도현   90.0
     하린   80.0
     민재   70.0
```

계산.

```text
80 + 90 + 70
= 240

240 / 3
= 80
```

따라서 하린의 결측값이 `80`으로 대체됨.

<br>

> ## **2-4 ) fillna()로 중앙값 대체**

[ python : code ] "사이클 파워 데이터의 결측치를 중앙값으로 대체"

```python
import pandas as pd
import numpy as np

power = pd.DataFrame({
    "athlete": [
        "서윤",
        "도현",
        "하린",
        "민재",
        "유나"
    ],
    "power_w": [
        250,
        260,
        np.nan,
        270,
        800
    ]
})

median_power = power[
    "power_w"
].median()

power["power_w"] = power[
    "power_w"
].fillna(
    median_power
)

print(
    "중앙값:",
    median_power
)

print(
    power.to_string(
        index=False
    )
)
```

[ Result ]

```text
중앙값: 265.0
athlete  power_w
     서윤    250.0
     도현    260.0
     하린    265.0
     민재    270.0
     유나    800.0
```

중앙값 계산.

```text
250, 260, 270, 800

가운데 두 값
260, 270

(260 + 270) / 2
= 265
```

<br>

> ## **2-5 ) fillna()로 최빈값 대체**

Pandas의 `mode()`는 최빈값을 Series 형태로 반환함.

첫 번째 최빈값을 선택할 때는 일반적으로 `mode()[0]` 형태를 사용함.

[ python : code ] "선수 종목의 결측치를 최빈값으로 대체"

```python
import pandas as pd

df = pd.DataFrame({
    "athlete": [
        "서윤",
        "도현",
        "하린",
        "민재",
        "유나"
    ],
    "sport": [
        "육상",
        "수영",
        None,
        "육상",
        "육상"
    ]
})

mode_sport = df[
    "sport"
].mode()[0]

df["sport"] = df[
    "sport"
].fillna(
    mode_sport
)

print(
    "최빈값:",
    mode_sport
)

print(
    df.to_string(
        index=False
    )
)
```

[ Result ]

```text
최빈값: 육상
athlete sport
     서윤    육상
     도현    수영
     하린    육상
     민재    육상
     유나    육상
```

<br>

> ## **2-6 ) dropna()와 fillna() 비교**

| 구분 | `dropna()` | `fillna()` |
| --- | --- | --- |
| 동작 | 결측 데이터 제거 | 결측값 대체 |
| 데이터 수 | 감소할 수 있음 | 유지 가능 |
| 대표 사용 | 불필요하거나 삭제 가능한 결측 행 | 평균·중앙값·최빈값 등으로 대체 |
| 주요 위험 | 데이터 손실·편향 | 분포·분산 왜곡 |

`dropna()`와 `fillna()` 중 하나만 선택해야 하는 것은 아님.

Column의 의미에 따라 서로 다른 전략을 함께 사용할 수 있음.

# **3. 데이터 특성에 따른 결측치 처리 방법 선택**

하나의 DataFrame에서도 Column마다 서로 다른 결측치 처리 방법이 필요할 수 있음.

> ## **3-1 ) 서로 다른 결측치 처리 방법 적용**

다음 스포츠 데이터가 있다고 가정함.

```text
age
→ 수치형
→ 큰 극단값 없음
→ 평균 대체 고려

weekly_distance
→ 수치형
→ 120이라는 큰 값 존재
→ 중앙값 대체 고려

sport
→ 범주형
→ 최빈값 대체 고려
```

[ python : code ] "컬럼 특성에 따라 평균·중앙값·최빈값 대체 적용"

```python
import pandas as pd

df = pd.DataFrame({
    "athlete": [
        "서윤",
        "도현",
        "하린",
        "민재",
        "유나"
    ],
    "age": [
        24,
        26,
        None,
        28,
        30
    ],
    "weekly_distance": [
        30,
        35,
        40,
        None,
        120
    ],
    "sport": [
        "육상",
        "육상",
        None,
        "수영",
        "육상"
    ]
})

age_mean = df[
    "age"
].mean()

distance_median = df[
    "weekly_distance"
].median()

sport_mode = df[
    "sport"
].mode()[0]

df["age"] = df[
    "age"
].fillna(
    age_mean
)

df["weekly_distance"] = df[
    "weekly_distance"
].fillna(
    distance_median
)

df["sport"] = df[
    "sport"
].fillna(
    sport_mode
)

print(
    "나이 평균:",
    age_mean
)

print(
    "주간거리 중앙값:",
    distance_median
)

print(
    "종목 최빈값:",
    sport_mode
)

print()

print(
    df.to_string(
        index=False
    )
)
```

[ Result ]

```text
나이 평균: 27.0
주간거리 중앙값: 37.5
종목 최빈값: 육상

athlete  age  weekly_distance sport
     서윤 24.0             30.0    육상
     도현 26.0             35.0    육상
     하린 27.0             40.0    육상
     민재 28.0             37.5    수영
     유나 30.0            120.0    육상
```

### 계산 과정

나이 평균.

```text
24 + 26 + 28 + 30
= 108

108 / 4
= 27
```

주간 훈련거리 중앙값.

```text
30, 35, 40, 120

가운데 값
35, 40

(35 + 40) / 2
= 37.5
```

종목 빈도.

```text
육상 → 3
수영 → 1

최빈값
→ 육상
```

### 흐름도

```text
[결측치 발견]
       │
       ↓
데이터 타입 확인
       │
   ┌───┴──────────┐
   ↓              ↓
수치형           범주형
   │              │
   ↓              ↓
분포·이상치 확인  빈도 확인
   │              │
┌──┴──┐           ↓
↓     ↓          mode()
평균  중앙값       │
↓     ↓           │
└──┬──┴───────────┘
   ↓
fillna()
   ↓
처리 후 결측치 재확인
```

# **4. 처리 방법 선택의 판단 근거 기록**

결측치 처리는 분석가의 판단이 개입되는 과정이므로 **무엇을 했는지뿐 아니라 왜 해당 방법을 선택했는지 기록하는 것이 중요함.**

> ## **4-1 ) 처리 이유를 코드 주석으로 기록**

[ python : code ] "결측치 처리 방법과 선택 근거 기록"

```python
# [결측치 처리 근거]
#
# age:
# 큰 극단값이 보이지 않고
# 값의 분포가 비교적 안정적임
# → 평균 대체
#
# weekly_distance:
# 120이라는 큰 값이 존재하여
# 평균이 영향을 받을 수 있음
# → 중앙값 대체
#
# sport:
# 범주형 데이터
# → 최빈값 대체

df["age"] = df[
    "age"
].fillna(
    df["age"].mean()
)

df["weekly_distance"] = df[
    "weekly_distance"
].fillna(
    df["weekly_distance"].median()
)

df["sport"] = df[
    "sport"
].fillna(
    df["sport"].mode()[0]
)
```

처리 근거에는 다음 내용을 기록하면 좋음.

```text
어떤 Column을 처리했는가?

결측치는 몇 개였는가?

왜 결측이 발생했는가?

어떤 처리 방법을 선택했는가?

왜 해당 방법을 선택했는가?

처리 후 결측치가 몇 개 남았는가?
```

<br>

> ## **4-2 ) 판단 근거 기록 예시**

| 기록 항목 | 예 |
| --- | --- |
| 대상 Column | `weekly_distance` |
| 처리 전 결측 개수 | 12개 |
| 결측 발생 원인 | 센서 전송 누락 |
| 처리 방법 | 중앙값 대체 |
| 선택 이유 | 일부 큰 값이 존재하여 평균 영향 가능 |
| 처리 후 결측 개수 | 0개 |
| 추가 조치 | 센서 수집 파이프라인 점검 |

이러한 기록은 다른 분석가가 전처리 과정을 이해하고 재현하는 데 도움을 줌.

# **5. Advanced 추가 학습**

> ## **5-1 ) MCAR · MAR · MNAR**

결측값은 발생 방식에 따라 다음처럼 구분할 수 있음.

| 구분 | 의미 |
| --- | --- |
| MCAR | 결측 발생이 다른 변수나 결측값 자체와 특별한 관련이 없는 경우 |
| MAR | 관측된 다른 변수와 관련하여 결측이 발생하는 경우 |
| MNAR | 결측된 값 자체와 관련하여 결측이 발생하는 경우 |

결측 비율이 작다고 해서 항상 삭제해도 되는 것은 아니며 **결측이 어떤 방식으로 발생했는지**도 중요함.

<br>

> ## **5-2 ) 평균·중앙값·최빈값 대체의 한계**

단순 대체는 모든 결측값을 동일한 값으로 채움.

따라서.

```text
원래 데이터
→ 다양한 값과 분산 존재

결측값을 평균 하나로 대체
→ 평균 근처 값 증가

결과
→ 분산 감소 가능
→ 변수 간 관계 왜곡 가능
```

즉 `fillna()`를 사용했다고 해서 항상 가장 좋은 전처리가 되는 것은 아님.

<br>

> ## **5-3 ) ffill과 bfill**

시계열 데이터에서는 앞 또는 뒤의 관측값을 이용하여 결측치를 처리하기도 함.

```python
df["value"] = df[
    "value"
].ffill()
```

은 앞의 값을 이용함.

```python
df["value"] = df[
    "value"
].bfill()
```

은 뒤의 값을 이용함.

다만 앞·뒤 값으로 채우는 것이 데이터 의미상 타당한 경우에만 사용해야 함.

<br>

> ## **5-4 ) 머신러닝에서는 Train 데이터 기준으로 대체값 계산**

머신러닝에서 전체 데이터로 평균이나 중앙값을 계산한 후 Train/Test에 적용하면 Test 데이터의 정보가 학습 전처리에 포함될 수 있음.

따라서 일반적으로.

```text
Train 데이터
     ↓
평균·중앙값 계산
     ↓
대체 기준 생성
     ↓
Train 데이터 처리
     ↓
같은 기준으로
Test 데이터 처리
```

하는 방식을 사용하여 데이터 누수(Data Leakage)를 방지함.

# **6. 핵심정리**

1. 결측치 처리 방법은 대표적으로 다음 네 가지임.

| 방법 | 주요 대상 |
| --- | --- |
| 행 삭제 | 삭제해도 정보 손실이 크지 않은 데이터 |
| 평균 대체 | 이상치 영향이 작고 비교적 대칭적인 수치형 데이터 |
| 중앙값 대체 | 이상치나 치우친 분포가 있는 수치형 데이터 |
| 최빈값 대체 | 범주형 데이터 |

2. `dropna()`는 결측치가 있는 행 또는 열을 제거할 때 사용함.

3. 특정 Column만 삭제 기준으로 사용하려면 `subset`을 지정함.

```python
df.dropna(
    subset=["score"]
)
```

4. `fillna()`는 결측값을 특정 값으로 대체할 때 사용함.

5. 평균 대체는 다음과 같이 작성함.

```python
df["score"] = df[
    "score"
].fillna(
    df["score"].mean()
)
```

6. 중앙값 대체는 다음과 같이 작성함.

```python
df["score"] = df[
    "score"
].fillna(
    df["score"].median()
)
```

7. 최빈값 대체는 다음과 같이 작성함.

```python
df["sport"] = df[
    "sport"
].fillna(
    df["sport"].mode()[0]
)
```

8. 평균은 이상치의 영향을 많이 받지만 중앙값은 상대적으로 영향을 적게 받음.

9. 범주형 데이터에서는 평균이나 중앙값보다 최빈값 대체를 고려할 수 있음.

10. `dropna()`로 결측 데이터를 많이 제거하면 데이터 손실과 편향이 발생할 수 있음.

11. 반대로 평균·중앙값·최빈값으로 단순 대체하면 데이터의 분산이나 변수 간 관계가 왜곡될 수 있음.

12. 결측치 처리 방법을 선택할 때는 다음 순서로 판단하는 것이 중요함.

```text
결측치 발견
   ↓
결측 발생 원인 확인
   ↓
데이터 타입 확인
   ↓
분포 확인
   ↓
이상치 확인
   ↓
결측 비율 확인
   ↓
처리 방법 선택
   ↓
처리 후 결측치 재확인
```

13. 결측치 처리에서는 하나의 DataFrame이라도 Column 특성에 따라 서로 다른 방법을 적용할 수 있음.

14. 처리 방법뿐 아니라 **왜 해당 방법을 선택했는지 코드 주석이나 분석 문서에 기록**하는 것이 중요함.

15. 머신러닝에서는 평균·중앙값 등의 대체 기준을 **Train 데이터에서 계산하고 동일한 값을 Test 데이터에 적용**하여 데이터 누수를 방지해야 함.

16. 결측치 처리에서 가장 중요한 것은 단순히 `dropna()`와 `fillna()` 사용법을 외우는 것이 아니라 **"왜 값이 누락되었고, 데이터의 특성을 최대한 보존하려면 어떤 처리가 적절한가?"를 판단하는 것**임.
