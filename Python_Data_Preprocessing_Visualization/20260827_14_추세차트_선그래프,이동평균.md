# **1. 공통 실습 데이터**

이번 강의에서는 선 그래프와 이동평균의 차이를 명확하게 이해하기 위해 **동일한 14일간의 팀 훈련부하 데이터**를 계속 사용함.

시간의 흐름에 따라 값이 어떻게 변하는지 확인하고, 이후 같은 데이터에 `rolling()`을 적용하여 이동평균을 계산함.

> ## **2-2 ) 선 그래프는 시간 순서가 중요**

선 그래프에서는 X축의 순서가 중요함.

예를 들어 날짜 데이터라면.

```text
2026-09-01
2026-09-02
2026-09-03
...
```

순서로 정렬되어 있어야 시간의 흐름을 올바르게 표현할 수 있음.

실제 데이터에서는 먼저 날짜형으로 변환하고 정렬하는 습관이 중요함.

```python
df["date"] = pd.to_datetime(
    df["date"]
)

df = df.sort_values(
    "date"
)
```

날짜 순서가 뒤섞인 상태에서 선을 연결하면 실제 시간 흐름과 다른 그래프가 만들어질 수 있음.

<br>

> ## **2-3 ) 선 그래프 스타일 옵션**

`plot()`에서는 다음 옵션으로 선의 형태를 조정할 수 있음.

| 옵션 | 예 | 의미 |
| --- | --- | --- |
| `linestyle` | `"-"`, `"--"`, `":"`, `"-."` | 선 형태 |
| `marker` | `"o"`, `"s"`, `"^"` | 데이터 위치 표시 |
| `linewidth` | `1`, `2`, `3` | 선 두께 |
| `alpha` | `0.3`, `0.7`, `1.0` | 투명도 |
| `label` | `"Team A"` | 범례에 표시할 이름 |

예.

```python
plt.figure(figsize=(10,5))

plt.plot(
    training["date"],
    training["team_a"],
    linestyle="--",
    marker="o",
    linewidth=2,
    alpha=0.8
)
```

스타일은 데이터를 꾸미기 위한 목적보다 **값과 그룹을 더 쉽게 구분하도록 사용하는 것이 중요함.**

# **3. 여러 선 비교와 차트 구성 요소**

하나의 차트에 여러 선을 표현하면 두 그룹의 시간 흐름을 동시에 비교할 수 있음.

이때 제목, 축 이름, 범례가 없으면 어떤 선이 무엇을 의미하는지 알기 어려움.

> ## **3-1 ) A팀과 B팀의 훈련부하 비교**

[ python : code ] "A팀과 B팀의 일별 훈련부하를 하나의 선 그래프에서 비교"

```python
import matplotlib.pyplot as plt

fig, ax = plt.subplots(
    figsize=(10, 5)
)

ax.plot(
    training["date"],
    training["team_a"],
    marker="o",
    label="Team A"
)

ax.plot(
    training["date"],
    training["team_b"],
    marker="s",
    linestyle="--",
    label="Team B"
)

ax.set_xlabel("Date")
ax.set_ylabel("Training Load")

ax.set_title(
    "Daily Training Load by Team"
)

ax.legend(
    title="Team"
)

ax.grid(
    True,
    alpha=0.3
)

plt.tight_layout()
plt.show()
```

[ Result ]

```text

두 개의 선으로 함께 출력됨.

2026-09-07

B팀 → 115

2026-09-14
A팀 → 190
B팀 → 160

두 팀 모두 날짜가 지날수록
전체적으로 높은 훈련부하가 나타나는 경향을 확인할 수 있음.
```

<br>

> ## **3-2 ) 제목 · 축 · 범례의 역할**

| 요소 | 역할 |
| --- | --- |
| `set_xlabel()` | X축이 의미하는 변수 설명 |
| `set_ylabel()` | Y축이 의미하는 변수 설명 |
| `set_title()` | 그래프가 무엇을 보여주는지 설명 |
| `label` | 각 선의 이름 지정 |
| `legend()` | 여러 선의 의미 표시 |
| `grid()` | 위치와 값 비교 보조 |

특히 여러 선을 함께 그릴 때는 `label`과 `legend()`가 중요함.

```text
선만 2개 존재
→ 어떤 팀인지 알기 어려움

label + legend
→ 각 선의 의미 확인 가능
```

> ## **3-3 ) plt 방식과 fig, ax 방식**

# **4. 이동평균(Moving Average)**

일별 데이터는 값이 크게 오르내릴 수 있기 때문에 원본 선만 보면 전체적인 추세가 잘 보이지 않을 수 있음.

이때 최근 일정 개수의 값을 평균내는 **이동평균(Moving Average)**을 사용하면 단기적인 변동을 완화하여 전체 흐름을 보기 쉬워짐.

> ## **4-1 ) 3일 이동평균**

A팀의 `team_a`에 대해 3개 관측값의 이동평균을 계산함.

[ python : code ] "A팀 훈련부하의 3일 이동평균 계산"

```python
training["ma3"] = (
    training["team_a"]
    .rolling(
        window=3
    )
    .mean()
)

print(
    training[
        [
            "date",
            "team_a",
            "ma3"
        ]
    ].round(2).to_string(
        index=False
    )
)
```

[ Result ]

```text
      date  team_a    ma3
2026-09-01     100    NaN
2026-09-02     130    NaN
2026-09-03      90 106.67
2026-09-04     140 120.00
2026-09-05     110 113.33
2026-09-06     150 133.33
2026-09-07     120 126.67
2026-09-08     160 143.33
2026-09-09     130 136.67
2026-09-10     170 153.33
2026-09-11     140 146.67
2026-09-12     180 163.33
2026-09-13     150 156.67
2026-09-14     190 173.33
```

첫 번째 이동평균 계산.

```text
09-01 → 100
09-02 → 130
09-03 → 90

(100 + 130 + 90) / 3
= 320 / 3
= 106.67
```

다음 날짜에서는 창(Window)이 한 칸 이동함.

```text
09-02 → 130
09-03 → 90
09-04 → 140

(130 + 90 + 140) / 3
= 360 / 3
= 120
```

이 과정을 반복함.

<br>

> ## **4-2 ) rolling(window=3)의 의미**

```python
rolling(
    window=3
)
```

에서 `3`은 **평균 계산에 사용할 연속된 관측값의 개수**를 의미함.

현재 Row를 포함하여 직전 관측값까지 총 3개를 사용함.

```text
현재 값
+
바로 이전 값
+
그 이전 값
```

즉.

```text
window=3
→ 현재 + 이전 2개 관측값
```

임.

### 중요한 주의점

`window=3`이 항상 정확히 **3일**을 의미하는 것은 아님.

데이터에 날짜가 빠져 있다면.

```text
3개 관측값
```

을 의미함.

따라서 진짜 일별 이동평균을 계산하려면 날짜가 연속적으로 존재하는지도 확인해야 함.

<br>

> ## **4-3 ) 첫 두 값이 NaN인 이유**

기본 `rolling(window=3)`에서는 3개의 관측값이 모두 모여야 평균을 계산함.

```text
첫 번째 Row
→ 데이터 1개
→ 부족
→ NaN

두 번째 Row
→ 데이터 2개
→ 부족
→ NaN

세 번째 Row
→ 데이터 3개
→ 평균 계산 가능
```

따라서 `window=N`이면 기본적으로 **앞쪽 `N-1`개의 값이 NaN**이 됨.

```text
window=3
→ 처음 2개 NaN

window=7
→ 처음 6개 NaN
```

양쪽 끝이 모두 NaN이 되는 것은 아님.

# **5. 원본 데이터와 이동평균 비교**

이동평균을 사용하는 이유는 원본 데이터를 없애기 위해서가 아니라 **원본의 단기 변동과 완화된 추세를 함께 보기 위해서**임.

> ## **5-1 ) 원본 + 3일 이동평균**

[ python : code ] "A팀 훈련부하와 3일 이동평균을 하나의 그래프에서 비교"

```python
import matplotlib.pyplot as plt

fig, ax = plt.subplots(
    figsize=(10, 5)
)

ax.plot(
    training["date"],
    training["team_a"],
    alpha=0.4,
    label="Daily Training Load"
)

ax.plot(
    training["date"],
    training["ma3"],
    linewidth=2,
    label="3-Day Moving Average"
)

ax.set_xlabel("Date")
ax.set_ylabel("Training Load")

ax.set_title(
    "Daily Training Load and 3-Day Moving Average"
)

ax.legend()

plt.tight_layout()
plt.show()
```

[ Result ]

```text
원본 훈련부하
→ 100 → 130 → 90 → 140 → 110 ...
→ 값이 상승과 하락을 반복함.

3일 이동평균
→ 106.67 → 120.00 → 113.33 → 133.33 ...
→ 원본보다 변화가 완만하게 나타남.

따라서 짧은 변동을 줄이고
전체적인 방향을 확인하기 쉬워짐.
```

<br>

> ## **5-2 ) 이동평균은 원본 데이터를 대체하지 않음**

이동평균을 계산하면 일별 원본 값의 세부 변동이 완화됨.

따라서.

```text
원본 데이터
→ 실제 일별 변동 확인

이동평균
→ 부드러운 추세 확인
```

두 선을 함께 보는 것이 유용함.

```text
원본
+
이동평균
=
단기 변화 + 전체 흐름 동시 확인
```

# **6. Window 크기에 따른 차이**

`window`가 커질수록 더 많은 관측값을 평균내므로 선이 일반적으로 더 부드러워짐.

하지만 너무 큰 값을 사용하면 실제 변화가 늦게 반영되거나 중요한 단기 변화가 희석될 수 있음.

> ## **6-1 ) 3일 이동평균과 7일 이동평균**

[ python : code ] "동일한 A팀 데이터에서 3일·7일 이동평균 비교"

```python
training["ma3"] = (
    training["team_a"]
    .rolling(
        window=3
    )
    .mean()
)

training["ma7"] = (
    training["team_a"]
    .rolling(
        window=7
    )
    .mean()
)

print(
    training[
        [
            "date",
            "team_a",
            "ma3",
            "ma7"
        ]
    ].round(2).to_string(
        index=False
    )
)
```

[ Result ]

```text
      date  team_a    ma3    ma7
2026-09-01     100    NaN    NaN
2026-09-02     130    NaN    NaN
2026-09-03      90 106.67    NaN
2026-09-04     140 120.00    NaN
2026-09-05     110 113.33    NaN
2026-09-06     150 133.33    NaN
2026-09-07     120 126.67 120.00
2026-09-08     160 143.33 128.57
2026-09-09     130 136.67 128.57
2026-09-10     170 153.33 140.00
2026-09-11     140 146.67 140.00
2026-09-12     180 163.33 150.00
2026-09-13     150 156.67 150.00
2026-09-14     190 173.33 160.00
```

첫 번째 7일 이동평균.

```text
100 + 130 + 90 + 140 + 110 + 150 + 120
= 840

840 / 7
= 120
```

두 번째 7일 이동평균.


> ## **6-3 ) Window가 커질수록 생기는 변화**

```text
작은 Window
→ 최근 변화에 빠르게 반응
→ 원본의 변동이 비교적 많이 남음

큰 Window
→ 변화가 더 부드러움
→ 장기적인 흐름 확인에 유리
→ 갑작스러운 변화는 늦게 반영될 수 있음
```

따라서.

```text
window가 클수록 무조건 좋다
```

가 아니라 분석 목적에 맞는 Window를 선택해야 함.

# **7. 선 그래프와 이동평균 전체 흐름**

> ## **7-1 ) 시계열 데이터를 시각화하는 기본 과정**

```text
[원본 데이터]
      ↓
날짜형 변환
pd.to_datetime()
      ↓
시간 순서 정렬
sort_values() / sort_index()
      ↓
필요한 단위로 집계
일별 / 주별 / 월별
      ↓
plt.plot()
      ↓
원본 추세 확인
      ↓
변동이 큰가?
      │
      ├── No
      │    ↓
      │  그대로 해석
      │
      └── Yes
           ↓
       rolling()
           ↓
      이동평균 계산
           ↓
원본 + 이동평균 비교
           ↓
전체 추세 해석
```

시계열 그래프에서 가장 중요한 것은 **시간 순서가 올바르게 정렬되어 있는지 확인하는 것**임.


<br><br>

# **8. Advanced 추가 학습**

> ## **8-1 ) 날짜가 빠져 있으면 window=7은 7일이 아닐 수 있음**

다음과 같은 날짜가 있다고 가정함.

```text
09-01
09-02
09-05
09-08
09-10
09-13
09-20
```

여기서.

```python
rolling(
    window=7
)
```

을 사용하면 **7일이라는 기간**이 아니라 **7개의 Row**를 사용함.

따라서 실제 일별 시계열에서는 날짜가 빠져 있는지 확인하거나 필요하면 일정한 주기로 재구성하는 과정이 중요함.

<br>

> ## **8-2 ) min_periods를 이용하면 초기 NaN을 조절할 수 있음**

기본적으로.

```python
rolling(
    window=3
)
```

은 3개의 값이 모두 있어야 평균을 계산함.

하지만.

```python
rolling(
    window=3,
    min_periods=1
)
```

처럼 설정하면 관측값이 1개만 있어도 평균을 계산할 수 있음.

예.

```text
원본
100, 130, 90

기본 window=3
NaN, NaN, 106.67

min_periods=1
100.00, 115.00, 106.67
```

다만 초기 구간이 서로 다른 개수의 관측값으로 계산된다는 점을 알고 사용해야 함.

<br>

> ## **8-3 ) 이동평균에는 시차(Lag)가 발생할 수 있음**

이동평균은 과거 여러 값을 평균내므로 원본 값이 갑자기 증가하거나 감소해도 이동평균선은 변화에 즉시 동일한 크기로 반응하지 않음.

```text
원본 급상승
      ↓
이동평균
→ 여러 과거 값과 함께 평균
      ↓
완만하게 상승
```

따라서 이동평균은 노이즈를 줄이는 대신 **실제 변화보다 늦게 반응하는 특성**이 있음.

<br>

> ## **8-4 ) 월별 데이터를 만들 때 연도도 고려**

여러 해의 데이터에서.

```python
df["month"] = df[
    "date"
].dt.month
```

만 사용하여 Grouping하면.

```text
2025년 1월
+
2026년 1월
```

이 같은 `1월` 그룹으로 합쳐질 수 있음.

여러 연도를 포함한 시계열이라면.

```python
df["year_month"] = df[
    "date"
].dt.to_period("M")
```

처럼 **연도와 월을 함께 보존하는 방식**이 더 적절할 수 있음.

<br>

> ## **8-5 ) 선 그래프의 X축은 순서가 있는 값이어야 함**

선은 인접한 점 사이의 연결을 의미하기 때문에 범주에 자연스러운 순서가 없다면 선 그래프가 적절하지 않을 수 있음.

```text
날짜
월
연도
시간
연속적인 측정 순서

→ 선 그래프 적합
```

반면.

```text
육상
수영
사이클
```

처럼 순서 자체에 의미가 없는 범주를 선으로 연결하면 잘못된 연속성을 암시할 수 있음.

이런 비교에는 막대그래프가 더 적합함.

# **9. 핵심정리**

1. 선 그래프는 **시간이나 순서에 따라 값이 어떻게 변하는지 표현하는 추세 차트**임.

2. Matplotlib에서는 다음과 같이 선 그래프를 작성함.

```python
plt.plot(
    x,
    y
)
```

3. 시계열 데이터를 선 그래프로 표현하기 전에는 날짜형 변환과 시간 순서 정렬이 중요함.

```python
df["date"] = pd.to_datetime(
    df["date"]
)

df = df.sort_values(
    "date"
)
```

4. 선 그래프의 주요 스타일 옵션은 다음과 같음.

| 옵션 | 의미 |
| --- | --- |
| `linestyle` | 선 형태 |
| `marker` | 데이터 포인트 모양 |
| `linewidth` | 선 두께 |
| `alpha` | 투명도 |
| `label` | 범례 이름 |

5. 여러 선을 하나의 차트에 표현할 때는 `label`과 `legend()`를 이용하여 각 선을 구분함.

6. 제목과 축 이름은 다음과 같이 지정할 수 있음.

```python
ax.set_xlabel("Date")
ax.set_ylabel("Training Load")
ax.set_title("Daily Training Load")
```

7. `plt.plot()` 방식과 `fig, ax` 방식 모두 가능하며 복잡한 차트에서는 `fig, ax` 방식이 관리하기 편리함.

8. 이동평균은 **최근 일정 개수의 관측값을 평균내어 단기 변동을 완화하는 방법**임.

9. Pandas에서는 다음과 같이 이동평균을 계산함.

```python
df["ma3"] = (
    df["value"]
    .rolling(
        window=3
    )
    .mean()
)
```

10. `window=3`은 현재 관측값과 이전 관측값을 포함하여 **총 3개의 데이터 포인트**를 사용한다는 의미임.

11. `window=N`은 기본적으로 날짜 단위가 아니라 **Row 또는 관측값의 개수**를 의미함.

12. 기본 `rolling(window=N)`에서는 충분한 데이터가 없는 **앞쪽 `N-1`개 값이 NaN**이 됨.

```text
window=3
→ 처음 2개 NaN

window=7
→ 처음 6개 NaN
```

13. `window=3`의 첫 이동평균 계산은 다음과 같음.

```text
100 + 130 + 90
= 320

320 / 3
= 106.67
```

14. 이번 공통 데이터의 3일 이동평균은 다음과 같이 시작함.

```text
NaN
NaN
106.67
120.00
113.33
133.33
...
```

15. 7일 이동평균의 첫 값은 다음과 같음.

```text
100 + 130 + 90 + 140 + 110 + 150 + 120
= 840

840 / 7
= 120
```

16. 일반적으로 Window가 커질수록 더 많은 값을 평균내기 때문에 이동평균선이 부드러워짐.

```text
작은 Window
→ 단기 변화에 민감

큰 Window
→ 장기 흐름이 더 부드럽게 나타남
```

17. Window가 너무 크면 중요한 단기 변화가 희석되고 실제 변화보다 늦게 반응할 수 있음.

18. 이동평균은 원본 데이터를 대체하는 것이 아니라 **원본의 단기 변동과 전체 추세를 함께 비교하기 위한 보조 도구**임.

19. 여러 해의 월별 데이터를 분석할 때 `dt.month`만 사용하면 서로 다른 연도의 같은 월이 합쳐질 수 있으므로 연도와 월을 함께 관리하는 것이 좋음.

20. 추세 분석의 기본 흐름은 다음과 같음.

```text
날짜형 변환
     ↓
시간 순서 정렬
     ↓
필요한 시간 단위로 집계
     ↓
선 그래프
     ↓
변동 확인
     ↓
rolling().mean()
     ↓
원본 + 이동평균 비교
     ↓
전체 추세 해석
```

21. 선 그래프와 이동평균에서 가장 중요한 것은 단순히 선을 그리는 것이 아니라 **"시간이 흐르면서 값이 어떻게 변하고 있으며, 일시적인 변동을 제외했을 때 전체적인 방향은 무엇인가?"를 파악하는 것**임.
