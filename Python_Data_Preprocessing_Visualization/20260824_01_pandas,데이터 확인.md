# **1. 데이터 전처리(Data Preprocessing)**

데이터 전처리(Data Preprocessing)는 **원시 데이터(Raw Data)를 분석이나 모델링에 적합한 상태로 정리하고 변환하는 과정**을 의미함.

실제 데이터에는 다음과 같은 문제가 존재할 수 있음.

- 결측값(Missing Value)
- 중복 데이터
- 잘못 입력된 값
- 비정상적인 데이터 타입
- 단위 불일치
- 분석 목적에 맞지 않는 값
- 이상치(Outlier)

중요한 점은 단순히 데이터를 삭제하는 것이 아니라 **분석 목적과 데이터의 의미를 확인한 뒤 적절한 처리 방법을 결정하는 것**임.

<br>

> ## **1-1 ) 잘못된 값이 평균에 미치는 영향**

운동 참가자의 나이를 수집했다고 가정함.

[ python : code ] "이상값이 포함된 나이 데이터의 평균 계산"

```python
ages = [25, 31, 28, 999, 35, -1]

average_age = sum(ages) / len(ages)

print(average_age)
```

[ Result ]

```text
186.16666666666666
```

실제 데이터는 대부분 20~30대이지만 평균이 약 `186.17`세로 계산됨.

원인은 정상적인 나이로 보기 어려운 `999`, `-1`이 평균 계산에 포함되었기 때문임.

```text
25 + 31 + 28 + 999 + 35 - 1
= 1117

1117 / 6
= 186.166...
```

<br>

> ## **1-2 ) 분석 기준에 맞는 값만 선택하기**

이번에는 `0 < age < 100`이라는 기준을 사용하여 정상 범위라고 가정한 값만 선택함.

> 예제 학습을 위한 단순 기준이며 실제 연구나 분석에서는 데이터 정의와 연구 목적에 따라 정상 범위를 결정해야 함.

[ python : code ] "분석 기준에 맞는 나이만 선택하여 평균 계산"

```python
ages = [25, 31, 28, 999, 35, -1]

clean_ages = []

for age in ages:
    if 0 < age < 100:
        clean_ages.append(age)

average_age = sum(clean_ages) / len(clean_ages)

print(clean_ages)
print(average_age)
```

[ Result ]

```text
[25, 31, 28, 35]
29.75
```

`-1`, `999`를 제외한 이후 평균이 `29.75`로 계산됨.

### 처리 흐름

```text
원본 데이터
[25, 31, 28, 999, 35, -1]
        ↓
각 값이 0 < age < 100인지 확인
        ↓
25  → 포함
31  → 포함
28  → 포함
999 → 제외
35  → 포함
-1  → 제외
        ↓
[25, 31, 28, 35]
        ↓
평균 계산
        ↓
29.75
```

<br>

> ## **1-3 ) 데이터 전처리에서 먼저 생각할 것**

전처리를 시작하기 전에 다음 질문을 먼저 확인하는 것이 중요함.

```text
무엇을 분석하려는가?
        ↓
어떤 데이터가 필요한가?
        ↓
어떤 값이 정상이고 비정상인가?
        ↓
결측값·이상값·중복값을 어떻게 처리할 것인가?
        ↓
처리 후 분석에 사용할 수 있는가?
```

예를 들어 `999`라는 값도 항상 이상치라고 단정할 수 없음.

```text
나이 = 999
→ 일반적인 나이 데이터라면 오류일 가능성이 높음

제품 코드 = 999
→ 정상적인 제품 번호일 수도 있음
```

따라서 **값 자체가 아니라 Column의 의미와 데이터 정의를 확인해야 함.**

<br>

> ## **1-4 ) 이상치(Outlier)는 무조건 삭제하지 않기**

매우 큰 값이라고 해서 항상 잘못된 데이터인 것은 아님.

예를 들어 구매 금액.

```python
purchase_raw = [45000, 52000, 48000, 55000, 50000, 1000000]
```

`1,000,000`원이.

```text
입력 오류
→ 전처리 대상일 수 있음

실제 VIP 고객의 구매
→ 중요한 실제 데이터일 수 있음
```

이므로 분석 목적과 원본 데이터를 확인해야 함.

[ python : code ] "큰 값이 평균에 미치는 영향 확인"

```python
import pandas as pd

purchase_raw = pd.Series(
    [45000, 52000, 48000, 55000, 50000, 1000000]
)

purchase_without_large_value = pd.Series(
    [45000, 52000, 48000, 55000, 50000]
)

print("전체 평균:", purchase_raw.mean())
print("큰 값을 제외한 평균:", purchase_without_large_value.mean())
```

[ Result ]

```text
전체 평균: 208333.33333333334
큰 값을 제외한 평균: 50000.0
```

큰 값 하나로 인해 평균이 크게 상승함.

하지만 이 결과만 보고 `1,000,000`을 삭제해서는 안 됨.

먼저 해당 값이 **오류인지 실제 관측값인지 확인해야 함.**

<br>

> ## **1-5 ) 결측값 처리 방법에 따라 결과가 달라짐**

Pandas의 `Series.mean()`은 기본적으로 `NaN`을 제외하고 평균을 계산함.

[ python : code ] "결측값 제외와 0 대체 결과 비교"

```python
import pandas as pd
import numpy as np

scores = pd.Series([80, 90, np.nan, 70, 85, np.nan])

mean_drop = scores.mean()
mean_zero = scores.fillna(0).mean()

print("결측값 제외 평균:", mean_drop)
print("결측값을 0으로 처리한 평균:", mean_zero)
```

[ Result ]

```text
결측값 제외 평균: 81.25
결측값을 0으로 처리한 평균: 54.166666666666664
```

두 결과의 의미는 완전히 다름.

```text
NaN 제외
→ 시험에 응시한 사람들의 평균
→ 81.25

NaN을 0으로 변경
→ 미응시자를 0점으로 간주한 전체 평균
→ 약 54.17
```

따라서 결측값을 무조건 `0`으로 바꾸거나 삭제하는 것이 아니라 **결측이 발생한 이유와 분석 목적을 확인해야 함.**

# **2. Pandas**

Pandas는 Python에서 **표 형태의 데이터를 조작하고 분석하기 위해 널리 사용되는 외부 라이브러리**임.

행(Row)과 열(Column) 구조의 데이터를 다룰 수 있으며 데이터 분석과 전처리에 필요한 다양한 기능을 제공함.

주요 기능.

| 기능 | 설명 |
|---|---|
| 데이터 불러오기 | CSV, Excel, JSON 등 |
| 데이터 선택 | 특정 Row / Column 선택 |
| 데이터 정제 | 결측값, 중복값 처리 |
| 데이터 변환 | 자료형 변환, 새로운 Column 생성 |
| 집계 | 합계, 평균, 그룹별 통계 |
| 결합 | `merge()`, `concat()` 등 |
| 분석 | 기술통계, 빈도, 상관관계 계산 |

<br>

> ## **2-1 ) Pandas 프로젝트 의존성 추가**

> ## **2-2 ) DataFrame 생성**

육상·수영·농구 선수의 훈련 데이터를 표로 관리한다고 가정함.

[ python : code ] "딕셔너리를 DataFrame으로 변환"

```python
import pandas as pd

data = {
    "athlete_id": ["A101", "A102", "A103"],

    "sport": ["육상", "수영", "농구"],

df = pd.DataFrame(data)
```

[ Result ]


# **3. DataFrame과 Series**

Pandas에서 가장 중요한 자료구조는 `DataFrame`과 `Series`임.

| 구분 | `DataFrame` | `Series` |
|---|---|---|
| 차원 | 2차원 | 1차원 |
| 구조 | 행 × 열 | 값 + 인덱스 |
| 예시 | 전체 선수 기록표 | 점수 Column 하나 |
| 대표 생성 | `pd.DataFrame()` | `pd.Series()` |

<br>

> ## **3-1 ) DataFrame**

DataFrame은 **행과 열로 이루어진 2차원 표 형태의 자료구조**임.

```text
             Column
          ↓      ↓
       name    score
0      도윤       88   ← Row
1      서아       92   ← Row
2      태민       85   ← Row
↑
Index
```

DataFrame은.

```text
Index
Columns
Values
```

등을 가지고 있음.

<br>

> ## **3-2 ) Series**

Series는 **인덱스가 붙어 있는 1차원 자료구조**임.

DataFrame에서 하나의 Column을 선택하면 일반적으로 Series가 반환됨.

[ python : code ] "DataFrame의 단일 Column을 Series로 선택"

```python
score_series = df["score"]

print(score_series)
print(type(score_series))
```

[ Result ]

```text
0    88
1    92
2    85
Name: score, dtype: int64

<class 'pandas.core.series.Series'>
```

`df["score"]`의 반환 형태.

```text
Index   Value

0       88
1       92
2       85
```

<br>

> ## **3-3 ) 하나의 Column을 DataFrame으로 유지하기**

하나의 Column만 선택하더라도 **이중 대괄호**를 사용하면 DataFrame 형태를 유지할 수 있음.

[ python : code ] "하나의 Column을 DataFrame으로 선택"

```python
score_df = df[["score"]]

print(score_df)
print(type(score_df))
```

[ Result ]

```text
   score
0     88
1     92
2     85

<class 'pandas.core.frame.DataFrame'>
```

차이.

```python
df["score"]
```

```text
Series
```

반면.

```python
df[["score"]]
```

```text
DataFrame
```

<br>

> ## **3-4 ) 단일 대괄호와 이중 대괄호 비교**

| 코드 | 결과 |
|---|---|
| `df["score"]` | `Series` |
| `df[["score"]]` | `DataFrame` |
| `df[["name", "score"]]` | 여러 Column을 가진 `DataFrame` |

Pandas를 사용할 때 자주 발생하는 차이이므로 반드시 구분해야 함.

# **4. 데이터 불러오기와 저장하기**

실제 분석에서는 데이터를 Python 코드에 직접 입력하기보다 파일이나 데이터베이스에서 불러오는 경우가 많음.

Pandas는 CSV, Excel 등 다양한 파일 형식을 지원함.

<br>

> ## **4-1 ) CSV 파일 불러오기**

[ python : code ] "CSV 파일을 DataFrame으로 불러오기"

```python

df = pd.read_csv("athlete_performance.csv")
```

`pd.read_csv()`의 반환값은 DataFrame임.

파일 경로가 상대경로라면 `현재 작업 디렉터리(Current Working Directory)`를 기준으로 찾음.

<br>

> ## **4-2 ) Excel 파일 불러오기**

[ python : code ] "Excel 파일을 DataFrame으로 불러오기"

```python
df = pd.read_excel("athlete_performance.xlsx")
```

Excel 파일을 읽을 때는 파일 종류와 환경에 따라 `openpyxl` 등의 추가 엔진이 필요할 수 있음.

<br>

> ## **4-3 ) CSV 파일 저장**

[ python : code ] "DataFrame을 CSV로 저장"

```python
df.to_csv("processed_athletes.csv", index=False)
```

`index=False`는 DataFrame의 Index를 CSV의 별도 Column으로 저장하지 않도록 설정함.

예를 들어 DataFrame.

```text
  athlete_id name  score
0       A101   도윤     88
1       A102   서아     92
```

를 `index=False`로 저장하면.

```text
athlete_id,name,score
A101,도윤,88
A102,서아,92
```

형태가 됨.

반대로 Index 자체가 중요한 데이터라면 저장할 수도 있으므로 `index=False`를 무조건 사용해야 하는 것은 아님.

<br>

> ## **4-4 ) Excel 파일 저장**

[ python : code ] "DataFrame을 Excel로 저장"

```python
df.to_excel("processed_athletes.xlsx", index=False)
```

<br>

> ## **4-5 ) 저장한 데이터 다시 확인하기**

파일 저장 후 다시 읽어 데이터가 정상적으로 보존되었는지 확인할 수 있음.


### 처리 흐름

```text
DataFrame
   ↓
to_csv()
   ↓
CSV 파일 생성
   ↓
read_csv()
   ↓
다시 DataFrame 생성
   ↓
shape / columns 확인
```

# **5. 인덱스(Index)**

Index는 DataFrame이나 Series의 `각 행에 붙어 있는 레이블(Label)`임.

별도로 지정하지 않으면 일반적으로.

```text
0
1
2
3
...
```

형태의 `RangeIndex`가 생성됨.

<br>

> ## **5-1 ) 기본 Index**

[ python : code ] "기본 Index 확인"

```python
import pandas as pd

df = pd.DataFrame({
    "athlete_id": ["A101", "A102", "A103"],
    "name": ["하린", "시우", "유나"],
    "sport": ["육상", "수영", "농구"]
})

print(df)
print(df.index)
```

[ Result ]

```text
  athlete_id name sport
0       A101   하린    육상
1       A102   시우    수영
2       A103   유나    농구

RangeIndex(start=0, stop=3, step=1)
```

<br>

> ## **5-2 ) 특정 Column을 Index로 설정하기**

`athlete_id`처럼 각 선수를 식별하는 값이 있다면 Index로 지정할 수 있음.

[ python : code ] "athlete_id를 Index로 설정"

```python
df_indexed = df.set_index("athlete_id")

print(df_indexed)
```

[ Result ]

```text
           name sport
athlete_id
A101         하린    육상
A102         시우    수영
A103         유나    농구
```

`set_index()`는 기본적으로 원본 `df`를 직접 변경하지 않고 **새로운 DataFrame을 반환**함.

따라서.

```python
df_indexed = df.set_index("athlete_id")
```

처럼 결과를 변수에 저장하는 방식이 일반적임.

<br>

> ## **5-3 ) Index를 일반 Column으로 되돌리기**

[ python : code ] "Index를 일반 Column으로 복원"

```python
df_restored = df_indexed.reset_index()

print(df_restored)
```

[ Result ]

```text
  athlete_id name sport
0       A101   하린    육상
1       A102   시우    수영
2       A103   유나    농구
```

<br>

> ## **5-4 ) Index에 대한 주의점**

Index를 반드시 고유한 값으로 만들어야 하는 것은 아님.

Pandas에서는 **중복 Index도 허용**함.

```python
import pandas as pd

s = pd.Series(
    [10, 20, 30],
    index=["A", "A", "B"]
)

print(s)
```

[ Result ]

```text
A    10
A    20
B    30
dtype: int64
```

다만 한 행을 명확하게 식별해야 하는 분석에서는 고유한 Index가 더 편리할 수 있음.

또한 Index는 SQL의 `PRIMARY KEY`와 같은 개념이 아님.

```text
SQL PRIMARY KEY
→ 중복 불가
→ NULL 불가
→ 데이터베이스 제약조건

Pandas Index
→ 중복 가능
→ 행 레이블 역할
→ 데이터베이스 제약조건이 아님
```

# **6. 데이터 미리보기와 구조 확인**

# **7. 데이터 타입 확인과 변환**

데이터가 화면에서 숫자처럼 보여도 실제로는 문자열일 수 있음.

데이터 타입이 잘못되어 있으면.

```text
평균 계산
합계 계산
날짜 차이 계산
정렬
비교
```

등에서 문제가 발생할 수 있음.

<br>

> ## **7-1 ) 주요 Pandas 데이터 타입**

| dtype | 의미 |
|---|---|
| `int64` 등 | 정수 |
| `float64` 등 | 실수 |
| `bool` | 참/거짓 |
| `object` | 문자열 또는 여러 Python 객체가 포함될 수 있는 타입 |
| `string` | Pandas 문자열 dtype |
| `datetime64[ns]` | 날짜·시간 |
| `category` | 범주형 데이터 |

`object`를 무조건 문자열 타입이라고 생각하면 안 됨.

문자열이 많이 저장되지만 혼합된 Python 객체도 포함할 수 있음.

<br>

> ## **7-2 ) `astype()`으로 타입 변환**

[ python : code ] "문자열 숫자를 정수로 변환"

```python
import pandas as pd

df_type = pd.DataFrame({
    "name": ["건우", "다은", "준서"],
    "distance_m": ["100", "200", "400"]
})

print(df_type.dtypes)

df_type["distance_m"] = df_type["distance_m"].astype(int)

print(df_type.dtypes)
```

변환 전.

```text
name          object
distance_m    object
```

변환 후.

```text
name          object
distance_m     int64
```

단, 다음처럼 숫자로 변환할 수 없는 문자열이 있으면.

```text
"100"
"200"
"미측정"
```

`astype(int)`에서 오류가 발생함.

<br>

> ## **7-3 ) `pd.to_numeric()`으로 안전하게 숫자 변환**

잘못된 문자열을 결측값으로 처리하면서 변환하고 싶다면 `pd.to_numeric()`을 활용할 수 있음.

[ python : code ] "변환할 수 없는 데이터를 NaN으로 처리"

```python
import pandas as pd

distance = pd.Series(["100", "200", "미측정", "400"])

converted = pd.to_numeric(
    distance,
    errors="coerce"
)

print(converted)
```

[ Result ]

```text
0    100.0
1    200.0
2      NaN
3    400.0
dtype: float64
```

`errors="coerce"`는 숫자로 변환할 수 없는 값을 `NaN`으로 변경함.

따라서 변환 후에는 새로 만들어진 결측값도 확인해야 함.

<br>

> ## **7-4 ) 날짜 타입 변환**

날짜가 문자열이라면 `pd.to_datetime()`을 사용 가능.

[ python : code ] "문자열 날짜를 datetime으로 변환"

```python
import pandas as pd

df_date = pd.DataFrame({
    "athlete": ["가람", "나윤", "재하"],
    "test_date": [
        "2026-09-01",
        "2026-09-05",
        "2026-09-10"
    ]
})

print(df_date["test_date"].dtype)

df_date["test_date"] = pd.to_datetime(
    df_date["test_date"]
)

print(df_date["test_date"].dtype)
```

대표적인 결과.

```text
object
datetime64[ns]
```

날짜 타입으로 변환하면 이후.

```text
연도 추출
월 추출
요일 추출
기간 계산
날짜 필터링
```

등을 편리하게 수행할 수 있음.

# **8. 데이터 분포 파악**

데이터 구조를 확인한 다음에는 값이 어떤 형태로 분포되어 있는지 확인함.

주요 메서드.

```text
describe()
value_counts()
nunique()
corr()
```

<br>

> ## **8-1 ) `describe()`**

수치형 Column의 주요 기술통계량을 확인함.

[ python : code ] "훈련시간과 점수의 기술통계 확인"

```python
df[["training_min", "score"]].describe()
```

[ Result ]

| 통계량 | training_min | score |
|---|---:|---:|
| count | 6.000000 | 6.000000 |
| mean | 70.000000 | 88.000000 |
| std | 14.491377 | 5.966574 |
| min | 50.000000 | 78.000000 |
| 25% | 61.250000 | 85.750000 |
| 50% | 70.000000 | 89.000000 |
| 75% | 78.750000 | 91.500000 |
| max | 90.000000 | 95.000000 |

각 통계량.

| 값 | 의미 |
|---|---|
| `count` | 결측값을 제외한 데이터 개수 |
| `mean` | 평균 |
| `std` | 표준편차 |
| `min` | 최솟값 |
| `25%` | 제1사분위수(Q1) |
| `50%` | 중앙값(Q2) |
| `75%` | 제3사분위수(Q3) |
| `max` | 최댓값 |

Pandas의 일반적인 수치형 `describe()`에서 `std`는 표본 표준편차를 사용함.

<br>

> ## **8-2 ) 평균과 중앙값 함께 보기**

예를 들어.

```text
mean   = 88
median = 89
```

처럼 비슷하다면 큰 왜곡이 없어 보일 수 있지만 이것만으로 분포가 대칭이라고 확정할 수는 없음.

반대로 평균과 중앙값의 차이가 크다면.

```text
극단값 존재
분포의 치우침
서로 다른 집단 혼합
```

등을 추가로 확인할 필요가 있음.

<br>

> ## **8-3 ) 표준편차 해석**

표준편차(Standard Deviation)는 데이터가 평균 주변에서 얼마나 퍼져 있는지를 나타냄.

```text
표준편차 작음
→ 값들이 평균 주변에 비교적 모여 있음

표준편차 큼
→ 값들이 넓게 퍼져 있음
```

하지만.

```text
표준편차 > 평균
```

이라는 이유만으로 이상치가 존재한다고 단정할 수는 없음.

데이터의 분포와 단위, 값의 범위를 함께 확인해야 함.

<br>

> ## **8-4 ) `value_counts()`**

각 값이 몇 번 나타나는지 확인.

[ python : code ] "종목별 선수 수 확인"

```python

```

사용 가능.

<br>

> ## **8-5 ) `nunique()`**

중복을 제외한 고유값의 개수를 계산.

[ python : code ] "지역 종류 개수 확인"


[ Result ]

```text

```

```text

```

이므로 고유한 지역 수는 `3`.

`nunique()` 역시 기본적으로 결측값을 제외함.

<br>

> ## **8-6 ) `count()`와 `nunique()` 차이**

예.

```python
athlete_ids = pd.Series([
    "A101",
    "A102",
    "A101",
    "A103"

```

```text

nunique()

```

<br>

> ## **8-7 ) `corr()`**

수치형 변수 간 상관계수를 확인할 수 있음.

수치형 Column만 명확하게 선택해서 사용하는 것이 안전함.

[ python : code ] "수치형 변수 간 상관계수 계산"

```python
numeric_df = df[
    ["training_min", "score"]
]

```

상관계수는 일반적으로 `-1 ~ 1` 사이 값으로 표현됨.

```text
1에 가까움
→ 양의 선형 관계가 강함

-1에 가까움
→ 음의 선형 관계가 강함

0에 가까움
→ 선형 관계가 약함
```

단, **상관관계가 있다고 해서 인과관계가 있다는 의미는 아님.**

# **9. 데이터 선택과 필터링**

Pandas에서는 원하는 데이터만 선택하기 위해 다음 방법을 많이 사용함.

```text
[]
loc
iloc
Boolean Indexing
```

<br>

> ## **9-1 ) `iloc` - 위치 기반 선택**

`iloc`은 `정수 위치(Integer Position)`를 기준으로 Row와 Column을 선택함.

```python
df.iloc[행위치, 열위치]
```

예.

[ python : code ] "첫 번째 Row 선택"

```python
print(df.iloc[0])
```

첫 번째 Row의 위치는 `0`.

<br>

> ## **9-2 ) 여러 Row와 Column을 `iloc`으로 선택**

[ python : code ] "처음 3명의 이름과 점수 선택"

```python
print(
    df.iloc[
        0:3,
        [1, 4]
    ]
)
```

현재 Column 위치.

```text
0 → athlete_id
1 → name
2 → sport
3 → training_min
4 → score
5 → region
```

[ Result ]

|   | name | score |
|---:|---|---:|
| 0 | 도윤 | 88 |
| 1 | 서아 | 92 |
| 2 | 태민 | 85 |

`iloc`의 슬라이싱은 Python 슬라이싱과 마찬가지로 **끝 위치를 포함하지 않음.**

```python
0:3
```

은.

```text
0
1
2
```

를 선택함.

<br>

> ## **9-3 ) `loc` - 레이블 기반 선택**

`loc`은 Index와 Column 이름 같은 `레이블(Label)`을 기준으로 선택함.

[ python : code ] "name과 score Column 선택"

```python
print(
    df.loc[
        :,
        ["name", "score"]
    ]
)
```

`:`는 모든 Row를 의미함.

<br>

> ## **9-4 ) `loc`과 `iloc` 슬라이싱의 중요한 차이**

기본 `RangeIndex`가 있는 경우.

```python
df.iloc[0:3]
```

결과.

```text
Index 0
Index 1
Index 2
```

하지만.

```python
df.loc[0:3]
```

에서는 Label `3`도 포함됨.

```text
Index 0
Index 1
Index 2
Index 3
```

즉.

```text
iloc 슬라이스
→ 끝 위치 미포함

loc 레이블 슬라이스
→ 일반적으로 끝 레이블 포함
```

이 차이를 주의해야 함.

<br>

> ## **9-5 ) Boolean Indexing**

조건을 만족하는 Row만 선택할 때 사용.

예를 들어 점수가 `90` 이상인 선수.

[ python : code ] "점수가 90 이상인 선수 필터링"

```python
high_score = df[
    df["score"] >= 90
]

print(
    high_score[
        ["name", "sport", "score"]
    ]
)
```

[ Result ]

|   | name | sport | score |
|---:|---|---|---:|
| 1 | 서아 | 수영 | 92 |
| 3 | 하린 | 육상 | 95 |
| 5 | 유나 | 농구 | 90 |

조건식.

```python
df["score"] >= 90
```

은 실제로 다음과 같은 Boolean Series를 생성함.

```text
False
True
False
True
False
True
```

`True`인 Row만 선택되는 구조임.

<br>

> ## **9-6 ) 여러 조건을 AND로 연결**

예.

```text
서울 지역
AND
점수 85 이상
```

[ python : code ] "여러 조건을 모두 만족하는 선수 선택"

```python
selected = df[
    (df["region"] == "서울")
    & (df["score"] >= 85)
]

print(
    selected[
        ["name", "region", "score"]
    ]
)
```

서울 선수.

```text
도윤 → 88
태민 → 85
시우 → 78
```

점수 85 이상까지 만족.

```text
도윤
태민
```

[ Result ]

|   | name | region | score |
|---:|---|---|---:|
| 0 | 도윤 | 서울 | 88 |
| 2 | 태민 | 서울 | 85 |

### 처리 흐름

```text
전체 DataFrame
      ↓
region == "서울"
      ↓
True / False 생성
      ↓
score >= 85
      ↓
True / False 생성
      ↓
&
      ↓
두 조건이 모두 True인 Row
      ↓
도윤 / 태민
```

<br>

> ## **9-7 ) OR 조건**

둘 중 하나를 만족하면 선택.

```python
df[
    (df["sport"] == "수영")
    | (df["score"] >= 95)
]
```

`|`는 OR 조건.

<br>

> ## **9-8 ) NOT 조건**

조건의 반대를 선택하려면 `~` 사용 가능.

```python
df[
    ~(df["region"] == "서울")
]
```

의미.

```text
서울이 아닌 Row 선택
```

<br>

> ## **9-9 ) `and`, `or`가 아닌 `&`, `|`를 사용하는 이유**

다음 코드는 올바르지 않음.

```python
df[
    (df["region"] == "서울")
    and
    (df["score"] >= 85)
]
```

Pandas의 각 조건식은 하나의 `True`나 `False`가 아니라 **여러 Boolean 값으로 이루어진 Series**임.

예.

```text
df["region"] == "서울"

0     True
1    False
2     True
3    False
4     True
5    False
```

Python의 `and`는 Series 전체를 하나의 참/거짓으로 판단하려 하므로 모호성 오류가 발생함.

따라서 Pandas에서는.

```text
AND → &
OR  → |
NOT → ~
```

를 사용함.

여러 조건은 연산자 우선순위 문제를 방지하기 위해 각각 괄호로 묶는 것이 기본 패턴임.

```python
df[
    (조건1)
    & (조건2)
]
```

```text
        ↓
```


중복된 Row를 직접 확인하려면.

```python
df[
```

사용 가능.

> ## **12-3 ) `set_index()`는 원본을 자동 변경하지 않음**

```python
df_indexed = df.set_index("athlete_id")
```

기본적으로.

```text
df
→ 기존 DataFrame 유지

df_indexed
```

`reset_index()`도 동일한 방식으로 새로운 DataFrame을 반환함.

> ## **12-4 ) `inplace=True`에 의존하지 않아도 됨**

Pandas에서는.

```python
df.set_index(
    "athlete_id",
    inplace=True
)
```

처럼 원본을 직접 수정할 수도 있지만 초보 단계에서는.

```python
df = df.set_index("athlete_id")
```

또는.

```python
df_indexed = df.set_index("athlete_id")
```

처럼 반환값을 다시 저장하는 방식이 데이터 흐름을 확인하기 쉬움.

<br>

```python
df_raw = pd.read_csv(
    "athlete_performance.csv"

```

이후.

```text
df_raw
→ 원본 확인용

df_clean
→ 실제 전처리 작업용
```

으로 분리 가능.

특히 실제 프로젝트에서는 전처리 결과가 이상할 때 원본과 비교할 수 있어 유용함.



로 실제 변환 결과를 다시 확인하는 습관이 좋음.

과정이 필요함.

# **13. 핵심정리**

- 데이터 전처리(Data Preprocessing)는 원시 데이터를 분석이나 모델링에 적합한 상태로 정리하는 과정임.
- 데이터 전처리에는 결측값, 중복값, 오류값, 데이터 타입, 이상값 등의 점검이 포함될 수 있음.
- 전처리는 무조건 데이터를 삭제하는 과정이 아니며 **분석 목적과 데이터 의미를 먼저 확인해야 함.**
- 이상치는 실제로 중요한 관측값일 수도 있으므로 무조건 제거하면 안 됨.
- 결측값을 제외하는 것과 `0`으로 대체하는 것은 분석 의미가 완전히 다를 수 있음.
- Pandas는 Python에서 표 형태의 데이터를 다루기 위한 대표적인 외부 데이터 분석 라이브러리임.
- `import pandas as pd` 형태로 불러오는 것이 일반적임.
- `pd.DataFrame()`은 행과 열로 구성된 2차원 자료구조를 생성함.
- `Series`는 인덱스가 붙은 1차원 자료구조임.
- `df["column"]`은 일반적으로 Series를 반환함.
- `df[["column"]]`은 Column이 하나여도 DataFrame을 반환함.
- `pd.read_csv()`는 CSV 파일을 DataFrame으로 불러옴.
- `pd.read_excel()`은 Excel 파일을 DataFrame으로 불러옴.
- `to_csv()`, `to_excel()`을 이용하여 처리 결과를 다시 파일로 저장할 수 있음.
- `index=False`를 사용하면 DataFrame Index가 별도의 파일 Column으로 저장되지 않음.
- Index는 DataFrame과 Series의 각 Row에 붙어 있는 레이블임.
- Pandas Index는 중복될 수 있으므로 SQL의 `PRIMARY KEY`와 동일한 개념이 아님.
- `set_index()`는 특정 Column을 Index로 설정함.
- `reset_index()`는 Index를 다시 일반 Column으로 되돌릴 수 있음.
- `head()`는 앞부분, `tail()`은 뒷부분의 데이터를 확인함.
- `shape`은 `(Row 수, Column 수)`를 반환하는 속성임.
- `columns`는 Column 이름을 확인함.
- `dtypes`는 각 Column의 데이터 타입을 확인함.
- `info()`는 Row 수, Column, Non-Null 개수, dtype 등의 구조를 종합적으로 확인함.
- `info()`는 자체적으로 정보를 출력하므로 일반적으로 `print(df.info())`가 아니라 `df.info()`로 사용함.
- `astype()`으로 데이터 타입을 변환할 수 있으나 변환할 수 없는 값이 존재하면 오류가 발생할 수 있음.
- `pd.to_numeric(errors="coerce")`를 사용하면 변환할 수 없는 값을 `NaN`으로 처리하며 숫자로 변환할 수 있음.
- `pd.to_datetime()`을 사용하면 문자열 날짜를 날짜·시간 타입으로 변환할 수 있음.
- `describe()`는 `count`, `mean`, `std`, `min`, 사분위수, `max` 등의 기술통계를 제공함.
- 평균과 중앙값의 차이는 분포의 치우침이나 극단값을 의심하는 단서가 될 수 있지만 그것만으로 분포 형태를 확정하면 안 됨.
- 표준편차가 크다는 사실만으로 이상치가 있다고 단정할 수 없음.
- `value_counts()`는 각 값의 등장 빈도를 계산함.
- `nunique()`는 중복을 제외한 고유값 개수를 계산함.
- `count()`는 결측값을 제외한 데이터 개수를 계산하므로 `nunique()`와 목적이 다름.
- `corr()`은 수치형 변수 간 선형 상관관계를 확인할 수 있지만 상관관계가 인과관계를 의미하지는 않음.
- `iloc`은 정수 위치를 기준으로 데이터를 선택함.
- `loc`은 Index와 Column 이름 같은 레이블을 기준으로 데이터를 선택함.
- `iloc` 슬라이싱은 끝 위치를 포함하지 않음.
- `loc`의 레이블 슬라이싱은 일반적으로 끝 레이블까지 포함하므로 둘의 차이를 주의해야 함.
- Boolean Indexing은 조건이 `True`인 Row만 선택하는 방법임.
- Pandas Boolean Indexing에서 여러 조건을 결합할 때 `and`, `or` 대신 `&`, `|`를 사용함.
- 조건을 반대로 만들 때는 `~`를 사용할 수 있음.
- 여러 Boolean 조건은 각각 `( )`로 감싸는 것이 기본적인 작성 방식임.
- 새로운 데이터를 받았을 때는 `head()` → `shape` → `columns` → `info()` / `dtypes` → `describe()` → 결측·중복·이상값 확인 순으로 탐색하면 데이터 구조를 파악하기 쉬움.
- 전처리를 수행할 때는 원본 DataFrame과 작업용 DataFrame을 분리해 두면 전처리 결과를 비교하고 검증하기 편리함.
