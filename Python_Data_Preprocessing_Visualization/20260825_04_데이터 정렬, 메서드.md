# **1. sort_values(): 컬럼 값을 기준으로 정렬**

`sort_values()`는 DataFrame의 **특정 컬럼 값을 기준으로 데이터를 오름차순 또는 내림차순으로 정렬**할 때 사용하는 메서드임.

선수 기록, 경기 득점, 측정값, 훈련시간처럼 값의 크기를 기준으로 순서를 확인할 때 자주 사용함.

> ## **1-1 ) sort_values() 기본 사용**

`ascending=True`는 오름차순이며 기본값임.

`ascending=False`를 지정하면 내림차순으로 정렬함.

| 설정 | 정렬 방향 |
| --- | --- |
| `ascending=True` | 작은 값 → 큰 값 |
| `ascending=False` | 큰 값 → 작은 값 |

[ python : code ] "선수 평가점수를 높은 순서대로 정렬"

```python
import pandas as pd

df = pd.DataFrame({
    "athlete": ["서윤", "도현", "하린", "민재"],
    "sport": ["수영", "사이클", "육상", "농구"],
    "score": [88, 95, 91, 84]
})

result = (
    df.sort_values(
        "score",
        ascending=False
    )
    .reset_index(drop=True)
)

print(result.to_string(index=False))
```

[ Result ]

```text
athlete sport  score
     도현   사이클     95
     하린    육상     91
     서윤    수영     88
     민재    농구     84
```

`score`가 높은 순서대로 정렬되므로.

```text
95
↓
91
↓
88
↓
84
```

순서가 됨.

<br>

> ## **1-2 ) reset_index(drop=True)**

`sort_values()`를 실행해도 기존 Index는 그대로 유지됨.

예를 들어 원래 데이터가.

```text
index
0 → 서윤 88
1 → 도현 95
2 → 하린 91
3 → 민재 84
```

였다면 정렬 후 실제 Row의 순서는 변하지만 기존 Index 값은 따라 이동함.

```text
1 → 도현 95
2 → 하린 91
0 → 서윤 88
3 → 민재 84
```

새로운 순서에 맞게 Index를 다시 `0, 1, 2, 3`으로 만들고 싶다면.

```python
reset_index(drop=True)
```

를 사용함.

`drop=True`는 기존 Index를 새로운 컬럼으로 남기지 않고 제거함.

```text
정렬
   ↓
기존 Index 순서가 섞임
   ↓
reset_index(drop=True)
   ↓
0, 1, 2, 3 ... 새 Index 생성
```

정렬 후 반드시 필요한 것은 아니며 **연속된 새 Index가 필요한 경우 사용**하면 됨.

<br>

> ## **1-3 ) 여러 컬럼을 기준으로 정렬**

둘 이상의 컬럼을 순서대로 정렬 기준으로 지정할 수도 있음.

예를 들어.

```text
1순위 → score 내림차순
2순위 → athlete 오름차순
```

으로 정렬할 수 있음.

[ python : code ] "점수가 높은 순으로 정렬하고 동점이면 선수 이름으로 정렬"

```python
import pandas as pd

df = pd.DataFrame({
    "athlete": ["서윤", "도현", "하린", "민재", "유나"],
    "team": ["A", "B", "A", "B", "A"],
    "score": [90, 95, 95, 88, 95]
})

result = (
    df.sort_values(
        ["score", "athlete"],
        ascending=[False, True]
    )
    .reset_index(drop=True)
)

print(result.to_string(index=False))
```

[ Result ]

```text
athlete team  score
     도현    B     95
     유나    A     95
     하린    A     95
     서윤    A     90
     민재    B     88
```

먼저 `score`가 높은 순서로 정렬함.

```text
95
95
95
90
88
```

그다음 같은 `95점` 안에서는 `athlete` 이름을 오름차순으로 정렬함.

```text
도현
유나
하린
```

### 흐름도

```text
[원본 데이터]
      ↓
score 기준 정렬
ascending=False
      ↓
95 / 95 / 95 / 90 / 88
      ↓
95점 동점자 발생
      ↓
athlete 기준
ascending=True
      ↓
도현 → 유나 → 하린
      ↓
최종 정렬 결과
```

<br>

> ## **1-4 ) sort_values() 활용 예**

데이터 분석에서는 다음과 같은 상황에 활용 가능함.

```text
득점 상위 선수
→ score 내림차순

보행속도가 느린 대상자
→ gait_speed 오름차순

훈련량이 많은 선수
→ training_load 내림차순

회복 기간이 긴 선수
→ recovery_days 내림차순
```

상위 데이터만 필요하면 정렬 후 `head()`를 함께 사용할 수 있음.

```python
df.sort_values(
    "score",
    ascending=False
).head(10)
```

# **2. sort_index(): 인덱스를 기준으로 정렬**

`sort_index()`는 데이터의 실제 값이 아니라 **Index 레이블을 기준으로 정렬**함.

`groupby()` 결과처럼 그룹명이 Index가 되었거나 날짜·선수 ID 등이 Index인 데이터에서 유용함.

> ## **2-1 ) sort_index() 기본 사용**

[ python : code ] "측정 ID 인덱스를 오름차순으로 정렬"

```python
import pandas as pd

jump = pd.Series(
    [7.8, 6.9, 8.1],
    index=["T03", "T01", "T02"],
    name="jump_m"
)

result = jump.sort_index()

print(result)
```

[ Result ]

```text
T01    6.9
T02    8.1
T03    7.8
Name: jump_m, dtype: float64
```

점프 거리값인.

```text
7.8
6.9
8.1
```

을 크기 순서로 정렬한 것이 아님.

Index인.

```text
T03
T01
T02
```

를.

```text
T01
T02
T03
```

순서로 정렬한 것임.

<br>

> ## **2-2 ) sort_values()와 sort_index() 차이**

| 구분 | `sort_values()` | `sort_index()` |
| --- | --- | --- |
| 정렬 기준 | 컬럼의 실제 값 | Index 레이블 |
| 대표 목적 | 점수·매출·기록 순위 | 날짜·ID·그룹 Index 정리 |
| 기본 방향 | 오름차순 | 오름차순 |
| 내림차순 | `ascending=False` | `ascending=False` |

```text
값의 크기로 정렬
→ sort_values()

Index 순서로 정렬
→ sort_index()
```

<br>

> ## **2-3 ) groupby() 결과와 sort_index()**

`groupby()` 결과에서는 그룹 기준이 Index가 될 수 있음.

[ python : code ] "팀별 훈련시간 합계를 계산한 뒤 팀 Index를 정렬"

```python
import pandas as pd

training = pd.DataFrame({
    "team": ["C", "A", "B", "A", "C"],
    "training_min": [50, 60, 70, 40, 30]
})

team_total = (
    training
    .groupby(
        "team",
        sort=False
    )["training_min"]
    .sum()
)

print("정렬 전")
print(team_total)

print("\n정렬 후")
print(team_total.sort_index())
```

[ Result ]

```text
정렬 전
team
C    80
A    100
B    70
Name: training_min, dtype: int64

정렬 후
team
A    100
B     70
C     80
Name: training_min, dtype: int64
```

`groupby(sort=False)`를 사용했기 때문에 처음에는 원본 데이터에 등장한.

```text
C → A → B
```

순서가 유지됨.

이후 `sort_index()`를 사용해.

```text
A → B → C
```

순서로 정렬함.

# **3. lambda: 간단한 익명 함수**

`lambda`는 이름을 따로 정의하지 않고 **한 줄로 작성하는 간단한 함수**임.

기본 구조는 다음과 같음.

```python
lambda 입력값: 반환식
```

예를 들어.

```python
lambda x: x * 2
```

는 다음 함수와 비슷하게 동작함.

```python
def double(x):
    return x * 2
```

Pandas에서는 `Series.apply()`와 함께 간단한 값을 변환할 때 자주 사용할 수 있음.

> ## **3-1 ) apply()와 lambda**

훈련시간이 분 단위로 저장되어 있다고 가정함.

이를 시간 단위로 변환할 수 있음.

[ python : code ] "훈련시간을 분에서 시간으로 변환"

```python
import pandas as pd

df = pd.DataFrame({
    "athlete": ["서윤", "도현", "하린"],
    "training_min": [50, 70, 40]
})

df["training_hour"] = df[
    "training_min"
].apply(
    lambda x: x / 60
)

print(df.to_string(index=False))
```

[ Result ]

```text
athlete  training_min  training_hour
     서윤            50       0.833333
     도현            70       1.166667
     하린            40       0.666667
```

계산은 각 Row마다 다음과 같이 적용됨.

```text
50 / 60
= 0.833333...

70 / 60
= 1.166666...

40 / 60
= 0.666666...
```

<br>

> ## **3-2 ) lambda에 조건문 사용**

Python의 삼항 조건식을 이용하면 간단한 조건 분류도 가능함.

기본 형태.

```python
lambda x: 값1 if 조건 else 값2
```

회복일수가 3일 이하이면 `빠른 회복`, 그 외에는 `추가 회복 필요`로 구분한다고 가정함.

> 아래 기준은 Python 사용법을 설명하기 위한 가상의 예시이며 실제 운동처방·의학적 판단 기준이 아님.

[ python : code ] "회복일수에 따라 회복 유형을 분류"

```python
import pandas as pd

df = pd.DataFrame({
    "athlete": ["서윤", "도현", "하린", "민재"],
    "recovery_days": [2, 4, 3, 5]
})

df["recovery_type"] = df[
    "recovery_days"
].apply(
    lambda x:
    "빠른 회복"
    if x <= 3
    else "추가 회복 필요"
)

print(df.to_string(index=False))
```

[ Result ]

```text
athlete  recovery_days recovery_type
     서윤              2         빠른 회복
     도현              4      추가 회복 필요
     하린              3         빠른 회복
     민재              5      추가 회복 필요
```

동작 방식.

```text
2 <= 3 → True  → 빠른 회복
4 <= 3 → False → 추가 회복 필요
3 <= 3 → True  → 빠른 회복
5 <= 3 → False → 추가 회복 필요
```

<br>

> ## **3-3 ) lambda와 def 비교**

| 구분 | `lambda` | `def` |
| --- | --- | --- |
| 함수 이름 | 보통 없음 | 이름 지정 |
| 작성 형태 | 한 표현식 | 여러 문장 가능 |
| 적합한 상황 | 간단한 일회성 처리 | 복잡한 로직 |
| 재사용 | 상대적으로 불편 | 편리 |
| 가독성 | 짧은 로직에 좋음 | 복잡한 로직에 좋음 |

간단한 코드라면.

```python
df["score"].apply(
    lambda x: x * 1.1
)
```

처럼 사용할 수 있음.

하지만 조건이 많거나 여러 단계의 작업이 필요하다면.

```python
def calculate_score(x):
    ...
    return result
```

처럼 `def`를 사용하는 편이 읽기 쉬움.

# **4. split(): 문자열 분리**

`split()`은 문자열을 특정 구분자(Delimiter)를 기준으로 여러 부분으로 나누는 기능임.

일반 Python 문자열 하나에는 `split()`을 사용하고, Pandas Series 전체에 적용할 때는 `.str.split()`을 사용함.

> ## **4-1 ) Python 문자열의 split()**

[ python : code ] "선수 코드를 하이픈 기준으로 분리"

```python
code = "SWIM-001"

result = code.split("-")

print(result)
```

[ Result ]

```text
['SWIM', '001']
```

`-`가 구분자로 사용됨.

```text
SWIM-001
  ↓
"-" 기준 분리
  ↓
SWIM | 001
```

<br>

> ## **4-2 ) Pandas의 str.split()**

DataFrame의 한 Column 전체에 문자열 기능을 적용할 때 `.str` 접근자를 사용함.

```python
Series.str.split()
```

형태로 작성함.

[ python : code ] "선수 코드에서 종목 코드와 선수 번호를 새로운 컬럼으로 분리"

```python
import pandas as pd

df = pd.DataFrame({
    "athlete_code": [
        "SWIM-001",
        "RUN-014",
        "BIKE-203"
    ]
})

df[
    ["sport_code", "athlete_no"]
] = df[
    "athlete_code"
].str.split(
    "-",
    expand=True
)

print(df.to_string(index=False))
```

[ Result ]

```text
athlete_code sport_code athlete_no
    SWIM-001       SWIM        001
     RUN-014        RUN        014
    BIKE-203       BIKE        203
```

분리 과정.

```text
SWIM-001
  ↓
SWIM | 001

RUN-014
  ↓
RUN | 014

BIKE-203
  ↓
BIKE | 203
```

<br>

> ## **4-3 ) expand=True의 역할**

다음처럼 작성하면.

```python
df["athlete_code"].str.split("-")
```

각 Row가 리스트 형태로 반환됨.

```text
['SWIM', '001']
['RUN', '014']
['BIKE', '203']
```

반면.

```python
df["athlete_code"].str.split(
    "-",
    expand=True
)
```

처럼 `expand=True`를 사용하면 결과가 여러 Column으로 펼쳐짐.

```text
      0      1
0  SWIM    001
1   RUN    014
2  BIKE    203
```

따라서 다음처럼 여러 새로운 Column에 바로 저장 가능함.

```python
df[
    ["sport_code", "athlete_no"]
] = ...
```

<br>

> ## **4-4 ) split()과 str.split() 비교**

| 대상 | 사용 방법 |
| --- | --- |
| 문자열 하나 | `"RUN-001".split("-")` |
| Series 전체 | `df["code"].str.split("-")` |
| 여러 컬럼으로 분리 | `.str.split("-", expand=True)` |

`.str`은 **Series의 각 문자열 값에 문자열 기능을 적용하기 위한 Pandas 문자열 접근자**로 이해하면 됨.

# **5. rrule: 반복 날짜 규칙 생성**

`rrule`은 `dateutil` 라이브러리에서 제공하는 기능으로 **반복되는 날짜 규칙을 정의하고 날짜 시퀀스를 생성**할 때 사용함.

예를 들어.

```text
매주 월요일
매주 금요일
매월 특정 날짜
매년 특정 날짜
```

등의 반복 일정 생성에 활용할 수 있음.

> ## **5-1 ) 매주 반복되는 일정 생성**

팀에서 매주 월요일 운동능력 측정을 실시한다고 가정함.

[ python : code ] "매주 월요일 반복되는 5개의 체력측정 날짜 생성"

```python
from dateutil.rrule import (
    rrule,
    WEEKLY,
    MO
)
from datetime import datetime

test_dates = list(
    rrule(
        WEEKLY,
        count=5,
        byweekday=MO,
        dtstart=datetime(
            2026,
            9,
            7
        )
    )
)

for date in test_dates:
    print(
        date.strftime(
            "%Y-%m-%d"
        )
    )
```

[ Result ]

```text
2026-09-07
2026-09-14
2026-09-21
2026-09-28
2026-10-05
```

주요 설정.

| 설정 | 의미 |
| --- | --- |
| `WEEKLY` | 매주 반복 |
| `MO` | 월요일 |
| `count=5` | 총 5개의 날짜 생성 |
| `dtstart` | 반복 시작 기준 날짜 |

동작 흐름.

```text
시작일
2026-09-07
      ↓
WEEKLY
      ↓
월요일마다 반복
      ↓
count=5
      ↓
09-07
09-14
09-21
09-28
10-05
```

<br>

> ## **5-2 ) strftime()으로 날짜 출력 형식 변경**

`rrule()`에서 생성되는 값은 날짜·시간 객체임.

`strftime()`을 이용하면 원하는 문자열 형태로 변환 가능함.

```python
date.strftime(
    "%Y-%m-%d"
)
```

대표적인 날짜 형식 코드는 다음과 같음.

| 코드 | 의미 | 예 |
| --- | --- | --- |
| `%Y` | 4자리 연도 | `2026` |
| `%m` | 월 | `09` |
| `%d` | 일 | `07` |
| `%A` | 요일 이름 | `Monday` |

예.

```python
date.strftime(
    "%Y-%m-%d (%A)"
)
```

결과 형태.

```text
2026-09-07 (Monday)
```

<br>

> ## **5-3 ) rrule과 pd.date_range() 비교**

반복되는 날짜는 Pandas의 `pd.date_range()`로도 만들 수 있음.

두 기능은 목적이 일부 겹치지만 사용 방식에 차이가 있음.

| 구분 | `pd.date_range()` | `rrule` |
| --- | --- | --- |
| 주요 목적 | 일정한 빈도의 날짜 생성 | 반복 규칙 기반 날짜 생성 |
| 라이브러리 | Pandas | `dateutil` |
| 단순 일·주·월 간격 | 편리 | 가능 |
| 요일 등 반복 규칙 | 가능 | 세밀한 규칙 표현에 유용 |
| 대표 사용 | 시계열 Index 생성 | 반복 일정 생성 |

간단한 연속 날짜나 Pandas 시계열 분석용 날짜라면 `pd.date_range()`가 편리하고, 반복 일정 규칙을 명시적으로 표현해야 한다면 `rrule`을 활용할 수 있음.

# **7. Advanced 추가 학습**

> ## **7-1 ) lambda보다 벡터 연산이 간단한 경우**

단순 산술 연산은 반드시 `apply() + lambda`를 사용할 필요가 없음.

예를 들어.

```python
df["adjusted_score"] = df[
    "score"
].apply(
    lambda x: x * 1.1
)
```

은 다음처럼 더 간단하게 작성 가능함.

```python
df["adjusted_score"] = (
    df["score"] * 1.1
)
```

Pandas에서는 가능한 경우 **Series 전체에 직접 연산하는 벡터화 방식**이 간결하고 효율적인 경우가 많음.

<br>

> ## **7-2 ) 날짜는 split보다 datetime 변환도 고려**

날짜가.

```text
2026-09-13
```

처럼 저장되어 있을 때 단순 문자열 분리도 가능함.

```python
df["date"].str.split(
    "-",
    expand=True
)
```

하지만 실제 날짜 분석이 목적이라면.

```python
df["date"] = pd.to_datetime(
    df["date"]
)
```

로 날짜 타입으로 변환한 뒤.

```python
df["date"].dt.year
df["date"].dt.month
df["date"].dt.day
```

를 사용하는 방법도 있음.

<br>

> ## **7-3 ) 정렬 결과가 같을 때 추가 기준 지정**

점수가 같은 선수가 여러 명이면 첫 번째 정렬 기준만으로는 원하는 세부 순서를 표현하지 못할 수 있음.

이때 여러 정렬 기준을 사용함.

```python
df.sort_values(
    ["score", "athlete"],
    ascending=[False, True]
)
```

의미.

```text
1차 → score 높은 순
2차 → 이름 오름차순
```

# **8. 핵심정리**

1. `sort_values()`는 특정 **컬럼 값**을 기준으로 데이터를 정렬함.

2. `ascending=True`는 오름차순, `ascending=False`는 내림차순임.

3. 여러 정렬 기준이 필요하면 다음처럼 컬럼과 정렬 방향을 리스트로 지정할 수 있음.

```python
df.sort_values(
    ["score", "athlete"],
    ascending=[False, True]
)
```

4. 정렬 후 기존 Index가 필요하지 않고 새로운 연속 Index가 필요하다면 `reset_index(drop=True)`를 사용할 수 있음.

5. `sort_values()`와 `sort_index()`의 차이는 다음과 같음.

| 메서드 | 정렬 기준 |
| --- | --- |
| `sort_values()` | 데이터 값 |
| `sort_index()` | Index 레이블 |

6. `lambda`는 이름 없이 간단한 한 줄 함수를 작성할 때 사용하는 Python 문법임.

7. `Series.apply()`와 `lambda`를 함께 사용하면 각 값에 간단한 변환이나 조건식을 적용할 수 있음.

8. 복잡하거나 여러 번 재사용하는 함수는 `lambda`보다 `def`로 정의하는 것이 적합함.

9. 단순 산술 계산은 `apply() + lambda`보다 다음과 같은 벡터 연산으로 더 간단하게 처리할 수도 있음.

```python
df["new"] = df["value"] * 1.1
```

10. 문자열 하나를 분리할 때는 `split()`, Pandas Series 전체를 분리할 때는 `.str.split()`을 사용함.

11. `.str.split(..., expand=True)`를 사용하면 분리한 문자열을 여러 Column으로 만들 수 있음.

12. 날짜 문자열을 실제 날짜 분석에 사용해야 한다면 단순 `split()`뿐 아니라 `pd.to_datetime()` 변환도 고려해야 함.

13. `rrule`은 매주 특정 요일처럼 **반복되는 날짜 규칙을 정의하고 날짜 목록을 생성**할 때 활용함.

14. `pd.date_range()`는 Pandas에서 일정한 빈도의 날짜 범위를 만들 때 편리하고, `rrule`은 반복 일정 규칙을 표현할 때 유용함.

15. 이번 강의의 기능은 다음 기준으로 구분하면 이해하기 쉬움.

| 필요한 작업 | 사용 기능 |
| --- | --- |
| 점수·기록 등 값으로 정렬 | `sort_values()` |
| 날짜·ID 등 Index로 정렬 | `sort_index()` |
| 간단한 값 변환 | `lambda` + `apply()` |
| 문자열 구성요소 분리 | `str.split()` |
| 반복 일정 생성 | `rrule()` |
