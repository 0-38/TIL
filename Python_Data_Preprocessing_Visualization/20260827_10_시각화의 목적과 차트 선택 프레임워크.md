# **1. 데이터 시각화의 목적 3가지**

데이터 시각화(Data Visualization)는 데이터를 그래프나 차트 형태로 표현하여 **사람이 데이터의 특징을 직관적으로 이해할 수 있도록 돕는 작업**임.

시각화는 단순히 예쁜 그래프를 만드는 것이 아니라 **무엇을 발견하거나 전달하려는지 목적을 먼저 정하는 것**이 중요함.

대표적인 목적은 다음 세 가지임.

| 목적 | 의미 |
| --- | --- |
| 패턴 발견 | 데이터 속 분포·추세·이상한 움직임 탐색 |
| 의사결정 지원 | 데이터를 근거로 행동이나 전략 선택 |
| 효과적 커뮤니케이션 | 발견한 결과를 이해관계자에게 명확하게 전달 |

> ## **1-1 ) 패턴 발견**

EDA 과정에서는 데이터에 어떤 패턴이 존재하는지 탐색하기 위해 시각화를 사용할 수 있음.

예를 들어 선수의 월별 훈련량이 다음과 같다고 가정함.

```text
1월 → 120
2월 → 125
3월 → 118
4월 → 150
5월 → 170
```

[ python : code ] "월별 훈련량의 변화 추세를 선 그래프로 표현"

```python
import matplotlib.pyplot as plt

months = ["1월", "2월", "3월", "4월", "5월"]
training_load = [120, 125, 118, 150, 170]

plt.plot(
    months,
    training_load,
    marker="o"
)

plt.xlabel("Month")
plt.ylabel("Training Load")
plt.title("Monthly Training Load")

plt.show()
```

[ Result ]

```text
월별 훈련량을 연결한 선 그래프가 출력됨.

1월 → 120
2월 → 125
3월 → 118
4월 → 150
5월 → 170
```

그래프를 보면.

```text
1월 → 2월
120 → 125
증가

2월 → 3월
125 → 118
감소

3월 → 4월
118 → 150
큰 폭 증가

4월 → 5월
150 → 170
증가
```

라는 패턴을 쉽게 발견할 수 있음.

<br>

> ## **1-2 ) 의사결정 지원**

같은 그래프라도 목적이 의사결정이라면 다음과 같은 질문으로 연결할 수 있음.

```text
4월 이후 훈련량이 크게 증가했는가?
        ↓
증가 원인은 무엇인가?
        ↓
훈련 프로그램 변경 때문인가?
        ↓
경기력 또는 피로도에도 변화가 있는가?
        ↓
향후 훈련 프로그램을 유지할 것인가?
```

즉 시각화는 단순한 데이터 표현이 아니라 **다음 행동을 결정하는 근거**가 될 수 있음.

<br>

> ## **1-3 ) 효과적 커뮤니케이션**

분석 결과를 다른 사람에게 전달하는 것이 목적이라면 모든 데이터를 복잡하게 보여주기보다 **핵심 메시지가 잘 드러나는 그래프**를 선택하는 것이 중요함.

예를 들어.

```text
"최근 훈련량이 증가하고 있다."
```

라는 메시지를 전달하고 싶다면 월별 변화를 보여주는 간단한 선 그래프가 효과적일 수 있음.

반면 탐색 과정에서는 여러 변수나 여러 그래프를 함께 확인할 수 있음.

```text
탐색 목적
→ 다양한 패턴 확인

커뮤니케이션 목적
→ 핵심 메시지 명확하게 전달
```

<br>

> ## **1-4 ) 시각화 목적 비교**

| 목적 | 핵심 질문 | 특징 |
| --- | --- | --- |
| 패턴 발견 | 데이터에 무엇이 숨어 있는가? | EDA 중심 |
| 의사결정 지원 | 이 결과를 바탕으로 무엇을 할 것인가? | 행동 선택 중심 |
| 커뮤니케이션 | 무엇을 가장 명확하게 전달할 것인가? | 핵심 메시지 중심 |

같은 데이터라도 **왜 시각화하는지에 따라 차트와 표현 방식이 달라질 수 있음.**

# **2. 차트 선택 프레임워크**

차트를 선택할 때 무작정 그래프 종류부터 고르는 것이 아니라 다음 두 가지 질문을 먼저 확인함.

```text
Q1. 변수가 몇 개인가?

Q2. 무엇을 보여주고 싶은가?
```

> ## **2-1 ) Q1. 변수가 몇 개인가?**

시각화에 사용하는 변수 개수에 따라 다음처럼 구분할 수 있음.

| 구분 | 변수 수 |
| --- | ---: |
| 단변량(Univariate) | 1개 |
| 이변량(Bivariate) | 2개 |
| 다변량(Multivariate) | 3개 이상 |

예를 들어.

```text
선수의 키 분포
→ 키 1개
→ 단변량
```

```text
훈련시간과 경기점수의 관계
→ 훈련시간 + 경기점수
→ 이변량
```

```text
훈련시간 + 경기점수 + 포지션
→ 3개
→ 다변량
```

<br>

> ## **2-2 ) Q2. 무엇을 보여주고 싶은가?**

차트를 선택할 때는 변수 개수뿐 아니라 **전달하려는 목적**도 함께 확인해야 함.

대표적인 목적.

```text
분포
관계
비교
추세
구성비
```

| 목적 | 확인하려는 내용 |
| --- | --- |
| 분포 | 값이 어디에 많이 모여 있는가? |
| 관계 | 두 변수 사이에 어떤 관계가 있는가? |
| 비교 | 그룹별 값이 어떻게 다른가? |
| 추세 | 시간에 따라 어떻게 변하는가? |
| 구성비 | 전체에서 각 항목이 어느 정도를 차지하는가? |

<br>

> ## **2-3 ) 변수 수 + 전달 목적**

예를 들어 시간대에 따른 체육관 이용자 수를 확인한다고 가정함.

```text
변수 1
→ 시간

변수 2
→ 이용자 수
```

따라서 이변량 데이터임.

그리고 알고 싶은 것은.

```text
시간에 따라 이용자 수가 어떻게 변하는가?
```

이므로 목적은 **추세**임.

따라서 선 그래프를 사용할 수 있음.

[ python : code ] "시간대에 따른 체육관 이용자 수 변화 시각화"

```python
import matplotlib.pyplot as plt

hours = [9, 10, 11, 12, 13, 14]
users = [12, 18, 25, 48, 42, 30]

plt.plot(
    hours,
    users,
    marker="o"
)

plt.xlabel("Hour")
plt.ylabel("Users")
plt.title("Gym Users by Hour")

plt.show()
```

[ Result ]

```text
시간대별 체육관 이용자 수를 연결한 선 그래프가 출력됨.

9시  → 12명
10시 → 18명
11시 → 25명
12시 → 48명
13시 → 42명
14시 → 30명
```

그래프를 보면.

```text
9시부터 이용자 증가
       ↓
12시에 최대 48명
       ↓
13시부터 감소
```

라는 추세를 확인할 수 있음.

<br>

> ## **2-4 ) 차트 선택 매트릭스**

| 목적 | 단변량 | 이변량 | 다변량 |
| --- | --- | --- | --- |
| 분포 | 히스토그램, KDE | 그룹별 박스플롯 | 바이올린 플롯 등 |
| 관계 | — | 산점도 | 산점도 행렬 등 |
| 비교 | 막대그래프 | 그룹 막대그래프 | 히트맵 등 |
| 추세 | 선 그래프 | 복수 선 그래프 | 상황에 따라 선택 |
| 구성비 | 파이차트, 도넛차트 | 누적 막대그래프 | 상황에 따라 선택 |

이 표는 절대적인 규칙이라기보다 **차트를 선택할 때 사용할 수 있는 출발점**으로 이해하면 됨.

<br>

> ## **2-5 ) 목적별 대표 차트**

### 분포

```text
선수 체중은 어느 구간에 많이 분포하는가?
        ↓
히스토그램
```

### 관계

```text
훈련시간이 길수록 경기점수가 높은가?
        ↓
산점도
```

### 비교

```text
포지션별 평균 득점은 어떻게 다른가?
        ↓
막대그래프
```

### 추세

```text
월별 경기력은 어떻게 변하는가?
        ↓
선 그래프
```

### 구성비

```text
전체 선수 중 종목별 비율은?
        ↓
구성비를 표현할 수 있는 차트 검토
```

# **3. 흔한 시각화 오류**

잘못된 차트를 사용하거나 축을 부적절하게 설정하면 데이터 자체는 정확해도 **보는 사람이 실제보다 과장되거나 왜곡된 인상을 받을 수 있음.**

> ## **3-1 ) 막대그래프의 Y축을 중간에서 시작하는 문제**

두 팀의 평균 점수가 다음과 같다고 가정함.

```text
A팀 → 98점
B팀 → 100점
```

실제 차이는.

```text
100 - 98
= 2점
```

임.

그런데 막대그래프 Y축을 `90`부터 시작하면 두 값의 차이가 실제보다 매우 크게 보일 수 있음.

[ python : code ] "Y축을 90부터 시작하여 차이가 과장될 수 있는 막대그래프"

```python
import matplotlib.pyplot as plt

teams = ["A", "B"]
scores = [98, 100]

plt.bar(
    teams,
    scores
)

plt.ylim(
    90,
    101
)

plt.xlabel("Team")
plt.ylabel("Score")
plt.title("Average Score by Team")

plt.show()
```

[ Result ]

```text
A팀 → 98점
B팀 → 100점

실제 차이 → 2점

하지만 Y축이 90부터 시작하므로
막대의 높이 차이가 상대적으로 크게 보이는 그래프가 출력됨.
```

막대그래프는 **막대의 길이 자체가 값의 크기를 표현**하므로 기준선을 자르면 차이를 과장할 수 있음.

<br>

> ## **3-2 ) 0을 기준으로 한 막대그래프**

같은 데이터를 Y축 `0`부터 표현하면 두 값의 차이를 실제 크기에 더 가깝게 볼 수 있음.

[ python : code ] "Y축을 0부터 시작하여 두 팀 평균점수 비교"

```python
import matplotlib.pyplot as plt

teams = ["A", "B"]
scores = [98, 100]

plt.bar(
    teams,
    scores
)

plt.ylim(
    0,
    110
)

plt.xlabel("Team")
plt.ylabel("Score")
plt.title("Average Score by Team")

plt.show()
```

[ Result ]

```text
A팀 → 98점
B팀 → 100점

두 막대의 차이가 전체 크기에 비해
상대적으로 작게 보이는 그래프가 출력됨.
```

<br>

> ## **3-3 ) 색상 과용**

색상을 너무 많이 사용하면 중요한 정보보다 색상 자체에 시선이 분산될 수 있음.

예를 들어 5개의 막대를 모두 서로 다른 색으로 표현하면.

```text
빨강
파랑
초록
노랑
보라
```

중 어떤 값이 중요한지 명확하지 않을 수 있음.

색상은 장식보다는.

```text
특정 그룹 강조
위험 여부 구분
카테고리 구분
```

처럼 **의미가 있을 때 사용하는 것이 좋음.**

<br>

> ## **3-4 ) 시각화 오류의 핵심**

```text
정확한 데이터
      +
잘못된 표현
      ↓
왜곡된 인상 가능
```

따라서 시각화에서는.

```text
데이터 값
축 범위
차트 종류
색상
강조 방식
```

을 함께 고려해야 함.

# **4. 시각화 선택 전체 흐름**

> ## **4-1 ) 차트 선택 순서**

```text
[분석 질문]
      ↓
무엇을 알고 싶은가?
      ↓
사용할 변수 선택
      ↓
변수는 몇 개인가?
      │
      ├── 1개 → 단변량
      ├── 2개 → 이변량
      └── 3개 이상 → 다변량
      ↓
전달 목적은?
      │
      ├── 분포
      ├── 관계
      ├── 비교
      ├── 추세
      └── 구성비
      ↓
후보 차트 선택
      ↓
축·색상·레이블 확인
      ↓
메시지가 정확하게 전달되는지 검토
```

즉 차트 선택의 시작점은.

```text
"어떤 그래프를 그릴까?"
```

가 아니라.

```text
"무엇을 보여주고 싶은가?"
```

임.

# **5. Advanced 추가 학습**

> ## **5-1 ) 막대그래프와 선 그래프의 Y축 기준**

막대그래프는 막대 길이가 값의 크기 자체를 표현하므로 **0 기준선이 특히 중요함.**

반면 선 그래프는 절대적인 길이보다 값의 변화와 추세를 표현하는 경우가 많아 모든 상황에서 반드시 Y축을 `0`부터 시작해야 하는 것은 아님.

```text
막대그래프
→ 0 기준선 중요

선 그래프
→ 분석 목적과 변화 폭을 고려하여 축 범위 결정
```

<br>

> ## **5-2 ) 시각화 전에 집계 단위를 확인**

그래프를 그리기 전에 한 Row가 무엇을 의미하는지 확인하는 것이 중요함.

예를 들어.

```text
한 Row = 선수 1명
```

인지.

```text
한 Row = 선수의 경기 1회
```

인지에 따라 같은 데이터라도 집계와 그래프의 의미가 달라질 수 있음.

<br>

> ## **5-3 ) 파이차트는 구성비 표현 목적에 맞는지 먼저 확인**

파이차트는 전체에서 각 항목이 차지하는 비율을 보여주는 구성비 표현에 사용할 수 있음.

하지만 항목이 많거나 비율이 비슷하면 각 조각의 크기를 정확히 비교하기 어려움.

예를 들어.

```text
A → 21%
B → 20%
C → 19%
D → 18%
E → 22%
```

처럼 값이 비슷한 경우에는 파이 조각의 각도를 비교하는 것보다 막대그래프가 더 정확한 비교에 유리할 수 있음.

따라서.

```text
구성비
→ 무조건 파이차트
```

가 아니라.

```text
구성비인가?
      ↓
항목 수는 적은가?
      ↓
정확한 비교가 중요한가?
      ↓
파이차트 또는 막대그래프 선택
```

처럼 판단하는 것이 좋음.

# **6. 핵심정리**

1. 데이터 시각화는 데이터를 그래프나 차트로 표현하여 **패턴과 정보를 사람이 직관적으로 이해하도록 돕는 작업**임.

2. 시각화의 핵심 목적은 다음 세 가지임.

| 목적 | 의미 |
| --- | --- |
| 패턴 발견 | 데이터 속 특징·추세·이상한 움직임 탐색 |
| 의사결정 지원 | 분석 결과를 행동 선택의 근거로 사용 |
| 효과적 커뮤니케이션 | 핵심 메시지를 이해관계자에게 전달 |

3. 같은 데이터라도 시각화 목적에 따라 적합한 그래프와 표현 방법이 달라질 수 있음.

4. 차트를 선택할 때 가장 먼저 확인할 질문은 다음 두 가지임.

```text
Q1. 변수가 몇 개인가?

Q2. 무엇을 보여주고 싶은가?
```

5. 변수 수는 다음처럼 구분함.

| 구분 | 변수 수 |
| --- | ---: |
| 단변량 | 1개 |
| 이변량 | 2개 |
| 다변량 | 3개 이상 |

6. 주요 시각화 목적은 다음과 같음.

```text
분포
관계
비교
추세
구성비
```

7. 대표적인 차트 선택 예시는 다음과 같음.

| 질문 | 대표 차트 |
| --- | --- |
| 값이 어떻게 분포하는가? | 히스토그램 |
| 두 수치형 변수는 어떤 관계인가? | 산점도 |
| 그룹별 값은 어떻게 다른가? | 막대그래프 |
| 시간에 따라 어떻게 변하는가? | 선 그래프 |
| 전체에서 각 항목의 비율은? | 구성비 차트 검토 |

8. 변수의 개수만 보고 차트를 결정하면 안 되며 **변수 수와 전달 목적을 함께 고려해야 함.**

9. 막대그래프에서 Y축을 중간부터 시작하면 실제 차이를 과장할 수 있으므로 기준선 설정에 주의해야 함.

10. 막대그래프는 막대 길이로 값을 비교하므로 일반적으로 `0` 기준선이 중요하지만, 선 그래프는 추세 표현 목적에 따라 반드시 `0`부터 시작해야 하는 것은 아님.

11. 색상은 장식 목적으로 과도하게 사용하는 것보다 **특정 의미를 전달하거나 핵심 데이터를 강조할 때 사용하는 것이 효과적임.**

12. 파이차트는 구성비를 표현할 수 있지만 항목이 많거나 비율이 비슷할 경우 정확한 비교가 어려워 막대그래프가 더 적합할 수 있음.

13. 정확한 데이터라도 축이나 차트 형태가 부적절하면 보는 사람이 왜곡된 인상을 받을 수 있음.

14. 차트 선택의 전체 흐름은 다음과 같음.

```text
분석 질문 설정
      ↓
변수 선택
      ↓
변수 개수 확인
      ↓
전달 목적 확인
      ↓
적절한 차트 선택
      ↓
축·색상·레이블 검토
      ↓
메시지가 정확한지 확인
```

15. 시각화에서 가장 중요한 것은 많은 종류의 그래프를 외우는 것이 아니라 **"이 그래프로 무엇을 발견하고, 비교하고, 전달하려는가?"를 먼저 명확히 하는 것**임.
