# **1. 공통 실습 데이터**

이번 강의에서는 막대그래프, 수평 막대그래프, 그룹 막대그래프의 차이를 명확하게 비교하기 위해 **동일한 선수 데이터를 계속 사용**함.

앞 강의의 관계 분석에서 사용했던 선수 데이터를 비교 차트에 맞게 `team`, `sport`, `performance_score` 중심으로 구성함.

[ python : code ] "비교 차트에서 공통으로 사용할 선수 데이터 생성"

```python
import pandas as pd

athletes = pd.DataFrame({
    "athlete": [
        "서윤", "도현", "하린", "민재",
        "유나", "태민", "시우", "다은",

    ],
    "team": [
        "A", "A", "A", "A", "A", "A",

    ],
    "sport": [
        "육상", "육상",
        "수영", "수영",
        "사이클", "사이클",
        "육상", "육상",
        "수영", "수영",
        "사이클", "사이클"
    ],
    "performance_score": [
        88, 92,
        84, 86,
        90, 94,
        82, 85,

```

```text
        ↓
그룹 막대그래프
```

# **2. 막대그래프(Bar Plot)**

막대그래프는 **서로 다른 범주의 값 크기를 비교할 때 사용하는 차트**임.

예를 들어.

```text
육상 평균 경기력
수영 평균 경기력
사이클 평균 경기력
```

처럼 각 범주의 값을 비교하는 상황에 적합함.

> ## **2-1 ) 종목별 평균 경기력 계산**

먼저 종목별 `performance_score`의 평균을 계산함.

[ python : code ] "종목별 평균 경기력 점수 계산"

```python
sport_score = (
    athletes
    .groupby("sport")[
        "performance_score"
    ]
    .mean()
)

print(sport_score)
```

[ Result ]

```text
sport
사이클    90.00
수영     83.25
육상     86.75
Name: performance_score, dtype: float64
```

계산 과정.

```text
육상
= (88 + 92 + 82 + 85) / 4
= 347 / 4
= 86.75

수영
= (84 + 86 + 80 + 83) / 4
= 333 / 4
= 83.25

사이클
= (90 + 94 + 87 + 89) / 4
= 360 / 4
= 90.00
```

<br>

> ## **2-2 ) plt.bar()로 종목 비교**

[ python : code ] "종목별 평균 경기력을 막대그래프로 비교"

```python
import matplotlib.pyplot as plt

plt.bar(
    sport_score.index,
    sport_score.values
)

plt.xlabel("Sport")
plt.ylabel("Average Performance Score")
plt.title("Average Performance Score by Sport")

plt.show()
```

[ Result ]

```text
사이클 → 90.00
수영   → 83.25
육상   → 86.75

위 값을 높이로 하는
3개의 막대가 출력됨.

가장 높은 평균 경기력
→ 사이클 90.00점
```

막대그래프의 기본 구조.

```text
X축
→ 서로 다른 범주

Y축
→ 비교하려는 수치

막대 높이
→ 각 범주의 값
```

<br>

> ## **2-3 ) 막대그래프와 히스토그램 차이**

막대그래프와 히스토그램은 모두 막대 모양을 사용하지만 목적과 X축의 의미가 다름.

| 구분 | 막대그래프 | 히스토그램 |
| --- | --- | --- |
| 주요 데이터 | 범주형 + 수치값 | 연속형 수치 데이터 |
| X축 | 서로 다른 범주 | 연속적인 수치 구간 |
| 목적 | 범주 간 값 비교 | 데이터 분포 확인 |
| 대표 질문 | 어떤 종목의 평균이 높은가? | 기록이 어느 구간에 몰려 있는가? |
| 구간 개념 | 없음 | Bin 존재 |

앞 강의의 `record_min` 히스토그램과 연결하면.

```text
5km 기록이
20~30분 구간에 몇 명 있는가?
→ 히스토그램

육상·수영·사이클 중
평균 경기력이 높은 종목은?
→ 막대그래프
```

으로 구분함.

막대 사이에 간격이 보이는지 여부는 일반적인 시각적 특징일 뿐, **두 차트를 구분하는 핵심 기준은 데이터의 의미와 목적**임.

# **3. 수직·수평 막대와 정렬**

비교 목적의 차트에서는 단순히 막대를 그리는 것보다 **어떤 순서로 배치할 것인지**도 중요함.

> ## **3-1 ) 값이 높은 순서대로 정렬**

종목별 평균 경기력을 높은 순서대로 정렬함.

[ python : code ] "종목별 평균 경기력을 내림차순으로 정렬"

```python
sport_score_desc = (
    sport_score
    .sort_values(
        ascending=False
    )
)

print(sport_score_desc)
```

[ Result ]

```text
sport
사이클    90.00
육상     86.75
수영     83.25
Name: performance_score, dtype: float64
```

따라서 순위가 바로 보임.

```text
1위 사이클 → 90.00
2위 육상   → 86.75
3위 수영   → 83.25
```

<br>

> ## **3-2 ) 정렬된 수직 막대그래프**

[ python : code ] "평균 경기력이 높은 종목부터 수직 막대그래프로 표현"

```python
plt.bar(
    sport_score_desc.index,
    sport_score_desc.values
)

plt.xlabel("Sport")
plt.ylabel("Average Performance Score")
plt.title("Average Performance Score by Sport")

plt.show()
```

[ Result ]

```text
왼쪽부터

사이클 → 90.00
육상   → 86.75
수영   → 83.25

순서로 막대가 출력됨.
```

순위 비교가 목적이라면 값 기준 정렬이 패턴을 빠르게 읽는 데 도움이 됨.

다만 모든 막대그래프를 반드시 값 기준으로 정렬해야 하는 것은 아님.

예를 들어.

```text
월요일 → 화요일 → 수요일
1월 → 2월 → 3월
초급 → 중급 → 고급
```

처럼 **자연스러운 순서가 있는 범주**는 그 순서를 유지하는 것이 더 적절함.

<br>

> ## **3-3 ) 수직 막대와 수평 막대**

| 구분 | 수직 막대 | 수평 막대 |
| --- | --- | --- |
| 함수 | `plt.bar()` | `plt.barh()` |
| 범주 위치 | X축 | Y축 |
| 적합 상황 | 범주명이 짧음 | 범주명이 길음 |
| 순위 비교 | 가능 | 특히 읽기 편리 |

범주 이름이 길다면 수평 막대를 사용하면 라벨이 겹치는 문제를 줄일 수 있음.

<br>

> ## **3-4 ) 수평 막대그래프**

수평 막대에서 큰 값을 위쪽에 배치하려면 작은 값부터 정렬할 수 있음.

[ python : code ] "종목별 평균 경기력을 수평 막대그래프로 비교"

```python
sport_score_asc = (
    sport_score
    .sort_values(
        ascending=True
    )
)

plt.barh(
    sport_score_asc.index,
    sport_score_asc.values
)

plt.xlabel("Average Performance Score")
plt.ylabel("Sport")
plt.title("Average Performance Score by Sport")

plt.show()
```

[ Result ]

```text
아래쪽
수영   → 83.25

중간
육상   → 86.75

위쪽
사이클 → 90.00
```

Matplotlib의 일반적인 수평 막대에서는 첫 번째 범주가 아래에서 시작하므로 오름차순으로 정렬하면 가장 큰 값이 위쪽에 나타남.

# **4. 그룹 막대그래프(Grouped Bar Plot)**

단일 막대그래프는 하나의 범주에 하나의 대표값을 표시하기 좋음.

하지만 하나의 종목 안에서.

```text
A팀
vs
B팀
```

처럼 추가 그룹까지 함께 비교하려면 그룹 막대그래프가 유용함.

Seaborn에서는 `sns.barplot()`의 `hue`를 사용할 수 있음.

> ## **4-1 ) 종목별 A팀·B팀 평균 경기력**

공통 선수 데이터에서 종목과 팀별 평균 경기력을 계산하면 다음과 같음.

[ python : code ] "종목·팀별 평균 경기력 계산"

```python
team_sport_score = athletes.groupby(["sport", "team"])["performance_score"].mean()


print(team_sport_score)
```

[ Result ]

```text
sport  team
사이클    A       92.0
       B       88.0
수영     A       85.0
       B       81.5
육상     A       90.0
       B       83.5
Name: performance_score, dtype: float64
```

계산.

```text
육상 A팀
= (88 + 92) / 2
= 90.0

육상 B팀
= (82 + 85) / 2
= 83.5

수영 A팀
= (84 + 86) / 2
= 85.0

수영 B팀
= (80 + 83) / 2
= 81.5

사이클 A팀
= (90 + 94) / 2
= 92.0

사이클 B팀
= (87 + 89) / 2
= 88.0
```

<br>

> ## **4-2 ) sns.barplot()과 hue**

[ python : code ] "종목별 A팀과 B팀의 평균 경기력을 그룹 막대그래프로 비교"

```python
import seaborn as sns
import matplotlib.pyplot as plt

sns.barplot(
    data=athletes,
    x="sport",
    y="performance_score",
    hue="team",
    errorbar=None
)

plt.xlabel("Sport")
plt.ylabel("Average Performance Score")
plt.title("Performance Score by Sport and Team")

plt.show()
```

[ Result ]

```text
육상
A팀 → 90.0
B팀 → 83.5

수영
A팀 → 85.0
B팀 → 81.5

사이클
A팀 → 92.0
B팀 → 88.0

각 종목 안에서
A팀과 B팀의 막대가 나란히 표시됨.
```

`sns.barplot()`의 기본 집계는 평균임.

따라서 원본 데이터 여러 Row를 사용하면 각 `x`와 `hue` 조합의 `y` 평균을 계산하여 막대 높이로 표현함.

```text
x="sport"
→ 육상 / 수영 / 사이클

y="performance_score"
→ 평균을 계산할 수치

hue="team"
→ A팀 / B팀으로 막대 분리
```

<br>

> ## **4-3 ) 그룹 막대그래프의 장점**

단일 막대그래프.

```text
육상 전체 평균
수영 전체 평균
사이클 전체 평균
```

만 비교함.

그룹 막대그래프.

```text
육상
├─ A팀
└─ B팀

수영
├─ A팀
└─ B팀

사이클
├─ A팀
└─ B팀
```

처럼 두 개의 범주형 변수를 동시에 비교할 수 있음.

<br>

> ## **4-4 ) 그룹이 너무 많으면 생기는 문제**

`hue` 그룹이 많아지면 막대 수가 급격히 증가함.

```text
3개 종목
×
2개 팀
= 6개 막대
```

정도는 비교하기 쉬움.

하지만.

```text
10개 종목
×
8개 팀
= 80개 막대
```

라면 차트가 복잡해져 비교하기 어려워짐.

이 경우.

```text
주요 그룹만 선택
Facet 형태로 분리
다른 차트 검토
```

등을 고려할 수 있음.

# **5. sns.barplot()의 에러바**

`sns.barplot()`은 단순히 막대만 그리는 것이 아니라 원본 관측값에서 통계량을 계산하여 표시하는 함수임.

기본적으로 막대는 평균을 나타내며 Seaborn 버전에 따라 기본 설정으로 불확실성 구간이 함께 표시될 수 있음.

> ## **5-1 ) 에러바의 의미**

에러바는 막대의 평균값 주변에 **추정의 불확실성**을 표현하는 데 사용할 수 있음.

예.

```python
sns.barplot(
    data=athletes,
    x="sport",
    y="performance_score",
    hue="team",
    errorbar=("ci", 95)
)
```

는 평균 주변의 95% 신뢰구간을 표현하도록 요청하는 형태임.

하지만 에러바를 보고 단순히.

```text
겹침 → 유의하지 않음
안 겹침 → 통계적으로 유의함
```

이라고 판단해서는 안 됨.

**에러바는 통계적 유의성을 직접 판정하는 검정 결과가 아님.**

통계적 유의성을 판단하려면 분석 목적에 맞는 별도의 통계 검정이 필요함.

<br>

> ## **5-2 ) 평균 막대만 비교**

이번 예제에서는 차트 구조 자체를 배우는 것이 목적이므로.

```python
errorbar=None
```

을 사용함.

```python
sns.barplot(
    data=athletes,
    x="sport",
    y="performance_score",
    hue="team",
    errorbar=None
)
```

따라서.

```text
막대 높이
→ 각 종목·팀의 평균 경기력
```

만 비교함.

# **6. 그룹 막대와 누적 막대의 차이**

그룹 막대와 누적 막대는 비슷해 보이지만 목적이 다름.

> ## **6-1 ) 그룹 막대**

```text
A팀 █████
B팀 ████
```

처럼 막대를 같은 기준선에서 나란히 시작하므로 **각 그룹의 크기를 직접 비교**하기 쉬움.

적합한 질문.

```text
육상에서 A팀과 B팀 중
어느 팀의 평균 경기력이 높은가?
```

<br>

> ## **6-2 ) 누적 막대**

누적 막대는 여러 값을 하나의 막대 안에 쌓음.

```text
┌──────────────┐
│ B            │
├──────────────┤
│ A            │
└──────────────┘
```

전체 합과 구성비를 함께 표현하는 데 유용함.

다만 아래쪽 그룹을 제외하면 시작 기준선이 달라지므로 **개별 그룹의 정확한 크기 비교는 그룹 막대보다 어려울 수 있음.**

따라서.

```text
A vs B 직접 비교
→ 그룹 막대

전체 합 + 내부 구성
→ 누적 막대
```

처럼 목적에 따라 선택함.

# **7. 비교 차트 선택 전체 흐름**

> ## **7-1 ) 어떤 막대그래프를 선택할까?**

```text
[비교 질문]
      ↓
범주 간 값을 비교하는가?
      ↓
Yes
      ↓
범주 이름 길이 확인
      │
 ┌────┴────┐
 ↓         ↓
짧음       김
 ↓         ↓
bar()     barh()
      │
      ↓
추가 그룹이 있는가?
      │
 ┌────┴────┐
 ↓         ↓
No        Yes
 ↓         ↓
단일 막대  hue 사용
           ↓
      그룹 막대
```

그리고 마지막으로.

```text
값 순위가 중요한가?
→ 정렬 검토

자연스러운 순서가 있는가?
→ 원래 순서 유지
```

를 판단함.

# **8. Advanced 추가 학습**

> ## **8-1 ) 막대그래프의 Y축은 0 기준이 중요**

막대의 길이가 값 자체를 나타내므로 Y축을 중간에서 자르면 차이가 실제보다 크게 보일 수 있음.

예.

```text
A팀 = 88
B팀 = 90
```

인데 Y축을 `85`부터 시작하면 두 막대의 차이가 과장될 수 있음.

따라서 일반적인 막대그래프에서는 **0 기준선을 사용하는 것이 중요함.**

<br>

> ## **8-2 ) 평균을 막대로 표현할 때 원본 분포도 생각하기**

다음 두 그룹이 모두 평균 `80`이라고 해도.

```text
A
79, 80, 81

B
50, 80, 110
```

분포는 매우 다름.

따라서 평균 막대만 보면 데이터의 퍼짐이나 이상치를 놓칠 수 있음.

EDA 단계에서는 필요하면.

```text
Bar Plot
+
Box Plot
+
원본 분포
```

를 함께 확인하는 것이 좋음.

<br>

> ## **8-3 ) 정렬은 무조건 내림차순이 아님**

순위 비교에서는 내림차순이 유용하지만 시간이나 단계처럼 자연스러운 순서가 존재한다면 정렬하면 의미가 깨질 수 있음.

```text
잘못된 예

월별 데이터
12월 → 3월 → 7월 → 1월
```

값 기준으로 정렬하면 시간 흐름을 읽기 어려움.

따라서.

```text
순위 비교
→ 값 기준 정렬

시간·단계·등급
→ 의미 있는 원래 순서 유지
```

가 기본 원칙임.

<br>

> ## **8-4 ) barplot()은 원본 데이터와 집계 데이터의 의미가 다름**

원본 데이터를 사용하면.

```python
sns.barplot(
    data=athletes,
    x="sport",
    y="performance_score"
)
```

가 각 종목의 평균을 내부적으로 계산함.

이미 평균을 계산한 데이터를 사용한다면.

```text
값이 이미 어떤 통계량인지
```

명확히 알고 사용해야 함.

그래프 제목과 Y축에도.

```text
Performance Score
```

보다.

```text
Average Performance Score
```

처럼 어떤 값을 표현하는지 명확하게 표시하는 것이 좋음.
