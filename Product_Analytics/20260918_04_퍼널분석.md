# 04. 퍼널 분석(Funnel Analysis) - 전환율, 이탈률 측정원리

<br>

---


# **1. 퍼널 분석이란?**

> ## **1-1 ) 최종 복귀 선수 수만 보면 어디에서 문제가 발생했는지 알기 어렵다**

스포츠의학센터에서 무릎 부상을 입은 선수를 대상으로 재활 프로그램을 운영한다고 생각해보자.

선수는 부상 이후 다음과 같은 과정을 거칠 수 있다.

```text
초기 스포츠의학 평가
200명
    ↓
재활 프로그램 시작
170명
    ↓
4주 재활 지속
130명
    ↓
기능 평가 실시
100명
    ↓
Return to Sport 평가 완료
70명
```

처음 스포츠의학 평가를 받은 선수는 `200명`이지만 최종적으로 복귀 평가까지 완료한 선수는 `70명`이다.

이 데이터를 통해

```text
많은 선수가
최종 복귀 평가까지
이어지지 않았다.
```

는 사실은 알 수 있다.

하지만 실제 재활 프로그램을 개선하려면 조금 더 구체적인 질문이 필요하다.

> **선수들은 어느 단계에서 가장 많이 다음 과정으로 이어지지 않았을까?**

> **어느 구간을 우선적으로 살펴봐야 할까?**

선수의 재활 과정을 단계별로 나누고 각 단계에서 다음 단계로 얼마나 이동하는지 살펴보면 문제를 더 구체적으로 확인할 수 있다.

예를 들어 재활 프로그램을 시작한 선수는 `170명`이고 4주 동안 재활을 지속한 선수는 `130명`이다.

```text
재활 프로그램 시작
170명
    ↓
4주 재활 지속
130명

130 / 170 × 100
≈ 76.5%
```

즉, 재활 프로그램을 시작한 선수 중 약 `76.5%`가 4주 재활까지 이어졌다.

이를 **전환율(Conversion Rate)** 이라고 볼 수 있다.

반대로 다음 단계로 이어지지 않은 비율은

```text
100% - 76.5%

= 23.5%
```

이다.

이를 **이탈률(Drop-off Rate)** 이라고 볼 수 있다.

이러한 계산을 각 구간에 적용하면 선수의 재활 과정에서 **어느 단계에서 다음 과정으로 잘 이어지지 않는지** 비교할 수 있다.

```text
초기 스포츠의학 평가
        ↓
재활 프로그램 시작
        ↓
4주 재활 지속
        ↓
기능 평가
        ↓
Return to Sport 평가

각 구간의
전환율과 이탈률 확인
        ↓
이탈이 집중되는 구간 탐색
```

이처럼 특정 목표 행동에 도달하기까지의 과정을 여러 단계로 나누고 **각 단계의 대상자 수와 전환·이탈을 분석하는 방법을 퍼널 분석(Funnel Analysis)** 이라고 한다.

<br>

> ## **1-2 ) 왜 Funnel이라고 부를까?**

일반적으로 단계가 진행될수록 다음 단계까지 도달하는 선수의 수가 줄어든다.

```text
초기 평가          200명
████████████████████

재활 시작          170명
 █████████████████

4주 재활 지속      130명
   █████████████

기능 평가          100명
     ██████████

복귀 평가 완료      70명
       ███████
```

위에서 아래로 갈수록 대상자 수가 줄어드는 형태가 깔때기와 비슷하기 때문에 `Funnel`이라는 표현을 사용한다.

<br>

> ## **1-3 ) 퍼널 분석의 목적**

퍼널 분석의 목적은 단순히

```text
최종적으로 몇 명이 남았는가?
```

를 확인하는 것이 아니다.

더 중요한 질문은

```text
어느 단계에서
다음 단계로 이어지지 않는가?
```

이다.

예를 들어

```text
초기 평가
→ 재활 시작
전환율 높음

재활 시작
→ 4주 재활 지속
전환율 낮음
```

이라면 선수 모집보다 **재활을 지속하는 과정**을 먼저 살펴볼 수 있다.

즉,

```text
최종 결과 확인
        ↓
단계별 행동 정의
        ↓
전환율 / 이탈률 계산
        ↓
문제 구간 발견
        ↓
추가 분석
```

으로 연결된다.

# **2. 퍼널은 분석 목적에 맞게 구성한다**

> ## **2-1 ) 하나의 스포츠의학 프로그램에도 여러 퍼널이 존재할 수 있다**

한 스포츠의학센터에서 ACL 재활 프로그램을 운영한다고 하자.

분석 목적이

```text
ACL 손상 선수가
초기 평가 이후
재활 프로그램을 시작하는 과정
```

이라면 다음과 같이 구성할 수 있다.

```text
초기 진료
    ↓
MRI / 추가 평가
    ↓
재활 상담
    ↓
재활 프로그램 등록
```

반면 분석 목적이

```text
재활을 시작한 선수가
복귀 평가까지 완료하는 과정
```

이라면 퍼널은 달라진다.

```text
재활 프로그램 시작
    ↓
4주 재활 지속
    ↓
근력 평가
    ↓
기능적 움직임 평가
    ↓
Return to Sport 평가 완료
```

따라서

> **하나의 서비스나 프로그램에 하나의 퍼널만 존재하는 것은 아니다.**

분석하려는 문제와 최종 목표 행동에 따라 퍼널의 시작점과 종료점이 달라진다.

<br>

> ## **2-2 ) 목표 행동을 먼저 정의한다**

퍼널을 만들기 전에 가장 먼저 결정해야 하는 것은

```text
이번 분석에서
최종적으로 확인하려는 행동은 무엇인가?
```

이다.

예를 들어

```text
목표
→ 발목 염좌 선수의
   재활 프로그램 완료
```

라면 최종 목표 행동은

```text
재활 프로그램 완료
```

이다.

퍼널을 다음처럼 만들 수 있다.

```text
초기 진료
    ↓
재활 프로그램 등록
    ↓
첫 재활 세션 참석
    ↓
4주 재활 지속
    ↓
최종 기능 평가
    ↓
재활 완료
```

<br>

> ## **2-3 ) 퍼널 단계를 너무 크게 잡으면 문제 위치를 찾기 어렵다**

다음처럼 구성했다고 하자.

```text
부상 진료
    ↓
재활 완료
```

이 경우 재활 완료율이 낮다는 것은 알 수 있지만 **어디에서 문제가 나타나는지 알기 어렵다.**

```text
진료 후 등록을 안 했는가?

등록은 했지만 첫 재활에 오지 않았는가?

초반에는 참여했지만
중간에 중단했는가?

기능 평가까지 도달하지 않았는가?
```

를 구분할 수 없다.

따라서 주요 행동을 적절한 수준으로 나눈다.

<br>

> ## **2-4 ) 반대로 지나치게 세분화해도 좋지 않다**

다음처럼 모든 작은 행동을 퍼널 단계로 넣는다고 생각해보자.

```text
센터 방문
    ↓
접수
    ↓
문진표 작성
    ↓
대기실 입장
    ↓
진료실 입장
    ↓
신장 측정
    ↓
체중 측정
    ↓
문진 확인
    ↓
기능 검사
    ↓
상담
    ↓
...
```

분석 목적과 관계없는 행동까지 지나치게 포함하면 전체적인 흐름을 파악하기 어렵다.

따라서 처음에는

> **목표 행동에 도달하는 데 의미가 있는 주요 행동을 중심으로 퍼널을 구성한다.**

그리고 문제가 발견된 구간은 이후 더 세분화한다.

```text
목표 행동 정의
        ↓
주요 단계 정의
        ↓
퍼널 분석
        ↓
문제 구간 발견
        ↓
해당 구간 세분화
```

# **3. AARRR과 Funnel의 차이**

> ## **3-1 ) AARRR은 큰 관점, Funnel은 세부 흐름**

앞에서 배운 AARRR 역시 행동을 단계별로 나누는 방법이었다.

하지만 두 방법의 분석 범위에는 차이가 있다.

| 구분 | AARRR | Funnel |
| --- | --- | --- |
| 목적 | 전체 사용자 행동을 큰 관점에서 구조화 | 특정 목표까지의 세부 흐름 분석 |
| 질문 | 어느 행동 영역에 문제가 있는가? | 구체적으로 어느 구간에서 이탈하는가? |
| 범위 | 넓음 | 상대적으로 좁고 구체적 |
| 예시 | 획득 → 활성화 → 유지 → 수익 → 추천 | 초기 평가 → 재활 시작 → 기능 평가 → 복귀 평가 |

예를 들어 스포츠의학 프로그램에서

```text
Retention

재활 프로그램을 시작한 선수가
지속적으로 재활에 참여하지 않는다.
```

는 문제가 발견되었다고 하자.

이때 Retention 과정을 더 세부적인 퍼널로 만들 수 있다.

```text
재활 등록
    ↓
첫 재활 세션 참석
    ↓
2주 지속
    ↓
4주 지속
    ↓
8주 지속
```

즉,

```text
AARRR
→ 어떤 행동 영역을 볼 것인가?

Funnel
→ 그 행동 영역 안에서
   어디에서 이탈하는가?
```

로 이해할 수 있다.

# **4. 전환율 Conversion Rate**

> ## **4-1 ) 전환율 계산**

전환율은 **현재 단계에 도달한 대상자 중 다음 단계까지 이동한 대상자의 비율**이다.

```text
전환율

= 다음 단계 선수 수
  / 현재 단계 선수 수
  × 100
```

예를 들어 발목 염좌 재활 퍼널이 다음과 같다고 하자.

```text
초기 평가
200명
    ↓
재활 등록
160명
    ↓
첫 세션 참석
144명
    ↓
4주 재활 지속
108명
    ↓
최종 평가
81명
```

초기 평가 → 재활 등록의 전환율은

```text
160 / 200 × 100

= 80%
```

이다.

즉, 초기 평가를 받은 선수의 `80%`가 실제 재활 프로그램 등록으로 이어졌다.

<br>

> ## **4-2 ) 구간별 전환율 계산**

각 구간을 계산해보자.

```text
초기 평가 → 재활 등록

160 / 200 × 100
= 80%
```

```text
재활 등록 → 첫 세션 참석

144 / 160 × 100
= 90%
```

```text
첫 세션 참석 → 4주 지속

108 / 144 × 100
= 75%
```

```text
4주 지속 → 최종 평가

81 / 108 × 100
= 75%
```

표로 정리하면 다음과 같다.

| 구간 | 계산 | 전환율 |
| --- | --- | ---: |
| 초기 평가 → 재활 등록 | 160 / 200 | 80% |
| 재활 등록 → 첫 세션 참석 | 144 / 160 | 90% |
| 첫 세션 참석 → 4주 지속 | 108 / 144 | 75% |
| 4주 지속 → 최종 평가 | 81 / 108 | 75% |

# **5. 이탈률 Drop-off Rate**

> ## **5-1 ) 이탈률 계산**

이탈률은 **현재 단계에 도달했지만 다음 단계까지 이어지지 않은 대상자의 비율**이다.

즉, `이탈률 = 100% - 전환율`로 나타낼 수 있다.

같은 구간에서

```text
전환율 + 이탈률
= 100%
```

이므로

```text
이탈률
= 100% - 전환율
```

로 계산할 수 있다.

예를 들어

```text
첫 재활 세션 참석
144명
        ↓
4주 재활 지속
108명
```

이면 전환율은

```text
108 / 144 × 100
= 75%
```

이므로 이탈률은

```text
100% - 75%

= 25%
```

이다.

즉, 첫 재활에 참여한 선수 중 `25%`는 4주 시점까지 이어지지 않았다.

<br>

> ## **5-2 ) 구간별 전환율과 이탈률**

| 구간 | 전환율 | 이탈률 |
| --- | ---: | ---: |
| 초기 평가 → 재활 등록 | 80% | 20% |
| 재활 등록 → 첫 세션 참석 | 90% | 10% |
| 첫 세션 참석 → 4주 지속 | 75% | 25% |
| 4주 지속 → 최종 평가 | 75% | 25% |

이제 단순한 선수 수보다

```text
어느 과정에서
다음 단계로 이어지는 비율이 낮은가?
```

를 비교할 수 있다.

# **6. 전체 전환율과 구간별 전환율**

> ## **6-1 ) 전체 전환율**

전체 전환율은 **퍼널의 최초 단계에 들어온 대상자 중 최종 목표 행동까지 도달한 대상자의 비율**이다.

앞의 발목 재활 퍼널에서는

```text
초기 평가
200명

        ↓

최종 기능 평가
81명
```

이므로

```text
전체 전환율

= 81 / 200 × 100

= 40.5%
```

이다.

즉, 초기 평가를 받은 선수 중 `40.5%`가 최종 기능 평가까지 도달했다.

<br>

> ## **6-2 ) 전체 전환율과 구간별 전환율은 질문이 다르다**

```text
전체 전환율

"처음 시작한 선수 중
최종 목표까지 얼마나 도달했는가?"
```

반면

```text
구간별 전환율

"어느 행동 사이에서
다음 단계로 잘 이어지지 않는가?"
```

를 보여준다.

예를 들어

```text
전체 전환율
= 40.5%
```

만 보면 최종적으로 많은 선수가 이탈했다는 것은 알 수 있다.

하지만 이탈이

```text
초기 상담에서 발생했는지

재활 초기에 발생했는지

중간 재활에서 발생했는지

최종 평가 전에 발생했는지
```

알 수 없다.

따라서 퍼널에서는 **전체 전환율과 구간별 전환율을 함께 확인하는 것이 중요하다.**

<br>

> ## **6-3 ) 전환율을 말할 때 기준을 명확하게 표현한다**

다음 두 지표를 생각해보자.

```text
초기 평가 선수 중
재활 완료 선수 비율
```

과

```text
4주 재활 지속 선수 중
재활 완료 선수 비율
```

은 서로 다른 지표이다.

따라서 단순히

```text
재활 전환율은 60%입니다.
```

라고 표현하는 것보다

```text
초기 평가 → 재활 완료
전체 전환율은 60%입니다.
```

또는

```text
4주 재활 지속 → 최종 평가
전환율은 60%입니다.
```

처럼 **분모와 분자가 어떤 단계인지 명확하게 표현하는 것이 좋다.**

# **7. 다양한 스포츠의학 퍼널 예시**

> ## **7-1 ) ACL 재활 퍼널**

분석 목표:

```text
ACL 수술 이후
Return to Sport 평가까지
재활 과정이 얼마나 이어지는가?
```

퍼널:

```text
수술 후 초기 평가
        ↓
재활 프로그램 시작
        ↓
12주 재활 지속
        ↓
근력 평가
        ↓
Hop Test 실시
        ↓
Return to Sport 평가 완료
```

살펴볼 수 있는 질문:

```text
재활 초기에 중단하는 선수가 많은가?

12주 이후 기능 평가까지
이어지지 않는가?

기능 검사를 완료했지만
복귀 평가까지 가지 않는가?
```

<br>

> ## **7-2 ) 발목 염좌 재활 퍼널**

분석 목표:

```text
급성 발목 염좌 이후
재활 프로그램 완료까지
어디에서 이탈하는가?
```

```text
초기 스포츠의학 평가
        ↓
재활 처방
        ↓
첫 재활 세션
        ↓
2주 재활 지속
        ↓
균형·기능 검사
        ↓
재활 완료
```

<br>

> ## **7-3 ) 투수 어깨 재활 퍼널**

야구 투수의 어깨 통증 관리 프로그램이라고 하자.

```text
통증 평가
        ↓
가동범위 평가
        ↓
회전근개 재활 시작
        ↓
재활 지속
        ↓
단계적 투구 프로그램 시작
        ↓
불펜 투구
        ↓
경기 복귀 평가
```

이 퍼널에서는

```text
재활 운동은 수행하지만
단계적 투구 프로그램으로
이어지지 않는가?
```

같은 문제를 확인할 수 있다.

<br>

> ## **7-4 ) 선수 건강검진 퍼널**

대학 운동선수를 대상으로 시즌 전 건강검진을 진행한다고 하자.

```text
검진 대상 선수
        ↓
기초 문진 완료
        ↓
근골격계 평가
        ↓
위험 선수 추가 검사
        ↓
전문의 상담
        ↓
예방 프로그램 참여
```

최종 목표를

```text
위험군 선수의
예방 프로그램 참여
```

로 정의한다면 이 과정 역시 하나의 퍼널로 분석할 수 있다.

<br>

> ## **7-5 ) 뇌진탕 복귀 관리 퍼널**

예를 들어 뇌진탕 의심 선수 관리 과정의 **운영 흐름**을 분석한다고 하자.

```text
증상 보고
        ↓
초기 의료 평가
        ↓
추적 평가
        ↓
단계적 복귀 프로그램 시작
        ↓
각 단계 모니터링
        ↓
최종 의료 평가
```

이 경우 퍼널 분석의 목적은 임상적으로 복귀 가능 여부를 판단하는 것이 아니라

```text
관리 과정에서
어느 단계의 추적이 잘 이어지지 않는가?
```

와 같은 **프로세스 운영 문제를 확인하는 것**이다.

# **8. 이탈이 집중되는 구간을 찾는다**

> ## **8-1 ) ACL 재활 사례**

다음과 같은 전환율이 나타났다고 하자.

| 구간 | 전환율 | 이탈률 |
| --- | ---: | ---: |
| 초기 평가 → 재활 시작 | 90% | 10% |
| 재활 시작 → 12주 지속 | 82% | 18% |
| 12주 지속 → 근력 평가 | 88% | 12% |
| 근력 평가 → Hop Test | 58% | 42% |
| Hop Test → 복귀 평가 | 85% | 15% |

가장 높은 이탈률은

```text
근력 평가
        ↓
Hop Test

이탈률
42%
```

구간이다.

따라서

> **근력 평가 이후 기능적 Hop Test로 이어지는 과정**

을 우선적으로 살펴볼 수 있다.

<br>

> ## **8-2 ) 높은 이탈률은 원인이 아니다**

위 결과를 보고 바로

```text
선수들이 Hop Test를
어려워해서 참여하지 않는다.
```

라고 결론 내릴 수는 없다.

현재 데이터에서 확인한 것은

```text
근력 평가 이후
Hop Test 실시까지
이어지는 비율이 낮다.
```

는 **현상**이다.

```text
검사가 어렵다.

예약이 불편하다.

검사 일정이 늦다.

선수가 필요성을 이해하지 못한다.

팀 일정과 겹친다.
```

등은 모두 **원인에 대한 가설**이다.

```text
퍼널에서 확인한 현상

근력 평가 → Hop Test
이탈률 42%

        ≠

Hop Test가 어려워서
선수가 중단했다.
```

<br>

> ## **8-3 ) 추가로 확인할 수 있는 데이터**

| 가설 | 추가 확인 데이터 |
| --- | --- |
| 검사 일정 때문에 참여하지 못한다 | 예약 대기기간, 일정 취소율 |
| 특정 팀 선수의 이탈이 많다 | 팀별 전환율 |
| 특정 시기에 이탈이 증가한다 | 월별·시즌별 전환율 |
| 선수들이 검사 필요성을 이해하지 못한다 | 상담 여부별 검사 참여율 |
| 접근성이 문제다 | 센터·지역별 검사 참여율 |

즉,

```text
퍼널 분석
        ↓
문제 구간 발견
        ↓
관련 데이터 추가 분석
        ↓
가설 설정
        ↓
검증
```

# **9. 퍼널은 비교하면서 해석한다**

> ## **9-1 ) 지난달과 이번 달 비교**

스포츠 재활센터의 퍼널을 비교한다고 하자.

| 구간 | 지난달 | 이번 달 |
| --- | ---: | ---: |
| 초기 평가 → 재활 시작 | 88% | 87% |
| 재활 시작 → 4주 지속 | 82% | 80% |
| 4주 지속 → 기능 평가 | 78% | 52% |

이번 달 데이터만 보면

```text
4주 지속 → 기능 평가
52%
```

라는 사실을 확인할 수 있다.

하지만 지난달과 비교하면

```text
78% → 52%
```

로 `26%p`나 감소했다.

따라서 단순히

```text
52%는 낮다.
```

보다

> **기존에 78%였던 전환율이 이번 달 52%까지 급격히 감소했다.**

라고 문제를 더 구체적으로 정의할 수 있다.

<br>

> ## **9-2 ) 종목별 비교**

같은 스포츠의학센터라도 종목에 따라 다를 수 있다.

| 종목 | 4주 재활 → 기능 평가 전환율 |
| --- | ---: |
| 축구 | 78% |
| 농구 | 74% |
| 배드민턴 | 76% |
| 핸드볼 | 51% |

전체 평균만 보면 문제를 발견하기 어려울 수 있지만 **핸드볼 선수에서 특히 낮은 전환율**이 나타날 수 있다.

따라서

```text
종목별

팀별

성별

연령대별

시즌 단계별

재활 프로그램별
```

등으로 비교해볼 수 있다.

<br>

> ## **9-3 ) 신규 선수와 기존 선수 비교**

예를 들어 스포츠의학센터를 처음 이용하는 선수와 기존에 이용한 경험이 있는 선수를 비교할 수도 있다.

```text
초진 선수

재활 시작 → 4주 지속
= 58%
```

```text
기존 이용 선수

재활 시작 → 4주 지속
= 82%
```

차이가 크다면

```text
초진 선수의
초기 재활 적응 과정
```

을 우선적으로 살펴볼 수 있다.

# **10. 퍼널 단계 정의 시 주의할 점**

> ## **10-1 ) 단계의 순서를 잘못 정의하면 안 된다**

퍼널은 실제 행동 순서를 반영해야 한다.

예를 들어

```text
초기 평가
        ↓
재활 프로그램 등록
        ↓
첫 재활 참석
        ↓
기능 평가
```

가 실제 과정이라면 이 순서를 기준으로 분석한다.

행동 순서를 무시하면 전환율의 의미가 달라질 수 있다.

<br>

> ## **10-2 ) 같은 선수를 중복 계산하지 않도록 기준을 정한다**

한 선수가 재활 세션에 10번 참여했다고 해서

```text
재활 참여 선수
= 10명
```

으로 계산하면 안 된다.

퍼널의 단위가 `선수`라면

```text
선수 1명
→ 재활 10회 참여

퍼널 사용자 수
→ 1명
```

으로 계산한다.

따라서 분석 전에 단위를 명확하게 정한다.

```text
선수 기준인가?

방문 건수 기준인가?

재활 세션 기준인가?

부상 Episode 기준인가?
```

<br>

> ## **10-3 ) 기간을 동일하게 정의한다**

다음 두 선수를 비교한다고 하자.

```text
선수 A
관찰기간
12주

선수 B
관찰기간
2주
```

선수 B가 아직 기능 평가에 도달하지 않았다고 해서 즉시 이탈로 처리하면 잘못된 해석이 될 수 있다.

따라서

```text
등록 후 4주 이내

수술 후 12주 이내

초기 평가 후 30일 이내
```

처럼 분석 기간을 명확하게 정의해야 한다.

<br>

> ## **10-4 ) 단계 정의가 너무 모호하면 안 된다**

예를 들어

```text
재활 참여
```

라고만 하면 의미가 모호하다.

다음과 같이 구체적으로 정의할 수 있다.

```text
재활 시작

= 초기 평가 후 14일 이내
  첫 재활 세션에 실제 참석한 선수
```

또는

```text
4주 재활 지속

= 첫 재활 세션 이후
  28일 동안
  최소 6회 이상 재활 세션에 참여한 선수
```

처럼 명확한 기준을 정한다.

<br>

> ## **10-5 ) 최종 목표와 관계없는 단계를 무조건 넣지 않는다**

ACL 복귀 평가를 분석하고 있는데

```text
센터 SNS 게시물 조회

뉴스레터 클릭

홈페이지 FAQ 조회
```

등을 모두 주요 퍼널 단계에 넣을 필요는 없다.

퍼널에는

> **최종 목표 행동에 도달하는 데 의미 있는 행동**

을 중심으로 포함한다.

# **11. 스포츠의학 퍼널 분석 실습**

> ## **11-1 ) 문제 상황**

한 스포츠의학센터에서 발목 염좌 선수들의 재활 완료율이 감소했다.

다음과 같은 데이터가 있다.

```text
초기 평가
500명
    ↓
재활 프로그램 등록
450명
    ↓
첫 재활 세션 참석
405명
    ↓
2주 재활 지속
324명
    ↓
4주 재활 지속
194명
    ↓
최종 기능 평가
155명
```

<br>

> ## **11-2 ) 구간별 전환율 계산**

### 초기 평가 → 재활 등록

```text
450 / 500 × 100

= 90%
```

### 재활 등록 → 첫 재활 참석

```text
405 / 450 × 100

= 90%
```

### 첫 재활 참석 → 2주 지속

```text
324 / 405 × 100

= 80%
```

### 2주 지속 → 4주 지속

```text
194 / 324 × 100

≈ 59.9%
```

### 4주 지속 → 최종 기능 평가

```text
155 / 194 × 100

≈ 79.9%
```

<br>

> ## **11-3 ) 전환율과 이탈률 정리**

| 구간 | 전환율 | 이탈률 |
| --- | ---: | ---: |
| 초기 평가 → 재활 등록 | 90% | 10% |
| 재활 등록 → 첫 세션 | 90% | 10% |
| 첫 세션 → 2주 지속 | 80% | 20% |
| 2주 지속 → 4주 지속 | 약 59.9% | 약 40.1% |
| 4주 지속 → 최종 평가 | 약 79.9% | 약 20.1% |

가장 큰 이탈은

```text
2주 재활 지속
        ↓
4주 재활 지속

이탈률
약 40.1%
```

구간에서 나타난다.

따라서

```text
재활 초반은 잘 이어지지만

2주 이후부터
중도 중단이 증가한다.
```

고 문제를 구체화할 수 있다.

<br>

> ## **11-4 ) 전체 전환율**

```text
155 / 500 × 100

= 31%
```

즉,

> **초기 평가를 받은 선수 중 최종 기능 평가까지 도달한 비율은 31%이다.**

하지만 전체 `31%`만 봤다면

```text
2주 → 4주
```

구간에 문제가 집중된다는 사실을 알기 어려웠을 것이다.

<br>

> ## **11-5 ) 다음 분석으로 연결**

이제 다음과 같은 질문을 만들 수 있다.

```text
왜 2주 이후에
재활을 중단하는 선수가
많아졌을까?
```

가능한 가설은 다음과 같다.

```text
재활 통증이나 불편감 때문인가?

훈련 복귀를 너무 일찍 시도했는가?

팀 일정과 충돌했는가?

재활 방문 빈도가 부담스러운가?

선수가 증상이 좋아졌다고 느껴
재활이 더 이상 필요하지 않다고 생각했는가?
```

하지만 이들은 아직 가설이다.

추가 데이터를 확인해야 한다.

```text
재활 방문 간격

중도 취소 이유

종목

팀 일정

부상 중증도

재활 세션 횟수

증상 변화

선수 연령

재활 장소
```

등을 추가로 분석할 수 있다.

# **13. Advanced 추가 학습**

> ## **13-1 ) 이탈률이 가장 높은 구간이 항상 최우선 개선 대상은 아니다**

예를 들어

```text
구간 A

1,000명
→ 700명

이탈률
30%

이탈 선수
300명
```

이고

```text
구간 B

100명
→ 50명

이탈률
50%

이탈 선수
50명
```

이라고 하자.

이탈률만 보면 구간 B가 더 높다.

하지만 실제 영향을 받는 선수 수는

```text
구간 A
300명

구간 B
50명
```

으로 구간 A가 더 크다.

따라서 우선순위를 결정할 때는

```text
이탈률

+

이탈 대상자 수

+

프로그램상 중요성

+

개선 가능성
```

등을 함께 고려할 수 있다.

<br>

> ## **13-2 ) 기준 전환율과 비교한다**

단순히

```text
전환율 60%
```

이라는 숫자만으로 높고 낮음을 판단하기 어렵다.

다음과 비교할 수 있다.

```text
지난달

지난해 같은 시기

다른 종목

다른 팀

다른 센터

프로그램 변경 전후
```

예를 들어

```text
기능 평가 → 복귀 평가

지난달
82%

이번 달
61%
```

이라면 단순히 61%라는 숫자보다

```text
21%p 감소
```

했다는 변화가 더 중요한 분석 단서가 될 수 있다.

<br>

> ## **13-3 ) 퍼널은 인과관계를 증명하지 않는다**

퍼널에서

```text
재활 등록 → 첫 세션
전환율 감소
```

를 발견했다고 하자.

최근 예약 시스템이 변경되었다고 해서

```text
예약 시스템 변경 때문에
전환율이 감소했다.
```

고 바로 단정할 수는 없다.

```text
시간적 변화 확인

관련 데이터 분석

사용자 그룹 비교

필요하면 실험 또는 추가 연구
```

등을 통해 가설을 검증해야 한다.

# **14. 핵심정리**

> ## **14-1 ) 퍼널 분석**

퍼널 분석은

> **특정 목표 행동까지 도달하는 과정을 여러 단계로 나누고, 각 단계 사이의 전환과 이탈을 분석하여 문제가 나타나는 구간을 찾는 방법**

이다.

스포츠의학 예시로는

```text
초기 평가
    ↓
재활 시작
    ↓
재활 지속
    ↓
기능 평가
    ↓
Return to Sport 평가
```

와 같이 구성할 수 있다.

<br>

> ## **14-2 ) 전환율**

```text
전환율

= 다음 단계 대상자 수
  /
  현재 단계 대상자 수
  × 100
```

전환율은

> **현재 단계의 선수 중 얼마나 많은 선수가 다음 단계까지 이어졌는가?**

를 보여준다.

<br>

> ## **14-3 ) 이탈률**

```text
이탈률

= 100% - 전환율
```

또는

```text
이탈률

= 다음 단계로 이어지지 않은 선수 수
  /
  현재 단계 선수 수
  × 100
```

이다.

같은 구간에서는

```text
전환율 + 이탈률
= 100%
```

이다.

<br>

> ## **14-4 ) 전체 전환율과 구간별 전환율**

```text
전체 전환율

→ 처음 시작한 선수 중
   최종 목표까지
   얼마나 도달했는가?
```

```text
구간별 전환율

→ 어느 행동 사이에서
   다음 단계로
   잘 이어지지 않는가?
```

둘은 서로 다른 질문에 답하므로 함께 확인하는 것이 좋다.

<br>

> ## **14-5 ) 다양한 스포츠의학 퍼널**

| 분석 목적 | 퍼널 예시 |
| --- | --- |
| ACL 재활 | 초기 평가 → 재활 → 근력 평가 → Hop Test → 복귀 평가 |
| 발목 염좌 | 진료 → 재활 등록 → 재활 지속 → 기능 평가 → 완료 |
| 투수 어깨 | 통증 평가 → 재활 → 단계적 투구 → 불펜 → 복귀 평가 |
| 시즌 전 검진 | 대상 선수 → 문진 → 근골격계 평가 → 추가검사 → 예방 프로그램 |
| 뇌진탕 관리 프로세스 | 증상 보고 → 의료 평가 → 추적 평가 → 단계적 복귀 관리 |

<br>

> ## **14-6 ) 퍼널 분석에서 중요한 주의점**

```text
이탈이 많다
        ↓
문제 구간을 발견
```

한 것과

```text
왜 이탈했는지
원인을 확인
```

한 것은 다르다.

따라서

```text
퍼널 분석
        ↓
문제 위치 발견
        ↓
추가 데이터 분석
        ↓
가설 설정
        ↓
검증
        ↓
개선
```

으로 이어져야 한다.

<br>

> ## **14-7 ) 가장 중요한 전체 흐름**

```text
무엇을 개선하고 싶은가?
        ↓
목표 행동 정의
        ↓
목표까지의 주요 단계 정의
        ↓
선수 수 계산
        ↓
전환율 계산
        ↓
이탈률 계산
        ↓
전체 전환율 확인
        ↓
이탈이 집중되는 구간 탐색
        ↓
시간·종목·선수 특성별 비교
        ↓
문제 구체화
        ↓
왜 이런 현상이 발생했을까?
        ↓
가설 설정
        ↓
추가 분석 및 검증
        ↓
스포츠의학 프로그램 개선
```

**한 문장으로 정리하면**

> **퍼널 분석은 선수의 진료·재활·기능평가·복귀 관리처럼 목표 행동까지 이어지는 과정을 단계별로 나누어 전환율과 이탈률을 측정하고, 어느 과정에서 다음 단계로 잘 이어지지 않는지 찾아 추가 분석과 프로그램 개선으로 연결하는 방법이다.**
