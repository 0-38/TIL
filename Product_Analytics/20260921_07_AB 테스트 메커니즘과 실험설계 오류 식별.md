# **1. A/B 테스트는 왜 필요한가?**

> ## **1-1 ) 새로운 훈련 피드백을 적용한 뒤 기록이 좋아졌다면 정말 피드백의 효과일까?**

탁구 선수의 서브 리턴 정확도를 높이기 위해 새로운 **볼 궤적 시각화 피드백**을 만들었다고 생각해보자.

기존에는 코치가 선수에게 구두로 피드백을 제공했다.

```text
기존 방식

선수 리턴 수행
    ↓
코치 관찰
    ↓
구두 피드백
```

새로운 방식에서는 고속 카메라로 공의 궤적을 추적한 뒤 화면에 다음 정보를 제공한다.

```text
새로운 방식

서브 리턴 수행
    ↓
공의 궤적 추적
    ↓
임팩트 위치 표시
    ↓
리턴 방향 표시
    ↓
목표 구역과 비교
    ↓
시각화 피드백 제공
```

새로운 피드백을 전체 선수에게 적용하기 전 평균 리턴 성공률이 `58%`였다고 하자.

적용 후에는 `67%`가 되었다.

```text
적용 전
58%

    ↓
새로운 피드백 적용
    ↓

적용 후
67%
```

겉으로 보면

```text
+9%p
```

만큼 좋아졌다.

하지만 이것만으로 다음과 같이 단정할 수 있을까?

> 새로운 볼 궤적 피드백 때문에 리턴 성공률이 높아졌다.

그렇지는 않다.

적용 전과 적용 후에는 피드백 방식 이외에도 여러 조건이 달라졌을 수 있다.

```text
선수의 훈련 경험 증가

상대 서브 난이도 변화

훈련 시간 증가

컨디션 변화

라켓 또는 공 변경

반복 훈련에 따른 학습 효과
```

따라서 단순한

```text
Before
vs
After
```

비교만으로는 새로운 피드백의 효과인지 다른 요인의 영향인지 구분하기 어렵다.

<br>

> ## **1-2 ) A/B 테스트란?**

A/B 테스트는 실험 대상을 서로 다른 그룹으로 나누어 **기존 방식과 새로운 방식을 동시에 제공한 뒤 결과를 비교하는 실험 방법**이다.

탁구 피드백 실험을 다음과 같이 구성할 수 있다.

```text
실험 참여 선수
        ↓
    무작위 배정
     ↙       ↘

A 그룹        B 그룹
기존 피드백    궤적 시각화 피드백

     ↓          ↓

리턴 정확도   리턴 정확도

     ↘          ↙

       결과 비교
```

| 구분 | A 그룹 | B 그룹 |
| --- | --- | --- |
| 역할 | 대조군 | 실험군 |
| 훈련 | 기존 훈련 | 동일 |
| 피드백 | 코치 구두 피드백 | 궤적 시각화 피드백 |
| 목표 지표 | 리턴 성공률 | 리턴 성공률 |

기존 방법을 제공하는 그룹을 **대조군(Control Group)** 이라고 한다.

새롭게 검증할 방법을 제공하는 그룹을 **실험군(Treatment Group)** 이라고 한다.

<br>

> ## **1-3 ) 왜 무작위 배정이 필요할까?**

다음과 같이 그룹을 나눈다고 생각해보자.

```text
A 그룹
초급 선수
→ 기존 피드백

B 그룹
엘리트 선수
→ 새로운 피드백
```

실험 결과 B 그룹의 리턴 성공률이 높게 나타나더라도

```text
새로운 피드백 때문인가?

vs

원래 B 그룹 선수의
기술 수준이 높았기 때문인가?
```

를 구분하기 어렵다.

따라서 일반적으로 실험 대상 선수를 **무작위 배정(Random Assignment)** 한다.

```text
전체 선수
    ↓
무작위 배정
    ↓

A                    B
기존 피드백          새로운 피드백
```

무작위 배정은 특정 특성의 선수가 한쪽 그룹에 의도적으로 몰리는 것을 줄여준다.

단, 무작위 배정을 했다고 해서 두 그룹의 키, 경력, 성별, 기술 수준 등이 **항상 정확히 동일해지는 것은 아니다.**

무작위 배정은 이러한 차이를 확률적으로 줄이기 위한 방법이다.

<br>

> ## **1-4 ) 분석에서 실험으로 연결하는 과정**

스포츠 데이터 분석에서도 다음 흐름으로 연결할 수 있다.

```text
경기·훈련 데이터 분석
        ↓
문제 발견
        ↓
문제 구체화
        ↓
원인에 대한 가설
        ↓
개선 방법 설계
        ↓
A/B 테스트
        ↓
개선 효과 검증
```

예를 들어 다음과 같다.

```text
탁구 리턴 영상분석

        ↓

백핸드 리턴에서
네트 미스 비율 증가

        ↓

임팩트 위치가
몸 뒤쪽에서 형성되는 경향 발견

        ↓

가설

임팩트 위치를 실시간으로
시각화하면 리턴 정확도가
높아질 수 있다.

        ↓

A/B 테스트

기존 피드백
vs
실시간 위치 피드백
```

즉, A/B 테스트는 단순히 두 숫자를 비교하는 것이 아니라 **분석에서 발견한 문제와 개선 가설을 실제 실험으로 검증하는 과정**이다.

# **2. A/B 테스트를 설계한다**

> ## **2-1 ) 무엇을 어떻게 검증할지 먼저 정한다**

이번에는 쇼트트랙 선수의 스타트 동작을 개선하는 실험을 생각해보자.

영상분석 결과 일부 선수는 스타트 시 첫 세 걸음에서 상체가 너무 빠르게 일어나는 패턴이 관찰되었다고 하자.

```text
영상분석

스타트 첫 3보에서
상체가 빠르게 상승

        ↓

초기 가속 구간에서
전진 방향 추진이 감소할 가능성

        ↓

개선안

실시간 몸통각 피드백 제공
```

A/B 테스트를 하기 전에 다음 내용을 결정해야 한다.

```text
검증 가설

        ↓

목표 지표

        ↓

실험 대상

        ↓

대조군 / 실험군

        ↓

무작위 배정

        ↓

실험 조건

        ↓

표본 크기 / 기간
```

<br>

> ## **2-2 ) 검증 가설을 설정한다**

관찰된 사실과 검증 가설을 구분한다.

| 구분 | 내용 |
| --- | --- |
| 관찰된 사실 | 일부 선수의 스타트에서 몸통이 빠르게 상승 |
| 원인 가설 | 몸통각 조절이 초기 가속 수행과 관련될 수 있음 |
| 개선안 | 첫 3보의 몸통각 실시간 피드백 |
| 검증 가설 | 실시간 몸통각 피드백을 제공하면 10m 기록이 단축될 것이다 |

검증 가설은 다음과 같이 구체적이어야 한다.

```text
X

새로운 피드백이
더 좋을 것이다.
```

보다는

```text
O

스타트 훈련에서
몸통각 실시간 피드백을 제공하면

기존 코치 피드백보다

10m 통과시간(ms)이
감소할 것이다.
```

처럼 어떤 변화가 **어떤 지표에 영향을 주는지** 명확하게 정의하는 것이 좋다.

<br>

> ## **2-3 ) 목표 지표를 설정한다**

이번 실험의 Primary Metric은

```text
10m 스타트 통과시간(ms)
```

으로 정할 수 있다.

측정 정의도 구체적으로 정한다.

```text
스타트 신호가 발생한 시점

        ↓

선수의 몸통 중심이
출발선으로부터 10m 지점을
통과한 시점까지의 시간
```

단위는 `ms`이다.

값이 작을수록 더 빠르다.

보조 지표도 설정할 수 있다.

| 지표 구분 | 변수 |
| --- | --- |
| Primary | 10m 통과시간 `ms` |
| Secondary | 첫 3보 평균 접촉시간 `ms` |
| Secondary | 첫 3보 평균 보폭 `m` |
| Secondary | 3보 시점 몸통 기울기 `°` |
| Secondary | 최대 전방 속도 `m/s` |
| Guardrail | 스타트 실격률 `%` |

목표 지표는 **실험 결과를 보기 전에 정하는 것**이 중요하다.

결과를 모두 확인한 뒤 좋아진 지표만 선택하면 처음 검증하려던 가설과 다른 결론을 만들 수 있기 때문이다.

<br>

> ## **2-4 ) 실험 대상과 그룹을 설정한다**

실험 대상은 다음처럼 정의할 수 있다.

```text
현재 동일 스타트 훈련 프로그램에
참여하고 있는 쇼트트랙 선수
```

그리고 선수들을 두 그룹으로 나눈다.

```text
선수
    ↓
무작위 배정
 ↙          ↘

Control     Treatment

기존 코치    기존 코치 피드백
피드백       +
             몸통각 실시간 피드백
```

검증하려는 요소를 제외한 조건은 가능한 한 동일하게 유지한다.

| 통제할 조건 | 예시 |
| --- | --- |
| 트랙 | 동일 링크 |
| 스타트 위치 | 동일 |
| 스케이트 | 선수 본인 장비 유지 |
| 워밍업 | 동일 프로토콜 |
| 측정 장비 | 동일 카메라·센서 |
| 훈련 횟수 | 동일 |
| 휴식시간 | 동일 |
| 코치 지시 | 피드백 요소 외 동일 |

<br>

> ## **2-5 ) 실험 조건을 설정한다**

대조군과 실험군을 정했다면 마지막으로 **어느 정도의 차이를 검증할 것인지, 몇 명의 선수가 필요한지, 어느 기간 동안 실험할지** 결정해야 한다.

단순히 선수들을 두 그룹으로 나누는 것만으로는 충분하지 않다.

실험을 시작하기 전에 다음 조건을 미리 설정한다.

```text
검증 가설
        ↓
목표 지표
        ↓
MDE 설정
        ↓
필요 표본 크기 결정
        ↓
실험 기간 결정
        ↓
A/B 테스트 수행
        ↓
결과 비교
````

이번 쇼트트랙 스타트 실험에서는 다음과 같이 생각할 수 있다.

```text
Primary Metric

10m 스타트 통과시간(ms)
```

기존 선수들의 평균 10m 통과시간이 예를 들어

```text
2,100 ms
```

라고 하자.

이때 단순히

```text
조금이라도 빨라지면
효과가 있다.
```

라고 정하는 것이 아니라, **실제로 의미 있다고 판단할 최소한의 개선폭**을 먼저 정한다.

<br>

### **MDE : 최소한 어느 정도의 차이를 탐지할 것인가?**

`MDE(Minimum Detectable Effect)`는 실험에서 **탐지하고자 하는 최소한의 효과 크기**이다.

예를 들어 이번 실험에서

```text
기존 평균 10m 기록
2,100 ms

MDE
50 ms
```

로 정한다고 하자.

그러면 이번 실험은 다음과 같은 차이를 탐지하는 것을 목표로 한다.

```text
Control
약 2,100 ms

Treatment
약 2,050 ms
```

즉,

> **몸통각 실시간 피드백으로 10m 통과시간이 최소 50ms 정도 단축되는지를 확인하겠다.**

라는 의미이다.

MDE는

```text
차이가 존재하는가?
```

뿐만 아니라

```text
어느 정도의 차이를
의미 있는 변화로 볼 것인가?
```

를 실험 전에 정하는 기준이다.

너무 작은 차이까지 탐지하려고 하면 일반적으로 더 많은 표본이 필요하다.

<br>

### **표본 크기 : 몇 명의 선수가 필요한가?**

표본 크기는 **실험 결과를 비교하기 위해 Control과 Treatment에 얼마나 많은 선수가 필요한가**를 의미한다.

```text
표본이 너무 적음

        ↓

선수 개인차의 영향이 커짐

        ↓

실제로 효과가 있어도
차이를 확인하기 어려울 수 있음
```

예를 들어 다음 정보를 이용하여 필요한 표본 수를 결정할 수 있다.

```text
현재 10m 기록의 평균

기록의 표준편차

MDE

유의수준 α

검정력 Power
```

이번 실험을 예로 들면

```text
Baseline Mean
= 2,100 ms

SD
= 100 ms

MDE
= 50 ms

α
= 0.05

Power
= 0.80
```

과 같이 실험 조건을 설정할 수 있다.

여기서

```text
MDE 50 ms
```

는 이번 실험에서 확인하려는 최소 기록 차이이다.

다만 스포츠과학 실험에서는 실제 확보 가능한 선수 수가 적을 수 있기 때문에 **선수 한 명의 반복 스타트 시도를 독립된 선수 여러 명처럼 계산해서는 안 된다.**

```text
선수 1명
스타트 10회

≠

선수 10명
```

같은 선수의 반복 측정은 서로 연관되어 있기 때문이다.

<br>

### **실험 기간 : 얼마나 오래 측정할 것인가?**

실험 기간도 실험 전에 정해야 한다.

너무 짧은 기간만 측정하면 특정 훈련일의 상태에 결과가 영향을 받을 수 있다.

예를 들어

```text
훈련 당일 피로

빙질 상태

직전 고강도 훈련

컨디션

학습 효과

측정 순서
```

등이 기록에 영향을 줄 수 있다.

따라서 이번 실험에서는 예를 들어

```text
실험 기간
4주

주당 스타트 훈련
2회

측정 시도
훈련당 3회

동일 워밍업

동일 휴식시간

동일 측정 장비
```

처럼 조건을 미리 정의할 수 있다.

중요한 것은 단순히 많은 시도를 모으는 것이 아니라 **두 그룹이 가능한 한 동일한 조건에서 충분한 기간 동안 측정되도록 설계하는 것**이다.

<br>

### **이번 쇼트트랙 A/B 테스트의 실험 조건 정리**

| 항목             | 설정 예시                            |
| -------------- | -------------------------------- |
| 검증 가설          | 몸통각 실시간 피드백을 제공하면 10m 통과시간이 감소한다 |

> ## **2-7 ) Python으로 무작위 배정하기**

120명의 쇼트트랙 선수를 정확히 `60명 : 60명`으로 나눈다고 가정한다.

[Python : code] "120명의 선수를 대조군과 실험군에 정확히 1:1 무작위 배정"

```python
import numpy as np
import pandas as pd

rng = np.random.default_rng(42)

athletes = pd.DataFrame({
    "athlete_id": [f"S{i:03d}" for i in range(1, 121)]
})

# 60개의 Control, 60개의 Treatment 생성
groups = np.array(
    ["Control"] * 60 +
    ["Treatment"] * 60
)

# 그룹 순서를 무작위로 섞음
athletes["group"] = rng.permutation(groups)

print(athletes.head())

print("\n그룹별 선수 수")
print(athletes["group"].value_counts())
```

```text
4       S005  Treatment

Control      60

```

# **3. A/B 테스트를 진행할 때 주의할 점**

> ## **3-1 ) 실험 설계가 좋아도 진행 과정에서 문제가 생길 수 있다**

A/B 테스트에서는 결과만 확인하는 것이 아니라 **실험이 처음 설계한 방식대로 진행되었는지** 확인해야 한다.

대표적으로 다음 문제를 살펴볼 수 있다.

| 문제 | 의미 | 스포츠 예시 |
| --- | --- | --- |
| 조기 종료 | 계획보다 일찍 결과 판단 | 스키 실험을 4주 계획했는데 1주 결과만 보고 종료 |
| 신규성 효과 | 새 방법에 대한 일시적 반응 | 새로운 VR 피드백에 초기 집중도 증가 |
| 표본 오염 | 서로 다른 처치가 섞임 | 유도 실험군의 훈련법이 대조군에게 전달 |
| SRM | 계획 배정과 실제 표본 비율 불일치 | 조정 선수 50:50 계획이 70:30으로 수집 |

<br>

> ## **3-2 ) 조기 종료 - 알파인스키 턴 피드백 실험**

알파인스키 선수에게 새로운 턴 라인 오버레이 피드백을 적용한다고 하자.

실험 계획은 `4주`이다.

```text
계획

4주 동안 훈련
        ↓
모든 데이터 수집
        ↓
결과 분석
```

하지만 1주 후 다음 결과가 나타났다고 하자.

```text
Control
코스 평균 기록
64.8초

Treatment
코스 평균 기록
62.9초
```

Treatment가 좋아 보인다는 이유로 여기서 실험을 종료하면 **우연히 첫 주에 발생한 차이를 실제 효과로 판단할 가능성**이 있다.

따라서 특별한 순차검정 설계를 사용하지 않았다면 사전에 계획한 표본과 기간을 기준으로 결과를 판단하는 것이 중요하다.

<br>

> ## **3-3 ) 신규성 효과 - 유도 훈련 피드백**

유도 선수에게 새로운 AR 기반 자세 피드백을 제공했다고 하자.

```text
실험 초반

새로운 장비에 높은 관심
        ↓
집중도 증가
        ↓
훈련 수행률 증가
```

하지만 시간이 지나면

```text
새로운 장비에 익숙해짐
        ↓
초기 관심 감소
        ↓
Control과 차이 감소
```

할 수 있다.

이처럼 새로운 시스템 자체에 대한 관심 때문에 일시적으로 행동이 변화하는 것을 **신규성 효과(Novelty Effect)**라고 한다.

따라서 실험 첫날이나 첫 주의 결과만 보고 장기적인 효과라고 판단하면 안 된다.

<br>

> ## **3-4 ) 표본 오염 - 카누 패들링 피드백**

카누 선수에게 다음과 같은 실험을 한다고 하자.

```text
A 그룹
기존 패들링 코칭

B 그룹
패들 각도 실시간 피드백
```

그런데 두 그룹이 함께 훈련하면서 B 그룹 선수들이 A 그룹 선수들에게 새로운 패들링 피드백 내용을 알려주었다고 하자.

```text
Treatment 정보

B 선수
   ↓
훈련 중 공유
   ↓
A 선수도 적용
```

그러면 대조군도 실험 처치의 일부를 경험하게 된다.

이를 **표본 오염(Sample Contamination)**이라고 한다.

이 경우 A와 B의 차이가 작아지거나 실제 효과를 정확하게 측정하기 어려워질 수 있다.

<br>

> ## **3-5 ) SRM - 조정 훈련 시스템**

200명의 조정 선수를 다음처럼 배정할 계획이었다고 하자.

```text
계획

Control
100명

Treatment
100명
```

그런데 실제 데이터는 다음과 같았다.

```text
Control
140명

Treatment
60명
```

[ Result ]

```text
계획
50% : 50%

실제
70% : 30%
```

이처럼 계획한 배정 비율과 실제 수집된 비율이 비정상적으로 어긋나는 현상을 **SRM(Sample Ratio Mismatch)**이라고 한다.

가능한 원인으로는 다음과 같은 문제가 있을 수 있다.

```text
그룹 배정 코드 오류

Treatment 센서 연결 실패

특정 기기에서 로그 누락

실험군 데이터 저장 실패

선수 ID 중복 또는 누락
```

따라서 바로 성과 지표를 비교하기보다 **실험 배정 및 데이터 수집 과정을 먼저 확인**해야 한다.

<br>

> ## **3-6 ) 실험 결과를 보기 전 체크**

```text

    ↓
무작위 배정
    ↓
실험 진행
    ↓
실험 과정 점검
    ↓
SRM 확인
    ↓
표본 오염 확인
    ↓
계획한 기간·표본 확인
    ↓
결과 분석
```

결과가 좋아 보이더라도 실험 자체가 잘못 진행되었다면 결과의 신뢰성이 떨어질 수 있다.

# **4. A/B 테스트 결과를 분석한다**

> ## **4-1 ) 실험군의 성공률이 더 높으면 바로 효과가 있다고 볼 수 있을까?**

이번에는 골프 퍼팅 훈련에서 새로운 시각 피드백의 효과를 검증한다고 하자.

실험 조건은 다음과 같다.

| 그룹 | 피드백 방식 | 선수 수 |
| --- | --- | ---: |
| A | 기존 코치 피드백 | 100명 |
| B | 퍼팅 라인 시각화 피드백 | 100명 |

실험 종료 후 각 선수는 동일한 거리에서 표준화된 퍼팅 평가를 수행했다.

이번 예에서는 선수별 평가 결과를 다음처럼 단순화한다.

```text
성공
→ 사전에 정의한 퍼팅 수행 기준 통과

실패
→ 기준 미달
```

결과는 다음과 같다.

| 그룹 | 전체 선수 | 성공 선수 | 성공률 |
| --- | ---: | ---: | ---: |
| A | 100 | 58 | 58% |
| B | 100 | 72 | 72% |

관찰된 차이는

```text
72% - 58%
= +14%p
```

이다.

B 그룹의 성공률이 더 높지만 표본에서 나타난 차이는 **우연한 표본 변동으로도 발생할 수 있다.**

따라서 가설검정을 수행한다.

<br>

> ## **4-2 ) 귀무가설과 대립가설**

```text
H0

A 그룹과 B 그룹의
퍼팅 평가 성공률에는 차이가 없다.


H1

A 그룹과 B 그룹의
퍼팅 평가 성공률에는 차이가 있다.
```

이번처럼 독립된 두 그룹의 비율을 비교하는 단순 예에서는 **2표본 비율 검정(Two-Proportion Z-Test)** 을 사용할 수 있다.

<br>

> ## **4-3 ) Python으로 두 비율 검정하기**

[Python : code] "기존 피드백과 퍼팅 라인 시각화 피드백의 성공률 차이 검정"

```python
import numpy as np
from statsmodels.stats.proportion import proportions_ztest

# 성공 선수 수
success = np.array([
    58,   # Control
    72    # Treatment
])

# 각 그룹 전체 선수 수
nobs = np.array([
    100,
    100
])

# 2표본 비율 검정
z_stat, p_value = proportions_ztest(
    count=success,
    nobs=nobs
)

control_rate = success[0] / nobs[0] * 100
treatment_rate = success[1] / nobs[1] * 100
difference = treatment_rate - control_rate

print(f"Control 성공률   : {control_rate:.1f}%")
print(f"Treatment 성공률 : {treatment_rate:.1f}%")
print(f"관찰된 차이       : {difference:+.1f}%p")
print(f"z-statistic      : {z_stat:.3f}")
print(f"p-value          : {p_value:.4f}")
```

[ Result ]

```text
Control 성공률   : 58.0%
Treatment 성공률 : 72.0%
관찰된 차이       : +14.0%p

z-statistic      : -2.075
p-value          : 0.0379
```

유의수준을

```text
α = 0.05
```

로 설정했다면

```text
p-value = 0.0379

0.0379 < 0.05
```

이므로 귀무가설을 기각한다.

즉, 이 예시 데이터에서는 **두 그룹의 성공률에 통계적으로 유의한 차이가 관찰되었다.**

<br>

> ## **4-4 ) 코드 흐름도**

```text
A 그룹 성공 선수 수
58명

B 그룹 성공 선수 수
72명

        ↓

각 그룹 전체 선수
100명 / 100명

        ↓

성공률 계산

58%
vs
72%

        ↓

관찰된 차이
+14%p

        ↓

Two-Proportion Z-Test

        ↓

p-value
0.0379

        ↓

α = 0.05와 비교

        ↓

p < α

        ↓

귀무가설 기각
```

<br>

> ## **4-5 ) 관찰된 차이와 p-value의 역할은 다르다**

| 값 | 의미 |
| --- | --- |
| `+14%p` | 두 그룹에서 실제로 관찰된 차이의 크기 |
| `p = 0.0379` | 귀무가설 아래 현재와 같은 차이를 평가하는 통계적 근거 |
| `α = 0.05` | 실험 전에 정한 판단 기준 |

`p-value`가 작다고 해서 효과의 크기가 크다는 뜻은 아니다.

반대로 효과가 크게 보여도 표본이 작고 변동이 크다면 통계적 근거가 충분하지 않을 수 있다.

# **5. 통계적 유의성과 실질적 유의성을 함께 본다**

> ## **5-1 ) 통계적으로 유의하면 항상 중요한 변화일까?**

보행분석 연구에서 새로운 청각 리듬 피드백을 적용했다고 생각해보자.

목표는 좌우 보행 비대칭을 줄이는 것이다.

다음 두 실험을 비교해보자.

| 실험 | 기존 비대칭 | 새로운 방식 | 차이 | p-value |
| --- | ---: | ---: | ---: | ---: |
| A | 8.0% | 5.0% | -3.0%p | 0.020 |
| B | 8.0% | 7.8% | -0.2%p | 0.010 |

두 실험 모두 `p < 0.05`라고 가정하면 통계적으로 유의하다.

그러나 변화의 크기는 매우 다르다.

```text
실험 A

8.0%
→
5.0%

-3.0%p
```

```text
실험 B

8.0%
→
7.8%

-0.2%p
```

따라서 최종적으로는 다음을 함께 확인해야 한다.

```text
통계적으로 차이가 있는가?

        ↓

차이가 얼마나 큰가?

        ↓

스포츠과학적·임상적으로
의미 있는 변화인가?
```

<br>

> ## **5-2 ) MDE와 관찰된 효과 비교**

실험 전에 다음처럼 정했다고 하자.

```text
MDE

보행 비대칭
최소 2.0%p 개선
```

관찰 결과가

```text

```

이면 사전에 중요하다고 정한 크기보다 큰 변화이다.

반면

```text

```

라면 통계적으로 유의하더라도 사전에 정한 실질적 기준보다 작을 수 있다.

즉,

```text

+
효과 크기

+
MDE

```

를 함께 해석하는 것이 중요하다.

<br>

> ## **5-3 ) 절대 변화와 상대 변화는 구분한다**

양궁이 아닌 다른 예로, 클라이밍 홀드 접촉 성공률이 다음과 같이 변했다고 하자.

```text
기존
50%

새로운 시각 탐색 훈련
60%
```

절대 변화는

```text
60% - 50%
= +10%p
```

이다.

상대 변화는

```text
(60% - 50%) / 50% × 100

= +20%
```

이다.

| 표현 | 값 | 의미 |
| --- | ---: | --- |
| 절대 변화 | `+10%p` | 성공률 자체가 10 percentage point 증가 |
| 상대 변화 | `+20%` | 기존 성공률 대비 20% 증가 |

두 표현은 서로 다르므로 결과를 보고할 때 구분해야 한다.

# **6. 목표 지표와 가드레일 지표를 함께 본다**

> ## **6-1 ) 한 지표가 좋아졌다고 전체 수행이 좋아졌다고 볼 수 있을까?**

이번에는 스포츠클라이밍에서 새로운 루트 미리보기 영상을 제공하는 실험을 생각해보자.

Primary Metric은

```text
완등 성공률
```

이라고 하자.

결과가 다음과 같이 나타났다.

```text
Control

완등 성공률
55%


Treatment

완등 성공률
68%
```

완등 성공률만 보면 Treatment가 좋아 보인다.

하지만 추가 지표를 확인했더니 다음과 같았다고 하자.

| 지표 | Control | Treatment |
| --- | ---: | ---: |
| 완등 성공률 | 55% | 68% |
| 평균 완등시간 | 95초 | 128초 |
| 손가락 통증 보고율 | 4% | 11% |

이 경우 완등률 하나만으로 새로운 방식을 평가하기 어렵다.

<br>

> ## **6-2 ) Primary / Secondary / Guardrail Metric**

| 구분 | 역할 | 클라이밍 예시 |
| --- | --- | --- |
| Primary | 실험의 핵심 효과 | 완등 성공률 |
| Secondary | 수행 변화 이해 | 완등시간, 시도 횟수 |
| Guardrail | 악화되면 안 되는 지표 | 통증 보고율 |

가드레일 지표는 **Primary Metric을 개선하는 과정에서 다른 중요한 결과가 악화되지 않았는지 확인하는 지표**이다.

```text
Primary 개선

        ↓

Guardrail 유지?

        ↓

YES
→ 적용 검토

NO
→ 추가 분석 필요
```

<br>

> ## **6-3 ) 가드레일 지표가 필요한 이유**

예를 들어 다음 결과가 있다고 하자.

```text
완등 성공률

55%
→
68%

+13%p
```

하지만 동시에

```text
손가락 통증 보고율

4%
→
11%

+7%p
```

라면 단순히

```text
성공률이 증가했으므로
새로운 훈련법이 더 좋다.
```

라고 결론 내리기 어렵다.

특히 스포츠·의료·재활 데이터에서는 수행 향상과 함께 **안전성, 통증, 부상 위험, 피로** 등의 지표를 함께 확인할 필요가 있다.

# **7. 분석 결과를 A/B 테스트와 의사결정으로 연결한다**

> ## **7-1 ) 조정 경기영상분석에서 문제를 발견했다고 가정한다**

조정 선수의 레이스 영상을 분석했다고 하자.

다음과 같은 현상이 나타났다.

```text
레이스 후반 500m

        ↓

스트로크 길이 감소

        ↓

캐치 시 몸통각 변화 증가

        ↓

보트 평균 속도 감소
```

현재 확인한 것은 **후반부에 특정 기술적 변화와 속도 감소가 함께 관찰되었다는 사실**이다.

원인까지 확인된 것은 아니다.

<br>

> ## **7-2 ) 문제를 개선 가설로 연결한다**

다음과 같은 가설을 만들 수 있다.

```text
관찰된 사실

후반 500m에서
캐치 자세 변동 증가

        ↓

원인 가설

피로 상황에서
캐치 자세를 유지하기 어려운 것이
속도 감소와 관련될 수 있다.

        ↓

개선안

후반부 피로 상황을 재현한 뒤
실시간 캐치각 피드백 제공
```

검증 가설은 다음과 같이 정리할 수 있다.

> 실시간 캐치각 피드백을 제공받은 선수는 기존 훈련 선수보다 피로 상황에서 캐치각 변동성이 감소할 것이다.

<br>

> ## **7-3 ) A/B 테스트 설계**

| 설계 요소 | 내용 |
| --- | --- |
| 실험 대상 | 동일 훈련 프로그램의 조정 선수 |
| Control | 기존 기술 코칭 |
| Treatment | 기존 코칭 + 실시간 캐치각 피드백 |
| Primary | 후반 500m 캐치각 변동성 |
| Secondary | 스트로크 길이, 평균 보트 속도 |
| Guardrail | RPE, 허리 통증 보고 |
| 배정 | 선수 단위 무작위 배정 |

```text
경기영상분석
        ↓
기술적 문제 발견
        ↓
가설 설정
        ↓
피드백 방법 설계
        ↓
선수 무작위 배정
        ↓
Control / Treatment
        ↓
훈련 시행
        ↓
Primary Metric 비교
        ↓
통계적 검정
        ↓
실질적 차이 확인
        ↓
Guardrail 확인
        ↓
훈련 프로그램 적용 여부 결정
```

<br>

> ## **7-4 ) 최종 의사결정 전에 확인해야 하는 것**

A/B 테스트 결과는 다음 순서로 해석할 수 있다.

```text
실험은 계획대로 진행되었는가?

        ↓

그룹 배정에 문제가 없는가?

        ↓

Primary Metric에
차이가 나타났는가?

        ↓

통계적 근거가 있는가?

        ↓

효과 크기는 얼마나 큰가?

        ↓

MDE보다 큰가?

        ↓

실제 경기 수행에서
의미 있는 변화인가?

        ↓

Guardrail은
악화되지 않았는가?

        ↓

적용 여부 판단
```

A/B 테스트의 최종 목적은 `p-value`를 작게 만드는 것이 아니라 **실험 결과를 근거로 실제 훈련·분석·중재 방법을 어떻게 결정할 것인지 판단하는 것**이다.

# **8. 연습문제**

> ## **8-1 ) 스쿼시 시선 피드백 A/B 테스트**

스쿼시 선수의 리턴 정확도를 높이기 위해 새로운 시선 위치 피드백을 실험한다.

```text
Control
기존 코치 피드백

Treatment
기존 피드백
+
볼 임팩트 직전 시선 위치 시각화
```

Primary Metric은

```text
목표 코트 영역 리턴 성공률
```

이다.

결과는 다음과 같다.

| 그룹 | 선수 수 | 기준 통과 선수 |
| --- | ---: | ---: |
| Control | 80 | 44 |
| Treatment | 80 | 56 |

### 문제

1. 각 그룹의 성공률을 계산하시오.
2. 절대 차이를 `%p`로 계산하시오.
3. Treatment 성공률이 높다는 사실만으로 새로운 피드백의 효과라고 단정할 수 있는가?
4. 어떤 추가 검정이 필요한가?

[ Result ]

```text
Control

44 / 80 × 100
= 55%


Treatment

56 / 80 × 100
= 70%


절대 차이

70% - 55%
= +15%p
```

Treatment에서 `15%p` 높은 성공률이 관찰되었다.

하지만 표본 변동 가능성이 있기 때문에 두 그룹 차이에 대한 **통계적 검정과 효과 크기 해석**이 추가로 필요하다.

<br>

> ## **8-2 ) 쇼트트랙 조기 종료 문제**

4주 실험을 계획했다.

하지만 첫 주 결과가 다음과 같았다.

```text
Control
10m 스타트
평균 2.18초

Treatment
10m 스타트
평균 2.05초
```

코치는 Treatment가 빠르므로 즉시 실험을 종료하려고 한다.

### 해석

이 경우 **조기 종료(Early Stopping)** 문제가 발생할 수 있다.

첫 주의 차이가

```text
실제 중재 효과

또는

우연한 주간 변동
```

중 무엇인지 충분히 판단하기 어렵다.

따라서 처음 계획한 표본과 기간에 따라 실험을 수행하는 것이 중요하다.

<br>

> ## **8-3 ) 볼링 실험에서 여러 요소를 동시에 변경한 경우**

다음과 같은 실험을 했다고 하자.

```text
Control

기존 투구 피드백


Treatment

새로운 궤적 피드백
+
새로운 볼
+
접근 스텝 변경
+
훈련량 증가
```

Treatment의 스트라이크율이 높아졌다.

하지만 이것만으로 **궤적 피드백이 효과적이었다고 판단하기 어렵다.**

여러 요소가 동시에 변경되었기 때문이다.

더 적절한 설계는 다음과 같다.

```text
Control

기존 훈련
+
기존 피드백


Treatment

기존 훈련
+
새로운 궤적 피드백
```

이렇게 해야 두 그룹의 핵심 차이가 **피드백 방법**이 되도록 만들 수 있다.

# **9. Advanced 추가 학습**

> ## **9-1 ) 무작위 배정과 무작위 표집은 다르다**

```text
Random Sampling

모집단에서
누구를 연구에 포함할 것인가?
```

```text
Random Assignment

연구에 들어온 사람을
어느 실험 그룹에 넣을 것인가?
```

A/B 테스트의 핵심은 일반적으로 **무작위 배정**이다.

<br>

> ## **9-2 ) 선수의 반복 시도를 독립 표본으로 착각하면 안 된다**

한 선수가 퍼팅을 50번 수행했다고 하자.

```text
선수 1명
×
퍼팅 50회

≠

독립 선수 50명
```

같은 선수의 반복 시도는 서로 관련될 수 있다.

따라서 실험의 배정 단위가 선수라면 분석에서도 **선수 내 반복 측정 구조**를 고려해야 한다.

간단한 교육용 예제에서는 선수별 성공률을 하나의 값으로 요약할 수 있고, 더 정교한 분석에서는 혼합효과모형 등 반복 측정을 고려한 방법을 사용할 수 있다.

<br>

> ## **9-3 ) p-value와 신뢰구간을 함께 볼 수 있다**

`p-value`는 통계적 판단에 도움을 주지만 **효과가 어느 범위에 있을 가능성이 있는지** 직접 보여주지는 않는다.

따라서 가능하면

```text
효과 크기

+

95% 신뢰구간

+

p-value
```

를 함께 해석하는 것이 좋다.

# **10. 핵심정리**

> ## **10-1 ) A/B 테스트의 목적**

A/B 테스트는

> **기존 방식과 새로운 방식을 비교하여 특정 변화가 목표 지표에 영향을 주는지 실험적으로 검증하는 방법**

이다.

```text
문제 발견
    ↓
가설
    ↓
개선안
    ↓
A/B 테스트
    ↓
효과 검증
```

<br>

> ## **10-2 ) 실험 설계의 핵심 요소**

| 요소 | 질문 |
| --- | --- |
| 검증 가설 | 무엇을 검증할 것인가? |
| Primary Metric | 어떤 지표가 변해야 하는가? |
| 실험 대상 | 누구에게 적용할 것인가? |
| Control | 기존 방식은 무엇인가? |
| Treatment | 어떤 새로운 변화를 줄 것인가? |
| Random Assignment | 어떻게 그룹을 나눌 것인가? |
| MDE | 최소 어느 정도 차이를 중요하게 볼 것인가? |
| 표본 크기 | 몇 명이 필요한가? |
| 실험 기간 | 얼마나 진행할 것인가? |

<br>

> ## **10-3 ) 실험 중 확인할 오류**

| 오류 | 핵심 문제 |
| --- | --- |
| Early Stopping | 결과가 좋아 보인다고 너무 빨리 종료 |
| Novelty Effect | 새 방법 자체에 대한 일시적 반응 |
| Sample Contamination | Control과 Treatment의 처치가 섞임 |
| SRM | 계획한 그룹 비율과 실제 표본 비율이 비정상적으로 다름 |

<br>

```text

        ↓

        ↓

        ↓

        ↓

MDE와 비교

        ↓

        ↓

        ↓

최종 의사결정
```

> ## **10-5 ) 통계적 유의성과 실질적 유의성**

```text
통계적 유의성
```

> 실험 과정의 오류를 점검하고,    
> 관찰된 차이의 통계적 근거와 실제 스포츠 현장에서의 의미를 함께 해석하여    
> 의사결정으로 연결하는 것이다.**
