# 02. 좋은 지표의 조건: KPI, 보조지표, 허무지표 구분

<br>

---


# **1. 모든 지표가 같은 중요도를 가지는 것은 아니다**

> ## **1-1 ) 측정할 수 있는 숫자가 많다고 모두 중요한 것은 아니다**

스포츠 분석 서비스에서도 다양한 지표를 확인할 수 있다.

예를 들어 여러 종목의 경기 영상을 분석해주는 서비스가 있다고 생각해보자.

| 지표 | 이번 달 |
| --- | ---: |
| 월간 방문 선수 수 | 10,000명 |
| 신규 가입 선수 수 | 2,500명 |
| 영상 업로드 수 | 18,000회 |
| Pose 분석 완료 선수 수 | 4,000명 |
| 유료 분석 이용 선수 수 | 1,200명 |
| SNS 영상 조회 수 | 500,000회 |

모두 서비스의 상태를 보여주는 숫자이지만 **모든 지표가 같은 중요도를 가지는 것은 아니다.**

예를 들어 현재 서비스의 목표가

```text
유료 Pose 분석을
사용하는 선수를 늘린다.
````

라면

```text
SNS 영상 조회 수
```

보다

```text
유료 분석 이용 선수 수

유료 전환율
```

이 목표 달성 여부와 더 직접적으로 연결된다.

따라서 지표를 선택하기 전에 가장 먼저 생각해야 하는 것은

> **현재 우리가 달성하려는 목표가 무엇인가?**

이다.

<br>

> ## **1-2 ) KPI Key Performance Indicator**

`KPI(Key Performance Indicator)`는 **핵심 목표가 어느 정도 달성되고 있는지를 판단하기 위해 중요하게 관리하는 핵심 성과 지표**이다.

기본적인 관계는 다음과 같다.

```text
목표 설정
        ↓
목표를 어떻게
숫자로 확인할 것인가?
        ↓
KPI 설정
```

스포츠 분야에서도 목표에 따라 KPI는 달라질 수 있다.

| 종목 / 서비스 | 목표                  | KPI 예시          |
| -------- | ------------------- | --------------- |
| 핸드볼      | Pose 슈팅 분석 기능 이용 증가 | 슈팅 분석 완료율       |
| 펜싱       | 훈련 분석 서비스 재사용 증가    | 30일 재분석률        |
| 양궁       | 자세 피드백 활용 증가        | 분석 후 피드백 저장률    |
| 테니스      | 유료 서브 분석 이용 증가      | 무료 → 유료 분석 전환율  |
| 배드민턴     | 풋워크 분석 기능 활성화       | 월간 풋워크 분석 선수 비율 |
| 수영       | 코치의 영상 분석 활용 증가     | 선수 영상 분석 완료 건수  |

즉,

```text
항상 같은 KPI
```

가 존재하는 것이 아니다.

```text
현재 목표
        ↓
적절한 KPI
```

가 결정된다.

<br>

> ## **1-3 ) 같은 지표도 목표에 따라 중요도가 달라진다**

예를 들어 `신규 가입 선수 수`를 생각해보자.

```text
목표
→ 새로운 선수 확보

신규 가입 선수 수
→ 중요한 KPI가 될 수 있음
```

하지만 목표가

```text
기존 선수가
서비스를 계속 이용하게 한다.
```

라면 신규 가입 선수 수만으로는 목표 달성 여부를 판단하기 어렵다.

이 경우에는

```text
7일 재방문율

30일 재분석률

두 번째 영상 업로드율
```

등이 더 직접적인 KPI가 될 수 있다.

따라서

> **지표의 중요도는 지표 이름 자체가 아니라 현재 목표와의 관계에 따라 달라진다.**

<br><br>

# **2. KPI · 보조 지표 · 허무 지표**

> ## **2-1 ) 세 가지 지표의 차이**

프로덕트 분석에서는 여러 지표의 역할을 다음과 같이 나눠 생각할 수 있다.

| 구분        | 의미                            | 핵심 질문                       |
| --------- | ----------------------------- | --------------------------- |
| **KPI**   | 핵심 목표 달성 여부를 판단하는 지표          | 목표를 달성하고 있는가?               |
| **보조 지표** | KPI가 변한 이유를 이해하는 데 도움을 주는 지표  | KPI가 왜 변했는가?                |
| **허무 지표** | 숫자는 좋아 보이지만 목표나 행동과 연결이 약한 지표 | 이 숫자가 좋아진 것이 실제로 무엇을 의미하는가? |

전체적인 관계는 다음과 같다.

```text
KPI
"목표를 달성하고 있는가?"
        ↓
보조 지표
"왜 KPI가 변했는가?"
        ↓
분석
        ↓
다음 행동 결정
```

반면 허무 지표는

```text
숫자는 증가함
        ↓
하지만
목표와의 연결이 불명확
        ↓
무엇을 개선해야 하는지도
알기 어려움
```

인 경우가 많다.

<br>

> ## **2-2 ) 핸드볼 예시**

핸드볼 Pose 분석 서비스의 목표가

```text
선수들이 슈팅 분석 기능을
실제로 사용하도록 만든다.
```

라고 하자.

다음과 같은 지표가 있다.

```text
서비스 방문 선수 수

영상 업로드 선수 수

슈팅 Pose 분석 실행 선수 수

분석 결과 확인 선수 수

SNS 슈팅 영상 조회 수
```

현재 목표에 대한 KPI를

```text
슈팅 분석 완료율

= 슈팅 분석 결과를 확인한 선수 수
  /
  영상을 업로드한 선수 수
  × 100
```

로 설정할 수 있다.

만약 KPI가 감소한다면 다음과 같은 보조 지표를 확인할 수 있다.

```text
영상 업로드 완료율

Pose 분석 실행률

분석 처리 성공률

분석 결과 화면 진입률
```

예를 들어

```text
영상 업로드
→ 정상

Pose 분석 실행
→ 정상

Pose 분석 성공
→ 정상

결과 화면 진입
→ 크게 감소
```

했다면 결과 화면으로 이동하는 과정의 문제를 우선적으로 살펴볼 수 있다.

반면

```text
SNS 슈팅 영상 조회 수
100만 회
```

가 되었더라도 실제 슈팅 분석 사용자가 늘지 않았다면 SNS 조회 수만으로 서비스가 성공했다고 판단하기 어렵다.

이 상황에서는 SNS 조회 수가 **허무 지표처럼 사용되고 있을 수 있다.**

<br>

> ## **2-3 ) 펜싱 예시**

펜싱 서비스의 목표가

```text
첫 런지 분석 이후
선수가 다시 서비스를 사용하도록 만든다.
```

라면 KPI를 다음과 같이 정의할 수 있다.

```text
30일 재분석률

= 첫 런지 분석을 완료한 선수 중
  30일 이내 새로운 런지 영상을
  다시 분석한 선수의 비율
```

예를 들어

```text
지난달
→ 55%

이번 달
→ 38%
```

로 감소했다면 보조 지표를 살펴본다.

```text
첫 분석 결과 확인률

피드백 저장률

분석 결과 공유율

7일 재방문율

두 번째 영상 업로드율
```

이를 통해

```text
왜 재분석률이 감소했는가?
```

를 더 구체적으로 탐색할 수 있다.

<br>

> ## **2-4 ) 양궁 예시**

양궁 분석 서비스의 목표가

```text
선수가 자세 분석 결과를
실제 훈련에 활용하게 한다.
```

라면 다음과 같이 생각할 수 있다.

```text
KPI

→ 자세 피드백 저장률
```

구체적으로

```text
자세 피드백 저장률

= 분석 결과를 확인한 선수 중
  어깨·팔꿈치 정렬 피드백을
  저장한 선수의 비율
```

보조 지표는

```text
70m 슈팅 영상 업로드율

Pose 분석 완료율

분석 결과 확인률

관절각도 그래프 조회율
```

등이 될 수 있다.

반면

```text
양궁 관련 SNS 게시물의
누적 노출 수
```

가 증가했지만 피드백 활용과 아무 관계가 없다면 현재 목표에서는 핵심적인 성과로 보기 어렵다.

<br>

> ## **2-5 ) 테니스 예시**

테니스 분석 서비스의 목표가

```text
무료 사용자를
유료 서브 분석 사용자로 전환한다.
```

라면 KPI는

```text
유료 서브 분석 전환율

= 무료 서브 분석을 사용한 선수 중
  유료 분석 기능을 결제한 선수의 비율
```

이 될 수 있다.

보조 지표로는

```text
서브 영상 업로드율

첫 서브 분석 완료율

관절각도 리포트 조회율

요금제 페이지 진입률

결제 화면 진입률
```

등을 확인할 수 있다.

예를 들어

```text
관절각도 리포트 조회
→ 정상

요금제 페이지 진입
→ 정상

결제 화면 진입
→ 크게 감소
```

한다면

```text
리포트 확인
        ↓
유료 기능 선택
```

과정을 추가로 살펴볼 수 있다.

<br>

> ## **2-6 ) 배드민턴 예시**

배드민턴 풋워크 분석 서비스에서

```text
목표
→ 풋워크 분석 기능의
   지속적인 사용 증가
```

라고 하자.

KPI는

```text
월간 풋워크 분석 활성 선수 비율
```

로 설정할 수 있다.

```text
월간 풋워크 분석 활성 선수 비율

= 한 달 동안
  풋워크 영상을 3회 이상 분석한 선수
  /
  월간 로그인 선수
  × 100
```

보조 지표는

```text
풋워크 영상 업로드율

이동경로 분석 실행률

셔틀 도달시간 결과 확인률

두 번째 분석 실행률
```

등으로 설정할 수 있다.

<br>

> ## **2-7 ) 허무 지표는 지표 자체의 이름으로 결정되지 않는다**

중요한 점은

```text
SNS 조회 수
= 무조건 허무 지표
```

가 아니라는 것이다.

예를 들어 목표가

```text
새로운 선수들에게
서비스를 알린다.
```

라면 SNS 콘텐츠 도달률이나 조회 수가 중요한 관련 지표가 될 수도 있다.

반대로 목표가

```text
유료 분석 사용자를 늘린다.
```

인데 SNS 조회 수만 증가한 것을 보고

```text
서비스가 성공적으로 성장하고 있다.
```

라고 판단한다면 허무 지표로 사용되고 있을 가능성이 있다.

따라서

> **어떤 지표가 KPI·보조 지표·허무 지표인지는 현재 목표와 그 지표를 어떻게 사용하는지에 따라 달라진다.**

<br><br>

# **3. 좋은 KPI는 어떻게 선택할까?**

> ## **3-1 ) 좋은 KPI의 세 가지 조건**

좋은 KPI를 선택할 때는 크게 다음 세 가지를 확인할 수 있다.

| 조건             | 확인할 질문                                |
| -------------- | ------------------------------------- |
| **목표와의 연결성**   | 이 지표가 좋아지면 우리가 원하는 목표도 실제로 좋아지는가?     |
| **명확한 측정 가능성** | 누구나 같은 기준으로 지속적으로 계산할 수 있는가?          |
| **행동 가능성**     | 지표가 변했을 때 원인을 분석하고 다음 행동으로 연결할 수 있는가? |

<br>

> ## **3-2 ) 목표와의 연결성 - 테니스 예시**

테니스 서비스의 목표가

```text
선수가 실제로
서브 자세 분석 기능을
반복해서 사용하게 한다.
```

라고 하자.

다음 두 지표 중 어느 것이 더 적절할까?

```text
A
테니스 관련 콘텐츠 조회 수

B
30일 이내 서브 재분석률
```

현재 목표에는 B가 더 직접적으로 연결된다.

```text
30일 서브 재분석률

= 첫 서브 분석을 완료한 선수 중
  30일 이내 새로운 서브 영상을
  다시 분석한 선수 비율
```

이 지표가 증가한다면

```text
선수들이 분석 기능을
한 번만 사용하는 것이 아니라
반복적으로 활용하고 있다.
```

는 목표와 직접 연결해 해석할 수 있다.

<br>

> ## **3-3 ) 명확한 측정 가능성 - 수영 예시**

수영 영상 분석 서비스에서

```text
활성 선수 수
```

를 KPI로 사용한다고 생각해보자.

하지만 팀마다 활성 선수의 의미가 다르면 문제가 발생한다.

```text
마케팅팀

→ 한 달에 한 번 이상
   서비스에 접속한 선수
```

```text
코칭팀

→ 한 달에 한 번 이상
   수영 영상을 업로드한 선수
```

```text
데이터팀

→ 한 달에 3회 이상
   영법 분석을 완료한 선수
```

같은

```text
활성 선수
```

라는 이름을 사용하지만 계산 결과가 서로 달라진다.

따라서 KPI를 구체적으로 정의해야 한다.

예를 들어

> **월간 활성 선수 = 해당 월에 자유형 또는 접영 영상을 3회 이상 업로드하고 Pose 분석 결과를 확인한 선수**

처럼 정의할 수 있다.

이제

```text
기간
→ 1개월

행동
→ 영상 업로드 + 분석 결과 확인

기준
→ 3회 이상
```

이 명확해진다.

<br>

> ## **3-4 ) 행동 가능성 Actionability - 양궁 예시**

좋은 KPI는 숫자를 확인하는 데서 끝나지 않고 **지표가 변했을 때 무엇을 분석하고 어떤 행동을 할지 연결할 수 있어야 한다.**

양궁 서비스의 KPI가

```text
분석 후 자세 피드백 저장률
```

이라고 하자.

지난달과 이번 달이

```text
지난달
→ 72%

이번 달
→ 51%
```

이라면 다음 질문으로 이어질 수 있다.

```text
분석 결과까지 정상적으로 도달했는가?

관절각도 그래프를 확인했는가?

피드백 작성 화면에 진입했는가?

저장 버튼까지 도달했는가?

특정 기기에서 저장 오류가 있었는가?
```

그리고

```text
KPI 감소
        ↓
관련 행동 데이터 분석
        ↓
문제가 발생한 단계 발견
        ↓
가설 설정
        ↓
개선
        ↓
A/B 테스트
```

와 같이 실제 행동으로 연결할 수 있다.

이러한 특성을 **행동 가능성(Actionability)**이라고 한다.

<br>

> ## **3-5 ) 누적 수치가 KPI로 주의가 필요한 이유**

예를 들어 스포츠 분석 서비스에서

```text
누적 가입 선수 수
```

가

```text
50,000명
→ 60,000명
```

으로 증가했다고 하자.

누적 지표는 일반적으로 시간이 지나면서 계속 증가하기 쉽다.

하지만

```text
현재 실제로 몇 명이 사용하는가?

가입한 선수가 분석 기능을 사용하는가?

사용자가 다시 돌아오는가?
```

는 알기 어렵다.

따라서

```text
누적 가입 선수 수
```

보다 목표에 따라

```text
월간 활성 선수 비율

가입 후 7일 이내
첫 분석 완료율

30일 재분석률
```

처럼 현재 사용자의 행동을 보여주는 지표가 더 행동 가능성이 높을 수 있다.

<br><br>

# **4. 종목별 KPI를 다양하게 설정해보기**

> ## **4-1 ) 핸드볼**

목표가

```text
Pose 기반 슈팅 분석 기능을
실제로 사용하게 한다.
```

라면

```text
KPI

슈팅 분석 완료율
```

구체적인 정의는

```text
슈팅 분석 완료율

= Pose 슈팅 분석 결과까지 확인한 선수 수
  /
  슈팅 영상을 업로드한 선수 수
  × 100
```

보조 지표는

```text
영상 업로드 성공률

Pose 분석 실행률

분석 처리 성공률

분석 결과 화면 진입률
```

등이다.

<br>

> ## **4-2 ) 펜싱**

목표가

```text
첫 분석 이후
훈련 과정에서 반복적으로
런지 분석을 사용하게 한다.
```

라면

```text
KPI

30일 런지 재분석률
```

```text
= 첫 런지 분석 완료 선수 중
  30일 이내 새로운 런지 영상을
  다시 분석한 선수의 비율
```

보조 지표는

```text
첫 분석 결과 확인률

관절각도 피드백 저장률

두 번째 영상 업로드율

7일 재방문율
```

등이다.

<br>

> ## **4-3 ) 양궁**

목표가

```text
Pose 분석 결과를
실제 자세 교정에 활용하게 한다.
```

라면 KPI를

```text
자세 피드백 활용률
```

로 정의할 수 있다.

```text
= 분석 결과를 확인한 선수 중
  어깨·팔꿈치 정렬 피드백을
  1개 이상 저장한 선수의 비율
```

보조 지표는

```text
70m 영상 분석 완료율

어깨 정렬 그래프 조회율

팔꿈치 각도 조회율

피드백 화면 진입률
```

등이다.

<br>

> ## **4-4 ) 테니스**

목표가

```text
무료 서브 분석 사용자를
유료 분석 사용자로 전환한다.
```

라면

```text
KPI

유료 서브 분석 전환율
```

```text
= 무료 서브 분석 완료 선수 중
  유료 분석 상품을 구매한 선수 비율
```

보조 지표는

```text
유료 리포트 미리보기 클릭률

요금제 페이지 진입률

결제 화면 진입률

결제 완료율
```

등이다.

<br>

> ## **4-5 ) 배드민턴**

목표가

```text
풋워크 분석 기능을
반복적으로 사용하게 한다.
```

라면 KPI를

```text
월간 풋워크 반복 분석률
```

로 설정할 수 있다.

```text
= 한 달 동안
  서로 다른 훈련 영상으로
  풋워크 분석을 3회 이상 완료한 선수
  /
  해당 월 풋워크 분석 선수
  × 100
```

보조 지표는

```text
이동경로 결과 확인률

셔틀 도달시간 결과 확인률

두 번째 풋워크 영상 업로드율

7일 재분석률
```

등이다.

<br>

> ## **4-6 ) 수영**

목표가

```text
코치가 영상 분석 리포트를
실제 선수 피드백에 활용하게 한다.
```

라면

```text
KPI

분석 리포트 코칭 활용률
```

로 설정할 수 있다.

```text
= 영법 분석 리포트를 확인한 코치 중
  피드백 메모를 저장하거나
  선수에게 리포트를 공유한 코치의 비율
```

보조 지표는

```text
영법 분석 완료율

스트로크 결과 조회율

리포트 공유 화면 진입률

피드백 메모 작성률
```

등이다.

# **5. KPI · 보조 지표 · 허무 지표 비교 실습**

> ## **5-1 ) 핸드볼 서비스 상황**

현재 목표는

```text
Pose 슈팅 분석 기능의
실제 사용을 증가시키는 것
```

이다.

다음 지표가 있다고 하자.

```text
① SNS 핸드볼 영상 조회 수

② 슈팅 영상 업로드 선수 수

③ Pose 분석 실행 선수 수

④ 분석 결과 확인 선수 수
```

현재 KPI를

```text
슈팅 분석 완료율
```

로 설정했다면

```text
④ 분석 결과 확인 선수 수
```

가 KPI 계산과 직접 연결된다.

②와 ③은 KPI 감소 원인을 살펴볼 수 있는 **보조 지표**가 될 수 있다.

①의 SNS 조회 수는 현재 목표와 실제 분석 이용의 관계를 확인하지 않은 채

```text
조회 수가 많이 늘었으므로
서비스가 성공했다.
```

라고 판단한다면 **허무 지표로 사용되고 있을 수 있다.**

<br>

> ## **5-2 ) 같은 SNS 조회 수도 항상 허무 지표는 아니다**

서비스의 목표가 바뀌었다고 생각해보자.

```text
기존 목표
→ Pose 분석 이용 증가
```

에서

```text
새로운 목표
→ 대학 선수들에게
   새로운 분석 서비스를 알린다.
```

로 바뀌었다면 SNS 콘텐츠 도달률이나 특정 대상의 콘텐츠 조회 수가 중요한 지표로 활용될 수 있다.

따라서

```text
지표 이름
        ↓
역할 결정
```

이 아니라

```text
현재 목표

+

지표의 사용 목적

+

다음 행동과의 연결

        ↓

KPI / 보조 / 허무 판단
```

으로 생각해야 한다.

<br><br>

# **6. 좋은 KPI를 판단하는 질문**

> ## **6-1 ) 목표와 연결되어 있는가?**

```text
이 지표가 좋아졌을 때
현재 우리가 달성하려는 목표도
실제로 좋아졌다고 볼 수 있는가?
```

예를 들어

```text
목표
→ 펜싱 선수의 반복 이용 증가

KPI
→ 30일 런지 재분석률
```

은 직접적으로 연결되어 있다.

<br>

> ## **6-2 ) 측정 기준이 명확한가? (명확한 측정 가능성)**

단순히

```text
활성 사용자
```

라고 하지 않는다.

예를 들어 배드민턴 서비스라면

```text
월간 활성 선수

= 해당 월에
  풋워크 영상을 3회 이상 분석하고
  분석 결과를 1회 이상 확인한 선수
```

처럼 계산 기준을 명확하게 정의한다.

<br>

> ## **6-3 ) 행동 가능성이 있는가?**

```text
KPI가 감소했다.
        ↓
왜 감소했는지 분석할 수 있는가?
        ↓
문제가 발생한 단계를 찾을 수 있는가?
        ↓
개선 가설을 만들 수 있는가?
        ↓
개선안을 검증할 수 있는가?
```

까지 연결되어야 한다.

예를 들어 테니스의

```text
유료 서브 분석 전환율
```

이 감소하면

```text
무료 분석 완료율

리포트 조회율

요금제 페이지 진입률

결제 화면 진입률

결제 완료율
```

을 차례로 분석하여 어느 단계에 문제가 있는지 찾아볼 수 있다.  
  
따라서 행동가능성은 **지표가 변했을 때 원인을 분석하고 다음 행동을 결정할 수 있는지 파악해야 한다**는 것이다.

# **7. Advanced 추가 학습**

> ## **7-1 ) KPI 하나만 보면 모든 것을 알 수 있는 것은 아니다**

KPI는 핵심 목표를 보여주지만 **KPI 하나만으로 원인을 설명할 수는 없다.**

예를 들어

```text
펜싱 30일 재분석률

55% → 38%
```

로 감소했다면

```text
왜 감소했는가?
```

를 알기 위해 보조 지표가 필요하다.

```text
첫 분석 결과 확인률

피드백 저장률

7일 재방문율

두 번째 영상 업로드율
```

등을 함께 본다.

즉,

```text
KPI
→ 무엇이 변했는가?

보조 지표
→ 어디에서 변화가 발생했는가?
```

로 연결할 수 있다.

<br>

> ## **7-2 ) KPI가 좋아져도 다른 문제가 생길 수 있다**

예를 들어 핸드볼 분석 서비스의 KPI가

```text
분석 완료율
```

이라고 하자.

분석 완료율을 높이기 위해 분석 단계를 지나치게 단순화했더니

```text
분석 완료율
↑

하지만

결과 정확성 만족도
↓
```

가 될 수도 있다.

따라서 주요 KPI와 함께 **중요한 품질 지표나 Guardrail Metric**을 확인할 수 있다.

```text
Primary KPI

→ 분석 완료율


Guardrail Metric

→ 분석 결과 오류율

→ 결과 만족도

→ 재사용률
```

<br>

> ## **7-3 ) KPI의 평균만 보지 말고 세그먼트도 확인한다**

전체 KPI가 동일하더라도 종목별 상황은 다를 수 있다.

```text
전체 30일 재분석률

50% → 50%
```

하지만 종목별로 보면

```text
핸드볼
55% → 62%

양궁
50% → 53%

펜싱
58% → 35%

테니스
45% → 49%
```

일 수 있다.

전체 평균만 보면 변화가 없어 보이지만 **펜싱 사용자에서 문제가 발생**하고 있다.

따라서 필요에 따라

```text
종목

선수 / 코치

신규 / 기존

무료 / 유료

모바일 / 웹
```

등으로 나누어 살펴볼 수 있다.

<br><br>

# **8. 핵심정리**

> ## **8-1 ) KPI**

KPI는

> **현재 서비스나 프로젝트의 핵심 목표가 어느 정도 달성되고 있는지를 판단하기 위해 중요하게 관리하는 지표**

이다.

```text
목표
        ↓
목표를 무엇으로 측정할까?
        ↓
KPI
```

따라서 항상 같은 지표가 KPI가 되는 것은 아니다.

<br>

> ## **8-2 ) KPI · 보조 지표 · 허무 지표**

| 구분    | 핵심 역할                      |
| ----- | -------------------------- |
| KPI   | 목표 달성 여부를 판단               |
| 보조 지표 | KPI가 변한 원인을 이해             |
| 허무 지표 | 숫자는 좋아 보이지만 목표·행동과의 연결이 약함 |

다음과 같이 기억할 수 있다.

```text
KPI
→ 목표가 좋아지고 있는가?

보조 지표
→ 왜 KPI가 변했는가?

허무 지표
→ 이 숫자가 커진 것이
   실제로 어떤 의미가 있는가?
```

<br>

> ## **8-3 ) 허무 지표는 고정되어 있지 않다**

```text
SNS 조회 수
앱 다운로드 수
누적 가입자 수
```

등이 항상 허무 지표인 것은 아니다.

```text
현재 목표와 직접 연결되는가?

분석에 활용할 수 있는가?

다음 행동을 결정할 수 있는가?
```

에 따라 지표의 역할이 달라진다.

<br>

> ## **8-4 ) 좋은 KPI의 세 가지 조건**

```text
좋은 KPI

① 목표와의 연결성
        +
② 명확한 측정 가능성
        +
③ 행동 가능성
```

### 목표와의 연결성

```text
이 지표가 좋아지면
우리가 달성하려는 목표도
실제로 좋아지는가?
```

### 명확한 측정 가능성

```text
누가 계산하더라도
같은 기준으로 계산할 수 있는가?
```

### 행동 가능성

```text
지표가 변했을 때

왜 변했는지 분석하고

문제를 발견하고

다음 행동을 결정할 수 있는가?
```

<br>

> ## **8-5 ) 종목별 KPI 예시**

| 종목   | 목표             | KPI 예시        |
| ---- | -------------- | ------------- |
| 핸드볼  | 슈팅 분석 기능 활용 증가 | 슈팅 분석 완료율     |
| 펜싱   | 반복적인 런지 분석 이용  | 30일 런지 재분석률   |
| 양궁   | 자세 피드백 활용 증가   | 자세 피드백 저장률    |
| 테니스  | 유료 서브 분석 전환    | 유료 분석 전환율     |
| 배드민턴 | 풋워크 분석 반복 사용   | 월간 풋워크 반복 분석률 |
| 수영   | 코칭 리포트 활용 증가   | 분석 리포트 코칭 활용률 |

<br>

> ## **8-6 ) 가장 중요한 전체 흐름**

```text
현재 목표가 무엇인가?
        ↓
그 목표를 어떤 숫자로
확인할 수 있는가?
        ↓
KPI 설정
        ↓
KPI 변화 확인
        ↓
왜 변했는가?
        ↓
보조 지표 분석
        ↓
문제 발생 구간 발견
        ↓
가설 설정
        ↓
개선 또는 실험
        ↓
KPI가 실제로 개선되었는가?
        ↓
의사결정
```

**한 문장으로 정리하면**

> **좋은 KPI는 단순히 숫자가 크거나 측정하기 쉬운 지표가 아니라 현재의 핵심 목표와 직접 연결되고, 누구나 같은 기준으로 지속적으로 측정할 수 있으며, 지표가 변했을 때 원인을 분석해 실제 개선 행동으로 연결할 수 있는 지표이다.**
