# **1. 이벤트 로그 기반 분석**

> ## **1-1 ) 이벤트 로그란?**

`이벤트 로그(Event Log)`는 **특정 대상이 어떤 행동을 언제 수행했는지 시간 순서대로 기록한 데이터**이다.

일반적인 프로덕트 분석에서는 다음과 같이 기록한다.

```text
사용자
+
행동
+
발생 시간
```

예를 들어

```text
사용자 U001
10:03 서비스 방문
10:05 상품 조회
10:08 장바구니 추가
10:12 구매
```

와 같은 형태이다.

스포츠과학에서도 동일한 구조를 사용할 수 있다.

예를 들어 핸드볼 경기영상에서는 다음과 같은 경기 행동을 이벤트로 정의할 수 있다.

```text
선수 H012
19:32:10 공격권 획득
19:32:14 9m 공격 진입
19:32:17 점프슛
19:32:17 유효 슈팅
19:32:17 득점
```

따라서 스포츠 이벤트 로그는 단순히

```text
무슨 행동이 발생했는가?
```

만 기록하는 것이 아니라

```text
누가?

언제?

어떤 경기에서?

어떤 공격 상황에서?

어떤 행동을 수행했는가?
```

를 함께 기록할 수 있다.

<br>

> ## **1-2 ) 경기영상과 운동역학 데이터를 함께 기록할 수 있다**

경기 이벤트와 Pose Estimation 또는 Motion Capture 데이터를 연결하면 경기 상황과 운동역학 변수를 함께 분석할 수 있다.

예를 들어 하나의 점프슛 이벤트에 다음과 같은 정보를 저장할 수 있다.

| 컬럼 | 의미 | 예시 |
| --- | --- | --- |
| `athlete_id` | 선수 ID | H012 |
| `match_id` | 경기 ID | M03 |
| `possession_id` | 공격권 ID | P104 |
| `event_time` | 행동 발생 시간 | 19:32:17 |
| `event_name` | 경기 행동 | jump_shot |
| `position` | 포지션 | LB |
| `phase` | 경기 구간 | second_half |
| `pressure_level` | 수비 압박 수준 | high |
| `shot_zone` | 슈팅 위치 | left_9m |
| `release_speed` | 공 릴리스 속도 | 24.8 m/s |
| `release_height` | 공 릴리스 높이 | 2.31 m |
| `knee_angle` | 무릎 굴곡각 | 71.2° |
| `trunk_angle` | 몸통 회전각 | 47.3° |
| `trunk_ang_vel` | 몸통 회전 각속도 | 842 °/s |
| `jump_height` | 점프 높이 | 0.54 m |
| `is_goal` | 득점 여부 | True |

이렇게 구성하면

```text
경기 행동

+

경기 상황

+

운동역학
```

을 하나의 분석 흐름으로 연결할 수 있다.

<br>

> ## **1-3 ) 이벤트 수와 선수 수는 서로 다르다**

한 선수가 경기에서 점프슛을 8회 수행했다고 하자.

```text
점프슛 이벤트 수
→ 8건

점프슛을 수행한 선수 수
→ 1명
```

따라서 다음을 구분해야 한다.

| 구분 | 의미 |
| --- | --- |
| `event_count` | 행동이 총 몇 번 발생했는가? |
| `unique_athletes` | 해당 행동을 수행한 선수가 몇 명인가? |

예를 들어

```text
점프슛 210회

≠

선수 210명
```

이다.

같은 선수에게 여러 번의 슈팅이 반복적으로 측정될 수 있기 때문이다.

<br>

> ## **1-4 ) 전체 분석 흐름**

이번 분석에서는 AARRR, Funnel, Retention, Cohort, Segmentation을 각각 따로 사용하는 것이 아니라 하나의 분석 흐름으로 연결한다.

```text
문제 정의
        ↓
이벤트 로그 확인
        ↓
분석 질문 설정
        ↓
AARRR
전체 행동 영역 확인
        ↓
Funnel
세부 경기 행동 과정 확인
        ↓
Retention / Cohort
시간에 따른 유지 패턴 확인
        ↓
Segmentation
선수·포지션·경기 상황 비교
        ↓
운동역학 변수 분석
        ↓
문제 구체화
        ↓
관찰된 사실과 가설 구분
        ↓
훈련·전술 개선 가설
        ↓
실험 및 검증
```

핵심은

```text
분석 질문
→ 데이터 집계
→ 지표 계산
→ 시각화
→ 결과 해석
→ 다음 분석 질문
```

의 흐름을 반복하는 것이다.

# **2. 분석 질문과 기준을 먼저 설정한다**

> ## **2-1 ) 데이터를 바로 집계하지 않는다**

이벤트 로그가 있다고 바로 그래프를 그리는 것이 아니다.

먼저

```text
무엇을 알고 싶은가?
```

를 정의해야 한다.

이번 핸드볼 경기영상 분석의 문제를 다음과 같이 설정한다고 하자.

> **후반 고압박 상황에서 백코트 선수의 점프슛 득점률이 낮아지는가? 그렇다면 어떤 경기 행동과 운동역학적 특징이 함께 나타나는가?**

이를 한 번에 분석하지 않고 질문을 단계적으로 나눈다.

```text
전체적으로 어떤 행동이 나타나는가?
        ↓
공격 과정의 어느 구간에서 연결이 감소하는가?
        ↓
시간이 지나도 특정 수행 패턴이 유지되는가?
        ↓
어떤 선수·포지션·경기상황에서 차이가 큰가?
        ↓
그 상황에서 어떤 운동역학 변수가 함께 변하는가?
```

<br>

> ## **2-2 ) 분석 방법마다 질문이 다르다**

| 분석 방법 | 원래 사용자행동 분석의 질문 | 스포츠 경기·운동역학 적용 질문 |
| --- | --- | --- |
| AARRR | 서비스 전체의 어느 영역을 살펴볼 것인가? | 영상분석 서비스의 어느 이용 행동을 살펴볼 것인가? |
| Funnel | 목표 행동까지 어디에서 이탈하는가? | 공격이 득점까지 연결되는 어느 단계에서 끊기는가? |
| Retention | 시간이 지나도 다시 행동하는가? | 교정된 기술 또는 분석 행동이 시간이 지나도 유지되는가? |
| Cohort | 시작 시기에 따라 유지 패턴이 다른가? | 훈련 시작 시기에 따라 기술 유지 패턴이 다른가? |
| Segmentation | 어떤 사용자 집단에서 차이가 나타나는가? | 어떤 포지션·상황·선수 집단에서 차이가 나타나는가? |

모든 분석을 기계적으로 수행하는 것이 아니라 **현재 질문에 필요한 분석을 선택**해야 한다.

# **3. AARRR로 스포츠 영상분석 서비스의 전체 행동을 진단한다**

> ## **3-1 ) AARRR의 이론적 의미**

AARRR은 사용자 행동을 다음 5개의 영역으로 나누어 살펴보는 프레임워크이다.

```text
Acquisition
Activation
Retention
Revenue
Referral
```

각 영역은 고정된 이벤트 이름이 아니다.

서비스에서

```text
어떤 행동을
각 영역의 대표 행동으로 정의하는가?
```

에 따라 달라진다.

예를 들어 일반 서비스와 스포츠 영상분석 서비스를 비교하면 다음과 같다.

| AARRR | 일반 서비스 | 스포츠 영상분석 서비스 |
| --- | --- | --- |
| Acquisition | 최초 서비스 방문 | 최초 영상분석 시스템 접속 |
| Activation | 첫 핵심 기능 사용 | 첫 생체역학 리포트 확인 |
| Retention | 일정 기간 후 재방문 | Day 7 경기 재분석 |
| Revenue | 유료 구매 | 고급 분석 플랜 이용 |
| Referral | 서비스 공유 | 코치·팀원에게 분석 리포트 공유 |

중요한 것은 AARRR을 반드시

```text
Acquisition
↓
Activation
↓
Retention
↓
Revenue
↓
Referral
```

의 하나의 퍼널처럼 계산하는 것이 아니라는 점이다.

각 영역이 측정하는 행동과 목적이 서로 다르다.

<br>

> ## **3-2 ) AARRR 이벤트 정의**

이번 예제에서는 다음과 같이 정의한다.

```text
open_analysis
→ 분석 플랫폼 접속

view_biomech_report
→ 첫 생체역학 리포트 확인

Day 7 open_analysis
→ 7일 후 다시 분석

subscribe
→ 고급 분석 플랜 이용

share_report
→ 코치 또는 팀원에게 리포트 공유
```

<br>

> ## **3-3 ) AARRR 영역별 선수 수 계산**

```python
# Acquisition
acquisition = df.loc[

activation = df.loc[

```

> ## **3-4 ) Day 7 Retention 계산**

Retention은 단순히 특정 이벤트가 발생했는지만 보는 것이 아니라 **기준 시점 이후 일정 시간이 지난 뒤 다시 행동했는지**를 확인한다.

[Python : code] "최초 영상분석 이후 Day 7에 다시 분석한 선수 수 계산"

```python
analysis_df = df[
    df["event_name"] == "open_analysis"
].copy()

analysis_df["event_date"] = (
    analysis_df["event_time"]
    .dt.normalize()
)

first_analysis = (
    analysis_df
    .groupby("athlete_id")["event_date"]
    .min()
)

analysis_df["first_analysis_date"] = (
    analysis_df["athlete_id"]
    .map(first_analysis)
)

analysis_df["days_after_first"] = (
    analysis_df["event_date"]
    -
    analysis_df["first_analysis_date"]
).dt.days

retention = analysis_df.loc[
    analysis_df["days_after_first"] == 7,
    "athlete_id"
].nunique()

print(
    "Day 7 Retention Users :",
    retention
)
```

[ Result ]

```text
Day 7 Retention Users : 38
```

Retention Rate 공식은 다음과 같다.

```text
Retention Rate (%)

=

특정 시점에 다시 행동한 선수 수
────────────────────────
최초 선수 수

× 100
```
해석을 해보면

```text
처음 행동을 시작한 선수 중에서

일정 시간이 지난 뒤에도
같은 행동을 다시 한 선수가

전체의 몇 %인지를 계산한다.
```

이번 예제에서는

```text
Day 7 Retention

= 38 / 120 × 100

≈ 31.7%
```

이다.

### 해석

```text
처음 영상분석 서비스를 사용한 선수
120명 중

7일 뒤 다시 사용한 선수가
38명이다.

따라서 처음 사용자의 약 31.7%가
Day 7에도 서비스를 다시 사용했다.
```

<br>

> ## **3-5 ) AARRR 전체 결과 정리**

[Python : code] "AARRR 영역별 선수 수와 비율 계산"

```python
activation_rate = (
    activation / acquisition * 100
)

retention_rate = (
    retention / acquisition * 100
)

revenue_rate = (
    revenue / acquisition * 100
)

referral_rate = (
    referral / acquisition * 100
)

aarrr_summary = pd.DataFrame({
    "AARRR": [
        "Acquisition",
        "Activation",
        "Retention",
        "Revenue",
        "Referral"
    ],
    "athletes": [
        acquisition,
        activation,
        retention,
        revenue,
        referral
    ],
    "rate": [
        100,
        activation_rate,
        retention_rate,
        revenue_rate,
        referral_rate
    ]
})

aarrr_summary["rate"] = (
    aarrr_summary["rate"].round(1)
)

print(aarrr_summary)
```

[ Result ]

```text
         AARRR  athletes   rate
0  Acquisition       120  100.0
1   Activation        96   80.0
2    Retention        38   31.7
3      Revenue        30   25.0
4     Referral        18   15.0
```

여기서

```text
Referral이 15%로
가장 낮다.

→ Referral이 가장 큰 문제다.
```

라고 단정하면 안 된다.

AARRR은 서로 다른 행동을 측정하기 때문이다.

현재 서비스의 목표나 기존 기준과 비교하여 추가로 확인할 영역을 선택해야 한다.

# **4. Funnel 분석으로 핸드볼 공격 과정의 문제 구간을 찾는다**

> ## **4-1 ) Funnel의 이론적 의미**

Funnel은 목표 행동에 도달하기까지의 과정을 여러 단계로 나누고 **어느 단계에서 다음 단계로 이어지지 않는지** 확인하는 분석이다.

일반 서비스에서는

```text
방문
↓
상품 조회
↓
장바구니
↓
결제 시작
↓
구매
```

와 같이 정의할 수 있다.

경기분석에서는 공격 행동의 연결 과정을 Funnel로 응용할 수 있다.

```text
공격권 획득
        ↓
9m 공격 진입
        ↓
점프슛
        ↓
유효 슈팅
        ↓
득점
```

이번 Funnel의 목표 행동은

```text
Goal
득점
```

이다.

<br>

> ## **4-2 ) 전환율과 이탈률의 의미**

전환율 공식은 다음과 같다.

```text
전환율 (%)

=

다음 단계까지 이어진 이벤트 수
──────────────────────
현재 단계의 이벤트 수

× 100
```

### 
### 해석
```text
현재 단계까지 도달한 공격 중

몇 %가 다음 행동까지
이어졌는지를 계산한다.
```

예를 들어 9m 공격 진입이 `360회`이고 점프슛까지 이어진 공격이 `210회`라면

```text
전환율

= 210 / 360 × 100

= 58.3%
```

이다.

즉,

> **9m 지역까지 진입한 공격 중 58.3%가 점프슛까지 이어졌다.**

이탈률은

```text
이탈률 (%)

=

100
-
전환율
```

이다.

### 해석

```text
현재 단계에는 도달했지만

다음 단계까지 이어지지 않은 공격이
몇 %인지를 계산한다.
```

전환율이 `58.3%`라면

```text
이탈률

= 100 - 58.3

= 41.7%
```

이다.

즉,

> **9m 공격 진입의 41.7%는 점프슛까지 이어지지 않았다.**

<br>

> ## **4-3 ) 핸드볼 공격 Funnel 계산**

각 단계의 이벤트 수가 다음과 같다고 하자.

```text
공격권 획득
520회

9m 공격 진입
360회

점프슛
210회

유효 슈팅
144회

득점
72회
```

직접 계산하면 다음과 같다.

```text
공격권 → 9m 진입

360 / 520 × 100

= 69.2%
```

### 의미

```text
전체 공격권 520회 중
360회가 9m 공격 진입까지 발전했다.
```

```text
9m 진입 → 점프슛

210 / 360 × 100

= 58.3%
```

### 의미

```text
9m 지역에 진입한 공격 360회 중
210회가 점프슛까지 연결되었다.
```

```text
점프슛 → 유효 슈팅

144 / 210 × 100

= 68.6%
```

### 의미

```text
점프슛 210회 중
144회가 골문 안쪽으로 향했다.
```

```text
유효 슈팅 → 득점

72 / 144 × 100

= 50.0%
```

### 의미

```text
유효 슈팅 144회 중
72회가 실제 득점으로 연결되었다.
```

[ Result ]

| 구간 | 전환율 | 이탈률 |
| --- | ---: | ---: |
| 공격권 → 9m 진입 | 69.2% | 30.8% |
| 9m 진입 → 점프슛 | 58.3% | 41.7% |
| 점프슛 → 유효 슈팅 | 68.6% | 31.4% |
| 유효 슈팅 → 득점 | 50.0% | 50.0% |

가장 높은 이탈률은

```text
유효 슈팅
        ↓
득점

50.0%
```

이다.

하지만 이 결과는

```text
슈팅 기술이 부족하다.
```

라는 원인을 의미하지 않는다.

현재 확인한 것은

> **유효 슈팅이 실제 득점으로 이어지지 않은 비율이 다른 구간보다 높았다는 사실**

이다.

<br>

> ## **4-4 ) Python으로 Funnel 계산**

[Python : code] "핸드볼 공격 단계별 전환율과 이탈률 계산"

```python
funnel_events = [
    "possession_start",
    "nine_meter_entry",
    "jump_shot",
    "shot_on_target",
    "goal"
]

funnel_count = (
    df[
        df["event_name"]
        .isin(funnel_events)
    ]
    ["event_name"]
    .value_counts()
    .reindex(funnel_events)
)

funnel_summary = pd.DataFrame({
    "event_name": funnel_events,
    "events": funnel_count.values
})

funnel_summary[
    "conversion_rate"
] = (
    funnel_summary["events"]
    /
    funnel_summary["events"].shift(1)
    *
    100
)

funnel_summary.loc[
    0,
    "conversion_rate"
] = 100

funnel_summary[
    "dropoff_rate"
] = (
    100
    -
    funnel_summary[
        "conversion_rate"
    ]
)

funnel_summary[
    "conversion_rate"
] = (
    funnel_summary[
        "conversion_rate"
    ].round(1)
)

funnel_summary[
    "dropoff_rate"
] = (
    funnel_summary[
        "dropoff_rate"
    ].round(1)
)

print(
    funnel_summary
)
```

[ Result ]

```text
          event_name  events  conversion_rate  dropoff_rate
0   possession_start     520            100.0           0.0
1  nine_meter_entry     360             69.2          30.8
2          jump_shot     210             58.3          41.7
3     shot_on_target     144             68.6          31.4
4               goal      72             50.0          50.0
```

> ## **4-6 ) 실제 경기 Funnel에서는 순서까지 확인해야 한다**

단순히 이벤트 횟수만 비교하면 실제 Funnel을 잘못 계산할 수 있다.

예를 들어 한 선수가 첫 번째 공격에서

```text
jump_shot
```

을 수행하고 다른 공격에서

```text
nine_meter_entry
```

를 수행했다면 두 이벤트는 같은 공격 흐름이 아니다.

따라서 실제 분석에서는

```text
match_id
+
possession_id
+
event_time
```

을 함께 사용해야 한다.

즉,

```text
같은 경기
        ↓
같은 공격권
        ↓
9m Entry
        ↓
Jump Shot
        ↓
Shot on Target
        ↓
Goal
```

순서를 실제로 만족한 공격만 Funnel 전환으로 계산하는 것이 더 정확하다.

Funnel 분석 이후 다음 질문은

> **득점으로 이어지지 않은 유효 슈팅은 어떤 선수와 경기상황에서 많이 나타나는가?**

이다.

# **5. Retention과 Cohort로 시간에 따른 기술 유지 패턴을 분석한다**

> ## **5-1 ) Retention의 이론적 의미**

Retention은 기준 행동을 수행한 대상이 **시간이 지나도 그 행동을 다시 수행하는지** 확인하는 분석이다.

일반 서비스에서는

```text
Day 0
서비스 최초 사용
        ↓
Day 1
재방문
        ↓
Day 7
재방문
        ↓
Day 14
재방문
```

과 같이 사용한다.

스포츠과학에서는 이를 다음과 같이 확장할 수 있다.

```text
Day 0
교정된 기술 획득
        ↓
Day 7
기술 유지
        ↓
Day 14
기술 유지
        ↓
Day 30
기술 유지
```

즉, Retention은 반드시 웹서비스의 재방문만 의미하는 것이 아니다.

**분석 목적에 따라 정의한 행동의 지속성**을 확인하는 개념이다.

<br>

> ## **5-2 ) 점프슛 Target Mechanics 정의**

핸드볼 선수에게 운동역학적 점프슛 피드백을 제공했다고 하자.

목표 동작을 다음과 같이 정의한다.

```text
릴리스 직전 무릎 굴곡각
≥ 65°

        +

몸통 Peak Angular Velocity
≥ 800 °/s

        +

Release Height
≥ 2.25 m
```

세 조건을 모두 만족하면

```text
Target Mechanics
```

를 수행한 것으로 정의한다.

여기서 기준값은 예시이며 실제 연구에서는 종목 특성, 선수 수준, 측정 방법, 선행연구 등을 근거로 정의해야 한다.

<br>

> ## **5-3 ) Retention Rate 공식**

```text
Retention Rate (%)

=

특정 시점에도 목표 행동을 유지한 선수 수
────────────────────────────
Day 0에서 목표 행동을 수행한 선수 수

× 100
```

### 해석

```text
처음 목표 기술을 획득했던 선수 중

시간이 지난 뒤에도
그 기술을 유지하고 있는 선수가

전체의 몇 %인지를 계산한다.
```

예를 들어

```text
Day 0
60명

Day 7
45명

Day 14
36명

Day 30
30명
```

이라면

```text
Day 7

45 / 60 × 100

= 75%
```

### 해석

```text
처음 목표 기술을 수행했던 60명 중
7일 후에도 기술을 유지한 선수가 45명이다.

따라서 Day 7 기술 Retention은 75%이다.
```

```text
Day 14

36 / 60 × 100

= 60%
```

```text
Day 30

30 / 60 × 100

= 50%
```

[ Result ]

| 시점 | 목표 동작 유지 선수 | Retention |
| --- | ---: | ---: |
| Day 0 | 60 | 100% |
| Day 7 | 45 | 75% |
| Day 14 | 36 | 60% |
| Day 30 | 30 | 50% |

중요한 것은 Day 30을

```text
30 / 36
```

으로 계산하는 것이 아니라 최초 Cohort인

```text
30 / 60
```

으로 계산한다는 것이다.

<br>

> ## **5-4 ) Python으로 Retention 계산**


> ## **5-6 ) Cohort의 이론적 의미**

Cohort는 **공통된 시작 시점이나 특성을 가진 집단**이다.

예를 들어 운동역학 피드백 시작 주차를 기준으로 다음처럼 나눌 수 있다.

```text
8월 1주
→ Cohort A

8월 2주
→ Cohort B

8월 3주
→ Cohort C

8월 4주
→ Cohort D
```

각 Cohort의 Retention은 다음과 같다.

| Cohort | Day 0 | Day 7 | Day 14 | Day 30 |
| --- | ---: | ---: | ---: | ---: |
| 8월 1주 | 100% | 80% | 68% | 60% |
| 8월 2주 | 100% | 82% | 70% | 62% |
| 8월 3주 | 100% | 79% | 67% | 58% |
| 8월 4주 | 100% | 65% | 48% | 36% |

현재 데이터에서 확인할 수 있는 사실은

> **8월 4주에 프로그램을 시작한 선수의 기술 유지율이 이전 Cohort보다 낮게 나타났다.**

이다.

다음은 아직 가설이다.

```text
코치가 변경되었기 때문이다.

경기 일정이 많아졌기 때문이다.

훈련 빈도가 감소했기 때문이다.
```

<br>

# **6. Segmentation으로 어떤 선수와 상황에서 차이가 나타나는지 확인한다**

> ## **6-1 ) Segmentation의 이론적 의미**

Segmentation은 전체 데이터를 하나로만 보지 않고 **공통된 특성을 가진 여러 집단으로 나누어 동일한 지표를 비교하는 방법**이다.

예를 들어 전체 점프슛 득점률이

```text
53%
```

라고 해도 모든 상황이 같은 것은 아니다.

다음처럼 나눌 수 있다.

```text
포지션별

전반 / 후반

수비 압박 수준

슈팅 구역

경기 점수 차

선수 수준

피로 상태
```

세그멘테이션의 핵심 질문은

```text
전체적으로 어떤가?
```

에서

```text
어떤 선수에게?

어떤 상황에서?

언제?

어떤 조건에서?
```

로 문제를 구체화하는 것이다.

<br>

> ## **6-2 ) 포지션별 점프슛 분석**

[Python : code] "포지션별 점프슛 득점률과 운동역학 변수 비교"

```python
jump_df = df[
    df["event_name"]
    == "jump_shot"
].copy()

position_summary = (
```

# **7. 운동역학 변수와 공식을 이해한다**

> ## **7-1 ) Scalar와 Vector의 차이**

운동역학에서는 수치를 크게 `Scalar`와 `Vector`로 구분한다.

| 구분 | 의미 | 예시 |
| --- | --- | --- |
| Scalar | 크기만 존재 | 시간, 질량, 속력, 회전수 |
| Vector | 크기와 방향이 함께 존재 | 속도, 힘, 가속도 |

예를 들어

```text
속력
8 m/s
```

은 선수의 이동이 얼마나 빠른지만 알려준다.

반면 속도 Vector는

```text
v = [vx, vy, vz]
```

처럼 표현할 수 있다.

### 기호 뜻

```text
vx
→ X축 방향 속도

vy
→ Y축 방향 속도

vz
→ Z축 방향 속도
```
 해석하면

> **선수가 얼마나 빠르게 움직이는지뿐 아니라 어느 방향으로 움직이는지도 함께 표현한다.**

Vector의 전체 크기는 다음과 같이 계산할 수 있다.

```text
|v|

=

√(vx² + vy² + vz²)
```

### 해석

```text
X 방향 속도
+
Y 방향 속도
+
Z 방향 속도

세 방향의 움직임을 합쳐

전체 이동 속도의 크기를 계산한다.
```

<br>

> ## **7-2 ) 관절각 Joint Angle**

관절각은 신체 분절 사이의 자세를 각도로 표현한 것이다.

예를 들어 무릎각을

```text
Hip
  \
   Knee
     \
      Ankle
```

세 점으로 계산할 수 있다.

Hip-Knee-Ankle 내부각을 사용하면 완전 신전 상태가 약

```text
180°
```

이다.

반면 무릎 굴곡각 convention을 사용하면 완전 신전을

```text
0°
```

로 정의할 수 있다.

따라서 단순한 경우

```text
무릎 굴곡각

=

180°
-
Hip-Knee-Ankle 내부각
```

로 변환할 수 있다.

예를 들어 내부각이

```text
120°
```

라면

```text
무릎 굴곡각

= 180° - 120°

= 60°
```

이다.

### 해석

```text
무릎을 완전히 편 상태를 기준으로

현재 얼마나 굽혀져 있는지를
계산한 값이다.
```

즉, `60°`라면 완전 신전 위치에서 무릎이 약 `60°` 굴곡되어 있다는 의미이다.

<br>

> ## **7-3 ) 각속도 Angular Velocity**

관절 또는 신체 분절이 얼마나 빠르게 회전하는지를 나타내는 값이 각속도이다.

기호는 보통

```text
ω
```

를 사용한다.

평균 각속도는 다음과 같이 계산할 수 있다.

```text
ω

=

Δθ
───
Δt
```

### 기호 뜻

| 기호 | 의미 |
| --- | --- |
| `ω` | 각속도 |
| `θ` | 각도 |
| `Δθ` | 각도의 변화량 |
| `t` | 시간 |
| `Δt` | 시간의 변화량 |
| `Δ` | 두 값 사이의 변화량 |

### 해석

```text
각도가 얼마나 변했는가
────────────────
그 변화가 일어난 시간

=

얼마나 빠르게 회전했는가
```

예를 들어 몸통 회전각이

```text
0.00초
15°

0.05초
37°
```

로 변했다면

```text
Δθ

= 37 - 15

= 22°
```

이고

```text
Δt

= 0.05 - 0.00

= 0.05초
```

이다.

따라서

```text
ω

= 22 / 0.05

= 440 °/s
```

이다.

해석하면
> **몸통이 0.05초 동안 22° 회전했으며, 그 구간의 평균 회전 속도가 440°/s라는 의미이다.**

`°/s`는

```text
degree per second
```

로,

> **1초를 기준으로 각도가 얼마나 빠르게 변화하는가**

를 나타내는 단위이다.

<br>

> ## **7-5 ) 각가속도 Angular Acceleration**

각속도가 시간에 따라 얼마나 빠르게 변하는지를 `각가속도`라고 한다.

기호는

```text
α
```

를 사용한다.

```text
α

=

Δω
───
Δt
```

또는 미분 형태로

```text
α

=

dω
──
dt
```

라고 표현할 수 있다.

해석해보면

```text
회전 속도가 얼마나 변했는가
─────────────────
그 변화가 일어난 시간

=

회전 속도가
얼마나 빠르게 빨라지거나 느려졌는가
```

예를 들어

```text
몸통 각속도

300 °/s
→
700 °/s
```

로 짧은 시간 동안 증가했다면 큰 양의 각가속도가 나타난다.

반대로

```text

→
200 °/s
```

로 감소하면 회전 운동이 빠르게 감속되고 있다는 의미이다.

> ## **7-6 ) 지면반력 Ground Reaction Force**

선수가 지면을 밀면 지면도 선수에게 반대 방향의 힘을 가한다.

이 힘을

```text
Ground Reaction Force
GRF
```

라고 한다.

점프슛 도약에서

```text
Fx = 420 N

Fz = 1650 N
```

이라고 하자.

여기서

```text
Fx
→ 수평 방향 힘

Fz
→ 수직 방향 힘

N
→ Newton, 힘의 단위
```

이다.

2차원 합력의 크기는

```text
|F|

=

√(Fx² + Fz²)
```

로 계산할 수 있다.

이번 예에서는

```text
|F|

=

√(420² + 1650²)

≈ 1702.6 N
```

이다.

해석해보면

> **수평 방향으로 작용한 힘과 수직 방향으로 작용한 힘을 하나로 합쳤을 때 전체 지면반력의 크기가 약 1702.6 N이라는 뜻이다.**

하지만

```text
|F| = 1700 N
```

만으로는 힘의 방향을 알 수 없다.

따라서 다음을 함께 살펴보는 것이 중요하다.

```text
Horizontal GRF
→ 수평 추진력

Vertical GRF
→ 수직 추진력

Resultant GRF
→ 전체 힘의 크기

Force Direction
→ 힘이 작용한 방향
```

<br>

> ## **7-7 ) Impulse 충격량**

힘이 얼마나 큰지뿐 아니라 **얼마 동안 작용했는지**도 운동에 중요하다.

Impulse는 다음과 같이 표현한다.

```text
J

=

∫ F dt
```

간단한 평균값으로 근사하면

```text
J

≈

Favg × Δt
```

이다.

### 기호 뜻

```text
J
→ Impulse, 충격량

Favg
→ 평균 힘

Δt
→ 힘이 작용한 시간
```

해석해보면

> **힘의 크기와 그 힘이 작용한 시간을 함께 고려한 값이다.**

예를 들어

```text
평균 수직 GRF
1500 N

힘 작용 시간
0.20 s
```

라면

```text
J

≈ 1500 × 0.20

= 300 N·s
```

이다.

점프 분석에서는 큰 힘을 얼마나 오랫동안 지면에 전달했는지를 함께 이해하는 데 사용할 수 있다.

<br>

> ## **7-8 ) Torque 관절 모멘트**

힘이 관절이나 물체를 회전시키는 효과를 `Torque` 또는 `Moment`라고 한다.

기본적으로

```text
τ

=

r × F
```

로 표현한다.

크기만 보면

```text
|τ|

=

rF sinθ
```

이다.

### 기호 뜻

```text
τ
→ Torque

r
→ 회전축에서 힘이 작용하는 지점까지의 거리

F
→ 힘

θ
→ r과 F 사이의 각도
```

해석해보면

> **같은 힘이라도 관절 중심에서 얼마나 떨어진 위치에 어떤 방향으로 작용하는지에 따라 회전시키는 효과가 달라진다는 뜻이다.**

예를 들어 어깨 관절에서 손까지의 거리가 길고 공에 큰 힘을 가한다면 어깨 주위 회전 모멘트도 커질 수 있다.

<br>

> ## **7-9 ) Angular Momentum 각운동량**

회전하는 신체의 운동 상태는 각운동량으로 표현할 수 있다.

단순화하면

```text
L

=

Iω
```

이다.

### 기호 뜻

```text
L
→ 각운동량

I
→ 관성모멘트

ω
→ 각속도
```

해석해보면

> **몸이 얼마나 회전하기 어려운 구조를 가지고 있는지와 실제 회전 속도를 함께 고려한 회전 운동의 양이다.**

같은 각속도라도 팔을 몸에서 멀리 벌리면 관성모멘트가 달라질 수 있다.

따라서 회전 동작에서는

```text
신체 자세
+
회전 속도
```

를 함께 살펴볼 필요가 있다.

# **10. 여러 분석 결과를 연결하여 문제를 구체화한다**

> ## **10-1 ) 분석 결과를 따로 끝내지 않는다**

각 분석의 결과를 정리하면 다음과 같다.

| 분석 | 관찰 결과 |
| --- | --- |
| Funnel | 유효 슈팅 → 득점 전환율 50.0% |
| Phase | 후반 득점률이 전반보다 낮게 나타남 |
| Segmentation | High Pressure에서 득점률이 낮게 나타남 |
| 운동역학 | High Pressure에서 Release Speed 감소 |
| 운동역학 | High Pressure에서 Trunk Angular Velocity 감소 |
| 운동역학 | 비득점에서 Knee Flexion이 상대적으로 작음 |
| Retention | Day 30 Target Mechanics 유지율 50% |
| Cohort | 8월 4주 Cohort의 유지율이 상대적으로 낮음 |

이 결과들을 연결하면

```text
전체 공격
        ↓
득점 전환 문제 확인
        ↓
후반에서 차이 확대
        ↓
High Pressure에서 차이 확대
        ↓
운동역학 변수 차이 확인
        ↓
기술 유지 Retention도 감소
```

처럼 문제를 점차 좁힐 수 있다.

<br>

> ## **10-2 ) 관찰된 사실과 가설을 구분한다**

현재 데이터에서 직접 확인한 사실은 다음과 같다.

```text
후반 득점률이
전반보다 낮게 나타났다.

High Pressure 상황의 득점률이
Low Pressure보다 낮게 나타났다.

High Pressure에서
평균 릴리스 속도가 낮게 나타났다.

High Pressure에서
평균 몸통 각속도가 낮게 나타났다.
```

반면 다음 내용은 가설이다.

```text
후반 피로 때문에
몸통 회전이 감소했다.

수비 압박 때문에
무릎의 사전 굴곡을 충분히 만들지 못했다.

몸통 각속도가 감소해서
릴리스 속도가 감소했다.

릴리스 속도가 감소해서
득점률이 감소했다.
```

즉,

```text
관찰된 연관성

≠

인과관계
```

이다.

<br>

> ## **10-3 ) 검증 가능한 원인 가설로 발전시킨다**

현재 결과를 바탕으로 다음 가설을 설정할 수 있다.

> **후반 고압박 상황에서는 슈팅 준비 시간이 짧아지면서 하지의 도약 동작과 몸통 회전이 충분히 이루어지지 않고, 이로 인해 공 릴리스 속도와 슈팅 수행이 변화하는 것은 아닐까?**

이 가설을 검증하려면 추가 변수를 확인할 수 있다.

```text

Peak Trunk Angular Velocity

Peak 발생 시점

Release Height

선수별 경기시간

심박수

RPE
```

> ## **10-4 ) 개선 시나리오로 연결한다**

가설을 바탕으로 다음과 같은 훈련을 설계할 수 있다.

```text
후반 피로 조건 재현
        ↓
수비수 빠른 접근
        ↓
3-step Jump Shot
        ↓
Pose Estimation
        ↓
Knee Flexion
        ↓
Pelvis Rotation
        ↓
Trunk Rotation
        ↓
Shoulder Rotation
        ↓
Elbow Extension
        ↓
Release
        ↓
실시간 피드백
```

개선 목표는 단순히

```text

```

가 아니다.

실제 경기 수행을 나타내는 Primary Metric을 먼저 정하고 운동역학 변수는 Secondary Metric으로 사용할 수 있다.

| 지표 | 역할 | 예시 |
| --- | --- | --- |
| Primary | 최종 경기수행 지표 | High Pressure 목표 구역 슈팅 성공률 |
| Secondary | 수행 과정 지표 | Release Speed |
| Secondary | 수행 과정 지표 | Trunk Angular Velocity |
| Secondary | 수행 과정 지표 | Knee Flexion |
| Secondary | 수행 과정 지표 | Jump Height |
| Guardrail | 부작용 확인 | 유효 슈팅 비율 |
| Guardrail | 안전성 확인 | 어깨·팔꿈치 통증 |

> ## **10-5 ) 검증 단계**

개선안을 적용했다고 분석이 끝나는 것은 아니다.

> **실시간 운동역학 피드백을 제공했을 때 실제 High Pressure 슈팅 성공률이 증가하는가?**

```text

        ↓

기존 훈련

Pose Estimation 실시간 피드백
```

# **11. Advanced 추가 학습**

> ## **11-1 ) 반복 측정 구조를 반드시 고려한다**

스포츠 경기영상 데이터는 대부분 계층적인 구조를 가진다.

```text
팀
    ↓
선수
    ↓
경기
    ↓
공격권
    ↓
슈팅
    ↓
영상 프레임
```

예를 들어

```text
선수 1명

10경기

50개 슈팅

5,000개 Pose 좌표
```

가 있다고 해서

```text
독립 표본
5,000명
```

인 것은 아니다.

같은 선수에게서 얻은 반복 데이터는 서로 연관될 수 있다.

따라서 추론통계에서는

```text
Mixed-effects Model

GEE

Repeated-measures Model
```

등을 고려할 수 있다.

<br>

> ## **11-2 ) 2D Pose와 3D 운동학은 다르다**

2D Pose Estimation은 카메라 화면에 투영된 좌표를 사용한다.

```text
2D

[x, y]
```

3D Motion Capture에서는

```text
3D

[x, y, z]
```

좌표를 사용한다.

### 기호

```text
x
→ 한 축 방향 위치

y
→ 두 번째 축 방향 위치

z
→ 세 번째 축 방향 위치
```

어느 축이 좌우·전후·수직인지는 사용하는 좌표계 정의에 따라 달라지므로 연구에서 명확히 적어야 한다.

선수의 움직임이 카메라 평면에서 크게 벗어나면 2D 관절각에 오차가 증가할 수 있다.

<br>

> ## **11-3 ) 각속도와 각가속도는 Noise에 민감하다**

각도 데이터를 한 번 미분하면 각속도를 얻는다.

```text
Angle

        ↓
1차 미분

Angular Velocity
```

수식으로는

```text
ω

=

dθ
──
dt
```

이다.

해석해보면

> **시간이 매우 조금 변할 때 각도가 얼마나 빠르게 변하는지를 나타낸다.**

다시 미분하면 각가속도를 얻는다.

```text
α

=

dω
──
dt
```

또는

```text
α

=

d²θ
───
dt²
```

이다.

해석해보면

> **회전 속도가 시간에 따라 얼마나 빠르게 변하는지를 계산한다.**

하지만 미분은 작은 좌표 오차도 크게 만들 수 있다.

따라서 실제 운동역학 연구에서는

```text
Low-pass Filter

Butterworth Filter

Spline Smoothing
```

등을 이용한 신호처리가 필요할 수 있다.

<br>

> ## **11-4 ) 경기 상황과 운동역학 변수를 동시에 모델링할 수 있다**

득점 여부를 다음 변수들과 함께 분석할 수 있다.

```text
Goal

←

Pressure Level

Phase

Position

Release Speed

Trunk Angular Velocity

Knee Flexion

Jump Height
```

득점 여부가

```text
Goal = 1

No Goal = 0
```

인 이진 변수라면 Logistic Regression을 사용할 수 있다.

같은 선수가 여러 번 슈팅했다면

```text
Mixed-effects Logistic Regression
```

을 고려할 수 있다.

예를 들어

```text
Fixed Effects

Pressure

Phase

Release Speed

Trunk Angular Velocity

        +

Random Effect

Athlete
```

와 같이 구성할 수 있다.

이렇게 하면 단순 평균 비교보다 여러 경기 상황 변수를 동시에 고려하면서 선수별 반복측정도 반영할 수 있다.

<br>

> ## **11-5 ) Retention과 경기력 향상은 같은 의미가 아니다**

기술 Retention이 높다는 것은

```text
정의한 동작 기준을
시간이 지나도 유지한다.
```

는 의미이다.

하지만 이것이 곧

```text
경기력이 향상되었다.

득점률이 증가했다.

부상 위험이 감소했다.
```

를 의미하지 않는다.

따라서 기술 유지와 실제 경기 성과를 별도로 확인해야 한다.

```text
Technique Retention

+

Match Performance

+

Clinical / Injury Outcome
```

을 서로 구분하는 것이 중요하다.

# **12. 핵심정리**

> ## **12-1 ) 이벤트 로그**

이벤트 로그는

```text
누가?

언제?

어떤 행동을 했는가?
```

를 기록한 데이터이다.

스포츠에서는

```text
선수

경기

공격권

이벤트

운동역학 변수
```

를 함께 기록할 수 있다.

<br>

> ## **12-2 ) AARRR**

AARRR은

```text
Acquisition
Activation
Retention
Revenue
Referral
```

의 5개 영역에서 전체 사용자 행동을 살펴보는 프레임워크이다.

스포츠 경기 자체보다 **선수·코치가 영상분석 서비스를 사용하는 행동**을 분석할 때 자연스럽게 적용할 수 있다.

중요한 것은 가장 작은 숫자를 무조건 문제라고 판단하는 것이 아니다.

<br>

> ## **12-3 ) Funnel**

Funnel은 목표 행동까지 이어지는 과정에서 **어느 단계의 연결이 많이 끊기는지** 확인한다.

핸드볼에서는

```text
공격권
        ↓
9m 진입
        ↓
점프슛
        ↓
유효 슈팅
        ↓
득점
```

으로 정의할 수 있다.

전환율은

```text
다음 단계 이벤트
──────────
현재 단계 이벤트

× 100
```

이다.

즉,

> **현재 단계의 공격 중 다음 단계까지 이어진 비율이다.**

이탈률은

```text
100 - 전환율
```

이다.

즉,

> **현재 단계에는 도달했지만 다음 단계까지 이어지지 않은 비율이다.**

<br>

> ## **12-4 ) Retention**

Retention은

```text
Retention Rate

=

특정 시점에도 행동을 유지한 선수
──────────────────────
처음 행동을 시작한 선수

× 100
```

으로 계산할 수 있다.

즉,

> **처음 시작한 선수 가운데 시간이 지나도 같은 행동이나 기술을 유지한 선수의 비율이다.**

<br>

> ## **12-5 ) Cohort**

Cohort는 공통된 시작 시점을 가진 집단을 비교한다.

```text
8월 1주 시작

vs

8월 2주 시작

vs

8월 3주 시작

vs

8월 4주 시작
```

과 같이 훈련 시작 시점에 따른 기술 유지 차이를 확인할 수 있다.

<br>

> ## **12-6 ) Segmentation**

Segmentation은 전체 평균을

```text
어떤 선수?

어떤 포지션?

어떤 경기 구간?

어떤 수비 압박?

어떤 슈팅 위치?
```

로 나누어 문제를 구체화한다.

<br>

> ## **12-8 ) 관찰된 사실과 가설**

이다.
