# **1. 스칼라·벡터·행렬이 필요한 이유**

데이터 분석과 머신러닝에서는 하나의 숫자부터 수천 개의 특성을 가진 데이터까지 다양한 형태의 값을 다룬다.

이러한 데이터를 수학적으로 표현할 때 가장 기본이 되는 구조가 다음 세 가지이다.

```text
하나의 값
→ Scalar(스칼라)

여러 값을 순서대로 표현
→ Vector(벡터)

여러 Vector를 행과 열로 구성
→ Matrix(행렬)
```

예를 들어 선수의 경기 데이터를 생각해보면 다음과 같이 구분할 수 있다.

```text
최고 속도 8.4 m/s
→ Scalar

[최고 속도, 이동 거리, Player Load]
→ Vector

여러 선수의
[최고 속도, 이동 거리, Player Load]
→ Matrix
```

즉, 스칼라·벡터·행렬은 서로 완전히 별개의 개념이라기보다 **데이터의 규모와 구조를 표현하기 위한 기본적인 수학적 형식**으로 이해하면 된다.

<br>

> ## **1-1) 기본 구조 비교**

| 구분 | 의미 | 예시 | 데이터 분석에서의 역할 |
| --- | --- | --- | --- |
| Scalar | 하나의 값 | `7.5` | 하나의 측정값, 손실값 |
| Vector | 여러 값을 순서대로 표현 | `[7.5, 1200, 430]` | 하나의 Sample의 여러 Feature |
| Matrix | Vector를 행과 열로 구성 | 여러 선수 × 여러 Feature | 전체 Dataset |
| Tensor | 3개 이상의 축을 가진 배열 | 선수 × 시간 × 센서축 | 시계열·영상·딥러닝 데이터 |

가장 중요한 관점은 다음과 같다.

```text
Scalar
        ↓
Vector
        ↓
Matrix
        ↓
더 높은 차원의 Tensor
```

데이터 구조가 복잡해져도 기본 원리는 **숫자를 일정한 구조로 배열하는 것**이다.

# **2. Scalar - 하나의 숫자**

> ## **2-1) Scalar의 정의**

**Scalar**는 하나의 숫자로 표현되는 값이다.

주로 `a`, `x`, `y` 등을 사용하여 나타낸다.

일반적으로 다음처럼 나타낸다.

```text
x = 5
v = 8.4
L = 0.35
```

각 값은 모두 하나의 숫자이므로 Scalar이다.

예를 들어 운동역학 데이터를 생각하면 다음 값들은 모두 Scalar이다.

| 변수 | 값 |
| --- | ---: |
| 최대 수직 지면반력 | `2430 N` |
| 점프 높이 | `42.6 cm` |
| 최대 속도 | `8.3 m/s` |
| 평균 심박수 | `168 bpm` |
| 모델 손실 | `0.21` |

<br>

> ## **2-2) Scalar는 데이터 값뿐 아니라 계산 결과에도 사용된다**

Scalar는 단순한 입력값에만 사용되는 것은 아니다.

머신러닝에서는 다음과 같은 값도 Scalar가 될 수 있다.   

머신러닝에서 **예측값, 손실률, 학습률 등**도 스칼라로 표현할 수 있다.

```text
Prediction Score
→ 0.83

Loss
→ 0.17

Learning Rate
→ 0.001
```

따라서 Scalar는

```text
측정값

파라미터

예측값

손실값
```

등 다양한 역할을 할 수 있다.

# **3. Vector(벡터) - 여러 숫자를 하나의 순서로 표현**

> ## **3-1) Vector의 정의**

**Vector**는 여러 개의 숫자를 순서대로 나열한 수학적 객체이다.

일반적으로 굵은 소문자 **x, v** 등을 사용하여 나타낸다.

예를 들어, 한 축구 선수의 경기 데이터를 다음과 같이 정의한다고 하자.

```text
최고 속도
→ 8.2 m/s

총 이동 거리
→ 10,850 m

고강도 질주 횟수
→ 34회
```

하나의 Vector로 표현하면 다음과 같다.

`x_A = [8.2, 10850, 34]`


이 Vector의 각 원소는 서로 다른 Feature를 의미한다.

```text
x₁
→ 최고 속도

x₂
→ 이동 거리

x₃
→ 고강도 질주 횟수
```

<br>

> ## **3-2) Feature Vector**

머신러닝에서는 한 Sample을 구성하는 여러 Feature를 하나의 Vector로 표현하는 경우가 많다.

예:

```text
선수 A

Speed
Distance
Player Load
Heart Rate
```

Vector:

```math
\mathbf{x}_A
=
[8.2,\ 10850,\ 432,\ 166]
```

이를 **Feature Vector**라고 한다.

즉,

```text
하나의 Sample
+
여러 Feature
=
Feature Vector
```

라고 이해할 수 있다.

<br>

> ## **3-3) Vector의 순서가 중요한 이유**

Vector는 단순한 숫자의 묶음이 아니라 **원소의 위치에 의미가 있다.**

예를 들어

```text
[8.2, 10850, 432]
```

를

```text
[10850, 8.2, 432]
```

로 바꾸면 숫자는 같아도 의미가 달라진다.

따라서 머신러닝에서는 Training Data와 Prediction Data 모두 동일한 Feature 순서를 유지해야 한다.

```text
[Speed, Distance, Player Load]
```

라는 구조로 학습했다면 예측할 때도 동일한 순서를 사용해야 한다.

# **4. Row Vector(행 벡터)와 Column Vector(열 벡터)**

> ## **4-1) 같은 값이어도 방향이 다르다**

Vector는 행 형태와 열 형태로 표현할 수 있다.

행 Vector (Row Vector):

```math
\mathbf{x}
=
\begin{bmatrix}
3 & 4
\end{bmatrix}
```

Shape:

```text
1 × 2
```

열 Vector (Column Vector):

```math
\mathbf{x}
=
\begin{bmatrix}
3 \\
4
\end{bmatrix}
```

Shape:

```text
2 × 1
```

두 Vector는 같은 숫자 `3`, `4`를 포함하지만 행렬 연산에서는 다른 구조이다.

<br>

> ## **4-2) NumPy의 1차원 배열과는 다르다**

Python에서 다음 배열을 생성하면

[ Python : code ] "1차원 배열의 Shape 확인"

```python
import numpy as np

x = np.array([3, 4])

print(x.ndim)
print(x.shape)
```

[ Result ]

```text
1
(2,)
```

이 배열은 엄밀하게 말하면

```text
행 Vector
```

도 아니고

```text
열 Vector
```

도 아니다.

NumPy의 **1차원 배열**이다.

2차원 행 Vector로 만들면

[ Python : code ] "행 Vector와 열 Vector 생성"

```python
x = np.array([3, 4])

x_row = x.reshape(1, 2)
x_col = x.reshape(2, 1)

print(x_row.shape)
print(x_col.shape)
```

[ Result ]

```text
(1, 2)
(2, 1)
```

따라서 NumPy에서는

```text
(2,)
(1, 2)
(2, 1)
```

을 구분해야 한다.

# **5. Matrix(행렬) - 여러 Sample을 하나의 구조로 표현**

> ## **5-1) Matrix의 정의**

Matrix는 숫자를 Row와 Column으로 배열한 구조이다.

예를 들어 세 명의 선수에게서 다음 Feature를 측정했다고 하자.

| 선수 | 최고 속도 | Player Load |
| --- | ---: | ---: |
| A | 8.1 | 410 |
| B | 7.8 | 385 |
| C | 8.6 | 460 |

Matrix로 표현하면 다음과 같다.

```math
X
=
\begin{bmatrix}
8.1 & 410 \\
7.8 & 385 \\
8.6 & 460
\end{bmatrix}
```

해석:

```text
Row
→ 선수

Column
→ Feature
```

따라서

```text
3 Samples
2 Features
```

의 데이터이다.

<br>

> ## **5-2) Matrix 원소 표기**

행렬의 특정 원소는 일반적으로 다음처럼 나타낸다.

```math
X_{ij}
```

여기서

```text
i
→ Row 번호

j
→ Column 번호
```

이다.

앞 행렬에서


```math
X_{2,1}
=
7.8
```

은

```text
2번째 선수 B의
1번째 Feature인 최고 속도
```

를 의미한다.

또한

```math
X_{3,2}
=
460
```

은

```text
선수 C의 Player Load
```

를 의미한다.


<br><br>

# **6. 머신러닝에서 X, y, w, b의 의미**

> ## **6-1) 입력 데이터 `X`**

머신러닝에서는 여러 Sample과 Feature를 하나의 Matrix `X`로 표현하는 경우가 많다.

예를 들어

```text
선수 3명

Feature
→ 최고 속도
→ 이동 거리
→ Player Load
```

가 있다면

```math
X
=
\begin{bmatrix}
8.1 & 10300 & 410 \\
7.8 & 9800 & 385 \\
8.6 & 11200 & 460
\end{bmatrix}
```

가 된다.

일반적으로

```math
X \in \mathbb{R}^{n \times d}
```

로 표현한다.

```text
n
→ Sample 수

d
→ Feature 수
```

<br>

> ## **6-2) Target Vector `y`**

각 선수에게 대응하는 정답이 있다고 하자.

예를 들어 다음 경기에서 고강도 Performance 유지 여부를

```text
유지
→ 1

저하
→ 0
```

으로 정의하면

```math
y
=
[1,\ 0,\ 1]
```

로 표현할 수 있다.

`X`의 첫 번째 Row와 `y`의 첫 번째 원소는 반드시 같은 Sample에 대응해야 한다.

```text
X[0]
↔
y[0]
```

즉 데이터와 정답의 순서가 일치해야 한다.

<br>

> ## **6-3) Weight Vector `w`**

입력 Feature가 3개라면 각 Feature에 하나씩 Weight를 둘 수 있다.

```math
w
=
[0.4,\ 0.2,\ 0.7]
```

Weight는 각 Feature가 계산 결과에 기여하는 정도를 조절한다.

<br>

> ## **6-4) Bias `b`**

Bias는 일반적으로 하나의 출력값을 계산하는 모델에서는 하나의 Scalar가 될 수 있다.

```math
b = 0.5
```

따라서 기본적인 Linear Model의 형태를 단순화하면

```math
z
=
\mathbf{x}\cdot\mathbf{w}
+
b
```

라고 표현할 수 있다.


<br><br>

# **7. Weight와 Bias를 이용한 계산 이해**

> ## **7-1) 하나의 Sample에 대한 계산**

운동처방 모델에서 다음 Feature를 사용한다고 하자.

```text
주간 운동 횟수
→ 3

평균 운동 시간
→ 45분
```

입력 Vector:

```math
x
=
[3,\ 45]
```

Weight:

```math
w
=
[2,\ 0.1]
```

Bias:

```
b = 1
```

점수는

```math
score
=
2(3)
+
0.1(45)
+
1
```

이므로

```math
score
=
6 + 4.5 + 1
=
11.5
```

이다.

<br>

> ## **7-2) Python 구현**

[ Python : code ] "Feature Vector와 Weight를 이용한 선형 점수 계산"

```python
import numpy as np

x = np.array([3, 45])
w = np.array([2.0, 0.1])
b = 1.0

score = np.dot(x, w) + b

print(score)
```

[ Result ]

```text
11.5
```

여기서 `11.5`는 단순한 Linear Score이다.

```text
확률
```

이나

```text
분류 결과
```

를 직접 의미하는 것은 아니다.

Logistic Regression에서는 이 값을 Sigmoid 함수에 넣어 확률로 변환한다.

# **8. 여러 출력을 만들면 Weight가 Matrix가 된다**

> ## **8-1) 하나의 입력에서 여러 출력 계산**

입력 Feature가

```text
최고 속도

Player Load
```

두 개라고 하자.

이 데이터를 이용하여

```text
Performance Score

Fatigue Score
```

두 개를 동시에 계산하려고 한다.

Weight를 다음과 같이 둘 수 있다.

```math
W
=
\begin{bmatrix}
0.5 & 0.2 \\
0.3 & 0.8
\end{bmatrix}
```

첫 번째 Column:

```text
Performance Score용 Weight
```

두 번째 Column:

```text
Fatigue Score용 Weight
```

이다.

<br>

> ## **8-2) Vector와 Matrix의 관계**

입력 Vector:

```math
x
=
[8,\ 400]
```

Weight Matrix:

```math
W
=
\begin{bmatrix}
0.5 & 0.2 \\
0.3 & 0.8
\end{bmatrix}
```

출력:

```math
xW
```

와 같이 계산할 수 있다.

즉 머신러닝과 딥러닝에서 Weight가 Matrix 형태로 등장하는 이유는 **여러 입력과 여러 출력을 한 번에 연결하기 위해서**이다.

# **9. Vector의 Dimension과 배열의 ndim은 다르다**

> ## **9-1) 가장 헷갈리기 쉬운 개념**

다음 Vector를 생각하자.

```math
x
=
[3,\ 5,\ 7]
```

수학적으로는 원소가 3개이므로

```text
3차원 Vector
```

이다.

그러나 NumPy에서는

[ Python : code ] "수학적 Vector 차원과 NumPy ndim 비교"

```python
import numpy as np

x = np.array([3, 5, 7])

print(x.ndim)
print(x.shape)
```

[ Result ]

```text
1
(3,)
```

이는 모순이 아니다.

`Vector Dimension`과 `ndim`이 서로 다른 것을 의미하기 때문이다.

| 용어 | 의미 |
| --- | --- |
| Vector의 Dimension | Vector 원소의 개수 |
| NumPy `ndim` | 배열의 Axis 개수 |
| NumPy `shape` | 각 Axis의 크기 |

따라서

```text
Vector Dimension
= 3

NumPy ndim
= 1
```

이 동시에 가능하다.

# **10. Matrix Size와 Shape**

> ## **10-1) m × n Matrix**

행이 `m`개이고 열이 `n`개라면

```math
m \times n
```

Matrix라고 한다.

예:

```math
X
=
\begin{bmatrix}
1 & 2 & 3 \\
4 & 5 & 6
\end{bmatrix}
```

은

```text
2 Rows

3 Columns
```

이므로

```text
2 × 3 Matrix
```

이다.

NumPy Shape:

```text
(2, 3)
```

이다.

<br>

> ## **10-2) Sample과 Feature의 관계**

머신러닝의 일반적인 입력 구조는

```math
X
\in
\mathbb{R}^{n \times d}
```

이다.

```text
n
→ Sample 수

d
→ Feature 수
```

예를 들어 선수 200명에게 Feature 8개를 사용하면

```text
X.shape
→ (200, 8)
```

이 된다.

가중치 하나가 각 Feature에 대응하는 선형 모델이라면

```text
w.shape
→ (8,)
```

이 필요하다.

Sample이 200개라고 Weight가 200개 필요한 것이 아니다.

Weight의 개수는 기본적으로 **입력 Feature 수와 연결**된다.

import numpy as np

# **12. reshape()의 의미**

> ## **12-1) 원소 수는 유지해야 한다**

NumPy의 `reshape()`는 데이터 값은 유지하면서 배열 구조만 변경한다.

[ Python : code ] "1차원 배열을 행·열 Vector로 변경"

```python
import numpy as np

x = np.array([1, 2, 3, 4, 5, 6])

a = x.reshape(2, 3)
b = x.reshape(3, 2)

print(a)
print(b)
```

[ Result ]

```text
[[1 2 3]
 [4 5 6]]

[[1 2]
 [3 4]
 [5 6]]
```

원소의 총개수는 모두 6개이다.

따라서 다음은 가능하다.

```text
(6,)
→ (1, 6)
→ (2, 3)
→ (3, 2)
→ (6, 1)
```

하지만

```text
(4, 2)
```

는 8개의 원소가 필요하므로 불가능하다.

# **13. Norm - Vector의 크기를 하나의 값으로 표현**

> ## **13-1) Norm의 기본 개념**

Vector는 여러 숫자로 이루어져 있기 때문에 단순히 하나의 값처럼 크기를 비교하기 어렵다.

이를 하나의 Scalar로 표현하는 함수가 Norm이다.

일반적으로

```math
\|\mathbf{x}\|
```

와 같이 표현한다.

대표적인 Norm은

```text
L1 Norm

L2 Norm
```

이다.

# **14. L1 Norm**

> ## **14-1) 정의**

L1 Norm은 모든 원소의 절댓값을 더한다.

```math
\|\mathbf{x}\|_1
=
\sum_{i=1}^{n}
|x_i|
```

예:

```math
x
=
[3,\ -4]
```

이면

```math
\|x\|_1
=
|3|
+
|-4|
=
7
```

이다.

<br>

> ## **14-2) Python 예제**

[ Python : code ] "L1 Norm 계산"

```python
import numpy as np

x = np.array([3, -4])

l1 = np.linalg.norm(x, ord=1) # (ord=1)

print(l1)
```

[ Result ]

```text
7.0
```

L1 Norm에서는 음수도 절댓값으로 변환하므로 서로 상쇄되지 않는다.

# **15. L2 Norm**

> ## **15-1) 정의**

L2 Norm은 원소를 제곱하여 더한 뒤 제곱근을 계산한다.

```math
\|\mathbf{x}\|_2
=
\sqrt{
\sum_{i=1}^{n}
x_i^2
}
```

2차원에서는 익숙한 피타고라스 정리와 같다.

예:

```math
x
=
[3,\ 4]
```

이면

```math
\|x\|_2
=
\sqrt{
3^2 + 4^2
}
```

```math
=
\sqrt{25}
=
5
```

이다.

<br>

> ## **15-2) Python 예제**

[ Python : code ] "L2 Norm 계산"

```python
import numpy as np

x = np.array([3, 4])

l2 = np.linalg.norm(x, ord=2)

print(l2)
```

[ Result ]

```text
5.0
```

# **16. L1 Norm과 L2 Norm 비교**

| 구분 | `L1 Norm` | `L2 Norm` |
| --- | --- | --- |
| 계산 | 절댓값의 합 | 제곱합의 제곱근 |
| 대표 거리 | Manhattan Distance | Euclidean Distance |
| 큰 값의 영향 | 상대적으로 작음 | 제곱 때문에 더 크게 반영 |
| ML 활용 | L1 Regularization | L2 Regularization |
| 특징 | 희소성 유도 가능 | 큰 Weight 억제 |

같은 Vector

```math
x=[3,4]
```

에 대해

```text
L1
→ 7

L2
→ 5
```

가 된다.

Norm마다 `크기`를 정의하는 방법이 다르기 때문에 동일한 Vector에도 결과가 다르다.

# **20. Vector Normalization**

> ## **20-1) Unit Vector 만들기**

0이 아닌 Vector를 자신의 L2 Norm으로 나누면 길이가 1인 Unit Vector가 된다.

```math
\hat{x}
=
\frac{x}
{\|x\|_2}
```

예:

```math
x
=
[3,4]
```

```math
\|x\|_2
=
5
```

따라서

```math
\hat{x}
=
\left[
\frac{3}{5},
\frac{4}{5}
\right]
```

```math
=
[0.6,\ 0.8]
```

이다.

정규화된 Vector의 L2 Norm:

```math
\sqrt{
0.6^2+0.8^2
}
=
1
```

이다.

<br>

> ## **20-2) Python 예제**

[ Python : code ] "L2 Normalization으로 Unit Vector 생성"

```python
import numpy as np

x = np.array([3.0, 4.0])

norm = np.linalg.norm(x, ord=2)
x_normalized = x / norm

print(x_normalized)
print(np.linalg.norm(x_normalized))
```

[ Result ]

```text
[0.6 0.8]
1.0
```

단, Zero Vector는

```math
\|x\|_2=0
```

이므로 0으로 나누면 안 된다.

# **22. Normalization과 Standardization은 다르다**

> ## **22-1) Vector Normalization**

개별 Vector 전체의 길이를 조정한다.

```math
x'
=
\frac{x}
{\|x\|}
```

목적:

```text
Vector 길이 제거

방향 비교

Cosine Similarity 등에 활용
```

<br>

> ## **22-2) Standardization**

각 Feature Column의 평균과 표준편차를 기준으로 값을 변환한다.

```math
z
=
\frac{x-\mu}
{\sigma}
```

여기서

```text
μ
→ Feature 평균

σ
→ Feature 표준편차
```

이다.

목적:

```text
Feature별 Scale 조정
```

<br>

> ## **22-3) 비교**

| 구분 | Vector Normalization | Standardization |
| --- | --- | --- |
| 기준 | 한 Vector | 한 Feature Column |
| 대표 공식 | `x / ||x||₂` | `(x - μ) / σ` |
| 결과 | Vector 길이 1 | 평균 0, 표준편차 1 |
| 목적 | 방향 비교 | Feature Scale 조정 |
| 대표 활용 | Embedding, Cosine Similarity | Regression, KNN, SVM 등 |

두 개념은 이름이 비슷하지만 해결하려는 문제가 다르다.

# **23. Normalization과 Regularization도 구분해야 한다**

> ## **23-1) Normalization**

```text
데이터 또는 Vector의 Scale을 조정
```

예:

```text

```

<br>

> ## **23-2) Regularization**

모델 학습 과정에서 Weight가 지나치게 커지는 것을 제어한다.

예:

L1 Penalty:

```math
\lambda
\sum_i
|w_i|
```

L2 Penalty:

```math
\lambda
\sum_i
w_i^2
```

즉,

```text
Normalization
→ Data Transformation

Regularization
→ Model Complexity Control
```

이다.

# **24. L1과 L2 Regularization의 직관**

> ## **24-1) L1 Regularization**

Weight의 절댓값 합을 Penalty로 사용한다.

특징:

```text
일부 Weight를
정확히 0에 가깝게 만들 수 있음

        ↓

Sparse Model 유도
```

따라서 Feature Selection 효과가 나타날 수 있다.

<br>

> ## **24-2) L2 Regularization**

Weight의 제곱합을 Penalty로 사용한다.

특징:

```text
매우 큰 Weight에
더 큰 Penalty

        ↓

Weight를 전체적으로 작게 유지
```

L1과 L2 Norm은 단순한 Vector 길이 계산에서 끝나지 않고 머신러닝의 Regularization 개념으로 확장된다.

# **28. 핵심정리**

1. Scalar는 하나의 숫자로 표현되는 가장 기본적인 데이터 구조이다.

2. Vector는 여러 숫자를 순서대로 표현한 수학적 객체이다.

3. Matrix는 여러 숫자를 Row와 Column으로 배열한 구조이다.

4. 머신러닝에서는 일반적으로

```text
한 Sample
→ Feature Vector

여러 Sample
→ Feature Matrix
```

로 표현한다.

5. Feature Vector에서 각 원소의 위치는 Feature의 의미와 연결되므로 순서를 유지해야 한다.

6. Matrix에서 일반적으로

```text
Row
→ Sample

Column
→ Feature
```

로 구성한다.

7. 머신러닝 입력 Matrix는 일반적으로

```math
X\in\mathbb{R}^{n\times d}
```

로 나타낸다.

8. 여기서 `n`은 Sample 수, `d`는 Feature 수이다.

9. Target `y`는 Sample마다 하나의 정답이 있다면 일반적으로 Vector로 표현한다.

10. Weight는 Feature마다 하나의 가중치를 적용하는 모델에서는 Vector로 표현할 수 있다.

11. Bias는 하나의 출력을 조정한다면 Scalar가 될 수 있다.

12. 여러 Output을 동시에 계산하면 Weight는 Matrix 형태로 확장될 수 있다.

13. Vector의 Dimension은 Vector를 구성하는 원소의 개수이다.

14. NumPy의 `ndim`은 배열이 가지고 있는 Axis의 개수이다.

15. 따라서

```text
np.array([1, 2, 3])
```

은 수학적으로 3차원 Vector이지만 NumPy에서는 `ndim = 1`이다.

16. Shape는 배열의 각 Axis 크기를 나타낸다.

17. `(100, 5)`는 일반적인 머신러닝 데이터에서

```text
100 Samples

5 Features
```

를 의미한다.

18. NumPy의 1차원 배열 `(5,)`과 행 Vector `(1,5)`, 열 Vector `(5,1)`은 서로 다른 Shape이다.

19. `reshape()`는 원소의 개수를 유지하면서 배열의 구조만 변경한다.

20. Norm은 Vector의 크기를 Scalar 하나로 표현하는 함수이다.

21. L1 Norm은 다음과 같다.

```math
\|x\|_1

\sum_i|x_i|
```

22. L2 Norm은 다음과 같다.

```math
\|x\|_2
=
\sqrt{
\sum_i x_i^2

```

23. 두 Vector의 차이에 Norm을 적용하면 Distance를 정의할 수 있다.

24. L1 Norm 기반 거리는 Manhattan Distance이다.

25. L2 Norm 기반 거리는 Euclidean Distance이다.

26. 거리 기반 분석에서는 Feature Scale이 매우 중요하다.

27. 값의 범위가 큰 Feature가 Distance 계산을 지나치게 지배할 수 있기 때문이다.

28. Vector Normalization은 하나의 Vector를 자신의 Norm으로 나누는 방식이다.

29. L2 Normalization 후 Vector의 길이는 1이 된다.
