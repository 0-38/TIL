# **1. 시계열 데이터의 이해**

> ## 1-1 ) 시계열 데이터(Time Series Data)

**시계열 데이터(Time Series Data)** 는 시간의 흐름에 따라 순서대로 관측된 데이터이다.

일반적인 데이터에서는 각 행을 독립적인 관측값처럼 다루는 경우가 많다.

하지만 시계열 데이터에서는 다음 두 가지가 모두 중요하다.

```text
관측값
+
관측된 시간과 순서
```

예를 들어 한 육상 선수의 주차별 30m 기록이 다음과 같다고 하자.

| 주차 | 30m 기록 |
|---|---:|
| 1주차 | 4.32초 |
| 2주차 | 4.28초 |
| 3주차 | 4.30초 |
| 4주차 | 4.21초 |
| 5주차 | 4.18초 |

시간 순서대로 보면 3주차에 일시적인 기록 저하가 있었지만 전체적으로 기록이 향상되고 있다는 것을 확인할 수 있다.

하지만 순서를 섞으면,

```text
4.21
4.32
4.18
4.30
4.28
```

값 자체는 그대로 존재하지만 다음과 같은 정보를 잃게 된다.

```text
언제 기록이 향상되었는가?

장기적으로 증가하거나 감소하는가?

특정 시점 이후 변화가 발생했는가?

일정한 패턴이 반복되는가?
```

따라서 시계열에서는 **데이터의 순서를 유지하는 것이 기본 전제**이다.

<br>

> ## 1-2 ) 일반 데이터와 시계열 데이터의 차이

| 일반적인 데이터 | 시계열 데이터 |
|---|---|
| 관측값 자체가 중요 | 관측값과 시간이 함께 중요 |
| 행 순서가 중요하지 않은 경우가 많음 | 시간 순서가 중요 |
| 관측값을 독립적으로 다루는 경우가 많음 | 서로 다른 시점의 값이 관련될 수 있음 |
| 순서를 바꾸어도 의미가 유지될 수 있음 | 순서를 바꾸면 시간 구조가 사라질 수 있음 |

예를 들어 선수 100명의 키와 체중을 분석한다면 행의 순서를 바꾸더라도 분석 의미가 크게 달라지지 않는다.

반면 한 선수의 심박수가 다음처럼 측정되었다면,

```text
운동 시작
90 bpm

5분
125 bpm

10분
151 bpm

15분
164 bpm

회복 5분
112 bpm
```

시간 순서를 바꾸면 운동 중 심박수 증가와 회복 과정을 분석할 수 없다.

따라서 날짜 컬럼이 있다는 이유만으로 모두 시계열 문제라고 판단하지 않는다.

중요한 것은 다음 질문이다.

```text
분석 목적에서
시간의 흐름과 순서가
중요한 정보인가?
```

예를 들어,

```text
선수 등번호를 Feature로 사용해
포지션 예측
→ 일반적인 분류 문제일 수 있음

일별 훈련 부하로
다음 주 훈련 부하 예측
→ 시계열 문제
```

<br>

> ## 1-3 ) Frequency

**Frequency**는 시계열 데이터가 관측되는 시간 간격을 의미한다.

| 데이터 | Frequency 예시 |
|---|---|
| Force Plate | 1000Hz |
| IMU | 100Hz |
| 심박수 | 1초 또는 수초 |
| 시간별 GPS | 1시간 |
| 일별 훈련 부하 | 1일 |
| 주별 경기 기록 | 1주 |
| 월별 체력검사 | 1개월 |

Frequency가 다르면 분석할 수 있는 시간적 변화도 달라진다.

예를 들어,

```text
Force Plate 1000Hz
→ 1초에 1000개 데이터
→ 매우 짧은 힘 변화 분석 가능

1초 Frequency
→ 1초마다 1개 데이터
→ 수 ms 단위 변화 분석 어려움
```

따라서 시계열 분석 전에는 다음을 확인해야 한다.

```text
시간 단위는 무엇인가?

관측 간격은 얼마인가?

관측 간격은 일정한가?

분석하려는 반복 패턴은 몇 개의 관측값에 해당하는가?
```

<br>

> ## 1-4 ) Lag와 자기상관(Autocorrelation)

시계열 데이터에서는 현재 값이 과거 값과 관련될 수 있다.

이를 **자기상관(Autocorrelation)** 이라고 한다.

현재 시점을 $`t`$라고 하면 과거 값은 다음처럼 표현할 수 있다.

```text
현재
y_t

Lag 1
y_(t-1)

Lag 2
y_(t-2)

Lag k
y_(t-k)
```

여기서 `Lag`는 현재 시점과 과거 시점 사이의 시간적 거리를 의미한다.

예를 들어 일별 데이터라면,

```text
Lag 1
→ 하루 전

Lag 7
→ 7일 전
```

시간별 데이터라면,

```text
Lag 1
→ 1시간 전

Lag 24
→ 24시간 전

Lag 168
→ 1주 전
```

이 된다.

자기상관은 현재와 과거 사이의 관계를 확인하는 중요한 개념이지만 모든 시계열이 강한 자기상관을 가지는 것은 아니다.

또한 **높은 자기상관이 반드시 정상적인 시계열이나 높은 예측 성능을 의미하는 것도 아니다.**

# **2. 시계열 데이터의 주요 패턴**

> ## 2-1 ) Trend(추세)

**Trend**는 시간이 지나면서 나타나는 장기적인 증가 또는 감소 흐름이다.

예를 들어 높이뛰기 선수의 월별 최고기록이 다음과 같다고 하자.

```text
1월 185cm
2월 186cm
3월 184cm
4월 188cm
5월 190cm
6월 191cm
```

3월에는 일시적으로 감소했지만 전체적으로는 기록이 증가하고 있다.

따라서 Trend는 모든 값이 한 방향으로 움직여야 한다는 의미가 아니다.

```text
단기적 변화
↑ ↓ ↑ ↓

하지만

장기적 수준
→ 증가
```

장기적인 방향성이 존재하면 Trend가 있다고 볼 수 있다.

<br>

> ## 2-2 ) Seasonality(계절성)

**Seasonality**는 일정한 시간 간격을 두고 반복되는 패턴이다.

예를 들어 축구팀의 훈련 부하가 경기 일정에 따라 다음처럼 반복될 수 있다.

```text
경기 직후
훈련 부하 감소
        ↓
주중
훈련 부하 증가
        ↓
경기 전날
훈련 부하 감소
        ↓
       경기
        ↓
다음 주 반복
```

Frequency에 따라 다양한 계절성이 존재할 수 있다.

| Frequency | 반복 패턴 예시 |
|---|---|
| 시간별 | 하루 중 특정 시간대에 반복되는 변화 |
| 일별 | 특정 요일마다 반복되는 변화 |
| 주별 | 특정 주마다 반복되는 변화 |
| 월별 | 특정 월마다 반복되는 변화 |

중요한 것은 **규칙적인 반복**이다.

```text
일정한 간격으로 반복
→ Seasonality

한 번만 발생
→ Seasonality라고 보기 어려움
```

<br>

> ## 2-3 ) Residual(잔차)

**Residual**은 Trend와 Seasonality 등의 주요 구조를 설명한 뒤 남는 변동이다.

```text
Observed
        ↓
Trend 제거
        ↓
Seasonality 제거
        ↓
남은 변동
        ↓
Residual
```

따라서 특정 이벤트 자체를 Residual이라고 부르는 것은 정확하지 않다.

특정 이벤트는 Residual에 영향을 줄 수 있지만 Residual은 어디까지나 **모델이나 분해 과정에서 설명되지 않고 남은 부분**이다.

<br>

> ## 2-4 ) 시계열 분해(Time Series Decomposition)

시계열을 Trend, Seasonal, Residual 등의 구성요소로 분리하는 것을 **Time Series Decomposition**이라고 한다.

Additive Model을 사용한다.

```math
Observed_t = Trend_t + Seasonal_t + Residual_t
```

| 기호 | 의미 |
|---|---|
| $`Observed_t`$ | 실제 관측값 |
| $`Trend_t`$ | 장기적인 흐름 |
| $`Seasonal_t`$ | 일정한 주기의 반복 변화 |
| $`Residual_t`$ | 나머지 변동 |

예를 들어,

```text
Trend
66.67

Seasonal
-0.22

Residual
0.98
```

이라면,

```math
Observed = 66.67 - 0.22 + 0.98 = 67.43
```

처럼 각 구성요소가 실제 관측값을 구성한다.

<br>

> ## 2-5 ) period의 의미

`seasonal_decompose()`에서 `period`는 하나의 반복 주기를 구성하는 관측값의 개수이다.

예를 들어 Frequency가 1시간이라면,

```text
period = 24
→ 24시간
→ 하루 반복

period = 168
→ 24 × 7
→ 일주일 반복
```

월별 데이터라면,

```text
period = 12
→ 12개월
→ 1년 반복
```

이 된다.

따라서 `period`는 임의로 입력하는 숫자가 아니라 다음 두 요소를 기준으로 설정한다.

```text
데이터 Frequency
+
분석하려는 반복 주기
```

<br>

> ## 2-6 ) Trend와 Residual에서 NaN이 발생할 수 있는 이유

`seasonal_decompose()`는 이동평균을 기반으로 Trend를 계산한다.

현재 시점을 중심으로 주변 데이터가 필요하기 때문에 양 끝에서는 충분한 데이터가 존재하지 않을 수 있다.

```text
시계열 처음
→ 이전 데이터 부족

시계열 중간
→ 앞뒤 데이터 존재

시계열 마지막
→ 이후 데이터 부족
```

따라서 Trend의 처음과 마지막 일부가 `NaN`이 될 수 있다.

Residual은,

```math
Residual_t = Observed_t - Trend_t - Seasonal_t
```

이므로 Trend가 계산되지 않는 구간에서는 Residual 역시 `NaN`이 나타날 수 있다.

# **3. 정상성(Stationarity)과 단위근(Unit Root)**

> ## 3-1 ) 정상성(Stationarity)

**정상성(Stationarity)** 은 시계열의 통계적인 특성이 시간에 따라 안정적으로 유지되는 성질을 의미한다.

정상성은 다음 세 가지의 특성이 존재한다.

| 특성 | 의미 |
|---|---|
| Mean | 데이터가 움직이는 평균적인 수준 |
| Variance | 평균을 중심으로 변동하는 정도 |
| Lag 관계 | 일정한 시차를 가진 값들 사이의 관계 |

정상성을 직관적으로 표현하면 다음과 같다.

```text
시간이 지나도

평균
→ 크게 변하지 않음

분산
→ 크게 변하지 않음

같은 Lag의 관계
→ 크게 달라지지 않음
```

<br>

> ## 3-2 ) 정상성은 모든 값이 동일하다는 의미는 아니다

다음 데이터를 생각해보자.

```text
101
98
103
100
97
102
99
101
```

값은 계속 달라지지만 약 100이라는 일정한 수준을 중심으로 움직인다.

반면,

```text
100
110
120
130
140
150
160
```

은 시간이 지날수록 수준 자체가 계속 증가한다.

즉,

```text
정상성

≠

값이 변하지 않음
```

이고,

```text
값은 변하지만
통계적인 구조가
시간에 따라 안정적
```

이라는 의미이다.

<br>

> ## 3-3 ) Trend와 Seasonality가 정상성에 미치는 영향

Trend가 존재하면 평균적인 수준이 시간에 따라 달라질 수 있다.

```text
시간 증가
    ↓
전체 수준 증가
    ↓
평균 변화
```

Seasonality도 시점마다 반복되는 구조를 만들어 평균적인 패턴이 달라질 수 있다.

따라서 정상성을 확인할 때는 단순히 그래프가 평평해 보이는지만 보는 것이 아니라,

```text
Trend
+
Seasonality
+
평균 변화
+
분산 변화
+
Lag 관계
```

를 함께 확인해야 한다.

<br>

> ## 3-4 ) Unit Root

단위근을 가장 단순한 형태로 생각하면 다음과 같다.

```math
y_t = y_{t-1} + \varepsilon_t
```

| 기호 | 의미 |
|---|---|
| $`y_t`$ | 현재 시점의 값 |
| $`y_{t-1}`$ | 이전 시점의 값 |
| $`\varepsilon_t`$ | 새로운 변화 또는 충격 |

예를 들어,

```text
100
 ↓ +5
105
 ↓ -2
103
 ↓ +8
111
```

처럼 현재 값이 이전 값의 영향을 계속 이어받는 구조를 생각할 수 있다.

큰 충격이 발생한 뒤에도 그 영향이 이후 데이터 수준에 계속 남는다면 안정적인 평균으로 쉽게 돌아오지 않을 수 있다.

```text
과거 충격
    ↓
현재 수준 변화
    ↓
다음 시점에도 영향 지속
```

이러한 특성과 관련된 개념이 `Unit Root`이다.

단위근이 존재하는 시계열은 일반적으로 비정상 시계열과 관련된다.

# **4. ADF Test와 Differencing 이론**

> ## 4-1 ) ADF Test

**ADF Test(Augmented Dickey-Fuller Test)** 는 시계열에 단위근이 존재하는지를 검정하는 대표적인 통계적 방법이다.

가설은 다음과 같다.

```math
H_0: \text{Unit Root가 존재한다}
```

```math
H_1: \text{Unit Root가 존재하지 않는다}
```

유의수준을 `0.05`로 설정한다면 다음과 같이 해석한다.

| p-value | 판단 | 해석 |
|---|---|---|
| `< 0.05` | $`H_0`$ 기각 | 단위근이 없다는 방향의 근거 |
| `≥ 0.05` | $`H_0`$ 기각하지 못함 | 단위근이 없다고 판단할 충분한 근거 부족 |

특히 다음 두 표현을 구분해야 한다.

```text
p-value >= 0.05

잘못된 해석
→ 단위근이 존재한다.

더 정확한 해석
→ 단위근이 존재한다는
   귀무가설을 기각하지 못했다.
```

통계적 가설검정은 귀무가설이 참이라는 사실을 직접 증명하는 과정이 아니다.

<br>

> ## 4-2 ) Differencing (차분)

정상성을 만족하지 않는 시계열을 변환하는 대표적인 방법 중 하나가 **차분(Differencing)** 이다.

1차 차분은 다음과 같다.

```math
\Delta y_t = y_t - y_{t-1}
```

| 기호 | 의미 |
|---|---|
| $`\Delta y_t`$ | 현재 시점의 차분값 |
| $`y_t`$ | 현재 값 |
| $`y_{t-1}`$ | 이전 값 |

예를 들어,

```text
원본

100 → 110 → 125 → 135
```

이라면,

```text
차분

10 → 15 → 10
```

이 된다.

중요한 것은 차분 후 데이터의 의미가 달라진다는 것이다.

```text
원본
→ Level
→ 현재 수준

1차 차분
→ Change
→ 이전 시점 대비 변화량
```

<br>

> ## 4-3 ) 차분 후에는 다시 정상성을 확인해야 합니다

차분을 적용했다고 해서 자동으로 정상성이 확보되는 것은 아니다.

따라서 다음 흐름을 사용한다.

```text
원본 시계열
    ↓
시각화
    ↓
ADF Test
    ↓
정상성 부족
    ↓
차분
    ↓
차분 데이터 시각화
    ↓
ADF Test 재실행
    ↓
정상성 재확인
```

또한 차분은 많이 할수록 좋은 것이 아니다.

```text
필요 이상의 차분
        ↓
원본 정보 손실
        ↓
해석 어려움
        ↓
예측 정보 손실 가능
```

따라서 **필요한 만큼만 차분하고 매 단계에서 다시 진단하는 것**이 중요하다.

# **9. ADF Test로 정상성 검정**

> ## 9-1 ) 반복 검정을 위한 함수 만들기

같은 검정을 여러 변수에 반복하기 위해 함수를 만들 수 있다.

[ Python : code ] **"ADF Test 함수 생성"**

```python
def run_adf_test(series, name):
    result = adfuller(series.dropna())

    print(f"[ {name} ]")
    print("ADF Statistic:", round(result[0], 4))
    print("p-value:", result[1])
    print("Used Lag:", result[2])
    print("Observations:", result[3])

    for key, value in result[4].items():
        print(f"Critical Value {key} : {value:.4f}")
```

함수의 흐름은 다음과 같다.

```text
시계열 입력
    ↓
NaN 제거
    ↓
adfuller()
    ↓
ADF Statistic
p-value
Used Lag
Critical Values
    ↓
결과 출력
```

<br>

[ Python : code ] **"performance_index 정상성 검정"**

```text

    ↓

    ↓

ARIMA(p, 1, q)
         ↑
         d
```

# **11. 전체 분석 코드 연결**

> ## 11-1 ) 데이터 준비부터 차분 후 ADF Test까지

[ Python : code ] **"시계열 정상성 분석 전체 흐름"**

```python
import pandas as pd
import matplotlib.pyplot as plt

from statsmodels.tsa.seasonal import seasonal_decompose
from statsmodels.tsa.stattools import adfuller


# 1. 데이터 불러오기
data = pd.read_csv("sports_timeseries.csv")


# 2. timestamp 변환
data["timestamp"] = pd.to_datetime(data["timestamp"])


# 3. 시간 순서 정렬
data = data.sort_values("timestamp")


# 4. 시간 인덱스 설정
data = data.set_index("timestamp")


# 5. 기본 구조 확인
print(
    "Shape:",
    data.shape
)

print(
    "Frequency:",
    pd.infer_freq(data.index)
)


# 6. 원본 시계열
plt.figure(figsize=(14, 5))

plt.plot(
    data.index,
    data["performance_index"]
)

plt.title("Performance Index")

plt.show()


# 7. 자기상관
for lag in [1, 24, 168]:
    value = (
        data["performance_index"]
        .autocorr(lag=lag)
    )

    print(f"Lag {lag}: {value:.4f}")


# 8. 시계열 분해
decomposition = seasonal_decompose(
    data["performance_index"],
    model="additive",
    period=24
)

decomposition.plot()
plt.show()


# 9. 이동평균
data["rolling_mean_168h"] = (
    data["performance_index"]
    .rolling(window=168)
    .mean()
)


# 10. 원본 ADF Test
original_adf = adfuller(
    data["performance_index"]
    .dropna()
)

print(
    "Original ADF:",
    original_adf[0]
)

print(
    "Original p-value:",
    original_adf[1]
)


# 11. 1차 차분
data["performance_diff"] = (
    data["performance_index"]
    .diff()
)

diff_data = (
    data["performance_diff"]
    .dropna()
)


# 12. 차분 데이터 확인
plt.figure(figsize=(14, 5))

plt.plot(
    diff_data.index,
    diff_data
)

plt.axhline(0, linestyle="--")

plt.title("Differenced Performance Index")

plt.show()


# 13. 차분 후 ADF Test
diff_adf = adfuller(diff_data)

print(
    "Differenced ADF:",
    diff_adf[0]
)

print(
    "Differenced p-value:",
    diff_adf[1]
)
```

[ Result ]

```text
Shape: (5000, 9)
Frequency: h

Lag 1: 0.9895
Lag 24: 0.9627
Lag 168: 0.9791

Original ADF:
-2.3694

Original p-value:
0.15056064245961914

Differenced ADF:
-9.7531

Differenced p-value:
7.919092121921419e-17
```

# **12. Advanced 추가 학습**

> ## 12-1 ) 약한 정상성(Weak Stationarity)

이번 강의에서 설명한 정상성은 다음 구조와 연결된다.

```text
평균 일정
+
분산 일정
+
동일한 Lag의 관계 일정
```

특히 두 시점 사이의 관계가 실제 날짜보다 **두 관측값 사이의 Lag**에 의해 결정되는 구조를 생각할 수 있다.

이는 실무 시계열 분석에서 자주 다루는 `Weak Stationarity`의 기본적인 직관과 연결된다.

<br>

> ## 12-2 ) 정상성이 모든 머신러닝 모델의 필수 조건은 아닙니다

시계열 데이터라고 해서 항상 차분해야 하는 것은 아니다.

```text
시계열 데이터
=
무조건 차분
```

은 잘못된 접근이다.

정상성은 특히 ARIMA와 같은 전통적인 시계열 모델에서 중요하며, 사용하는 모델과 분석 목적에 따라 정상성의 필요성이 달라질 수 있다.

<br>

> ## 12-3 ) 계절 차분(Seasonal Differencing)

일반적인 1차 차분은 바로 이전 관측값과 비교한다.

```math
\Delta y_t = y_t - y_{t-1}
```

시간별 데이터에서 24시간 반복 패턴을 제거하고 싶다면 다음처럼 계절 차분을 사용할 수도 있다.

```math
\Delta_{24} y_t = y_t - y_{t-24}
```

[ Python : code ] **"24시간 계절 차분"**

```python
data["performance_diff_24"] = (
    data["performance_index"]
    .diff(24)
)
```

두 차분은 목적이 다르다.

| 방법 | 계산 | 주요 목적 |
|---|---|---|
| 1차 차분 | 현재 - 1시간 전 | Trend 완화 |
| 24시간 계절 차분 | 현재 - 24시간 전 | 하루 반복 패턴 완화 |

<br>

> ## 12-4 ) ACF와 PACF

정상성을 확보한 뒤에는 `ACF`와 `PACF`를 이용하여 여러 Lag와의 관계를 더 체계적으로 분석할 수 있다.

이후 ARIMA에서는 이러한 분석이,

```text
ARIMA(p, d, q)

p
→ AR 차수

d
→ 차분 차수

q
→ MA 차수
```

를 이해하는 과정과 연결된다.

<br>

> ## 12-5 ) KPSS Test

ADF Test와 다른 가설 구조를 가진 `KPSS Test`를 함께 사용할 수도 있다.

```text
ADF Test

H0
→ Unit Root 존재


KPSS Test

H0
→ 정상성
```

두 검정을 함께 사용하면 하나의 검정 결과만 보는 것보다 정상성을 여러 관점에서 판단할 수 있다.

# **13. 핵심정리**

이번 강의의 이론과 코드 실습을 함께 정리하면 다음과 같다.

| 개념 | 핵심 의미 |
|---|---|
| Time Series | 시간 순서에 따라 관측된 데이터 |
| Frequency | 관측값이 기록되는 시간 간격 |
| Lag | 현재와 과거 관측값 사이의 시차 |
| Autocorrelation | 현재값과 과거값 사이의 관계 |
| Trend | 장기적인 증가 또는 감소 흐름 |
| Seasonality | 일정한 간격으로 반복되는 패턴 |
| Residual | 주요 구조를 설명한 뒤 남은 변동 |
| Decomposition | 시계열을 구성요소로 분해하는 과정 |
| Stationarity | 통계적 특성이 시간에 따라 안정적인 성질 |
| Unit Root | 충격의 영향이 지속되는 비정상 구조와 관련된 개념 |
| ADF Test | 단위근 존재 여부 검정 |
| Differencing | 현재 값과 이전 값의 차이를 계산 |
| Rolling Mean | 이동하는 구간의 평균 |
| Seasonal Differencing | 동일한 계절 주기의 이전 값과 차분 |

시계열 데이터에서는 **시간과 순서가 데이터의 일부**이다.

따라서 분석 전에 반드시,

```text
datetime 변환
    ↓
시간 순서 정렬
    ↓
Frequency 확인
```

을 수행해야 한다.

시계열에 나타나는 주요 구조는 다음과 같다.

```math
Observed_t = Trend_t + Seasonal_t + Residual_t
```

`Trend`는 장기적인 흐름이고, `Seasonality`는 일정한 주기로 반복되는 패턴이며, `Residual`은 이러한 구조를 설명한 뒤 남은 변동이다.

정상성은 데이터 값이 항상 같은 것을 의미하지 않는다.

```text
평균
+
분산
+
동일 Lag에서의 관계
```

와 같은 통계적 특성이 시간에 따라 비교적 안정적으로 유지되는 것이 중요하다.

ADF Test에서는,

```math
H_0: \text{Unit Root가 존재한다}
```

를 귀무가설로 사용한다.

일반적으로,

```text
p-value < 0.05
→ H0 기각
→ 단위근이 없다는 방향의 근거

p-value >= 0.05
→ H0 기각하지 못함
→ 단위근이 없다고 판단할 근거 부족
```

으로 해석한다.

단, `p-value >= 0.05`라고 해서 단위근이 존재한다는 사실을 증명한 것은 아니다.

1차 차분은,

```math
\Delta y_t = y_t - y_{t-1}
```

이며 데이터의 의미가,

```text
Level
→ Change
```

로 변한다.

따라서 차분 후에는 반드시 시각화와 ADF Test를 다시 수행하여 정상성을 확인해야 한다.

이번 실습 데이터에서는 다음 결과가 나타났다.

| 데이터 | ADF Statistic | p-value | 해석 |
|---|---:|---:|---|
| `performance_index` | -2.3694 | 0.1506 | 정상성을 만족한다고 보기 어려움 |
| `stationary_signal` | -30.0881 | 약 0 | 정상성을 지지 |
| `performance_diff` | -9.7531 | 약 0 | 1차 차분 후 정상성을 지지 |

최종적인 정상성 분석 흐름은 다음과 같다.

```text
시계열 데이터 준비
        ↓
시간 순서 정렬
        ↓
Frequency 확인
        ↓
원본 시계열 시각화
        ↓
Autocorrelation 확인
        ↓
Trend / Seasonality / Residual 확인
        ↓
Rolling Mean과 통계량 확인
        ↓
ADF Test
        ↓
정상성을 만족하는가?
        ↓
필요하면 Differencing
        ↓
차분 데이터 시각화
        ↓
ADF Test 재실행
        ↓
정상성 재확인
        ↓
다음 시계열 모델링 단계
```

가장 중요한 것은 **ADF Test의 p-value 하나만 보고 기계적으로 정상성을 판단하거나 차분하는 것이 아니다.**

시계열 분석에서는 항상,

```text
시간 구조
+
Frequency
+
Trend
+
Seasonality
+
Autocorrelation
+
시각화
+
통계적 검정
+
분석 목적
```

을 함께 고려해야 한다.
