# **1. 과거 데이터로 미래 값을 예측하는 시계열 예측**

시계열(Time Series) 데이터는 **시간의 순서에 따라 관측된 데이터**다.

지난 학습에서는 시계열 데이터에서 나타날 수 있는 다음 특징을 확인했다.

```text
Trend (추세)
→ 장기적으로 증가하거나 감소하는 흐름

Seasonality (계절성)
→ 일정한 주기로 반복되는 패턴

Autocorrelation (자기상관성)
→ 현재 값과 과거 값 사이의 상관관계

Stationarity (정상성)
→ 시간에 따라 통계적 특성이 크게 변하지 않는 상태

Differencing (차분)
→ 이전 시점과 현재 시점의 차이를 계산하는 변환
```

이번에는 이러한 특성을 이용하여 **과거의 값을 이용해 아직 관측되지 않은 미래의 값을 예측하는 방법**을 학습한다.

스포츠과학에서는 다음과 같은 시계열 예측 문제를 생각할 수 있다.

| 분야 | 과거 데이터 | 예측 대상 |
| --- | --- | --- |
| 축구 GPS | 주간 고속주행거리 | 다음 주 고속주행거리 |
| 웨어러블 | 일별 HRV | 다음 날 HRV |
| 운동처방 | 주간 훈련부하 | 다음 주 훈련부하 |
| 야구 | 경기별 투구 수 | 다음 경기 투구부하 |
| 수영 | 세션별 스트로크 지표 | 다음 세션 수행값 |
| 보행 분석 | 일별 보행량 | 다음 날 보행량 |
| IoT 센서 | 시간별 온도·진동 | 다음 시간 센서값 |

예를 들어 선수의 주간 훈련부하가 다음과 같다고 가정한다.

```text
1주 → 120
2주 → 128
3주 → 135
4주 → 131
5주 → 142
6주 → ?
```

목적은 지금까지 관측한 값을 이용하여 **아직 관측하지 않은 6주의 값을 예측하는 것**이다.

```text
과거 관측값

120 → 128 → 135 → 131 → 142
                         ↓
                   미래 값 예측
                         ↓
                         ?
```

시계열 모델에서는 현재 값이 과거 값과 관련되어 나타날 수 있다는 특징을 이용한다.

대표적인 ARIMA 모델은 다음 세 가지 아이디어를 결합한다.

```text
AR
→ 과거의 실제 값 이용

I
→ 차분을 이용하여 시계열 변환

MA
→ 과거의 예측 오차 이용

        ↓

      ARIMA
```

전체적인 학습 흐름은 다음과 같다.

```text
시계열 데이터 준비
        ↓
시간 순서를 유지하여 Train / Test 분리
        ↓
AR · MA · I 이해
        ↓
ARIMA 모델 생성
        ↓
Train 데이터로 모델 학습
        ↓
미래 Test 기간 예측
        ↓
Actual과 Predicted 비교
        ↓
Prediction Interval 확인
        ↓
MAE · RMSE 평가
```

# **2. 시계열 데이터의 Train/Test 분리**

일반적인 머신러닝에서는 데이터를 무작위로 섞어 Train과 Test로 분리하는 경우가 많다.

하지만 **미래를 예측하는 시계열 문제에서는 시간 순서를 유지해야 한다.**

예를 들어 현재가 30주차이고 31~36주차를 예측한다고 가정한다.

```text
과거                                        미래
────────────────────────────────────────────→

1주                         30주 │ 31주          36주
└──────── Train ────────────────┘ └──── Test ─────┘

         학습 가능                  예측 대상
```

모델은 30주차까지의 정보만 이용해야 한다.

31~36주차는 미래라고 가정하고 모델에게 보여주지 않는다(학습하지 않는다).

<br>

> ## **2-1) 무작위 분리가 문제가 되는 이유**

다음과 같이 무작위로 분리했다고 가정한다.

```text
Train

2주
5주
18주
31주
34주
...

Test

3주
12주
24주
29주
...
```

29주차를 예측하는데 Train에 31주차와 34주차가 들어가 있다.

```text
29주차를 예측

             29주
              ↑
           예측 대상

24주 ───── 29주 ───── 31주 ───── 34주
                         ↑          ↑
                    Train에 포함
```

실제 29주차 시점에서는 31주와 34주의 값을 알 수 없다.

이처럼 **실제 예측 시점에서는 사용할 수 없는 미래 정보가 학습에 포함되는 문제**를 시간적 누수 또는 Look-ahead Leakage라고 할 수 있다.

```text
미래 정보
    ↓
Train에 유입
    ↓
실제 사용할 수 없는 정보를 학습
    ↓
평가 성능 과대평가 가능
```

따라서 미래 예측 문제에서는 일반적으로 다음 원칙을 사용한다.

```text
과거
 ↓
Train
 ↓
모델 학습
 ↓
미래
 ↓
Test
 ↓
성능 평가
```

<br>

> ## **2-2) Test 크기는 반드시 20%여야 하는가**

아니다.

시계열 데이터에서는 단순히 `80:20` 또는 `70:30` 비율을 적용하는 것보다 **실제로 얼마나 먼 미래를 예측할 것인지**가 중요하다.

```text
다음 날 예측
→ Test Horizon = 1일

다음 주 예측
→ Test Horizon = 1주

앞으로 4주 예측
→ Test Horizon = 4주

앞으로 6개월 예측
→ Test Horizon = 6개월
```

즉 다음 두 질문이 먼저 필요하다.

```text
어디까지 알고 있는가?
        ↓
Train 종료 시점

얼마나 먼 미래를 예측해야 하는가?
        ↓
Test 기간
```

이번 실습에서는 전체 36주 중 다음과 같이 사용한다.

```text
전체 = 36주

Train = 처음 30주
Test  = 마지막 6주
```

# **3. AR(Autoregressive) 모델**

AR은 **Autoregressive, 자기회귀**의 약자다.

AR 모델은 현재 값을 설명할 때 **과거에 실제로 관측된 값**을 이용한다.

가장 단순한 AR(1)은 직전 시점 하나를 사용한다.

```text
직전 값
  ↓
현재 값
```

AR(1)은 다음과 같이 표현할 수 있다.

```math
y_t
=
c
+
\phi_1 y_{t-1}
+
\epsilon_t
```

예측 시점의 새로운 오차를 제외한 예측값은 다음처럼 생각할 수 있다.

```math
\hat{y}_t
=
c
+
\phi_1 y_{t-1}
```

| 기호 | 의미 |
| --- | --- |
| `y_t` | 현재 시점의 값 |
| `y_{t-1}` | 직전 시점 값 |
| `c` | 상수항 |
| `φ₁` | AR 계수 |
| `ε_t` | 현재 시점 오차 |

<br>

> ## **3-1) AR 계수는 무엇인가**

예를 들어 모델이 다음 관계를 학습했다고 가정한다.

```text
현재 훈련부하 = 30 + 0.8 × 직전 주 훈련부하 + 오차
```

직전 훈련부하가 `139`라면 예측값은 다음과 같다.

```math
\hat{y}_t
=
30
+
0.8 \times 139
```

```math
\hat{y}_t
=
141.2
```

흐름은 다음과 같다.

```text
직전 훈련부하
139
 ↓
× 0.8
 ↓
111.2
 ↓
+ 30
 ↓
예측값
141.2
```

즉 AR은 직전 값을 그대로 복사하는 모델이 아니다.

**과거 값과 현재 값 사이의 관계를 계수로 학습하여 미래 값을 계산한다.**

<br>

> ## **3-2) AR에서 우리가 정하는 것과 모델이 학습하는 것**

다음 두 가지를 구분해야 한다.

| 구분 | 의미 |
| --- | --- |
| 사용자가 결정 | 몇 개의 과거 값을 사용할 것인가 |
| 모델이 학습 | 각 과거 값을 얼마나 반영할 것인가 |

과거 값을 몇 개 사용할지를 `p`라고 한다.

```text
AR(1)
→ Lag 1

AR(2)
→ Lag 1 + Lag 2

AR(3)
→ Lag 1 + Lag 2 + Lag 3
```

AR(2)는 다음과 같다.

```math
y_t
=
c
+
\phi_1 y_{t-1}
+
\phi_2 y_{t-2}
+
\epsilon_t
```

여기서 `φ₁`, `φ₂`는 모델이 학습한다.

<br>

> ## **3-3) Lag의 의미**

Lag는 현재 시점을 기준으로 이전 시점까지의 시간 차이다.

```text
27주       28주       29주       30주
127        135        158        172
 ↑          ↑          ↑
Lag 3      Lag 2      Lag 1      현재
```

`p=3`이면 Lag 1~3을 이용한다.

# **4. MA(Moving Average) 모델**

**MA** 모델은 과거의 실제 값이 아니라 **과거에 발생한 예측 오차**를 이용한다.

여기서 Moving Average라는 이름은 단순히 값들의 이동평균을 계산한다는 의미와 다르다.

시계열 모델의 MA는 **과거 오차 항을 이용하는 모델**이다.

예를 들어 다음과 같이 예측했다고 가정한다.

```text
실제값
137

예측값
132

 ↓

Error
= 137 - 132
= +5
```

오차는 다음과 같이 정의할 수 있다.

```math
Error_t = Actual_t - Predicted_t
```

<br>

> ## **4-1) MA(1)의 구조**

MA(1)은 직전 오차 하나를 이용한다.

```math
y_t
=
\mu
+
\theta_1 \epsilon_{t-1}
+
\epsilon_t
```

예측값은 개념적으로 다음과 같다.

```math
\hat{y}_t
=
\mu
+
\theta_1 \epsilon_{t-1}
```

| 기호 | 의미 |
| --- | --- |
| `μ` | 시계열의 평균 수준 |
| `ε_{t-1}` | 직전 시점의 오차 |
| `θ₁` | MA 계수 |
| `ε_t` | 현재 새롭게 발생하는 오차 |

예를 들어 다음과 같다고 가정한다.

```text
평균 수준 = 135

MA 계수 = 0.6

직전 오차 = +5
```

예측값은 다음과 같다.

```math
\hat{y}_t
=
135
+
0.6 \times 5
```

```math
\hat{y}_t
=
138
```

<br>

> ## **4-2) MA의 오차는 원본 데이터에 직접 들어 있지 않다**

AR이 사용하는 과거 값은 실제 데이터에서 바로 확인할 수 있다.

```text
AR

1주 값
2주 값
3주 값
...
→ 직접 관측 가능
```

반면 MA의 오차는 모델의 예측 과정과 관련되어 있다.

```text
모델 파라미터
      ↓
예측값
      ↓
예측 오차
```

따라서 MA 모델은 데이터에 적합하도록 MA 계수 등의 파라미터를 추정해야 한다.

<br>

> ## **4-3) q의 의미**

MA에서 과거 오차를 몇 개 사용할지를 `q`로 나타낸다.

```text
MA(1)
→ 직전 오차 1개

MA(2)
→ 과거 오차 2개

MA(3)
→ 과거 오차 3개
```

MA(2)는 다음과 같다.

```math
y_t
=
\mu
+
\theta_1 \epsilon_{t-1}
+
\theta_2 \epsilon_{t-2}
+
\epsilon_t
```

AR과 MA를 비교하면 다음과 같다.

| 모델 | 사용하는 정보 | 모델이 학습 |
| --- | --- | --- |
| AR | 과거 실제값 | AR 계수 |
| MA | 과거 예측 오차 | MA 계수 |

# **5. I(Integrated)와 ARIMA**

AR과 MA는 기본적으로 정상성을 고려한 시계열 구조다.

하지만 실제 스포츠과학 데이터에는 다음과 같은 변화가 나타날 수 있다.

```text
훈련량 증가
경기 일정 변화
재활 진행
시즌 단계 변화
컨디션 변화
```

이러한 추세 때문에 정상성을 만족하기 어렵다면 차분(Differencing)을 사용할 수 있다.

<br>

> ## **5-1) Differencing**

원본 값이 다음과 같다고 가정한다.

```text
123 → 128 → 132 → 129
```

1차 차분은 다음과 같다.

```text
128 - 123 = +5

132 - 128 = +4

129 - 132 = -3
```

따라서 다음처럼 변환된다.

```text
원본

123 → 128 → 132 → 129

       ↓ 1차 차분

     +5 → +4 → -3
```

차분은 수식으로 다음과 같이 표현할 수 있다.

```math
\Delta y_t
=
y_t
-
y_{t-1}
```

ARIMA에서 차분 횟수를 `d`라고 한다.

```text
d = 0
→ 차분 없음

d = 1
→ 1차 차분

d = 2
→ 2차 차분
```

차분은 많을수록 좋은 것이 아니다.

**정상성을 확보하기 위해 필요한 수준만 사용해야 한다.**

<br>

> ## **5-2) ARIMA(p, d, q)**

ARIMA는 **AutoRegressive Integrated Moving Average**의 약자다.

```text
AR
+
I
+
MA
=
ARIMA
```

모델은 다음과 같이 표현한다.

```text
ARIMA(p, d, q)
```

| 파라미터 | 의미 |
| --- | --- |
| `p` | AR에서 사용할 과거 값 수 |
| `d` | 차분 횟수 |
| `q` | MA에서 사용할 과거 오차 수 |

예를 들어 다음 모델을 생각해볼 수 있다.

```text
ARIMA(2, 1, 1)
       ↓  ↓  ↓
       p  d  q
```

해석하면 다음과 같다.

```text
p = 2
→ AR 부분에서 Lag 2까지 사용

d = 1
→ 1차 차분

q = 1
→ MA 부분에서 과거 오차 1개 사용
```

<br>

> ## **5-3) ARIMA(2,1,1)의 흐름**

개념적으로 다음과 같이 이해할 수 있다.

```text
원본 시계열
      ↓
1차 차분
      ↓
변화량 시계열
      ↓
과거 변화량 2개의 관계
      +
과거 오차 1개의 관계
      ↓
다음 시점 변화 예측
      ↓
원래 시계열의 수준으로 변환
      ↓
최종 미래 값 예측
```

`statsmodels`의 `ARIMA`를 사용하면 차분과 원래 단위로 복원하는 과정은 모델 내부에서 처리된다.

따라서 사용자가 예측값에 직접 누적합을 다시 적용할 필요는 없다.

<br>

> ## **5-4) p, d, q와 모델 계수의 차이**

매우 중요한 구분이다.

```text
우리가 설정

p
d
q

        ↓

모델 구조

모델이 학습

AR 계수
MA 계수
오차 분산 등

        ↓

모델 파라미터
```

`ARIMA(2,1,1)`을 설정했다고 해서 AR 계수가 `2`, MA 계수가 `1`이라는 뜻이 아니다.

`2,1,1`은 **모델의 구조**다.

실제 계수는 Train 데이터에서 추정한다.

# **6. ARIMA 모델은 어떻게 학습하는가**

`statsmodels`의 ARIMA에서는 `fit()`을 실행하여 Train 데이터에 적합한 파라미터를 추정한다.

핵심 개념은 Likelihood다.

Likelihood는 현재 파라미터를 사용했을 때 **실제로 관측된 데이터가 얼마나 그럴듯하게 나타나는지**와 관련된 값이다.

```text
초기 파라미터
      ↓
Likelihood 계산
      ↓
파라미터 조정
      ↓
Likelihood 다시 계산
      ↓
반복
      ↓
관측 데이터를 잘 설명하는
파라미터 추정
```

Likelihood가 최대가 되도록 파라미터를 추정하는 방법을 **Maximum Likelihood Estimation, MLE**라고 한다.

실제 계산에서는 Log-Likelihood를 주로 사용한다.

```text
Likelihood 최대화

        ≈

Log-Likelihood 최대화
```

<br>

> ## **6-1) ARIMA 모델 직접 생성**

[ Python : code ] "훈련부하 Train 데이터로 ARIMA(2,1,1) 모델 생성 및 학습"

```python
from statsmodels.tsa.arima.model import ARIMA

model = ARIMA(
    train["training_load_au"],
    order=(2, 1, 1)
)

model_fit = model.fit()

print(model_fit.params.round(4))
```

[ Result ]

```text
ar.L1       0.3677
ar.L2      -0.2373
ma.L1      -0.6793
sigma2    173.3441
dtype: float64
```

여기서 다음 값들은 `fit()`을 통해 학습된 결과다.

```text
ar.L1
→ Lag 1의 AR 계수

ar.L2
→ Lag 2의 AR 계수

ma.L1
→ Lag 1 오차의 MA 계수

sigma2
→ 오차 분산과 관련된 값
```

즉 코드의 역할은 다음처럼 구분된다.

```text
ARIMA(
    ...,
    order=(2,1,1)
)

→ 모델 구조 지정

model.fit()

→ Train 데이터 이용
→ 모델 파라미터 추정
```

전체 흐름은 다음과 같다.

```text
Train 데이터
      ↓
ARIMA(2,1,1) 구조
      ↓
fit()
      ↓
Likelihood 기반
파라미터 추정
      ↓
AR 계수
MA 계수
오차 분산
      ↓
학습된 모델
```

# **7. ARIMA를 이용한 미래 예측**

모델 학습이 완료되면 Train 종료 시점 이후의 미래 값을 예측할 수 있다.

현재 실습에서는 다음과 같다.

```text
Train
2026-01-05 ~ 2026-07-27

              ↓ 예측 시작

Test
2026-08-03 ~ 2026-09-07
```

Test의 실제값은 이미 데이터에 존재하지만 모델 학습에는 사용하지 않는다.

즉 다음과 같이 생각한다.

```text
모델 입장

Train
→ 알고 있음

Test
→ 아직 발생하지 않은 미래라고 가정
```

<br>

> ## **7-1) Forecast Horizon**

현재 시점에서 앞으로 몇 시점까지 예측할 것인지를 **Forecast Horizon**이라고 한다.

```text
Horizon = 1
→ 다음 1시점

Horizon = 3
→ 앞으로 3시점

Horizon = 6
→ 앞으로 6시점
```

이번 실습에서는 Test가 6주이므로 다음과 같다.

```text
Forecast Horizon = 6
```

```text
현재
30주
 ↓
31주 → 32주 → 33주 → 34주 → 35주 → 36주
 ↑                                      ↑
1-step                               6-step
```

<br>

> ## **7-2) Multi-step Forecast**

여러 미래 시점을 한 번에 예측하는 것을 Multi-step Forecast라고 한다.

```text
30주까지 관측
      ↓
ARIMA
      ↓
31주 예측
32주 예측
33주 예측
34주 예측
35주 예측
36주 예측
```

여기서 Test의 실제 31주 값을 모델에 넣은 뒤 32주를 다시 예측하는 것이 아니다.

**30주까지의 정보만 알고 있는 상태에서 미래 6주를 예측한다.**

<br>

> ## **7-3) 미래 6주 직접 예측**

[ Python : code ] "ARIMA 모델로 미래 6주 훈련부하 예측"

```python
forecast_result = model_fit.get_forecast(steps=len(test))

predicted = forecast_result.predicted_mean

print(predicted.round(3))
```

[ Result ]

```text

2026-08-17    135.360
2026-08-24    135.703
2026-08-31    135.814
2026-09-07    135.773
Freq: W-MON
```

첫 번째 미래 시점의 예측은 약 `136.64`다.

더 먼 시점으로 이동하면서 예측값은 약 `135~136` 수준으로 수렴하는 형태를 보인다.

# **8. Prediction Interval과 예측 불확실성**

미래 예측값이 `136.64`라고 해서 실제값이 반드시 정확히 `136.64`가 된다는 의미는 아니다.

미래에는 모델이 설명하지 못하는 새로운 변동이 발생할 수 있다.

따라서 미래 예측에는 **불확실성**이 존재한다.

이를 범위로 나타내는 방법이 Prediction Interval이다.

개념적으로 95% Prediction Interval은 다음처럼 생각할 수 있다.

```math
Prediction\ Interval
\approx
Forecast
\pm
1.96
\times
Forecast\ Standard\ Error
```

<br>

> ## **8-1) Forecast Standard Error**

Forecast Standard Error는 **특정 미래 시점의 예측 불확실성 크기**와 관련된 값이다.

```text
Forecast Standard Error 작음
        ↓
불확실성 상대적으로 작음
        ↓
예측 구간 좁음

Forecast Standard Error 큼
        ↓
불확실성 상대적으로 큼
        ↓
예측 구간 넓음
```

<br>

> ## **8-2) 95% Prediction Interval 직접 계산**

[ Python : code ] "ARIMA 미래 예측값과 95% 예측 구간 계산"

```python
prediction_interval = forecast_result.conf_int(alpha=0.05)

result = pd.DataFrame({
    "actual":test["training_load_au"],
    "predicted":predicted,
    "lower":prediction_interval.iloc[:, 0],
    "upper":prediction_interval.iloc[:, 1]
})

result["error"] = result["actual"] - result["predicted"]

print(result.round(3))
```

<br>

> ## **8-3) 실제 미래에서는 Actual을 알 수 없다**

모델 평가 상황과 실제 미래 예측 상황은 구분해야 한다.

| 구분 | Actual | Error | Prediction Interval |
| --- | --- | --- | --- |
| 과거 Test 평가 | 존재 | 계산 가능 | 계산 가능 |
| 실제 미래 예측 | 아직 없음 | 계산 불가 | 계산 가능 |

모델 평가 단계에서는 Test의 정답이 존재한다.

```text
Train
 ↓
모델 학습
 ↓
Test 예측
 ↓
숨겨두었던 Actual 확인
 ↓
Error 계산
```

반면 실제 미래는 다음과 같다.

```text
현재까지 데이터
      ↓
모델 학습
      ↓
미래 예측
      ↓
Predicted
+
Prediction Interval

Actual
→ 아직 없음

Error
→ 계산 불가능
```

시간이 지나 Actual이 관측된 이후에야 오차를 계산할 수 있다.

<br>

> ## **8-4) Forecast Horizon과 불확실성**

현재 실습의 Prediction Interval을 보면 미래로 갈수록 대체로 넓어지는 것을 확인할 수 있다.

```text
1-step

110.832 ─── 136.637 ─── 162.442

6-step

99.927 ─────── 135.773 ─────── 171.619
```

일반적으로 먼 미래로 갈수록 아직 관측되지 않은 정보가 증가하므로 예측 불확실성이 커질 수 있다.

다만 모든 시계열과 모든 모델에서 구간이 반드시 계속 넓어진다고 단정할 수는 없다.

# **9. 시계열 예측 평가 : MAE와 RMSE**

미래 값을 예측한 뒤 모델의 성능을 비교하려면 Actual과 Predicted 사이의 차이를 수치화해야 한다.

대표적인 지표가 MAE와 RMSE다.

<br>

> ## **9-1) Error**

예측 오차는 다음과 같다.

```math
Error_t
=
Actual_t
-
Predicted_t
```

예를 들어 실제 훈련부하가 `140`, 예측값이 `145`라면 다음과 같다.

```math
Error
=
140
-
145
=
-5
```

음수이므로 실제보다 크게 예측한 것이다.

<br>

> ## **9-2) MAE**

MAE는 **Mean Absolute Error**다.

각 오차의 절댓값을 계산한 뒤 평균을 구한다.

```math
MAE
=
\frac
{\sum_{i=1}^{n}|y_i-\hat{y}_i|}
{n}
```

예를 들어 다음과 같다고 가정한다.

```text
Actual       100    110    120

Predicted    104    107    122

절대오차        4      3      2
```

MAE는 다음과 같다.

```math
MAE
=
\frac{4+3+2}{3}
=
3
```

즉 평균적으로 실제값과 약 `3` 정도 차이가 발생했다고 해석할 수 있다.

MAE는 원래 Target과 같은 단위를 가진다는 장점이 있다.

<br>

> ## **9-3) RMSE**

RMSE는 **Root Mean Squared Error**다.

```math
RMSE
=
\sqrt{
\frac
{\sum_{i=1}^{n}(y_i-\hat{y}_i)^2}
{n}
}
```

오차가 다음과 같다고 가정한다.

```text
2
3
10
```

제곱하면 다음과 같다.

```text
2²  =   4
3²  =   9
10² = 100
```

큰 오차 `10`이 `100`으로 커진다.

따라서 RMSE는 **큰 예측 실패에 상대적으로 더 민감하다.**

| 지표 | 특징 |
| --- | --- |
| MAE | 평균적인 절대 오차를 직관적으로 표현 |
| RMSE | 큰 오차에 상대적으로 더 큰 영향 |
| 공통점 | 작을수록 Actual과 Predicted 차이가 작음 |
| 단위 | 두 지표 모두 원래 Target과 같은 단위 |

# **11. 모델 평가와 실제 미래 예측의 차이**

모델 개발 과정에서 사용하는 Test는 실제로 이미 가지고 있는 과거 데이터다.

다만 모델에게 보여주지 않고 미래처럼 사용한다.

```text
전체 데이터

과거 ───────────────────────── 현재

평가 과정

Train
───────┐

        │ 경계

        └──── Test
              ↑
        미래라고 가정
```

따라서 Test에서는 Actual을 알고 있기 때문에 다음을 계산할 수 있다.

```text
Predicted
+
Actual
↓
Error
↓
MAE
RMSE
```

반면 아직 발생하지 않은 실제 미래에서는 다음과 같다.

```text
Predicted
→ 계산 가능

Prediction Interval
→ 계산 가능

Actual
→ 아직 모름

Error
→ 계산 불가

MAE / RMSE
→ 계산 불가
```

시간이 지나 Actual이 관측되면 그때 오차를 계산한다.

<br>

> ## **11-1) 개발과 실제 운영 흐름 비교**

| 단계 | 모델 개발·평가 | 실제 미래 예측 |
| --- | --- | --- |
| 과거 데이터 | 있음 | 있음 |
| 모델 학습 | 가능 | 가능 |
| 미래 예측 | Test에 대해 수행 | 실제 미래에 수행 |
| Actual | 이미 존재하지만 숨김 | 아직 존재하지 않음 |
| Error | 계산 가능 | 아직 불가능 |
| Prediction Interval | 계산 가능 | 계산 가능 |
| MAE/RMSE | 계산 가능 | Actual 발생 후 가능 |

<br>

> ## **11-2) 한 번에 여러 시점 예측과 한 시점씩 갱신하는 예측**

두 방식은 서로 다르다.

**방법 1. Multi-step Forecast**

```text
30주까지 학습
      ↓
31주
32주
33주
34주
35주
36주

한 번에 예측
```

**방법 2. Rolling / One-step Forecast**

```text
30주까지 학습
      ↓
31주 예측
      ↓
31주 실제값 관측
      ↓
31주까지 반영
      ↓
32주 예측
      ↓
반복
```

두 모델을 비교할 때는 동일한 예측 방식을 사용해야 한다.

```text
동일한 Forecast Horizon
+
동일한 Forecast 방식
+
동일한 Test 기간
```

# **12. 스포츠과학 ARIMA 실무 전체 코드**

지금까지 내용을 하나의 코드로 연결한다.

이 코드는 다음 단계를 모두 포함한다.

```text
주간 훈련부하 DataFrame 생성
        ↓
날짜 Index 설정
        ↓
Train/Test 분리
        ↓
ARIMA(2,1,1)
        ↓
fit()
        ↓
미래 6주 예측
        ↓
95% Prediction Interval
        ↓
Actual / Predicted / Error
        ↓
MAE / RMSE
        ↓
그래프
```

[ Python : code ] "스포츠과학 주간 훈련부하 ARIMA 예측 전체 실무 코드"

```python
import pandas as pd
import matplotlib.pyplot as plt

from statsmodels.tsa.arima.model import ARIMA

from sklearn.metrics import (
    mean_absolute_error,
    mean_squared_error
)

# 1. 시계열 DataFrame 생성
training_data = pd.DataFrame({
    "date": pd.date_range(
        start="2026-01-05",
        periods=36,
        freq="W-MON"
    ),

    "training_load_au": [
        98, 102, 105, 101, 108, 112,
        109, 115, 111, 118, 139, 154,
        110, 113, 117, 115, 121, 126,
        123, 130, 127, 135, 158, 172,
        123, 128, 132, 129, 137, 139,
        136, 143, 140, 148, 171, 189
    ]
})

# 2. 날짜 정렬 및 Index 설정
training_data = (
    training_data
    .sort_values("date")
    .set_index("date")
)

# 3. Train / Test 분리
train = training_data.iloc[:-6]
test = training_data.iloc[-6:]

# 4. ARIMA 모델 생성
model = ARIMA(
    train["training_load_au"],
    order=(2, 1, 1)
)

# 5. Train 데이터로 학습
model_fit = model.fit()

# 6. Test Horizon만큼 미래 예측
forecast_result = (
    model_fit.get_forecast(
        steps=len(test)
    )
)

# 7. 예측값
predicted = forecast_result.predicted_mean

# 8. 95% Prediction Interval
prediction_interval = forecast_result.conf_int(alpha=0.05)


# 9. 결과 DataFrame
result = pd.DataFrame({
    "actual": test["training_load_au"],

    "predicted": predicted,

    "lower": prediction_interval.iloc[:, 0],

    "upper": prediction_interval.iloc[:, 1]
})

# 10. Error
result["error"] = result["actual"] - result["predicted"]


# 11. MAE
mae = mean_absolute_error(result["actual"], result["predicted"])

# 12. RMSE
rmse = mean_squared_error(result["actual"], result["predicted"]) ** 0.5

# 13. 결과 출력
print(result.round(3))

print()

print(f"MAE: {mae:.2f}")

print(f"RMSE: {rmse:.2f}")

# 14. 시각화
plt.figure(figsize=(12, 5))

plt.plot(
    train.index,
    train["training_load_au"],
    label="Train"
)

plt.plot(
    test.index,
    test["training_load_au"],
    label="Actual"
)

plt.plot(
    result.index,
    result["predicted"],
    label="Predicted"
)

plt.fill_between(
    result.index,
    result["lower"],
    result["upper"],
    alpha=0.2,
    label="95% Prediction Interval"
)

plt.xlabel("Date")

plt.ylabel("Training Load (AU)")

plt.title("ARIMA Training Load Forecast")

plt.legend()

plt.tight_layout()

plt.show()
```

# **13. 양궁 센서 데이터 5,000개를 이용한 실무형 ARIMA 실습**

이전처럼 값이 일정하게 증가하는 단순 예제 대신 **훈련 단계 변화, 느린 수준 변화, 단기 흔들림, 일시적 센서 튐**을 함께 적용한다. 교육용 합성 데이터이며 실제 측정값 또는 특정 선수의 피로 진단이 아니다.

```text
합성 센서 데이터 → 추세 확인 → Train/Test → ADF → d 결정
                  → ACF/PACF → ARIMA → 예측 구간 → MAE/RMSE
```

> ## **13-1) 데이터 정의와 실제 분석 상황**

| 항목 | 설정 |
|---|---|
| 대상 | 한 명의 가상 양궁 선수, 한 세션 |
| 시간 | 2026-09-01 09:00:00부터 1초 간격 |
| 데이터 | 5,000개(약 83분 20초) |
| Target | `postural_sway_rms_mm` (mm) |
| Train/Test | 4,700개 / 300개 |
| 예측 | 4,700초까지로 다음 300초를 한 번에 예측 |
| 중요한 점 | 구간마다 자세 흔들림 수준이 달라짐 |

훈련 상태가 항상 한 방향으로 변하지는 않는다는 점을 보여 주기 위해, 특정 구간의 수준을 올리거나 내리고 짧은 이상 변동도 추가한다. `postural_sway_rms_mm`은 이번 예제에서 1초마다 기록한 가상의 RMS 요약 지표다.

<br>

> ## **13-2) 데이터 생성**

[ Python : code ] "구간 전환과 센서 변동이 섞인 양궁 데이터 생성"

```python
%matplotlib inline

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from statsmodels.tsa.stattools import adfuller, acf, pacf
from statsmodels.graphics.tsaplots import plot_acf, plot_pacf
from statsmodels.tsa.arima.model import ARIMA
from sklearn.metrics import mean_absolute_error, mean_squared_error

rng = np.random.default_rng(42)
n = 5000
t = np.arange(n)
time = pd.date_range("2026-09-01 09:00:00", periods=n, freq="s")

# 1. 천천히 누적되는 기저 수준 변화
baseline = 3.0 + np.cumsum(rng.normal(0, 0.006, n))

# 2. 훈련 단계에 따른 변화(수준 증가와 감소가 모두 존재)
phase = np.zeros(n)
phase[800:1550] = 0.22
phase[1550:2250] = -0.08
phase[2250:3200] = 0.30
phase[3200:3800] = 0.08
phase[3800:4500] = 0.48
phase[4500:] = 0.20

# 3. 완만한 반복 변화와 짧은 측정 변동
sway = baseline + phase + 0.11 * np.sin(t / 90)
sway += rng.normal(0, 0.075, n)

# 4. 짧은 센서 튐을 가정한 이벤트
sway[1050:1055] += 0.35
sway[2950:2956] += 0.28
sway[4210:4214] += 0.32

data = pd.DataFrame({"postural_sway_rms_mm": np.round(sway, 3)}, index=time)
data.index.name = "timestamp"

print("데이터:", len(data), "개")
print("최솟값:", data.iloc[:, 0].min())
print("최댓값:", data.iloc[:, 0].max())
print("첫 값:", data.iloc[0, 0])
print("마지막 값:", data.iloc[-1, 0])
```

[ Result ]

```text
데이터: 5000 개
최솟값: 1.971
최댓값: 3.494
첫 값: 2.982
마지막 값: 2.497
```

| 표현 | 의미 |
|---|---|
| `rng.normal()` | 작은 무작위 변동 생성 |
| `np.cumsum()` | 작은 변화가 시간에 따라 누적되는 상황 |
| `phase[구간]` | 특정 훈련 단계에서 수준 변경 |
| `np.sin()` | 완만하게 오르내리는 반복 패턴 |
| `sway[1050:1055] += 0.35` | 짧은 이상 변동 추가 |

**실무 해석:** 첫 값보다 마지막 값이 낮더라도, 그 사이에 상승·하락·급등 구간이 섞여 있다. 시작과 끝만으로 추세를 판단하면 안 된다.

> ## **13-4) ADF 정상성 검정과 차분 차수 d 결정**

ADF 검정의 귀무가설은 `단위근이 존재한다`는 것이다.  
  
`p-value < 0.05`면 귀무가설을 기각하지만, 이것만으로 모든 정상성 조건이 증명되지는 않는다.  
  
훈련 단계 변화나 결정적 추세가 있는 데이터에서는 해석에 주의한다.

[ Python : code ] "양궁 원본과 1차 차분의 ADF 결과 비교"

```python
# 원본 Train
```

> ## **13-5) ACF와 PACF로 p, q 후보 살펴보기**

| 항목 | 어떤 관계를 나타내는가 | 참고 용도 |
|---|---|---|
| ACF | 현재와 이전 시점 값의 상관 | `q` 후보 탐색 참고 |
| PACF | 중간 시차 영향을 제외한 관계 | `p` 후보 탐색 참고 |

차분 후 데이터로 확인한다.

```text

```

Lag 1에서 음의 상관이 크게 나타난다.  
  
ACF의 초기 패턴을 참고하여 `q=1`을 후보로 삼는다.  
  
PACF만으로 `p=1`을 확정할 수는 없지만, `p=1`을 첫 후보로 시도한다.

```text
p=1  (연습용 AR 후보)
d=1  (이번 ADF 진단에 따른 값)
q=1  (초기 ACF 패턴 참고)
→ ARIMA(1,1,1)
```

복잡한 후보 자동 탐색 없이 **한 모델을 먼저 학습**하며, 이 차수가 최적이라고 주장하지 않는다.

# **14. 오픈워터 수영 GPS 데이터 5,000개를 이용한 실무형 ARIMA 실습**

오픈워터 수영의 속도는 한 방향으로만 감소하거나 증가하기보다  
**준비 페이스, 가속 구간, 회복 구간, 페이스 유지, GPS 변동**이 섞여 나타날 수 있다. 

> ## **14-1) 데이터 정의와 분석 목적**

| 항목 | 설정 |

| 데이터 수 | 5,000개 |
| Target | `gps_speed_mps` (m/s) |
| Train/Test | 4,700개 / 300개 |
| 변화 패턴 | 구간별 페이스 전환 + 부드러운 변동 + 짧은 하락 |

양궁은 mm 단위의 자세 흔들림이고, 수영은 m/s 단위의 속도다. 두 지표의 MAE를 숫자만 보고 직접 비교하지 않는다.

> ## **14-2) 수영 데이터 생성과 추세 시각화**

[ Python : code ] "구간별 페이스 변동이 있는 수영 GPS 속도 데이터 생성"

```python
%matplotlib inline

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from statsmodels.tsa.stattools import adfuller, acf, pacf
from statsmodels.graphics.tsaplots import plot_acf, plot_pacf
from statsmodels.tsa.arima.model import ARIMA
from sklearn.metrics import mean_absolute_error, mean_squared_error

rng = np.random.default_rng(24)
n = 5000
t = np.arange(n)
time = pd.date_range("2026-09-01 09:00:00", periods=n, freq="s")

# 1. 서서히 달라지는 기본 속도
baseline = 1.22 + np.cumsum(rng.normal(0, 0.0008, n))

# 2. 준비·가속·회복 구간
pace = np.zeros(n)
pace[:650] = -0.10
pace[650:1500] = 0.06
pace[1500:2150] = -0.07
pace[2150:3150] = 0.13
pace[3150:3850] = -0.04
pace[3850:4500] = 0.10
pace[4500:] = -0.025

# 3. 리듬 변화와 작게 변동하는 GPS 속도 요약값
speed = baseline + pace + 0.035 * np.sin(t / 85)
speed += 0.014 * np.sin(t / 12) + rng.normal(0, 0.03, n)

# 4. 짧은 속도 하락/측정 변동 상황
speed[1200:1204] -= 0.10
speed[2870:2874] -= 0.12
speed[4270:4274] -= 0.11

data = pd.DataFrame({"gps_speed_mps": np.round(speed, 3)}, index=time)
data.index.name = "timestamp"

print("데이터:", len(data), "개")
print("최솟값:", data.iloc[:, 0].min())
print("최댓값:", data.iloc[:, 0].max())
print("첫 값:", data.iloc[0, 0])
print("마지막 값:", data.iloc[-1, 0])
```

```text
최댓값: 1.515
첫 값: 1.131

```

# **16. Advanced 추가 학습**

> ## **16-1) ACF와 PACF를 이용한 p, q 후보 탐색**

ARIMA의 `p`, `q`는 무작정 정하기보다 ACF와 PACF를 이용하여 후보를 탐색할 수 있다.

```text
PACF
→ AR 차수 p 탐색에 참고

ACF
→ MA 차수 q 탐색에 참고
```

단, 그래프 하나만으로 최종 모델을 결정하기보다 예측 성능과 잔차도 함께 확인한다.

<br>

> ## **16-2) AIC와 BIC**

여러 ARIMA 모델을 비교할 때 AIC와 BIC를 사용할 수 있다.

```text
작을수록
→ 적합도와 복잡도의 균형 측면에서 유리한 후보
```

하지만 AIC/BIC가 작다는 이유만으로 Test 예측 성능까지 반드시 가장 좋은 것은 아니다.

<br>

> ## **16-3) Rolling Forecast**

실제 스포츠 현장에서는 새로운 주차의 데이터가 들어올 때마다 다음 주를 다시 예측할 수 있다.

```text
1~30주 학습
→ 31주 예측

31주 Actual 추가
→ 1~31주 학습
→ 32주 예측

32주 Actual 추가
→ 다음 주 예측
```

이는 한 번에 6주를 예측하는 Multi-step Forecast와 다른 평가 방식이다.

<br>

> ## **16-4) 계절성이 강하면 SARIMA**

ARIMA는 비계절 ARIMA 모델이다.

요일, 주간, 월간 또는 시즌 주기가 뚜렷하다면 계절 구조를 추가한 SARIMA도 학습할 수 있다.

```text
ARIMA
+
Seasonal 구조

      ↓

SARIMA
```

# **17. 핵심정리**

1. 시계열 예측은 **과거에 관측된 데이터를 이용하여 미래 값을 예측하는 문제**다.

2. 시계열 데이터에서는 시간 순서가 중요하므로 미래 예측을 평가할 때 일반적으로 데이터를 무작위로 섞지 않는다.

3. Train은 과거 구간, Test는 그 이후의 미래 구간으로 구성한다.

4. 미래 정보가 Train에 들어가면 Look-ahead Leakage가 발생하여 실제보다 좋은 성능이 나타날 수 있다.

5. Test 크기는 단순한 `80:20` 비율보다 실제 Forecast Horizon을 고려하여 결정하는 것이 중요하다.

6. AR은 과거의 실제 값을 이용한다.

```math
y_t
=
c
+
\phi_1 y_{t-1}
+
\epsilon_t
```

7. `p`는 AR에서 몇 개의 과거 Lag를 사용할지를 의미하고, 실제 AR 계수는 모델이 학습한다.

8. MA는 과거의 예측 오차를 이용한다.

```math
y_t
=
\mu
+
\theta_1\epsilon_{t-1}
+
\epsilon_t
```

9. `q`는 MA에서 몇 개의 과거 오차를 사용할지를 의미하며, MA 계수는 모델이 학습한다.

10. I(Integrated)는 차분을 의미하고 `d`는 차분 횟수를 나타낸다.

```math
\Delta y_t
=
y_t-y_{t-1}
```

11. ARIMA는 다음 구조로 표현한다.

```text
ARIMA(p, d, q)

p
→ AR Lag 수

d
→ 차분 횟수

q
→ MA 오차 Lag 수
```

12. `order=(p,d,q)`는 모델 구조를 지정하는 것이고 `fit()`은 Train 데이터에서 실제 파라미터를 추정하는 과정이다.

13. `statsmodels`의 ARIMA는 Likelihood 기반으로 모델 파라미터를 추정한다.

14. Forecast Horizon은 현재 시점으로부터 앞으로 몇 시점까지 예측할지를 의미한다.

15. 현재 시점에서 여러 미래 시점을 한 번에 예측하는 것을 Multi-step Forecast라고 한다.

16. 먼 미래로 갈수록 아직 관측되지 않은 정보가 많아져 예측 불확실성이 커질 수 있다.

17. Prediction Interval은 하나의 예측값뿐 아니라 미래 예측의 불확실성을 범위로 나타낸다.

18. 모델 평가 단계에서는 Test Actual이 존재하기 때문에 예측 오차를 계산할 수 있다.

19. 실제 미래를 예측하는 순간에는 Actual이 없기 때문에 Error, MAE, RMSE를 아직 계산할 수 없다.

20. 미래 Actual이 관측된 이후에는 Predicted와 비교하여 실제 운영 성능을 다시 평가할 수 있다.

21. MAE는 절대 오차의 평균이다.

```math
MAE
=
\frac
{\sum_{i=1}^{n}|y_i-\hat{y}_i|}
{n}
```

22. RMSE는 제곱 오차 평균의 제곱근이다.

```math
RMSE
=
\sqrt{
\frac
{\sum_{i=1}^{n}(y_i-\hat{y}_i)^2}
{n}
}
```

23. RMSE는 큰 오차에 상대적으로 더 민감하다.

24. MAE와 RMSE 모두 값이 작을수록 Actual과 Predicted의 차이가 작다는 의미지만 Target의 단위와 규모를 함께 고려해야 한다.

25. 서로 다른 모델을 비교하려면 동일한 Test 구간, Forecast Horizon, 예측 방식과 평가 지표를 사용해야 한다.

26. 시계열 예측의 전체 흐름은 다음과 같다.

```text
시계열 DataFrame
      ↓
시간 순서 확인
      ↓
과거 Train
+
미래 Test
      ↓
정상성 고려
      ↓
p, d, q 설정
      ↓
ARIMA 모델 생성
      ↓
fit()
      ↓
Train에서 파라미터 학습
      ↓
Forecast Horizon 설정
      ↓
미래 값 예측
      ↓
Prediction Interval 계산
      ↓
Actual과 Predicted 비교
      ↓
시점별 Error 확인
      ↓
MAE / RMSE
      ↓
그래프와 지표를 함께 해석
      ↓
최종 시계열 예측 모델 평가
```
