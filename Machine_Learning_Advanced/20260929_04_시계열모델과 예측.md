# **1. 학습 내용**

> ## **1-1 ) 과거의 스포츠 수행 데이터를 이용해 미래 수행 상태를 어떻게 예측할 수 있을까?**

선수 또는 팀의 수행 상태가 시간에 따라 다음과 같이 기록되어 있다고 생각해보자.

```text
10:00 → 87.9
11:00 → 88.0
12:00 → 88.1
13:00 → 88.2
14:00 → ?
```

우리의 목적은 지금까지 관측된 수행지표를 이용하여 아직 관측하지 않은 미래의 값을 예측하는 것이다.

시계열에서는 현재 값이 이전 값과 완전히 독립적이지 않을 수 있다.

지난 학습에서 `performance_index`를 확인했을 때 Lag 1 자기상관이 매우 높게 나타났다.

```text
과거의 Performance
        ↓
현재 Performance
        ↓
미래 Performance
```

따라서 과거의 수행 상태는 미래 값을 예측하는 데 사용할 수 있는 정보가 된다.

하지만 모델링을 시작하기 전에 중요한 문제가 있다.

현재가 `2025-07-22 23:00`이라고 가정해보자.

이 시점에서 알고 있는 정보는 여기까지이다.

```text
과거
────────────────────────────→

2025-01-01 ───────── 2025-07-22 23:00
                          ↑
                       현재 시점
```

다음 시간인

```text
2025-07-23 00:00
```

부터의 값은 아직 모른다고 가정해야 한다.

따라서 미래 데이터를 모델 학습에 사용하면 안 된다.

<br>

> ## **1-2 ) 미래 정보를 학습에 사용하면 왜 문제가 될까?**

일반적인 머신러닝에서는 데이터를 무작위로 섞어 Train과 Test를 나누기도 한다.

하지만 시계열 데이터를 무작위로 섞으면 다음과 같은 상황이 발생할 수 있다.

```text
Train

2025-01
2025-03
2025-07-25
2025-07-28
...

Test

2025-02
2025-07-23
2025-07-27
...
```

예를 들어 `2025-07-23`을 예측하려고 하는데 Train에 이미 `2025-07-28` 데이터가 포함되어 있다면 모델은 실제 예측 시점에서는 알 수 없는 미래 정보를 사용하게 된다.

이를 **Data Leakage(데이터 누수)** 라고 한다.

```text
미래 데이터
     ↓
Train Data에 포함
     ↓
모델이 미래 정보까지 학습
     ↓
실제보다 성능이 좋아 보일 수 있음
```

따라서 시계열 데이터는 기본적으로 다음 구조를 유지해야 한다.

```text
과거
 ↓
Train
 ↓
모델 학습
 ↓
미래
 ↓
Test
 ↓
성능 평가
```

<br>

> ## **1-3 ) 이번 실습의 Train/Test 구성**

이번 데이터는 총 5,040시간이다.

마지막 `168시간`을 Test로 사용한다.

<div align="center">

</div>

</div>

이다.

```

~
2025-07-22 23:00

Test
2025-07-23 00:00
~
2025-07-29 23:00
```

즉,

```text

└──────────── Train 4,872시간 ───────────────┘ └── Test 168시간 ───┘

```

모델은 Train만 보고 Test의 168시간을 예측한다.

# **2. 시계열 데이터의 Train/Test 분리**

> ## **2-1 ) Train과 Test의 역할**

모델을 학습하고 평가하기 위해 데이터를 Train과 Test로 나눈다.

| 데이터 | 역할 |
| --- | --- |
| Train Data | 모델의 파라미터를 학습 |
| Test Data | 학습하지 않은 미래 구간의 성능 평가 |

Train Data는 모델에게 보여준다.

Test Data는 정답을 가지고 있지만 모델 학습에는 사용하지 않는다.

```text
Train
→ 모델이 알고 있는 과거

Test
→ 모델이 모르는 미래라고 가정
```

예측이 끝난 뒤에만 Test의 실제값과 모델이 만든 예측값을 비교한다.

<br>

> ## **2-2 ) Test 기간은 왜 168시간일까?**

시계열에서는 항상 `80:20`과 같은 비율로 나눠야 하는 것은 아니다.

중요한 것은 **실제 운영에서 얼마나 먼 미래를 예측할 것인가**이다.

이번 데이터는 시간별 데이터이다.

예를 들어 스포츠 현장에서 일주일 동안의 수행 상태를 예측하고 싶다면

<div align="center">

**24시간 × 7일 = 168시간**

</div>

을 평가 구간으로 사용할 수 있다.

Forecast Horizon을 비교하면 다음과 같다.

| Forecast Horizon | 시간별 데이터에서 의미 |
| ---: | --- |
| 1 | 다음 1시간 |
| 24 | 다음 24시간 |
| 72 | 다음 3일 |
| 168 | 다음 7일 |

이번 실습에서는

<div align="center">

**Forecast Horizon = 168**

</div>

이다.

# **3. AR, MA와 ARIMA 모델의 이해**

> ## **3-1 ) AR은 과거 값을 이용한다**

**AR(Autoregressive, 자기회귀)** 은 과거의 값을 이용하여 현재 값을 설명한다.

가장 간단한 AR(1)은 한 시점 전의 값을 사용한다.

```text
이전 시점
   ↓
현재 시점
```

AR(1)의 수식은 다음과 같다.

<div align="center">

**y<sub>t</sub> = c + φ₁y<sub>t−1</sub> + ε<sub>t</sub>**

</div>

각 기호는 다음과 같다.

| 기호 | 의미 |
| --- | --- |
| y<sub>t</sub> | 현재 값 |
| y<sub>t−1</sub> | 한 시점 전 값 |
| c | 상수항 |
| φ₁ | AR 계수 |
| ε<sub>t</sub> | 현재 오차 |

예를 들어 수행 변화량에 다음과 같은 관계가 학습되었다고 가정해보자.

<div align="center">

**Δy<sub>t</sub> = 0.02 + 0.6Δy<sub>t−1</sub> + ε<sub>t</sub>**

</div>

직전 변화량이

<div align="center">

**Δy<sub>t−1</sub> = 0.10**

</div>

이라면 새로운 오차를 제외한 값은

<div align="center">

**Δŷ<sub>t</sub> = 0.02 + (0.6 × 0.10)**

**= 0.02 + 0.06**

**= 0.08**

</div>

이 된다.

AR 모델은 이전 값을 그대로 복사하는 것이 아니다.

```text
과거 값
   ↓
학습된 AR 계수 적용
   ↓
현재 값을 설명
```

<br>

> ## **3-2 ) p는 사용할 과거 값의 개수이다**

ARIMA에서 AR 부분의 차수를 `p`라고 한다.

현재 시점에서 이전 시점과의 차이를 **Lag(시차)** 라고 한다.

<div align="center">

**p = 1 → Lag 1**

**p = 2 → Lag 1 + Lag 2**

**p = 3 → Lag 1 + Lag 2 + Lag 3**

</div>

AR(2)는 다음과 같다.

<div align="center">

**y<sub>t</sub> = c + φ₁y<sub>t−1</sub> + φ₂y<sub>t−2</sub> + ε<sub>t</sub>**

</div>

중요한 차이는 다음과 같다.

```text
우리가 결정
→ p

모델이 학습
→ φ₁, φ₂ 등의 실제 계수
```

즉,

<div align="center">

**p = 2**

</div>

라고 지정한다고 해서 φ₁과 φ₂의 값까지 우리가 정하는 것은 아니다.

<br>

> ## **3-3 ) MA는 과거의 예측 오차를 이용한다**

모델이 이전 시점에서 만든 예측 오차를 생각해보자.

예측 오차는 다음과 같다.

<div align="center">

**ε<sub>t</sub> = y<sub>t</sub> − ŷ<sub>t</sub>**

</div>

예를 들어

<div align="center">

**Actual = 88.50**

**Predicted = 88.40**

</div>

이라면

<div align="center">

**ε<sub>t</sub> = 88.50 − 88.40**

**= 0.10**

</div>

이다.

이러한 이전 오차가 현재 값의 움직임과 관련되어 있다면 과거 오차도 현재 값을 설명하는 정보가 될 수 있다.

이를 이용하는 것이 **MA(Moving Average)** 이다.

MA(1)은 다음과 같이 표현할 수 있다.

<div align="center">

**y<sub>t</sub> = μ + θ₁ε<sub>t−1</sub> + ε<sub>t</sub>**

</div>

| 기호 | 의미 |
| --- | --- |
| μ | 평균 수준 또는 모델의 중심 항 |
| ε<sub>t−1</sub> | 직전 시점의 오차 |
| θ₁ | MA 계수 |
| ε<sub>t</sub> | 현재 새롭게 발생하는 오차 |

예를 들어

<div align="center">

**μ = 0.05**

**ε<sub>t−1</sub> = 0.10**

**θ₁ = 0.4**

</div>

라면

<div align="center">

**ŷ<sub>t</sub> = 0.05 + (0.4 × 0.10)**

**= 0.05 + 0.04**

**= 0.09**

</div>

와 같이 이전 오차의 영향을 반영할 수 있다.

<br>

> ## **3-4 ) q는 사용할 과거 오차의 개수이다**

ARIMA에서 MA 차수를 `q`라고 한다.

<div align="center">

**q = 1 → ε<sub>t−1</sub>**

**q = 2 → ε<sub>t−1</sub>, ε<sub>t−2</sub>**

**q = 3 → ε<sub>t−1</sub>, ε<sub>t−2</sub>, ε<sub>t−3</sub>**

</div>

MA(2)는 다음과 같다.

<div align="center">

**y<sub>t</sub> = μ + θ₁ε<sub>t−1</sub> + θ₂ε<sub>t−2</sub> + ε<sub>t</sub>**

</div>

AR과 MA의 차이를 정리하면 다음과 같다.

| 구분 | AR | MA |
| --- | --- | --- |
| 사용하는 정보 | 과거 관측값 | 과거 예측 오차 |
| 차수 | p | q |
| 학습하는 값 | φ 계수 | θ 계수 |

<br>

> ## **3-5 ) I는 차분을 의미한다**

AR과 MA는 정상적인 시계열 구조를 모델링하는 데 사용된다.

지난 강의에서 `performance_index`의 ADF Test p-value는 약 `0.1506`이었다.

<div align="center">

**p-value = 0.1506**

**0.1506 ≥ 0.05**

</div>

따라서 정상성을 만족한다고 보기 어렵다.

1차 차분 후에는 p-value가 거의 0에 가까워졌다.

<div align="center">

**p-value ≈ 0**

</div>

따라서 이번 ARIMA 실습에서는

<div align="center">

**d = 1**

</div>

을 사용한다.

ARIMA의 `I`는 **Integrated**이며 차분을 의미한다.

```text
d = 0
→ 차분하지 않음

d = 1
→ 1차 차분

d = 2
→ 2차 차분
```

1차 차분은 다음과 같이 계산한다.

<div align="center">

**Δy<sub>t</sub> = y<sub>t</sub> − y<sub>t−1</sub>**

</div>

예를 들어 원본 값이

<div align="center">

**88.10 → 88.18 → 88.30 → 88.25**

</div>

라면

<div align="center">

**88.18 − 88.10 = +0.08**

**88.30 − 88.18 = +0.12**

**88.25 − 88.30 = −0.05**

</div>

이므로 차분된 값은

<div align="center">

**+0.08 → +0.12 → −0.05**

</div>

가 된다.

원본의 의미는

```text
Performance 수준
```

이고 차분 후에는

```text
이전 시간 대비 Performance 변화량
```

이 된다.

<br>

> ## **3-6 ) ARIMA(p,d,q)**

ARIMA는 다음 세 가지 요소를 결합한 모델이다.

<div align="center">

**AR + I + MA = ARIMA**

</div>

표현 방법은

<div align="center">

**ARIMA(p,d,q)**

</div>

이다.

| 파라미터 | 의미 |
| --- | --- |
| p | 사용할 과거 값의 개수 |
| d | 차분 횟수 |
| q | 사용할 과거 오차의 개수 |

이번에는

<div align="center">

**ARIMA(2,1,1)**

</div>

을 사용한다.

즉,

<div align="center">

**p = 2**

**d = 1**

**q = 1**

</div>

이다.

```text
p = 2
→ 차분된 시계열의 과거 2개 값

d = 1
→ 원본을 1회 차분

q = 1
→ 과거 오차 1개
```

<br>

> ## **3-7 ) ARIMA(2,1,1)의 실제 동작 흐름**

첫 번째 단계는 원본 `performance_index`를 차분하는 것이다.

<div align="center">

**88.10 → 88.18 → 88.30 → 88.25**

</div>

1차 차분하면

<div align="center">

**+0.08 → +0.12 → −0.05**

</div>

가 된다.

일반적인 1차 차분은

<div align="center">

**Δy<sub>t</sub> = y<sub>t</sub> − y<sub>t−1</sub>**

</div>

이다.

ARIMA(2,1,1)의 구조는 개념적으로 다음과 같이 표현할 수 있다.

<div align="center">

**Δy<sub>t</sub> = c + φ₁Δy<sub>t−1</sub> + φ₂Δy<sub>t−2</sub> + θ₁ε<sub>t−1</sub> + ε<sub>t</sub>**

</div>

즉, AR 부분에서는

<div align="center">

**Δy<sub>t−1</sub>, Δy<sub>t−2</sub>**

</div>

를 사용하고 MA 부분에서는

<div align="center">

**ε<sub>t−1</sub>**

</div>

을 사용한다.

```text
원본 Performance
        ↓
1차 차분
        ↓
Performance 변화량
        ↓
┌───────────────────────┐
│ AR                    │
│ Lag 1 + Lag 2         │
│                       │
│ MA                    │
│ 직전 오차              │
└───────────────────────┘
        ↓
다음 변화량 예측
        ↓
원래 Performance 수준으로 복원
        ↓
최종 예측
```

AR과 MA가 각각 별도의 최종 예측을 만든 뒤 두 값을 평균내는 것이 아니다.

**하나의 ARIMA 모델 내부에서 AR 구조와 MA 구조가 동시에 사용된다.**

<br>

> ## **3-8 ) ARIMA는 무엇을 우리가 결정하고 무엇을 모델이 학습할까?**

두 종류의 파라미터를 구분해야 한다.

| 구분 | 값 |
| --- | --- |
| 분석자가 결정 | p, d, q |
| 모델이 학습 | φ₁, φ₂, θ₁, σ² 등 |

우리가

```python
order=(2, 1, 1)
```

이라고 작성하면

<div align="center">

**(p,d,q) = (2,1,1)**

</div>

이라는 모델 구조를 결정한 것이다.

하지만 실제 AR·MA 계수값은 아직 결정되지 않았다.

이후

```python
model.fit()
```

을 실행하면 Train Data에서 실제 파라미터를 추정한다.

<br>

> ## **3-9 ) Maximum Likelihood Estimation (최대우도)**

`statsmodels`의 ARIMA는 모델 파라미터를 데이터에 맞게 추정한다.

핵심적인 개념은 **Likelihood(우도)** 이다.

Likelihood는 현재 선택한 모델과 파라미터를 사용할 때 실제 관측 데이터가 얼마나 그럴듯하게 나타나는지를 의미한다.

이를 간단하게 표현하면

<div align="center">

**L(θ) = P(y₁, y₂, ..., y<sub>n</sub> | θ)**

</div>

로 표현할 수 있다.

Maximum Likelihood Estimation은 이 값을 가장 크게 만드는 파라미터를 찾는다.

<div align="center">

**θ̂ = arg max L(θ)**

</div>

실제 계산에서는 Log-Likelihood를 많이 사용한다.

<div align="center">

**ℓ(θ) = log L(θ)**

</div>

따라서

<div align="center">

**θ̂ = arg max ℓ(θ)**

</div>

로도 표현할 수 있다.

예를 들어 같은 ARIMA(2,1,1)이라도 다음처럼 여러 계수 조합을 생각할 수 있다.

후보 A

<div align="center">

**φ₁ = 0.2**

**φ₂ = −0.1**

**θ₁ = 0.3**

</div>

후보 B

<div align="center">

**φ₁ = 0.6**

**φ₂ = −0.2**

**θ₁ = 0.4**

</div>

후보 C

<div align="center">

**φ₁ = 0.8**

**φ₂ = −0.4**

**θ₁ = 0.1**

</div>

```text
초기 파라미터
      ↓
Likelihood 계산
      ↓
파라미터 조정
      ↓
Likelihood 다시 계산
      ↓
반복
      ↓
관측 데이터를 잘 설명하는
파라미터 추정
```

`fit()`은 단순히 모델을 실행하는 명령이 아니라 **Train Data를 이용하여 AR, MA 등의 실제 계수를 추정하는 학습 과정**이다.

# **5. ARIMA를 이용한 미래 예측**

> ## **5-1 ) Forecast란 무엇인가?**

Forecast는 아직 관측되지 않았다고 가정한 미래 값을 모델이 예측하는 것이다.

이번 실습의 Forecast Horizon은

<div align="center">

**H = 168시간 = 7일**

</div>

이다.

<br>

> ## **5-2 ) 한 시점 예측과 여러 시점 예측**

한 시점만 예측한다면

<div align="center">

**H = 1**

</div>

이다.

168개 시점을 예측한다면

<div align="center">

**H = 168**

</div>

이다.

이번 실습은 **Multi-step Forecast**이다.

<br>

> ## **5-3 ) get_forecast() 사용**

[ Python : code ] **"Test 168시간 미래 예측"**

```python
forecast_result = (
    model_fit.get_forecast(
        steps=len(test)
    )
)
```

Test 데이터는 168개이므로

<div align="center">

**n<sub>test</sub> = 168**

</div>

이며

<div align="center">

**steps = 168**

</div>

이다.

<br>

> ## **5-4 ) Predicted Mean 추출**

[ Python : code ] **"ARIMA 미래 예측값 추출"**

```python
forecast = (
    forecast_result
    .predicted_mean
)

forecast.index = (
    test.index
)
```

각 시점의 실제값을

<div align="center">

**y<sub>t</sub>**

</div>

라고 하고 예측값을

<div align="center">

**ŷ<sub>t</sub>**

</div>

라고 표현할 수 있다.

<br>

> ## **5-5 ) Prediction Interval이 필요한 이유**

예측값 하나만으로 미래의 불확실성을 모두 설명할 수 없다.

95% Prediction Interval은 다음과 같이 표현할 수 있다.

<div align="center">

**L<sub>t</sub> ≤ y<sub>t</sub> ≤ U<sub>t</sub>**

</div>

여기서

```text
Lₜ
→ Lower Bound

Uₜ
→ Upper Bound

ŷₜ
→ Point Forecast
```

이다.

<br>

> ## **5-6 ) 95% Prediction Interval 계산**

[ Python : code ] **"95% Prediction Interval 계산"**

```python
forecast_interval = (
    forecast_result
    .conf_int(
        alpha=0.05
    )
)

forecast_interval.index = (
    test.index
)
```

`alpha=0.05`이므로

<div align="center">

**1 − α = 1 − 0.05 = 0.95**

</div>

이다.

즉,

<div align="center">

**95% Prediction Interval**

</div>

을 계산한다.

<br>

> ## **5-7 ) Actual, Predicted, Prediction Interval 결합**

[ Python : code ] **"실제값·예측값·예측구간 DataFrame 생성"**

```python
result = pd.DataFrame({
    "actual":
        test["performance_index"],

    "predicted":
        forecast,

    "lower":
        forecast_interval.iloc[:, 0],

    "upper":
        forecast_interval.iloc[:, 1]
})

print(
    result.head()
)
```

첫 번째 시점은

<div align="center">

**y<sub>t</sub> = 88.4820**

**ŷ<sub>t</sub> = 88.4193**

**L<sub>t</sub> = 88.2918**

**U<sub>t</sub> = 88.5468**

</div>

이다.

Prediction Interval 포함 여부를 확인하면

<div align="center">

**88.2918 ≤ 88.4820 ≤ 88.5468**

</div>

이므로 실제값은 예측구간 안에 들어온다.

<br>

> ## **5-8 ) 예측 오차 직접 계산**

예측 오차는

<div align="center">

**e<sub>t</sub> = y<sub>t</sub> − ŷ<sub>t</sub>**

</div>

이다.

첫 번째 시점에서는

<div align="center">

**e<sub>t</sub> = 88.4820 − 88.4193**

**= 0.0627**

</div>

이다.

절대오차는

<div align="center">

**|e<sub>t</sub>| = |y<sub>t</sub> − ŷ<sub>t</sub>|**

</div>

이다.

오차의 방향은 다음과 같다.

<div align="center">

**e<sub>t</sub> > 0 → y<sub>t</sub> > ŷ<sub>t</sub>**

</div>

따라서 모델이 실제보다 낮게 예측하였다.

반대로

<div align="center">

**e<sub>t</sub> < 0 → y<sub>t</sub> < ŷ<sub>t</sub>**

</div>

이면 모델이 실제보다 높게 예측한 것이다.

<br>

> ## **5-10 ) Forecast Horizon이 길어질수록 불확실성이 커지는 이유**

Prediction Interval의 폭을 `W`라고 하면

<div align="center">

**W<sub>t</sub> = U<sub>t</sub> − L<sub>t</sub>**

</div>

이다.

첫 번째 시점에서는

<div align="center">

**W₁ = 88.5468 − 88.2918**

**= 0.2550**

</div>

이다.

168번째 시점에서는

<div align="center">

**W₁₆₈ = 91.8583 − 84.9529**

**= 6.9054**

</div>

이다.

따라서

<div align="center">

**W₁₆₈ > W₁**

</div>

이다.

즉,

```text
가까운 미래
→ 불확실성 작음

먼 미래
→ 오차가 누적될 수 있음
→ 불확실성 증가
```

라는 특징을 확인할 수 있다.

<br>

> ## **5-11 ) Prediction Interval 안에 실제값이 있으면 좋은 모델일까?**

Coverage는 다음과 같이 생각할 수 있다.

<div align="center">

**Coverage = 예측구간 안에 포함된 실제값 개수 ÷ 전체 실제값 개수**

</div>

이번 데이터에서는

<div align="center">

**Coverage = 168 ÷ 168**

**= 1**

**= 100%**

</div>

이다.

하지만 Prediction Interval이 지나치게 넓다면 Coverage는 높아지기 쉽다.

따라서 Coverage만으로 모델을 평가해서는 안 된다.

# **6. MAE와 RMSE를 이용한 예측 성능 평가**

> ## **6-1 ) 왜 평가 지표가 필요할까?**

모델의 예측 성능을 정량적으로 평가하기 위해 MAE와 RMSE를 사용한다.

<br>

> ## **6-2 ) MAE**

MAE는 **Mean Absolute Error**이다.

<div align="center">

**MAE = (1 / n) × Σ |y<sub>t</sub> − ŷ<sub>t</sub>|**

</div>

같은 의미를 조금 더 풀어쓰면

<div align="center">

**MAE = ( |e₁| + |e₂| + ... + |e<sub>n</sub>| ) / n**

</div>

이다.

예를 들어 오차가

<div align="center">

**e₁ = +0.2**

**e₂ = −0.3**

**e₃ = +0.1**

</div>

이면

<div align="center">

**MAE = (0.2 + 0.3 + 0.1) / 3**

**= 0.6 / 3**

**= 0.2**

</div>

이다.

<br>

> ## **6-3 ) RMSE**

RMSE는 **Root Mean Squared Error**이다.

<div align="center">

**RMSE = √[(1 / n) × Σ(y<sub>t</sub> − ŷ<sub>t</sub>)²]**

</div>

또는

<div align="center">

**RMSE = √[(e₁² + e₂² + ... + e<sub>n</sub>²) / n]**

</div>

으로 표현할 수 있다.

예를 들어 오차가

<div align="center">

**0.2, 0.3, 1.5**

</div>

라면

<div align="center">

**0.2² = 0.04**

**0.3² = 0.09**

**1.5² = 2.25**

</div>

가 된다.

따라서

<div align="center">

**RMSE = √[(0.04 + 0.09 + 2.25) / 3]**

</div>

이다.

큰 오차가 제곱되기 때문에 RMSE는 큰 예측 실패에 더 민감하다.

<br>

> ## **6-4 ) MAE와 RMSE 비교**

| 구분 | MAE | RMSE |
| --- | --- | --- |
| 수식 | (1/n) × Σ\|y<sub>t</sub> − ŷ<sub>t</sub>\| | √[(1/n) × Σ(y<sub>t</sub> − ŷ<sub>t</sub>)²] |
| 큰 오차 영향 | 비교적 작음 | 상대적으로 큼 |
| 단위 | Target과 동일 | Target과 동일 |
| 주요 해석 | 평균적으로 얼마나 틀렸는가 | 큰 오차까지 고려하면 얼마나 틀렸는가 |

<br>

> ## **6-5 ) Python으로 MAE와 RMSE 계산**

[ Python : code ] **"ARIMA(2,1,1)의 MAE와 RMSE 계산"**

```python
from sklearn.metrics import (
    mean_absolute_error,
    mean_squared_error
)

mae = mean_absolute_error(

    ],
    forecast
)

rmse = (
    mean_squared_error(
        test[
            "performance_index"
        ],
        forecast
    )
    ** 0.5
)

print(
    f"MAE: {mae:.4f}"
)

print(
    f"RMSE: {rmse:.4f}"
)
```

# **10. Advanced 추가 학습**

> ## **10-1 ) Walk-Forward Validation**

시점 `T`까지 데이터를 가지고 다음 시점을 예측한다고 하면

<div align="center">

**ŷ<sub>T+1</sub> = f(y₁, y₂, ..., y<sub>T</sub>)**

</div>

이다.

실제값 `y<sub>T+1</sub>`이 새롭게 관측되면 이를 추가하여

<div align="center">

**ŷ<sub>T+2</sub> = f(y₁, y₂, ..., y<sub>T</sub>, y<sub>T+1</sub>)**

</div>

을 다시 예측한다.

<br>

> ## **10-2 ) AIC와 BIC**

AIC는 다음과 같다.

<div align="center">

**AIC = 2k − 2ln(L̂)**

</div>

BIC는 다음과 같다.

<div align="center">

**BIC = k ln(n) − 2ln(L̂)**

</div>

<br>

> ## **10-3 ) SARIMA**

시간별 데이터에서 하루 주기를 생각하면

<div align="center">

**s = 24**

</div>

이다.

일주일 주기를 생각하면

<div align="center">

**s = 24 × 7 = 168**

</div>

이다.

SARIMA는 다음과 같이 표현할 수 있다.

<div align="center">

**SARIMA(p,d,q)(P,D,Q)<sub>s</sub>**

</div>

여기서

```text
(p,d,q)
→ 비계절 ARIMA 구조

(P,D,Q)
→ 계절 ARIMA 구조

s
→ 계절 주기
```

이다.

<br>

> ## **10-4 ) 외생변수 사용**

일반 ARIMA는 Target 자신의 과거 정보를 중심으로 사용한다.

<div align="center">

**ŷ<sub>t+h</sub> = f(y<sub>t</sub>, y<sub>t−1</sub>, ...)**

</div>

외생변수를 추가하면 개념적으로

<div align="center">

**y<sub>t</sub> = ARIMA 구조 + βᵀx<sub>t</sub> + ε<sub>t</sub>**

</div>

와 같이 생각할 수 있다.

<br>

> ## **10-5 ) Baseline 모델**

Naive Forecast는

<div align="center">

**ŷ<sub>T+h</sub> = y<sub>T</sub>**

</div>

이다.

Seasonal Naive Forecast는

<div align="center">

**ŷ<sub>t</sub> = y<sub>t−s</sub>**

</div>

로 표현할 수 있다.

Moving Average Forecast는 최근 `k`개의 평균을 사용한다.

<div align="center">

**ŷ<sub>t+1</sub> = (y<sub>t</sub> + y<sub>t−1</sub> + ... + y<sub>t−k+1</sub>) / k**

</div>

```text

        ↓
모델 학습
        ↓
Forecast
        ↓
Prediction Interval
        ↓
MAE / RMSE
        ↓
Baseline 비교
        ↓
오차 패턴 확인
```

이번 핵심은 **ARIMA 코드를 실행하는 것 자체가 아니라, 과거 데이터로 모델을 학습하고 실제 미래 구간에서 얼마나 잘 예측하는지 검증하는 전체 시계열 모델링 과정을 이해하는 것**이다.
