# **1. 시계열 데이터와 Streamlit 웹앱**

`soccer_team_timeseries.csv`를 이용하여 **축구팀의 훈련 및 경기 데이터를 웹 화면에서 확인하고 미래 팀 경기력 지수를 예측하는 시계열 웹앱**을 구현한다.

데이터는 2017년 1월 1일부터 2025년 12월 31일까지 **일 단위로 기록된 축구팀 시계열 데이터**이다.

총 데이터 수는 `3,287개`이며 날짜별로 훈련 형태, 훈련부하, 이동거리, 고속주행거리, 스프린트 횟수, 평균 심박수, 피로도, 준비도, 팀 경기력 지수 등이 기록되어 있다.

```text
축구팀 데이터
    ↓
CSV 파일 업로드
    ↓
pandas 데이터 전처리
    ↓
일별 시계열 데이터 구성
    ↓
Streamlit 표와 그래프 출력
    ↓
예측 기간 선택
    ↓
ARIMA 모델 학습
    ↓
미래 팀 경기력 지수 예측
```

Streamlit은 시계열 모델 자체를 대신하는 것이 아니라 **Python으로 작성한 데이터 처리 및 예측 기능을 사용자가 웹 브라우저에서 사용할 수 있도록 연결하는 역할**을 한다.

<br>

> ## 1-1 ) 사용 데이터

이번 실습에서 사용하는 파일은 다음과 같다.

```text
soccer_team_timeseries.csv
```

실제 데이터의 기간은 다음과 같다.

```text

시간 단위 : 일(Daily)

```

따라서 한 행은 **축구팀의 하루 훈련 또는 경기 상태**를 의미한다.

# **2. 데이터 컬럼 구성**

`soccer_team_timeseries.csv`는 날짜별 축구팀의 훈련 및 경기 상태를 여러 변수로 기록한 데이터이다.

| 컬럼 | 의미 | 자료형 |
|---|---|---|
| `date` | 데이터가 기록된 날짜 | 날짜 |
| `session_type` | 당일 세션 종류 | 범주형 |
| `training_load_au` | 훈련부하 | 수치형 |
| `total_distance_km` | 총 이동거리 | 수치형 |
| `high_speed_running_m` | 고속주행거리 | 수치형 |
| `sprint_count` | 스프린트 횟수 | 정수형 |
| `avg_heart_rate_bpm` | 평균 심박수 | 수치형 |
| `fatigue_score` | 피로도 점수 | 수치형 |
| `readiness_score` | 준비도 점수 | 수치형 |
| `team_performance_index` | 팀 경기력 지수 | 수치형 |

<br>

> ## 2-1 ) 세션 종류

`session_type`에는 다음과 같은 훈련 및 경기 유형이 들어 있다.

| 세션 | 의미 |
|---|---|
| `Rest` | 휴식 |
| `Recovery` | 회복 훈련 |
| `Technical` | 기술 훈련 |
| `HighIntensity` | 고강도 훈련 |
| `Tactical` | 전술 훈련 |
| `PreMatch` | 경기 전 훈련 |
| `Match` | 실제 경기 |

따라서 단순히 시계열 값만 있는 데이터가 아니라 **훈련 프로그램과 선수의 신체적 반응이 함께 포함된 실무형 스포츠 데이터**라고 볼 수 있다.

<br>

> ## 2-2 ) 주요 변수의 관계

데이터의 구조를 개념적으로 표현하면 다음과 같다.

```text
session_type
     ↓
훈련 및 경기 형태
     ↓
training_load_au
total_distance_km
high_speed_running_m
sprint_count
avg_heart_rate_bpm
     ↓
신체적 반응
     ↓
fatigue_score
readiness_score
     ↓
team_performance_index
```

즉, 하나의 날짜에 **훈련 내용 → 운동량 → 신체적 반응 → 팀 경기력 상태**가 함께 기록되어 있다.

# **3. Streamlit의 역할**

일반적인 Python 분석에서는 사용자가 직접 코드를 실행해야 한다.

```text
CSV 파일
    ↓
Python 코드 실행
    ↓
pandas 처리
    ↓
ARIMA 모델
    ↓
결과 출력
```

Streamlit을 사용하면 사용자가 Python 코드를 직접 수정하지 않아도 된다.

```text
사용자
    ↓
웹 화면
    ↓
CSV 업로드
    ↓
예측 기간 선택
    ↓
Python 코드 자동 실행
    ↓
분석 및 예측 결과 확인
```

<br>

> ## 3-1 ) 일반 Python과 Streamlit 비교

| 구분 | 일반 Python | Streamlit |
|---|---|---|
| 데이터 입력 | 코드에 파일 경로 작성 | 웹에서 파일 업로드 |
| 사용자 선택 | 변수값 직접 변경 | `selectbox`, `slider` |
| 표 출력 | `print()` | `st.dataframe()` |
| 그래프 | matplotlib 등 | `st.line_chart()` |
| 실행 결과 | Notebook / 터미널 | 웹 브라우저 |

중요한 것은 데이터 처리 자체는 여전히 `pandas`, 모델링은 `statsmodels` 등이 수행한다는 것이다.

```text
pandas
→ 데이터 처리

statsmodels
→ ARIMA 시계열 모델

Streamlit
→ 입력 및 결과 화면
```

# **4. 첫 번째 Streamlit 웹앱 실행하기**

Streamlit 웹앱은 Notebook 셀보다는 `.py` 파일로 작성하여 실행하는 것이 기본적인 사용 방식이다.

먼저 Streamlit을 설치한다.

```bash
uv add streamlit
```

`app.py` 파일을 만든 뒤 코드를 작성한다.

<br>

> ## 4-1 ) 기본 웹 화면 만들기

[Python : code] "축구팀 데이터 분석 웹앱의 제목과 설명 출력"

```python
import streamlit as st

st.title("축구팀 시계열 데이터 분석")

st.write(
    "축구팀의 훈련 및 경기 데이터를 분석합니다."
)
```

터미널에서 실행한다.

```bash
uv run streamlit run app.py
```

[ Result ]

```text

축구팀의 훈련 및 경기 데이터를 분석합니다.
```

정상적으로 실행되면 터미널에 다음과 같은 주소가 생성된다.

```text

```

> ## 4-2 ) Streamlit 실행 흐름

# **5. CSV 파일을 웹에서 업로드하기**

실제 서비스에서는 데이터를 코드 내부에 직접 작성하기보다 사용자가 파일을 업로드할 수 있도록 만드는 것이 편리하다.

Streamlit에서는 `st.file_uploader()`를 사용할 수 있다.

<br>

> ## 5-1 ) CSV 업로드

[Python : code] "축구팀 CSV 데이터를 웹에서 업로드"

```python
import pandas as pd
import streamlit as st

st.title("축구팀 시계열 분석")

uploaded_file = st.file_uploader(
    "soccer_team_timeseries.csv 파일을 업로드하세요.",
    type="csv"
)

if uploaded_file is not None:
    data = pd.read_csv(uploaded_file)

    st.write("업로드한 데이터")
    st.dataframe(data)
```

[ Result ]

```text
사용자
   ↓
soccer_team_timeseries.csv 선택
   ↓
uploaded_file
   ↓
pd.read_csv()
   ↓
pandas DataFrame
   ↓
웹 화면의 표
```

<br>

> ## 5-2 ) `uploaded_file is not None`

파일을 아직 업로드하지 않은 경우에는 다음 상태이다.

```text
uploaded_file = None
```

따라서 파일이 존재하는 경우에만 데이터를 읽는다.

```python
if uploaded_file is not None:
    data = pd.read_csv(uploaded_file)
```

이를 통해 파일이 없는 상태에서 분석 코드가 실행되는 것을 방지할 수 있다.

# **6. 축구팀 시계열 데이터 전처리**

CSV를 불러온 후에는 ARIMA와 같은 시계열 모델에 사용할 수 있도록 날짜와 분석 변수를 정리해야 한다.

이번 데이터는 원래 `date` 컬럼이 `YYYY-MM-DD` 형태이므로 AirPassengers 데이터처럼 소수형 연도를 날짜로 변환할 필요가 없다.

<br>

> ## 6-1 ) 날짜 자료형 변환

[Python : code] "date 컬럼을 datetime 형식으로 변환"

```python
data["date"] = pd.to_datetime(
    data["date"],
    errors="coerce"
)
```

[ Result ]

```text

"2017-01-02"
"2017-01-03"

       ↓

2017-01-02
2017-01-03

```

<br>

> ## 6-2 ) 날짜 기준 정렬

시계열 데이터에서는 관측 순서가 중요하다.

따라서 날짜를 과거부터 최근 순서로 정렬한다.

[Python : code] "축구팀 데이터를 날짜순으로 정렬"

```python
data = data.sort_values("date")
```

처리 후 데이터는 다음과 같은 순서를 갖는다.

```text

     ↓

     ↓
2017-01-03
     ↓

     ↓

```

<br>

> ## 6-3 ) 날짜를 인덱스로 설정

[Python : code] "date를 시계열 인덱스로 설정"

```python
data = data.set_index("date")
```


날짜가 인덱스가 되면 pandas와 statsmodels가 시간의 흐름을 기준으로 데이터를 처리하기 쉬워진다.

> ## 6-4 ) 일별 시계열 빈도 설정

# **8. 사용자가 분석 지표를 선택하도록 만들기**

실무에서는 하나의 변수만 확인하기보다 사용자가 원하는 스포츠 지표를 선택할 수 있도록 만드는 것이 활용도가 높다.

`st.selectbox()`를 사용하면 분석할 변수를 선택할 수 있다.

<br>

> ## 8-1 ) 분석 지표 선택

[Python : code] "사용자가 시각화할 스포츠 지표 선택"

```python
metric = st.selectbox(
    "확인할 지표를 선택하세요.",
    [
        "training_load_au",
        "total_distance_km",
        "high_speed_running_m",
        "avg_heart_rate_bpm",
        "fatigue_score",
        "readiness_score",
        "team_performance_index"
    ]
)

st.line_chart(
    data[metric]
)
```

사용자가 `fatigue_score`를 선택하면 다음과 같이 동작한다.

[ Result ]

```text
웹 화면

      ↓
metric = "fatigue_score"
      ↓
data[metric]
      ↓
피로도 시계열 그래프 출력
```

<br>

> ## 8-2 ) 사용자 입력의 기본 구조

```text
사용자 선택
     ↓

     ↓
Python 변수
     ↓
pandas 데이터 선택
     ↓
분석 및 시각화
```

Streamlit 입력 컴포넌트에서 반환되는 값은 일반적인 Python 변수와 동일하게 사용할 수 있다.

# **9. ARIMA를 이용한 팀 경기력 지수 예측**

이번 실습에서는 `team_performance_index`를 이용하여 미래 팀 경기력 지수를 예측한다.

ARIMA는 시계열 데이터의 과거 값과 변화 패턴을 이용하여 미래 값을 예측하는 대표적인 통계적 시계열 모델이다.

\[
ARIMA(p,d,q)
\]

| 값 | 의미 |
|---|---|
| `p` | 이전 시점 값을 몇 개 사용할지 결정 |
| `d` | 정상성을 위한 차분 횟수 |
| `q` | 이전 예측 오차를 몇 개 사용할지 결정 |

이번 실습에서는 Streamlit과 ARIMA를 연결하는 과정에 집중하기 위해 `ARIMA(2, 1, 1)`을 사용한다.

<br>

> ## 9-1 ) 예측 기간 선택

데이터가 일별 데이터이므로 예측 기간도 일 단위로 구성한다.

[Python : code] "사용자가 미래 예측 일수를 선택"

```python
forecast_period = st.selectbox(
    "예측 기간을 선택하세요.",
    [7, 14, 30]
)
```

사용자가 `7`을 선택하면 다음과 같다.

[ Result ]

```text
forecast_period = 7
```

# **11. 모델 평가와 미래 예측의 차이**

ARIMA를 사용한다고 해서 항상 MAE나 RMSE를 계산하는 것은 아니다.

모델 평가와 실제 미래 예측의 목적은 다르다.

| 구분 | 모델 평가 | 미래 예측 |
|---|---|---|
| 학습 데이터 | Train 데이터 | 현재까지 전체 데이터 |
| 예측 구간 | Test 데이터 | 관측되지 않은 미래 |
| 실제값 | 존재 | 아직 없음 |
| MAE | 계산 가능 | 계산 불가 |
| RMSE | 계산 가능 | 계산 불가 |
| 목적 | 모델 성능 검증 | 미래 값 추정 |

<br>

> ## 11-1 ) MAE

MAE는 실제값과 예측값 차이의 절댓값 평균이다.

\[
MAE =
\frac{
\sum_{i=1}^{n}|y_i-\hat{y_i}|
}{
n
}
\]

값이 작을수록 예측값이 실제값과 가깝다는 의미이다.

<br>

> ## 11-2 ) RMSE

RMSE는 오차를 제곱한 뒤 평균하고 다시 제곱근을 계산한다.

\[
RMSE =
\sqrt{
\frac{
\sum_{i=1}^{n}(y_i-\hat{y_i})^2
}{
n
}
}
\]

큰 오차에 더 큰 패널티를 주는 특징이 있다.

<br>

> ## 11-3 ) 현재 웹앱에서는 평가하지 않는 이유

현재 마지막 관측일은 다음과 같다.

```text
2025-12-31
```

웹앱이 예측하는 시점은 그 이후이다.

```text
실제 데이터

2017-01-01 ───────── 2025-12-31

                        │
                        ↓

미래 예측

2026-01-01 이후
```

미래 실제값이 아직 없다고 가정하기 때문에 현재는 MAE와 RMSE를 계산할 수 없다.

나중에 실제 데이터가 수집되면 예측값과 비교하여 성능을 평가할 수 있다.

> ## 14-2 ) 전체 Streamlit 시계열 분석 코드

[Python : code] "축구팀 CSV 업로드부터 ARIMA 미래 예측까지 연결한 전체 웹앱"

```python
import pandas as pd
import streamlit as st

from statsmodels.tsa.arima.model import ARIMA


# -----------------------------------
# 1. 웹앱 제목
# -----------------------------------

st.title(
    "축구팀 시계열 데이터 예측"
)

st.write(
    "축구팀의 일별 훈련 및 경기 데이터를 "
    "분석하고 미래 팀 경기력 지수를 예측합니다."
)


# -----------------------------------
# 2. CSV 파일 업로드
# -----------------------------------

uploaded_file = st.file_uploader(
    "soccer_team_timeseries.csv 파일을 업로드하세요.",
    type="csv"
)


# -----------------------------------
# 3. 파일 업로드 후 분석
# -----------------------------------

if uploaded_file is not None:

    data = pd.read_csv(
        uploaded_file
    )


    # --------------------------------
    # 4. 필수 컬럼 확인
    # --------------------------------

    required_columns = [
        "date",
        "team_performance_index"
    ]

    missing_columns = [
        column
        for column in required_columns
        if column not in data.columns
    ]

    if missing_columns:

        st.error(
            "필수 컬럼이 없습니다: "
            + ", ".join(
                missing_columns
            )
        )

        st.stop()


    # --------------------------------
    # 5. 날짜 자료형 변환
    # --------------------------------

    data["date"] = pd.to_datetime(
        data["date"],
        errors="coerce"
    )


    # --------------------------------
    # 6. 예측 변수 숫자형 변환
    # --------------------------------

    data[
        "team_performance_index"
    ] = pd.to_numeric(
        data[
            "team_performance_index"
        ],
        errors="coerce"
    )


    # --------------------------------
    # 7. 결측값 제거
    # --------------------------------

    data = data.dropna(
        subset=[
            "date",
            "team_performance_index"
        ]
    )


    # --------------------------------
    # 8. 날짜 기준 정렬
    # --------------------------------

    data = data.sort_values(
        "date"
    )


    # --------------------------------
    # 9. 날짜를 인덱스로 설정
    # --------------------------------

    data = data.set_index(
        "date"
    )


    # --------------------------------
    # 10. 일별 시계열 빈도 설정
    # --------------------------------

    data = data.asfreq(
        "D"
    )


    # --------------------------------
    # 11. 데이터 확인
    # --------------------------------

    st.write(
        "축구팀 시계열 데이터"
    )

    st.dataframe(
        data
    )


    # --------------------------------
    # 12. 분석 지표 선택
    # --------------------------------

    numeric_metrics = [
        "training_load_au",
        "total_distance_km",
        "high_speed_running_m",
        "sprint_count",
        "avg_heart_rate_bpm",
        "fatigue_score",
        "readiness_score",
        "team_performance_index"
    ]

    available_metrics = [
        metric
        for metric in numeric_metrics
        if metric in data.columns
    ]

    selected_metric = st.selectbox(
        "그래프로 확인할 지표를 선택하세요.",
        available_metrics,
        index=(
            available_metrics.index(
                "team_performance_index"
            )
        )
    )


    # --------------------------------
    # 13. 선택 지표 시각화
    # --------------------------------

    st.write(
        f"{selected_metric} 변화"
    )

    st.line_chart(
        data[
            selected_metric
        ]
    )


    # --------------------------------
    # 14. 팀 경기력 지수 확인
    # --------------------------------

    st.write(
        "팀 경기력 지수 변화"
    )

    st.line_chart(
        data[
            "team_performance_index"
        ]
    )


    # --------------------------------
    # 15. 예측 기간 선택
    # --------------------------------

    forecast_period = (
        st.selectbox(
            "예측 기간을 선택하세요.",
            [7, 14, 30]
        )
    )


    # --------------------------------
    # 16. 시계열 누락 여부 검사
    # --------------------------------

    if data[
        "team_performance_index"
    ].isna().any():

        st.error(
            "일별 시계열에 누락된 날짜 또는 "
            "값이 존재합니다."
        )

        st.stop()


    # --------------------------------
    # 17. ARIMA 모델 생성
    # --------------------------------

    model = ARIMA(
        data[
            "team_performance_index"
        ],
        order=(2, 1, 1)
    )


    # --------------------------------
    # 18. ARIMA 모델 학습
    # --------------------------------

    model_fit = model.fit()


    # --------------------------------
    # 19. 미래 값 예측
    # --------------------------------

    forecast = (
        model_fit.forecast(
            steps=forecast_period
        )
    )


    # --------------------------------
    # 20. 미래 날짜 생성
    # --------------------------------

    future_dates = pd.date_range(
        start=(
            data.index[-1]
            + pd.DateOffset(
                days=1
            )
        ),
        periods=forecast_period,
        freq="D"
    )


    # --------------------------------
    # 21. 예측 결과 DataFrame
    # --------------------------------

    forecast_data = pd.DataFrame({
        "date":
            future_dates,
        "predicted_performance":
            forecast.values
    })

    forecast_data = (
        forecast_data
        .set_index(
            "date"
        )
    )


    # --------------------------------
    # 22. 예측 결과 출력
    # --------------------------------

    st.write(
        f"앞으로 {forecast_period}일 "
        "팀 경기력 예측"
    )

    st.dataframe(
        forecast_data.style.format({
            "predicted_performance":
                "{:.4f}"
        })
    )


    # --------------------------------
    # 23. 실제 관측 데이터
    # --------------------------------

    actual_data = (
        data[
            [
                "team_performance_index"
            ]
        ]
        .rename(
            columns={
                "team_performance_index":
                "actual_performance"
            }
        )
    )


    # --------------------------------
    # 24. 실제값 + 예측값 결합
    # --------------------------------

    chart_data = pd.concat(
        [
            actual_data,
            forecast_data
        ],
        axis=1
    )


    # --------------------------------
    # 25. 최종 시각화
    # --------------------------------

    st.write(
        "실제 팀 경기력과 미래 예측"
    )

    st.line_chart(
        chart_data
    )
```

# **15. Advanced 추가 학습**

> ## 15-1 ) ARIMA의 파라미터 선택

이번 예제에서는 학습을 위해 `ARIMA(2,1,1)`을 사용했지만 실제 분석에서는 여러 `p`, `d`, `q` 조합을 비교하여 적절한 모델을 선택하는 것이 좋다.

```text
ARIMA(1,1,1)
ARIMA(2,1,1)
ARIMA(3,1,2)
...
```

Train/Test 데이터를 이용하여 MAE, RMSE 등을 비교할 수 있다.

<br>

> ## 15-2 ) 축구 데이터의 주기성

현재 데이터의 `session_type`은 휴식, 회복, 기술, 고강도, 전술, 경기 전, 경기 등 일정한 훈련 주기를 가지고 있다.

이러한 반복적인 패턴이 강한 경우에는 단순 ARIMA뿐 아니라 **SARIMA와 같은 계절성 시계열 모델**도 고려할 수 있다.

```text
ARIMA
→ 일반적인 시계열 패턴

SARIMA
→ 일반적인 패턴 + 반복되는 계절성
```

<br>

> ## 15-3 ) 여러 변수를 함께 사용하는 예측

ARIMA는 기본적으로 하나의 시계열 변수를 중심으로 예측한다.

하지만 실제 경기력에는 다음과 같은 여러 변수가 동시에 영향을 줄 수 있다.

```text
training_load_au
fatigue_score
readiness_score
avg_heart_rate_bpm
sprint_count
        ↓
team_performance_index
```

이런 경우에는 외생변수를 추가하는 `ARIMAX`, 머신러닝 또는 다변량 시계열 모델을 추가로 학습할 수 있다.

# **16. 핵심정리**

- Streamlit은 데이터 분석이나 시계열 모델을 대신하는 것이 아니라 **Python 분석 기능을 사용자가 웹 화면에서 사용할 수 있도록 연결하는 도구**이다.

- 실제 데이터 분석 웹앱의 기본 구조는 다음과 같다.

```text
사용자 입력
    ↓
데이터 전처리
    ↓
분석 및 모델링
    ↓
결과 출력
```

- 시계열 데이터에서는 일반적인 데이터와 달리 **시간 순서와 시간 간격이 분석의 중요한 정보**이므로 날짜 변환, 정렬, 인덱스 설정이 중요하다.

- `st.file_uploader()`를 이용하면 사용자가 CSV 파일을 직접 입력할 수 있고, 업로드된 데이터는 `pd.read_csv()`를 통해 일반적인 pandas DataFrame과 동일하게 처리할 수 있다.

- `st.selectbox()`를 사용하면 사용자가 분석 지표나 예측 기간을 선택할 수 있으며 선택 결과는 일반적인 Python 변수로 전달된다.

- 이번 데이터는 `2017-01-01`부터 `2025-12-31`까지의 **3,287개 일별 관측값**으로 구성되어 있으므로 월별이 아닌 **일별 시계열 분석**을 수행해야 한다.

- ARIMA를 적용할 때는 분석 대상 변수를 시간 순서대로 구성한 뒤 모델을 학습하고 `forecast()`를 이용하여 미래 값을 예측할 수 있다.

- 이번 실습에서는 `team_performance_index`를 예측 대상으로 사용하였으며 마지막 관측일 이후의 `7일`, `14일`, `30일`을 사용자가 선택할 수 있도록 구성하였다.

- 모델 평가와 실제 미래 예측은 서로 구분해야 한다.

```text
Train / Test
→ 이미 실제값이 존재
→ MAE, RMSE 계산 가능

실제 미래
→ 아직 실제값이 없음
→ 현재는 예측값만 확인
```

- 실제 데이터 웹앱에서는 모델을 만드는 것뿐 아니라 **필수 컬럼 확인, 자료형 변환, 결측값 처리, 시계열 간격 검사와 같은 입력 데이터 검증 과정**도 매우 중요하다.

- 복잡한 Streamlit 시계열 웹앱도 기능을 나누면 다음 네 단계로 이해할 수 있다.

```text
1. 입력
   → CSV 업로드 / 옵션 선택

2. 전처리
   → 날짜 변환 / 정렬 / 결측값 처리

3. 모델링
   → ARIMA 학습 / 미래 예측

4. 출력
   → DataFrame / 시계열 그래프
```
