# [ 1. 회귀분석 ]

- 예측 (Prediction) : 설명 가능한 독립변수(x)로 종속변수(y)의 값을 예측
- 관계 설명 (Explanation): 독립변수(x)가 종속변수(y)에 얼마나 영향을 미치는지 수치적으로 설명

<br><br>

# [ 2. 단순 선형회귀 모델 ]
> 1개의 독립변수(x)와 1개의 종속변수(y) 사이의 직선관계를 설명

- 수식 : $y = \beta_0 + \beta_1 x + \varepsilon$

|기호|이름|의미|
|---|---|---|
|y|	종속변수 (반응변수)|	예측하고자 하는 값|
|x|	독립변수 (설명변수)|	예측에 사용하는 값|
|β₀|	절편 (intercept)|	x=0일 때 y의 예상값|
|β₁|	기울기 (slope)|	x가 1 증가할 때 y의 평균 변화량|
|ε|	오차항|	모델이 설명하지 못하는 무작위 변동|

```python
회귀식 예시

이용 시간으로 공유 자전거 요금 계산

공유 자전거의 이용 시간 `x`와 예상 이용 요금 `y`의 관계가 다음 회귀식으로 표현된다고 가정한다.

y = 1000 + 200x

- `x`: 이용 시간
- `y`: 예상 이용 요금
- `β₀ = 1000`
- `β₁ = 200`

자전거를 6시간 이용했을 때 예상 이용 요금 계산.

초기 코드:

beta0 = 1000
beta1 = 200
x = 6

y = beta0 + beta1 * x # 회귀식

print(f"예상 이용 요금: {y}원")

```

# [ 3. 최소제곱법 ]
> 잔차(residual)의 제곱합을 최소화하는 β₀와 β₁을 찾는 방법
> - 잔차 : 실제값 - 예측값
> - 잔차 ** 2 : 이유 잔차가 음수일 경우 그대로 더하면 양수와 음수가 서로 상쇄되기 때문에 의미있는 비교가 되지 않음. 때문에 음수도 제곱하여 방향에 관계없이 오차의 크기를 측정하여 큰 오차에 더 높은 **패널티**를 부여 가능

[수식]

$$
SSE=\sum_{i=1}^{n}(y_i-\hat{y}_i)^2
$$

$$
\hat{\beta}_1 = 
\frac{\sum(x_i - \bar{x})(y_i - \bar{y})}{\sum(x_i - \bar{x})^2}
$$

$$
\hat{\beta}_0 = \bar{y} - \hat{\beta}_1 \bar{x}
$$


```python
# SSE 직접 구하기

import numpy as np

actual = np.array([20, 30, 40, 50])

pred_a = np.array([22, 29, 39, 52])
pred_b = np.array([25, 35, 45, 55])

residual_a = actual - pred_a # 잔차
residual_b = actual - pred_b # 잔차

sse_a = np.sum(residual_a ** 2) # 잔차 제곱
sse_b = np.sum(residual_b ** 2) # 잔차 제곱

print("모델 A 잔차 제곱합:", sse_a)
print("모델 B 잔차 제곱합:", sse_b)
```

# [ 4. 회귀계수 해석 (기울기, 절편) ]

|수식|설명|해석|
|---|---|---|
|β₁|기울기|x가 1단위 증가할때 y의 평균 변화량, 기울기의 방향(+/-)은 관계의 방향을 나타냄|
|β₀|절편|x=0일 때 y의 예상값, 회귀선이 y축을 만나는 지점(결과값 보정 역할)|

```python
배달 거리 `x`와 예상 배달 시간 `y`의 관계가 다음과 같다.

y = 15 + 3x

다음 질문에 답하세요.

1. 기울기 `3`은 어떤 의미인가요?
2. 절편 `15`는 어떤 의미인가요?
3. 배달 거리가 8km라면 예상 배달 시간은 몇 분인가요?

- 예시 답안

beta0 = 15
beta1 = 3
x = 8
    
y = beta0 + beta1 * x
    
print(f"예상 배달 시간: {y}분")

    
기울기 `3` :
배달 거리가 1km 증가할 때 예상 배달 시간이 평균적으로 3분 증가
    
절편 `15` :
배달 거리가 0km일 때 예상 배달 시간이 15분
    
8km의 배달 시간은 39분으로 예상 가능
```

# [ 5. sklearn으로 회귀 모델 적합하기 ]

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression

# 데이터 준비 (2D 배열로 변환 필요)
x = np.array([2, 4, 6, 8, 10]).reshape(-1, 1)
y = np.array([50, 60, 70, 80, 90])

# 모델 생성 및 학습
model = LinearRegression()
model.fit(x, y)

# 회귀 계수 확인
print(f"절편(β₀): {model.intercept_:.4f}")
print(f"기울기(β₁): {model.coef_[0]:.4f}")

# 예측
x_new = np.array([[7]])
y_pred = model.predict(x_new)
print(f"공부시간 7시간 → 예측 점수: {y_pred[0]:.2f}점")

# 회귀선 시각화
x_range = np.linspace(1, 11, 100).reshape(-1, 1)
y_line = model.predict(x_range)

plt.figure(figsize=(7, 4))
plt.scatter(x, y, color='steelblue', label='실제 데이터', zorder=5)
plt.plot(x_range, y_line, color='tomato', label='회귀선')
plt.xlabel('공부시간')
plt.ylabel('시험점수')
plt.title('단순 선형회귀')
plt.legend()
plt.tight_layout()
plt.show()
```

### 주요 메서드와 속성

| 코드 | 기능 |
|---|---|
| `LinearRegression()` | 선형회귀 모델 생성 |
| `model.fit(X, y)` | 최소제곱법으로 모델 학습 |
| `model.intercept_` | 학습된 절편 확인 |
| `model.coef_` | 학습된 기울기 확인 |
| `model.predict(X_new)` | 새로운 입력의 값 예측 |

- sklearn의 입력 X는 (샘플 수, 특성 수) 형태의 2차원 배열로 변환해야 함

# [ 6. 잔차: 모델이 설명하지 못하는 부분 ]

```python
# 매장의 하루 매출 예측 회귀모델

import numpy as np

actual_sales = np.array([120, 150, 170, 210, 240])
predicted_sales = np.array([125, 145, 175, 205, 240])

residuals = actual_sales - predicted_sales

print("실제 매출:", actual_sales)
print("예측 매출:", predicted_sales)
print("잔차:", residuals)

# 실행결과
실제 매출: [120 150 170 210 240]
예측 매출: [125 145 175 205 240]
잔차: [-5  5 -5  5  0]
```
- 첫 번째 예측의 경우 실제는 120, 모델의 예측은 125로,    
residual = 120 - 125 = -5   
- 잔차는 음수이므로 실제값 > 예측값   
- 만약 양수면 실제값 < 예측했다는 의미   
- 0이면 실제값 = 예측값

> 1. 잔차의 합은 0   
> 2. 잔차의 패턴은 무작위로 흩어져야 선형모델이 적절히 학습된 것으로 판단 가능

### 참고
1. 상관분석은 두 변수의 **관계 강도와 방향**을 측정하는 탐색적 분석 

2. 회귀분석은 여기서 한 발 더 나아가 **예측 모델**을 만들고, x가 y에 미치는 영향을 수치(계수)로 표현 

3. 상관계수가 높을수록 선형 관계가 강하므로 일반적으로 회귀 모델의 적합도도 높아짐.   

4. 하지만 상관계수가 높다고 반드시 좋은 예측 모델이 되는 것은 아님
