# [ 1. 공분산(Covariance) ]
> 두 변수 사이의 움직이는 관계  
> 양(+)의 방향 : 한 변수가 증가할 때, 다른 변수도 증가  
> 음(-)의 방향 : 한 변수가 증가할 때, 다른 변수는 감소   
> 공분산 = 0 : 두 변수간의 선형관계는 약함

공분산은 두 변수의 단위(unit)가 다르면 영향을 받기 때문에 관계의 강도를 비교하기에 한계가 존재

함수 : `df[].cov('비교할 컬럼')`

[수식]   

$Cov(X, Y) = \frac{1}{n} \sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})$

<br><br>

# [ 2. 피어슨 상관계수 (Pearson r) ]
> 두 변수간의 **선형관계**의 강함 정도 측정   
> 상관계수는 **-1 ~ 1** 사이   

함수 : `df[].corr('비교할 컬럼')`    

[수식]   

#$r = \frac{Cov(X, Y)}{s_X \cdot s_Y}$

- 공분산을 두 변수의 표준편차로 나눠 표준화한 값
- 표준화 했기 때문에 변수 간에 단위가 달라도 영향을 받지 않음

[상관계수 강도 기준]

|절댓값 범위|해석|
|---|---|
|0.7 이상|강한 상관관계|
|0.3 ~ 0.7|중간 상관관계|
|0.3 미만|약한 상관관계|

<br><br>

# [ 3. 스피어만 상관계수 (Spearman ρ) ]
> 순위를 중심으로 두 변수간의 단조관계 (한 변수가 증가할 때 다른 변수도 증가하거나 감소하는 관계) 측정 

함수: 
``` python
from scipy import stats   

rho, p_value = stats.spearmanr(df[], df[])

print(f'스피어만 상관계수: {rho:.4f}')
```

- 실제 값보다 순위를 이용해 관계 측정
- 한 변수가 증가할때 다른 변수도 증가하거나 감소하는 단조 관계 측정 가능
- 이상치나 비정규 데이터에서 피어슨보다 적합할 가능성이 존재함

# [ 4. 산점도로 상관관계 시각화 ]

``` python
import pandas as pd
import matplotlib.pyplot as plt

data = {
    "가격": [10, 15, 20, 25, 30, 35],
    "판매량": [100, 92, 80, 65, 52, 40]
}

df = pd.DataFrame(data)

r = df["가격"].corr(df["판매량"])

print(f"피어슨 상관계수: {r:.4f}")

plt.figure(figsize=(6, 4))
plt.scatter(df["가격"], df["판매량"])
plt.xlabel("가격")
plt.ylabel("판매량")
plt.title(f"가격 vs 판매량 (r = {r:.2f})")
plt.tight_layout()
plt.show()
``` 

- 산점도(scatter plot): 두 변수간의 선형성 가정의 성립을 볼 수 있으며, 이상치의 기준 판단 가능

# [ 5. 상관행렬과 히트맵: 다변량 관계 한눈에 보기 ]

``` python
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

data = {
    "가격": [10, 20, 30, 40, 50],
    "판매량": [50, 45, 35, 25, 20],
    "매출": [500, 900, 1050, 1000, 1000]
}

df = pd.DataFrame(data)

corr_matrix = df.corr()

print(corr_matrix)

plt.figure(figsize=(6, 4))
sns.heatmap(
    corr_matrix,
    annot=True,
    fmt=".2f",
    cmap="coolwarm",
    vmin=-1,
    vmax=1,
    center=0
)

plt.title("상품 데이터 상관행렬")
plt.tight_layout()
plt.show()
```
- 상관행렬(Correlation Matrix) : 상관계수를 표 형채로 정리한 것
- 여러 변수의 관계를 한 눈에 비교 가능
