#  [ 1. 정규분포 (Normal Distribution) ]

```
 N(μ, σ²) 
    - μ: 평균 - 분포의 중심 위치 결정 
    - σ²: 분산
    - σ: 표준편차 - 분포가 평균을 중심으로 얼마나 넓게 떨어져 있는지 결정

> 평균(μ)을 중심으로 좌우 대칭인 종 모양의 연속확률분포
> 평균(μ)과 표준편차(σ)의 두 가지 모수(parameter)에 의해 결정
    → 모수(parameter) - 모집단의 특성을 요약하는 값 (ex. 정규분포의 평균과 표준편차)
```

# [ 2. 표준 정규분포 (Standard Normal Distribution) ]
```
N(0, 1)
    - 평균이 0, 표준편차가 1인 정규분포

Z = (X - μ) / σ
    - X: 원래 값
    - μ: 원래 분포의 평균
    - σ: 원래 분포의 표준편차
    - Z: 표준화된 값(Z-score)
```
- 평균과 표준편차가 서로 다른 정규분포는 서로 비교할 수 없으므로 동일한 단위 변환이 필요    
→ 표준화 (Standardizaton)


## Z-score와 표준화
```
Z-score = 개별 데이터 값이 평균으로부터 표준편차의 몇 배만큼 떨어져 있는지를 나타내는 값

Z = (X - μ) / σ
- Z = 0 : 평균과 같은 위치
- Z = 1 : 평균보다 표준편차 1배만큼 **높은** 위치
- Z = -1 : 평균보다 표준편차 1배만큼 **낮은** 위치
- Z = 2 : 평균보다 표준편차 2배만큼 **높은** 위치
- Z = -2 : 평균보다 표준편차 2배만큼 **낮은** 위치
```
- ex)   
평균이 60점이고 표준편차가 10점인 시험에서 80점을 받았다면,   
Z = (80 - 60) / 10 = 2   
즉, 80점은 표준편차 2배만큼 높은 위치에 있는 값이라는 의미

## Zscore를 활용한 이상치 탐지      
```
- 이상치 기준 : |Z| > 3인 값을 이상치 후보로 판단

- Z = -1 ~ 1: 약 68.3%
- Z = -2 ~ 2: 약 95.4%
- Z = -3 ~ 3: 약 99.7%
```
- 정규분포를 따르는 데이터에서는 약 99.7%의 데이터가 평균 ± 3 표준편차 범위 안에 존재하게 되지만, 이 범위를 벗어난 값에 대해서는 이상치로 탐지 가능
- 서로 다른 단위와 척도의 데이터를 공정하게 비교 가능
-  이상치 탐지할 경우 Z-score만이 아닌 IQR도 참고하여 처리

# [ 3. 이산확률분포와 연속확률분포 ]

## 이산확률분포 (Discrete Probability Distribution)   
- 변수가 셀 수 있는 값을 가지는 경우
- ex) 주사위 눈의 수(1~6), 사람 수 (0, 1, 2, 3...)
- 각 값에 대해 확률을 직접 구할 수 있음 ** P(X = k)**

## 연속확률분포(Continuous Probability Distribution)
- 변수가 연속적인 실수값을 가질 때
- ex) 키, 온도, 반응시간
- 특정 구간의 확률을 구함
- 정규분포는 연속확률분포로 구분됨

|구분|이산확률분포|연속확률분포|
|---|---|---|
|변수 유형|정수값 (셀 수 있음)|실수값 (무한히 세밀)|
|확률 표현|P(X = k)|P(a ≤ X ≤ b)|
|대표 분포|이항분포, 포아송분포|정규분포, 균등분포|

# [ 4. 이항분포 (Binomial Distribution) ]
```python
X ~ B(n, p)
    - n : 시행 횟수
    - p : 성공 확률


from scipy.stats import binom

binom.pmf(k, n, p)
    - n번의 독립적인 시행에서 성공 확률이 p일 때 정확히 k번 성공할 확률    
```
> 이항분포는 이산확률분포이지만 시행횟수가 충분히 크고 성공확률이 극단적이지 않는다면 종 모양에 가까워지면서 정규분포로 형성이 가능

> 이항분포 성립 조건 4가지:  (다음 조건을 모두 만족하는 성공횟수 X의 분포)  
    1. 고정된 n번의 시행   
    2. 각 시행은 독립적   
    3. 각 시행의 결과는 성공 또는 실패 두 가지뿐   
    4. 성공 확률 p가 모든 시행에서 동일   
    

ex)   
1. 불량률 3%인 공정에서 50개중 2개 이하가 불량일 확률
2. 이메일 오픈율 20%일 때, 100명에세 보낸 메일 중 정확히 25명이 열 확률

```python
문제) 
광고를 20명의 고객에게 보여줬을 때, 각 고객이 광고를 클릭할 확률은 10%이고, 각 고객의 클릭 여부는 독립적이라고 가정한다. 이때 20명 중 정확히 3명이 광고를 클릭할 확률은?  

from scipy.stats import binom

n = 20
p = 0.1
k = 3

probability = binom.pmf(k, n, p)
print(f'정확히 3명이 클릭할 확률 : {probability :.4f}')

# 출력
정확히 3명이 클릭할 확률 : 0.1901
```

## 기댓값과 분산

> **기댓값** : 확률분포에서 무수히 많은 시행을 반복했을 때 평균적으로 얻게되는 값

- ### 기댓값 (Expected Value) : `E(X) = np`
- ### 분산(Variance) : `Var(X) = np(1-p)`

    ex) 불량률 5%, 100개 생산

    - 기댓값: E(X) = 100 × 0.05 = 5개 (평균적으로 5개 불량)
    - 분산: Var(X) = 100 × 0.05 × 0.95 = 4.75
    - 표준편차: σ = √4.75 ≈ 2.18개

    → "생산할 때마다 정확히 5개가 불량"이 아니라, 
        "장기적으로 평균 5개가 불량으로 나온다"는 의미

# [ 5. scipy.stats.binom으로 확률 계산 및 정규근사 ]
ex) 앱 알림 클릭 수를 이항분포와 정규분포로 계산하기   

앱 사용자 1,000명에게 알림을 발송했다. 사용자 한 명이 알림을 클릭할 확률이 20%라면 클릭한 사용자 수 X는 다음 이항분포를 따른다.

```
X ~ B(1000, 0.2)

E(X) = 1000 x 0.2 = 200       # 기댓값
Var(X) = 1000 x 0.2(1 - 0.2) = 160     # 분산 

-> 기댓값과 분산의 값이 모두 충분히 크기 때문에 정규분포로 근사 가능
```
```python
# 이항분포를 연속형인 정규분포로 근사 -> 연속성 보정 (continuity correction) 사용
# X ≤ 220

from scipy.stats import binom, norm

n = 1000
p = 0.2
k = 220

# 이항분포
binom_probability = binom.cdf(k, n, p)

# 정규근사를 위한 평균과 표준편차
mean = n * p
std = (n * p * (1 - p)) ** 0.5

# 연속성 보정을 적용한 정규근사
normal_probability = norm.cdf(k + 0.5, loc=mean, scale=std)

print(f"이항분포 계산: {binom_probability:.4f}")
print(f"정규근사 계산: {normal_probability:.4f}")
```

||확률질량함수 (**p**robability **m**ass **f**unction)|누적분포함수 (**c**umulative **d**istribution **f**unction)|
|-|-|-|
|정의|**정확히 특정 횟수**만큼 성공할 확률 계산|**특정 횟수 이하**로 성공할 누적 확률|
|표현|P(X = x) (0 < X < 1)|P(X ≤ x)|
|특징|이산형 확률변수|이산형, 연속형 확률변수|

```python
from scipy.stats import binom

n, p = 100, 0.2  # 100번 시행, 성공 확률 20%

# 정확히 25번 성공할 확률 (확률질량함수)
prob_25 = binom.pmf(25, n, p)
print(f"정확히 25번 성공: {prob_25:.4f}")

# 25번 이하 성공할 확률 (누적분포함수)
prob_le_25 = binom.cdf(25, n, p)
print(f"25번 이하 성공: {prob_le_25:.4f}")

# 기댓값과 분산 계산
mean, var = binom.stats(n, p)
print(f"기댓값: {mean}, 분산: {var}")  # 20.0, 16.0
```


### 중심극한정리
- 이항분포에서 n이 충분히 크고 p가 0이나 1에서 멀리 떨어져 있을때, 이항분포는 정규분포로 근사할 수 있음   
`B(n, p) ≈ N(np, np(1-p))`
- 표본 수가 30개 이상이면 중심극한정리를 가정하여 정규성을 가정 가능
