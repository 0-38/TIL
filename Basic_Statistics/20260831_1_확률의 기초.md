# [확률의 기초]
## [확률 (Probability)]   
> 어떤 사건이 일어날 가능성을 0부터 1사이의 숫자로 나타낸 것

**덧셈 법칙**: 두 사건 중 하나라도 발생할 확률

- P(A ∪ B) = P(A) + P(B) - P(A ∩ B)
- 두 사건이 배반 사건이면: P(A ∪ B) = P(A) + P(B)

**곱셈 법칙**: 두 사건이 모두 발생할 확률

- P(A ∩ B) = P(A) × P(B|A)
- 두 사건이 독립이면: P(A ∩ B) = P(A) × P(B)

**여사건**: 사건 A가 일어나지 않을 확률

- P(Aᶜ) = 1 - P(A)

   
   
## [조건부 확률]
```
> P(A|B) = P(A ∩ B) / P(B)  (단, P(B) > 0)   
> 어떤 사건 B가 이미 발생했다는 조건 하에서 사건 A가 발생할 확률  
```
- 나이브 베이즈 분류기 (머신러닝)는 조건부 확률로 동작   
- 변수들 사이의 관계를 정량화하는 가장 기본적인 방법 


## [베이즈 정리 (Bayes' Theorem)]
```
> 사전 확률에 새로운 증거를 반영해 사후확률을 계산하는 방법

P(A|B) = P(A ∩ B) / P(B) ← 곱셈법칙 정의 넣어주면 
P(B|A) P(A) / P(B) 
        = P(B|A) P(A) / P(B) 

→ 조건부 확률 정의: P(A|B) = P(A ∩ B) / P(B)
→ 곱셈 법칙 정의: P(A ∩ B) = P(A) × P(B|A)
```

예시: 의료 검사

- 어떤 질병의 유병률(사전 확률) P(질병) = 0.01 (1%)
- 실제 환자에게 양성이 나올 확률 P(양성|질병) = 0.95
- 건강한 사람에게 양성이 나올 확률(위양성) P(양성|정상) = 0.05
- 검사 결과 양성이 나왔을 때 실제로 병이 있을 확률은 생각보다 낮을 수 있습니다.

**문제)   
어떤 스팸 필터가 실제 스팸 메일을 "스팸"으로 정확히 분류할 확률은 90%이고, 정상 메일을 실수로 "스팸"으로 분류할 확률(위양성)은 5%이다. 전체 메일 중 스팸의 비율(사전 확률)은 10%다.**   
어떤 메일이 "스팸"으로 분류되었을 때, 이 메일이 실제로 스팸일 확률을 베이즈 정리로 계산해보세요.

- 정답
    
    P(스팸) = 0.1
    
    P(정상) = 1 - P(스팸) = 0.9 
    
    P(스팸분류|스팸) =  0.9 
    
    P(스팸분류|정상) = 0.05 
    
    문제에서 주어진 것 외 추가 확인해야 할 것은 P(스팸분류)

> P(스팸분류)   
→ 스팸 중 스팸 분류되는 것 + 정상 중 스팸분류되는 것.  
→ P(스팸 분류, 스팸) + P(스팸 분류, 정상)    
→ P(스팸분류|스팸)P(스팸) + P(스팸분류|정상) P(정상)   
= 0.9×0.1 + 0.05×0.9 = 0.09 + 0.045 = 0.135

> P(스팸|스팸분류)   
= P(스팸, 스팸분류) / P(스팸분류)   
= P(스팸분류|스팸)×P(스팸) / P(스팸분류)

> P(스팸|스팸분류)    
= P(스팸분류|스팸)×P(스팸) / P(스팸분류)   
→ P(A|B) = P(B|A)P(A) / P(B) = (0.9 x 0.1) / 0.135

> P(스팸|스팸분류) = 0.09 / 0.135 ≈ 0.667 (약 66.7%)

검사 정확도가 90%로 높아 보여도 스팸의 사전 확률(10%)이 낮기 때문에, "스팸으로 분류됨"이라는 새 증거를 반영해도 실제 스팸일 확률은 100%가 아닌 약 67%에 그친다는 점이 핵심이다.
