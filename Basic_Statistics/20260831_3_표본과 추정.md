- 모집단(population) : 알고싶은 대상 전체
- 표본(sample) : 모집단에서 일부만 추출하여 실제로 조사한 일부
- 모수(parameter) : 모집단의 특성
- 통계량(statistic) : 표본에서 계산한 값


ex)   
심리검사 연구를 위해 연구 대상 10,000명이 있다. 모든 대상자를 검사하여 연구결과를 내면 자료가 많이 쌓여 좋지만, 모든 대상자를 검사하면 시간과 비용이 많이 든다. 그래서 모든 대상자 중 일부인 1,000명을 무작위로 뽑아 각 수치형 변수의 평균 검사 결과를 낼 수 있다.

여기서
- **모집단:** 모든 연구대상자 1만 명
- **표본:** 무작위로 선택한 대상자 1,000명
- **모수:** 모든 대상자의 실제 평균 검사 결과
- **통계량:** 표본 1,000명의 평균 검사결과

> 표본의 통계량을 이용해 모집단의 모수를 추정
```python
import pandas as pd

# 전체 고객의 구매금액 데이터라고 가정
population = pd.Series([
    32000, 45000, 28000, 51000, 39000,
    62000, 47000, 35000, 41000, 55000
])

# 모집단에서 5명을 표본으로 추출
sample = population.sample(n=5, random_state=42)
```

# [ 2. 표본 추출 방법 ]

> ### 1) 단순 무작위 추출 (Simple Random Sampling)
- 모집단의 모든 구성원이 동일한 확률로 선택되는 방법
- 무작위 추출
```python
# 모집단에서 10명 무작위 추출
sample = df.sample(n = 10, random_state = 42)
```

> ### 2) 층화 추출 (Stratified Sampling)
- 모집단을 의미있는 하위그룹(층)으로 나눈 후, 각 층에서 무작위로 추출하는 방법
- 집단 간 비교 분석이 필요할 경우 사용
- ex) 성별, 연령대, 지역 등으로 하위 층을 나눈 후, 각 층에서 표본 추출

```python
# 성별에 따른 층화추출 (각 층에서 50명 추출)
sample = df.groupby('gender').apply(lambda x : x.sample(n = 50))
```
> ### 3) 군집 추출
- 형성된 집단(군집)을 무작위로 선택한 뒤, 선택된 군집 내에서 구성원을 전수 조사하는 방법
- 일부 군집을 선택

> ### 4) 계통 추출 (Systematic Sampling)
- 목록에서 일정한 간격(k)으로 표본을 추출하는 방법
- 1,000명의 목록에서 100명을 뽑을 때 -> 10번째 마다 한 명씩 표본 추출
```python
k = len(df) // 100 # 모집단 중 100명 표본 추출 예정

sample = df.iloc[::k]
```

## 샘플링 편향 (Sampling Bias)
> 표본이 모집단을 제대로 대표하지 못할 때 발생하는 오류

- 선택 편향 : 특정 그룹이 과대/과소 대표됨 (ex) 온라인 설문 -> 인터넷 사용자만 응답한 것으로 표본 추출)
- 생존 편향 : 성공한 사례만 보고 실패 사례를 무시함
- 자기선택 편향 : 특정 성향의 사람들만 집중적으로 참여함
