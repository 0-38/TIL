# [ 1. 표본분포 (Sampling Distribution) ]

> - 같은 모집단에서 같은 크기의 표본을 반복해서 추출할 때, 각 표본에서 계산한 통계량이 이루는 확률분포  
> - 랜덤으로 표본을 추출하기 때문에 각 표본이 이루는 통계량은 다를 수 있음

```python
# 표본 분포 반복 추출

import numpy as np

np.random.seed(10)

population = np.random.normal(50000, 10000, 10000)

sample_means = []

# 30명씩 뽑아 평균을 구하는 과정을 500번 반복
for _ in range(500):
    sample = np.random_choice(population, size = 30, replace = True)
    sample_means.append(np.mean(sample))

print(f'모집단 평균 : {np.mean(population):.2f}원')
print(f'표본집단들의 평균 : {np.mean(sample_means):.2f}원')

# [출력결과 예시] - 표본집단에 따라 결과가 달라질 수 있음
모집단 평균 : 50051.02원
표본집단들의 평균 : 49990.67원
```

### 표본 분포의 특성
- 중심 : 기댓값 = 모평균(μ)
- 퍼짐 정도 : 표준편차 = 표준오차(Standard Error) =  σ / √n
- 표본 크기의 영향 : n이 커질수록 표준오차가 작아짐 -> 표본평균들이 중심에 가깝게 모이게 됨
- 형태 : n이 충분히 커지게 되면 정규분포 형태에 가까워짐 -> 중심극한정리

# [ 2. 중심극한정리(**C**entral **L**imit **T**heorem) ]
> 모집단에서 크기 n만큼 표본을 반복추출하여 평균을 구했을때,  
**n이 충분히 크면 표본평균들의 분포가 정규분포에 가까워진다**는 정리

||모집단|표본집단||
|---|---|---|---|
|평균|μ|μ|
|분산|σ²| σ²/n|
|표준편차|σ|σ/√n|

- 보통 n ≥ 30 일때 정규분포를 이룬다고 가정함
- 하지만 절대적인 지표는 아니며 표본마다 다를 수 있음

```python
import numpy as np
import matplotlib.pyplot as plt

# 균등분포에서 표본평균 반복 계산
n_simulations = 1000
sample_size = 30

sample_means = []
for _ in range(n_simulations):
    sample = np.random.uniform(0, 1, sample_size)
    sample_means.append(np.mean(sample))

# 시각화
plt.figure(figsize=(10, 4))
plt.subplot(1, 2, 1)
plt.hist(np.random.uniform(0, 1, 10000), bins=50, color='skyblue')
plt.title('모집단 분포 (균등분포)')

plt.subplot(1, 2, 2)
plt.hist(sample_means, bins=50, color='salmon')
plt.title(f'표본평균의 분포 (n={sample_size})')
plt.tight_layout()
plt.show()
```

# [ 3. 표준오차 (**S**tandard **E**rror) ]
> 표본평균들의 표준편차

수식 : `SE = σ/√n`
- n이 4배 커지면 SE = σ/√4 -> SE는 절반으로 감소
- n이 100배 커지면 SE = σ/√100 -> SE는 1/10 감소  
-> 표본이 커질수록 표준오차가 작아진다   
=> 표본이 커질수록 **추정이 정밀해진다**는 의미
