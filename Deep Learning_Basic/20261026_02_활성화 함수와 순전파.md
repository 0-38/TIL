# 02. [DNN의 기본 구조와 순전파] : 활성화 함수와 순전파

# 1. 활성화 함수와 신경망의 계산 흐름

## 1-1) 이전 강의의 `Z = XW + b`에서 시작하기

앞선 강의에서는 Dense Layer의 기본 연산을 다음과 같이 학습했다.

$$
Z=XW+b
$$

여기서

- `X`: 입력 데이터
- `W`: Weight
- `b`: Bias
- `Z`: 가중합 또는 Pre-Activation 값

이다.

하지만 DNN은 일반적으로 `Z`를 그대로 다음 Layer로 전달하지 않는다.

Hidden Layer에서는 다음과 같이 **Activation Function**을 추가한다.

$$
A=f(Z)
$$

따라서 하나의 Hidden Layer는 다음 흐름으로 이해할 수 있다.

```text
Input
↓
Linear
Z = XW + b
↓
Activation Function
A = f(Z)
↓
Next Layer
```

즉 지난 강의에서 배운 `행렬곱 + Bias` 뒤에 **Activation Function이 추가되면서 본격적인 DNN 구조가 만들어진다.**

## 1-2) 활성화 함수(Activation Function)란?

Activation Function은 뉴런이 계산한 가중합 `Z`를 새로운 값으로 변환하는 함수이다.

$$
A=f(Z)
$$

Activation Function은 크게 두 가지 역할을 한다.

| 역할 | 설명 |
| --- | --- |
| 값 변환 | Logit 또는 가중합을 특정 형태로 변환 |
| 비선형성 추가 | Network가 복잡한 비선형 관계를 표현할 수 있도록 함 |

대표적인 활성화 함수는 다음과 같다.

| 함수 | 출력 범위 | 대표적인 활용 | 주로 활용되는 레이어 |
| --- | --- | --- | --- |
| **Sigmoid** | `(0, 1)` | Binary Classification 확률 계산, Gate 제어 | 출력층(이진 분류) / <br> 은닉층에서도 사용 가능 |
| **Softmax** | `(0, 1)` | Multi-Class Classification 확률 계산, Attention 가중치 | 출력층(다중 분류) / <br> Attention 등 내부 연산 |
| **Tanh** | `(-1, 1)` | 일부 RNN 및 상태 표현, 비선형 특징 변환 | 은닉층 / <br> 일부 RNN·LSTM 내부 |
| **ReLU** | `[0, ∞)` | 일반적인 DNN의 비선형 특징 학습 | 주로 은닉층 |
| **Leaky ReLU** | `(-∞, ∞)` | 음수 영역에서도 작은 기울기를 유지하여 Dying ReLU 문제 완화 | 주로 은닉층 |

### 활성화 함수별 특징

- **Sigmoid**: 각 입력값을 0~1 사이로 변환하며, 주로 이진 분류의 확률 계산에 사용한다.
- **Softmax**: 여러 출력값을 하나의 확률 분포로 변환하며, 전체 출력값의 합이 1이 된다.
- **Tanh**: 입력값을 -1~1 사이로 변환하며, 주로 은닉층이나 RNN에서 사용한다.
- **ReLU**: 음수는 0으로 변환하고 양수는 그대로 유지하여 비선형성을 추가한다.
- **Leaky ReLU**: 양수는 그대로 유지하고 음수에는 작은 기울기를 적용하여 음수 영역에서도 기울기가 전달되도록 한다.

### 핵심 정리

- **은닉층**: ReLU, Leaky ReLU, Tanh 등을 주로 사용하여 비선형 특징을 학습한다.
- **출력층(이진 분류)**: Sigmoid를 사용하여 클래스 1의 확률을 계산한다.
- **출력층(다중 분류)**: Softmax를 사용하여 각 클래스의 확률을 계산한다.
- **출력층(회귀)**: 일반적으로 활성화 함수를 사용하지 않고 연속적인 값을 출력한다.

※ PyTorch에서 `BCEWithLogitsLoss` 또는 `CrossEntropyLoss`를 사용하는 경우, 학습 시 모델의 출력에 Sigmoid나 Softmax를 별도로 적용하지 않고 Logit을 손실함수에 전달한다.

## 1-3) 보행 센서 데이터에서는 어떻게 사용되는가?

웨어러블 IMU를 이용하여 보행 패턴을 분류한다고 가정하자.

입력 Feature는 다음과 같이 구성할 수 있다.

| 변수 | 의미 |
| --- | --- |
| `cadence_norm` | 정규화된 보행 Cadence |
| `pelvic_acc_rms_norm` | 골반 가속도 RMS |
| `stance_asymmetry_norm` | 좌우 입각시간 비대칭 |

하나의 Hidden Neuron은 다음과 같이 계산할 수 있다.

$$
z = w_1x_1+w_2x_2+w_3x_3+b
$$

그리고 ReLU를 적용한다면

$$
h=\mathrm{ReLU}(z)
$$

가 된다.

즉 Sensor Data가 바로 최종 예측으로 가는 것이 아니라,

```text
센서 Feature
↓
Weight + Bias
↓
가중합
↓
Activation
↓
새로운 Hidden Representation
```

으로 단계적으로 변환된다.

# 2. Sigmoid 함수

## 2-1) Sigmoid의 수식과 출력 범위

Sigmoid 함수는 실수 입력을 `0`과 `1` 사이의 값으로 변환한다.

$$
\sigma(z) = \frac{1}{1+e^{-z}}
$$

출력 범위는

$$
0<\sigma(z)<1
$$

이다.

대표적인 입력값에 대한 결과는 다음과 같다.

| `z` | `Sigmoid(z)` |
| ---: | ---: |
| -2 | 0.119 |
| -1 | 0.269 |
| 0 | 0.500 |
| 1 | 0.731 |
| 2 | 0.881 |

입력이 큰 양수일수록 `1`에 가까워지고, 큰 음수일수록 `0`에 가까워진다.

- 로짓(예측값)값에서 확률값으로 변환한다.

## 2-2) Binary Classification과 Sigmoid

보행 패턴을

```text
0 = Normal Pattern
1 = Abnormal Pattern
```

으로 분류한다고 하자.

Output Layer에서 계산한 값이

```text
Logit = 0.8
```

이라면 Sigmoid를 적용하여 **Class 1** Probability를 계산할 수 있다.

$$
P(Y=1) = \sigma(0.8)
$$

$$
P(Y=1)\approx0.690
$$

즉

```text
Abnormal Pattern Probability
≈ 69.0%
```

로 해석할 수 있다.

Class 0 Probability는

$$
P(Y=0)=1-P(Y=1)
$$

이므로

$$
1-0.690=0.310
$$

이다.

## 2-3) Sigmoid의 미분

Sigmoid의 도함수는 다음과 같다.

$$
\sigma'(z) = \sigma(z)(1-\sigma(z))
$$

`z=0`이라면

$$
\sigma(0)=0.5
$$

이므로

$$
\sigma'(0) = 0.5(1-0.5) = 0.25
$$

이다.

Sigmoid는 `|z|`가 매우 커지면 출력값이 0 또는 1에 가까워지고 미분값도 0에 가까워진다.

이러한 특성은 깊은 Network의 Backpropagation(역전파)에서 **Vanishing Gradient(기울기 소실)** 와 연결될 수 있다.

# 3. Tanh 함수

## 3-1) Tanh의 수식과 출력 범위

Tanh는 다음과 같이 정의된다.

$$
\tanh(z) = \frac{e^z-e^{-z}} {e^z+e^{-z}}
$$

출력 범위는

$$
-1<\tanh(z)<1
$$

이다.

| `z` | `Tanh(z)` |
| ---: | ---: |
| -2 | -0.964 |
| -1 | -0.762 |
| 0 | 0 |
| 1 | 0.762 |
| 2 | 0.964 |

Sigmoid와 달리 음수 출력이 존재하며 `z=0`일 때 출력도 0이다.

## 3-2) Sigmoid와 Tanh 비교

| 구분 | Sigmoid | Tanh |
| --- | --- | --- |
| 출력 범위 | `(0, 1)` | `(-1, 1)` |
| `z=0` 출력 | 0.5 | 0 |
| 음수 출력 | X | O |
| 중심 | 0.5 부근 | 0 중심 |
| 대표 활용 | Binary Output | 일부 Hidden State |

## 3-3) Tanh의 미분

Tanh의 도함수는 다음과 같다.

$$
tanh'(z) = 1-\tanh^2(z)
$$

`z=0`에서는

$$
\tanh(0)=0
$$

이므로

$$
tanh'(0)=1
$$

이다.

하지만 Sigmoid와 마찬가지로 입력 절댓값이 커지면 미분값이 0에 가까워질 수 있다.

# 4. ReLU 함수

## 4-1) ReLU의 수식

ReLU는 Rectified Linear Unit의 약자이다.

$$
\mathrm{ReLU}(z)=\max(0,z)
$$

즉,

$$
\mathrm{ReLU}(z)=
\begin{cases}
0 & z \leq 0 \\
z & z > 0
\end{cases}
$$

이다.

| `z` | `ReLU(z)` |
| ---: | ---: |
| -2 | 0 |
| -1 | 0 |
| 0 | 0 |
| 1 | 1 |
| 2 | 2 |

출력 범위는

$$
[0,\infty)
$$

이다.

## 4-2) ReLU가 Hidden Layer에서 많이 사용되는 이유

ReLU는 양수 영역에서 입력값을 그대로 전달한다.

따라서 Sigmoid와 Tanh처럼 양수 영역 전체가 포화되는 구조가 아니다.

또한 계산도 매우 단순하다.

```text
음수 → 0
양수 → 그대로
```

이러한 특징 때문에 일반적인 DNN Hidden Layer에서 널리 사용된다.

## 4-3) ReLU의 미분

ReLU의 미분은 다음처럼 생각할 수 있다.

$$
\mathrm{ReLU}'(z)=
\begin{cases}
0 & z < 0 \\
1 & z > 0
\end{cases}
$$

`z=0`에서는 수학적으로 미분 가능하지 않다.

Deep Learning Framework에서는 구현상 특정 값을 정의하여 사용하며, PyTorch의 경우 일반적으로 `0`으로 처리한다.

## 4-4) Dead ReLU

ReLU의 입력이 계속 음수라면

```text
ReLU Output = 0
Gradient = 0
```

상태가 반복될 수 있다.

그러면 해당 Neuron의 Weight가 충분히 Update되지 않는 문제가 발생할 수 있다.

이를 **Dead ReLU** 문제라고 한다.

이번 단계에서는

> ReLU는 양수 영역에서는 Gradient가 잘 전달되지만, 음수 영역에서는 Gradient가 0이 될 수 있다.

정도로 이해하면 된다.

# 5. Sigmoid·Tanh·ReLU 비교

## 5-1) 세 활성화 함수의 핵심 차이

| 구분 | Sigmoid | Tanh | ReLU |
| --- | --- | --- | --- |
| 수식 | `1/(1+e^-z)` | Hyperbolic Tangent | `max(0,z)` |
| 출력 범위 | `(0,1)` | `(-1,1)` | `[0,∞)` |
| 음수 출력 | X | O | X |
| `z=0` 출력 | 0.5 | 0 | 0 |
| 큰 양수 | 1에 접근 | 1에 접근 | 그대로 증가 |
| 큰 음수 | 0에 접근 | -1에 접근 | 0 |
| Hidden Layer | 제한적 사용 | 특정 구조 | 매우 많이 사용 |
| Binary Output | 대표적으로 사용 | 거의 사용하지 않음 | 일반적이지 않음 |

## 5-2) 같은 입력에 세 함수를 적용하기

[ Python : code ] "동일한 입력에 Sigmoid, Tanh, ReLU를 적용해 출력 비교"

```python
import numpy as np

z = np.array([-2., -1., 0., 1., 2.])

sigmoid = 1 / (1 + np.exp(-z))
tanh = np.tanh(z)
relu = np.maximum(0, z)

print("Sigmoid:", np.round(sigmoid, 3))
print("Tanh:", np.round(tanh, 3))
print("ReLU:", relu)
```

[ Result ]

```text
Sigmoid: [0.119 0.269 0.500 0.731 0.881]
Tanh: [-0.964 -0.762  0.000  0.762  0.964]
ReLU: [0. 0. 0. 1. 2.]
```

같은 입력이라도 Activation Function에 따라 전혀 다른 Hidden Representation이 만들어진다.

## 5-3) 활성화 함수를 미분하는 이유

**활성화 함수(Activation Function)를 미분하는 이유**

- 특정 입력 지점에서 활성화 함수 출력값의 변화율(기울기)을 계산하기 위해
- 역전파 과정에서 Chain Rule(연쇄법칙)을 적용하여 이전 Layer로 기울기를 전달하기 위해
- 각 가중치(Weight)와 편향(Bias)이 최종 Loss에 미치는 영향을 계산하기 위해
- 계산된 기울기를 바탕으로 Optimizer가 가중치와 편향을 업데이트하기 위해

```text
[순전파 Forward Propagation]
입력값
   ↓
가중합 + 편향 (z)
   ↓
활성화 함수 f(z)
   ↓
다음 은닉층 → 최종 예측 → Loss
------------------------------------------
[역전파 Backpropagation]
손실함수(Loss)
   ↓
손실함수 미분 (예측값 변화에 대한 손실의 기울기 계산)
   ↓
┌─────────────────────────────────────────┐
│       Chain Rule (연쇄법칙) 시작           │
│                                         │
│ 출력층의 기울기 계산                         │
│   ↓                                     │
│ 출력층의 기울기 × 은닉층 2의 미분값             │
│   ↓                                     │
│ 은닉층 2의 기울기 계산                       │
│   ↓                                     │
│ 연결 가중치를 반영하여 기울기 전달              │
│   ↓                                     │
│ 전달된 기울기 × 은닉층 1의 미분값             │
│   ↓                                     │
│ 은닉층 1의 기울기 계산                       │
│   ↓                                     │
│ 각 층의 가중치와 편향에 대한                  │
│ Loss의 기울기 계산                         │
└─────────────────────────────────────────┘
   ↓
각 층의 기울기 저장
   ↓
Optimizer가 가중치와 편향 업데이트
   ↓
Loss를 줄이는 방향으로 학습
```

**핵심:**

1. 순전파에서는 활성화 함수로 출력값을 계산하고,
2. 역전파에서는 활성화 함수의 미분값을 이용하여 손실함수의 기울기를 이전 층으로 전달한다.

# 6. 비선형 활성화 함수가 필요한 이유

## 6-1) Linear Layer만 여러 개 연결하면 어떻게 되는가?

다음 두 Layer를 생각하자.

$$
h=2x+1
$$

$$
y=3h-2
$$

첫 번째 식을 두 번째 식에 대입하면

$$
y=3(2x+1)-2
$$

$$
y=6x+1
$$

이다.

즉 두 개의 Layer를 사용했지만 결국 하나의 Affine Transformation이다.

```text
Linear
↓
Linear
```

을 많이 반복하더라도 Activation Function이 없다면 하나의 Affine Transformation으로 합칠 수 있다.

## 6-2) Matrix 형태에서도 동일하다

첫 번째 Layer가

$$
H=XW_1+b_1
$$

이고 두 번째 Layer가

$$
Y=HW_2+b_2
$$

라고 하자.

첫 번째 식을 대입하면

$$
Y=(XW_1+b_1)W_2+b_2
$$

이다.

정리하면

$$
Y=X(W_1W_2)+(b_1W_2+b_2)
$$

이다.

새로운 Weight와 Bias를

$$
W'=W_1W_2
$$

$$
b'=b_1W_2+b_2
$$

라고 정의하면

$$
Y=XW'+b'
$$

이다.

결국 하나의 Affine Layer와 같다.

## 6-3) ReLU가 추가되면 무엇이 달라지는가?

이번에는

$$
h=\mathrm{ReLU}(2x+1)
$$

$$
y=3h-2
$$

라고 하자.

`2x+1 ≤ 0`이면

$$
h=0
$$

이므로

$$
y=-2
$$

이다.

반면 `2x+1 > 0`이면

$$
h=2x+1
$$

이므로

$$
y=6x+1
$$

이다.

즉 최종 함수는

$$
y=
\begin{cases}
-2 & x\leq-0.5\\
6x+1 & x>-0.5
\end{cases}
$$

가 된다.

하나의 직선이 아니라 입력 구간에 따라 서로 다른 형태를 갖는다.

## 6-4) Linear-only와 ReLU Network 비교

| `x` | Linear만 사용 | ReLU 사용 |
| ---: | ---: | ---: |
| -2 | -11 | -2 |
| -1 | -5 | -2 |
| 0 | 1 | 1 |
| 1 | 7 | 7 |
| 2 | 13 | 13 |

[ Python : code ] "Linear Layer만 연결한 모델과 ReLU를 포함한 모델 비교"

```python
import numpy as np

x = np.array([-2., -1., 0., 1., 2.])

linear_only = 3 * (2 * x + 1) - 2
with_relu = 3 * np.maximum(0, 2 * x + 1) - 2

print("Linear:", linear_only)
print("ReLU:", with_relu)
```

[ Result ]

```text
Linear: [-11.  -5.   1.   7.  13.]
ReLU: [-2. -2.  1.  7. 13.]
```

## 6-5) XOR과 비선형성

XOR처럼 하나의 직선으로 구분하기 어려운 데이터에서는 단순한 Linear Model만으로 한계가 있다.

Hidden Layer에 Non-linear Activation을 적용하면 입력 공간을 여러 단계로 변환하여 더 복잡한 Decision Boundary를 만들 수 있다.

즉,

```text
Linear
→ Linear
→ Linear
```

보다

```text
Linear
→ ReLU
→ Linear
→ ReLU
→ Linear
```

이 더 다양한 함수를 표현할 수 있다.

단,

> 모델의 표현력이 높아졌다고 해서 반드시 Prediction 성능이 좋아지는 것은 아니다.

Dataset, Parameter 수, Optimization, Regularization, Train/Validation 구조도 함께 중요하다.

# 7. 순전파(Forward Propagation)

## 7-1) 순전파란?

Forward Propagation은 현재 Weight와 Bias를 사용하여 Input에서 최종 Prediction 방향으로 값을 계산하는 과정이다.

예를 들어 다음 DNN을 생각하자.

```text
Input 3
↓
Linear 3 → 4
↓
ReLU
↓
Linear 4 → 2
↓
ReLU
↓
Linear 2 → 1
↓
Logit
```

Forward Propagation은

```text
입력
→ Hidden Layer 1
→ Hidden Layer 2
→ Output Layer
```

방향으로 진행된다.

## 7-2) Layer별 수식

첫 번째 Hidden Layer는

$$
Z_1=XW_1+b_1
$$

$$
H_1=\mathrm{ReLU}(Z_1)
$$

이다.

두 번째 Hidden Layer는

$$
Z_2=H_1W_2+b_2
$$

$$
H_2=\mathrm{ReLU}(Z_2)
$$

이다.

Output Layer는

$$
Z_3=H_2W_3+b_3
$$

이다.

Binary Classification Probability가 필요하면

$$
P=\mathrm{Sigmoid}(Z_3)
$$

를 계산한다.

## 7-3) 순전파 흐름도

```text
Gait / IMU Features
X
│
▼
Linear Layer 1
Z₁ = XW₁ + b₁
│
▼
ReLU
H₁
│
▼
Linear Layer 2
Z₂ = H₁W₂ + b₂
│
▼
ReLU
H₂
│
▼
Output Linear
Z₃ = H₂W₃ + b₃
│
▼
Logit
│
├── Training → Loss Function
│
└── Prediction → Sigmoid → Probability
```

Forward Propagation에서는 값을 계산할 뿐 Weight와 Bias를 Update하지 않는다.

# 8. 보행·IMU 데이터로 DNN 순전파 계산하기

## 8-1) 실무형 입력 데이터

# 9. NumPy로 전체 Batch 순전파 구현하기

## 9-1) 실무형 DNN 순전파 코드

[ Python : code ] "보행 IMU Batch를 3→4→2→1 DNN으로 순전파"

```python
import numpy as np

def relu(x):
    return np.maximum(0, x)

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

# 입력값
X = np.array([
    [ 0.8,  0.3, -0.2],
    [ 0.2,  0.7,  0.4],
    [-0.4,  0.5,  0.9],
    [ 0.6, -0.1,  0.2]
])

# Hidden Layer 1 - 가중치 + 편향
W1 = np.array([
    [ 0.5, -0.3,  0.2,  0.4],
    [ 0.1,  0.6, -0.5,  0.2],
    [-0.4,  0.2,  0.3, -0.1]
])
b1 = np.array([0.1, -0.2, 0.0, 0.05])

# Hidden Layer 2 - 가중치 + 편향
W2 = np.array([
    [ 0.6, -0.2],
    [-0.3,  0.5],
    [ 0.4,  0.1],
    [ 0.2,  0.3]
])
b2 = np.array([0.0, -0.1])

# Output Layer - 가중치 + 편향
W3 = np.array([
    [ 0.8],
    [-0.6]
])
b3 = np.array([-0.15])

# Hidden Layer 1
z1 = X @ W1 + b1
h1 = relu(z1) # 활성화 함수 (비선형성 추가)

# Hidden Layer 2
z2 = h1 @ W2 + b2
h2 = relu(z2) # 활성화 함수 (비선형성 추가)

# Output Layer
logits = h2 @ W3 + b3
probabilities = sigmoid(logits) # 활성화 함수(이진분류 - 확률변환)

predictions = (probabilities >= 0.5).astype(int)

print("H1:")
print(np.round(h1, 3))

print("H2:")
print(np.round(h2, 3))

print("Logits:", np.round(logits.ravel(), 4))
print("Probabilities:", np.round(probabilities.ravel(), 3))
print("Predictions:", predictions.ravel())
```

# 10. 순전파와 Shape 변화

## 10-1) `3 → 4 → 2 → 1` Network

Batch Size가 4이고 Network가

```text
3 → 4 → 2 → 1
```

이면 Shape 변화는 다음과 같다.

| 단계 | Shape |
| --- | --- |
| Input `X` | `(4, 3)` |
| `Z₁` | `(4, 4)` |
| `H₁` | `(4, 4)` |
| `Z₂` | `(4, 2)` |
| `H₂` | `(4, 2)` |
| Logit | `(4, 1)` |
| Probability | `(4, 1)` |

Activation Function은 일반적으로 **Shape을 변경하지 않는다.**

즉

```text
Z₁ (4, 4)
↓ ReLU
H₁ (4, 4)
```

처럼 값만 변경되고 Shape은 유지된다.

## 10-2) Linear Layer가 Shape을 바꾼다

`Linear(3 → 4)`가

```text
(4, 3)
→
(4, 4)
```

로 Shape을 바꾸고,

`Linear(4 → 2)`가

```text
(4, 4)
→
(4, 2)
```

로 바꾼다.

따라서 일반적인 Dense DNN에서는

> **Linear Layer가 Feature Dimension을 변경하고 Activation Function은 값의 형태를 비선형적으로 변환한다.**

라고 이해할 수 있다.

# 11. Logit·Probability·Prediction Class

## 11-1) Logit

Output Linear Layer에서 계산한 값이다.

```text
Logit = H @ W + b
```

Binary Classification에서도 Logit 자체는

```text
-∞ ~ +∞
```

범위의 값을 가질 수 있다.

## 11-2) Probability

Binary Classification에서는 Logit에 Sigmoid를 적용하여 Class 1 Probability를 계산할 수 있다.

$$
p=\sigma(z)
$$

예를 들어

```text
Logit = 0.2148
```

이면

```text
Probability ≈ 0.553
```

이다.

## 11-3) Prediction Class

Probability에 **Threshold**를 적용한다.

Threshold가 `0.5`이면

$$
\mathrm{Prediction}=
\begin{cases}
1 & p\geq0.5\\
0 & p<0.5
\end{cases}
$$

이다.

## 11-4) 세 개념 비교

| 구분 | 예 | 의미 |
| --- | ---: | --- |
| Logit | `0.2148` | Output Layer의 Raw Score |
| Probability | `0.553` | Class 1 예측 확률 |
| Prediction | `1` | Threshold 적용 후 Class |

## 11-5) Threshold를 바꾸면 무엇이 변하는가?

Probability가

```text
0.553
```

이라고 하자.

Threshold `0.5`에서는

```text
Prediction = 1
```

이다.

Threshold `0.6`에서는

```text
Prediction = 0
```

이다.

하지만 Probability 자체는 여전히

```text
0.553
```

이다.

즉 Threshold는 모델의 순전파 결과를 다시 계산하는 것이 아니라 **확률을 Class로 변환하는 Decision Rule**이다.

# 12. PyTorch로 순전파 구현하기

## 12-1) `nn.Sequential` 구조

보행 Feature 3개를 사용하는 Network를 다음과 같이 만들 수 있다.

```text
3
↓
Linear(3, 4)
↓
ReLU
↓
Linear(4, 2)
↓
ReLU
↓
Linear(2, 1)
```

[ Python : code ] "PyTorch로 보행 센서 Binary Classification DNN 순전파"

```python
import torch
import torch.nn as nn  # 신경망의 Layer 및 활성화 함수 등을 제공하는 모듈

# 1. 난수 시드 고정
# 모델의 가중치 초기화 결과를 재현하기 위해 사용
torch.manual_seed(42)

# 2. 입력 데이터 생성
# Batch Size = 4 (데이터 4개)
# Input Feature = 3 (각 데이터의 독립변수 3개)
# X Shape = (4, 3) → 2차원 Tensor
X = torch.tensor([
    [ 0.8,  0.3, -0.2],  # Sample 1
    [ 0.2,  0.7,  0.4],  # Sample 2
    [-0.4,  0.5,  0.9],  # Sample 3
    [ 0.6, -0.1,  0.2]   # Sample 4
], dtype=torch.float32)

# 3. DNN(MLP) 모델 정의
# 전체 구조: 3 → 4 → 2 → 1
# nn.Sequential: Layer를 순서대로 연결하여 순전파 수행
model = nn.Sequential(
    # Hidden Layer 1
    # 입력 Feature 3개 → 출력 뉴런 4개
    # 가중치: 3 × 4 = 12개 / 편향: 4개
    # Tensor Shape: (4, 3) → (4, 4)
    nn.Linear(3, 4),

    # ReLU 활성화 함수
    # 음수는 0으로, 양수는 그대로 출력
    # 비선형성을 추가하여 복잡한 특징 학습 가능
    # Tensor Shape 유지: (4, 4)
    nn.ReLU(),

    # Hidden Layer 2
    # 은닉층 1의 출력값 4개 → 출력 뉴런 2개
    # 가중치: 4 × 2 = 8개 / 편향: 2개
    # Tensor Shape: (4, 4) → (4, 2)
    nn.Linear(4, 2),

    # ReLU 활성화 함수
    # Tensor Shape 유지: (4, 2)
    nn.ReLU(),

    # Output Layer
    # 은닉층 2의 출력값 2개 → 출력 뉴런 1개
    # 가중치: 2 × 1 = 2개 / 편향: 1개
    # Tensor Shape: (4, 2) → (4, 1)
    # 활성화 함수 적용 전 원시 출력값(Logit) 생성
    nn.Linear(2, 1)
)

# 4. 모델을 평가 모드로 전환
# Dropout, BatchNorm 등이 있다면 평가 모드로 동작
# 현재 모델은 Linear와 ReLU만 있으므로 실질적인 변화 없음
model.eval()

# 5. 순전파(Forward Propagation)
# torch.no_grad(): 기울기 계산을 위한 연산 기록 비활성화
# 추론 시 메모리 사용량 감소
with torch.no_grad():
    # 입력 데이터 X를 모델에 전달
    # Linear → ReLU → Linear → ReLU → Linear
    # 최종 Logit Shape: (4, 1)
    logits = model(X)

    # Sigmoid 활성화 함수 적용
    # Logit을 0~1 사이의 확률로 변환
    # 각 Sample의 Class 1 예측 확률
    # Probability Shape: (4, 1)
    probabilities = torch.sigmoid(logits)

    # 임계값(Threshold) 0.5를 기준으로 이진 분류
    # 확률 >= 0.5 → Class 1
    # 확률 <  0.5 → Class 0
    # .int(): Boolean(True/False)을 정수(1/0)로 변환
    # Prediction Shape: (4, 1)
    predictions = (probabilities >= 0.5).int()

# 6. 각 Tensor의 Shape 확인
# tuple(): torch.Size([4, 3]) → (4, 3) 형태로 변환
print("Input Shape:", tuple(X.shape))
print("Logit Shape:", tuple(logits.shape))
print("Probability Shape:", tuple(probabilities.shape))
print("Prediction Shape:", tuple(predictions.shape))
```

[ Result ]

```text
Input Shape: (4, 3)
Logit Shape: (4, 1)
Probability Shape: (4, 1)
Prediction Shape: (4, 1)
```

PyTorch가 초기 Weight와 Bias를 임의로 초기화하기 때문에 앞서 직접 지정한 NumPy Network와 Probability 값은 다를 수 있다.

하지만 Shape 흐름은 동일하다.

## 12-2) Layer별 Shape 확인하기

[ Python : code ] "PyTorch DNN의 Hidden Layer 출력 Shape 직접 확인"

```python
h1_linear = model[0](X)
h1 = model[1](h1_linear)

h2_linear = model[2](h1)
h2 = model[3](h2_linear)

logits = model[4](h2)

print("X:", tuple(X.shape))
print("Z1:", tuple(h1_linear.shape))
print("H1:", tuple(h1.shape))
print("Z2:", tuple(h2_linear.shape))
print("H2:", tuple(h2.shape))
print("Logits:", tuple(logits.shape))
```

[ Result ]

```text
Z1: (4, 4)
H1: (4, 4)
Z2: (4, 2)
H2: (4, 2)
Logits: (4, 1)
```

# 13. 출력층 Activation과 Loss Function

## 13-1) Binary Classification

개념적으로는

```text
Logit
↓
Sigmoid
↓
Probability
↓
BCE
```

이다.

하지만 PyTorch에서

```python
nn.BCEWithLogitsLoss()
```

를 사용한다면 Model은 **Sigmoid를 적용하지 않은 Logit**을 반환하도록 구성하는 것이 일반적이다.

```text
Model
↓
Raw Logit
↓
BCEWithLogitsLoss
```

`BCEWithLogitsLoss` 내부에서 Sigmoid와 BCE에 대응하는 계산을 수치적으로 안정적인 방식으로 처리한다.

## 13-2) Multi-Class Classification

Class가

```text
Normal
Mild Abnormal
Severe Abnormal
```

세 개라면 Output Neuron을 3개 사용할 수 있다.

```text
[z₀, z₁, z₂]
```

개념적으로는 Softmax를 적용하여

```text
[P₀, P₁, P₂]
```

를 얻는다.

그러나 PyTorch의

```python
nn.CrossEntropyLoss()
```

는 일반적으로 Softmax 적용 전 Raw Logits을 입력받는다.

따라서

```text
Linear(?, 3)
↓
CrossEntropyLoss
```

형태로 Training한다.

## 13-3) 문제 유형별 출력 구조

| 문제 | Output | 대표 Loss 입력 |
| --- | --- | --- |
| Regression | 연속값 | Raw Output |
| Binary Classification | 1 Logit | `BCEWithLogitsLoss` |
| Multi-Class | K Logits | `CrossEntropyLoss` |

Prediction 단계에서만 필요에 따라 Sigmoid 또는 Softmax Probability를 계산할 수 있다.

# 14. 순전파와 학습 과정의 차이

## 14-1) 순전파만으로 학습되는 것은 아니다

Forward Propagation은

```text
Input
↓
Current Weight / Bias
↓
Prediction
```

을 계산하는 과정이다.

Weight와 Bias를 변경하지 않는다.

## 14-2) 실제 Training 전체 과정

모델 Training은 다음 흐름으로 이루어진다.

```text
1. Input Batch
      ↓
2. Forward Propagation
      ↓
3. Prediction / Logit
      ↓
4. Loss Calculation
      ↓
5. Backpropagation
      ↓
6. Gradient
      ↓
7. Optimizer Step
      ↓
8. Weight / Bias Update
```

즉

```text
Forward
≠
Training 전체
```

이다.

Forward는 Training 과정 중 첫 번째 계산 단계라고 이해해야 한다.

# 15. 활성화 함수 선택 시 자주 혼동하는 내용

## 15-1) Hidden Layer에는 항상 Sigmoid를 사용하는가?

아니다.

일반적인 DNN Hidden Layer에서는 ReLU 계열 함수가 많이 사용된다.

Sigmoid는 Binary Classification Output에서 대표적으로 사용된다.

## 15-2) ReLU가 Probability를 출력하는가?

아니다.

ReLU는

```text
0 ~ +∞
```

범위의 값을 출력하며 Probability Function이 아니다.

## 15-3) Sigmoid Output이면 무조건 Probability인가?

수학적으로 값은 0과 1 사이지만, 모델 맥락 없이 모든 Sigmoid 결과를 Probability라고 단정하면 안 된다.

Binary Classification Output처럼 확률 모델로 설계된 경우 Probability로 해석한다.

## 15-4) Activation Function이 Shape을 바꾸는가?

일반적인 Element-wise Activation Function은 Shape을 바꾸지 않는다.

```text
(32, 64)
↓ ReLU
(32, 64)
```

이다.

## 15-5) Output에 Sigmoid를 넣고 `BCEWithLogitsLoss`를 사용해도 되는가?

중복 적용이 된다.

`BCEWithLogitsLoss`는 Raw Logit을 기대하므로 Model 마지막 Sigmoid는 제거하는 것이 일반적이다.

## 15-6) ReLU를 많이 사용하면 무조건 좋은가?

아니다.

ReLU도 Dead ReLU 문제가 존재할 수 있으며 모델 구조, Initialization, Learning Rate 등에 따라 Training 결과가 달라진다.

---

# 16. Advanced 추가 학습

## 16-1) Leaky ReLU

ReLU는 음수 영역의 Gradient가 0이다.

Leaky ReLU는 음수 영역에서도 작은 기울기를 남겨 Dead ReLU 문제를 완화하려는 Activation이다.

## 16-2) GELU

Transformer 계열 모델에서는 ReLU 대신 GELU가 많이 사용된다.

입력을 단순히 0 또는 그대로 나누는 ReLU보다 부드러운 비선형 변환을 수행한다.

## 16-3) Activation Distribution 확인

실무에서는 각 Hidden Layer의 Activation 값이

- 대부분 0인지
- 지나치게 큰지
- 특정 값에 몰려 있는지

확인하면 Training 문제를 진단하는 데 도움이 될 수 있다.

## 16-4) Threshold는 학습 파라미터가 아니다

Binary Classification에서 Threshold `0.5`는 Weight처럼 Backpropagation으로 학습되는 Parameter가 아니다.

문제 목적에 따라 Precision, Recall, Sensitivity, Specificity 등을 고려하여 별도로 조정할 수 있다.

# 17. 핵심정리

1. Activation Function은 뉴런의 Weighted Sum을 새로운 값으로 변환하는 함수이다.

2. 하나의 Hidden Layer는 기본적으로 다음 구조를 가진다.

```text
Input
→ Linear
→ Activation
→ Output
```

3. Linear Layer의 기본 연산은

$$
Z=XW+b
$$

이다.

4. Activation Function을 적용하면

$$
A=f(Z)
$$

가 된다.

5. Sigmoid는 입력을 `(0,1)` 범위로 변환한다.

6. Sigmoid는 Binary Classification에서 Class 1 Probability를 표현할 때 대표적으로 사용할 수 있다.

7. Tanh는 입력을 `(-1,1)` 범위로 변환한다.

8. Tanh는 0을 중심으로 음수와 양수 출력을 모두 가질 수 있다.

9. ReLU는

$$
\mathrm{ReLU}(z)=\max(0,z)
$$

로 정의된다.

10. ReLU는 음수 입력을 0으로 만들고 양수 입력은 그대로 전달한다.

11. ReLU는 일반적인 DNN Hidden Layer에서 널리 사용된다.

12. Sigmoid의 도함수는

$$
\sigma'(z)=\sigma(z)(1-\sigma(z))
$$

이다.

13. Tanh의 도함수는

$$
\tanh'(z)=1-\tanh^2(z)
$$

이다.

14. ReLU는 양수 영역에서 Gradient가 1이고 음수 영역에서는 0이다.

15. Sigmoid와 Tanh는 입력 절댓값이 커질수록 Gradient가 작아질 수 있다.

16. 이러한 특성은 Vanishing Gradient와 연결된다.

17. ReLU는 음수 영역의 Gradient가 0이기 때문에 Dead ReLU 문제가 발생할 수 있다.

18. 여러 Affine Layer만 연결하면 전체 Network를 하나의 Affine Transformation으로 합칠 수 있다.

19. 예를 들어

$$
H=XW_1+b_1
$$

$$
Y=HW_2+b_2
$$

는

$$
Y=X(W_1W_2)+(b_1W_2+b_2)
$$

로 정리할 수 있다.

20. 따라서 Hidden Layer를 많이 추가하더라도 Non-linear Activation이 없다면 표현 능력에 근본적인 한계가 있다.

21. ReLU 같은 Non-linear Activation을 사용하면 전체 Network를 하나의 Affine Transformation으로 합칠 수 없다.

22. Non-linearity는 DNN이 복잡한 함수와 Decision Boundary를 표현하는 핵심 요소이다.

23. Forward Propagation은 Input에서 Output 방향으로 값을 계산하는 과정이다.

24. Forward Propagation 자체는 Weight와 Bias를 Update하지 않는다.

25. `3 → 4 → 2 → 1` DNN에서는 다음과 같은 계산이 이루어진다.

```text
X
↓
Z₁ = XW₁ + b₁
↓
H₁ = ReLU(Z₁)
↓
Z₂ = H₁W₂ + b₂
↓
H₂ = ReLU(Z₂)
↓
Z₃ = H₂W₃ + b₃
```

26. Binary Classification에서는 최종 `Z₃`를 Logit이라고 할 수 있다.

27. Logit에 Sigmoid를 적용하면 Class 1 Probability를 계산할 수 있다.

28. Logit, Probability, Prediction Class는 서로 다른 개념이다.

29. 예를 들어

```text
Logit = 0.2148
Probability = 0.553
Prediction = 1
```

처럼 표현할 수 있다.

30. Threshold는 Probability를 최종 Class로 변환하는 기준이다.

31. Threshold가 변경되어도 Model이 계산한 Probability 자체는 변경되지 않는다.

32. Dense DNN에서 Linear Layer는 Feature Dimension을 변경할 수 있다.

33. ReLU, Sigmoid, Tanh 같은 일반적인 Element-wise Activation은 Shape을 변경하지 않는다.

34. Batch Size가 4이고 Network가 `3 → 4 → 2 → 1`이라면

```text
(4,3)
→
(4,4)
→
(4,2)
→
(4,1)
```

로 Shape이 변한다.

35. `Z₁`과 `ReLU(Z₁)`의 Shape은 동일하다.

36. PyTorch의 `nn.Sequential`을 이용하면 Layer를 순서대로 연결하여 Forward Propagation을 수행할 수 있다.

37. `model(X)`를 호출하면 정의된 Layer 순서대로 Input이 전달된다.

38. Binary Classification Training에서 `BCEWithLogitsLoss`를 사용한다면 Raw Logit을 Loss에 전달하는 것이 일반적이다.

39. 따라서 `BCEWithLogitsLoss` 앞에서 Sigmoid를 중복해서 적용하지 않는다.

40. Multi-Class Classification의 `CrossEntropyLoss`도 일반적으로 Raw Logits을 입력으로 사용한다.

41. Prediction 단계에서는 필요에 따라 Sigmoid 또는 Softmax를 적용하여 Probability를 확인할 수 있다.

42. Forward Propagation 이후 Model Training을 위해서는 Loss Calculation이 필요하다.

43. 이후 Backpropagation으로 각 Parameter의 Gradient를 계산한다.

44. Optimizer는 계산된 Gradient를 이용하여 Weight와 Bias를 Update한다.

45. 전체 Training Flow는 다음과 같다.

```text
Input Batch
↓
Forward Propagation
↓
Logit / Prediction
↓
Loss
↓
Backpropagation
↓
Gradient
↓
Optimizer
↓
Parameter Update
```

46. 따라서 1장 1강과 1장 2강을 연결하면 DNN의 기본 구조는 다음처럼 이해할 수 있다.

```text
Input Data
↓
Weight / Bias
↓
Linear Transformation
↓
Activation Function
↓
Hidden Representation
↓
다음 Layer
↓
Output Logit
↓
Probability
```

47. 결국 DNN의 순전파는 **`행렬곱 → Bias → Activation`을 여러 번 반복하여 원본 Feature를 단계적으로 새로운 표현으로 변환하는 과정**이다.
