# **1. 선형 변환에서 신경망까지의 전체 흐름**

앞에서 학습한 벡터 내적과 행렬곱은 신경망에서 단순한 계산 도구가 아니라 **입력 데이터를 새로운 표현으로 변환하는 핵심 연산**이다.

신경망의 기본적인 계산은 다음 흐름으로 이해할 수 있다.

```text
입력 데이터 X

        ↓

가중치 행렬 W와 행렬곱

        ↓

선형 변환
XW

        ↓

편향 b 추가

        ↓

아핀 변환
XW + b

        ↓

활성화 함수 적용

        ↓

새로운 Feature 표현

        ↓

다음 Layer

        ↓

최종 Output
```

가장 기본적인 식은 다음과 같다.

$$
Z=XW+b
$$

그리고 활성화 함수 $f$를 적용하면

$$
A=f(Z)
$$

가 된다.

여기서

- `X`: 입력 데이터
- `W`: 가중치
- `b`: 편향
- `Z`: 활성화 함수를 적용하기 전 값
- `A`: 활성화 함수를 적용한 출력

을 의미한다.

<br>

> ## **1-1) 이번 강의에서 연결해야 하는 핵심 개념**

| 개념 | 핵심 역할 |
| --- | --- |
| Linear Transformation | 행렬곱으로 입력을 변환 |
| Affine Transformation | 선형 변환 결과에 Bias 추가 |
| Weight | 입력 Feature를 어떻게 조합할지 결정 |
| Bias | 출력의 기준 위치를 이동 |
| Neuron | 여러 입력을 하나의 출력으로 변환 |
| Layer | 여러 Neuron을 동시에 계산 |
| Activation Function | 비선형성을 추가 |
| Forward Propagation | 입력에서 출력까지 순서대로 계산 |

핵심은 각각의 개념을 따로 외우는 것이 아니라 다음 연결을 이해하는 것이다.

```text
행렬곱
→ 선형 변환

선형 변환 + Bias
→ 아핀 변환

아핀 변환 + Activation
→ 신경망 Layer

여러 Layer 연결
→ Neural Network
```

# **2. 선형 변환(Linear Transformation)의 의미**

**선형 변환**은 Vector를 다른 Vector로 변환하면서 **덧셈과 Scalar Multiplication의 구조를 보존하는 변환**이다.

행 벡터를 기준으로 하면 다음과 같이 표현할 수 있다.

$$
T(x)=xW
$$

여기서

- `x`: 입력 Vector
- `W`: 변환 Matrix
- `T(x)`: 변환 결과

이다.

수학 교재에서는 열 벡터를 사용하는 경우가 많기 때문에 다음과 같이 표현하기도 한다.

$$
T(x)=Wx
$$

둘 중 어느 표현을 사용하는지가 중요한 것이 아니라 **Vector와 Matrix의 Shape와 방향을 일관되게 유지하는 것**이 중요하다.

<br>

> ## **2-1) 간단한 선형 변환 예제**

입력 Vector를 다음과 같이 정의하자.

$$
x=[3,2]
$$

변환 Matrix:

$$
W=
\begin{bmatrix}
2&0\\
0&3
\end{bmatrix}
$$

행 벡터 표기에서는

$$
T(x)=xW
$$

이므로

첫 번째 출력은

$$
3(2)+2(0)=6
$$

두 번째 출력은

$$
3(0)+2(3)=6
$$

이다.

따라서

$$
T(x)=[6,6]
$$

이다.

원래 Vector는

```text
[3, 2]
```

였지만 선형 변환 이후

```text
[6, 6]
```

으로 바뀌었다.

즉 Matrix `W`는 입력 공간의 Vector를 새로운 Vector로 변환하는 역할을 한다.

<br>

> ## **2-2) Python 예제**

[ Python : code ] "행렬곱을 이용한 선형 변환"

```python
import numpy as np

x = np.array([3, 2])

W = np.array([
    [2, 0],
    [0, 3]
])

output = x @ W

print(output)
```

[ Result ]

```text
[6 6]
```

# **3. 선형 변환이 만족해야 하는 두 가지 성질**

모든 행렬 연산이나 함수가 선형 변환인 것은 아니다.

선형 변환은 다음 두 조건을 만족해야 한다.

<br>

> ## **3-1) 덧셈 보존 - Additivity**

두 Vector $a,b$에 대해

$$
T(a+b)=T(a)+T(b)
$$

가 성립해야 한다.

- 덧셈 보존  
        - 두 벡터를 먼저 더한 뒤 변환하는, 각각 변환한 뒤 더하는 결과가 같다.   
        - `T`는 벡터를 다른 벡터로 바꾸는 변환(Transformation)을 의미한다.

예를 들어 아래의 a, b 두 벡터가 있다고 가정하고

변환 규칙은 각 원소를 2배로 만드는 것으로 정해보면,

$$
T([x,y])=[2x,2y]
$$

로 표현된다.

$$
a=[1, 2]
$$

$$
b=[3, 4]
$$

이고

> **방법 1. 먼저 더하고 변환하기**

벡터를 먼저 더하면, 

$$
a+b = [1+3, \ 2+4] = [4, \ 6]
$$

여기에 변환을 적용하면 

$$
T(a+b) = T([4,6]) = [8, \ 12]
$$

> **방법 2. 각각 변환하고 더하기**

먼저 각 벡터를 변환하면(2배로 만드는 변환 규칙을 먼저 적용),

$$
T(a) = [2, \ 4]
$$

$$
T(b) = [6, \ 8]
$$

두 결과를 더하면 

$$
T(a)+T(b)=[8,12]
$$

> **방법 3. 최종 결과 비교**

방법 1의
$$
T(a+b)= [8, \ 12]
$$

방법2의 
$$
T(a)+T(b) = [8, \ 12]
$$

따라서

$$
T(a+b)=T(a)+T(b)
$$

가 성립한다.

<br>


> ## 3-2) Scalar Multiplication 보존 - Homogeneity

**스칼라 곱 보존은 벡터를 먼저 c배 한 뒤 변환하든, 변환한 벡터를 c배 하든 결과가 같다는 의미이다.**

$$
T(ca)=cT(a)
$$

> ### 예제

벡터와 Scalar가 다음과 같다고 가정하자.

$$
a=[1,2],\quad c=2
$$

변환 규칙은 다음과 같다.

$$
T([x,y])=[2x, \ 3y]
$$

> ### 방법 1) 먼저 2배 한 뒤 변환

$$
ca=2[1,2]=[2, \ 4]
$$

$$
T(ca)=T([2,4])=[4, \ 12]
$$

> ### 방법 2) 먼저 변환한 뒤 2배

$$
T(a)=T([1,2])=[2, \ 6]
$$

$$
cT(a)=2[2,6]=[4,\ 12]
$$

> ### 방법 3) 결과 비교

```text
방법 1. 벡터를 2배 → 변환

[1,2] → [2,4] → [4,12]


방법 2. 벡터를 변환 → 2배

[1,2] → [2,6] → [4,12]


         결과 동일
```

$$
\boxed{T(ca)=cT(a)=[4,12]}
$$


- **Scalar:** 벡터에 곱하는 하나의 숫자.
- **Homogeneity:** 스칼라 곱과 선형 변환의 순서를 바꿔도 결과가 동일한 성질.
- 모든 벡터와 Scalar에 대해 이 성질이 성립해야 한다.

**즉, 스칼라 곱 보존은 변환 전후에 벡터를 확대하거나 축소하는 순서가 결과에 영향을 주지 않는다는 의미이다.**


<br>

> ## **3-3) Python으로 두 조건 확인**

[ Python : code ] "선형 변환의 덧셈 및 Scalar Multiplication 보존 확인"

```python
import numpy as np

a = np.array([1, 2])
b = np.array([2, 1])
c = 2

W = np.array([
    [2, 0],
    [0, 3]
])

# 덧셈 보존의 법칙
add_left = (a + b) @ W
add_right = (a @ W) + (b @ W)

# 곱셈 보존의 법칙
scale_left = (c * a) @ W
scale_right = c * (a @ W)

print(add_left)
print(add_right)

print(scale_left)
print(scale_right)
```

[ Result ]

```text
[6 9]
[6 9]

[ 4 12]
[ 4 12]
```

# **4. 선형 변환은 반드시 원점을 유지한다**

> ## **4-1) 0 Vector를 넣으면 반드시 0 Vector가 나온다**

선형 변환은 다음 성질도 자연스럽게 만족한다.

$$
T(0)=0
$$

행렬곱으로 보면

$$
0W=0
$$

이기 때문이다.

예를 들어

$$
x=[0,0]
$$

이라면 어떠한 선형 변환 Matrix를 곱하더라도

$$
T(x)=[0,0]
$$

이다.

이 성질은 이후 **Affine Transformation과 Linear Transformation을 구분하는 중요한 기준**이 된다.

# **5. 선형 변환은 공간을 어떻게 변화시키는가**

행렬곱은 단순히 숫자를 계산하는 것이 아니라 Vector가 존재하는 공간을 변환한다.

Matrix의 값에 따라 다음과 같은 변환을 표현할 수 있다.

| 변환 | 의미 |
| --- | --- |
| Scaling | 특정 방향으로 확대 또는 축소 |
| Rotation | Vector 방향 회전 |
| Reflection | 특정 축을 기준으로 반사 |
| Projection | 특정 방향으로 투영 |
| Dimension Transformation | 입력 Dimension을 다른 Dimension으로 변경 |

<br>

> ## **5-1) Scaling 예제**

$$
W=
\begin{bmatrix}
2&0\\
0&3
\end{bmatrix}
$$

라면

```text
첫 번째 축
→ 2배

두 번째 축
→ 3배
```

로 변환한다.

따라서

$$
[3,2]\rightarrow[6,6]
$$

이 된다.

<br>

> ## **5-2) Dimension 자체도 바꿀 수 있다**

입력 Vector가 Feature 3개라고 하자.

```text
x.shape
→ (3,)
```

가중치 Matrix가

```text
W.shape
→ (3, 5)
```

라면

```text
x @ W

→ (5,)
```

가 된다.

즉 입력 Feature 3개를 이용해 **새로운 Feature 5개**를 만들 수 있다.

신경망에서 Layer가 하는 일이 바로 이와 연결된다.

# **6. 아핀 변환(Affine Transformation)**

선형 변환 결과에 일정한 Vector를 더한 것을 Affine Transformation(아핀 변환)이라고 한다.

$$
f(x)=xW+b
$$

- `xW`: Linear Transformation
- `b`: Bias
- `xW + b`: Affine Transformation

<br>

> ## **6-1) 계산 예제**

입력:

$$
x=[3,2]
$$

Weight:

$$
W=
\begin{bmatrix}
2&0\\
0&3
\end{bmatrix}
$$

Bias:

$$
b=[1,-2]
$$

먼저 행렬곱의 출력은

$$
xW=[6,6]
$$

이다.

Bias를 더하면

$$
xW+b
=
[6,6]+[1,-2]
$$

$$
=[7,4]
$$

이다.

<br>

> ## **6-2) Python 예제**

[ Python : code ] "Weight와 Bias를 이용한 Affine Transformation"

```python
import numpy as np

x = np.array([3, 2])

W = np.array([
    [2, 0],
    [0, 3]
])

b = np.array([1, -2])

linear_output = x @ W # 선형변환
affine_output = x @ W + b # 아핀변환

print("Linear:", linear_output)
print("Affine:", affine_output)
```

[ Result ]

```text
Linear: [6 6]
Affine: [7 4]
```

# **7. 선형 변환과 아핀 변환의 차이**

> ## **7-1) 0 Vector를 넣어보면 가장 쉽게 구분할 수 있다**

> 선형 변환:

$$
T(x)=xW
$$

이면

$$
T(0)=0
$$

이다.

> Affine Transformation:

$$
f(x)=xW+b
$$

이면

$$
f(0)=b
$$

이다.

Bias가 0 Vector가 아니라면

$$
f(0)\neq0
$$

이므로 엄밀한 의미의 Linear Transformation이 아니다.

<br>

> ## **7-2) 비교**

| 구분 | Linear Transformation | Affine Transformation |
| --- | --- | --- |
| 기본식 | `xW` | `xW + b` |
| Weight | 사용 | 사용 |
| Bias | **없음** | **있음** |
| 원점 보존 | Yes | 일반적으로 No |
| `x=0` 출력 | `0` | `b` |
| 신경망 활용 | Bias 없는 Layer | 일반적인 Dense Layer 계산 |

신경망에서 흔히

```text
Linear Layer
```

라고 부르는 구현체도 실제 계산식이

$$
XW+b
$$

라면 수학적으로는 **Affine Transformation**이다.

# **8. Weight의 역할**

Weight는 입력 Feature를 출력으로 어떻게 조합할지를 결정하는 Parameter이다.

한 Output을 계산하는 경우

$$
z=w_1x_1+w_2x_2+\cdots+w_nx_n+b
$$

로 표현할 수 있다.

Vector로는

$$
z=x\cdot w+b
$$

이다.

<br>

> ## **8-1) Weight의 부호**

다른 조건이 동일하다고 가정하면 Weight의 부호는 Linear Score의 변화 방향과 연결된다.

| Weight | 의미 |
| --- | --- |
| `w > 0` | 입력 증가 시 Linear Score 증가 |
| `w < 0` | 입력 증가 시 Linear Score 감소 |
| `w = 0` | 해당 Feature가 Linear Score에 직접 기여하지 않음 |

예를 들어

$$
w=[2,-1]
$$

이면

$$
z=2x_1-x_2
$$

이다.

`x₁`이 1 증가하면 다른 값이 같을 때 Score가 2 증가한다.

반대로 `x₂`가 1 증가하면 Score가 1 감소한다.

<br>

> ## **8-2) Weight 크기만으로 Feature Importance를 판단하면 안 된다**

예를 들어

```text
Ground Reaction Force
→ 1800 N

Joint Angle
→ 35 deg
```

처럼 Feature Scale이 크게 다르면 학습된 Weight 크기를 직접 비교하는 것이 적절하지 않을 수 있다.

따라서 Weight를 해석할 때는 다음도 함께 고려해야 한다.

```text
Feature Scale

Standardization 여부

Feature 간 상관관계

Model 구조

Activation Function

Regularization
```

# **9. Bias의 역할**

Bias는 가중합에 더해지는 Parameter이다.

$$
z=xW+b
$$

Bias는 Input 값 자체와 곱해지지 않는다.

<br>

> ## **9-1) 출력의 기준점을 이동시킨다**

입력과 Weight가 동일하고 Bias만 변경한다고 하자.

가중합:

$$
x\cdot w=14
$$

이라면 다음과 같다.

| Bias | 최종 Score |
| ---: | ---: |
| `0` | 14 |
| `1` | 15 |
| `-2` | 12 |
| `5` | 19 |

Bias가 3 증가하면 모든 Sample의 같은 Output에 3이 추가된다.

<br>

> ## **9-2) 입력이 0이어도 Output을 만들 수 있다**

입력이

$$
x=[0,0]
$$

이라면

$$
xW=0
$$

이다.

하지만 Bias가 존재하면

$$
z=0+b=b
$$

이다.

따라서 Bias를 통해 모델은 반드시 원점을 지나야 하는 제한에서 벗어날 수 있다.

<br><br>

# **10. Weight와 Bias 비교**

| 구분 | Weight | Bias |
| --- | --- | --- |
| Symbol | `W`, `w` | `b` |
| 적용 방식 | Input과 곱함 | Weighted Sum에 더함 |
| 주요 역할 | Feature 조합 방향 결정 | 출력 기준 이동 |
| Input 의존성 | 있음 | 직접적으로 없음 |
| 학습 대상 | Yes | Yes |
| 여러 Output | Matrix | Vector |

Weight와 Bias를 함께 조정함으로써 모델은 입력과 출력의 관계를 학습한다.

# **12. 여러 Output을 계산하면 Weight는 Matrix가 된다**


지금까지는 가중치와 편향을 직접 설정했지만,

실제 딥러닝 모델은 일반적으로 모덿이 학습 데이터를 이용하여 파라미터를 조정한다.

```text
학습과정은 다음과 같이 진행한다.

1. 모델의 가중치와 편향을 초기화한다.   
→ 모델의 가중치와 편향을 초기화 한다라는 말의 의미는 이후 곱하고 더하는 연산이 가능하도록 숫자로 만들어준다라는 뜻

2. 입력 데이터와 파라미터를 이용하여 예측값을 계산한다.

3. 예측값과 실제 정답을 비교하여 손실(Loss)을 계산한다.

4. 손실을 줄이는 방향으로 가중치와 편향을 조정한다.

5. 이 과정을 반복하면서 모델의 예측을 개선한다.
```

입력 Feature가 4개이고 Output이 3개라면 각 Output마다 Feature 4개에 대한 Weight가 필요하다.

따라서

$$
W\in\mathbb{R}^{4\times3}
$$

가 된다.

Bias는 Output마다 하나씩 필요하므로

$$
b\in\mathbb{R}^{3}
$$

이다.

<br>

> ## **12-1) Parameter 개수**

Weight 수:

$$
4\times3=12
$$

Bias 수:

$$
3
$$

전체 Parameter:

$$
12+3=15
$$

일반적으로 Fully Connected Layer의 Parameter 수는 다음과 같다.

$$
\text{Parameters}
=
n_{\text{inputs}}\times n_{\text{neurons}}
+
n_{\text{neurons}}
$$

즉

$$
=
(n_{\text{inputs}}+1)n_{\text{neurons}}
$$

이다.

# **13. 신경망의 Neuron(뉴런)**

**Neuron(뉴런)**

-  여러 Input(입력값)을 받아 가중합을 계산하고, 활성화 함수를 적용해 하나의 Output(출력값)을 만드는 인공신경망의 기본 계산 단위

- 은닉틍의 뉴런 하나는 앞 층의 입력을 받아 다음 계산을 수행한다.


<img src="https://vos.line-scdn.net/landpress-content-v2_954/1655699066955.png?updatedAt=1655699068000" width="500"  height="300">


기본 계산은 두 단계이다.

```text
1. Affine Transformation

z = x · w + b

        ↓

2. Activation Function

a = f(z)
```

즉

$$
a=f(x\cdot w+b)
$$

이다.

<br>

> ## **13-1) 단일 Neuron 예제**

입력:

$$
x=[3,2]
$$

Weight:

$$
w=[2,-1]
$$

Bias:

$$
b=3
$$

그러면

$$
z
=
3(2)+2(-1)+3
$$

$$
=
6-2+3
=
7
$$

이다.

Activation Function이 ReLU이면

$$
a=\operatorname{ReLU}(7)=7
$$

이다.

# **14. Activation Function(활성화 함수)이란 무엇인가**

**Activation Function**은 Affine Transformation으로 계산된 값을 다시 변환하는 함수이다.

> 활성화 함수를 사용하는 이유:
- 신경망에 비선형성을 추가하여 복잡한 데이터 패턴을 학습할 수 있도록 하기 위해서이다.

        - 예를 들어 High-Intensity Rally 횟수가 증가할수록 경기력 점수가 증가한다고 가정해보면

        - 실제로는 일정 수준 이상에서 피로가 누적되어 경기력 향상 효과가 감소하거나 오히려 경기력이 떨어질 수도 있다.

        - 이런 관계는 단순한 직선 하나로 표현하기 어렵다.

        - 활성화 함수를 사용하는 다층 신경망은 이런 비선형적인 관계를 학습할 수 있다.

$$

| --- | --- | --- |

| Sigmoid | 값을 0~1 범위로 변환 | Binary Classification Output |
| Tanh | 값을 -1~1 범위로 변환 | 일부 RNN 등 |
| Softmax | 여러 Score를 확률 분포로 변환 | Multiclass Output |

이 강의에서는 가장 직관적인 ReLU를 중심으로 이해한다.

# **15. ReLU(Rectified Linear Unit)**

ReLU는 다음과 같이 정의한다.

$$
\operatorname{ReLU}(z)
=
\max(0,z)
$$

즉,

$$
\operatorname{ReLU}(z)
=
\begin{cases}
z & z>0\\
0 & z\le0
\end{cases}
$$

이다.

<br>

> ## **15-1) 입력에 따른 결과**

| `z` | `ReLU(z)` |
| ---: | ---: |
| -4 | 0 |
| -1 | 0 |
| 0 | 0 |
| 2 | 2 |
| 7 | 7 |

앞에서 계산한 Neuron의

$$
z=7
$$

에 ReLU를 적용하면

$$
a=7
$$

이다.

반대로

$$
z=-3
$$

이라면

$$
a=0
$$

이다.

<br>

> ## **15-2) Python 구현**

[ Python : code ] "NumPy를 이용한 ReLU 구현"

```python
import numpy as np

def relu(z):
    return np.maximum(0, z)

z = np.array([-4, -1, 0, 2, 7])

print(relu(z))
```

[ Result ]

```text
[0 0 0 2 7]
```

# **16. 왜 비선형 Activation Function이 필요한가**

Activation Function이 없는 Layer를 여러 개 연결한다고 하자.

첫 번째 Layer:

$$
H=XW_1+b_1
$$

두 번째 Layer:

$$
Y=HW_2+b_2
$$

첫 번째 식을 두 번째 식에 대입하면

$$
Y=(XW_1+b_1)W_2+b_2
$$

이다.

전개하면

$$
Y=XW_1W_2+b_1W_2+b_2
$$

이다.

새로운 Weight를

$$
W'=W_1W_2
$$

라고 하고 새로운 Bias를

$$
b'=b_1W_2+b_2
$$

라고 하면

$$
Y=XW'+b'
$$

가 된다.

즉 여러 개의 Affine Transformation을 연결해도 결과적으로 **하나의 Affine Transformation과 동일한 형태**가 된다.

<br>

> ## **16-1) 비선형 함수가 들어가면 달라진다**

다음 구조를 생각하자.

$$
H=\operatorname{ReLU}(XW_1+b_1)
$$

$$
Y=HW_2+b_2
$$

ReLU는 비선형 함수이므로 일반적으로 전체 연산을 하나의

$$
XW+b
$$

형태로 합칠 수 없다.

따라서 Neural Network는 Layer 사이에 비선형 Activation Function을 넣어 **복잡한 비선형 관계를 표현할 수 있는 능력**을 얻는다.

<br>

> **딥러닝에서 활성화 함수 구성 방법**

은닉층(Hidden Layer) 에서는 `ReLU`를 사용하고, 

출력층(Output Layer) 에서는 `Linear`를 사용할 수 있다.

$$
h=\operatorname{ReLU}(XW_1+b_1)
$$

$$
\hat y=hW_2+b_2
$$

여기서 첫 번째 층의 ReLU가 음수를 0으로 만들더라도, 두 번째 층의 Weight와 Bias에 의해 최종 출력은 음수가 될 수 있다.

예를 들어,
$$
h=[2,3],\quad W_2=[-2,1],\quad b_2=-1
$$

이면,
$$
\hat y=(2\times-2)+(3\times1)-1=-2
$$

이렇게 최종 출력값을 음수로 만들 수 있다.

# **18. 여러 Neuron을 묶으면 Layer가 된다**

입력 Feature가 3개이고 Hidden Layer의 Neuron이 4개라면 Weight Matrix는

$$
W\in\mathbb{R}^{3\times4}
$$

가 된다.

Bias는

$$
b\in\mathbb{R}^{4}
$$

이다.

Sample이 100개라면

```text
X.shape
→ (100, 3)

W.shape
→ (3, 4)

b.shape
→ (4,)
```

이다.

Affine Transformation:

```text
X @ W

(100, 3) @ (3, 4)

→ (100, 4)
```

Bias를 Broadcasting으로 더해도

```text
Z.shape
→ (100, 4)
```

이다.

Activation Function을 적용해도 Shape는 그대로 유지된다.

```text
A.shape
→ (100, 4)
```

즉 Layer의 Neuron 수가 **출력 Feature 수**를 결정한다.

# **19. Layer의 Shape를 일반식으로 이해하기**

신경망 Layer에서 가장 중요한 Shape 관계는 다음과 같다.

```text
X
(n_samples, n_inputs)

        @

W
(n_inputs, n_neurons)

        ↓

Z
(n_samples, n_neurons)

        +

b
(n_neurons,)

        ↓

A
(n_samples, n_neurons)
```

수식으로는

$$
X\in\mathbb{R}^{N\times D}
$$

$$
W\in\mathbb{R}^{D\times H}
$$

$$
b\in\mathbb{R}^{H}
$$

이면

$$
A\in\mathbb{R}^{N\times H}
$$

가 된다.

여기서

- `N`: Sample 수
- `D`: Input Feature 수
- `H`: Neuron 수

이다.

| 선수 | Peak Force | Impulse | Jump Height |
| --- | ---: | ---: | ---: |
| A | 1800 | 220 | 42 |
| B | 1650 | 205 | 38 |
| C | 1950 | 240 | 45 |

입력 Matrix:

$$
X\in\mathbb{R}^{3\times3}
$$

이다.

3개의 Feature를 4개의 Hidden Neuron으로 변환하면

```text
W.shape
→ (3, 4)

b.shape
→ (4,)
```


이다.

이는 신경망이 단순히 원본 Feature를 전달하는 것이 아니라 여러 Feature를 Weight를 통해 조합하여 새로운 표현을 만든다는 의미이다.

# **21. 하나의 Layer를 Python으로 구현하기**

[ Python : code ] "운동역학 데이터를 Hidden Layer로 변환하고 ReLU 적용"

```python
import numpy as np

def relu(z):
    return np.maximum(0, z)

X = np.array([
    [1.80, 2.20, 4.20],
    [1.65, 2.05, 3.80],
    [1.95, 2.40, 4.50]
])

W = np.array([
    [ 0.5, -0.2,  0.3,  0.1],
    [ 0.4,  0.6, -0.1,  0.2],
    [-0.3,  0.5,  0.4, -0.2]
])

b = np.array([0.2, -0.5, 0.1, 0.3])

Z = X @ W + b # 아핀 변환
A = relu(Z) # 아핀 변환 후 활성화 함수 적용(비선형성 구현)

print("Z Shape:", Z.shape)
print("A Shape:", A.shape)

print(A)
```

[ Result ]

```text
Z Shape: (3, 4)
A Shape: (3, 4)

[[0.72 2.56 2.10 0.08]
 [0.69 2.30 1.91 0.09]
 [0.80 2.78 2.12 0.08]]
```

각 Row는 선수 한 명을 의미하고 각 Column은 Hidden Neuron의 Output을 의미한다.

원래 Feature가

```text
Peak Force
Impulse
Jump Height
```

였다면 Hidden Layer 이후에는 원래 변수 이름으로 직접 해석하기 어려운 **학습된 표현(Latent Representation)** 으로 변환된다.

# **22. Forward Propagation(순전파)의 의미**

Forward Propagation은 입력 데이터가 Network를 앞 방향으로 통과하며 최종 Output을 계산하는 과정이다.

예를 들어

```text
Input Layer
2 Features

        ↓

Hidden Layer
3 Neurons + ReLU

        ↓

Output Layer
1 Neuron

        ↓

Prediction Score
```

구조라면 다음 순서로 계산한다.

```text
X -> 입력값

        ↓

Z1 = X @ W1 + b1  -> 아핀변환

        ↓

H = ReLU(Z1) -> 활성화 함수

        ↓

Z2 = H @ W2 + b2 -> 두번째 아핀변환

        ↓

Y -> 예측값 산출
```

- 순전파는 파라미터를 수정하지 않고, 예측값만 계산한다.

# **26. Neural Network Layer의 Parameter 수 계산**

> ## **26-1) 기본 공식**

Input Feature가 $D$개이고 Neuron이 $H$개라면 Weight는

$$
D\times H
$$

개이다.

Bias는 Neuron마다 하나씩 필요하므로

$$
H
$$

개이다.

따라서 전체 Parameter는

$$
DH+H
$$

이다.

Factorization하면

$$
H(D+1)
$$

이다.

<br>

> ## **26-2) 예제**

Input Feature:

```text
20
```

Hidden Neuron:

```text
64
```

이면 Weight 수는

$$
20\times64=1280
$$

이다.

Bias 수는

$$
64
$$

이다.

전체 Parameter는

$$
1280+64=1344
$$

이다.

<br>

> ## **26-3) 여러 Layer 전체 Parameter**

Network가 다음과 같다고 하자.

```text
Input
10

↓

Hidden 1
32

↓

Hidden 2
16

↓

Output
3
```

$$
10(32)+32=352

$$
32(16)+16=528
$$

출력 Layer:

$$
16(3)+3=51
$$

$$
352+528+51=931

# **27. Broadcasting을 이용한 Bias 추가**

Batch Data에 Bias를 더할 때 Bias를 Sample마다 직접 복사할 필요는 없다.

예를 들어

```text

→ (100, 32)
```

이고

```text

→ (32,)
```

개념적으로는

```text
[Sample 1 Output] + b
[Sample 2 Output] + b
[Sample 3 Output] + b
...
[Sample 100 Output] + b
```

가 수행된다.

라고 이해하면 안 된다.

# **29. Forward Propagation과 학습은 다르다**

Forward Propagation은 **현재 Parameter로 Prediction을 계산하는 과정**이다.

Forward Propagation만 수행해서는 Weight가 학습되지 않는다.

학습 과정은 다음과 같이 진행된다.

```text
1. Forward Propagation

        ↓

Prediction 계산

        ↓

2. Loss Function

        ↓

실제값과 Prediction 차이 계산

        ↓

3. Backpropagation

        ↓

각 Parameter의 Gradient 계산

        ↓

4. Optimizer

        ↓

Weight와 Bias Update

        ↓

5. 반복
```

즉

```text
Forward Propagation
→ 예측 계산

Backpropagation
→ Parameter 변화 방향 계산

Optimizer
→ 실제 Parameter Update
```

로 구분할 수 있다.

| 요소 | 학습 과정에서 역할 |
| --- | --- |
| Input Data `X` | 일반적으로 주어진 관측 데이터 |
| Target `y` | 정답 데이터 |
| Weight `W` | 학습을 통해 조정 |
| Bias `b` | 학습을 통해 조정 |
| Prediction | Parameter에 따라 변화 |
| Loss | Prediction과 Target 차이에 따라 변화 |
| Gradient | Parameter Update 방향 결정 |

즉 모델 학습의 핵심은 **주어진 데이터에 맞게 Weight와 Bias를 조정하는 과정**이다.

# **31. 자주 발생하는 개념 혼동**

> ## **31-1) `XW + b`는 Linear Transformation인가?**

엄밀히 말하면 Bias가 0이 아니면 Affine Transformation이다.

```text
XW
→ Linear

XW + b
→ Affine
```

<br>

> ## **31-2) Weight가 크면 중요한 Feature인가?**

항상 그렇지 않다.

Feature Scale, Standardization, 상관관계, Model 구조 등을 함께 고려해야 한다.

<br>

> ## **31-3) Bias는 Weight와 같은 역할인가?**

아니다.

```text
Weight
→ Input과 곱함

Bias
→ Output에 더함
```

역할이 다르다.

<br>

> ## **31-4) Activation Function은 단순히 값을 줄이는 함수인가?**

아니다.

핵심 목적은 Network에 **Non-linearity**를 추가하는 것이다.

<br>

> ## **31-5) ReLU를 사용하면 모든 음수 정보를 영원히 잃는가?**

해당 Neuron의 해당 Forward Pass에서는 음수 입력이 0이 된다.

그러나 Network 전체에서는 여러 Neuron과 다른 Weight가 존재하므로 다른 Neuron에서 관련 정보가 다르게 표현될 수 있다.

<br>

> ## **31-6) Layer 수를 늘리기만 하면 항상 좋은가?**

아니다.

Layer와 Parameter가 증가하면 모델 표현력은 증가할 수 있지만

```text
Overfitting
Training Difficulty
Memory Usage
Computation Cost
```

도 증가할 수 있다.

# **34. Forward Propagation 전체 코드**

[ Python : code ] "두 Hidden Layer를 가진 신경망의 Forward Propagation"

```python
import numpy as np

def relu(z):
    return np.maximum(0, z)

X = np.array([
    [0.8, 1.2, 0.5],
    [1.1, 0.7, 1.3]
])

W1 = np.array([
    [ 0.5, -0.3,  0.2,  0.1],
    [ 0.4,  0.6, -0.2,  0.3],
    [-0.1,  0.2,  0.5, -0.4]
])
b1 = np.array([0.1, -0.2, 0.0, 0.3])

W2 = np.array([
    [ 0.5, -0.2],
    [ 0.3,  0.4],
    [-0.1,  0.6],
    [ 0.2,  0.1]
])
b2 = np.array([0.2, -0.1])

W3 = np.array([
    [0.7],
    [-0.5]
])
b3 = np.array([0.1])

Z1 = X @ W1 + b1 # 첫 번째 은닉층의 아핀변환 (뉴런 3개 계산)
H1 = relu(Z1) # 첫 번쨰 층의 활성화함수 (ReLU)

Z2 = H1 @ W2 + b2 # 두번째 은닉층의 아핀변환 (은닉층 1의 출력으로 가중합 계산 - 뉴런 2개 계산)
H2 = relu(Z2) # 두 번째 층의 활성화 함수 (ReLU)

Y = H2 @ W3 + b3 # 출력층

print("X :", X.shape)
print("H1:", H1.shape)
print("H2:", H2.shape)
print("Y :", Y.shape)

print(Y)
```

```text
H1: (2, 4)
H2: (2, 2)

[[0.3642]
 [0.3789]]
```

```python
import numpy as np

def dense_relu(X, W, b):
```

# **36. 실무적으로 Feature Scaling이 중요한 이유**

신경망의 Weight는 Input 값과 곱해진다.

따라서 Feature Scale이 극단적으로 다르면 학습 과정에 영향을 줄 수 있다.

| Feature | 일반적인 크기 |
| --- | ---: |
| Total Distance | 10000 |
| Sprint Count | 30 |
| Max Speed | 9 |

Scaling 없이 그대로 입력하면 Feature마다 수치 규모가 크게 다르다.

따라서 실제 모델에서는

```text
Standardization

Min-Max Scaling

Domain-based Normalization
```

등을 고려할 수 있다.

다만 어떤 Scaling이 적합한지는 Model과 Data 특성에 따라 결정해야 한다.

핵심은 **Weight의 의미는 Input Scale과 분리해서 생각할 수 없다는 것**이다.

# **38. Advanced 추가 학습**

> ## **38-1) Universal Approximation**

충분한 Neuron과 적절한 비선형 Activation Function을 사용하는 Neural Network는 매우 다양한 함수 관계를 근사할 수 있다.

즉 비선형 Activation이 Network의 표현력을 크게 확장한다.

<br>

> ## **38-2) Xavier / He Initialization**

실제 Neural Network에서는 Weight를 아무 값으로 초기화하지 않는다.

Layer의 크기와 Activation Function에 따라 Xavier Initialization이나 He Initialization 같은 방법을 사용할 수 있다.

이는 Signal과 Gradient가 Layer를 지나면서 지나치게 작아지거나 커지는 문제를 완화하는 데 도움을 준다.

<br>

> ## **38-3) Dead ReLU**

ReLU Neuron이 계속 음수 영역에 머무르면 출력이 계속 0이 될 수 있다.

이러한 현상을 Dead ReLU라고 한다.

이를 완화하기 위해 Leaky ReLU 등의 변형을 사용할 수도 있다.

<br>

> ## **38-4) Representation Learning**

Hidden Layer에서 생성되는 값은 사람이 직접 정의한 Feature가 아니라 학습 과정에서 만들어지는 내부 표현이다.

Deep Learning의 중요한 특징 중 하나는 이러한 표현 자체도 데이터로부터 학습한다는 것이다.

# **39. 핵심정리**

1. Linear Transformation은 Vector의 덧셈과 Scalar Multiplication을 보존하는 변환이다.

2. 행 벡터 표기를 사용하면 Linear Transformation을 다음과 같이 표현할 수 있다.

$$
T(x)=xW
$$

3. 열 벡터 표기에서는 일반적으로 다음과 같이 표현한다.

$$
T(x)=Wx
$$

4. 중요한 것은 표기 방향보다 Vector와 Matrix의 Shape를 일관되게 구성하는 것이다.

5. Linear Transformation은 다음 두 조건을 만족한다.

$$
T(a+b)=T(a)+T(b)
$$

$$
T(ca)=cT(a)
$$

6. Linear Transformation은 반드시 원점을 보존한다.

$$
T(0)=0
$$

7. Matrix Multiplication은 입력 Vector의 크기와 방향을 변경하거나 Dimension 자체를 변경할 수 있다.

8. Affine Transformation은 Linear Transformation 결과에 Bias를 추가한 것이다.

$$
f(x)=xW+b
$$

9. Bias가 0이 아니라면 Affine Transformation은 일반적으로 Linear Transformation이 아니다.

10. 그 이유는

$$
f(0)=b
$$

이므로 원점을 원점으로 보내지 않기 때문이다.

11. Weight는 Input Feature를 어떤 방식으로 조합할지 결정하는 Trainable Parameter이다.

12. 한 Output에 대한 기본적인 계산은 다음과 같다.

$$
z=w_1x_1+w_2x_2+\cdots+w_nx_n+b
$$

13. Vector 표현으로는 다음과 같다.

$$
z=x\cdot w+b
$$

14. Weight가 양수이면 다른 조건이 동일할 때 Input 증가가 Linear Score 증가 방향으로 작용한다.

15. Weight가 음수이면 다른 조건이 동일할 때 Input 증가가 Linear Score 감소 방향으로 작용한다.

16. Weight가 0이면 해당 Feature는 현재 Linear Combination에 직접 기여하지 않는다.

17. Weight 절댓값이 크다고 해서 해당 Feature가 항상 더 중요하다고 해석해서는 안 된다.

18. Feature Scale, Correlation, Standardization, Model 구조 등을 함께 고려해야 한다.

19. Bias는 Weighted Sum에 더해지는 Trainable Parameter이다.

20. Bias는 출력 기준점을 이동시키는 역할을 한다.

21. Input이 모두 0이라면 Affine Transformation의 Output은 Bias가 된다.

$$
0W+b=b
$$

22. Input Feature 수가 $D$, Neuron 수가 $H$라면 Weight Matrix의 Shape는 다음과 같다.

$$
(D,H)
$$

23. Bias Vector의 Shape는 다음과 같다.

$$
(H,)
$$

24. Batch Sample 수가 $N$이라면 Input Matrix의 Shape는 다음과 같다.

$$
(N,D)
$$

25. Layer의 Affine Output Shape는 다음과 같다.

$$
(N,D)@(D,H)
\rightarrow
(N,H)
$$

26. Bias를 더하고 Activation Function을 적용해도 일반적으로 Shape는 `(N,H)`로 유지된다.

27. 따라서 Layer의 Neuron 수는 해당 Layer의 Output Feature 수를 결정한다.

28. 하나의 Neuron은 기본적으로 다음 계산을 수행한다.

$$
a=f(x\cdot w+b)
$$

29. 여기서 `f`는 Activation Function이다.

30. ReLU는 다음과 같이 정의한다.

$$
\operatorname{ReLU}(z)=\max(0,z)
$$

31. ReLU는 음수와 0을 0으로 만들고 양수는 그대로 유지한다.

32. Activation Function이 없는 Affine Layer만 여러 개 연결하면 전체 Network는 다시 하나의 Affine Transformation으로 표현할 수 있다.

33. 예를 들어

$$
H=XW_1+b_1
$$

$$
Y=HW_2+b_2
$$

라면

$$
Y=X(W_1W_2)+(b_1W_2+b_2)
$$

로 정리할 수 있다.

34. 따라서 깊은 Network가 복잡한 관계를 표현하려면 Layer 사이의 Non-linear Activation이 매우 중요하다.

35. ReLU는 비선형 함수이므로 여러 Layer를 단순히 하나의 Affine Transformation으로 합칠 수 없도록 한다.

36. 여러 Neuron을 하나로 묶은 구조가 Layer이다.

37. Dense Layer의 전체 Parameter 수는 다음과 같다.

$$
n_{\text{inputs}}\times n_{\text{neurons}}
+
n_{\text{neurons}}
$$

38. 이를 Factorization하면 다음과 같다.

$$
(n_{\text{inputs}}+1)n_{\text{neurons}}
$$

39. Bias는 NumPy 등에서 Broadcasting을 통해 Batch의 모든 Sample에 자동으로 적용될 수 있다.

40. Hidden Layer에서는 ReLU 등의 Non-linear Activation을 자주 사용한다.

41. Output Layer의 Activation Function은 해결하려는 문제에 따라 달라진다.

42. Regression에서는 Output Layer에 Activation을 사용하지 않는 경우가 많다.

43. Binary Classification에서는 Sigmoid를 사용할 수 있다.

44. Multiclass Classification에서는 Softmax를 사용할 수 있다.

45. Forward Propagation은 현재 Weight와 Bias를 사용하여 Input에서 Output까지 값을 계산하는 과정이다.

46. 기본적인 Forward Propagation 구조는 다음과 같다.

```text
X

↓

X @ W1 + b1

↓

Activation

↓

Hidden Representation

↓

Hidden @ W2 + b2

↓

Activation 또는 Output Function

↓

Prediction
```

47. Forward Propagation 자체는 학습을 의미하지 않는다.

48. 실제 Training에서는 Prediction 이후 Loss를 계산한다.

49. Backpropagation을 통해 각 Parameter에 대한 Gradient를 계산한다.

50. Optimizer는 Gradient 정보를 이용하여 Weight와 Bias를 Update한다.

51. 따라서 전체 Training 흐름은 다음과 같다.

```text
Forward Propagation

        ↓

Prediction

        ↓

Loss

        ↓

Backpropagation

        ↓

Gradient

        ↓

Parameter Update

        ↓

반복
```

52. 신경망에서 Input Data는 Layer를 통과하면서 새로운 Representation으로 변환된다.

53. Hidden Layer에서 생성된 Representation은 원래 Feature와 직접 대응하지 않을 수도 있다.

54. 이러한 내부 표현을 학습하는 것을 Representation Learning 관점에서 이해할 수 있다.

55. Neural Network의 Shape를 추적할 때 가장 중요한 규칙은 다음과 같다.

```text
현재 Layer의 Output Dimension
=
다음 Layer의 Input Dimension
```

56. 예를 들어

```text
X
(32, 12)

W1
(12, 64)

H1
(32, 64)

W2
(64, 32)

H2
(32, 32)

W3
(32, 5)

Y
(32, 5)
```

와 같이 연결된다.

57. Batch Size는 일반적인 Dense Layer를 통과하면서 유지되고 Feature Dimension은 Neuron 수에 따라 변경된다.

58. 신경망 구현에서 Shape 오류가 발생하면 먼저 Input Matrix의 Column 수와 Weight Matrix의 Row 수를 확인해야 한다.

59. Shape가 맞더라도 Feature 순서와 의미가 맞는지 함께 검증해야 한다.

60. 이 강의에서 가장 중요한 전체 연결 구조는 다음과 같다.

```text
Vector / Matrix

        ↓

Matrix Multiplication

        ↓

Linear Transformation

        ↓

+ Bias

        ↓

Affine Transformation

        ↓

Activation Function

        ↓

Neuron Output

        ↓

여러 Neuron

        ↓

Layer

        ↓

여러 Layer

        ↓

Forward Propagation

        ↓

Prediction

        ↓

Loss / Backpropagation / Optimization
```

61. 결국 신경망의 복잡한 구조도 기본적으로는 **행렬곱, Bias Addition, Activation Function의 반복**으로 이해할 수 있다.
