# **1. 회귀와 분류 모델의 전체 예측 흐름**

같은 입력(학습) 데이터라도 **무엇을 예측하려는가**에 따라 최종 출력의 의미가 달라진다.

예를 들어, 선수의 GPS·웨어러블 데이터를 입력으로 사용한다고 하자.

```text
입력 데이터

Total Distance
High-Speed Running Distance
Sprint Count
Session RPE
Sleep Duration
CMJ Asymmetry
...

```

이 데이터로 다음과 같이 서로 다른 문제를 만들 수 있다.

| 문제 | 예측 대상 | 문제 유형 |
| --- | --- | --- |
| 회복에 필요한 시간 예측 | `32.5시간` | Regression |
| 추가 모니터링 필요 여부 | `0 / 1` | Binary Classification |
| 배드민턴 스트로크 종류 | Smash / Drop / Clear | Multiclass Classification |

세 문제 모두 신경망 내부에서는 행렬곱과 Bias를 통해 Score를 계산할 수 있지만, **마지막 출력 Layer의 해석 방법이 다르다.**

```text
Input X

        ↓

Neural Network

        ↓

Output Score Z

        ↓

문제 유형에 따라 분기

Regression
→ 연속적인 수치

Binary Classification
→ Sigmoid
→ Probability
→ Threshold
→ Class 0 / 1

Multiclass Classification
→ Softmax
→ Class Probabilities
→ Argmax
→ 최종 Class
```

즉 이번 강의의 핵심은 단순히 **Sigmoid**와 **Softmax** 공식을 외우는 것이 아니라

```text
Score

→ Probability

→ Decision Rule

→ Final Prediction
```

의 차이를 이해하는 것이다.


```text
이진 분류모델에서 Sigmoid 함수를 사용하여 변환 전에 logit 변환을 진행해야 함.
```

# **2. 회귀(Regression)란 무엇인가**

Regression은 **연속적인 수치 값을 예측하는 문제**이다.

대표적인 예시는 다음과 같다.

| 예측 문제 | Target 예시 |
| --- | --- |
| 경기 후 회복 시간 예측 | 31.5시간 |
| 마라톤 완주 시간 예측 | 194.2분 |
| 투구 속도 예측 | 148.7 km/h |
| 점프 높이 예측 | 42.8 cm |
| 다음 경기 이동거리 예측 | 10.3 km |

회귀에서는 Class를 선택하는 것이 아니라 **실수값 자체가 Prediction**이 된다.

<br>

> ## **2-1) 회귀 모델의 기본 출력**

가장 단순한 Linear Regression 형태는 다음과 같다.

```math
\hat{y}=x\cdot w+b
```

여기서

- $x$ : Input Feature
- $w$ : Weight
- $b$ : Bias
- $\hat{y}$ : Prediction

이다.

앞 강의에서 배운 Affine Transformation이 그대로 Regression Prediction으로 사용될 수 있다.

<br>

> ## **2-2) 실제값과 예측값**

회귀에서는 다음 두 값을 구분한다.

```text
y
→ 실제 Target

ŷ
→ Model Prediction
```

예를 들어

```text
실제 회복 시간
→ 30시간

모델 예측
→ 32시간
```

이라면 오차는

```math
\hat{y}-y
```

이므로

```math
32-30=2
```

시간이다.

이러한 Prediction Error를 이용해 Loss를 정의하게 된다.

```math

1.2x_3

10
```

```text
32.26
→ 32.26%

X

32.26
→ 연속적인 Prediction
O
```

회귀 Output은 Target이 무엇인지에 따라 단위와 의미가 결정된다.

# **4. 회귀 출력은 항상 범위가 제한되는 것은 아니다**

일반적인 Linear Output은

```math
-\infty<\hat{y}<\infty
```

범위의 값을 가질 수 있다.

즉 모델은 상황에 따라 음수나 매우 큰 값을 출력할 수도 있다.

예를 들어 Target이

```text
Jump Height
Recovery Time
Running Speed
```

처럼 실제로 음수가 될 수 없는 변수라 하더라도 단순 Linear Output은 음수를 예측할 수 있다.

따라서 실제 Modeling에서는 Target의 특성에 따라

```text
Target Transformation
Output Activation
Loss Function
Model Family
```

등을 함께 고려한다.

핵심은

> 회귀라고 해서 모든 문제의 Output Layer가 반드시 동일해야 하는 것은 아니다.

라는 점이다.

# **5. 분류(Classification)란 무엇인가**

Classification은 Input을 미리 정의된 **Class 또는 Category**에 배정하는 문제이다.

예를 들어 스포츠 데이터에서는 다음과 같이 구성할 수 있다.

| 문제 | Class |
| --- | --- |
| 추가 모니터링 여부 | 정상 / 확인 필요 |
| 경기 승패 | 승 / 패 |
| 동작 분류 | 정상 / 오류 |
| 테니스 샷 분류 | Forehand / Backhand / Serve |
| 수영 영법 분류 | Freestyle / Backstroke / Breaststroke / Butterfly |

분류 Model도 내부적으로는 숫자를 계산한다.

하지만 이 숫자를 바로 Class 이름으로 출력하는 것이 아니라 일반적으로

```text
Input

↓

Score

↓

Probability

↓

Decision Rule

↓

Class
```

순서로 해석한다.

# **6. Logit 또는 Score의 의미**

분류 Model의 Output Layer에서 계산한 값은 흔히 **Logit**이라고 부른다.

이진 분류의 단일 Output을 생각하면

```math
z=x\cdot w+b
```

와 같이 계산할 수 있다.

이 $z$는 Probability가 아니다.

예를 들어

```text
z = 3.2
```

라고 해서

```text
Probability = 320%
```

라는 의미는 아니다.

Logit은

```text
음수 가능
0 가능
1보다 큰 값 가능
```

한 제한되지 않은 Score이다.

따라서 Classification에서는 이를 Probability 형태로 변환하는 과정이 필요하다.

# **7. 이진 분류(Binary Classification)**

Binary Classification은 두 개의 Class 중 하나를 구분하는 문제이다.

예를 들어 웨어러블 데이터를 기반으로 다음 Class를 정의한다고 하자.

```text
Class 0
→ 일반 모니터링

Class 1
→ 추가 모니터링 필요
```

Model은 먼저

```math
z=x\cdot w+b
```

를 계산한다.

그다음 Sigmoid를 이용하여 Class 1에 대한 Probability를 계산할 수 있다.

```text
Input

↓

Logit z

↓

Sigmoid

↓

P(y=1 | x)

↓

Threshold

↓

0 or 1
```

<br><br>

# **8. Sigmoid 함수**

**Sigmoid**는 **실수 전체를 0과 1 사이**로 압축한다.

시그모이드 함수는 이진분류 모델에서 아핀 변환 후 진행한다. 

```text
1. 아핀 변환 후 입력값을 변환 (아핀변환 과정에서는 아직 비선형성 관계)

2. 시그모이드 함수로 선형성 부여 

입력    ->  아핀 변환   -> 시그모이드
(x)         (Wx+b)       (sigma(z))


아핀 변환은
f(x)=Wx+b

이고 시그모이드와 합성한 함수는

g(x)=σ(Wx+b)


입력을 선형적으로 변환하고 이동시킨 뒤 비선형 함수 적용
```



공식은 다음과 같다.


```math
\sigma(z)
=
\frac{1}
{1+e^{-z}}
```

출력 범위는

```math
0<\sigma(z)<1
```

이다.

<br>

> ## **8-1) 대표적인 값**

| Logit \(z\) | Sigmoid |
| ---: | ---: |
| -4 | 0.018 |
| -2 | 0.119 |
| -1 | 0.269 |
| 0 | 0.500 |
| 1 | 0.731 |
| 2 | 0.881 |
| 4 | 0.982 |

따라서

```text
z → 큰 음수
→ Probability가 0에 가까움

z = 0
→ Probability = 0.5

z → 큰 양수
→ Probability가 1에 가까움
```

으로 이해할 수 있다.

<br><br>

---

# **9. Sigmoid 직접 계산하기**

Logit이

```math
z=2
```

라고 하자.

Sigmoid는

```math
\sigma(2)
=
\frac{1}
{1+e^{-2}}
```

이다.

```math
e^{-2}\approx0.1353
```

이므로

```math
\sigma(2)
\approx
\frac{1}{1.1353}
```

```math
\approx0.8808
```

이다.

즉 Model은 Class 1에 약 `0.881`의 Probability를 부여한다.

반대로

```math
z=-2
```

이면

```math
\sigma(-2)\approx0.1192
```

이다.

<br><br>

---

# **10. Sigmoid의 중요한 대칭 관계**

Sigmoid는 다음 관계를 만족한다.

```math
\sigma(-z)=1-\sigma(z)
```

예를 들어

```math
\sigma(2)\approx0.881
```

이면

```math
\sigma(-2)
=
1-0.881
```

```math
\approx0.119
```

이다.

따라서 단일 Logit 기반 Binary Classification에서는

```math
P(y=0\mid x)
=
1-P(y=1\mid x)
```

로 계산할 수 있다.

<br><br>

# **11. Logit과 Odds의 관계**

Sigmoid를 더 깊게 이해하려면 Logit이 Probability와 어떻게 연결되는지 알면 좋다.

Probability를 \(p\)라고 하면 Odds는 다음과 같다.

```math
\text{Odds}
=
\frac{p}
{1-p}
```

Log Odds는

```math
\log
\left(
\frac{p}
{1-p}
\right)
```

이다.

Logistic Regression에서는

```math
z
=
\log
\left(
\frac{p}
{1-p}
\right)
```

로 해석할 수 있다.

이를 \(p\)에 대해 정리하면

```math
p
=
\frac{1}
{1+e^{-z}}
```

가 되어 Sigmoid 식이 나온다.

즉 Sigmoid는 Logit을 Probability로 연결하는 함수이다.

> ## **12-1) Python 예제**

[ Python : code ] "웨어러블 Feature로 Binary Logit과 Sigmoid Probability 계산"

```python
import numpy as np

X = np.array([
    [4.2, 7.5, 1.35],
    [2.1, 4.0, 0.95],
    [5.5, 8.0, 1.50]
])

```

```text
선수 B
z = -1.325
→ p ≈ 0.210

선수 C
z = 2.325
→ p ≈ 0.911
```

이다.

이 값은 Model이 Class 1에 부여한 확률형 출력이다.

실제 Class를 결정하려면 이후 Threshold가 필요하다.

# **13. Threshold란 무엇인가**

**Threshold**는 Binary Classification(이진 분류)에서 Probability를 Class로 변환하는 기준이다.

일반적으로 다음과 같이 표현한다.

$$
\hat{y} =
\begin{cases}
1 & \text{if } p \geq t \\
0 & \text{if } p < t
\end{cases}
$$


여기서

- $p$: Predicted Probability
- $t$: Threshold
- $hat{y}$: Predicted Class

이다.

<br>

> ## **13-1) Threshold 0.5 예제**

Probability가

```text
[0.812, 0.210, 0.911]
```

이라면 Threshold `0.5`에서

```text
0.812 ≥ 0.5
→ 1

0.210 < 0.5
→ 0

0.911 ≥ 0.5
→ 1
```

따라서 Prediction은

```text
[1, 0, 1]
```

이다.

<br><br>

---

# **14. Threshold는 반드시 0.5여야 하는가**

아니다.

`0.5`는 기본적으로 이해하기 쉬운 기준이지만 문제의 목적에 따라 변경할 수 있다.

예를 들어 Probability가

```text
[0.85, 0.65, 0.45, 0.20]
```

라고 하자.

| Probability | `t=0.5` | `t=0.7` |
| ---: | ---: | ---: |
| 0.85 | 1 | 1 |
| 0.65 | 1 | 0 |
| 0.45 | 0 | 0 |
| 0.20 | 0 | 0 |

Threshold를 높이면 Class 1로 예측하는 Sample 수가 줄어든다.

반대로 Threshold를 낮추면 Class 1로 분류하는 범위가 넓어진다.

<br><br>

# **15. Threshold와 TP·FP·TN·FN**

Binary Classification에서는 실제값과 Prediction을 비교하여 네 경우로 나눌 수 있다.

| Actual | Prediction | 결과 |
| --- | --- | --- |
| 1 | 1 | TP |
| 0 | 1 | FP |
| 0 | 0 | TN |
| 1 | 0 | FN |

Threshold가 증가하면 동일한 Probability Output을 기준으로

```text
Positive Prediction
→ 감소하거나 유지

FP
→ 감소하거나 유지

TP
→ 감소하거나 유지

FN
→ 증가하거나 유지

TN
→ 증가하거나 유지
```

하는 방향으로 변화한다.

반대로 Threshold를 낮추면 Positive Prediction이 증가한다.

따라서 Threshold는 단순히 Class를 자르는 값이 아니라 **어떤 오류를 더 허용할 것인지 결정하는 요소**이기도 하다.

<br><br>

# **16. 스포츠 분석에서 Threshold가 중요한 이유**

예를 들어 경기 전 선수 데이터를 이용해

```text
Class 1
→ 추가 평가 권고

Class 0
→ 일반 모니터링
```

을 구분한다고 하자.

이 경우 Threshold를 너무 높게 설정하면 일부 확인 대상 선수를 놓칠 수 있다.

반대로 너무 낮게 설정하면 많은 선수가 Class 1로 분류되어 추가 평가 자원이 과도하게 사용될 수 있다.

따라서 실무에서는

```text
Accuracy

Precision

Recall

Specificity

F1 Score

ROC Curve

PR Curve

업무 비용
```

등을 함께 고려할 수 있다.

Threshold 선택은 **모델 자체와는 별개의 의사결정 단계**라는 점이 중요하다.

# **17. Threshold 0.5와 Logit 0의 관계**

Sigmoid에는 다음 관계가 있다.

```math
\sigma(0)=0.5
```

또한 Sigmoid는 단조 증가 함수이다.

따라서 Threshold가 0.5라면

```math
p\ge0.5
```

와

```math
z\ge0
```

은 동일한 Class Decision을 만든다.

즉

```text
Logit z < 0
→ Probability < 0.5
→ Class 0

Logit z ≥ 0
→ Probability ≥ 0.5
→ Class 1
```

이다.

<br>

> ## **17-1) Python 예제**

[ Python : code ] "Probability Threshold와 Logit 부호의 결과 비교"

```python
import numpy as np

logits = np.array([-2.0, 0.0, 1.5]) # 선형변환으로 얻은 예측값

probabilities = 1 / (1 + np.exp(-logits)) # 시그모이드 함수(확률로 변환)

pred_prob = (probabilities >= 0.5).astype(int)
pred_logit = (logits >= 0).astype(int)

print(np.round(probabilities, 3))
print(pred_prob)
print(pred_logit)
```

[ Result ]

```text
[0.119 0.500 0.818]

[0 1 1]
[0 1 1]
```

# **18. Probability Threshold를 Logit Threshold로 변환하기**

Threshold가 0.5가 아니라면 Logit 기준도 0이 아니다.

Probability Threshold를 \(t\)라고 하면 이에 대응하는 Logit Threshold는

```math
\log
\left(
\frac{t}
{1-t}
\right)
```

이다.

예를 들어

```math
t=0.7
```

이면

```math
\log
\left(
\frac{0.7}
{0.3}
\right)
```

```math
\approx0.847
```

이다.

따라서

```text
Probability ≥ 0.7
```

과 동일한 Decision은

```text
Logit ≥ 약 0.847
```

이다.

즉 Threshold가 바뀌면 Logit 기준도 함께 바뀐다.

이면

```text
→ 2

→ 0
```

이다.

# **20. Softmax 함수**

Softmax는 여러 Class Logit을 **합이 1인 Probability Distribution**으로 변환한다.

Class $i$의 Probability는

```math
P_i
=
\frac{e^{z_i}}
{\sum_{j=1}^{K}e^{z_j}}
```

이다.

여기서

- $K$: Class 수
- $z_i$: Class $i$의 Logit
- $P_i$: Class $i$의 Probability

이다.

<br>

> ## **20-1) 핵심 성질**

Softmax 결과는 다음 조건을 만족한다.

```math
0<P_i<1
```

그리고

```math
\sum_{i=1}^{K}P_i=1
```

이다.

따라서 여러 Class 중 하나를 선택하는 문제의 확률 분포로 사용할 수 있다.

<br><br>

---

# **21. Softmax 직접 계산하기**

Logit이 다음과 같다고 하자.

```math
z=[2,1,0]
```

각 값에 Exponential을 적용한다.

```math
e^2\approx7.389
```

```math
e^1\approx2.718
```

```math
e^0=1
```

전체 합은

```math
7.389+2.718+1
=
11.107
```

이다.

첫 번째 Class:

```math
P_1
=
\frac{7.389}
{11.107}
\approx0.665
```

두 번째 Class:

```math
P_2
=
\frac{2.718}
{11.107}
\approx0.245
```

세 번째 Class:

```math
P_3
=
\frac{1}
{11.107}
\approx0.090
```

따라서

```text
Softmax([2, 1, 0])

≈ [0.665, 0.245, 0.090]
```

이다.

# **22. Softmax는 상대적인 Logit 차이를 본다**

Softmax에서는 모든 Logit에 같은 값을 더하거나 빼도 결과가 변하지 않는다.

예를 들어

```text
[3, 2, 1]
```

과

```text
[13, 12, 11]
```

은 각각의 차이가 동일하다.

두 번째 Vector는 첫 번째 Vector에 모두 10을 더한 것이다.

Softmax 결과는 동일하다.

이를 수식으로 보면

```math
\frac{e^{z_i+c}}
{\sum_j e^{z_j+c}}
```

에서

```math
e^{z_i+c}
=
e^c e^{z_i}
```

이므로 분자와 분모의 \(e^c\)가 상쇄된다.

따라서 Softmax는 절대적인 Logit 크기보다 **Class 간 상대적 차이**를 중요하게 사용한다.

# **23. Stable Softmax**

Exponential은 입력이 크면 매우 큰 값이 된다.

예를 들어

```math
e^{1000}
```

같은 계산은 Computer에서 Overflow 문제를 일으킬 수 있다.

따라서 실제 구현에서는 가장 큰 Logit을 먼저 뺀다.

```math
z'_i
=
z_i-\max(z)
```

그리고

```math
Softmax(z')
```

를 계산한다.

앞에서 본 것처럼 모든 Logit에서 같은 값을 빼도 Probability는 변하지 않으므로 안전하게 계산할 수 있다.

<br>

> ## **23-1) Python 예제**

[ Python : code ] "수치적으로 안정적인 Softmax 구현"

```python
import numpy as np

def softmax(z):
    shifted = z - np.max(z)
    exp_z = np.exp(shifted)
    return exp_z / np.sum(exp_z)

logits = np.array([1002.0, 1001.0, 1000.0])

probabilities = softmax(logits)

print(np.round(probabilities, 3))
print(np.sum(probabilities))
```

[ Result ]

```text
[0.665 0.245 0.090]
1.0
```

# **24. 여러 Sample에 Softmax 적용하기**

실무에서는 Logit이 Matrix로 나온다.

예를 들어

```text
3 Athletes
×
3 Classes
```

라면

```text

→ (3, 3)
```

이다.

각 Row가 서로 다른 Sample이므로 **각 Row별로 Softmax**를 계산해야 한다.

<br>

> ## **24-1) Python 예제**

[ Python : code ] "Batch 단위 Multiclass Softmax 계산"

```python
import numpy as np

Z = np.array([
    [2.0, 1.0, 0.0],
    [0.0, 2.0, 1.0],
    [1.0, 0.0, 3.0]
])

shifted = Z - np.max(Z, axis=1, keepdims=True)

exp_z = np.exp(shifted)

probabilities = exp_z / np.sum(
    exp_z,
    axis=1,
    keepdims=True
)

print(np.round(probabilities, 3))
print(np.sum(probabilities, axis=1))
```

[ Result ]

```text
[[0.665 0.245 0.090]
 [0.090 0.665 0.245]
 [0.114 0.042 0.844]]

[1. 1. 1.]
```

`axis=1`을 사용한 이유는 각 Sample의 Class Dimension을 따라 Probability를 계산하기 위해서이다.

# **25. Argmax란 무엇인가**

Argmax는 가장 큰 값을 반환하는 것이 아니라 **가장 큰 값이 위치한 Index**를 반환한다.

예를 들어

```text
Probability

[0.20, 0.65, 0.15]
```

이면 가장 큰 값은

```text
0.65
```

이고 위치는

```text
Index 1
```

이다.

따라서

```math
Argmax([0.20,0.65,0.15])=1
```

이다.

Class Mapping이

```text
0 → Smash
1 → Drop
2 → Clear
```

이라면 Prediction은 `Drop`이다.

# **26. Softmax와 Argmax의 관계**

Softmax는 각 Logit의 순서를 바꾸지 않는다.

Exponential 함수가 단조 증가하고 모든 Class가 동일한 분모를 사용하기 때문이다.

따라서

```math
Argmax(z)
=
Argmax(Softmax(z))
```

이다.

예를 들어

```text
Logits

[2, 1, 0]
```

의 Argmax는 `0`이다.

Softmax:

```text
[0.665, 0.245, 0.090]
```

의 Argmax도 `0`이다.

따라서 최종 Class만 필요하다면 Probability를 계산하지 않고 Logit에 바로 Argmax를 사용할 수 있다.

```python
import numpy as np

X = np.array([
```

# **29. Multiclass와 Multilabel은 다르다**

두 개념은 자주 혼동된다.

| 구분 | Multiclass | Multilabel |
| --- | --- | --- |
| 하나의 Sample에 가능한 Class | 하나 | 여러 개 가능 |
| 대표 출력 | Softmax | Class별 Sigmoid |
| Probability 합 | 일반적으로 1 | 반드시 1일 필요 없음 |
| 예시 | Stroke 종류 하나 선택 | 영상에 여러 Event 동시 존재 |

예를 들어 한 Frame을

```text
Serve
Forehand
Backhand
```

중 하나로만 분류한다면 Multiclass이다.

반면 한 장면에

```text
Sprint 발생
Contact 발생
Possession Change 발생
```

가 동시에 존재할 수 있다면 Multilabel 문제가 될 수 있다.

Multilabel에서는 각 Label마다 독립적인 Sigmoid를 적용할 수 있다.

- **Multi-class Classification (다중 클래스 분류)**
    - 하나의 데이터가 여러 클래스 중 정확히 하나에 속하도록 분류함

    - ex)    
    Softmax 활성화 함수 사용하여    
    Smash → 0.7 / Drop → 0.2 / Clear → 0.1    
    => [1, 0, 0]  
    => Smash로 최종 예측
    - "이 영상은 어떤 영상인가?"


- **Multi-label Classification (다중 레이블 분류)**
    -  하나의 데이터가 여러 레이블에 동시에 속하도록 분류함

    - ex)    
    배드민턴 랠리 영상에서 이벤트 탐지 모델의 경우 Sigmoid에서    Long Rally. → 0.9 / Smash → 0.8 / Diving Defence → 0.7.  
    => 최종 예측 [1, 1, 1]
    - "이  영상에 어떤 이벤트들이 포함되어 있는가?"

|구분|	Multi-class|	Multi-label|
|---|---|---|
|정답 개수|	하나|	여러 개 가능|
|클래스 관계|	상호 배타적|	동시 발생 가능|
|대표 활성화 함수|	`Softmax`|	`Sigmoid`|
|출력 예시|	[1,0,0]|	[1,1,0]|
|대표 손실 함수|	Cross-Entropy|	Binary Cross-Entropy|


<br><br>

# **30. Sigmoid와 Softmax 비교**

| 구분 | Sigmoid | Softmax |
| --- | --- | --- |
| 대표 문제 | Binary / Multilabel | Multiclass |
| 입력 | 개별 Logit | 여러 Class Logit |
| 출력 범위 | 0~1 | 0~1 |
| 출력 합 | 제약 없음 | 전체 합 1 |
| Class 간 경쟁 | 없음 | 있음 |
| 최종 결정 | Threshold | Argmax |

특히 Softmax에서는 한 Class의 Probability가 커지면 전체 합이 1이어야 하므로 다른 Class Probability와 경쟁한다.

반면 여러 개의 Sigmoid Output은 각각 독립적으로 높은 값을 가질 수 있다.

[Python Code] "시그모이드와 소프트맥스 코드 구현"

```python
import numpy as np

z = np.array([2.0, 1.0, 0.0])

# Sigmoid
sigmoid = 1 / (1 + np.exp(-z))

# Softmax
exp_z = np.exp(z - np.max(z))
softmax = exp_z / np.sum(exp_z)

print("Sigmoid:", sigmoid.round(3))
print("Softmax:", softmax.round(3))
```

[Result]
```text
Sigmoid: [0.881 0.731 0.500]
Softmax: [0.665 0.245 0.090]
```

# **31. Regression·Binary·Multiclass의 Shape 비교**

Input Matrix를 다음과 같이 정의하자.

```math

```

- `N`: Sample 수
- `D`: Feature 수

문제별 Output 구조는 다음과 같다.

| 문제 | Weight Shape | Logit / Output Shape |

| K-Class Classification | `(D, K)` | `(N, K)` |

NumPy에서 Weight를 1차원 Vector `(D,)`로 사용하면 Regression과 Binary Output이 `(N,)`이 될 수도 있다.

따라서

```text
값의 의미

+

Shape
```

를 함께 이해해야 한다.

# **37. 회귀·이진·다중 클래스 통합 Python 예제**

[ Python : code ] "같은 입력 Matrix에서 Regression, Binary, Multiclass Prediction 비교"

```python
import numpy as np

X = np.array([
    [1.2, 0.8],
    [0.4, 1.5],
    [1.8, 0.5]
])

# -----------------
# 1. Regression
# -----------------

w_reg = np.array([2.0, -0.5])
b_reg = 3.0

reg_pred = X @ w_reg + b_reg

# -----------------
# 2. Binary
# -----------------

w_bin = np.array([1.2, -0.8])
b_bin = -0.3

bin_logits = X @ w_bin + b_bin

bin_probs = 1 / (
    1 + np.exp(-bin_logits)
)

bin_pred = (
    bin_probs >= 0.5
).astype(int)

# -----------------
# 3. Multiclass
# -----------------

W_multi = np.array([
    [1.0, -0.5, 0.2],
    [0.1,  0.8, 0.6]
])

b_multi = np.array([0.0, 0.1, -0.1])

multi_logits = X @ W_multi + b_multi

shifted = (
    multi_logits
    - np.max(
        multi_logits,
        axis=1,
        keepdims=True
    )
)

exp_z = np.exp(shifted)

multi_probs = exp_z / np.sum(
    exp_z,
    axis=1,
    keepdims=True
)

multi_pred = np.argmax(
    multi_probs,
    axis=1
)

print("Regression:")
print(np.round(reg_pred, 3))

print("\nBinary Probability:")
print(np.round(bin_probs, 3))

print("Binary Class:")
print(bin_pred)

print("\nMulticlass Probability:")
print(np.round(multi_probs, 3))

print("Multiclass Class:")
print(multi_pred)
```

# **38. 자주 발생하는 실수**

> ## **38-1) Logit 2를 Probability 2로 해석**

잘못된 해석이다.

```text
Logit = 2

↓

Sigmoid

↓

Probability ≈ 0.881
```

로 변환해야 한다.

<br>

> ## **38-2) Sigmoid 결과는 무조건 정확한 실제 Probability라고 생각**

Sigmoid는 0~1 값으로 변환하지만 실제 Probability 품질은 Model 학습과 Calibration에 따라 달라진다.

<br>

> ## **38-3) Multiclass에 Class별 Sigmoid를 사용하면서 하나의 Class만 선택한다고 가정**

상호 배타적인 하나의 Class를 예측하려면 일반적으로 Softmax 구조가 자연스럽다.

Class가 동시에 여러 개 존재할 수 있다면 Multilabel + Sigmoid가 적합할 수 있다.

<br>

> ## **38-4) Softmax를 Batch 전체에 한 번 적용**

Sample마다 독립적인 Probability Distribution을 만들어야 한다.

일반적인 Shape가

```text
(N, K)
```

이면 Class Axis인 `axis=1` 기준으로 계산한다.

<br>

> ## **38-5) Argmax가 가장 큰 Probability 값을 반환한다고 생각**

Argmax는 Value가 아니라 **Index**를 반환한다.

<br>

> ## **38-6) Threshold를 무조건 0.5로 사용**

Problem Cost와 Metric을 고려해 조정할 수 있다.

<br>

> ## **38-7) 높은 Probability를 높은 정확성과 동일하게 해석**

Probability Output과 실제 Correctness는 별개의 문제이다.

Calibration과 Test Performance를 함께 평가해야 한다.

# **39. Advanced 추가 학습**

> ## **39-1) Binary Classification의 두 가지 표현**

Binary Classification은

```text
1개의 Logit + Sigmoid
```

로 표현할 수 있다.

또는

```text
2개의 Logit + Softmax
```

구조로 만들 수도 있다.

실무에서는 하나의 Logit과 Sigmoid 또는 이에 대응하는 Binary Cross Entropy 계열 Loss를 많이 사용한다.

<br>

> ## **39-2) Temperature Scaling**

Softmax를 다음과 같이 변형할 수 있다.

```math
Softmax
\left(
\frac{z_i}{T}
\right)
```

`T`가 커지면 Probability Distribution이 상대적으로 평평해지고, 작아지면 더 뾰족해진다.

Temperature Scaling은 Calibration과도 연결될 수 있다.

<br>

> ## **39-3) Abstention**

Multiclass에서 무조건 Argmax Class를 선택하지 않고

```text
Top Probability가 일정 기준 이하

→ 판단 보류
```

와 같은 Rule을 사용할 수도 있다.

이는 불확실한 Prediction을 별도로 처리하는 방식이다.

<br>

> ## **39-4) 다음 강의와의 연결**

이번 강의에서는

```text
Model이 무엇을 예측하는가?
```

를 다뤘다.

다음 단계에서는

```text
실제 정답에 얼마나 높은 Probability를 주었는가?

Prediction이 얼마나 잘못되었는가?
```

를 평가하게 된다.

이 과정이

```text
Likelihood

Negative Log-Likelihood

Cross Entropy

MSE
```

와 연결된다.

# **40. 핵심정리**

1. 머신러닝의 Prediction 방식은 Target의 성격에 따라 Regression과 Classification으로 구분할 수 있다.

2. Regression은 연속적인 수치를 예측한다.

3. Classification은 미리 정의된 Class를 예측한다.

4. Binary Classification은 두 Class 중 하나를 구분한다.

5. Multiclass Classification은 서로 배타적인 3개 이상의 Class 중 하나를 선택한다.

6. Multilabel Classification은 하나의 Sample이 여러 Label을 동시에 가질 수 있다는 점에서 Multiclass와 다르다.

7. 회귀의 기본 Prediction은 다음과 같이 표현할 수 있다.

```math
\hat{y}=x\cdot w+b
```

8. Regression Output은 일반적으로 Probability가 아니라 Target과 같은 의미의 연속값이다.

9. 단순 Linear Regression Output은 자동으로 특정 범위에 제한되지 않는다.

10. Classification Model도 내부적으로는 숫자 Score를 계산한다.

11. 분류 Model이 Probability 변환 전에 계산한 Raw Score를 Logit이라고 부른다.

12. Logit 자체는 Probability가 아니다.

13. Logit은 음수, 0, 1보다 큰 값 모두 가질 수 있다.

14. Binary Classification에서는 하나의 Logit에 Sigmoid를 적용할 수 있다.

15. Sigmoid 공식은 다음과 같다.

```math
\sigma(z)
=
\frac{1}
{1+e^{-z}}
```

16. Sigmoid는 모든 실수를 0과 1 사이로 변환한다.

17. Sigmoid에서

```math
\sigma(0)=0.5
```

이다.

18. Logit이 증가하면 Sigmoid Probability도 증가한다.

19. Logit이 큰 양수이면 Probability는 1에 가까워진다.

20. Logit이 큰 음수이면 Probability는 0에 가까워진다.

21. Sigmoid는 다음 대칭 관계를 가진다.

```math
\sigma(-z)
=
1-\sigma(z)
```

22. Binary Classification의 Class 1 Probability가 \(p\)라면 Class 0 Probability는 일반적으로 \(1-p\)로 표현할 수 있다.

23. Logistic Model에서 Logit은 Log Odds와 연결된다.

```math
z
=
\log
\left(
\frac{p}
{1-p}
\right)
```

24. Probability를 Class로 변환하려면 Threshold가 필요하다.

25. Binary Decision Rule은 다음과 같이 표현할 수 있다.

$$
\hat{y} =
\begin{cases}
1 & \text{if } p \geq t \\
0 & \text{if } p < t
\end{cases}
$$


26. Threshold는 반드시 0.5일 필요가 없다.

27. Threshold를 높이면 동일한 Probability Output에서 Positive Prediction 수는 감소하거나 유지된다.

28. Threshold가 높아지면 일반적으로 FP와 TP는 감소 또는 유지하고, FN과 TN은 증가 또는 유지한다.

29. Threshold 선택은 어떤 Error를 더 중요하게 볼 것인지와 관련된다.

30. Threshold가 0.5라면 Sigmoid의 단조성 때문에

```math
p\ge0.5
```

와

```math
z\ge0
```

이 같은 Prediction을 만든다.

31. Probability Threshold \(t\)에 대응하는 Logit Threshold는 다음과 같다.

```math
\log
\left(
\frac{t}
{1-t}
\right)
```

32. Multiclass Classification에서는 Class마다 하나의 Logit을 계산한다.

33. K개 Class라면 일반적으로 K개의 Logit이 필요하다.

34. Softmax는 K개의 Logit을 Probability Distribution으로 변환한다.

35. Softmax 공식은 다음과 같다.

```math
P_i
=
\frac{e^{z_i}}
{\sum_{j=1}^{K}e^{z_j}}
```

36. Softmax Output은 각 값이 0과 1 사이이고 전체 합이 1이다.

37. Softmax에서는 Class들이 같은 Probability Mass를 공유하므로 서로 경쟁하는 구조가 된다.

38. 모든 Logit에 같은 Constant를 더하거나 빼도 Softmax 결과는 변하지 않는다.

39. 따라서 Stable Softmax에서는 다음과 같이 최대 Logit을 빼고 계산한다.

```math
z'_i
=
z_i-\max(z)
```

40. 이 처리는 Softmax Probability를 변경하지 않으면서 Overflow 위험을 줄인다.

41. 여러 Sample의 Multiclass Output Shape가 `(N,K)`라면 Sample별로 Class Axis를 따라 Softmax를 계산해야 한다.

42. Argmax는 가장 큰 값 자체가 아니라 가장 큰 값의 Index를 반환한다.

43. Multiclass Prediction은 보통 다음과 같이 결정한다.

```math
\hat{y}
=
Argmax(P)
```

44. Softmax는 Logit 순서를 바꾸지 않으므로 다음 관계가 성립한다.

```math
Argmax(z)
=
Argmax(Softmax(z))
```

45. 따라서 최종 Class만 필요하면 Logit에 바로 Argmax를 사용할 수도 있다.

46. Softmax Probability가 필요한 경우에는 Softmax 계산이 필요하다.

47. Multiclass와 Multilabel은 구분해야 한다.

48. Multiclass에서는 일반적으로 Softmax를 사용한다.

49. Multilabel에서는 각 Label에 독립적인 Sigmoid를 사용할 수 있다.

50. Multilabel Sigmoid Output의 합은 반드시 1일 필요가 없다.

51. Regression, Binary Classification, Multiclass Classification은 같은 Hidden Network를 사용하더라도 Output Layer의 구조가 다를 수 있다.

52. Input이

```math
X\in\mathbb{R}^{N\times D}
```

이면 Single Regression Output의 Weight는 일반적으로 `(D,1)` 형태로 구성할 수 있다.

53. Binary Single-Logit Model도 `(D,1)` 형태의 Weight를 사용할 수 있다.

54. K-Class Model의 Weight Matrix는 일반적으로 `(D,K)`이다.

55. 따라서 K-Class Logit Matrix는 `(N,K)`가 된다.

56. Classification에서는 다음 세 단계를 반드시 구분해야 한다.

```text
Logit

↓

Probability

↓

Predicted Class
```

57. Binary에서는 일반적으로

```text
Logit
→ Sigmoid
→ Probability
→ Threshold
→ Class
```

이다.

58. Multiclass에서는 일반적으로

```text
Logits
→ Softmax
→ Probability Distribution
→ Argmax
→ Class
```

이다.

59. 높은 Softmax Probability가 항상 정확한 Prediction을 의미하지는 않는다.

60. Model Probability가 실제 빈도와 얼마나 잘 일치하는지는 Calibration과 관련된다.

61. 동일한 Argmax Class를 갖는 두 Model도 Probability Distribution은 크게 다를 수 있다.

62. 따라서 Prediction Class와 Prediction Uncertainty는 별도로 살펴볼 필요가 있다.

63. Model Output과 실제 Decision Rule은 구분해야 한다.

64. Threshold를 변경해도 Model이 계산한 Probability 자체는 변하지 않는다.

65. Decision Rule만 변경된다.

66. Regression Model은 Prediction과 Actual Value 사이의 차이를 Loss로 평가할 수 있다.

67. Classification Model은 실제 Class에 얼마나 높은 Probability를 부여했는지를 이용하여 Loss를 만들 수 있다.

68. 따라서 이번 강의는 다음 개념으로 이어진다.

```text
Prediction

↓

Probability

↓

Likelihood

↓

Loss Function

↓

Backpropagation

↓

Parameter Update
```

69. 전체적으로 가장 중요한 흐름은 다음과 같다.

```text
Input Data

        ↓

Forward Propagation

        ↓

Raw Output

        ↓

문제 유형 확인

Regression
→ Continuous Prediction

Binary
→ Logit
→ Sigmoid
→ Threshold
→ Class

Multiclass
→ Logits
→ Softmax
→ Argmax
→ Class
```

70. 결국 회귀와 분류의 차이는 단순히 Model 이름의 차이가 아니라 **Target의 의미, Output Layer의 구조, Probability 변환 방식, 최종 Decision Rule이 서로 다르다는 것**으로 이해해야 한다.
