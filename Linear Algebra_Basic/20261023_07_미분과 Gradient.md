# **1. 미분과 Gradient를 배우는 이유**
앞선 과정에서는 머신러닝 모델이 다음과 같이 동작한다는 것을 학습했다.

```text

Input Data

    ↓

Model

    ↓

Prediction

    ↓

Actual Target과 비교

    ↓

Loss 계산

```

하지만 Loss를 계산하는 것만으로 Model Parameter가 자동으로 좋아지는 것은 아니다.

모델을 학습시키려면 다음 질문에 답할 수 있어야 한다.

```text

현재 Parameter에서

Weight를 증가시켜야 할까?

Weight를 감소시켜야 할까?

Bias는 어느 방향으로 움직여야 할까?

얼마나 움직여야 할까?

```

이때 필요한 개념이 **미분(Differentiation)** 과 **Gradient**이다.

전체 흐름은 다음과 같다.

```text

Prediction

    ↓

Loss

    ↓

Differentiation

    ↓

각 Parameter의 변화율 계산

    ↓

Gradient

    ↓

손실 감소 방향 확인

    ↓

Parameter Update

```

즉 미분은 단순한 수학 공식이 아니라

> **현재 Parameter를 어느 방향으로 변경해야 Loss가 감소하는지 판단하기 위한 도구**

라고 이해하는 것이 중요하다.

# **2. 앞선 AI 기초수학과의 연결**
AI에서 반복적으로 사용하는 수학적 구조를 정리하면 다음과 같다.

| 관점 | 수학적 형태 | 의미 |
| --- | --- | --- |
| Feature 1개인 Sample 1개 | Scalar 또는 1D Vector | 하나의 입력 데이터 |
| Feature $m$개인 Sample 1개 | $1 \times m$ Vector | 하나의 Feature Vector |
| Feature $m$개인 Sample $n$개 | $n \times m$ Matrix | 전체 Dataset |
| 입력 $m$개 → 출력 $o$개 | $m \times o$ Weight Matrix | Model Transformation |

머신러닝 Model은 일반적으로

$$
XW+b
$$

형태의 연산을 통해 Prediction을 만든다.

그다음 Target과 Prediction을 비교하여 Loss를 계산한다.

| 문제 | 대표 Loss | 확률적 해석 |
| --- | --- | --- |
| Regression | MSE | Gaussian Noise 가정에서 NLL 최소화와 연결 |
| Binary Classification | Binary Cross Entropy | Bernoulli NLL과 연결 |
| Multiclass Classification | Cross Entropy | Categorical NLL과 연결 |

따라서 전체 학습 흐름은 다음과 연결된다.

```text

Linear Algebra

    ↓

Prediction

    ↓

Probability Model

    ↓

Loss

    ↓

Differentiation

    ↓

Gradient

    ↓

Optimization

```

# **3. 함수(Function)와 변화율**
함수는 입력에 따라 출력이 결정되는 관계이다.

예를 들어

$$
f(x)=2x+1
$$

이라면 다음과 같다.

| $x$ | $f(x)$ |
| ---: | ---: |
| 1 | 3 |
| 2 | 5 |
| 3 | 7 |
| 4 | 9 |

입력 $x$가 1 증가할 때 출력은 항상 2 증가한다.

이때 변화율은

$$
\text{변화율} = \frac{\text{출력 변화량}}{\text{입력 변화량}}
$$

이다.

$x=1$에서 $x=3$으로 변하면

$$
\frac{f(3)-f(1)}{3-1} = \frac{7-3}{2} = 2
$$

이다.

즉 입력이 한 단위 변화할 때 출력이 평균적으로 2 변화한다.

# **4. 평균 변화율(Average Rate of Change)**

평균 변화율 
- 입력값 `x`가 일정한 구간에서 변할 때, 출력값 `y`가 평균적으로 얼마나 변하는지를 나타내는 값이다.
- 입력값의 변화량에 대한 출력값의 변화량의 비율이다.
$$
\boxed{\text{평균 변화율}=\frac{\text{출력값의 변화량}}{\text{입력값의 변화량}}}
$$

함수 $f(x)$에서 $x_1$부터 $x_2$까지의 평균 변화율은

$$
\frac{\Delta y}{\Delta x}= \frac{f(x_2)-f(x_1)}{x_2-x_1}
$$

이다.

단,

$$
x_1\neq x_2
$$

이어야 한다.

예를 들어

$$
f(x)=x^2
$$

라고 하자.

$1\rightarrow2$ 구간에서는

$$
\frac{4-1}{2-1} = 3
$$

이고,

$2\rightarrow3$ 구간에서는

$$
\frac{9-4}{3-2} = 5
$$

이다.

| 구간 | Average Rate |
| --- | ---: |
| 1 → 2 | 3 |
| 2 → 3 | 5 |
| 3 → 4 | 7 |

따라서 곡선에서는 위치에 따라 변화율이 달라진다.

# **5. 순간 변화율과 미분(Differentiation)**

평균 변화율은 **특정 구간**의 변화를 측정한다.

그리고 이 구간을 점점 좁혀 한 점에서의 순간적인 변화율을 구하는 것이 미분이다.

머신러닝에서는 현재 Weight에서 Loss가 어떻게 변하는지를 알고 싶기 때문에 특정 **지점의 순간 변화율**이 필요하다.

미분의 정의는

$$
f'(x) = \lim_{h\to0} \frac{f(x+h)-f(x)}{h}
$$

이다.

여기서 $h$는 아주 작은 입력 변화량이다.

예를 들어

$$
f(x)=x^2
$$

의 Derivative는

$$
f'(x)=2x
$$

이다.

$x=3$에서

$$
f'(3)=6
$$

이므로 현재 지점 주변에서 $x$가 아주 조금 증가하면 함수값도 대략 그 변화량의 6배 비율로 증가한다.

미분은 결국

```text

현재 위치에서

입력을 아주 조금 변화시키면

출력이 어느 방향으로

얼마나 민감하게 변화하는가?

```

를 측정한다.

# **6. 평균 변화율과 순간 변화율 비교**
| 구분 | 평균 변화율 | 순간 변화율 |
| --- | --- | --- |
| 기준 | 두 지점 사이 | 특정 한 지점 |
| 식 | Difference Quotient | Derivative |
| 의미 | 구간 평균 변화 | Local 변화 |
| 머신러닝 활용 | 제한적 | Parameter Gradient 계산 |

Loss Optimization에서는 현재 Parameter 주변의 변화가 중요하므로 순간 변화율인 Derivative를 사용한다.

# **7. 기본 미분 공식**
자주 사용하는 기본 공식은 다음과 같다.

| 함수 | Derivative |
| --- | --- |
| $c$ (상수) | $0$ |
| $x$ | $1$ |
| $ax+b$ | $a$ |
| $x^2$ | $2x$ |
| $x^3$ | $3x^2$ |
| $x^n$ | $nx^{n-1}$ |

예를 들어

$$
f(x)=2x^2+3x+5
$$

이면

$$
f'(x)=4x+3
$$

이다.

각 항을 따로 미분한 뒤 더할 수 있기 때문이다.

```text

2x² → 4x

3x  → 3

5   → 0

```

# **8. Derivative의 부호를 해석하는 방법**
Derivative의 부호는 현재 지점에서 함수가 어느 방향으로 변화하는지를 알려준다.

| Derivative | 해석 |
| --- | --- |
| $f'(x)>0$ | $x$를 조금 증가시키면 함수값 증가 |
| $f'(x)<0$ | $x$를 조금 증가시키면 함수값 감소 |
| $f'(x)=0$ | 현재 순간 변화율이 0 |

예를 들어

$$
f(x)=x^2
$$

이면

$$
f'(x)=2x
$$

이다.

| $x$ | $f(x)$ | $f'(x)$ |
| ---: | ---: | ---: |
| -2 | 4 | -4 |
| -1 | 1 | -2 |
| 0 | 0 | 0 |
| 1 | 1 | 2 |
| 2 | 4 | 4 |

`x < 0`에서는 오른쪽으로 움직이면 함수값이 감소하고, `x > 0`에서는 오른쪽으로 움직이면 함수값이 증가한다.

단,

> **Derivative가 0이라고 해서 항상 Minimum이라는 의미는 아니다.**

Maximum이나 Saddle Point에서도 Gradient가 0일 수 있다.

# **10. Loss Function을 미분하는 이유**
앞선 Loss는

$$
L(w)=(10-2w)^2
$$

이다.

전개하면

$$
L(w) = 4w^2-40w+100
$$

이다.

미분하면

$$
\frac{dL}{dw} = 8w-40
$$

이다.

이 값은 현재 Weight에서

> Weight를 조금 변경했을 때 Loss가 어느 방향으로 얼마나 변화하는가

를 의미한다.

각 위치를 계산하면 다음과 같다.

| $w$ | Loss | $\frac{dL}{dw}$ | Loss 감소 방향 |
| ---: | ---: | ---: | --- |
| 3 | 16 | -16 | $w$ 증가 |
| 4 | 4 | -8 | $w$ 증가 |
| 5 | 0 | 0 | 현재 Minimum |
| 6 | 4 | 8 | $w$ 감소 |

따라서

```text

Gradient < 0

→ Parameter 증가 방향이 Loss 감소

Gradient > 0

→ Parameter 감소 방향이 Loss 감소

```

라는 관계를 확인할 수 있다.

# **11. Loss와 Derivative를 Python으로 확인하기**
[ Python : code ] "단일 Weight 회귀 Model의 Loss와 Derivative 계산"

```python

import numpy as np

x = 2.0

y = 10.0

def loss(weight):
    prediction = weight * x
    return (y - prediction) ** 2

def derivative(weight):
    return 8 * weight - 40

weights = np.array([3.0, 4.0, 5.0, 6.0])

for weight in weights:
    print(
        f"w={weight:.1f}, "
        f"loss={loss(weight):.1f}, "
        f"gradient={derivative(weight):.1f}"
)

```

[ Result ]

```text

w=3.0, loss=16.0, gradient=-16.0
w=4.0, loss=4.0, gradient=-8.0
w=5.0, loss=0.0, gradient=0.0
w=6.0, loss=4.0, gradient=8.0

```

결과에서 Weight가 5보다 작으면 Gradient가 음수이고, 5보다 크면 양수이다.

따라서 Gradient의 부호만으로도 Local Loss 감소 방향을 판단할 수 있다.

# **12. 미분값은 정확한 Loss 변화량 자체가 아니다**
Derivative가

$$
\frac{dL}{dw}=-12
$$

이라고 해서 Weight를 1 증가시키면 Loss가 반드시 정확히 12 감소한다는 의미는 아니다.

Derivative는 **현재 지점 주변에서의 순간 변화율**이다.

아주 작은 변화량 $\Delta w$에서는

$$
\Delta L \approx \frac{dL}{dw}\Delta w
$$

로 근사할 수 있다.

따라서 큰 Step을 이동하면 이 Local Approximation이 부정확해질 수 있다.

이것이 Gradient Descent에서 Learning Rate가 중요한 이유이다.

# **13. 여러 Parameter가 존재하면 편미분이 필요하다**
실제 Model에는 Weight 하나만 존재하지 않는다.

예를 들어

$$
\hat y=wx+b
$$

에서는

```text

w → Weight

b → Bias

```

두 Parameter를 학습해야 한다.

Squared Error는

$$
L(w,b) = (y-wx-b)^2
$$

이다.

입력이

```text

x = 2

y = 10

```

이라면

$$
L(w,b) = (10-2w-b)^2
$$

이제 Loss는 $w$와 $b$ 두 변수에 의해 동시에 결정된다.

따라서

```text

w만 변할 때 Loss 변화율

b만 변할 때 Loss 변화율

```

을 각각 계산해야 한다.

# **14. 편미분(Partial Differentiation)**
편미분은 여러 변수 중 **하나의 변수만 변화시키고 나머지는 고정한 상태에서 변화율을 계산**하는 방법이다.

예를 들어

$$
f(w,b)=w^2+2b^2
$$

라고 하자.

$w$에 대해 편미분할 때 $b$는 상수로 처리한다.

$$
\frac{\partial f}{\partial w} = 2w
$$

반대로 $b$에 대해 편미분하면

$$
\frac{\partial f}{\partial b} = 4b
$$

| 미분 대상 | 나머지 변수 | 결과 |
| --- | --- | --- |
| $w$ | $b$ 고정 | $2w$ |
| $b$ | $w$ 고정 | $4b$ |

여러 변수를 가진 Model에서는 이러한 Partial Derivative가 각 Parameter의 영향력을 나타낸다.

$$

$$

$$
L(w,b) = 4w^2+4wb+b^2-40w-20b+100

# **16. Chain Rule 관점에서 더 간단하게 해석하기**
앞에서는 식을 전개한 뒤 미분했지만 실제 Deep Learning에서는 연산을 단계별로 나누어 생각하는 것이 더 중요하다.

$$
\hat y=wx+b
$$

$$
L=(y-\hat y)^2
$$

라고 하자.

Error를

$$
e=\hat y-y
$$

라고 정의하면

$$
L=e^2
$$

Squared Error의 Prediction에 대한 Derivative는

$$
\frac{\partial L}{\partial \hat y} = 2(\hat y-y)
$$

또한

$$
\frac{\partial \hat y}{\partial w} = x
$$

이므로

$$
\frac{\partial L}{\partial w} = 2(\hat y-y)x
$$

이다.

Bias에 대해서는

$$
\frac{\partial \hat y}{\partial b} = 1
$$

이므로

$$
\frac{\partial L}{\partial b} = 2(\hat y-y)
$$

현재

```text

x = 2

y = 10

w = 3

b = 1

```

이면

$$
\hat y=7
$$

이고

$$
\hat y-y=-3
$$

이므로

$$
\frac{\partial L}{\partial w} = 2(-3)(2) = -12
$$

$$
\frac{\partial L}{\partial b} = 2(-3) = -6
$$

가 된다.

이 방식은 다음 강의의 **Chain Rule과 Backpropagation**으로 직접 연결된다.

```text
b  = 1
```

# **18. Gradient란 무엇인가**
Gradient는 여러 변수에 대한 Partial Derivative를 하나의 Vector로 모은 것이다.

함수가

$$
f(w,b)
$$

라면

$$
\nabla f(w,b)
=
\begin{bmatrix}
\displaystyle \frac{\partial f}{\partial w} \\[12pt]
\displaystyle \frac{\partial f}{\partial b}
\end{bmatrix}
$$

로 표현할 수 있다.

예를 들어

$$
f(w,b)=w^2+2b^2
$$

이면

$$
\nabla f(w,b) = \begin{bmatrix} 2w\\ 4b \end{bmatrix}
$$

이다.

$w=2,\ b=1$에서는

$$
\nabla f(2,1) = \begin{bmatrix} 4\\ 4 \end{bmatrix}
$$

이다.

Gradient는 단순한 숫자 하나가 아니라 **Parameter 공간에서의 방향을 가진 Vector**이다.

<br><br>

---
# **19. Gradient와 Partial Derivative의 차이**
| 구분 | Partial Derivative | Gradient |
| --- | --- | --- |
| 대상 | Parameter 하나 | 모든 Parameter |
| 결과 | Scalar | Vector |
| 예시 | $\partial L/\partial w_1$ | $\nabla L$ |
| 의미 | 한 Parameter의 변화율 | 전체 Parameter 공간의 변화 방향 |

예를 들어 Parameter가

$$
\theta= [w_1,w_2,b]
$$

라면

$$
\nabla_{\theta} L
=
\begin{bmatrix}
\displaystyle \frac{\partial L}{\partial w_1} \\[12pt]
\displaystyle \frac{\partial L}{\partial w_2} \\[12pt]
\displaystyle \frac{\partial L}{\partial b}
\end{bmatrix}
$$

이다.

<br><br>

---
# **20. Gradient가 가리키는 방향**
Gradient는 현재 지점에서 같은 크기의 아주 작은 이동을 비교했을 때 **함수값이 가장 빠르게 증가하는 방향**을 나타낸다.

따라서 Loss를 줄이려면 반대 방향을 사용한다.

$$
-\nabla L
$$

이를 Negative Gradient라고 한다.

| 방향 | 의미 |
| --- | --- |
| $\nabla L$ | Loss가 가장 빠르게 증가하는 Local Direction |
| $-\nabla L$ | Loss가 가장 빠르게 감소하는 Local Direction |

예를 들어

$$
\nabla L= [-12,-6]
$$

이면

$$
-\nabla L= [12,6]
$$

이다.

따라서 현재 지점에서는 $w$와 $b$를 모두 증가시키는 쪽이 Loss 감소 방향이다.

<br><br>

---
# **21. Gradient Descent의 기본 Update 식**
Gradient Descent에서는 Parameter를 다음과 같이 Update한다.

$$
\theta_{\text{new}} = \theta_{\text{old}} - \eta\nabla_\theta L
$$

여기서

$$
\eta
$$

는 Learning Rate이다.

두 Parameter라면

$$
w_{\text{new}} = w-\eta \frac{\partial L}{\partial w}
$$

$$
b_{\text{new}} = b-\eta \frac{\partial L}{\partial b}
$$

가 된다.

현재

```text

w = 3

b = 1

Gradient = [-12, -6]

Learning Rate = 0.01

```

이라면

$$
w_{\text{new}} = 3-0.01(-12) = 3.12
$$

$$
b_{\text{new}} = 1-0.01(-6) = 1.06
$$

이다.

새 Prediction은

$$
\hat y = 2(3.12)+1.06 = 7.3
$$

이고 Loss는

$$
(10-7.3)^2 = 7.29
$$

이다.

기존 Loss가 9였으므로 Loss가 감소하였다.

<br><br>

---
# **22. Gradient Descent Python 예제**
[ Python : code ] "Weight와 Bias를 Gradient 방향으로 한 번 Update"

```python

import numpy as np

x = 2.0
y = 10.0

# 손실함수
def loss(weight, bias):
    prediction = weight * x + bias
    return (y - prediction) ** 2

# 기울기 계산 함수
def gradient(weight, bias):
    prediction = weight * x + bias
    error = prediction - y
    grad_weight = 2 * error * x
    grad_bias = 2 * error
    return np.array([grad_weight, grad_bias])

parameters = np.array([3.0, 1.0])

learning_rate = 0.01

old_loss = loss(parameters[0], parameters[1]) # 손실함수(가중치, 편향)

grad = gradient(parameters[0], parameters[1]) # 기울기

new_parameters = parameters - learning_rate * grad # 기울기 갱신

new_loss = loss(new_parameters[0], new_parameters[1]) # 손실함수 갱신

print("Old Parameters:", parameters)
print("Gradient:", grad)
print("New Parameters:", new_parameters)
print("Old Loss:", old_loss)
print("New Loss:", round(new_loss, 2))
```

[ Result ]

```text

Old Parameters: [3. 1.]

Gradient: [-12.  -6.]

New Parameters: [3.12 1.06]

Old Loss: 9.0

New Loss: 7.29

```

Gradient가 모두 음수이므로 Update 식의

```python

parameters - learning_rate * grad

```

에서 음수를 빼게 되어 두 Parameter가 증가한다.

```text

3.00 → 3.12

b

1.00 → 1.06

```

그 결과 Prediction이 실제 Target인 10에 가까워지고 Loss가

```text

```

로 감소한다.

<br>

> **22-2) 코드 흐름도**
```text

현재 Weight / Bias

        ↓

Prediction 계산

        ↓

Target과 Error 계산

        ↓

Squared Error Loss

        ↓

∂L/∂w

∂L/∂b

        ↓

Gradient Vector

        ↓

Learning Rate 적용

        ↓

        ↓

```

# **23. Learning Rate가 중요한 이유**
Gradient는 방향을 알려주지만 **얼마나 이동할지**는 알려주지 않는다.

이동 크기는 Learning Rate $\eta$가 결정한다.

| Learning Rate | 가능 현상 |
| --- | --- |
| 너무 작음 | Loss가 천천히 감소 |
| 적절함 | 안정적으로 Minimum 방향 이동 |
| 너무 큼 | Minimum을 지나치거나 진동 |
| 매우 큼 | Loss가 발산할 수도 있음 |

즉

```text

Gradient

→ Direction

Learning Rate

→ Step Size

```

라고 이해할 수 있다.

Negative Gradient Direction이 Loss 감소 방향이라도 지나치게 큰 Step을 적용하면 Loss가 오히려 증가할 수 있다.

# **24. 여러 Sample을 사용하는 실제 Regression Gradient**
실제 학습에서는 보통 Sample 하나가 아니라 Dataset을 사용한다.

다음 Linear Regression을 생각해보자.

$$
\hat y_i = w_1x_{i1} + w_2x_{i2} + b
$$

MSE는

$$
L = \frac{1}{n} \sum_{i=1}^{n} (y_i-\hat y_i)^2
$$

이다.

Weight $w_j$에 대한 Gradient는

$$
\frac{\partial L}{\partial w_j} = \frac{2}{n} \sum_{i=1}^{n} (\hat y_i-y_i)x_{ij}
$$

이고 Bias Gradient는

$$
\frac{\partial L}{\partial b} = \frac{2}{n} \sum_{i=1}^{n} (\hat y_i-y_i)
$$

이다.

즉 여러 Sample의 Error가 모여 하나의 Gradient를 만든다.

축구 GPS 데이터에서 다음 Feature로 Training Load Score를 예측한다고 하자.

```text
Acceleration Count

```

모델은

$$
\hat y=Xw+b
$$

이다.

[ Python : code ] "GPS Training Load Linear Model의 MSE Gradient 계산"

```python

import numpy as np

X = np.array([
    [1.2, 0.7, 3.0],
    [0.9, 0.4, 2.0],
    [1.5, 0.8, 4.0],
    [0.6, 0.3, 1.0]
])

y = np.array([
    8.0,
    5.5,
    9.5,
    3.8
])

weights = np.array([
    1.5,
    2.0,
    0.8
])

bias = 0.5

predictions = X @ weights + bias

errors = predictions - y

mse = np.mean(errors ** 2)

grad_weights = (2 / len(y)) * X.T @ errors

grad_bias = (2 / len(y)) * np.sum(errors)

print("Prediction:", np.round(predictions, 2))
print("MSE:", round(mse, 3))
print("Weight Gradient:", np.round(grad_weights, 3))
print("Bias Gradient:", round(grad_bias, 3))
```

```text
Weight Gradient: [-3.031 -1.594 -7.375]

Bias Gradient: -2.8
```

# **26. Vectorized Gradient의 의미**
앞선 GPS 예제의 Weight Gradient는

$$
\nabla_w L = \frac{2}{n} X^T(\hat y-y)
$$

로 한 번에 계산할 수 있다.

이 식에서 Shape는 다음과 같다.

| 변수 | Shape |
| --- | --- |
| $X$ | `(n_samples, n_features)` |
| $\hat y-y$ | `(n_samples,)` |
| $X^T$ | `(n_features, n_samples)` |
| $\nabla_wL$ | `(n_features,)` |

따라서 Weight가 3개이면 Gradient도 3개이다.

일반적으로

> **Parameter와 해당 Gradient는 같은 Shape를 가진다.**

# **28. Gradient와 Backpropagation의 관계**
Gradient는 **필요한 결과**이고, Backpropagation은 복잡한 Neural Network에서 그 Gradient를 효율적으로 계산하는 방법이다.

예를 들어

```text

Input

    ↓

Linear Layer

    ↓

ReLU

    ↓

Linear Layer

    ↓

Sigmoid

    ↓

Loss

```

와 같은 Model에서는 Loss가 첫 번째 Layer의 Weight와 직접 연결되어 있지 않고 여러 연산을 거쳐 연결된다.

따라서

```text

→ Output

→ Hidden Layer

→ Previous Layer

```

순서로 Chain Rule을 적용하여 Gradient를 전달한다.

이를 Backpropagation이라고 한다.

```text

Forward Propagation

→ Prediction과 Loss 계산

Backward Propagation

→ 각 Parameter의 Gradient 계산

```

# **29. Gradient가 0이면 항상 학습이 끝난 것인가**
그렇지 않다.

Gradient가 0인 지점을 **Stationary Point**라고 할 수 있으며 다음과 같은 경우가 존재한다.

| 종류 | 의미 |
| --- | --- |
| Local Minimum | 주변보다 함수값이 작음 |
| Local Maximum | 주변보다 함수값이 큼 |
| Saddle Point | 어떤 방향에서는 증가하고 다른 방향에서는 감소 |

따라서

$$
\nabla L=0
$$

이라는 사실만으로 Global Minimum이라고 판단할 수 없다.

단순한 Convex Quadratic Function에서는 Gradient가 0인 지점이 Minimum인 경우가 명확하지만 Deep Neural Network Loss Landscape는 훨씬 복잡하다.

# **30. Analytical Gradient와 Numerical Gradient**
Gradient를 계산하는 방법은 크게 두 가지로 생각할 수 있다.

| 구분 | Analytical Gradient | Numerical Gradient |
| --- | --- | --- |
| 방식 | 미분 공식 사용 | 작은 변화량으로 근사 |
| 속도 | 빠름 | 느림 |
| 정확도 | 수식이 맞으면 높음 | 근사 오차 존재 |
| 활용 | 실제 학습 | Gradient 검증 |

Numerical Gradient는 다음과 같이 근사할 수 있다.

$$
\frac{df}{dx} \approx \frac{f(x+h)-f(x-h)}{2h}
$$

이 방법은 Deep Learning Model의 Gradient 계산에 직접 사용하기보다는 구현한 Gradient가 맞는지 확인하는 **Gradient Checking**에 활용할 수 있다.

<br><br>

---
# **31. Numerical Gradient 검증 예제**
[ Python : code ] "Analytical Gradient와 Numerical Gradient 비교"

```python

def loss(weight):
    x = 2.0
    y = 10.0
    prediction = weight * x
    return (y - prediction) ** 2

def analytical_gradient(weight):
    return 8 * weight - 40

def numerical_gradient(weight, h=1e-5):
    return (loss(weight + h) - loss(weight - h)) / (2 * h)

weight = 3.0

print("Analytical:", analytical_gradient(weight))
print("Numerical:", round(numerical_gradient(weight), 6))
```

[ Result ]

```text

Analytical: -16.0

Numerical: -16.0

```

두 값이 거의 동일하므로 작성한 Derivative가 올바르다고 확인할 수 있다.

# **37. 자주 발생하는 실수**
> **37-1) Gradient가 음수이면 Parameter를 감소시킨다고 생각**
Gradient Descent는

$$
\theta_{\text{new}} = \theta-\eta\nabla L
$$

를 사용한다.

Gradient가 음수이면 음수를 빼기 때문에 Parameter는 오히려 증가한다.

<br>

> **37-2) Gradient의 절댓값을 Parameter 중요도로 해석**
Gradient 크기는 현재 Sample, 현재 Parameter, Feature Scale에 따라 달라진다.

따라서 Gradient 절댓값 하나만으로 Feature Importance를 판단해서는 안 된다.

<br>

> **37-3) Gradient가 0이면 반드시 Global Minimum이라고 생각**
Maximum이나 Saddle Point일 수도 있다.

<br>

> **37-4) Negative Gradient 방향이면 어떤 크기로 움직여도 Loss가 감소한다고 생각**
Gradient는 Local 정보이다.

Learning Rate가 지나치게 크면 Loss가 증가할 수 있다.

<br>

> **37-5) Partial Derivative와 Gradient를 같은 개념으로 생각**
Partial Derivative는 한 Parameter의 변화율이고, Gradient는 모든 Partial Derivative를 모은 Vector이다.

<br>

> **37-6) Prediction Error와 Gradient를 동일하게 생각**
Error는

$$
\hat y-y
$$

이고 Gradient는 Error가 각 Parameter에 미치는 영향까지 포함한다.

예를 들어 Linear Regression에서는

$$
\frac{\partial L}{\partial w} = 2(\hat y-y)x
$$

이므로 Feature $x$도 Gradient에 영향을 준다.

# **40. 핵심정리**
1. 미분은 입력값이 아주 조금 변할 때 함수값이 어떻게 변화하는지를 나타내는 순간 변화율을 계산하는 방법이다.

2. Average Rate of Change는 두 지점 사이의 평균 변화를 나타낸다.

3. Derivative는 특정 지점의 Local 변화율을 나타낸다.

4. 함수 $f(x)$의 Derivative는 일반적으로

$$
f'(x)
$$

또는

$$
\frac{df}{dx}
$$

로 표현한다.

5. 기본 Power Rule은

$$
\frac{d}{dx}x^n = nx^{n-1}
$$

이다.

6. Derivative가 양수이면 입력을 조금 증가시킬 때 함수값이 증가하는 Local Direction이다.

7. Derivative가 음수이면 입력을 조금 증가시킬 때 함수값이 감소하는 Local Direction이다.

8. Derivative가 0이라는 사실만으로 Minimum이라고 단정할 수 없다.

9. 머신러닝에서 미분은 Parameter가 조금 변할 때 Loss가 어떻게 변화하는지를 분석하는 데 사용한다.

10. 단일 Weight Model에서는

$$
\frac{dL}{dw}
$$

를 이용하여 Weight 변화에 따른 Loss 변화율을 확인할 수 있다.

11. Gradient의 부호를 이용하면 현재 지점에서 Loss를 감소시키기 위한 Parameter 방향을 판단할 수 있다.

12. Gradient는 현재 지점의 Local 정보이므로 큰 Parameter 변화까지 정확하게 설명하는 것은 아니다.

13. 여러 Parameter를 가진 함수에서는 Partial Differentiation을 사용한다.

14. Partial Differentiation은 다른 변수를 고정하고 하나의 변수만 변화시켜 변화율을 계산한다.

15. 두 Parameter를 가진 Loss

$$
L(w,b)
$$

에서는

$$
\frac{\partial L}{\partial w}
$$

와

$$
\frac{\partial L}{\partial b}
$$

를 각각 계산할 수 있다.

16. Linear Regression

$$
\hat y=wx+b
$$

에서 Squared Error를 사용하면

$$
L=(y-\hat y)^2
$$

이다.

17. 이때 Weight Gradient는

$$
\frac{\partial L}{\partial w} = 2(\hat y-y)x
$$

이다.

18. Bias Gradient는

$$
\frac{\partial L}{\partial b} = 2(\hat y-y)
$$

이다.

19. Gradient는 모든 Parameter의 Partial Derivative를 하나의 Vector로 모은 것이다.

20. Parameter가

$$
\theta=[w_1,w_2,b]
$$

이면 Gradient는

$$
\nabla_\theta L = \begin{bmatrix} \frac{\partial L}{\partial w_1}\\ \frac{\partial L}{\partial w_2}\\ \frac{\partial L}{\partial b} \end{bmatrix}
$$

이다.

21. Gradient는 현재 지점에서 함수값이 가장 빠르게 증가하는 Local Direction이다.

22. Negative Gradient는 가장 빠르게 감소하는 Local Direction이다.

23. Loss Minimization에서는 일반적으로 Negative Gradient Direction을 사용한다.

24. Gradient Descent의 기본 Update 식은

$$
\theta_{\text{new}} = \theta_{\text{old}} - \eta\nabla_\theta L
$$

이다.

25. $\eta$는 Learning Rate이다.

26. Gradient는 이동 방향을 결정하고 Learning Rate는 이동 크기를 조절한다.

27. Gradient가 음수이면 Gradient Descent Update 결과 Parameter가 증가할 수 있다.

28. Gradient가 양수이면 Gradient Descent Update 결과 Parameter가 감소할 수 있다.

29. Learning Rate가 지나치게 작으면 학습이 느려질 수 있다.

30. Learning Rate가 지나치게 크면 Minimum을 지나치거나 Loss가 발산할 수 있다.

31. Dataset 전체를 사용하는 MSE에서는 여러 Sample의 Error가 모여 Gradient를 만든다.

32. Linear Regression의 Weight Gradient는 Matrix 형태로

$$
\nabla_wL = \frac{2}{n} X^T(\hat y-y)
$$

로 표현할 수 있다.

33. Weight Vector와 Weight Gradient는 일반적으로 동일한 Shape를 가진다.

34. Neural Network Weight Matrix의 Gradient도 해당 Weight Matrix와 동일한 Shape를 가진다.

35. Deep Neural Network에서는 많은 Parameter의 Gradient를 모두 계산해야 한다.

36. Forward Propagation은 Prediction과 Loss를 계산하는 과정이다.

37. Backpropagation은 Loss로부터 각 Parameter의 Gradient를 계산하는 과정이다.

38. Backpropagation의 핵심 수학 원리는 Chain Rule이다.

39. Analytical Gradient는 미분 공식을 이용하여 Gradient를 계산한다.

40. Numerical Gradient는 작은 Parameter 변화를 이용하여 Gradient를 근사한다.

41. Numerical Gradient는 실제 Training보다 Gradient Checking에 주로 활용할 수 있다.

42. Gradient의 크기는 Feature Scale의 영향을 받을 수 있다.

43. 따라서 Feature Scaling은 Optimization 동작에 영향을 줄 수 있다.

44. Gradient의 절댓값만 보고 Feature Importance를 판단해서는 안 된다.

45. Regression에서는 Gaussian Assumption 아래

```text

Maximum Likelihood

→ MSE 최소화

→ Gradient 계산

→ Parameter Update

```

로 연결할 수 있다.

46. Classification에서는 Bernoulli 또는 Categorical Model을 통해

```text

Maximum Likelihood

→ NLL

→ Cross Entropy

→ Gradient 계산

→ Parameter Update

```

로 연결할 수 있다.

47. 따라서 앞선 Probability·Likelihood 강의와 이번 Gradient 강의는 서로 독립된 내용이 아니다.

48. 전체 머신러닝 학습 구조는 다음과 같이 연결된다.

```text

Data

    ↓

Model

    ↓

Prediction

    ↓

Probability / Regression Output

    ↓

Loss

    ↓

Differentiation

    ↓

Partial Derivative

    ↓

Gradient

    ↓

Gradient Descent

    ↓

Parameter Update

```

49. Gradient는 **현재 Parameter에서 Loss를 줄이기 위해 어느 방향으로 움직여야 하는지 알려주는 핵심 정보**이다.
