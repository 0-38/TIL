# 1. 벡터, 스칼라, 행렬 개념

> **1. 스칼라(Scalar)**

- 숫자를 의미
- 5,0, 0.4, -1 모두 스칼라가 될 수 있음

> **2. 벡터(Vector)**

- 벡터는 숫자들을 정해진 순서대로 모아놓은 것
- [5, 2]
- 세영의 출석은 5일, 과제는 2개를 제출했다면 이 두 가지 정보를 함께 묶고 싶을 때 [5,2]로 묶을 수 있다.

> **3. 벡터의 차원**

- [5,2]는 숫자가 2개이므로 2차원 벡터라고 부른다.
- [5,2,4]는 숫자가 3개이므로 3차원 벡터라고 부른다.

> **4. Shape 배열**

- Shape는 각 축에 값이 몇개씩 놓여있는지를 알려주는 정보
- x.shape = (2, )

> **5. 행 벡터와 열 벡터**
- 행 벡터 : 값을 한 행에 가로로 놓은 형태
- 열 벡터 : 한 열에 세로로 놓은 형태

> **6. reshape**
- reshape : 배열의 값과 전체 원소 개수를 유지하면서 배치를 바꾸는 기능
- x = np.array([5,2])에서 x.reshape(1,2)는 [[5,2]], x.reshape(2,1)은 [[5], [2]]를 만든다. 

> **7. 가중치** `w`
- 가중치 : 각 입력값에 곱하는 값
- 어떤 입력이 점수 계산에 어떻게 반영되었는지 조절함
- 참여 점수를 출석 하루당 2점, 과제 하나당 3점이라고 했을 때,    
세영이가 5일 출석했다면 5x2=10점을 받을 수 있다. 과제를 2개 냈다면 2x3=6점이다.    
그래서 16점 받을 수 있었다.

> **8. 편향** `b`
- 편향은 입력값에 가중치를 곱해 더한 결과에 추가로 더한 값
- 참여 점수를 계산할때, 모든 학생들에게 기본 점수 1점을 준다는 가정이라면,    
출석을 아예 하지 않은 하영은 0 x 2 + 0 X 3 + 1로 1점을 받을 수 있다.

> **9. 파라미터**
- 파라미터 : 모델의 계산에 사용되며 학습으로 조정할 수 있는 값(가중치와 편향)
- 공부시간으로 시험점수를 예상한다고 가정해보면   
예상점수 = 공부시간 x 5 + 10 이라는 기본 규칙에서   
실제 2시간 공부한 학생의 예상 점수는 20점인데, 실제로 30점이라면 두 점수 차이를 계산하여 이를 조정하는 값

> **10. 가중합과 출력 점수**
- 가중합 : 각 입력값에 대응하는 가중치를 곱한 뒤 모두 더한 값
- 아까 앞서 5x2=10점, 2x3=6점, 편향 1점이면 17점
- -> 여기서 16점이 가중합이라고 부를 수 있다.

>**11. 가중치 행렬**
- 여러 출력에 필요한 가중치들을 가중치 표로 모은 것
- W = [[2, 1], [3, 4]]라고 가정하면, 같은 출석, 과제 기록으로 점수를 만든다고 할때,    
첫 번째 점수는 출석당 2점, 과제당 3점, 둘째 점수는 출석당 1점, 과제당 4점으로 나타낼 수 있다.

> **12. 노름 (Norm)**
- L1 Norm 
    - 각 원소의 절댓값을 구한 뒤 전부 더한 값
    - 윤하가 오른쪽으로 3m 이동한 귀 아래쪽으로는 4m 이동했다고 가정하면, 이동 기록은 [3, -4]일 수 있다.
    - 이걸 이동거리로 계산해보면 |3|, |-4|, L1 노름을 이용하면 3+4=7m 이동했다고 볼 수 있다.
- L2 Norm
    - 각 원소를 제곱하고 모두 더한 뒤, 제곱근을 구한 값
    - 8강의실 출입문을 [0, 0]으로 정하고, 윤하가 오른쪽 6m, 위쪽 8m 지점에 있다고 가정하면, 출입문에서 윤하까지의 거리는 6x6=36, 8x8=64, 36+64=100의 루트를 써서 10m 정도 떨어져 있다는 것을 구할 수 있다.

> **13. 차이 벡터**
- 두 벡터에서 같은 위치의 값끼리 뺀 결과
- A = [3, 4], B=[6, 8]일 때, B-A=[6-3, 8-4]=[3, 4]로 계산할 수 있다.

> **14. 맨해튼 거리**
- 두 벡터의 같은 위,치 값끼리 차이를 구하고, 그 차이의 절댓값을 모두 더한 값
- A = [3, 4], B=[6, 8]이면, 차이=[3, 4] / 절댓값은 3과 4/ 합은 7로 7의 거리를 가진다.
- 가로 세로 통로를 따라 움직이는 상황에서 각 방향의 차이를 더해 거리를 구한다.

> **15. 유클리드 거리**
- 두 점 사이의 직선거리 방식으로 구한 차이의 크기
- A=[3, 4], B=[6, 8]이면 차이는 [3, 4]인데, 이걸 제곱하면 9, 16이고 두 값을 더해 루트 계산을 하면 5m 정도로 구할 수 있다.

> **16. 벡터의 방향과 비율**
-  방향은 벡터가 원점에서 어느 쪽을 가르키는지를 말한다.
- A = [3, 4], B=[6, 8]이면 B의 값은 A의 2배이다. 두 값의 비율은 3:4, 6:8로 같다.

# 2. 벡터 계산

> **1. 스칼라와 벡터 행렬**
- 스칼라와 벡터, 행렬에 대한 차이를 구분할 수 이싿.
- 스칼라 = 숫자 하나
- 벡터 = [3,2] 원소 2개를 가지는 벡터
- 행렬 = [[3,2], [5,1], [2,4]] = 3행 2열의 행렬

> **2. 백터의 내적 Dot Product**
- 백터 내적은 같은 위치의 숫자끼리 곱한 뒤, 곱셈결과를 모두 더하는 계산
- 영흠의 출석 과제 점수 기록을 [3,2]와 점수 규칙 [2,4]를 내적해본다고 가정하면
- 출석점수 = 3 X 2 = 6점
- 과제점수 = 2 x 4 = 8점
- 최종적으로 14점

> **3. 사이각과 각도** 
- 사이각
    - 두 벡터를 같은 출발점에서 그렸을 떄 두 방향 사이에 벌어진 각도
    - 0 : 같은 방향, 90 : 직각 / 180: 정반대 방향(1,0,-1)

>**4. 코사인 유사도**
- 두 벡터의 내적을 두 길이의 곱으로 나누어 방향관계를 비교하는 값
- 학생의 [국어, 수학] 문제 수가 민수[3, 4] 지수[6,8]이면 내적은 3 x 6 + 4 x 8=50,
- 각 길이는 5와 10이기 때문에 50 / 5x10=1

> **5. 행렬곱**
- C11 = A11 x B11 x A12 X 21
- C = A @ B에서 C11은 A의 1행 1, 2와 B의 1열 [5,7]을 내적한다.
- 1 x 5 + 2 x 7 = 19
- 앞에 열과 뒤에 행수가 같아야 함
    - (3, 2) @ (2, 4)는 가능하지만 (2, 4) @ (3, 2)는 불가능함

# 3. 딥러닝 흐름


## 3-1) ReLu 활성화 함수
- 공부를 시작한 뒤 처음 2시간은 기초를 익히기 때문에 점수 상승을 기대하기 어렵다.

- 기초를 충분히 파악한 2시간 뒤부터 점수가 올라갈 것이다.
    - h = x - 2
    
    - y = 50 + 10h

    - y = 50 + 10(x-2)
    
    -> ReLu 대입
    - h = ReLU(x-2) = max(0, x-2)
    
- 공부시간 0시간일 때
    - x-2 = -2, (ReLU를 적용하면 0, 최종점수 = 50)

- 공부 시간 1시간일 때
    - x-2 = -1, (ReLU를 적용하면 0, 최종점수 = 50)

- 공부시간이 2시간일 때
    - x-2 = 0, (ReLU를 적용하면 0, 최종점수 = 50)

- 공부시간이 3시간일 때
    - x-2 = 1, (ReLU를 적용하면 1, 최종점수 = 60)

- 공부시간이 4시간일 때
    - x-2 = 2, (ReLU를 적용하면 2, 최종점수 = 70)

- 2시간 이하의 공부시간이라면 굳이 패턴을 파악하지 않고 50점 유지

- 2시간 초과의 공부시간이라면 시간에 따른 점수 증가

<br>

## 3-2) 딥러닝

- 공부 기록으로 시험 점수를 예측하는 신경망 만들기
- 입력값은 3개 (공부시간, 풀어본 문제 수, 복습 횟수)
- 값은 (2,3,1)이라고 가정
- 신경망에 사용되는 데이터 `X1`, `X2`, `X3` = [2, 3, 1]

- 은닉층은 2개, 뉴런은 3개를 사용하여 딥러닝을 구성해보겠다.

- 첫번째 은닉층, 뉴런 3개가 각각 계산하겠다.

1. 세 뉴런 모두가 x의 특성값인 [2,3,1]을 받는다.
    - 단, 각각의 뉴런은 가중치와 편향이 다르기 때문에 다른 결과를 얻는다.

2. 첫 번째 뉴런, 가중치는 [1,1,-1] 편향은 -1로 가정하면
    - z1 = (1x2) + (1x3) + (-1x1) -1 = 3
    - h1 = ReLU(3) = 3

3. 두 번째 뉴런, 가중치는 [-1, 1, 1] 편향은 0으로 가정
    - z2 = (-1x2) + (1x3) +(1x1) +0 = 2
    - h2 = ReLu(2) = 2

4. 세 번쨰 뉴런, 가중치는 [1, -1, -1], 편향은 1로 가정
    - z3 = (1x2) + (-1x3) + (-1x1) +1 = -1
    - h3 = ReLu(-1) = 0

|뉴런|가중합 + 편향|ReLU 적용 후|
|---|---|---|
|뉴런 1|3|3|
|뉴런 2|2|2|
|뉴런 3|-1|0|

-> 첫 번째 은닉층의 출력값은 [3, 2, 0]의 값   

-> 두 번쨰 은닉층에서 사용할 중간값을 의미한다.

-> 두 번째 은닉층 : 앞에서 나온 중간값 [3, 2, 0]을 받는다.

- **첫 번째 뉴런 :** 
    - 첫번째 은닉층은 원래 데이터 [2, 3, 1]을 받았지만, 
    - 두 번째 은닉층에서는 첫번째 은닉층의 결과인 [3, 2, 0]을 받아서 계산한다.

- u1 = (1x3) + (1x2) + (1x0) -1 = 4
- a1 = ReLu(4) = 4

- **두 번째 뉴런 :**
    - u2 = (-1x3) + (1x2) + (1x0) + 0 = -1
    - a2 = ReLu(-1) = 0

- **세 번째 뉴런 :**
    - u3 = (1x3) + (-1x2) + (1x0) +1 = 2
    - a3 = ReLU(2) = 2

|뉴런|가중합 + 편향|ReLU 적용 후|
|---|---|---|
|뉴런 1|4|4|
|뉴런 2|-1|0|
|뉴런 3|2|2|

-> 두 번째 은닉층의 출력은 [4, 0, 2]

-> 두 개의 은닉층을 활용하여 최종 출력층을 만들어본다면   
    --> 출력층은 마지막 (두 번째 은닉층)에서 나온 [4, 0, 2]를 받는다.    
    --> 출력층도 마찬가지로 뉴런의 가중치를 [10, -5, -5], 편향을 20이라고 가정하면   
    --> y = (10x4) + (-5x0) + (5x2) + 20 = 70점   
    --> 최종 예측점수는 70점으로 볼 수 있다.


```text
지금까지의 순서 정리

1. 입력층 -> 학생의 정보 전달 -> [2, 3, 1]
2. 첫 번쨰 은닉층 -> 뉴런 3개가 각 가중합과 편향 계산 -> [3, 2, -1]
3. 첫 번째 은닉층의 ReLU -> 음수 결과를 0으로 변경 -> [3, 2, 0]
4. 두번째 은닉층 -> 뉴런 3개가 각 가중합과 편향을 계산 -> [4, -1, 2]
5. 두 번째 은닉층의 ReLU -> 음수 결과를 0으로 변경 -> [4, 0, 2]
6. 출력층 -> 마지막 가중합과 편향을 계산 -> 예측 점수 70점

- 출력층의 예측 점수와 실제 점수를 비교한 뒤 가중치와 편향을 수정한다.
- 이 학생의 실제점수가 80점이었다면,
- 예측값 : 70점
- 실제 정답 : 80점
- 제곱 오차 = (70-80)^2 = 100
- -> 이 오차를 바탕으로 다시 각 가중치와 편향의 기울기 계산
```

# 4. 선형변환과 레이어

> **1. 아핀변환**

- 선형 변환 결과에 일정한 벡터나 숫자 `b`를 더하는 계산

- 입력을 조합한 뒤에 기준 위치를 옮긴다.

- `T(x) = xW + b`

- 선형 결과 [6,6]에 b = [1, -2]를 더하면 [7, 4]

- 왜 쓰냐? 화면 속 점 [3,2]를 가로, 세로가 n배 늘어났고 옮긴다고 가정 하에 아핀 변환을 사용할 수 있다.

<br>

> **2. 뉴런**
- 뉴런은 입력을 받아 출력 하나를 만드는 계산 단위
- ex) z = x1w1 + x2w2 + b

- 학생의 [출석, 과제] 기록 [3, 2]를 받아 중간 값(은닉츨 출력 결과)를 만드는 계산기가 있다.
- 가중치 [1, 2]를 곱해 3+4=7을 만들고 편향 -4를 통해 3을 얻는다.

<br>

> **3. 레이어와 신경망**
- 레이어 : 여러 뉴런을 모아 놓은 계산 단계

- 신경망 : 이런 계산들을 연결한 모델
- 학생의 기록 [3,2]를 단계별 계산을 하면
- 첫 단계의 뉴런 두 개가 각각 3과 -3을 만들고 ReLU를 거쳐 3, 0을 만들어 내면 
- 두 번째 단계에서는 [3, 0]을 이어받아서 3x2 + 0x(-1) +1 =7을 만든다.
- 학생 기록-> 중간 숫자 -> 최종 점수 ; 이 단계가 레이어

<br>

> **4. 활성화 함수**

- 활성화 함수는 뉴런의 가중합에 편향을 더한 값을 다시 바꾸는 규칙

- ex) `z = xw + b`를 구하고 난 뒤 `a=f(z)`를 계산
- 학습실 이용시간을 4시간 초과한 경우 금액을 부과하기 위해 따로 기록을 남긴다고 가정하면
- z=-4를 계산, 3시간을 이용했다면 z=-1로 추가적인 금액은 부과하지 않겠다.
- 이렇게 이미 계산돤 식에 임의의 식을 더해서 그 기록과 규칙을 바꾸려고 하는게 활성화 함수다.

<br>

> **5. 비선형 함수**

- 비선형 함수는 선형변환이 지켜야 하는 덧셈 및 배수 관계를 모두 만족하지 않는 함수
- 추가 이용시간 y = ReLU(이용시간 - 4)를 계산한다고 가정하면
- 3시간 이용자 수, 4시간 이용자 수는 추가시간이 0인데 5시간, 6시간 이용자 수는 1시간, 2시간
- 이용시간이 한 시간 늘어나도 기준시간은 결과가 그대로이기 때문에 4시간 전까지 올바른 선형관계를 보이기 어렵다.

<br>

> **6. 은닉층**

- 입력과 최종 출력 사이에서 중간 값을 만드는 계산단계

- 은닉이라는 단어가 들어가 있지만 print()로 중간값을 확인 할수는 있음
- 학생의 출석 및 과제 기록이 [3, 2]로 최종점수를 바로 만들지 않고 중간계산을 거쳐서 검토한다고 가정해보면
- 두 뉴런으로 [3, -3]값을 만든 뒤 ReLU를 적용하여 [3, 0]을 만든다. -> 이 과정을 은닉층이라고 부른다.
- 출력층(최종 산출은)은 이 [3,0]을 조합하여 최종점수를 만든다.
- 실제 신경망 계산에서는 입력을 여러 중간값으로 바꾸어 계산을 진행한다.

<br>

> **7. 출력층**

- 출력층은 모델의 최종 결과를 만드는 계산 단계

- 앞 단계에서 학생의 중간값 H = [5, 3]을 얻었다고 가정해보면 이 각 컬럼에 대한 점수들을 가지고 실제 점수에 반영해보겠다.
- 10점 만점이라고 가정하고 가중치를 [2, -1], 편향을 1로 가정하면
- 5x2 + 3x-1 +1 =8점, 최종젃으로 학생의 점수는 8점을 나타낼 수 있다.
- 출력층에 ReLU가 없다면 만약에 H=[0, 3]이면 0-3+1=-2로, 최종 출력값은 0이 아니라 -2로 계산될 수 있다.

<br>

> **8. 순전파**
- 순전파는 입력부터 최종 출력까지 계산을 앞 방향으로 진행하는 과정

- 학생기록 [3, 2]를 모델에 넣고 계산결과를 순전파로 따라가 보면

1. 가중합과 편향을 계산 Z1 = [3, -3]

2. ReLU를 적용하여 H = [3, 0]을 만들고
3. 출력층에서 3x2 + 0x(-1) +1 =7을 산출한다.
4. 1 -> 2 -> 3 순서의 이 과정을 순전파라고 부른다.

- 예를 들어, 문의 한 건을 [배송, 환불, 기타] 중 하나로 분류해야 한다면

- 이렇게 클래스별로 확률을 만든 뒤 가장 큰 확률을 가진 0.66(배송)을 선택하겠다.

> **4. Argmax 아그맥스**
- 가장 큰 값이 있는 위치번호를 찾는 연산

- 가장 큰 값은 0.6이고 위치는 두 번째이다.
- 따라서 Python에서 표현하면 `np.argmax(p)`=1을 반환한다.
- 읽을 때에는 1번 환불이라고 읽으면 된다.
- 확률과 이름을 한번에 같이 표현 할 때 쓴다.

> **5. 조건부 확률**
- 특정 조건을 만족하는 경우만 모아서 보는 확률
- P(구매|장바구니 추가) = 장바구니 추가한 고객이라는 조건에서 구매한 확률, 세로줄 뒤가 조건
- 장바구니 추가 고객 6명 중 4명이 구매했다면 관측 구매 비율은 4/6=0.66 정도
- 단, 고객 10명 기준이 아니라 장바구니를 추가한 고객 6명을 기준으로 계산했다는 점을 알고있어야한다.

<br>

> **6. 베르누이 분포**
- 결과가 두 가지일 때 한 번의 결과를 0 또는 1로 나타내는 확률 모형

- 계산식 Y = 1에서, p, y = 0에서 확률은 1-p
- kant 수업에서 한 학생이 과제를 제출했지만 확인한다고 해보면 제출은 1, 미제출은 0으로 기록한다.
- 제출확률을 p=0.6으로 보면 제출에 0.6, 미제출에 0.4라는 점수를 부여한다.
- 이처럼 한 가지 결과를 두 가지로 표현하는 것이 베르누이 모형이다.

<br>

> **7. Likelihood (우도)**
- 이미 관측한 데이터를 고정해놓고, 파라미터에 따라 그 데이터에 부여되는 확률을 비교하는 함수

- y = [1, 0, 1, 1, 0], p=6이면,
- L(0.6) = 0.6 x 0.4 x 0.6 x 0.6 x 0.4 = 0.03456
- 이 경우 L(p)는 p를 넣었을 때의 우도라고 읽을 수 있다.
- 위의 계산식을 말로 풀어보면
- 다섯 개의 과제 제출기록이 [1, 0, 1, 1, 0]이라고 하면 이 기록을 그대로 공통 제출 확률 두 개를 비교한다.
- p=0.6이면 실제 기록에 준 확률의 곱은 0.6 x 0.4 x 0.6 x 0.6 x 0.4 = 0.03456이고
- p=0.8이면 실제 기록에 준 확률의 곱은 0.8 x 0.2 x 0.8 x 0.8 x 0.2 = 0.02048이다.
- 제출 확률 80로 설정을 해놓았다면 제출자에게는 유리하지만 미제출 두 명에게 20%씩만 준다.
- -> 왜 쓸까? -> 어느 모델의 설정한 값이 지금 현재 기록에 더 잘 맞는지 숫자로 비교하고 싶다.

<br>

> **8. Probability와 Likelihood(우도)의 관점**
- 두 개념은 확률식을 서로 다른 관점에서 바라본다.

- Probability는 모델을 정해두고 가능한 결과를 살펴보는 방법이라면
- Likelihood는 실제 출력된 결과를 보고 모델의 파라미터 값을 보겠다는 의미
- 확률관점에서 p=0.6일 때라고 가정하면 이 0.6이라는 숫자값이 중요하다. 
- 구매 확률이 60%야? 라는 질문을 던진다면
- Likelihood의 관점에서는 실제 구매, 미구매 기록을 고정한 상태에서 L(0.6), L(0.8)을 비교하겠다는 의미
- 질문 : 수업 전에 이번 AI기초 수학과제를 제출할 확률을 0.6으로 설정했다면 원우가 이번 과제를 제출할 확률은? ; **확률 관점**
- 수업이 끝나고 난 뒤에 [1,0,1,1,0]이라는 실제 기록을 확인한 뒤, p=0.6과 p=0.8 중 어느 설정이 이 기록에 더 큰 확률을 주는지?라고 물어본다면 **우도의 관점**

<br>

> **9. 파라미터 후보와 후보 비교**
- 파라미터의 후보라느 것은 시험해볼 파라미터 값을 의미한다.

- 각 후보에 같은 데이터를 넣어 우도를 구한 다음에 가장 큰 우도를 주는 후보를 선택한다.
- p=[0.2, 0.4, 0.6, 0.8]의 우도는 순서대로 [0.005, 0.023, 0.034, 0.020]이다.
- -> 그렇다면 가장 큰 우도로 연결된 후보는 p=0.6이다.
- 이 계산식을 말로 풀어보면
- [1,0,1,1,0]에 대한 제출확률을 p=[0.2, 0.4, 0.6, 0.8] 산출하면 우도는 [0.005, 0.023, 0.034, 0.020]이다.
- 따라서 제출 확률에 대한 우도값이 가장 큰 것은 p=0.6이기 때문에 지금 [1, 0, 1, 1, 0] 기록에 더 잘맞는 설정값을 찾는 일(p=0.6)이다. 
- p가 무조건 높다고 좋은 것은 아님(p=0.8은 탈락)

<br>

> **10. 최대우도추정과 MLE**
- 관측 데이터의 우도가 가장 커지는 파라미터를 찾는 방법

- 공통 p를 사용하는 독립 베르누이 모형에서는 MLE = 구매 수 / 전체 고객 수
- 구매 3명, 전체 5명이면 3 / 5 = 0.6 -> 이 모형에서는 0~1 사이에서 0.6이 우도를 가장 크게 만든다.
- 예를 들어, 예약 방문 기록이 [1,0,1,1,0]이라고 보면 방문 3명, 미방문 2명이 모든 예약에 같은 방문확률 P를 사용하겠다.고 가정해보면
- 각 결과가 독립인 베르누이 모형에서는 우도를 가장 크게 하는 P가 방문 수 / 전체 수인 3/5=0.6
- 따라서 0.6이 최대우도추정값이고, 그 때 전체 기록의 우도는 0.034 정도
- -> 사람이 임의로 정한 확률 대신에 관측 자료 결과에 근거하여 파라미터를 정하기 위해서 최대우도추정을 기준으로 사용한다.

<br>

> **11. 인덱스와 Argmax**
- 인덱스는 배열의 위치 번호, `np.argmax()`는 가장 큰 값 자체가 아니라 그 값이 들어있는 위치 번호를 확인

- 우도 배열 [0.005, 0.023, 0.034, 0.020]이라고 가정해보면
- 가장 큰 우도는 0.034이며, 순서는 세 번째에 있다는 것을 알기 위함
- -> 가장 좋은 평가값을 빠르게 찾고, 그 뒤 값을 만든 설정까지 빠르게 찾기 위함

<br>

> **12. 로그**
- 어떤 밑을 제곱하면 이 값이 되는가를 알려주는 연산자

- 예를 들어, 2를 제곱하면 8이니까 밑이 2인 8의 로그는 3이다.
- 그렇다면 우도랑 무슨 상관이냐?
- 예약 3건의 실제 결과에 확률이 0.8, 0.7, 0.7이라고 가정해보면
- 우도는 이 세 값을 곱한 0.392값을 의미한다.
- 이 우도의 자연로그는 ln(0.392)로 구할 수 있고 ln(0.8) + ln(0.7) + ln(0.7)로 얻을 수 있다.
- 즉, 로그의 특성을 이용하면 확률을 모두 곱하는 과정을 확률의 로그를 더하는 과정으로 바꿀 수가 있다.
- 기록이 매우 많아서 계속 곱해서 0에 한도끝도 없이 가까워지면 구분하기 어려우니까
- 같은 비교지만 로그를 써서 안정적으로 계산하겠다는 의미이다.

<br>

> **13. 로그우도(Log Likelihood)**
- 우도에 자연로그를 적용한 값

- 각 관측 확률의 자연로그를 더해서도 같은 값을 얻는다.
- 같은 데이터에서는 큰 로그우도를 선호한다.
- q = [0.8, 0.7, 0.7]이면 L=0.392고, ln(L) = ln(0.8) + ln(0.7) + ln(0.7) = -0.936이다,
- 코드에서는 np.sum(np.log(q))를 사용할 수 있다.
- 예를 들어 다른 모델이 같은 세 결과에 각각 0.5를 주면 우도는 0.125
- 로그 우도는 약 -2.0794 값
- -0.9365 > -2.0794이기 때문에 첫 모델을 선택하려고 한다.
- 우도로 비교해도 0.392 > 0.125보다는 크기 때문에 같은 선택을 한다.

<br>

> **14. 같은 데이터에서의 모델 비교**
- 같은 고객의 같은 실제 결과에 대해 각 모델이 부여한 우도를 비교하겠다.

- 한 고객에게 더 좋은 확률을 준 모델이 다른 고객 또는 전체 데이터에서 항상 좋은 것은 아니다.
- 실제값 [1,0,1]에서 A의 관측확률 [0.8, 0.6, 0.6]은 우도 0.288
- B의 관측확률 [0.6, 0.8, 0.5]는 0.240 -> 이 두 모델을 비교했을 때는 A의 우도값이 높으니까 A 모델을 선택하겠다.

# 6. 손실함수

> **1. 손실함수와 Loss**
- 모델의 예측을 실제 정답과 비교하여 숫자로 평가하는 규칙

- 금액 예측은 실제값과 예측값의 차이로 MSE를 구할 수 있다.
- 구매여부와 상품 종류는 실제 정답에 주어진 확률로 BCE 또는 CE를 구할 수 있다.
- 문제 종류에 맞게 계산 규칙을 선택한다.
- 예를 들어 배달 시간 예측 모델 두 개를 비교하겠다고 가정해보면
= 실제 시간은 [10, 20, 30]분이고, 예측 시간은 [12, 18, 27]분이라면
- 각 주문에서 실제 시간과 예측시간의 차이를 제곱하면 [4, 4, 9]다. -> 평균을 계산해보면 17/3 = 5.66
- 같은 주문에서 B의 평균제곱오차가 8.667이라면 5.66인 A모델이 더 좋았다고 평가할 수 있다.
- 손실함수는 모델의 예측을 비교하고 학습 중 어떤 것을 줄여야하는지 정하는 역할을 한다.

<br>

> **2. 제곱오차합과 SSE(Sum of Squared Error)**
- 제곱 오차를 모두 더한 값

- 제곱 오차 [4,4,9]의 SSE는 17이다.
- 배달 3건에 대해서 A모델의 제곱오차가 [4,4,9], B의 제곱오차가 [1, 16, 9]라고 가정해보면
- A의 합계는 17, B는 26 -> 이 합계가 의미하는 것이 SSE
- 같은 세 건에 대해서는 A의 전체 제곱오차가 더 작다.
- B가 비록 첫 주문을 A모델보가 더 잘 맞췄더라도 전체 합계에서는 A가 더 좋은 모델일 수 있다.
- SSE를 전체 주문 건수로 나누면 MSE가 된다.
- 그러면 이걸 왜 하느냐?
- -> SSE를 통해 MSE를 구할 수 있고, 합계가 커진 이유 자체가 오차인지, 데이터의 수에 영향을 받았는지 구분할 수 있다.

<br>

> **3. 평균제곱오차 MSE(Mean Squared Error)**
- 제곱오차의 평균

- 각 고객의 오차를 제곱하고 모두 더한 뒤, 전체 고객 수로 나눈다.
- 배달 세건의 실제 시간이 [10, 20, 30]분이고, 예측이 [12, 18, 27]분이면
- 실제 예측은 [-2, 2, 3], 각 오차의 제곱은 [4, 4, 9] 합계 17을 3(전체 고객 수)으로 나누면 5.66
- 다른 B모델의 MSE가 8.66이라면 A모델을 선택하는 것이 맞다.
- 그렇다면 왜 중요하게 배우는 건가?
- -> 여러 수치의 예측 제곱오차를 하나의 평균으로 요약해 비교하기 위해서다.
- -> 오차를 전체 수로 평균 내기 때문에 각 한 건에 대한 오차범위를 대략적으로 파악할 수 있다.

<br>

> **4. MSE의 단위**
- 오차를 제곱하면 단위도 제곱하면 된다.

- 단위가 만원 단위였다면 제곱오차의 대한 해석도 (만원)^2 단위로 읽으면 된다.

<br>

> **5. 이진 교차엔트로피와 BCE**
- Binary Cross Entropy : 구매 / 미구매 두가지 결과를 구분하는 분류 손실함수

- 한고객의 BCE는 실제 정답 확률에 음의 로그를 적용한 값
- 예를 들어, 두 예약자에 실제 방문 결과가 [1, 0]이고, A의 방문 확률이 [0.8, 0.3]이라고 가정하면
- 첫 번째 손님의 손실은 -ln(0.8) = 약 0.223, 둘째는 미방문이니까 -ln(0.7) = 약 0.356정도
- 평균 BCE값은 약 0.289정도
- B가 두 사람 모두에게 방문 확률 0.5를 주었다면 두 손실은 각각 약 0.6931로 평균도 0.6931로 나타난다.
- 같은 두 예약 확률에서는 BCE가 작은 A모델을 선택한다.
- 왜 쓰냐?
    - 두 예측 결과를 학습하고 평가할 기준으로 쓴다. 
    - 각 정답에 어느 정도의 확률을 부여했는지 알 수 있다.

<br>

> **6. 범주형 교차엔트로피와 CE**
- Categorical Cross Entropy : 여러 종류 중 실제 정답이 하나인 분류에 쓰이는 손실
- 상품 B의 정답이 수박 [배, 수박, 사과] 확률이 [0.2, 0.6, 0.2]라면 CE = -ln(0.6) = 약 0.511
- 예를 들어, 과일 종류를 [배, 수박, 사과] 순서로 분류한다고 했을 때
- 첫 문의의 실제 정답은 수박이고, 예측확률이 [0.2, 0.6, 0.2]일 때``, 정답인 수박의 0.6을 선택하여 
- -ln(0.6) = 약 0.511을 계산한다.
- 두 번째의 정답 확률이 0.8이라면 CE = 0.2231, 두 과일 선택의 평균을 내보면 0.367 정도
- 왜 쓰느냐?
    - 과일 선택처럼 대상마다 열의 확률을 고르고, 대상별 손실을 평균내는 계산을 활용할 수 있다.

<br>

> **7. 예측 클래스와 손실의 차이**
- 예측 클래스는 모델이 최종적으로 선택한 종류

- 손실은 실제 정답에 준 확률을 평가한 값
- 정답을 맞추면 손실이 0이냐? -> 아님
- 예를들어 실제 구매고객에게 확률 0.9와 0.6을 주면 임계값 0.5에서 둘 다 구매로 예측`
- 하지만 BCE는 약 0.105와 0.511로 다를 수 있음
- 즉 -> 정답을 맞췄다는 사실만으로 예측의 품질을 알 수가 없기 때문에 손실점수를 확인해야한다.
- 두 가지 사실, 정답을 맞췄는가? / 확률 예측 자체가 얼마나 좋은가? 에 대한 답을 할 수 있다.

<br>

> **8. 정규분포(가우시안)**
- 평균을 중심으로 좌우가 대칭인 종 모양의 연속형 분포

- 예를 들어보면 배달 모델에서 주문 도착 시간을 20분으로 예상했다고 가정하면 
- 실제 배달 시간이 19분, 21분처럼 약간의 오차가 발생할 수는 있다.
- 비슷한 조건의 주문에서 작은 차이는 자주, 큰 차이는 드물게 나타난다고 설명하기 위해 정규분포를 가정할 수 있다.

# 7. 미분과 Gradient 

- 작업시간으로 생산량 예측하기
- 과거에 2시간 작업해서 10개를 만든 기록이 있다고 가정해보자
- 입력 x는 2시간, y는 10
- 처음 모델에는 시간당 3개를 만드는 모델을 설계한다고 가정해보면

- y = wx
- y = 3 x 2 = 6

- 입력 2 -> 주어진 작업 기록으로 고정
- 정답 10 -> 비교기준으로 고정
- 가중치 w, 3 -> 학습하여 조절할 값

- 예측값 y^ -> w를 바꾸면서 계산


> **1. 손실** 

- 모델이 예측값과 실제값 사이에서 틀린 정도를 나타냄
- 보통 차이를 계산하고 제곱함

- L(w) = (y-y_pred)² = (10-2w)²
- L(3) = (10-6)² = 16
- X = 2, Y=10, W=3이라면, 예측값은 6, 정답과 예측의 차이는 4
- 그냥 4라고 하면 되는데 왜 제곱을 하는가?
- -> 정답과 -4만큼, +4만큼이 구분되어야 하기 때문에 제곱을 활용

|가중치 W|예측 y_pred = 2w|차이(10-y_pred)|손실|
|---|---|---|---|
|2|4|6|36|
|3|6|4|16|
|4|8|2|4|
|5|10|0|0|
|6|12|-2|4|
|7|14|-4|16|

- -> 손실의 값을 보고 방향성을 알 수가 없음

- w=3과 w=7은 모두 손실이 16이지만, w=3에서는 w를 늘려야 정답인 5에 가까워지고
- w=7에서는 w를 줄여야 5에 가까워진다.
- 손실은 어느정도 틀렸는지를 알려주고, 어느 방향으로 수정해야하는 지는 따로 확인이 필요하다.
- 어느 방향으로 수정해야하는지는 미분을 통해 알 수 있다.

<br>

> **2. 변화율**

- 변화율 : 변한 양을 비교

- 같은 20리터라도 채우는 시간이 다르다면 다르다.
- 물통의 물이 1분일 때 10리터, 3분일 때 30리터였다면 2분 동안 20리터 증가했다.
- 1분당 평균 증가량은 10리터
- 시간이 입력이고 물의 양을 출력이라고 보면, 분모는 시간, 분자는 물이 얼마나 늘었는지
- 변한 양을 같은 기준으로 비교하려고 나눈다.
- `f(x) = 2x + 1`

|입력 x|출력 계산|출력 f(x)|
|---|---|---|
|1|2 x 1 + 1|3|
|2|2 x 2 + 1|5|
|3|2 x 3 + 1|7|
|4|2 x 4 + 1|9|

- x가 1에서 3으로 변하면 입력은 2 증가하고, 출력은 4 증가한다.

- -> 입력 1단 평균적으로 2씩 증가하며, 어느 구간을 선택하여도 변화율이 2
- 그래프로 그리면 기울기가 항상 일정한 직선이 된다.

<br>

> **3. 미분**

- 미분 : 지금 위치의 변화율을 나타냄

|구간|출력 변화량|평균 변화율|
|---|---|---|
|1 -> 2|4 - 1 = 3|3 / 1 = 3|
|2 -> 3|9 - 4 = 5|5 / 1 = 5|
|3 -> 4|16 - 9 = 7|7 / 1 = 7|

- 같은 1만큼 움직여도 결과가 달라짐

- 이번에는 x=3으로 최대한 근처값을 수정

|구간|출력 변화량|평균 변화율|
|---|---|---|
|3 -> 4|1|(16 - 9) / 1 = 7|
|3 -> 3.1|0.1|(9.61 - 9) / 0.1=6.1|
|3 -> 3.01|0.01|(9.0601 - 9) / 0.01 = 6.01|
|3 -> 3.001|0.001|(9.00601 - 9) / 0.001=6.001|

- 구간을 줄일 수록 변화율이 6에 가까워짐

- x=3에서의 순간 변화율은 6이고, 이렇게 한 점을 찍었을 때 순간변화율을 구하는 것이 미분임.

<br>

> **4. 필요한 미분 공식**
- 변화가 없으면 기울기 0
- f(x) = 5면, x에 1, 100, 1000을 넣어도 결과는 5
- x를 바꿔도 출력이 바뀌지 않으면 도함수는 0
- f(x)=3x+5에서는 x가 1 증가할 때마다 결과가 3씩 증가한다. -> 도함수는 3
- +5 그래프는 그래프의 전체 높이를 높일 뿐 기울기를 바꾸지 않는다.

|원래 함수|도함수|이해할 점|
|---|---|---|
|5|0|변하는 값이 없음||
|x|1|입렵이 늘어난  만큼 출력도 증가||
|3x+5|3|x앞에 3이 변화율|
|x²|2x|현재 위치에 따라 변화율이 달라짐||
|x³|3x²|지수 3을 내리고 지수를 1로 줄임||

- f(X) = 2x² -4x +3

- x ^2의 도함수는 2x, 2x²의 도함수는 4x

- -4x의 도함수는 -4(마이너스도 함께 데려감)
- 상수 3의 도함수는 ㅇ
- f'(x) = 4x-4
- f'(2) = 8-4 = 4

> **5. 손실함수 미분하기**
- x=2와 y=10을 고정, 편향이 없는 모델에서 바뀌는 값은 w
- 이번에는 x가 아닌 w에 대해 손실을 미분
- y_pred = 2w
- L(w) = (10-2w)²

|곱하는 항|결과|
|---|---|
|10x10|100|
|10x(-2w)|-20w|
|(-2w) x (-2w)|4w²|

- 가운데 2개의 항을 더하면
- L(w) = 4w² -40w + 100
- -> 앞에서 배운 공식으로 한 항씩 미분하면 4w²은 8w, -40w는 -40, 100은 0
- L'(w) = 8w - 40
- L'(3) = 24-40 = -16
- -16은 w=3일 때 현재 위치에서의 손실 변화율 

<br>

> **6. 편미분**
- 편미분 : 하나씩 바꾸어 보는 것을 의미

- 조절할 숫자가 두 개라면
- x=2, y=10은 그대로라고 가정하고, w=3, b=1이면, 예측은 7이고 손실은 9
- y_pred = 2w + b = 2x3 +1 = 7
- L(3, 1) = (10-2x3-1)¹ = 9
- 손실은 w와 b 모두에 영향을 받는다. w의 영향만 보려고 b를 그대로 두고
- b의 영향만 보려면 w를 그대로 두어야한다.
- 목욕탕에서 온수와 냉수를 동시에 튼다고 하면, 무엇때문에 온도가 어떻게 변화했는지 구분하기 어려움
- 한 손잡이를 멈추고, 다른 손잡이만 돌려서 각각의 영향을 살펴보려고 함

|바꾸는 값|고정하는 값|새 예측|새 손실|
|---|---|---|---|
|변경 없음|w=3, b=1|7|9|
|w만 3.01로|b=1|7.02|8.88|
|b만 1.01로|w=3|7.01|8.94|

- 둘 다 손실은 줄었지만 감소량이 다르다. 즉 w와 b의 값을 고정하고 각각을 변화시키면

- 어떤 값이 n만큼 줄었을 때 영향을 크게 보는지 볼 수 있다.

<br>

> **7. Gradient(기울기)**

- Gradient : 편미분 값을 모은 것
- 파라미터 순서를 [w, b]로 정했다면, 기울기도 [w에 대한 값, b에 대한 값] 순서대로 모음

- Gradient로 모델 한 번 고치기
- 방향은 알고 움직일 크기를 선택
- 학습률은 Gradient에 곱하는 작은 숫자로 한 번에 얼마나 바꿀지를 조절

- 0.01을 예시로 사용
- 새로운 값 = 현재 값 - 학습률 x 현재 기울기
- 기울기를 빼는 이유는 손실이 커지는 반대 방향으로 가기 위함 -> 이 방법과 계산식이 경사하강법의 업데이트 규칙임

- 가중치와 편향을 각각 계산
- w=3, b=1이며, 같은 위치에서 구한 Gradient는 [-12, -6]
- 새 w = 3 - 0.01 x (-12) = 3 + 0.12 = 3.12
- 새 b = 1 - 0.01 x (-6) = 1 + 0.06 = 1.06
- 다시 새 숫자로 예측과 손실을 계산
- 새 y_pred = 2 x 3.12 + 1.06 = 7.30
- 새 L = (10 - 7.30)² = 7.29

<br>

> **8. 학습률이 필요한 경우**
- 모든 경우를 같은 시작점 w=3, b=1, 손실 9인 상황에서 비교

|학습률|새 w|새 b|새 예측|새 손실|
|---|---|---|---|---|
|0.001|3.012|1.006|7.03|8.82|
|0.01|3.12|1.06|7.30|7.29|
|0.10|4.20|1.60|10.00|0|
|0.30|6.60|2.80|16.00|36|

- 0.001에서는 조금 움직이기 때문에 손실도 조금씩 감소
- 0.30에서는 너무 크게 움직였기 때문에 정답 10을 지나서 16으로 예측
- 여러번 고치게 되면 어떤 변화가 있을까?(학습률 0.01로 고정)

|업데이트 횟수|w|b|손실|
|--|---|---|--|
|0|3.000|1.000|9.00|
|1|3.120|1.060|7.29|
|2|3.228|1.114|5.90|
|3|3.325|1.162|4.78|

- 손실이 지속적으로 줄어드는 것을 확인하고 크게 바뀌거나 (Loss의 변화가 갑자기 커지거나)
- 학습률이 너무 큰 경우 손실이 9 -> 7 -> 5 -> 2 -> 이런 식으로 너무 크게 변화하는지 확인한다.

```python
# 입력과 정답은 고정

x=2
y=10
w=3.0
b=1.0
learning_rate = 0.01

# 1. 현재 예측과 손실을 계산
y_pred = w * x +b
old_loss = (y - y_pred) ** 2

# 2. 같은 현재 w, b에서 기울기 구하기
grad_w = 8 * w + 4 * b -40
grad_b = 4 * w + 2 * b -20

# 3. 기울기의 반대방향으로 값을 바꾸기
new_w = w - learning_rate * grad_w
new_b = w - learning_rate * grad_b

# 4. 바꾼 값으로 예측과 손실을 다시 계산
new_pred = new_w * x + new_b
new_loss = (y - new_pred) ** 2

print('기울기:', grad_w, grad_b)
print('새 w와 b:', new_w, new_b)
print('새 예측:', round(new_pred, 2))
print('손실:', old_loss, '->',  round(new_loss, 2))


# [결과]
# 기울기: -12.0 -6.0
# 새 w와 b: 3.12 3.06
# 새 예측: 9.3
# 손실: 9.0 -> 0.49
```

> **9. 회귀모델의 순전파를 따라가기**

### 9-1) 2시간 작업의 생산량을 예측하기

- 입력 x = 2는 작업시간, 실제 정답 y=10을 생산량이라고 가정하면
- 현재 모델은 w = 3, b = 1을 사용한다.
- u = wx -> 3 x 2 = 6
- y_pred = u + b -> 6 + 1 = 7
- L = (y - y_pred)² -> (10-7)² = 9
- 순전파는 입력에서 시작하여 예측을 구하는 과정을 의미

|구분|현재 지정할 값|역전파에서 필요한 이유|
|---|---|---|
|입력|x = 2|w의 국소 미분값으로 사용|
|곱셈 결과|u = 6|계산이 어떻게 이어졌는지 확인|
|예측|y_pred = 7|손실의 미분값을 구할 때 활용|
|정답|y = 10|예측과 비교할 기준|

- 각 중간 값에 개한 손실의 기울기를 계산한여 역전파에서 전달

- 손실에서 시작한다면 어떤 것을 미분해야 하는가?
- 예측값이 조금 달라지면 손실은 어떻게 달라지는가?
- 가중치 편향 고려하지 않고 y_pred의 값이 조금 바뀐다고 가정해보면

|예측값|손실 계산|손실|
|--|----|---|
|7.00|(10 - 7.00)²|9|
|7.01|(10 - 7.01)²|8.940|

- 예측을 0.01 늘렸더니 손실은 0.059 감소, 현재 기울기 -6으로 예상한 변화, -6 x 0.01에 가까운 수치


### 9-2) 가중치와 편향까지 기울기 전달하기
- 앞서 기울기 -6, ∂L/∂ŷ=−6의 계산식을 얻었다.
- ŷ = wx + b에서 w와 b가 각각 무엇을 바꿀 수 있는지?(x=2 고정)
- 가중치 w를 0.01 늘리면 예측이 2x0.01 = 0.02 늘어남
- 따라서 w에 개한 예측의 변화율은 2, 편향 b도 0.01 늘리면 예측도 0.01 늘어나기 때문에 변화율은 1
- ∂ŷ/∂w = x = 2, / ∂ŷ/∂b = 1
- -6x2 = -12와 -6 x 1 = -6값을 얻을 수 있는데

|현재 계산 대상|값|what|
|---|---|---|
|예측 ŷ|7|모델이 내놓은 답|
|손실 L|9|예측이 틀린 정도|
|∂L/∂ŷ|-6|예측을 조금 바꿀 때 손실의 변화율|
|∂ŷ/∂w|-12|w를 조금 바꿀 때 손실의 변화율|
|∂L/∂b|-6|b를 조금 바꿀 때 손실의 변화율|

- L(w, b) = (10 - 2w - b)²를 전개하여 미분하면

- ∂L/∂w = 8w + 4b - 40
- ∂L/∂b = 4w + 2b - 20


### 9-3) 역전파 다음에 가중치를 바꾼다.

- 기울기를 계산하는 일 / 적용하는 일 분리

- 역전파로 Gradient [-12, -6]을 얻었지만, 여전히 w와 b는 3, 1로 고정인 상태다
- 이 3,1을 업데이트 하는 규칙을 실행해야한다.
- 새로운 파라미터 = 현재 파라미터 - 학습률 x 기울기
- 학습률 - 한 번에 학습률만큼 크기를 조절하겠다는 의미
- 업데이틀를 진행한 뒤에는 다시 순전파를 시작함
- 새 w = 3 - 0.01 x (-12) = 3.12
- 새 b = 1 - 0.01 x (-6) = 1.06
- 새 y_pred = 3.12 x 2 + 1.06 = 7.30
- 새 L = (10 - 7.30)² = 7.29

|단계|계산하는 내용|이번 결과|
|---|---|---|
|순전파|현재 파라미터로 예측|7|
|손실 계산|예측과 정답의 차이 평가|9|
|역전파|w와 b의 기울기|-12와 -6|
|업데이트|기울기로 파라미터 변경|3.12와 1.06|
|다음 순전파|바뀐 모델로 다시 계산|예측 7.30과 손실 7.29|

- -> 왜 학습률이 0.001처럼 낮은 숫자일까?

- 현재 기울기는 지금 위치의 근처 정보, 한번에 너무 크데 바꾸면 손실이 갑자기 커질 수 있음


```python
# 코드로 회귀 역전파 확인하기

x, y = 2.0, 10.0
w, b = 3.0, 1.0
learning_rate = 0.01

# 1. 순전파의 손실계산
y_pred = w * x + b # <------------ 레이어 1
loss = (y-y_pred) ** 2

# 2. 손실에서 예측값으로(역전파)
dL_dy_pred = 2 * (y_pred - y)

# 3. 예측값에서 각 파라미터로(역전파)
dL_dw = dL_dy_pred * x
dL_db = dL_dy_pred * 1.0

print('예측과 손실:', y_pred, loss)
print('기울기:', dL_dy_pred, dL_dw, dL_db)
print('업데이트 전:', w, b)

# 4. 모든 기율기를 구한 다음 업데이트 진행
new_w = w - learning_rate * dL_dw
new_b = b - learning_rate * dL_db
new_pred = new_w * x + new_b
new_loss = (y-new_pred) ** 2

print('업데이트 후:', new_w, new_b)
print('새 손실:', round(new_loss, 2))

# [결과]
# 예측과 손실: 7.0 9.0
# 기울기: -6.0 -12.0 -6.0
# 업데이트 전: 3.0 1.0
# 업데이트 후: 3.12 1.06
# 새 손실: 7.29
```

```python
# 코드로 은닉층과 역전파 확인하기

import numpy as np

x, y = 2.0, 1.0
w1, b1 = 1.0, 0.0
w2, b2 = 0.5, 0.0

# 1. 순전파
a = w1 * x + b1
h = max(0, 0, a) # <------- 여기까지가 레이어 1, 뉴런 1개의 계산, 은닉층의 뉴런 하나가 입력을 받아 출력값 h를 만든다.
            # 뉴런이 3개? -> 같은 입력 x를 받지만 뉴런은 자기 가중치와 자기 편향으로 따로 계산
            # 은닉층 하나에 뉴런 3개 h1 = max(0.0, w1 * x + b1) / h2 = max(0.0, w2 * x + b2)...
            # 따라서 은닉층의 출력이 [h1, h2, h3] 앞에 뉴런을 차례대로 계산하는게 하나라 같은 층에서 나란히 계산하기 때문  

z = w2 * h + b2
p = 1.0 / (1.0 + np.exp(-z)) # <------------- 여기까지가 레이어 2

loss = np.logaddexp(0.0, z) -y * z # <------------- 손실은 레이어가 아님

# 출력층의 역전파
dL_dz = p - y # <-------------레이어 x, 출력층의 기울기 계산 
dL_dw2 = dL_dz * h
dL_db2 = dL_dz

# ReLU를 거쳐 은닉층으로 전달 <------------- 레이어 x, 출력층의 기울기 계산
dL_dh = dL_dz * w2
relu_grad = 1.0 if a > 0 else 0.0
dL_da = dL_dh * relu_grad
dL_dw1 = dL_da * x
dL_db1 = dL_da

print('중간값:', a, h, z)
print('확률과 손실:', round(p, 4), round(loss, 4))
print('첫 층:', round(dL_dw1, 4), round(dL_db1, 4))
print('출력층:', round(dL_dw2, 4), round(dL_db2, 4))

# [결과]
# 중간값: 2.0 2.0 1.0
# 확률과 손실: 0.7311 0.3133
# 첫 층: -0.2689 -0.1345
# 출력층: -0.5379 -0.2689
```
