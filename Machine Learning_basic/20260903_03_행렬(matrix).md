# [ 1. 머신러닝을 공부할 때 행렬을 알아야 하는 이유 ]

머신러닝 데이터의 일반적인 형태.

| 고객 | 나이 | 구매횟수 | 방문시간 | 구매금액 |
|---|---:|---:|---:|---:|
| A | 20 | 3 | 10 | 50000 |
| B | 30 | 5 | 20 | 80000 |
| C | 40 | 8 | 30 | 120000 |

구매금액 예측 예시.

입력 데이터:

- 나이
- 구매횟수
- 방문시간

예측 대상:

- 구매금액

머신러닝에서 입력값 → `X`

정답값 → `y`

```python
X = [
    [20, 3, 10],
    [30, 5, 20],
    [40, 8, 30]
]

y = [
    50000,
    80000,
    120000
]
```

`X` → 행과 열을 가진 **행렬(Matrix)**.

`y` → 한 방향으로 값이 나열된 **벡터(Vector)**.

머신러닝의 핵심 구조:

> 데이터 행렬 `X`와 가중치 `W`의 행렬 연산 → 예측값 계산 → 실제값 `y`와 비교 → 가중치 학습.

# [ 8. 차원 정리 ]

| 종류 | 예 | ndim | shape |
|---|---|---:|---|
| Scalar | `10` | 0 | `()` |

```python
import numpy as np

scalar = np.array(10)

vector = np.array([
    1, 2, 3
])

matrix = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

tensor = np.array([
    [
        [1, 2],
        [3, 4]
    ],
    [
        [5, 6],
        [7, 8]
    ]
])

print("scalar")
print("ndim:", scalar.ndim)
print("shape:", scalar.shape)

print("\nvector")
print("ndim:", vector.ndim)
print("shape:", vector.shape)

print("\nmatrix")
print("ndim:", matrix.ndim)
print("shape:", matrix.shape)

print("\ntensor")
print("ndim:", tensor.ndim)
print("shape:", tensor.shape)
```

[result]

```text
scalar
ndim: 0
shape: ()

vector
ndim: 1
shape: (3,)

matrix
ndim: 2
shape: (2, 3)

tensor
ndim: 3
shape: (2, 2, 2)
```

# [ 11. 행렬의 곱셈(Matrix Multiplication) ]

머신러닝에서 매우 중요한 연산.

NumPy:

```python
A @ B
```

또는:

```python
np.matmul(A, B)
```

<br>

## 행렬곱이 가능한 조건

행렬 `A`:

```text
(m, n)
```

행렬 `B`:

```text
(n, p)
```

행렬곱:

```text
A @ B
```

결과:

```text
(m, p)
```

즉:

```text
(m, n) @ (n, p)
         ↑    ↑
```

가운데 차원 `n` 일치 필요.

<br><br>

# [ 12. 실제 행렬곱 예시 ]

```python
import numpy as np

A = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

B = np.array([
    [1, 2],
    [3, 4],
    [5, 6]
])

print("A shape:", A.shape)
print("B shape:", B.shape)

C = A @ B

print(C)
print("C shape:", C.shape)
```

차원:

```text
A : (2, 3)
B : (3, 2)

(2, 3) @ (3, 2)
             ↑
        가운데 3 동일

결과 = (2, 2)
```

|---|---:|---:|



3명의 데이터에 각각 하나의 예측값 생성.

행렬곱의 장점:

> 수많은 데이터의 동시 계산.

# [ 18. Weight(가중치) ]

Weight:

> 각각의 Feature가 예측 결과에 얼마나 영향을 주는지를 나타내는 값.

가장 단순한 선형회귀 식:

```text
ŷ = wx + b
```

여기서:

```text
x = 입력값
w = weight
b = bias
ŷ = 모델의 예측값
```

예:

```text
시험점수 = 공부시간 × 5 + 30
```

```text
weight = 5
bias = 30
```

<br><br>

# [ 19. 여러 Feature가 있을 때 Weight ]

입력 Feature 3개:

```text
x₁ = 공부시간
x₂ = 수면시간
x₃ = 출석률
```

각 Feature마다 하나의 Weight 필요.

```text
ŷ = w₁x₁ + w₂x₂ + w₃x₃ + b
```

예:

```text
ŷ =
10 × 공부시간
+ 3 × 수면시간
+ 0.5 × 출석률
+ 20
```

따라서:

```text
XW

(n_samples, 3) @ (3, 1)

= (n_samples, 1)
```

Bias 추가:

```text
ŷ = XW + b
```

선형회귀의 핵심 구조.

# [ 21. Weight의 개수는 왜 Feature 개수와 같아야 할까? ]


```text
100개의 데이터
4개의 feature
```

따라서:

```text

```




```text
4 != 3
```

행렬곱 불가능.

Weight 차원의 의미:

> 입력 Feature와 Weight의 1:1 대응을 위한 구조.

# [ 22. Bias(절편) ]

Bias:

> 입력값과 상관없이 추가되는 값.

선형회귀:

```text
ŷ = wx + b
```

`b` → Bias.

예:

```text
ŷ = 2x + 10
```

입력값 `0`:

```text
ŷ = 10
```

Bias → 그래프의 **y절편 역할.**

<br><br>

# [ 23. 왜 Bias가 필요한가? ]

Bias가 없는 경우:

```text
ŷ = wx
```

모든 직선이 반드시:

```text
(0, 0)
```

통과.

현실의 데이터가 반드시 원점을 지나지는 않음.

따라서:

```text
ŷ = wx + b
```

Bias 추가.

모델이 더 자유로운 위치에서 데이터를 설명하도록 지원.

<br><br>

# [ 24. Bias와 Broadcasting ]

다중 출력 모델 예:

```text
X.shape = (100, 3)

W.shape = (3, 2)

X @ W
→ (100, 2)
```

출력 2개인 경우 bias:

```text
b.shape = (2,)
```

연산:

```text
(100, 2) + (2,)
```

NumPy가 bias를 각 행에 반복 적용.

→ **Broadcasting.**

# [ 25. 선형 회귀의 학습은 무엇을 학습하는 것인가? ]

선형회귀 모델:

```text
ŷ = XW + b
```

학습 대상:

```text
W
b
```

즉 머신러닝 학습:

> 실제 정답 `y`와 최대한 비슷한 예측값 `ŷ`를 만드는 Weight와 Bias 탐색 과정.

# [ 26. Loss Function ]

모델의 예측:

```text
ŷ
```

실제 정답:

```text
y
```

둘 사이의 차이 → **오차(error).**

```text
error = y - ŷ
```

오차를 하나의 숫자로 나타내는 함수 → **Loss Function.**

회귀의 대표 Loss → MSE.

```text
MSE = 평균((실제값 - 예측값)²)
```

모델의 목표:

```text
MSE가 작아지는 방향
```

으로 Weight와 Bias 변경.

<br><br>

# [ 27. Gradient Descent 관점 ]

학습 과정 단순화:

```text
1. Weight와 Bias 설정
        ↓
2. 예측값 계산
   ŷ = XW + b
        ↓
3. 실제값 y와 비교
        ↓
4. Loss 계산
        ↓
5. Loss가 감소하도록 W와 b 변경
        ↓
6. 반복
```

반복을 통한 모델 파라미터 학습.

```text

```
