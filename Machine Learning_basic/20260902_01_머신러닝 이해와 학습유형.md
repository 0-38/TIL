# [ 1. AI, 머신러닝, 딥러닝, 생성형 AI의 관계 ]

> **AI ⊂ 머신러닝 ⊂ 딥러닝 ⊂ 생성형 AI**


1. AI (**A**rtificial **I**ntelligence)   
: 사람처럼 학습하고 추론하고 판단하는 능력을 기계로 구현하는 컴퓨터 과학의 한 분야, 인공지능
2. 머신러닝(**M**aching **L**earning)    
: 데이터로부터 패턴과 규칙을 학습하여 새로운 데이터에 대해 예측, 분류에 대해 판단을 수행하는 기술
3. 딥러닝(**D**eep **L**earing)   
: 인공신경망(Artificial Neural Network, ANN)을 이용해 데이터의 복잡한 패턴을 학습하는 기술,    
비정형 데이터 처리하는데에 유용,   
인간의 뇌에서 뉴런(신경세포)이 서로 연결되어 정보를 전달하는 방식을 모방

4. 생성형 AI (Generative AI)   
: 학습한 패턴을 바탕으로 텍스트, 이미지, 코드 등의 새로운 콘텐츠를 생성하는 AI,   
대부분 딥러닝을 기반으로 동작

# [ 2. 머신러닝 정의 : 전통적 프로그래밍과의 차이 ]
> 명시적으로 규칙을 프로그래밍하지 않고, 데이터로부터 패턴을 학습하여 새로운 데이터에 대해 예측(prediction), 분류(classification)를 통해 판단하는 기술


|구분|전통적 프로그래밍|머신러닝|
|-|-|-|
|입력|데이터 + 규칙 (프로그램)|데이터 + 정답 (Label)|
|사람이 하는 일|규칙(프로그램)을 직접 작성 (수기)|데이터 전처리, 모델을 학습|
|컴퓨터가 하는 일|규칙에 따라 출력|데이터를 기반으로 패턴 (모델)을 학습|
|출력|결과 (Output)|학습된 모델 (Model)|

<br><br>

# [ 3. 머신러닝 유형 ]

> 1. 지도학습 (Supervised Learning)
- 정답이 있는 데이터를 이용해서 모델을 학습하는 방식
- 예측 종속변수가 범주형이면 분류, 연속형이면 회귀형

> 2. 비지도 학습 (Unsupervised Learning)   
- 정답이 없는 데이터를 사용해 데이터에 내재된 패턴이나 관계를 학습하는 방식
- 비슷한 데이터를 중심으로 clustering, 데이터를 더 적은 특징으로 표현 하는 차원축소(Dimension Reduction)

> 3. 강화학습 (Reinforcement Learning)
- 행동에 대한 보상과 벌점을 통해 더 나은 행동을 스스로 행동하는 방식
- ex) 게임 AI에서 정답은 보상을 주고 오답을 이루면 벌점을 주는 것을 반복하여 보상을 최대화하기 위한 방법을 학습함

# [ 4. 머신러닝의 구성요소와 기본 용어 ]

| 구성요소 | 용어 | 정의 |
|---|---|---|
| 데이터셋 | Dataset | 데이터의 집합 (독립변수 + 종속변수) |
| 데이터 | Data | 데이터셋을 구성하는 정보 (한 행의 정보) |
| 특성 | Feature | 데이터를 구성하는 정보들 (독립변수들) |
| 레이블 | Label | 종속변수 (모델이 예측해야 하는 정답) |
| 모델 | Model | 데이터를 받아 예측을 수행하는 함수 `f(x)` |
| 학습 | Training | 모델이 데이터와 정답의 관계를 학습하여 예측하는 과정 |

# [ 5. 머신러닝 프로젝트 진행 순서 ]

1. 문제 정의  
: 해결하고자 하는 문제 정의

2. 데이터 수집, EDA  
:  데이터 탐색(EDA, Exploratory Data Analysis) -> 데이터 특성 파악 /  
 결측치(Missing Value), 이상치(Outlier), 데이터 분포 등을 분석
3. 데이터 전처리   
: 결측치, 이상치 처리, 모델 학습 데이터 준비
4. 모델학습   
: 예측 모델 학습
5. 평가와 개선   
: 성능지표를 활용하여 평가 /
Feature
6. 배포와 운영

진행 순서는 직선적으로 진행하는 것이 아닌 모델 학습과정에서 문제가 나면 데이터 수집 또는 데이터 전처리 단계로 돌아갈 수 있음
