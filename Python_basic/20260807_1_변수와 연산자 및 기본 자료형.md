
# **1. 변수와 참조 메커니즘**

Python에서 가장 먼저 이해해야 하는 개념은 변수.

변수는 값을 직접 담는 상자라기보다 **객체를 가리키는 이름(Name)**으로 이해하는 것이 좋음.

스포츠 데이터를 예로 들면 선수 이름, 등번호, 득점, 도움 등을 각각 변수에 저장할 수 있음.

> ## **1-1 ) 변수 기본 사용법**

[ python : code ] "축구 선수 정보를 변수에 저장하는 방법"

```python
player_name = "우영"
player_number = 10
player_goals = 12
player_assists = 7
player_rating = 8.5
is_starting = True

print(player_name)
print(player_goals)
print(is_starting)
````

[ Result ]

```text
우영
12
True
```

| 변수               |      값 | 의미    |
| ---------------- | -----: | ----- |
| `player_name`    | `"우영"` | 선수 이름 |
| `player_number`  |   `10` | 등번호   |
| `player_goals`   |   `12` | 득점    |
| `player_assists` |    `7` | 도움    |
| `player_rating`  |  `8.5` | 평점    |
| `is_starting`    | `True` | 선발 여부 |

<br>

> ## **1-2 ) 변수와 객체의 관계**

```python
player_goals = 12
```

개념적으로는 다음처럼 이해.

```text
player_goals
      │
      │ 참조
      ▼
     12
  int 객체
```

즉 `player_goals`라는 이름이 정수 객체 `12`를 참조.

<br>

> ## **1-3 ) 변수 명명 규칙**

| 변수명            | 사용 가능 여부 | 이유           |
| -------------- | -------- | ------------ |
| `player_name`  | 가능       | 문자로 시작       |
| `_total_score` | 가능       | `_`로 시작 가능   |
| `player2`      | 가능       | 숫자를 뒤에 사용 가능 |
| `2player`      | 불가능      | 숫자로 시작       |
| `player score` | 불가능      | 공백 포함        |
| `for`          | 불가능      | Python 예약어   |

Python에서는 일반적으로 `snake_case` 사용.

```python
player_name
total_goals
match_score
average_rating
```

# **2. 동적 타이핑 Dynamic Typing**

변수의 기본 개념을 이해한 다음에는 Python이 변수의 타입을 어떻게 다루는지 이해해야 함.

Python은 자료형을 미리 선언하지 않는 **동적 타이핑 언어**.

> ## **2-1 ) 자료형을 미리 선언하지 않아도 됨**

[ python : code ] "선수 데이터를 자료형 선언 없이 저장하는 방법"

```python
player_name = "우영"
player_goals = 12
player_rating = 8.5
is_starting = True

print(type(player_name))
print(type(player_goals))
print(type(player_rating))
print(type(is_starting))
```

[ Result ]

```text
<class 'str'>
<class 'int'>
<class 'float'>
<class 'bool'>
```

<br>

> ## **2-2 ) 같은 변수에 다른 타입을 재할당할 수 있음**

[ python : code ] "재할당에 따라 변수의 참조 대상 타입이 달라지는 방법"

```python
player_status = 1

print(player_status)
print(type(player_status))

player_status = "Starting"

print(player_status)
print(type(player_status))
```

[ Result ]

```text
1
<class 'int'>
Starting
<class 'str'>
```

```text
처음

player_status
      ↓
      1
     int


재할당 후

player_status
      ↓
 "Starting"
     str
```

<br>

> ## **2-3 ) 동적 타이핑의 장점과 주의점**

| 장점         | 주의점                 |
| ---------- | ------------------- |
| 코드 작성이 간결  | 실행 중 타입 오류 가능       |
| 빠른 실험 가능   | 현재 타입을 추적해야 할 수 있음  |
| 데이터 분석에 편리 | 대규모 프로젝트에서 타입 관리 중요 |
| 자유로운 재할당   | 예상하지 않은 타입 입력 가능    |

# **4. 변수 재할당과 객체 상태 확인**

자료형까지 이해했다면 변수에 새로운 값을 넣었을 때 어떤 변화가 일어나는지 확인.

> ## **4-1 ) 변수 재할당**

[ python : code ] "선수 득점 값을 재할당하는 방법"

```python
player_goals = 10

print(player_goals)

```

[ Result ]

```text
10
11
```

```text
1단계

player_goals
      ↓
     10


2단계

player_goals
      ↓
     11
```

<br>

> ## **4-2 ) type()과 id()**

[ python : code ] "type과 id를 이용해 객체 상태를 확인하는 방법"

```python
player_score = 10

print(type(player_score))
print(id(player_score))

player_score = "10"

print(type(player_score))
print(id(player_score))
```

[ Result ]

```text
<class 'int'>
실행 환경에 따라 달라지는 정수값

<class 'str'>
실행 환경에 따라 달라지는 정수값
```

`type()`은 자료형 확인.

<br>

> ## **4-3 ) 재할당 흐름도**

```text

        ↓

        ↓
type(player_score)
        ↓
<class 'int'>
        ↓
player_score = "10"
        ↓
str 객체 "10" 참조
        ↓
type(player_score)
        ↓

```

# **10. 논리 연산자**

비교 연산자를 배운 다음 여러 조건을 결합하는 논리 연산자를 학습.

> ## **10-1 ) and, or, not**

| 연산자   | 의미            |
| ----- | ------------- |
| `and` | 모든 조건이 참일 때 참 |
| `or`  | 하나 이상 참이면 참   |
| `not` | 참과 거짓을 반대로 변경 |

<br>

> ## **10-2 ) 선수 출전 조건 판단하기**

[ python : code ] "여러 조건을 결합하여 선수 출전 가능 여부를 판단하는 방법"

```python
is_injured = False
stamina = 85

can_play = (not is_injured) and stamina >= 70

print(can_play)
```

[ Result ]

```text
True
```

결과 해석.

```text
is_injured = False
↓
not False
↓
True

stamina >= 70
↓
85 >= 70
↓
True

True and True
↓
True
```

<br>

> ## **10-3 ) 단락 평가**

```python
print(False and (10 / 0 > 1))
```

[ Result ]

```text
False
```

왼쪽 값만으로 결과가 결정되므로 오른쪽 식을 평가하지 않음.

# **12. 문자열 형식화**

> ## **12-1 ) 문자열 형식화 방식 비교**

| 방식             | 예시                       | 특징         |
| -------------- | ------------------------ | ---------- |
| `%` 방식         | `"득점: %d" % goals`       | 오래된 방식     |

| `f-string`     | `f"득점: {goals}"`         | 가장 직관적인 방식 |

# **13. 스포츠 선수 기록 종합 실습**

앞에서 배운 개념들을 하나의 코드로 연결.

> ## **13-1 ) 선수 경기 기록 계산하기**

[ python : code ] "선수 경기 기록을 계산하고 MOM 후보 여부를 확인하는 방법"

```python
player_name = "우영"

shots = 5
goals = 3
assists = 2

rating = 9.1
is_injured = False

attack_points = goals + assists
shot_accuracy = goals / shots * 100

is_mom_candidate = (
    attack_points >= 3
    and rating >= 8.0
    and not is_injured
)

print(f"선수 이름 : {player_name}")
print(f"슈팅      : {shots}")
print(f"득점      : {goals}")
print(f"도움      : {assists}")
print(f"공격포인트 : {attack_points}")
print(f"슈팅 성공률: {shot_accuracy:.1f}%")
print(f"MOM 후보   : {is_mom_candidate}")
```

[ Result ]

```text
선수 이름 : 우영
슈팅      : 5
득점      : 3
도움      : 2
공격포인트 : 5
슈팅 성공률: 60.0%
MOM 후보   : True
```

# **16. 핵심정리**

* 학습 순서는 **변수 → 동적 타이핑 → 자료형 → 재할당 → Jupyter → 형변환 → 연산자 → 문자열 형식화** 순으로 이해하면 자연스러움.
* 변수는 객체를 참조하는 이름.
* Python은 동적 타이핑 언어이므로 변수의 타입을 미리 고정하지 않음.
* `int`, `float`, `str`, `bool`은 가장 기본적인 자료형.
* `type()`으로 객체의 자료형을 확인할 수 있음.
* `id()`로 객체의 identity 값을 확인할 수 있음.
* Jupyter Notebook에서는 같은 커널의 변수 상태가 유지됨.
* 명시적 형변환에는 `int()`, `float()`, `str()`, `bool()`을 사용.
* 정수와 실수를 함께 계산하면 실수형 결과가 나올 수 있음.
* 산술 연산자로 값을 계산하고 비교 연산자로 조건을 만들 수 있음.
* 논리 연산자로 여러 조건을 결합할 수 있음.
* 복잡한 표현식에서는 괄호를 활용하는 것이 좋음.
* 문자열 형식화는 최종 결과를 사람이 읽기 좋은 형태로 출력하는 단계.
* 현대 Python에서는 `f-string`을 가장 자주 사용.
* 복잡한 코드는 **입력 데이터 → 계산 → 조건 판단 → 결과 출력** 흐름으로 이해하면 쉬움.
