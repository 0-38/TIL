# **1. 파이썬 내장 함수와 표준 라이브러리**

Python에는 별도의 함수 정의나 외부 패키지 설치 없이 바로 사용할 수 있는 다양한 기능이 제공됨.

이때 `len()`, `sum()`, `all()`처럼 바로 사용할 수 있는 기능을 **내장 함수**(Built-in Function)라고 하고, `datetime`, `statistics`, `random`처럼 `import`해서 사용하는 기능 모음을 **표준 라이브러리**(Standard Library)라고 함.

> ## **1-1 ) 내장 함수와 표준 라이브러리의 차이**

| 구분 | 내장 함수 | 표준 라이브러리 |
|---|---|---|
| 사용 방법 | 바로 사용 | `import` 필요 |
| 예시 | `len()`, `sum()`, `round()` | `statistics`, `datetime`, `random` |
| 별도 설치 | 필요 없음 | 필요 없음 |
| 주요 목적 | 자주 사용하는 기본 연산 | 특정 분야의 전문 기능 |

예를 들어 `len()`은 바로 사용할 수 있음.

[ python : code ] "선수 경기 기록 개수를 확인하는 방법"

```python
match_scores = [8.2, 7.9, 9.1, 8.5]

print(len(match_scores))
```

[ Result ]

```text
4
```

반면 평균과 중앙값을 계산하는 `statistics`는 먼저 불러와야 함.

[ python : code ] "statistics 표준 라이브러리를 불러오는 방법"

```python
import statistics

scores = [8.2, 7.9, 9.1, 8.5]

print(statistics.mean(scores))
```

[ Result ]

```text
8.425
```

# **2. isinstance()를 이용한 자료형 검증**

`isinstance()`는 특정 값이 원하는 자료형인지 확인하는 내장 함수.

기본 구조.

```python
isinstance(값, 자료형)
```

조건에 맞으면 `True`, 아니면 `False` 반환.

> ## **2-1 ) 운동 데이터 자료형 확인**

운동 데이터 분석 전에 반복 횟수가 정수인지 확인한다고 가정.

[ python : code ] "근력 운동 반복 횟수의 자료형을 검증하는 방법"

```python
reps = 12

print(isinstance(reps, int))
```

[ Result ]

```text
True
```

<br>

> ## **2-2 ) 조건문과 함께 사용하기**

[ python : code ] "러닝 거리가 숫자형 데이터인지 확인하는 방법"

```python
distance = 10.5

if isinstance(distance, (int, float)):
    print("사용 가능한 거리 데이터입니다.")
else:
    print("거리 데이터를 확인해주세요.")
```

[ Result ]

```text
사용 가능한 거리 데이터입니다.
```

`isinstance()`의 두 번째 인수에 여러 자료형을 튜플로 전달하면 여러 타입 중 하나인지 확인 가능.

```python
(int, float)
```

은 `int` 또는 `float`인지 검사한다는 의미.

# **3. all()과 any()로 여러 조건 확인하기**

여러 개의 `True`, `False` 값을 한 번에 확인해야 할 때 `all()`과 `any()` 사용 가능.

> ## **3-1 ) all()**

`all()`은 모든 요소가 참일 때만 `True` 반환.

[ python : code ] "농구 선수의 출전 조건을 모두 만족하는지 확인하는 방법"

```python
game_conditions = [
    True,   # 등록 완료
    True,   # 부상 없음
    True    # 출전 정지 없음
]

print(all(game_conditions))
```

[ Result ]

```text
True
```

<br>

> ## **3-2 ) any()**

`any()`는 하나 이상의 요소가 참이면 `True` 반환.

[ python : code ] "선수가 여러 공격 기록 중 하나라도 기록했는지 확인하는 방법"

```python
attack_records = [
    False,  # 득점 없음
    True,   # 도움 있음
    False   # 스틸 없음
]

print(any(attack_records))
```

[ Result ]

```text
True
```

<br>

> ## **3-3 ) all()과 any() 비교**

| 함수 | `True` 반환 조건 |
|---|---|
| `all()` | 모든 요소가 참 |
| `any()` | 하나 이상이 참 |

예를 들어.

```python
conditions = [True, True, False]
```

이라면.

```text
all(conditions)
→ False

any(conditions)
→ True
```

<br>

> ## **3-4 ) 빈 리스트 사용 시 주의**

빈 리스트에서는 다음 결과가 나옴.

[ python : code ] "빈 리스트에서 all과 any의 결과를 확인하는 방법"

```python
data = []

print(all(data))
print(any(data))
```

[ Result ]

```text
True
False
```

`all([])`이 `True`이기 때문에 실제 데이터 검증에서는 데이터 존재 여부를 함께 확인하는 것이 안전.

[ python : code ] "빈 운동 데이터가 검증을 통과하지 않도록 확인하는 방법"

```python
measurement_checks = []

if measurement_checks and all(measurement_checks):
    print("모든 측정이 정상입니다.")
else:
    print("측정 데이터가 없거나 유효하지 않습니다.")
```

[ Result ]

```text
측정 데이터가 없거나 유효하지 않습니다.
```

실행 흐름.

```text
measurement_checks
        ↓
빈 리스트인가?
        ↓
Yes
        ↓
False로 평가
        ↓
all()까지 확인할 필요 없음
        ↓
else 실행
```

# **4. len(), sum(), round()로 데이터 요약하기**

스포츠 데이터에서도 데이터 개수, 총합, 평균은 매우 자주 계산.

> ## **4-1 ) len()**

`len()`은 데이터의 요소 개수를 반환.

[ python : code ] "수영 선수의 기록 측정 횟수를 확인하는 방법"

```python
lap_times = [31.2, 30.8, 31.0, 30.5, 30.9]

print(len(lap_times))
```

[ Result ]

```text
5
```

<br>

> ## **4-2 ) sum()**

`sum()`은 숫자 데이터를 모두 더함.

[ python : code ] "농구 경기별 득점의 총합을 계산하는 방법"

```python
points = [18, 22, 15, 27]

total_points = sum(points)

print(total_points)
```

[ Result ]

```text
82
```

<br>

> ## **4-3 ) round()**

`round()`는 숫자를 지정한 자리까지 반올림.

[ python : code ] "러닝 평균 속도를 소수점 둘째 자리까지 반올림하는 방법"

```python
average_speed = 4.87653

print(round(average_speed, 2))
```

[ Result ]

```text
4.88
```

<br>

> ## **4-4 ) 평균 계산하기**

평균은 다음 구조로 계산 가능.

```text
합계 / 데이터 개수
```

[ python : code ] "선수 경기 평점의 평균을 계산하는 방법"

```python
ratings = [8.2, 7.8, 9.1, 8.5]

total = sum(ratings)
count = len(ratings)

average = total / count

print(f"경기 수: {count}")
print(f"평점 합계: {total}")
print(f"평균 평점: {round(average, 2)}")
```

[ Result ]

```text
경기 수: 4
평점 합계: 33.6
평균 평점: 8.4
```

<br>

> ## **4-5 ) 주요 함수 비교**

| 함수 | 역할 | 예시 |
|---|---|---|
| `len()` | 개수 계산 | 경기 수 |
| `sum()` | 전체 합계 | 총 득점 |
| `round()` | 반올림 | 평균 속도 정리 |

# **5. statistics의 mean()과 median()**

`mean()`과 `median()`은 내장 함수가 아니라 Python 표준 라이브러리인 `statistics`에서 제공.

먼저 `import statistics` 필요.

> ## **5-1 ) mean() 평균**

[ python : code ] "러닝 기록의 평균 시간을 계산하는 방법"

```python
import statistics

running_times = [48.2, 47.5, 49.1, 48.0]

average_time = statistics.mean(running_times)

print(average_time)
```

[ Result ]

```text
48.2
```

<br>

> ## **5-2 ) median() 중앙값**

중앙값은 데이터를 정렬했을 때 가운데 위치하는 값.

[ python : code ] "운동 검사 결과의 중앙값을 계산하는 방법"

```python
import statistics

reaction_times = [0.21, 0.22, 0.23, 0.24, 1.50]

print(statistics.mean(reaction_times))
print(statistics.median(reaction_times))
```

[ Result ]

```text
0.48
0.23
```

`1.50`이라는 큰 값 때문에 평균은 크게 올라갔지만 중앙값은 상대적으로 영향을 적게 받음.

<br>

> ## **5-3 ) 평균과 중앙값 비교**

| 구분 | 평균 `mean()` | 중앙값 `median()` |
|---|---|---|
| 계산 방식 | 전체 합 / 개수 | 정렬 후 가운데 값 |
| 이상치 영향 | 큼 | 상대적으로 작음 |
| 활용 | 데이터 전체 수준 | 치우친 데이터의 대표값 |

운동역학이나 경기 분석에서 이상치가 존재한다면 평균만 보지 않고 중앙값을 함께 확인하는 것이 도움이 될 수 있음.

# **6. map()으로 데이터 전체 변환하기**

`map()`은 반복 가능한 데이터의 각 요소에 동일한 함수를 적용.

기본 구조.

```python
map(함수, 데이터)
```

Python 3의 `map()`은 `map` 객체를 반환하므로 결과를 리스트로 사용하려면 보통 `list()`로 변환.

> ## **6-1 ) 러닝 속도 단위 변환**

m/s 단위의 러닝 속도를 km/h로 변경한다고 가정.

[ python : code ] "map을 이용해 러닝 속도 단위를 일괄 변환하는 방법"

```python
speeds_ms = [3.5, 4.0, 4.5, 5.0]

speeds_kmh = list(
    map(lambda speed: speed * 3.6, speeds_ms)
)

print(speeds_kmh)
```

[ Result ]

```text
[12.6, 14.4, 16.2, 18.0]
```

<br>

> ## **6-2 ) map 실행 흐름**

```text
원본
[3.5, 4.0, 4.5, 5.0]
        ↓
map()
        ↓
각 요소를 하나씩 꺼냄
        ↓
lambda speed: speed * 3.6
        ↓
12.6, 14.4, 16.2, 18.0
        ↓
list()
        ↓
[12.6, 14.4, 16.2, 18.0]
```

# **7. filter()로 조건에 맞는 데이터 선택하기**

`filter()`는 각 요소를 조건 함수에 전달하고 결과가 참인 요소만 남김.

기본 구조.

```python
filter(조건함수, 데이터)
```

> ## **7-1 ) 보행 속도 필터링**

보행 속도가 `1.2m/s` 이상인 측정값만 추출한다고 가정.

[ python : code ] "filter를 이용해 기준 이상의 보행 속도를 추출하는 방법"

```python
gait_speeds = [0.95, 1.25, 1.10, 1.42, 1.30]

selected_speeds = list(
    filter(
        lambda speed: speed >= 1.2,
        gait_speeds
    )
)

print(selected_speeds)
```

[ Result ]

```text
[1.25, 1.42, 1.3]
```

<br>

> ## **7-2 ) map()과 filter() 비교**

| 함수 | 목적 |
|---|---|
| `map()` | 모든 요소 변환 |
| `filter()` | 조건에 맞는 요소 선택 |

```text
map()
원본 데이터
→ 전부 가공
→ 새로운 값

filter()
원본 데이터
→ 조건 검사
→ 일부 데이터 선택
```

# **8. enumerate()로 순번과 데이터를 함께 사용하기**

반복문에서 데이터와 순번을 동시에 사용하고 싶을 때 `enumerate()` 활용.

> ## **8-1 ) 육상 선수 순위 출력**

[ python : code ] "enumerate를 이용해 선수 순위에 번호를 붙이는 방법"

```python
athletes = ["우영", "민수", "지훈"]

for rank, athlete in enumerate(
    athletes,
    start=1
):
    print(f"{rank}위: {athlete}")
```

[ Result ]

```text
1위: 우영
2위: 민수
3위: 지훈
```

`start=1`을 사용하지 않으면 기본 인덱스는 `0`부터 시작.

<br>

> ## **8-2 ) enumerate 구조**

```text
["우영", "민수", "지훈"]
        ↓
enumerate(start=1)
        ↓
(1, "우영")
(2, "민수")
(3, "지훈")
        ↓
rank, athlete로 언패킹
```

# **9. zip()으로 여러 데이터를 묶기**

`zip()`은 여러 시퀀스의 같은 위치에 있는 요소를 하나씩 묶어줌.

> ## **9-1 ) 야구 선수 이름과 타율 결합**

[ python : code ] "zip을 이용해 선수 이름과 타율을 함께 출력하는 방법"

```python
players = ["우영", "민수", "지훈"]
batting_averages = [0.312, 0.287, 0.301]

for player, average in zip(
    players,
    batting_averages
):
    print(f"{player}: {average:.3f}")
```

[ Result ]

```text
우영: 0.312
민수: 0.287
지훈: 0.301
```

<br>

> ## **9-2 ) 길이가 다른 데이터의 zip()**

기본 `zip()`은 가장 짧은 데이터가 끝나는 시점에서 종료.

[ python : code ] "길이가 다른 두 리스트를 zip으로 결합하는 방법"

```python
players = ["우영", "민수", "지훈"]
scores = [10, 20]

print(list(zip(players, scores)))
```

[ Result ]

```text
[('우영', 10), ('민수', 20)]
```

`"지훈"`은 대응되는 점수가 없기 때문에 기본 `zip()` 결과에서 제외됨.

# **10. sorted(), min(), max()**

데이터를 정렬하거나 최댓값·최솟값을 확인할 때 사용하는 대표적인 내장 함수.

> ## **10-1 ) sorted()**

`sorted()`는 정렬된 **새로운 리스트**를 반환하고 원본 데이터는 변경하지 않음.

[ python : code ] "수영 기록을 빠른 순서대로 정렬하는 방법"

```python
swim_times = [58.4, 57.8, 59.1, 57.5]

sorted_times = sorted(swim_times)

print(sorted_times)
print(swim_times)
```

[ Result ]

```text
[57.5, 57.8, 58.4, 59.1]
[58.4, 57.8, 59.1, 57.5]
```

수영 경기 시간은 작은 값이 더 빠른 기록이므로 기본 오름차순이 빠른 기록 순.

<br>

> ## **10-2 ) 내림차순 정렬**

[ python : code ] "농구 득점을 높은 순으로 정렬하는 방법"

```python
points = [18, 30, 22, 27]

ranking = sorted(
    points,
    reverse=True
)

print(ranking)
```

[ Result ]

```text
[30, 27, 22, 18]
```

<br>

> ## **10-3 ) min()과 max()**

[ python : code ] "점프 높이의 최솟값과 최댓값을 확인하는 방법"

```python
jump_heights = [38, 42, 35, 47, 41]

print(min(jump_heights))
print(max(jump_heights))
```

[ Result ]

```text
35
47
```

<br>

> ## **10-4 ) sorted(), min(), max() 비교**

| 함수 | 역할 |
|---|---|
| `sorted()` | 데이터 전체 정렬 |
| `min()` | 가장 작은 값 |
| `max()` | 가장 큰 값 |

# **11. datetime과 time**

날짜와 시간을 다루거나 코드의 실행 시간을 측정할 때 사용하는 표준 라이브러리.

> ## **11-1 ) datetime으로 측정 날짜 관리하기**

[ python : code ] "운동 검사 날짜를 생성하고 문자열로 변환하는 방법"

```python
import datetime

test_date = datetime.datetime(
    2026,
    9,
    12,
    14,
    30
)

formatted_date = test_date.strftime(
    "%Y-%m-%d %H:%M"
)

print(formatted_date)
```

[ Result ]

```text
2026-09-12 14:30
```

<br>

> ## **11-2 ) 주요 날짜 포맷 코드**

| 코드 | 의미 | 예시 |
|---|---|---|
| `%Y` | 4자리 연도 | `2026` |
| `%m` | 월 | `09` |
| `%d` | 일 | `12` |
| `%H` | 시 | `14` |
| `%M` | 분 | `30` |
| `%S` | 초 | `05` |

<br>

> ## **11-3 ) timedelta로 날짜 계산하기**

[ python : code ] "훈련 날짜에서 7일 뒤 날짜를 계산하는 방법"

```python
import datetime

training_date = datetime.date(
    2026,
    9,
    12
)

next_training = (
    training_date
    + datetime.timedelta(days=7)
)

print(next_training)
```

[ Result ]


# **16. 종합 실습 - 운동 검사 데이터 검증 및 분석**

운동 검사에서 다음 보행 속도 데이터가 입력되었다고 가정.

```text
[1.10, 1.25, 1.32, 1.18, 1.40]
```

다음 작업 수행.

- 모든 값이 숫자인지 검증
- 데이터가 비어 있지 않은지 확인
- 평균 계산
- 중앙값 계산
- 평균 이상 데이터 추출
- 높은 순서대로 정렬
- 순위를 붙여 출력

> ## **16-1 ) 보행 속도 종합 분석**

[ python : code ] "내장 함수와 statistics를 조합하여 보행 데이터를 분석하는 방법"

```python
import statistics

gait_speeds = [
    1.10,
    1.25,
    1.32,
    1.18,
    1.40
]

valid_types = [
    isinstance(speed, (int, float))
    for speed in gait_speeds
]

if gait_speeds and all(valid_types):

    average_speed = statistics.mean(
        gait_speeds
    )

    median_speed = statistics.median(
        gait_speeds
    )

    above_average = list(
        filter(
            lambda speed: speed >= average_speed,
            gait_speeds
        )
    )

    ranking = sorted(
        above_average,
        reverse=True
    )

    print(
        f"평균 속도: "
        f"{average_speed:.2f} m/s"
    )

    print(
        f"중앙값: "
        f"{median_speed:.2f} m/s"
    )

    print("평균 이상 기록:")

    for rank, speed in enumerate(
        ranking,
        start=1
    ):
        print(
            f"{rank}위: "
            f"{speed:.2f} m/s"
        )

else:
    print("보행 데이터를 확인해주세요.")
```

[ Result ]

```text
평균 속도: 1.25 m/s
중앙값: 1.25 m/s
평균 이상 기록:
1위: 1.40 m/s
2위: 1.32 m/s
```


```text

```


위 코드에서는 부동소수점 계산 결과에 따라 경계값 처리에서 미세한 차이가 발생할 수 있으므로 실제 분석에서는 비교 기준과 반올림 정책을 명확하게 설계하는 것이 좋음.

# **20. 핵심정리**

- Python의 **내장 함수**는 별도의 `import` 없이 바로 사용할 수 있음.
- `statistics`, `datetime`, `random` 등은 **표준 라이브러리**이므로 `import` 후 사용.
- `isinstance()`는 값의 자료형을 검증할 때 사용.
- 여러 숫자 자료형을 허용하려면 `isinstance(value, (int, float))`처럼 작성 가능.
- `all()`은 모든 값이 참일 때 `True`.
- `any()`는 하나 이상의 값이 참일 때 `True`.
- `all([])`은 `True`, `any([])`은 `False`.
- 데이터 검증에서는 빈 데이터 여부도 함께 확인하는 것이 중요.
- `len()`은 데이터 개수 계산.
- `sum()`은 숫자 데이터의 합계 계산.
- `round()`는 원하는 자리까지 숫자를 반올림할 때 사용.
- `statistics.mean()`은 평균, `statistics.median()`은 중앙값 계산.
- 이상치가 존재하면 평균과 중앙값의 차이가 커질 수 있음.
- `map()`은 모든 데이터에 동일한 변환 적용.
- `filter()`는 조건을 만족하는 데이터만 선택.
- Python 3의 `map()`과 `filter()`는 리스트 자체가 아니므로 필요하면 `list()`로 변환.
- `enumerate()`는 순번과 데이터를 함께 순회.
- `zip()`은 여러 데이터의 같은 위치에 있는 요소를 묶음.
- 기본 `zip()`은 가장 짧은 데이터 길이를 기준으로 종료.
- `sorted()`는 정렬된 새로운 리스트를 반환하며 원본은 그대로 유지.
- `min()`은 최솟값, `max()`는 최댓값 반환.
- `datetime`은 날짜와 시간 처리에 사용.
- `datetime.timedelta()`는 날짜 또는 시간 간격 계산에 사용.
- `time.perf_counter()`는 코드의 소요 시간을 측정할 때 적합.
- `math.ceil()`은 올림, `math.floor()`는 내림, `math.trunc()`는 소수 부분 제거.
- `json.dumps()`는 Python 객체를 JSON 문자열로 변환.
- `json.loads()`는 JSON 문자열을 Python 객체로 복원.
- `random.choice()`는 하나를 선택하고 `random.sample()`은 중복 없이 여러 개를 선택.
- `random.shuffle()`은 원본 리스트의 순서를 직접 변경.
- `os`는 작업 디렉터리와 파일 경로 등의 운영체제 기능을 처리.
- `sys`는 현재 Python 인터프리터와 실행 환경 정보를 확인할 때 사용.
- 내장 함수와 표준 라이브러리를 잘 조합하면 긴 반복문과 복잡한 조건문을 줄이고 데이터를 더 간결하게 처리할 수 있음.
- 스포츠 데이터 분석에서는 **검증 → 요약 → 필터링 → 정렬 → 출력** 흐름으로 여러 함수를 연결해 사용하는 경우가 많음.
