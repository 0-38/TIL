# **1. 파일 입출력(File I/O)의 기본 구조**

프로그램이 실행되는 동안 변수에 저장된 데이터는 메모리에 존재하기 때문에 프로그램이 종료되면 일반적으로 사라짐.

데이터를 나중에도 다시 사용하려면 파일 형태로 저장해야 함.

Python에서는 `open()`을 이용하여 파일을 열고 읽기 또는 쓰기 작업 수행 가능.

> ## **1-1 ) with open()을 사용하는 이유**

파일 작업의 기본 흐름.

```text
파일 열기
   ↓
읽기 / 쓰기
   ↓
파일 닫기
```

일반적인 `open()` 방식에서는 작업이 끝난 뒤 `close()`를 직접 호출해야 함.

```python
file = open("training.txt", "w", encoding="utf-8")

file.write("러닝 훈련 완료")

file.close()
```

하지만 일반적으로는 `with open()` 사용을 권장.

`with` 블록이 종료되면 파일을 자동으로 닫아주기 때문.

[ python : code ] "러닝 훈련 기록을 텍스트 파일에 안전하게 저장하는 방법"

```python
with open(
    "training.txt",
    "w",
    encoding="utf-8"
) as file:
    file.write("5km 러닝 완료\n")
    file.write("평균 페이스: 5분 10초\n")

print("훈련 기록 저장 완료")
```

[ Result ]

```text
훈련 기록 저장 완료
```

`training.txt` 파일.

```text
5km 러닝 완료
평균 페이스: 5분 10초
```

실행 흐름.

```text
with open()
     ↓
파일 열기
     ↓
file 객체 생성
     ↓
파일 쓰기
     ↓
with 블록 종료
     ↓
파일 자동 닫기
```

`with open()`을 사용하면 정상적으로 작업이 끝난 경우뿐 아니라 블록 실행 중 예외가 발생하는 경우에도 파일 자원을 정리하기 쉬움.

<br>

> ## **1-2 ) 파일 열기 모드**

`open()`의 두 번째 인수에는 파일을 어떤 목적으로 열지 지정.

| 모드 | 의미 | 특징 |
|---|---|---|
| `"r"` | Read | 파일 읽기 |
| `"w"` | Write | 새로 쓰기, 기존 내용 덮어쓰기 |
| `"a"` | Append | 기존 내용 뒤에 추가 |
| `"x"` | Exclusive Creation | 파일이 없을 때만 새로 생성 |
| `"b"` | Binary | 이미지 등 바이너리 파일 처리 |

가장 많이 사용하는 형태.

```python
open("data.txt", "r")
open("data.txt", "w")
open("data.txt", "a")
```

`"w"` 모드는 기존 파일이 존재하면 **기존 내용을 지우고 새로 작성**하므로 주의.

<br>

> ## **1-3 ) w와 a의 차이**

[ python : code ] "운동 기록을 덮어쓰기와 추가 방식으로 저장하는 방법"

```python
with open(
    "exercise_log.txt",
    "w",
    encoding="utf-8"
) as file:
    file.write("월요일: 스쿼트\n")

with open(
    "exercise_log.txt",
    "a",
    encoding="utf-8"
) as file:
    file.write("화요일: 데드리프트\n")

with open(
    "exercise_log.txt",
    "r",
    encoding="utf-8"
) as file:
    print(file.read())
```

[ Result ]

```text
월요일: 스쿼트
화요일: 데드리프트
```

| 모드 | 기존 데이터 | 새 데이터 |
|---|---|---|
| `"w"` | 삭제 | 새로 작성 |
| `"a"` | 유지 | 뒤에 추가 |

# **2. 텍스트 파일 읽기**

텍스트 파일을 읽는 대표적인 방법은 `read()`, `readline()`, `readlines()`.

데이터의 크기와 처리 목적에 따라 적절한 방식을 선택해야 함.

> ## **2-1 ) read()**

`read()`는 파일 전체 내용을 **하나의 문자열**로 읽음.

[ python : code ] "수영 훈련 기록 전체를 한 번에 읽는 방법"

```python
with open(
    "swimming.txt",
    "w",
    encoding="utf-8"
) as file:
    file.write("자유형 100m: 58.2초\n")
    file.write("자유형 100m: 57.9초\n")
    file.write("자유형 100m: 58.5초\n")

with open(
    "swimming.txt",
    "r",
    encoding="utf-8"
) as file:
    content = file.read()

print(content)
print(type(content))
```

[ Result ]

```text
자유형 100m: 58.2초
자유형 100m: 57.9초
자유형 100m: 58.5초

<class 'str'>
```

작은 파일 전체를 한 번에 처리할 때 편리.

하지만 매우 큰 파일을 `read()`로 한 번에 읽으면 많은 메모리를 사용할 수 있음.

<br>

> ## **2-2 ) readline()**

`readline()`은 한 번 호출할 때마다 **한 줄씩** 읽음.

[ python : code ] "보행 측정 파일의 첫 번째 기록만 읽는 방법"

```python
with open(
    "gait.txt",
    "w",
    encoding="utf-8"
) as file:
    file.write("1.20 m/s\n")
    file.write("1.35 m/s\n")
    file.write("1.28 m/s\n")

with open(
    "gait.txt",
    "r",
    encoding="utf-8"
) as file:
    first_line = file.readline()

print(first_line.strip())
```

[ Result ]

```text
1.20 m/s
```

`readline()`으로 읽은 문자열에는 줄바꿈 문자 `\n`이 포함될 수 있음.

`strip()`을 사용하면 문자열 양쪽의 공백과 줄바꿈 제거 가능.

<br>

> ## **2-3 ) readlines()**

`readlines()`는 모든 줄을 읽어 **리스트**로 반환.

[ python : code ] "농구 경기 기록을 줄 단위 리스트로 읽는 방법"

```python
with open(
    "basketball.txt",
    "w",
    encoding="utf-8"
) as file:
    file.write("18점\n")
    file.write("24점\n")
    file.write("21점\n")

with open(
    "basketball.txt",
    "r",
    encoding="utf-8"
) as file:
    scores = file.readlines()

print(scores)
```

[ Result ]

```text
['18점\n', '24점\n', '21점\n']
```

`readlines()`는 줄 단위 작업에는 편리하지만 전체 파일을 리스트로 메모리에 올림.

<br>

> ## **2-4 ) read(), readline(), readlines() 비교**

| 함수 | 반환 형태 | 특징 |
|---|---|---|
| `read()` | 문자열 | 전체 파일을 한 번에 읽음 |
| `readline()` | 문자열 | 한 줄씩 읽음 |
| `readlines()` | 리스트 | 모든 줄을 리스트로 읽음 |

<br>

> ## **2-5 ) 파일 객체를 직접 반복하기**

대용량 텍스트 파일을 줄 단위로 처리한다면 파일 객체 자체를 `for`문으로 반복하는 방법도 많이 사용.

[ python : code ] "대용량 경기 기록을 한 줄씩 처리하는 방법"

```python
with open(
    "basketball.txt",
    "r",
    encoding="utf-8"
) as file:
    for line in file:
        print(line.strip())
```

[ Result ]

```text
18점
24점
21점
```

전체 내용을 리스트로 만들 필요 없이 한 줄씩 순회할 수 있음.

# **3. 텍스트 파일 가공 후 다시 저장하기**

파일에서 읽은 데이터를 Python에서 가공한 뒤 새로운 파일로 저장 가능.

> ## **3-1 ) 경기 기록에 순위 번호 붙이기**

[ python : code ] "수영 선수 명단에 번호를 붙여 새로운 파일로 저장하는 방법"

```python
with open(
    "swimmers.txt",
    "w",
    encoding="utf-8"
) as file:
    file.write("우영\n")
    file.write("민수\n")
    file.write("지훈\n")

with open(
    "swimmers.txt",
    "r",
    encoding="utf-8"
) as file:
    swimmers = file.readlines()

with open(
    "numbered_swimmers.txt",
    "w",
    encoding="utf-8"
) as file:
    for number, swimmer in enumerate(
        swimmers,
        start=1
    ):
        file.write(
            f"{number}. {swimmer.strip()}\n"
        )

with open(
    "numbered_swimmers.txt",
    "r",
    encoding="utf-8"
) as file:
    print(file.read())
```

[ Result ]

```text
1. 우영
2. 민수
3. 지훈
```

<br>

> ## **3-2 ) 코드 결과 해석**

첫 번째 파일.

```text
우영
민수
지훈
```

`readlines()` 실행.

```text
[
    "우영\n",
    "민수\n",
    "지훈\n"
]
```

`enumerate(start=1)` 실행.

```text
1, "우영"
2, "민수"
3, "지훈"
```

`strip()`으로 기존 줄바꿈 제거.

```text
"우영\n"
↓
"우영"
```

새 파일 저장.

```text
1. 우영
2. 민수
3. 지훈
```

<br>

> ## **3-3 ) 전체 실행 흐름도**

```text
원본 파일
    ↓
with open("r")
    ↓
readlines()
    ↓
줄 단위 리스트
    ↓
enumerate()
    ↓
번호 + 데이터
    ↓
strip()
    ↓
문자열 가공
    ↓
with open("w")
    ↓
새로운 파일 저장
```

# **4. CSV 파일**

CSV(Comma-Separated Values)는 데이터를 행과 열 형태로 저장하는 대표적인 텍스트 파일 형식.

데이터 분석에서 표 형태의 데이터를 저장하거나 교환할 때 자주 사용.

> ## **4-1 ) CSV 기본 구조**

예를 들어 농구 선수 데이터.

```text
name,points,assists
우영,24,7
민수,18,5
지훈,30,9
```

행(Row)은 각각 하나의 관측값을 의미하고 쉼표로 열(Column)을 구분.

<br>

> ## **4-2 ) csv.writer()로 CSV 저장하기**

[ python : code ] "농구 선수 경기 데이터를 CSV 파일로 저장하는 방법"

```python
import csv

basketball_data = [
    ["name", "points", "assists"],
    ["우영", 24, 7],
    ["민수", 18, 5],
    ["지훈", 30, 9]
]

with open(
    "basketball.csv",
    "w",
    encoding="utf-8",
    newline=""
) as file:
    writer = csv.writer(file)
    writer.writerows(basketball_data)

print("CSV 저장 완료")
```

[ Result ]

```text
CSV 저장 완료
```

`basketball.csv`.

```text
name,points,assists
우영,24,7
민수,18,5
지훈,30,9
```

`writerow()`는 한 행 저장.

```python
writer.writerow(["우영", 24, 7])
```

`writerows()`는 여러 행을 한 번에 저장.

```python
writer.writerows(basketball_data)
```

<br>

> ## **4-3 ) csv.reader()로 CSV 읽기**

[ python : code ] "CSV 파일을 2차원 리스트 형태로 불러오는 방법"

```python
import csv

with open(
    "basketball.csv",
    "r",
    encoding="utf-8",
    newline=""
) as file:
    reader = csv.reader(file)
    basketball_data = list(reader)

print(basketball_data)
```

[ Result ]

```text
[
    ['name', 'points', 'assists'],
    ['우영', '24', '7'],
    ['민수', '18', '5'],
    ['지훈', '30', '9']
]
```

CSV에서 읽은 값은 기본적으로 **문자열**.

따라서 `"24"`를 숫자 계산에 사용하려면 `int()` 또는 `float()`로 변환해야 함.

<br>

> ## **4-4 ) CSV 숫자 데이터 형변환**

[ python : code ] "CSV에서 읽은 농구 득점 데이터를 정수로 변환하는 방법"

```python
import csv

with open(
    "basketball.csv",
    "r",
    encoding="utf-8",
    newline=""
) as file:
    reader = csv.reader(file)

    header = next(reader)

    for row in reader:
        name = row[0]
        points = int(row[1])

        print(
            name,
            points,
            type(points)
        )
```

[ Result ]

```text
우영 24 <class 'int'>
민수 18 <class 'int'>
지훈 30 <class 'int'>
```

<br>

> ## **4-5 ) csv.reader와 csv.writer 비교**

| 기능 | 객체 |
|---|---|
| CSV 읽기 | `csv.reader()` |
| CSV 한 행 쓰기 | `writer.writerow()` |
| CSV 여러 행 쓰기 | `writer.writerows()` |

# **5. CSV 데이터를 딕셔너리로 다루기**

열 이름을 인덱스 번호 대신 키로 사용하면 데이터의 의미를 더 쉽게 파악할 수 있음.

이때 `csv.DictReader()`와 `csv.DictWriter()` 사용 가능.

> ## **5-1 ) DictReader()**

[ python : code ] "러닝 기록 CSV를 딕셔너리 형태로 읽는 방법"

```python
import csv

with open(
    "running.csv",
    "w",
    encoding="utf-8",
    newline=""
) as file:
    writer = csv.writer(file)

    writer.writerow(
        ["name", "distance_km", "time_min"]
    )
    writer.writerow(
        ["우영", 5, 24]
    )
    writer.writerow(
        ["민수", 10, 52]
    )

with open(
    "running.csv",
    "r",
    encoding="utf-8",
    newline=""
) as file:
    reader = csv.DictReader(file)

    for row in reader:
        print(row)
```

[ Result ]

```text
{'name': '우영', 'distance_km': '5', 'time_min': '24'}
{'name': '민수', 'distance_km': '10', 'time_min': '52'}
```

일반 `csv.reader()`에서는.

```python
row[0]
row[1]
```

처럼 접근.

`DictReader()`에서는.

```python
row["name"]
row["distance_km"]
```

처럼 의미 있는 열 이름으로 접근 가능.

<br>

> ## **5-2 ) reader와 DictReader 비교**

| 구분 | `csv.reader()` | `csv.DictReader()` |
|---|---|---|
| 행 형태 | 리스트 | 딕셔너리 |
| 접근 | `row[0]` | `row["name"]` |
| 장점 | 단순함 | 열 의미 파악이 쉬움 |

# **6. JSON 파일과 Python 자료구조**

JSON(JavaScript Object Notation)은 웹 API, 설정 파일, 데이터 교환 등에 널리 사용하는 텍스트 형식.

Python의 딕셔너리·리스트와 구조가 유사하지만 완전히 같은 문법은 아님.

> ## **6-1 ) JSON과 Python 자료형 대응**

| JSON | Python |
|---|---|
| Object | `dict` |
| Array | `list` |
| String | `str` |
| Number | `int`, `float` |
| `true` | `True` |
| `false` | `False` |
| `null` | `None` |

<br>

> ## **6-2 ) json.loads()**

`loads()`의 `s`는 문자열(String)을 처리한다고 이해하면 쉬움.

JSON 문자열을 Python 객체로 변환.

[ python : code ] "보행 분석 JSON 문자열을 Python 딕셔너리로 변환하는 방법"

```python
import json

gait_json = '''
{
    "name": "우영",
    "speed": 1.32,
    "symmetric": true
}
'''

gait_data = json.loads(gait_json)

print(gait_data)
print(type(gait_data))
print(gait_data["speed"])
```

[ Result ]

```text
{'name': '우영', 'speed': 1.32, 'symmetric': True}
<class 'dict'>
1.32
```

<br>

> ## **6-3 ) json.dumps()**

Python 객체를 JSON **문자열**로 변환.

[ python : code ] "운동 검사 딕셔너리를 JSON 문자열로 변환하는 방법"

```python
import json

test_result = {
    "athlete": "우영",
    "jump_cm": 42,
    "valid": True
}

json_text = json.dumps(
    test_result,
    ensure_ascii=False
)

print(json_text)
print(type(json_text))
```

[ Result ]

```text
{"athlete": "우영", "jump_cm": 42, "valid": true}
<class 'str'>
```

<br>

> ## **6-4 ) loads()와 dumps()**

```text
Python 객체
   ↓
json.dumps()
   ↓
JSON 문자열
   ↓
json.loads()
   ↓
Python 객체
```

# **7. JSON 파일 저장과 불러오기**

JSON 문자열이 아니라 실제 `.json` 파일을 다룰 때는 `json.dump()`와 `json.load()` 사용.

> ## **7-1 ) json.dump()**

[ python : code ] "운동처방 데이터를 JSON 파일로 저장하는 방법"

```python
import json

exercise_program = {
    "name": "우영",
    "exercise": "걷기",
    "duration_min": 30,
    "sessions_per_week": 3
}

with open(
    "exercise_program.json",
    "w",
    encoding="utf-8"
) as file:
    json.dump(
        exercise_program,
        file,
        ensure_ascii=False,
        indent=4
    )

print("JSON 저장 완료")
```

[ Result ]

```text
JSON 저장 완료
```

`exercise_program.json`.

```json
{
    "name": "우영",
    "exercise": "걷기",
    "duration_min": 30,
    "sessions_per_week": 3
}
```

`ensure_ascii=False`를 사용하면 한글을 `\uXXXX` 형태로 변환하지 않고 그대로 저장 가능.

`indent=4`는 사람이 읽기 편하도록 들여쓰기 적용.

# **8. 직렬화(Serialization)와 역직렬화**

Python 객체를 파일 저장이나 네트워크 전송이 가능한 형태로 변환하는 것을 **직렬화**(Serialization)라고 함.

반대로 저장된 데이터를 다시 Python 객체로 복원하는 과정을 **역직렬화**(Deserialization)라고 함.

> ## **8-1 ) JSON 함수 비교**

| 함수 | 입력 | 결과 | 주 사용 대상 |
|---|---|---|---|
| `json.dumps()` | Python 객체 | JSON 문자열 | 메모리 |
| `json.loads()` | JSON 문자열 | Python 객체 | 메모리 |
| `json.dump()` | Python 객체 | JSON 파일에 기록 | 파일 |
| `json.load()` | JSON 파일 | Python 객체 | 파일 |

핵심 구분.

```text
s가 있으면 문자열

dumps()
loads()

s가 없으면 파일

dump()
load()
```

<br>

> ## **8-2 ) 직렬화 흐름**

```text
Python dict
     ↓
json.dump()
     ↓
JSON 파일
     ↓
저장
     ↓
json.load()
     ↓
Python dict
```

<br>

> ## **8-3 ) CSV와 JSON 비교**

| 구분 | CSV | JSON |
|---|---|---|
| 구조 | 행·열 중심 | 계층 구조 가능 |
| 대표 Python 구조 | 2차원 리스트·딕셔너리 | 딕셔너리·리스트 |
| 숫자 읽기 | 기본적으로 문자열 | 숫자 자료형으로 복원 가능 |
| 중첩 데이터 | 표현하기 불편 | 표현하기 쉬움 |
| 주요 활용 | 표 형태 데이터 | API·설정·계층 데이터 |

예를 들어 경기 기록처럼 표 구조가 명확하면 CSV가 편리.

```text
선수 | 득점 | 도움
```

반대로 한 선수 안에 여러 측정 데이터를 중첩해서 저장하려면 JSON이 편리.

```json
{
    "name": "우영",
    "gait": {
        "speed": 1.32,
        "cadence": 112
    }
}
```

# **9. 종합 실습 - 운동역학 CSV 데이터 분석**

점프 높이 측정 결과가 CSV 파일에 저장되어 있다고 가정.

다음 작업 수행.

- CSV 파일 생성
- 데이터 읽기
- 숫자 자료형 변환
- 평균 계산
- 최고 기록 확인

> ## **9-1 ) 점프 높이 CSV 분석**

[ python : code ] "CSV 파일의 점프 높이를 읽어 평균과 최고 기록을 계산하는 방법"

```python
import csv

jump_data = [
    ["name", "jump_cm"],
    ["우영", 42],
    ["민수", 38],
    ["지훈", 47],
    ["서준", 41]
]

with open(
    "jump_data.csv",
    "w",
    encoding="utf-8",
    newline=""
) as file:
    writer = csv.writer(file)
    writer.writerows(jump_data)

jump_records = []

with open(
    "jump_data.csv",
    "r",
    encoding="utf-8",
    newline=""
) as file:
    reader = csv.DictReader(file)

    for row in reader:
        jump_records.append({
            "name": row["name"],
            "jump_cm": int(row["jump_cm"])
        })

jump_values = [
    record["jump_cm"]
    for record in jump_records
]

average_jump = (
    sum(jump_values)
    / len(jump_values)
)

best_jump = max(jump_records, key=lambda x: x["jump_cm"])

print(f"평균 점프 높이: {average_jump:.2f}cm")
print(
    f"최고 기록: "
    f"{best_jump['name']} "
    f"{best_jump['jump_cm']}cm"
)
```

[ Result ]

```text
평균 점프 높이: 42.00cm
최고 기록: 지훈 47cm
```

<br>

> ## **9-2 ) 코드 결과 해석**



합계.

```text

```

[ python : code ] "보행 속도 데이터를 분석하여 JSON 파일로 저장하는 방법"

```python

    1.10,
    1.25,
    1.35,
```

# **13. 핵심정리**

- 파일 입출력(File I/O)은 프로그램과 외부 파일 사이에서 데이터를 읽고 저장하는 작업.
- `open()`을 사용하여 파일을 열 수 있음.
- 일반적으로 파일 작업은 `with open()`을 사용하면 자원을 안전하게 관리하기 쉬움.
- `with` 블록이 종료되면 파일은 자동으로 닫힘.
- `"r"`은 읽기 모드.
- `"w"`는 쓰기 모드이며 기존 파일 내용을 덮어쓸 수 있음.
- `"a"`는 기존 파일의 뒤에 내용을 추가.
- `read()`는 파일 전체 내용을 하나의 문자열로 읽음.
- `readline()`은 한 줄을 읽음.
- `readlines()`는 모든 줄을 리스트로 읽음.
- 대용량 파일에서는 파일 객체를 직접 `for`문으로 순회하는 방법도 유용.
- `strip()`을 이용하면 줄 끝의 `\n`과 같은 공백 문자를 제거할 수 있음.
- CSV는 행과 열 형태의 표 데이터를 저장하기 좋은 텍스트 형식.
- `csv.writer()`는 CSV 파일을 작성할 때 사용.
- `writerow()`는 한 행, `writerows()`는 여러 행을 저장.
- `csv.reader()`는 CSV 파일을 읽을 때 사용.
- 일반적인 `csv.reader()`로 읽은 데이터는 기본적으로 문자열로 처리됨.
- 숫자 계산이 필요하면 `int()`, `float()` 등으로 형변환해야 함.
- `csv.DictReader()`를 사용하면 열 이름을 키로 가지는 딕셔너리 형태로 데이터를 다룰 수 있음.
- JSON은 키-값 구조와 계층 데이터를 표현하기 좋은 텍스트 데이터 형식.
- JSON 객체는 Python의 `dict`, JSON 배열은 Python의 `list`와 대응.
- JSON의 `true`, `false`, `null`은 Python에서 각각 `True`, `False`, `None`과 대응.
- `json.dumps()`는 Python 객체를 JSON 문자열로 변환.
- `json.loads()`는 JSON 문자열을 Python 객체로 변환.
- `json.dump()`는 Python 객체를 JSON 파일에 저장.
- `json.load()`는 JSON 파일을 Python 객체로 복원.
- 객체를 저장하거나 전송할 수 있는 형태로 변환하는 과정을 **직렬화**(Serialization)라고 함.
- 저장된 데이터를 다시 Python 객체로 복원하는 과정을 **역직렬화**(Deserialization)라고 함.
- CSV는 **표 형태의 데이터**, JSON은 **계층적인 구조의 데이터**를 표현할 때 특히 유용.
- 파일 기반 데이터 처리는 **파일 열기 → 읽기 → 자료형 변환 → 데이터 가공 → 파일 저장 → 다시 읽기** 흐름으로 이해하면 쉬움.
