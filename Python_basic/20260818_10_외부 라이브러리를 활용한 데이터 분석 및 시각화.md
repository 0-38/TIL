# **1. 파이썬 데이터 분석 라이브러리**

Python에서는 데이터 분석을 위해 `NumPy`, `Pandas`, `Matplotlib` 같은 외부 라이브러리를 자주 사용함.

각 라이브러리는 서로 역할이 다르며 함께 조합하여 사용하는 경우가 많음.

> ## **1-1 ) NumPy, Pandas, Matplotlib의 역할**

| 라이브러리 | 주요 역할 | 대표 사용 예 |
|---|---|---|
| `NumPy` | 수치 계산, 배열 연산 | 평균, 행렬 계산 |
| `Pandas` | 표 형태 데이터 처리 | 경기 기록, 선수 데이터 |
| `Matplotlib` | 데이터 시각화 | 기록 변화 그래프 |

[ python : code ] "수영 기록 데이터를 NumPy로 계산하고 Pandas로 정리하는 방법"

```python
import numpy as np
import pandas as pd

lap_times = np.array([
    31.2,
    30.8,
    30.5
])

print(
    "평균 기록:",
    np.mean(lap_times)
)

df_swim = pd.DataFrame({
    "구간": ["1구간", "2구간", "3구간"],
    "기록": lap_times
})

print(df_swim)
```

[ Result ]

```text
평균 기록: 30.833333333333332

    구간    기록
0  1구간  31.2
1  2구간  30.8
2  3구간  30.5
```

`NumPy`는 수치 계산을 담당하고 `Pandas`는 계산한 데이터를 행과 열 형태로 구성.

<br>

> ## **1-2 ) 데이터 분석 라이브러리 불러오기**

일반적으로 다음 별칭을 많이 사용.

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
```

| 라이브러리 | 일반적인 별칭 |
|---|---|
| `numpy` | `np` |
| `pandas` | `pd` |
| `matplotlib.pyplot` | `plt` |

별칭을 사용하면 긴 라이브러리 이름을 반복해서 작성하지 않아도 됨.

# **3. Pandas의 Series와 DataFrame**

Pandas에서 가장 기본적인 자료구조는 `Series`와 `DataFrame`.

> ## **3-1 ) Series**

`Series`는 인덱스를 가진 **1차원 데이터 구조**.

한 개의 열과 비슷하게 생각할 수 있음.

[ python : code ] "농구 선수의 경기별 득점을 Series로 만드는 방법"

```python
import pandas as pd

points = pd.Series([
    18,
    24,
    21,
    30
])

print(points)
```

[ Result ]

```text
0    18
1    24
2    21
3    30
dtype: int64
```

왼쪽의 `0`, `1`, `2`, `3`은 인덱스.

오른쪽 값은 실제 데이터.

<br>

> ## **3-2 ) DataFrame**

`DataFrame`은 여러 개의 행과 열로 구성된 **2차원 데이터 구조**.

[ python : code ] "육상 선수 기록을 DataFrame으로 생성하는 방법"

```python
import pandas as pd

running_data = {
    "선수": [
        "도윤",
        "하린",
        "태민"
    ],
    "100m기록": [
        11.2,
        11.8,
        10.9
    ]
}

df_running = pd.DataFrame(
    running_data
)

print(df_running)
```

[ Result ]

```text
    선수  100m기록
0  도윤     11.2
1  하린     11.8
2  태민     10.9
```

<br>

> ## **3-3 ) Series와 DataFrame 비교**

| 구분 | `Series` | `DataFrame` |
|---|---|---|
| 차원 | 1차원 | 2차원 |
| 구조 | 하나의 값 축 | 행과 열 |
| 예 | 선수 점수 한 열 | 선수명 + 점수 + 기록 |
| 생성 | `pd.Series()` | `pd.DataFrame()` |

```text
Series

0    18
1    24
2    21


DataFrame

   선수   득점
0 도윤   18
1 하린   24
2 태민   21
```

# **4. DataFrame 생성하기**

Python 딕셔너리를 `pd.DataFrame()`에 전달하면 간단하게 표 형태의 데이터 생성 가능.

> ## **4-1 ) 운동처방 데이터를 DataFrame으로 생성하기**

[ python : code ] "운동 대상자의 운동처방 데이터를 DataFrame으로 만드는 방법"

```python
import pandas as pd

exercise_data = {
    "이름": [
        "서아",
        "건우",
        "다은"
    ],
    "운동시간": [
        30,
        45,
        40
    ],
    "주당횟수": [
        3,
        4,
        3
    ]
}

df_exercise = pd.DataFrame(
    exercise_data
)

print(df_exercise)
```

[ Result ]

```text
    이름  운동시간  주당횟수
0  서아    30      3
1  건우    45      4
2  다은    40      3
```

딕셔너리의.

```python
"이름"
"운동시간"
"주당횟수"
```

가 DataFrame의 열 이름이 됨.

<br>

> ## **4-2 ) DataFrame의 기본 구성**

```text
          Column
        ↓
      운동시간
        ↓
0       30
1       45
2       40
↑
Index
```

DataFrame은 크게.

- `Index`
- `Column`
- `Value`

로 구성되어 있다고 이해하면 쉬움.

# **7. info()로 DataFrame 구조 확인하기**

`info()`는 DataFrame의 전체 구조를 빠르게 확인하는 데 사용.

주요 확인 정보.

- 행 개수
- 열 개수
- 열 이름
- Non-Null 개수
- 데이터 타입
- 메모리 사용량

> ## **7-1 ) 운동역학 데이터의 구조 확인**

[ python : code ] "점프 측정 데이터의 구조와 자료형을 info로 확인하는 방법"

```python

jump_data = {

        "예준",

        0.24,
        0.27,
        0.22,
        0.25
    ]

df_jump = pd.DataFrame(
    jump_data

df_jump.info()
```


# **8. describe()로 기초 통계 확인하기**

`describe()`는 수치형 열의 대표적인 기술통계를 자동으로 계산.

> ## **8-1 ) 러닝 기록의 기술통계 확인**

[ python : code ] "러닝 거리와 심박수의 기초 통계를 확인하는 방법"

```python
import pandas as pd

running_data = {
    "거리_km": [
        5,
        7,
        10,
        6,
        8
    ],
    "평균심박수": [
        145,
        152,
        158,
        149,
        154
    ]
}

df_running = pd.DataFrame(
    running_data
)

print(
    df_running.describe()
)
```

[ Result ]

```text
           거리_km      평균심박수
count    5.000000    5.000000
mean     7.200000  151.600000
std      1.923538    4.929503
min      5.000000  145.000000
25%      6.000000  149.000000
50%      7.000000  152.000000
75%      8.000000  154.000000
max     10.000000  158.000000
```

<br>

> ## **8-2 ) describe() 주요 통계량**

| 항목 | 의미 |
|---|---|
| `count` | 데이터 개수 |
| `mean` | 평균 |
| `std` | 표준편차 |
| `min` | 최솟값 |
| `25%` | 제1사분위수 |
| `50%` | 중앙값 |
| `75%` | 제3사분위수 |
| `max` | 최댓값 |

`describe()`만으로도 데이터의 범위와 중심, 분산 정도를 빠르게 파악 가능.

<br>

> ## **8-3 ) info()와 describe() 비교**

| 구분 | `info()` | `describe()` |
|---|---|---|
| 주요 목적 | 구조 확인 | 통계 확인 |
| 행/열 정보 | O | X |
| 자료형 | O | X |
| 결측치 파악 | O | 간접 확인 |
| 평균 | X | O |
| 표준편차 | X | O |
| 사분위수 | X | O |
| 최소/최대 | X | O |

데이터를 처음 받았다면 일반적으로.

```text
DataFrame 확인
      ↓
info()
      ↓
자료형 / 결측치 확인
      ↓
describe()
      ↓
수치 분포 확인
```

순서로 살펴볼 수 있음.

# **9. Matplotlib 기본 구조**

`Matplotlib`은 Python에서 널리 사용하는 외부 데이터 시각화 라이브러리.

`matplotlib.pyplot`을 일반적으로 `plt`라는 별칭으로 불러옴.

> ## **9-1 ) 선 그래프 만들기**

[ python : code ] "사이클 선수의 구간별 파워 변화를 선 그래프로 시각화하는 방법"

```python
import matplotlib.pyplot as plt

segments = [
    1,
    2,
    3,
    4,
    5
]

power = [
    220,
    245,
    238,
    260,
    275
]

plt.plot(
    segments,
    power
)

plt.show()
```

[ Result ]

```text
X축:
1 → 2 → 3 → 4 → 5

Y축:
220 → 245 → 238 → 260 → 275

각 값을 선으로 연결한 그래프 출력
```

<br>

> ## **9-2 ) Matplotlib 주요 함수**

| 함수 | 역할 |
|---|---|
| `plt.plot()` | 선 그래프 생성 |
| `plt.title()` | 제목 설정 |
| `plt.xlabel()` | X축 이름 |
| `plt.ylabel()` | Y축 이름 |
| `plt.grid()` | 격자 표시 |
| `plt.legend()` | 범례 표시 |
| `plt.show()` | 그래프 출력 |

# **10. 그래프에 제목과 축 이름 추가하기**

그래프는 단순히 선만 그리는 것보다 데이터가 무엇을 의미하는지 표시해야 해석하기 쉬움.

> ## **10-1 ) 농구 경기별 득점 변화**

[ python : code ] "농구 선수의 경기별 득점 변화를 선 그래프로 표현하는 방법"

```python
import matplotlib.pyplot as plt

games = [
    1,
    2,
    3,
    4,
    5
]

points = [
    15,
    21,
    18,
    27,
    24
]

plt.plot(
    games,
    points,
    marker="o",
    label="Points"
)

plt.title(
    "Points by Game"
)

plt.xlabel(
    "Game"
)

plt.ylabel(
    "Points"
)

plt.grid(True)
plt.legend()
plt.show()
```

[ Result ]

```text
경기별 득점 변화가 선 그래프로 출력됨.

1경기 → 15점
2경기 → 21점
3경기 → 18점
4경기 → 27점
5경기 → 24점

범례:
Points
```

`marker="o"`를 지정하면 실제 데이터 위치마다 점이 표시됨.

# **11. Pandas DataFrame과 Matplotlib 연결하기**

Pandas로 정리한 데이터를 별도의 리스트로 다시 만들지 않아도 DataFrame 열을 Matplotlib에 직접 전달 가능.

> ## **11-1 ) 수영 구간별 기록 변화 시각화**

[ python : code ] "DataFrame 열을 이용해 수영 구간별 기록을 시각화하는 방법"

```python
import pandas as pd

swim_data = {
    "구간": [
        1,
        2,
        3,
        4,
        5
    ],
    "기록": [
        31.2,
        30.8,
        30.4,
        30.7,
        30.1
    ]
}

df_swim = pd.DataFrame(
    swim_data
)

plt.plot(
    df_swim["구간"],
    df_swim["기록"],
    marker="o",
    label="Lap Time"
)

plt.title(
    "Swimming Lap Time"
)

plt.xlabel(
    "Lap"
```

```python
import pandas as pd
```

# **17. 핵심정리**

- `NumPy`는 수치 계산에 특화된 외부 라이브러리.
- `Pandas`는 표 형태의 데이터 처리에 특화된 외부 라이브러리.
- `Matplotlib`은 데이터를 그래프로 표현하는 외부 시각화 라이브러리.
- `NumPy`, `Pandas`, `Matplotlib`은 Python 표준 라이브러리가 아니라 별도 설치가 필요한 외부 패키지.
- `uv add pandas numpy matplotlib`을 이용하여 프로젝트 의존성으로 추가 가능.
- `NumPy`는 일반적으로 `np`, `Pandas`는 `pd`, `matplotlib.pyplot`은 `plt`라는 별칭 사용.
- `Series`는 인덱스를 가진 1차원 데이터 구조.
- `DataFrame`은 행과 열을 가진 2차원 데이터 구조.
- 딕셔너리를 `pd.DataFrame()`에 전달하여 DataFrame 생성 가능.
- DataFrame은 `Index`, `Column`, `Value` 구조로 이해할 수 있음.
- Jupyter Notebook에서는 셀 마지막에 DataFrame 변수만 작성하면 HTML 테이블 형태로 렌더링됨.
- `df.shape`은 DataFrame의 행과 열 개수 확인.
- `df.columns`는 열 이름 확인.
- `df.dtypes`는 각 열의 자료형 확인.
- `df.info()`는 DataFrame의 전체 구조, Non-Null 개수, 자료형 등을 확인.
- `df.describe()`는 수치형 데이터의 `count`, `mean`, `std`, 사분위수, 최소값, 최대값 등을 확인.
- `info()`는 **데이터 구조 확인**, `describe()`는 **통계적 특성 확인**에 초점을 둠.
- 실제 데이터 분석에서는 데이터를 불러온 직후 `info()`와 `describe()`를 사용하여 데이터 상태를 먼저 파악하는 것이 중요.
- `plt.plot()`은 선 그래프 생성.
- `plt.title()`은 그래프 제목 설정.
- `plt.xlabel()`과 `plt.ylabel()`은 축 이름 설정.
- `plt.grid()`는 격자 표시.
- `plt.legend()`는 범례 표시.
- `plt.show()`는 완성한 그래프 출력.
- `marker="o"`를 사용하면 실제 데이터 지점을 그래프 위에 표시 가능.
- Pandas DataFrame의 열을 Matplotlib의 X축과 Y축 데이터로 직접 전달 가능.
- Jupyter Notebook에서는 **데이터 작성 → DataFrame 생성 → 구조 확인 → 기초 통계 → 시각화 → 해석**을 한 문서 안에서 연속적으로 수행할 수 있음.
- 실제 데이터 분석의 기본 흐름은 **데이터 생성·불러오기 → 구조 확인 → 결측치·자료형 확인 → 기술통계 확인 → 필요한 분석 → 시각화 → 결과 해석**으로 이해하면 쉬움.
