# **1. 함수(Function)의 기본 개념**

함수(Function)는 특정 작업을 수행하는 코드를 하나의 이름으로 묶어둔 **재사용 가능한 코드 단위**.

같은 계산이나 처리 과정을 여러 번 작성하는 대신 함수로 만들어두면 필요할 때마다 호출하여 사용할 수 있음.

> ## **1-1 ) 함수가 필요한 이유**

예를 들어 선수의 운동 강도를 여러 번 계산해야 한다고 가정.

함수를 사용하지 않으면 같은 계산을 계속 작성해야 함.

```python
heart_rate_1 = 150
max_heart_rate_1 = 190
intensity_1 = heart_rate_1 / max_heart_rate_1 * 100

heart_rate_2 = 160
max_heart_rate_2 = 200
intensity_2 = heart_rate_2 / max_heart_rate_2 * 100
```

같은 계산 구조가 반복됨.

함수로 만들면 계산 방법을 한 번만 정의하고 여러 데이터에 재사용 가능.

[ python : code ] "심박수 기반 운동 강도를 계산하는 함수"

```python
def calculate_intensity(heart_rate, max_heart_rate):
    intensity = heart_rate / max_heart_rate * 100
    return intensity

runner_intensity = calculate_intensity(150, 190)
swimmer_intensity = calculate_intensity(160, 200)

print(f"러너 운동 강도   : {runner_intensity:.1f}%")
print(f"수영 선수 강도   : {swimmer_intensity:.1f}%")
```

[ Result ]

```text
러너 운동 강도   : 78.9%
수영 선수 강도   : 80.0%
```

함수를 사용하면.

```text
계산 로직 한 번 정의
        ↓
여러 데이터 입력
        ↓
동일한 계산 적용
        ↓
결과 재사용
```

가능.

<br>

> ## **1-2 ) 함수 정의와 호출**

함수는 `def` 키워드를 사용하여 정의.

```python
def 함수이름():
    실행할 코드
```

함수를 정의하는 것과 실행하는 것은 다름.

[ python : code ] "운동 시작 메시지를 함수로 정의하고 호출하는 방법"

```python
def start_training():
    print("워밍업을 시작합니다.")
    print("본 운동 준비를 완료했습니다.")

start_training()
```

[ Result ]

```text
워밍업을 시작합니다.
본 운동 준비를 완료했습니다.
```

실행 흐름.

```text
def start_training()
        ↓
함수 정의
        ↓
함수 객체 생성
        ↓
start_training()
        ↓
함수 호출
        ↓
함수 내부 코드 실행
```

`def`를 실행했다고 함수 내부 코드가 바로 실행되는 것은 아님.

함수 이름 뒤에 `()`를 붙여 `호출(Call)`해야 실행됨.

<br>

> ## **1-3 ) 함수 이름 작성 방법**

Python에서는 함수 이름도 일반적으로 `snake_case` 사용.

```python
calculate_speed()
calculate_average()
analyze_gait()
estimate_training_load()
```

함수가 어떤 작업을 수행하는지 알 수 있도록 **동작을 나타내는 이름**을 사용하는 것이 좋음.

# **2. 매개변수(Parameter)와 인수(Argument)**

함수는 외부에서 데이터를 전달받아 서로 다른 값을 처리할 수 있음.

> ## **2-1 ) Parameter와 Argument의 차이**

```python
def calculate_speed(distance, time):
    return distance / time
```

여기서.

```text
distance
time
```

은 **매개변수(Parameter)**.

함수를 정의할 때 입력받을 데이터의 이름을 지정한 것.

```python
calculate_speed(100, 12.5)
```

여기서.

```text
100
12.5
```

는 **인수(Argument)**.

함수를 실제 호출하면서 전달하는 값.

```text
함수 정의

distance, time
      ↓
Parameter


함수 호출

100, 12.5
   ↓
Argument
```

<br>

> ## **2-2 ) 위치 인수 Positional Argument**

위치 인수는 **매개변수 순서**를 기준으로 값을 전달.

[ python : code ] "100m 기록을 이용해 평균 속도를 계산하는 방법"

```python
def calculate_speed(distance, time):
    return distance / time

speed = calculate_speed(100, 12.5)

print(f"평균 속도: {speed:.2f} m/s")
```

[ Result ]

```text
평균 속도: 8.00 m/s
```

호출 과정.

```text
calculate_speed(100, 12.5)

100
 ↓
distance

12.5
 ↓
time
```

순서를 바꾸면 의미가 달라질 수 있으므로 주의.

<br>

> ## **2-3 ) 키워드 인수 Keyword Argument**

매개변수 이름을 직접 지정하여 값을 전달할 수도 있음.

[ python : code ] "키워드 인수로 체질량과 신장을 전달하는 방법"

```python
def calculate_bmi(weight, height):
    return weight / (height ** 2)

bmi = calculate_bmi(
    height=1.75,
    weight=70
)

print(f"BMI: {bmi:.2f}")
```

[ Result ]

```text
BMI: 22.86
```

키워드 인수는 매개변수 이름을 직접 지정했기 때문에 순서를 바꾸어도 됨.

```text
weight = 70
height = 1.75
```

처럼 의미가 명확하다는 장점도 있음.

※ BMI 예시는 Python 함수 구조를 설명하기 위한 단순 계산 예시이며 개인별 건강 상태를 판단하는 용도로 사용하지 않음.

# **3. 기본값 매개변수 Default Parameter**

함수를 정의할 때 매개변수에 기본값을 미리 지정할 수 있음.

호출할 때 해당 인수를 전달하지 않으면 기본값 사용.

> ## **3-1 ) 기본값 사용하기**

[ python : code ] "운동 세트 수에 기본값을 지정하는 방법"

```python
def show_training(exercise, sets=3):
    print(f"운동 종목 : {exercise}")
    print(f"운동 세트 : {sets}세트")

show_training("Squat")
```

[ Result ]

```text
운동 종목 : Squat
운동 세트 : 3세트
```

`sets` 값을 직접 전달하면 기본값 대신 전달한 값 사용.

```python
show_training("Squat", 5)
```

[ Result ]

```text
운동 종목 : Squat
운동 세트 : 5세트
```

<br>

> ## **3-2 ) 기본값 매개변수의 위치**

기본값이 없는 매개변수는 기본값이 있는 매개변수보다 앞에 작성.

정상.

```python
def show_training(exercise, sets=3):
    pass
```

잘못된 예.

```python
def show_training(sets=3, exercise):
    pass
```

[ Result ]

```text
SyntaxError
```

함수를 호출할 때 값을 어떤 매개변수에 연결해야 하는지 모호해지기 때문.

# **4. 가변 인수 args와 kwargs**

함수를 만들 때 입력 데이터의 개수가 항상 정해져 있는 것은 아님.

이때 가변 인수 사용.

> ## **4-1 ) *args**

`*args`는 여러 개의 **위치 인수**를 하나의 튜플로 묶어 받음.

[ python : code ] "여러 경기의 농구 득점을 한 번에 전달하는 방법"

```python
def calculate_total_score(*scores):
    print(scores)
    return sum(scores)

total = calculate_total_score(18, 24, 21, 30)

print(f"총 득점: {total}")
```

[ Result ]

```text
(18, 24, 21, 30)
총 득점: 93
```

함수 내부 구조.

```text
18, 24, 21, 30
        ↓
      *scores
        ↓
(18, 24, 21, 30)
        ↓
      tuple
```

<br>

> ## **4-2 ) *args를 이용한 평균 계산**

[ python : code ] "여러 번의 보행 속도 측정값 평균을 계산하는 방법"

```python
def calculate_average_speed(*speeds):
    if len(speeds) == 0:
        return 0

    total = sum(speeds)
    average = total / len(speeds)

    return average

result = calculate_average_speed(
    1.20,
    1.35,
    1.28,
    1.32
)

print(f"평균 보행 속도: {result:.2f} m/s")
```

[ Result ]

```text
평균 보행 속도: 1.29 m/s
```

<br>

> ## **4-3 ) 코드 결과 해석**

```text
입력

1.20, 1.35, 1.28, 1.32
        ↓
*speeds
        ↓
튜플로 패킹
        ↓
sum(speeds)
        ↓
5.15
        ↓
len(speeds)
        ↓
4
        ↓
5.15 / 4
        ↓
1.2875
        ↓
소수점 둘째 자리 출력
        ↓
1.29 m/s
```

<br>

> ## **4-4 ) `**kwargs`**

`**kwargs`는 `Key=Value` 형태의 인수를 하나의 딕셔너리로 받음.

[ python : code ] "야구 선수 정보를 키워드 가변 인수로 전달하는 방법"

```python
def show_player_info(**player):
    print(player)

    for key, value in player.items():
        print(f"{key}: {value}")

show_player_info(
    name="우영",
    position="Pitcher",
    wins=12
)
```

[ Result ]

```text
{'name': '우영', 'position': 'Pitcher', 'wins': 12}
name: 우영
position: Pitcher
wins: 12
```

구조.

```text
name="우영"
position="Pitcher"
wins=12
        ↓
     **player
        ↓
{
    "name": "우영",
    "position": "Pitcher",
    "wins": 12
}
        ↓
dictionary
```

<br>

> ## **4-5 ) args와 kwargs 비교**

| 구분 | `*args` | `**kwargs` |
|---|---|---|
| 전달 방식 | 위치 기반 | `key=value` |
| 함수 내부 자료형 | Tuple | Dictionary |
| 예시 | `func(10, 20)` | `func(age=20)` |
| 특징 | 개수 제한 없는 위치 인수 | 개수 제한 없는 키워드 인수 |

# **5. return으로 결과 반환하기**

함수 안에서 계산한 값을 함수 밖에서 사용하려면 `return` 사용.

> ## **5-1 ) print와 return의 차이**

`print()`는 화면에 값을 보여주는 기능.

`return`은 값을 함수 호출 위치로 전달하는 기능.

[ python : code ] "사이클링 평균 파워를 계산하여 반환하는 방법"

```python
def calculate_average_power(total_power, samples):
    average_power = total_power / samples
    return average_power

result = calculate_average_power(1250, 5)

print(result)
```

[ Result ]

```text
250.0
```

```text
calculate_average_power()
        ↓
함수 내부 계산
        ↓
250.0
        ↓
return
        ↓
함수 호출 위치로 반환
        ↓
result = 250.0
```

<br>

> ## **5-2 ) return을 만나면 함수가 종료됨**

[ python : code ] "측정값 조건에 따라 함수를 조기 종료하는 방법"

```python
def check_jump_height(height):
    if height < 0:
        return "잘못된 측정값"

    return f"점프 높이: {height}cm"

print(check_jump_height(-5))
print(check_jump_height(42))
```

[ Result ]

```text
잘못된 측정값
점프 높이: 42cm
```

첫 번째 호출에서는 `return "잘못된 측정값"`을 만나는 즉시 함수 종료.

<br>

> ## **5-3 ) 여러 값 반환하기**

Python에서는 여러 값을 쉼표로 구분하여 반환 가능.

실제로는 튜플로 묶여 반환됨.

[ python : code ] "러닝 기록의 최고 속도와 평균 속도를 함께 반환하는 방법"

```python
def analyze_speed(speeds):
    max_speed = max(speeds)
    average_speed = sum(speeds) / len(speeds)

    return max_speed, average_speed

max_speed, average_speed = analyze_speed(
    [4.2, 4.8, 5.1, 4.6]
)

print(f"최고 속도: {max_speed:.1f} m/s")
print(f"평균 속도: {average_speed:.2f} m/s")
```

[ Result ]

```text
최고 속도: 5.1 m/s
평균 속도: 4.68 m/s
```

실행 흐름.

```text
속도 리스트 입력
        ↓
max()
        ↓
최고 속도 계산
        ↓
sum() / len()
        ↓
평균 속도 계산
        ↓
return max_speed, average_speed
        ↓
튜플 형태로 반환
        ↓
언패킹
        ↓
max_speed
average_speed
```

# **6. 함수를 이용한 기능 분리**

함수의 중요한 목적 중 하나는 **한 프로그램의 여러 기능을 독립적으로 분리**하는 것.

하나의 함수에 모든 작업을 넣기보다 각 함수가 하나의 역할을 담당하도록 구성하면 코드를 이해하고 수정하기 쉬워짐.

> ## **6-1 ) 스포츠 기록 분석 기능 분리**

[ python : code ] "수영 기록의 평균과 최고 기록 계산 기능을 함수로 분리하는 방법"

```python
def calculate_average(times):
    return sum(times) / len(times)


def find_best_time(times):
    return min(times)


swim_times = [58.4, 57.9, 59.1, 57.5]

average_time = calculate_average(swim_times)
best_time = find_best_time(swim_times)

print(f"평균 기록: {average_time:.2f}초")
print(f"최고 기록: {best_time:.1f}초")
```

[ Result ]

```text
평균 기록: 58.23초
최고 기록: 57.5초
```

수영처럼 시간이 짧을수록 좋은 기록이라면 `min()`을 이용해 최고 기록 확인 가능.

<br>

> ## **6-2 ) 기능 분리의 흐름**

```text
원본 기록
    ↓
 ┌───────────────┐
 │ calculate_average()
 └───────────────┘
    ↓
평균 기록

원본 기록
    ↓
 ┌───────────────┐
 │ find_best_time()
 └───────────────┘
    ↓
최고 기록
```

하나의 기능을 수정해도 다른 함수에 미치는 영향을 줄일 수 있음.

# **7. 변수 스코프 Scope**

변수 스코프는 **변수를 사용할 수 있는 범위**를 의미.

함수 안에서 만든 변수와 함수 밖에서 만든 변수는 서로 다른 영역에 존재할 수 있음.

> ## **7-1 ) 전역 변수와 지역 변수**

함수 밖에서 만들어진 변수.

```python
competition = "전국체전"
```

은 전역 영역에 존재.

함수 내부에서 만들어진 변수는 해당 함수의 지역 영역에서 사용.

[ python : code ] "전역 변수와 지역 변수의 차이를 확인하는 방법"

```python
pace = 5.0

def analyze_running():
    pace = 4.2
    print(f"함수 내부 페이스: {pace}")

analyze_running()

print(f"함수 외부 페이스: {pace}")
```

[ Result ]

```text
함수 내부 페이스: 4.2
함수 외부 페이스: 5.0
```

같은 이름을 사용했지만 서로 다른 스코프의 변수.

```text
Global
pace = 5.0


analyze_running()
└─ Local
   pace = 4.2
```

지역 변수 `pace`가 전역 변수 `pace` 자체를 변경한 것은 아님.

<br>

> ## **7-2 ) 변수 은닉 Shadowing**

함수 내부에서 전역 변수와 같은 이름의 지역 변수를 만들면 함수 내부에서는 가까운 지역 변수가 우선 사용됨.

이를 **Variable Shadowing**이라고 함.

```text
Global pace = 5.0
        ↓
함수 진입

Local pace = 4.2 존재
        ↓
Local이 우선
        ↓
4.2 사용

함수 종료
        ↓
Global pace
        ↓
5.0 사용
```

# **8. LEGB 변수 탐색 규칙**

Python은 변수를 찾을 때 아무 곳이나 무작위로 찾지 않음.

다음 순서로 탐색.

```text
L → E → G → B
```

| 순서 | 영역 | 의미 |
|---|---|---|
| L | Local | 현재 함수 |
| E | Enclosing | 현재 함수를 감싸는 함수 |
| G | Global | 모듈의 전역 영역 |
| B | Built-in | Python 내장 영역 |

> ## **8-1 ) LEGB 동작 확인**

[ python : code ] "중첩 함수에서 LEGB 규칙으로 변수를 탐색하는 방법"

```python
sport = "Global Sport"

def outer():
    sport = "Running"

    def inner():
        sport = "Gait Analysis"
        print(sport)

    inner()

outer()
```

[ Result ]

```text
Gait Analysis
```

`inner()` 내부의 Local 영역에서 먼저 `sport`를 찾았기 때문에 더 바깥쪽까지 탐색하지 않음.

<br>

> ## **8-2 ) Local에 변수가 없다면**

[ python : code ] "Local 변수가 없을 때 Enclosing 변수를 사용하는 방법"


# **16. 종합 실습 - 보행 데이터 분석 함수 만들기**

측정된 보행 속도에서.

- `None`은 결측치로 제외
- 유효 측정값 개수 계산
- 평균 속도 계산
- 최고 속도 계산
- 평균 이상인 측정값 추출

을 수행.

> ## **16-1 ) 보행 속도 분석 함수**

[ python : code ] "결측치를 제외하고 보행 속도 데이터를 종합 분석하는 함수"

```python
def analyze_gait_speed(*speeds):

    valid_speeds = list(
        filter(
            lambda speed: speed is not None,
            speeds
        )
    )

    if len(valid_speeds) == 0:
        return 0, 0, []

    average_speed = (
        sum(valid_speeds)
        / len(valid_speeds)
    )

    max_speed = max(valid_speeds)

    above_average = list(
        filter(
            lambda speed: speed >= average_speed,
            valid_speeds
        )
    )

    return (
        average_speed,
        max_speed,
        above_average
    )


average, maximum, selected = analyze_gait_speed(
    1.10,
    1.25,
    None,
    1.35,
    1.20,
    1.40
)

print(f"평균 속도       : {average:.2f} m/s")
print(f"최고 속도       : {maximum:.2f} m/s")
print(f"평균 이상 측정값: {selected}")
```

[ Result ]

```text

최고 속도       : 1.40 m/s
```

```python
    {"name": "지훈", "points": 15}

ranking = sorted(
    players,
    key=lambda player: player["points"],
    reverse=True
)

print(ranking)
```

`lambda player: player["points"]`를 이용해 정렬 기준을 지정.

> ## **19-4 ) nonlocal**

중첩 함수에서 Enclosing 영역의 변수를 재할당하려면 `nonlocal`을 사용할 수 있음.

```python
def counter():
    count = 0

    def increase():
        nonlocal count
        count += 1
        return count

    return increase
```

`global`이 전역 변수를 대상으로 한다면 `nonlocal`은 자신을 감싸는 함수의 변수를 대상으로 함.

# **20. 핵심정리**

- 함수는 특정 기능을 하나로 묶어 **재사용 가능한 코드 구조**를 만드는 방법.
- `def`로 함수를 정의하고 `함수이름()`으로 호출.
- 함수 정의와 함수 실행은 서로 다른 과정.
- Parameter는 함수 정의부의 입력 변수.
- Argument는 함수를 호출할 때 실제 전달하는 값.
- 위치 인수는 순서를 기준으로 매핑.
- 키워드 인수는 `매개변수=값` 형태로 전달.
- 기본값 매개변수는 인수를 생략했을 때 사용할 기본값을 지정.
- 기본값이 있는 매개변수는 일반 매개변수 뒤에 작성.
- `*args`는 여러 위치 인수를 Tuple로 수집.
- `**kwargs`는 여러 키워드 인수를 Dictionary로 수집.
- `return`은 함수의 결과를 호출 위치로 전달.
- `return`이 실행되면 해당 함수 호출은 즉시 종료.
- 여러 값을 `return`하면 Tuple 형태로 반환되며 언패킹 가능.
- 기능별로 함수를 분리하면 코드 재사용성과 유지보수성이 높아짐.
- Scope는 변수를 사용할 수 있는 유효 범위.
- 함수 내부에 만들어진 변수는 Local 영역에 존재.
- 함수 밖의 변수는 Global 영역에 존재할 수 있음.
- 같은 이름의 지역 변수가 있으면 가까운 지역 변수가 우선되어 전역 이름을 가리는 Shadowing이 발생.
- Python은 **Local → Enclosing → Global → Built-in** 순서로 변수를 검색.
- 전역 변수를 함수 내부에서 재할당하려면 `global` 사용 가능.
- 전역 변수 직접 수정은 코드 추적을 어렵게 만들 수 있으므로 필요한 경우에만 사용하는 것이 좋음.
- `lambda`는 간단한 한 줄 함수를 작성할 때 사용.
- `map()`은 모든 데이터에 같은 변환을 적용.
- `filter()`는 조건을 만족하는 데이터만 선택.
- `map()`과 `filter()`를 연결하면 **원본 데이터 → 변환 → 필터링** 형태의 처리 가능.
- 함수는 변수에 저장하거나 다른 함수에 전달할 수 있는 **일급 객체**.
- 다른 함수를 인수로 받거나 함수를 반환하는 함수는 **고차 함수**.
- 스포츠 데이터 분석에서도 함수는 **입력 → 처리 → return → 결과 재사용** 구조로 이해하면 쉬움.
