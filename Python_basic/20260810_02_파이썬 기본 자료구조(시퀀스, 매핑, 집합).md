# **1. 리스트(List)와 튜플(Tuple)**

여러 개의 데이터를 하나의 변수에 묶어서 관리할 때 리스트와 튜플을 사용할 수 있음.

두 자료형은 모두 순서가 있는 **시퀀스(Sequence)** 자료형이지만, 생성 이후 데이터를 수정할 수 있는지 여부에서 차이가 있음.

> ## **1-1 ) 리스트 List**

리스트는 내부 요소를 추가·수정·삭제할 수 있는 **가변(Mutable) 자료형**.

대괄호 `[]`를 사용하여 생성.

[ python : code ] "선수 경기별 득점을 리스트에 저장하는 방법"

```python
player_name = "우영"
match_goals = [1, 0, 2, 1, 3]

print(player_name)
print(match_goals)
````

[ Result ]

```text
우영
[1, 0, 2, 1, 3]
```

리스트는 생성 후 내부 값을 변경할 수 있음.

[ python : code ] "리스트의 특정 경기 득점을 수정하는 방법"

```python
match_goals = [1, 0, 2, 1, 3]

match_goals[1] = 1

print(match_goals)
```

[ Result ]

```text
[1, 1, 2, 1, 3]
```

<br>

> ## **1-2 ) 튜플 Tuple**

튜플은 생성 후 각 위치의 요소를 다른 값으로 재할당할 수 없는 **불변(Immutable) 자료형**.

일반적으로 소괄호 `()` 사용.

[ python : code ] "축구 경기장 좌표를 튜플에 저장하는 방법"

```python
stadium_location = (37.5665, 126.9780)

print(stadium_location)
```

[ Result ]

```text
(37.5665, 126.978)
```

다음과 같이 요소를 수정하려고 하면 오류 발생.

```python
stadium_location[0] = 38.0
```

[ Result ]

```text
TypeError
```

<br>

> ## **1-3 ) 리스트와 튜플 비교**

| 구분       | 리스트        | 튜플         |
| -------- | ---------- | ---------- |
| 생성       | `[]`       | `()`       |
| 순서       | 있음         | 있음         |
| 인덱싱      | 가능         | 가능         |
| 슬라이싱     | 가능         | 가능         |
| 요소 수정    | 가능         | 불가능        |
| 요소 추가·삭제 | 가능         | 불가능        |
| 특징       | Mutable    | Immutable  |
| 활용       | 변경되는 경기 기록 | 좌표, 고정 데이터 |

<br>

> ## **1-4 ) 튜플에서 중요한 것은 쉼표**

튜플은 소괄호보다 `,`가 핵심.

```python
player = "우영", 10, "MF"

print(player)
print(type(player))
```

[ Result ]

```text
('우영', 10, 'MF')
<class 'tuple'>
```

요소가 하나인 튜플은 반드시 쉼표 필요.

```python
data = (10,)

print(type(data))
```

[ Result ]

```text
<class 'tuple'>
```

# **2. 인덱싱(Indexing)과 슬라이싱(Slicing)**

리스트와 튜플처럼 순서가 있는 자료형은 위치를 이용하여 원하는 데이터를 가져올 수 있음.

> ## **2-1 ) 정방향 인덱싱**

Python의 인덱스는 `0`부터 시작.

```text
값       1    0    2    1    3
        ↑    ↑    ↑    ↑    ↑
index   0    1    2    3    4
```

[ python : code ] "첫 번째 경기의 득점을 인덱싱으로 가져오는 방법"

```python
match_goals = [1, 0, 2, 1, 3]

first_match = match_goals[0]

print(first_match)
```

[ Result ]

```text
1
```

<br>

> ## **2-2 ) 음수 인덱싱**

뒤에서부터 접근할 때는 음수 인덱스 사용.

```text
값       1    0    2    1    3
음수    -5   -4   -3   -2   -1
```

[ python : code ] "가장 최근 경기의 득점을 확인하는 방법"

```python
match_goals = [1, 0, 2, 1, 3]

latest_goal = match_goals[-1]

print(latest_goal)
```

[ Result ]

```text
3
```

<br>

> ## **2-3 ) 기본 슬라이싱**

기본 구조.

```python
data[start:stop:step]
```

[ python : code ] "두 번째부터 네 번째 경기 기록을 추출하는 방법"

```python
match_goals = [1, 0, 2, 1, 3, 2]

selected_goals = match_goals[1:4]

print(selected_goals)
```

[ Result ]

```text
[0, 2, 1]
```

`start`는 포함하고 `stop`은 포함하지 않음.

```text
match_goals[1:4]

index 1 이상
index 4 미만

↓
index 1, 2, 3

↓
[0, 2, 1]
```

<br>

> ## **2-4 ) step 사용하기**

[ python : code ] "두 칸 간격으로 경기 기록을 추출하는 방법"

```python
match_goals = [1, 0, 2, 1, 3, 2]

print(match_goals[::2])
```

[ Result ]

```text
[1, 2, 3]
```

<br>

> ## **2-5 ) 역순으로 출력하기**

[ python : code ] "가장 최근 경기부터 역순으로 기록을 확인하는 방법"

```python
match_goals = [1, 0, 2, 1, 3]

reverse_goals = match_goals[::-1]

print(reverse_goals)
```

[ Result ]

```text
[3, 1, 2, 0, 1]
```

# **3. 시퀀스의 공통 연산과 패킹·언패킹**

리스트와 튜플 같은 시퀀스 자료형에는 공통으로 사용할 수 있는 연산이 존재.

> ## **3-1 ) 시퀀스 연결 +**

[ python : code ] "두 팀의 선수 명단을 하나로 연결하는 방법"

```python
team_a = ["우영", "민수"]
team_b = ["준호", "지훈"]

players = team_a + team_b

print(players)
```

[ Result ]

```text
['우영', '민수', '준호', '지훈']
```

<br>

> ## **3-2 ) 시퀀스 반복**

```python
goal_pattern = [1, 0]

print(goal_pattern * 3)
```

[ Result ]

```text
[1, 0, 1, 0, 1, 0]
```

<br>

> ## **3-3 ) len()**

[ python : code ] "선수 명단의 인원수를 확인하는 방법"

```python
players = ["우영", "민수", "준호", "지훈"]

print(len(players))
```

[ Result ]

```text
4
```

<br>

> ## **3-4 ) in과 not in**

[ python : code ] "선수가 명단에 포함되어 있는지 확인하는 방법"

```python
players = ["우영", "민수", "준호", "지훈"]

print("우영" in players)
print("철수" not in players)
```

[ Result ]

```text
True
True
```

<br>

> ## **3-5 ) 패킹 Packing**

[ python : code ] "선수 정보를 하나의 튜플로 패킹하는 방법"

```python
player = "우영", 10, "MF"

print(player)
print(type(player))
```

[ Result ]

```text
('우영', 10, 'MF')
<class 'tuple'>
```

<br>

> ## **3-6 ) 언패킹 Unpacking**

[ python : code ] "튜플의 선수 정보를 각각의 변수로 분리하는 방법"

```python
player = ("우영", 10, "MF")

player_name, player_number, position = player

print(player_name)
print(player_number)
print(position)
```

[ Result ]

```text
우영
10
MF
```

<br>

> ## **3-7 ) 가변 언패킹**

[ python : code ] "첫 경기 기록과 나머지 경기 기록을 분리하는 방법"

```python
match_goals = [2, 1, 0, 3, 1]

first_goal, *other_goals = match_goals

print(first_goal)
print(other_goals)
```

[ Result ]

```text
2
[1, 0, 3, 1]
```

<br>

> ## **3-8 ) 패킹·언패킹 흐름**

```text
"우영", 10, "MF"
        ↓
Packing
        ↓
("우영", 10, "MF")
        ↓
player
        ↓
Unpacking
        ↓
player_name = "우영"
player_number = 10
position = "MF"
```

# **4. 딕셔너리(Dictionary)**

딕셔너리는 값을 위치가 아니라 **Key를 이용해 조회하는 자료구조**.

선수 이름, 득점, 도움처럼 각 값의 의미가 명확할 때 사용하기 좋음.

> ## **4-1 ) Key-Value 구조**

[ python : code ] "축구 선수 정보를 딕셔너리로 저장하는 방법"

```python
player = {
    "name": "우영",
    "number": 10,
    "goals": 12,
    "assists": 7
}

print(player)
```

[ Result ]

```text
{'name': '우영', 'number': 10, 'goals': 12, 'assists': 7}
```

```text
Key          Value
-----------------
name      →  우영
number    →  10
goals     →  12
assists   →  7
```

<br>

> ## **4-2 ) Key를 이용한 조회**

[ python : code ] "딕셔너리에서 선수 이름과 득점을 조회하는 방법"

```python
player = {
    "name": "우영",
    "goals": 12
}

print(player["name"])
print(player["goals"])
```

[ Result ]

```text
우영
12
```

<br>

> ## **4-3 ) 값 수정과 추가**

[ python : code ] "선수 득점을 수정하고 도움 정보를 추가하는 방법"

```python
player = {
    "name": "우영",
    "goals": 12
}

player["goals"] = 13
player["assists"] = 7

print(player)
```

[ Result ]

```text
{'name': '우영', 'goals': 13, 'assists': 7}
```

딕셔너리는 Mutable 자료형.

같은 Key에 다시 값을 저장하면 기존 값이 변경됨.

<br><br>

# **5. 딕셔너리 주요 메서드**

> ## **5-1 ) keys()**

[ python : code ] "딕셔너리의 모든 Key를 확인하는 방법"

```python
player = {
    "name": "우영",
    "goals": 12,
    "assists": 7
}

print(player.keys())
```

[ Result ]

```text
dict_keys(['name', 'goals', 'assists'])
```

<br>

> ## **5-2 ) values()**

[ python : code ] "딕셔너리의 모든 Value를 확인하는 방법"

```python
player = {
    "name": "우영",
    "goals": 12,
    "assists": 7
}

print(player.values())
```

[ Result ]

```text
dict_values(['우영', 12, 7])
```

<br>

> ## **5-3 ) items()**

[ python : code ] "딕셔너리의 Key와 Value를 함께 확인하는 방법"

```python
player = {
    "name": "우영",
    "goals": 12,
    "assists": 7
}

print(player.items())
```

[ Result ]

```text
dict_items([('name', '우영'), ('goals', 12), ('assists', 7)])
```

<br>

> ## **5-4 ) get()**

존재하지 않는 Key를 `[]`로 조회하면 `KeyError`.

`get()`은 Key가 없어도 안전하게 기본값을 반환할 수 있음.

[ python : code ] "존재하지 않는 선수 평점을 기본값으로 조회하는 방법"

```python
player = {
    "name": "우영",
    "goals": 12
}

rating = player.get("rating", 0.0)

print(rating)
```

[ Result ]

```text
0.0
```

| 조회 방법                    | Key 있음 | Key 없음     |
| ------------------------ | ------ | ---------- |
| `dict[key]`              | 값 반환   | `KeyError` |
| `dict.get(key)`          | 값 반환   | `None`     |
| `dict.get(key, default)` | 값 반환   | 기본값 반환     |

# **6. 집합(Set)**

집합은 **중복을 허용하지 않는 자료구조**.

중복 제거와 집합 연산에 적합.

> ## **6-1 ) 중복 제거**

[ python : code ] "중복된 선수 등번호를 제거하는 방법"

```python
player_numbers = [7, 10, 7, 9, 10, 11]

unique_numbers = set(player_numbers)

print(unique_numbers)
```

[ Result ]

```text
{7, 9, 10, 11}
```

집합의 출력 순서는 보장되지 않음.

<br>

> ## **6-2 ) 집합은 인덱싱할 수 없음**

```python
unique_numbers[0]
```

[ Result ]

```text
TypeError
```

위치 기반 순서가 없기 때문에 인덱싱과 슬라이싱 불가능.

<br>

> ## **6-3 ) 교집합**

[ python : code ] "두 팀에 공통으로 등록된 선수 ID를 찾는 방법"

```python
team_a = {101, 102, 103, 104}
team_b = {103, 104, 105, 106}

common_players = team_a & team_b

print(common_players)
```

[ Result ]

```text
{103, 104}
```

<br>

> ## **6-4 ) 합집합**

```python
all_players = team_a | team_b

print(all_players)
```

[ Result ]

```text
{101, 102, 103, 104, 105, 106}
```

<br>

> ## **6-5 ) 차집합**

```python
only_team_a = team_a - team_b

print(only_team_a)
```

[ Result ]

```text
{101, 102}
```

<br>

> ## **6-6 ) 집합 연산 비교**

| 연산    | 문법       | 의미           |
| ----- | -------- | ------------ |
| 교집합   | `A & B`  | 양쪽 모두 포함     |
| 합집합   | `A \| B` | 둘 중 하나 이상 포함 |
| 차집합   | `A - B`  | A에만 포함       |
| 포함 여부 | `x in A` | x 존재 여부 확인   |

# **7. 자료구조 간 상호 변환**

실제 데이터 분석에서는 목적에 따라 자료구조를 서로 변환하여 사용.

> ## **7-1 ) list, tuple, set 변환**

[ python : code ] "리스트를 튜플과 집합으로 변환하는 방법"

```python
players = ["우영", "민수", "우영", "지훈"]

player_tuple = tuple(players)
player_set = set(players)

print(player_tuple)
print(player_set)
```

[ Result ]

```text
('우영', '민수', '우영', '지훈')
{'우영', '민수', '지훈'}
```

집합 출력 순서는 달라질 수 있음.

<br>

> ## **7-2 ) set으로 중복 제거하기**

[ python : code ] "선수 명단의 중복을 제거하고 다시 리스트로 만드는 방법"

```python
players = ["우영", "민수", "우영", "지훈", "민수"]

unique_players = list(set(players))

print(unique_players)
```

[ Result ]

```text
출력 순서는 달라질 수 있음.

예:
['우영', '민수', '지훈']
```

실행 흐름.

```text
원본 리스트
        ↓
set()
        ↓
중복 제거
        ↓
list()
        ↓
다시 리스트로 변환
```

<br>

> ## **7-3 ) 순서를 유지하면서 중복 제거하기**

[ python : code ] "선수 명단의 기존 순서를 유지하면서 중복을 제거하는 방법"

```python
players = ["우영", "민수", "우영", "지훈", "민수"]

unique_players = list(dict.fromkeys(players))

print(unique_players)
```

[ Result ]

```text
['우영', '민수', '지훈']
```

# **8. 자료구조 전체 비교**

> ## **8-1 ) list, tuple, dict, set 비교**

| 자료형     | 예시               | 순서       | 중복        | 수정  | 주요 접근 방법 |
| ------- | ---------------- | -------- | --------- | --- | -------- |
| `list`  | `[1, 2]`         | 있음       | 가능        | 가능  | 인덱스      |
| `tuple` | `(1, 2)`         | 있음       | 가능        | 불가능 | 인덱스      |
| `dict`  | `{"name": "우영"}` | 삽입 순서 유지 | Key 중복 불가 | 가능  | Key      |
| `set`   | `{1, 2}`         | 위치 순서 없음 | 불가능       | 가능  | 값 탐색     |

자료 선택 기준.

```text
순서가 있고 자주 수정
→ list

순서가 있고 변경하지 않음
→ tuple

Key를 기준으로 데이터 관리
→ dict

중복 제거 / 집합 연산
→ set
```

# **9. 스포츠 데이터 종합 실습**

앞에서 배운 자료구조를 하나의 예제로 연결.

> ## **9-1 ) 선수 시즌 기록 정리하기**

[ python : code ] "여러 자료구조를 이용해 선수 시즌 기록을 정리하는 방법"

```python
player_name = "우영"

match_goals = [1, 0, 2, 1, 3, 2]

player_info = {
    "name": player_name,
    "number": 10,
    "position": "MF",
    "team": "Seoul FC"
}

tournament_teams = (
    "Seoul FC",
    "Busan FC",
    "Suwon FC"
)

scored_opponents = [
    "Busan FC",
    "Suwon FC",
    "Busan FC",
    "Incheon FC"
]

recent_goals = match_goals[-3:]
recent_total = sum(recent_goals)

unique_opponents = set(scored_opponents)

player_number = player_info["number"]
position = player_info["position"]

print(f"선수 이름      : {player_name}")
print(f"등번호         : {player_number}")
print(f"포지션         : {position}")
print(f"전체 경기 득점 : {match_goals}")
print(f"최근 3경기     : {recent_goals}")
print(f"최근 3경기 득점: {recent_total}")
print(f"득점 상대 팀   : {unique_opponents}")
```

# **11. 핵심정리**

* 학습 순서는 **리스트·튜플 → 인덱싱·슬라이싱 → 시퀀스 연산·패킹 → 딕셔너리 → 집합 → 자료구조 변환** 순서.
* `list`는 Mutable, `tuple`은 Immutable.
* Python 인덱스는 `0`부터 시작.
* `-1`은 마지막 요소.
* 슬라이싱은 `[start:stop:step]` 구조.
* `start`는 포함하고 `stop`은 포함하지 않음.
* `[::-1]`은 역순으로 데이터를 확인할 때 사용.
* `+`는 시퀀스 연결, `*`는 반복.
* `len()`은 데이터 개수 확인.
* `in`, `not in`은 포함 여부 확인.
* 패킹은 여러 값을 하나로 묶는 것.
* 언패킹은 하나의 자료구조를 여러 변수로 분리하는 것.
* `*변수`는 남은 요소들을 리스트로 수집.
* 딕셔너리는 `Key-Value` 구조.
* `keys()`, `values()`, `items()`로 딕셔너리 데이터를 확인할 수 있음.
* `get()`은 존재하지 않는 Key를 안전하게 조회할 때 사용.
* 집합은 중복을 허용하지 않음.
* 집합에서는 인덱싱과 슬라이싱을 사용할 수 없음.
* `&`는 교집합, `|`는 합집합, `-`는 차집합.
* `set()`을 이용하면 중복 제거 가능.
* `list(set(data))`는 중복 제거는 가능하지만 원래 순서를 보장하지 않음.
* 순서를 유지하며 중복을 제거하려면 `list(dict.fromkeys(data))` 사용 가능.
* `list`, `tuple`, `dict`, `set`은 데이터의 성격에 따라 적절하게 선택해야 함.
