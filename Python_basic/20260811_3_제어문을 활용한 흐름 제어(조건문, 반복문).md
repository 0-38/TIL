# **1. 조건문으로 실행 흐름 제어하기**

조건문은 조건의 결과에 따라 **실행할 코드를 선택하는 문법**.

Python에서는 `if`, `elif`, `else`를 이용하여 프로그램의 실행 경로를 결정할 수 있음.

> ## **1-1 ) if문의 기본 구조**

`if`는 조건식의 결과가 `True`일 때만 하위 코드를 실행.

```python
if 조건식:
    실행할 코드
```

조건식 뒤에는 반드시 `:`을 작성하고 내부 코드는 들여쓰기해야 함.

Python에서는 일반적으로 **공백 4칸** 사용.

[ python : code ] "선수가 출전 기준을 충족했는지 확인하는 방법"

```python
player_name = "우영"
stamina = 85

if stamina >= 70:
    print(f"{player_name} 선수는 출전 가능합니다.")
```

[ Result ]

```text
우영 선수는 출전 가능합니다.
```

실행 흐름.

```text
stamina = 85
      ↓
85 >= 70 ?
      ↓
   True
      ↓
if 내부 코드 실행
      ↓
우영 선수는 출전 가능합니다.
```

<br>

> ## **1-2 ) 들여쓰기 Indentation**

Python은 `{}` 대신 **들여쓰기**로 코드 블록을 구분.

정상 코드.

```python
stamina = 85

if stamina >= 70:
    print("출전 가능")
    print("선발 명단에 등록")
```

[ Result ]

```text
출전 가능
선발 명단에 등록
```

잘못된 예.

```python
if stamina >= 70:
    print("출전 가능")
   print("선발 명단에 등록")
```

들여쓰기가 맞지 않으므로 `IndentationError`가 발생할 수 있음.

# **2. if-else로 두 가지 상황 처리하기**

조건이 `True`일 때와 `False`일 때 서로 다른 코드를 실행하려면 `if-else` 사용.

> ## **2-1 ) if-else 기본 구조**

```python
if 조건식:
    조건이 True일 때 실행
else:
    조건이 False일 때 실행
```

[ python : code ] "선수 체력에 따라 출전 가능 여부를 판단하는 방법"

```python
player_name = "우영"
stamina = 55

if stamina >= 70:
    print(f"{player_name} 선수는 출전 가능합니다.")
else:
    print(f"{player_name} 선수는 휴식이 필요합니다.")
```

[ Result ]

```text
우영 선수는 휴식이 필요합니다.
```

실행 흐름.

```text
stamina = 55
      ↓
55 >= 70 ?
   ↙     ↘
True    False
          ↓
        else
          ↓
우영 선수는 휴식이 필요합니다.
```

# **3. if-elif-else로 여러 조건 처리하기**

조건이 두 개보다 많다면 `elif`를 사용하여 여러 갈래로 분기 가능.

Python은 위에서 아래로 조건을 확인하고 **처음으로 `True`가 된 블록 하나만 실행**.

> ## **3-1 ) 다중 조건 분기**

[ python : code ] "선수 평점에 따라 경기 등급을 분류하는 방법"

```python
rating = 9.2

if rating >= 9.0:
    grade = "S"
elif rating >= 8.0:
    grade = "A"
elif rating >= 7.0:
    grade = "B"
else:
    grade = "C"

print(grade)
```

[ Result ]

```text
S
```

실행 흐름.

```text
rating = 9.2
      ↓
9.2 >= 9.0 ?
      ↓
    True
      ↓
grade = "S"
      ↓
나머지 elif / else는 실행하지 않음
```

<br>

> ## **3-2 ) 조건 순서가 중요한 이유**

다음 코드는 문법 오류는 없지만 **논리적인 결과가 잘못될 수 있음.**

[ python : code ] "조건 순서를 잘못 작성한 경우"

```python
score = 95

if score >= 80:
    print("B")
elif score >= 90:
    print("A")
```

[ Result ]

```text
B
```

`95`는 이미 첫 번째 조건인 `score >= 80`을 만족하기 때문에 아래의 `score >= 90`은 검사하지 않음.

올바르게 작성.

[ python : code ] "점수 범위를 올바른 순서로 분기하는 방법"

```python
score = 95

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
else:
    print("C")
```

[ Result ]

```text
A
```

조건이 서로 포함 관계라면 단순히 "높은 숫자"가 아니라 **더 제한적이고 구체적인 조건을 먼저 작성하는 것이 중요**.

# **4. 중첩 조건문과 논리 연산자**

조건문 내부에 다시 조건문을 작성할 수 있으며 이를 중첩 조건문(Nested if)이라고 함.

> ## **4-1 ) 중첩 if문**

[ python : code ] "선수의 부상 여부와 체력을 순서대로 확인하는 방법"

```python
player_name = "우영"
is_injured = False
stamina = 85

if not is_injured:
    if stamina >= 70:
        print(f"{player_name} 선수는 선발 출전 가능합니다.")
```

[ Result ]

```text
우영 선수는 선발 출전 가능합니다.
```

실행 흐름.

```text
is_injured = False
        ↓
not False
        ↓
True
        ↓
stamina >= 70 ?
        ↓
85 >= 70
        ↓
True
        ↓
선발 출전 가능
```

<br>

> ## **4-2 ) 논리 연산자로 조건 합치기**

조건이 단순하다면 `and`, `or`, `not`을 이용해 하나의 조건식으로 작성 가능.

[ python : code ] "논리 연산자를 사용하여 출전 조건을 하나로 결합하는 방법"

```python
player_name = "우영"
is_injured = False
stamina = 85

if not is_injured and stamina >= 70:
    print(f"{player_name} 선수는 선발 출전 가능합니다.")
```

[ Result ]

```text
우영 선수는 선발 출전 가능합니다.
```

# **5. for문으로 반복하기**

`for`문은 리스트, 튜플, 문자열 등의 데이터를 **하나씩 순회**할 때 사용.

반복할 대상이나 범위가 명확할 때 주로 활용.

```python
players = ["우영", "민수", "지훈"]

for player in players:
    print(player)
```

[ Result ]

```text

민수
지훈
```

```text

        ↓

        ↓
player = "민수"
        ↓
출력
        ↓
player = "지훈"
        ↓
출력
        ↓
반복 종료
```

# **6. while문으로 조건이 참인 동안 반복하기**

`while`문은 조건식이 `True`인 동안 반복.

반복 횟수를 미리 알기 어려운 상황에서 주로 사용.

> ## **6-1 ) while 기본 구조**

[ python : code ] "남은 훈련 횟수가 0이 될 때까지 반복하는 방법"

```python
training_count = 3

while training_count > 0:
    print(f"남은 훈련: {training_count}회")
    training_count -= 1

print("훈련 완료")
```

[ Result ]

```text
남은 훈련: 3회
남은 훈련: 2회
남은 훈련: 1회
훈련 완료
```

실행 흐름.

```text
training_count = 3
        ↓
3 > 0 → True
        ↓
3 출력
        ↓
training_count = 2
        ↓
2 > 0 → True
        ↓
2 출력
        ↓
training_count = 1
        ↓
1 > 0 → True
        ↓
1 출력
        ↓
training_count = 0
        ↓
0 > 0 → False
        ↓
while 종료
```

<br>

> ## **6-2 ) for와 while 비교**

| 구분 | `for` | `while` |
|---|---|---|
| 반복 기준 | 데이터 또는 범위 | 조건 |
| 반복 횟수 | 비교적 명확 | 미리 모를 수 있음 |
| 대표 활용 | 선수 목록 순회 | 특정 상태까지 반복 |
| 종료 기준 | 순회 대상 종료 | 조건이 `False` |
| 주의점 | 비교적 안전 | 무한 루프 가능 |

<br>

> ## **6-3 ) 무한 루프**

다음 코드에는 `count`를 변경하는 코드가 없기 때문에 무한 반복.

```python
count = 1

while count <= 5:
    print(count)
```

수정.

[ python : code ] "상태값을 변경하여 while 반복을 종료하는 방법"

```python
count = 1

while count <= 5:
    print(count)
    count += 1
```

[ Result ]

```text
1
2
3
4
5
```

Jupyter Notebook에서 의도하지 않은 무한 루프가 발생하면 `Interrupt Kernel`을 사용하여 실행 중단 가능.

# **7. break와 continue**

반복문의 흐름을 중간에 변경할 때 사용.

> ## **7-1 ) break**

`break`는 자신이 포함된 **가장 가까운 반복문을 즉시 종료**.

[ python : code ] "목표 선수를 찾으면 검색을 종료하는 방법"

```python
players = ["민수", "지훈", "우영", "준호"]

for player in players:
    print(f"{player} 확인 중")

    if player == "우영":
        print("우영 선수를 찾았습니다.")
        break
```

[ Result ]

```text
민수 확인 중
지훈 확인 중
우영 확인 중
우영 선수를 찾았습니다.
```

`우영`을 찾은 시점에서 반복문이 종료되므로 `준호`는 확인하지 않음.

<br>

> ## **7-2 ) continue**

`continue`는 반복문을 종료하지 않고 **현재 반복의 남은 코드만 건너뛰고 다음 반복으로 이동**.

[ python : code ] "결측 경기 기록을 건너뛰는 방법"

```python
match_scores = [8.5, None, 7.8, 9.1, None]

for score in match_scores:
    if score is None:
        continue

    print(score)
```

[ Result ]

```text
8.5
7.8
9.1
```

실행 흐름.

```text
score = 8.5
    ↓
None 아님
    ↓
출력

score = None
    ↓
continue
    ↓
아래 코드 생략
    ↓
다음 반복
```

# **8. 중첩 반복문**

반복문 내부에 다시 반복문을 사용하는 구조.

2차원 데이터나 그룹별 데이터를 순회할 때 활용.

> ## **8-1 ) 팀별 선수 순회하기**

[ python : code ] "여러 팀의 선수 명단을 이중 반복문으로 출력하는 방법"

```python
teams = [
    ["우영", "민수"],
    ["지훈", "준호"]
]

for team in teams:
    for player in team:
        print(player)
```

[ Result ]

```text
우영
민수
지훈
준호
```

실행 흐름.

```text
첫 번째 팀
["우영", "민수"]
        ↓
우영
        ↓
민수
        ↓
두 번째 팀
["지훈", "준호"]
        ↓
지훈
        ↓
준호
```

<br>

> ## **8-2 ) 중첩 반복문의 반복 횟수**

예를 들어.

```python

    for column in range(3):

```

```text

```

바깥 반복 `2회 ×` 내부 반복 `3회`이므로 내부 `print()`는 총 `6회` 실행.

# **9. 반복문과 조건문으로 데이터 필터링하기**

# **10. 누적 변수를 이용한 데이터 집계**

반복하면서 값을 계속 더하거나 비교하면 합계, 평균, 최댓값, 최솟값 계산 가능.

> ## **10-1 ) 합계 계산**

[ python : code ] "선수의 경기별 득점 합계를 반복문으로 계산하는 방법"

```python
match_goals = [1, 2, 0, 3, 1]

total_goals = 0

for goals in match_goals:
    total_goals += goals

print(total_goals)
```

[ Result ]

```text
7
```

누적 과정.

```text
0
↓
0 + 1 = 1
↓
1 + 2 = 3
↓
3 + 0 = 3
↓
3 + 3 = 6
↓
6 + 1 = 7
```

<br>

> ## **10-2 ) 평균 계산**

[ python : code ] "경기별 평점의 평균을 반복문으로 계산하는 방법"

```python
ratings = [8.0, 9.0, 7.5, 8.5]

total = 0

for rating in ratings:
    total += rating

average = total / len(ratings)

print(average)
```

[ Result ]

```text
8.25
```

계산.

```text
8.0 + 9.0 + 7.5 + 8.5
= 33.0

33.0 / 4
= 8.25
```

<br>

> ## **10-3 ) 최댓값과 최솟값 직접 찾기**

첫 번째 값을 기준값으로 설정한 뒤 **두 번째 값부터 비교하면 불필요한 자기 자신과의 비교를 줄일 수 있음.**

[ python : code ] "경기별 평점의 최댓값과 최솟값을 직접 찾는 방법"

```python
ratings = [8.5, 9.2, 7.8, 6.9, 9.5, 8.1]

highest_rating = ratings[0]
lowest_rating = ratings[0]

for rating in ratings[1:]:
    if rating > highest_rating:
        highest_rating = rating

    if rating < lowest_rating:
        lowest_rating = rating

print(f"최고 평점: {highest_rating}")

```

# **11. 조건문과 반복문 종합 스포츠 실습**

다음 기준으로 우영 선수의 경기 기록을 분석.

- `None`은 결장 경기이므로 제외
- 평점 `8.0` 이상은 좋은 경기
- 유효 경기 수 계산
- 좋은 경기 수 계산
- 평균 평점 계산
- 최고 평점 계산
- 좋은 경기가 `3회 이상`이면 `"우수"` 등급

> ## **11-1 ) 선수 경기 기록 분석하기**

[ python : code ] "조건문과 반복문을 이용해 선수 경기 성과를 분석하는 방법"

```python
player_name = "우영"

match_ratings = [
    8.5,
    None,
    7.2,
    9.1,
    8.3,
    6.8,
    8.7
]

valid_count = 0
good_match_count = 0
rating_sum = 0
highest_rating = None

for rating in match_ratings:

    if rating is None:
        continue

    valid_count += 1
    rating_sum += rating

    if highest_rating is None or rating > highest_rating:
        highest_rating = rating

    if rating >= 8.0:
        good_match_count += 1

if valid_count > 0:
    average_rating = rating_sum / valid_count
else:
    average_rating = 0

if good_match_count >= 3:
    player_grade = "우수"
else:
    player_grade = "일반"

print(f"선수 이름   : {player_name}")
print(f"유효 경기 수: {valid_count}")
print(f"좋은 경기 수: {good_match_count}")
print(f"평균 평점   : {average_rating:.2f}")
print(f"최고 평점   : {highest_rating}")
print(f"선수 등급   : {player_grade}")
```

# **12. while True와 break 활용**

종료 시점을 미리 알 수 없는 반복에서는 `while True`와 `break`를 함께 사용할 수 있음.

> ## **12-1 ) while True로 등번호 맞히기**

이전 예제에서는 제목은 `while True`인데 실제 코드는 `for`문을 사용하고 있었기 때문에 일치하도록 수정.

[ python : code ] "while True를 사용하여 정답을 찾을 때까지 반복하는 방법"

```python
answer = 10

guesses = [7, 15, 10]
index = 0

while True:
    guess = guesses[index]
    index += 1

    print(f"입력: {guess}")

    if guess < answer:
        print("Up!")
    elif guess > answer:
        print("Down!")
    else:
        print("정답입니다!")
        break
```

[ Result ]

```text

입력: 15
Down!
입력: 10
정답입니다!
```

```text

        ↓

        ↓

        ↓

        ↓

        ↓

        ↓
15 > 10
        ↓
Down!
        ↓
다음 반복
        ↓
guess = 10
        ↓
answer와 같음
        ↓
```

> ## **14-1 ) 중첩 if 대신 continue 활용하기**

중첩이 깊어지면 조건을 반대로 검사하여 `continue`로 제외하는 방식도 사용 가능.

```python

    {"name": "우영", "active": True, "goals": 2},
    {"name": "민수", "active": False, "goals": 3},
    {"name": "지훈", "active": True, "goals": 0}
]

for player in players:

    if not player["active"]:
        continue

    if player["goals"] <= 0:

    print(player["name"])
```

# **15. 핵심정리**

- `if`는 조건이 `True`일 때 코드 실행.
- `else`는 `if` 조건이 `False`일 때 실행.
- `elif`는 여러 조건을 순서대로 검사할 때 사용.
- `if-elif-else`는 위에서부터 검사하여 처음으로 `True`가 된 블록 하나만 실행.
- 서로 포함되는 조건은 더 제한적인 조건을 먼저 검사해야 함.
- Python은 들여쓰기로 코드 블록을 구분하며 일반적으로 공백 4칸 사용.
- `for`는 시퀀스나 일정한 범위를 순회할 때 사용.
- `range(start, stop, step)`에서 `stop` 값은 포함하지 않음.
- `while`은 조건식이 `True`인 동안 반복.
- `while`에서는 조건을 변화시키는 코드가 없으면 무한 루프가 발생할 수 있음.
- `break`는 가장 가까운 반복문을 즉시 종료.
- `continue`는 현재 반복의 남은 코드만 건너뛰고 다음 반복으로 이동.
- 중첩 반복문에서는 바깥 반복 한 번마다 안쪽 반복이 전체 실행됨.
- 반복문과 조건문을 결합하면 원하는 데이터만 필터링 가능.
- 누적 합계는 일반적으로 `0`부터 시작.
- 최댓값과 최솟값은 첫 번째 데이터를 초기 기준값으로 설정한 뒤 이후 데이터와 비교하는 방식이 안전.
- 평균을 계산할 때 데이터 개수가 `0`일 가능성이 있다면 `ZeroDivisionError`를 방지해야 함.
- `None` 같은 결측값은 `continue`를 이용하여 제외할 수 있음.
- `while True`는 반복 횟수를 미리 알 수 없을 때 사용하며 종료 조건에서 `break` 필요.
- `enumerate()`는 값과 순번을 함께 사용할 때 유용.
- `zip()`은 여러 시퀀스의 대응되는 값을 동시에 순회할 때 유용.
- 복잡한 코드는 **입력 데이터 → 반복 → 조건 검사 → 제외/누적/갱신 → 최종 계산 → 결과 출력** 순서로 해석하면 이해하기 쉬움.
