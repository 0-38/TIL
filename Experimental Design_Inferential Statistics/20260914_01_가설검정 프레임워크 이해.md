# **1. 가설검정의 기본 구조**

`가설검정(Hypothesis Testing)`은 **표본에서 관찰한 차이가 단순한 우연인지, 실제 모집단에서도 의미 있는 차이라고 볼 수 있는지 통계적으로 판단하는 방법**이다.

실제 분석에서는 모집단 전체를 조사하기 어려운 경우가 많기 때문에 일부 데이터를 표본으로 추출하고, 표본을 이용해 모집단의 특성을 추론한다.

```text
모집단 Population
      ↓
일부 데이터 추출
      ↓
표본 Sample
      ↓
표본에서 차이 관찰
      ↓
이 차이가 우연인가?
실제 차이인가?
      ↓
가설검정
```

<br>

> ## **1-1 ) 표본과 모집단**

| 구분 | 의미 | 예시 |
|---|---|---|
| 모집단(Population) | 관심 있는 전체 대상 | 모든 축구 선수의 점프 높이 |
| 표본(Sample) | 실제 분석한 일부 대상 | 훈련 프로그램에 참여한 선수 10명 |
| 모수(Parameter) | 모집단의 특성 | 전체 선수의 평균 점프 높이 |
| 통계량(Statistic) | 표본에서 계산한 값 | 표본 선수 10명의 평균 점프 높이 |

표본에서 평균이 달라졌다고 해서 모집단에서도 반드시 차이가 있다고 할 수는 없다.

표본은 어떤 대상이 선택되었는지에 따라 매번 조금씩 달라질 수 있기 때문이다.

이를 **표본변동(Sampling Variability)** 이라고 생각할 수 있다.

<br>

> ## **1-2 ) 귀무가설 H₀와 대립가설 H₁**

가설검정에서는 서로 반대되는 두 가설을 설정한다.

| 가설 | 의미 |
|---|---|
| 귀무가설 `H₀` | 일반적으로 차이 또는 효과가 없다고 가정 |
| 대립가설 `H₁` | 차이 또는 효과가 있다고 주장 |

예를 들어 기존 축구 선수들의 평균 점프 높이가 `50cm`이고 새로운 근력 프로그램을 적용한 뒤 점프 높이가 달라졌는지 확인한다고 하자.

```text
H₀ : 평균 점프 높이 = 50cm
H₁ : 평균 점프 높이 ≠ 50cm
```

수식으로 표현하면 다음과 같다.

```text
H₀ : μ = 50
H₁ : μ ≠ 50
```

여기서 `μ`는 모집단 평균을 의미한다.

<br>

> ## **1-3 ) 왜 귀무가설부터 가정하는가**

가설검정은 우선 **귀무가설이 참이라고 가정한 상태**에서 시작한다.

그리고 다음 질문을 한다.

```text
"정말 차이가 없다고 가정했을 때,
지금 관찰한 표본 결과가 나타나는 것이 얼마나 드문가?"
```

현재 결과가 귀무가설 아래에서 매우 드문 결과라면

```text
귀무가설로 현재 데이터를 설명하기 어렵다.
        ↓
귀무가설을 기각한다.
```

라고 판단한다.

이를 재판에 비유하면 다음과 비슷하다.

```text
귀무가설
→ 우선 무죄라고 가정

표본 데이터
→ 증거

증거가 충분히 강함
→ 기존 가정을 기각
```

단, 귀무가설이 항상 단순히 `차이 = 0` 형태만 가지는 것은 아니다. 기본적인 가설검정에서는 계산 가능한 명확한 기준을 귀무가설로 두고 **그 기준 아래에서 데이터가 얼마나 특이한지 판단한다**고 이해하면 된다.

일반적으로 귀무가설을 기각하고 대립가설 채택을  위해 대립가설을 정의한다.

<br>

> ## **1-4 ) 단일표본 t-검정 예제**

기존 축구 선수의 평균 점프 높이가 `50cm`라고 하자.

새로운 하체 근력 프로그램을 적용한 선수들의 점프 높이가 기존과 다른지 확인한다.

```text
H₀ : 평균 점프 높이 = 50cm
H₁ : 평균 점프 높이 ≠ 50cm
```

[ python : code ] "축구 선수의 평균 점프 높이가 기존 50cm와 다른지 단일표본 t-검정"

```python
from scipy import stats
import numpy as np

# 귀무가설 : 축구선수의 평균 점프높이는 기존 50cm와 같을 것이다.
# 대립가설 : 축구선수의 평균 점프높이는 기존 50cm와 다를 것이다.

jump_height = [
    52, 55, 49, 57, 54,
    51, 56, 53, 50, 55
]

t_stat, p_value = stats.ttest_1samp(
    jump_height,
    popmean=50
)

if p_value < 0.05:
    print('대립가설을 채택합니다.')
else:
    print('귀무가설을 채택합니다.')

print(f"표본 평균: {np.mean(jump_height):.1f}cm")
print(f"t-statistic: {t_stat:.3f}")
print(f"p-value: {p_value:.4f}")
```

[ Result ]

```text
대립가설을 채택합니다.
표본 평균: 53.2cm
t-statistic: 3.807
p-value: 0.0042
```

유의수준을 `α = 0.05`로 설정하면

```text
p-value = 0.0042
α = 0.05

0.0042 < 0.05
```

이므로 **귀무가설을 기각한다.**

따라서

```text
"새로운 훈련 후 선수들의 평균 점프 높이가
기존 50cm와 다르다고 볼 통계적 근거가 있다."
```

라고 해석할 수 있다.

단순히 표본 평균이 `53.2cm`이므로 효과가 있다고 결론 내린 것이 아니라, **표본의 변동성까지 고려한 가설검정을 통해 판단했다는 점**이 중요하다.

<br>

> ## **1-5 ) 가설검정의 전체 논리**

```text
① 연구 질문 설정
예: 훈련 후 점프 높이가 달라졌는가?
        ↓
② H₀ / H₁ 설정
H₀: μ = 50
H₁: μ ≠ 50
        ↓
③ 유의수준 α 설정
예: α = 0.05
        ↓
④ 적절한 통계검정 수행
단일표본 t-검정
        ↓
⑤ p-value 계산
        ↓
⑥ p-value와 α 비교
        ↓
p ≤ α              p > α
  ↓                   ↓
H₀ 기각        H₀ 기각 근거 부족
        ↓
⑦ 통계적 결론 해석
```

# **2. 유의수준 ( α)과 두 가지 오류**

가설검정은 표본을 이용하여 모집단을 판단하기 때문에 항상 완벽한 결론을 내릴 수 있는 것은 아니다.

따라서 올바른 판단뿐 아니라 **잘못된 판단이 발생할 가능성**도 고려해야 한다.

<br>

> ## **2-1 ) 유의수준 α**

유의수준(Significance Level, `α`)은 **귀무가설이 실제로 참인데 이를 잘못 기각하는 제1종 오류를 어느 수준까지 허용할지 미리 설정한 기준**이다.

일반적으로 다음 값이 많이 사용된다.

```python
alpha = 0.05
```

이는 제1종 오류를 `5%` 수준으로 통제하는 검정 기준을 사용한다는 의미이다.

유의수준은 **데이터의 결과를 확인하기 전에** 결정하는 것이 원칙이다.

<br>

> ## **2-2 ) 제1종 오류 (Type I Error)**

제1종 오류는

```text
실제로 H₀가 참
+
H₀를 기각함
```

인 경우이다.

즉,

```text
실제로 효과가 없는데
효과가 있다고 판단
```

하는 오류이다.

### 스포츠 예시

새로운 러닝화가 달리기 기록을 향상시키는지 검정한다고 하자.

```text
실제 상황
→ 러닝화의 효과가 없음

분석 결과
→ 효과가 있다고 판단
```

이것이 **제1종 오류**이다.

제1종 오류의 확률을 `α`라고 한다.

<br>

> ## **2-3 ) 제2종 오류 (Type II Error)**

제2종 오류는

```text
실제로 H₀가 거짓
+
H₀를 기각하지 못함
```

인 경우이다.

즉,

```text
실제로 효과가 있는데
효과를 발견하지 못함
```

이다.

### 스포츠 예시

```text
실제 상황
→ 새로운 재활 프로그램이 실제로 효과가 있음

분석 결과
→ 효과가 있다고 판단할 통계적 근거가 부족함
```

이것이 **제2종 오류**이다.

제2종 오류가 발생할 확률을 `β`라고 한다.

<br>

> ## **2-4 ) 제1종 오류와 제2종 오류 비교**

| 실제 상황 / 검정 판단 | 실제 H₀ 참 | 실제 H₀ 거짓 |
|---|---|---|
| H₀ 기각 | **제1종 오류 `α`** | 올바른 판단 |
| H₀ 기각하지 못함 | 올바른 판단 | **제2종 오류 `β`** |

제2종 오류와 함께 자주 사용되는 개념이 **검정력(Power)**  이다.

```text
검정력 = 1 - β
```

검정력은

**실제로 효과가 존재할 때 그 효과를 검정으로 발견할 확률**이다.

<br>

> ## **2-5 ) α를 무조건 작게 설정하면 좋은가?**

그렇지 않다.

`α`를 매우 작게 설정하면 귀무가설을 기각하기 위한 기준이 더 엄격해진다.

```text
α 감소
  ↓
H₀ 기각이 어려워짐
  ↓
제1종 오류 위험 감소
  ↓
하지만 실제 차이를 놓칠 가능성 증가 가능
  ↓
제2종 오류 β 증가 가능
```

다른 조건이 같다면 제1종 오류와 제2종 오류 사이에는 이러한 **트레이드오프(Trade-off)** 가 존재한다.

따라서 연구 목적과 잘못된 판단의 위험성을 고려하여 유의수준을 정해야 한다.

<br>

> ## **2-6 ) 오류 구분 예제**

새로운 운동처방 프로그램이 환자의 보행 속도를 개선하는지 조사한다고 하자.

```text
H₀ : 운동처방 프로그램의 효과가 없다.
H₁ : 운동처방 프로그램의 효과가 있다.
```

| 상황 | 오류 |
|---|---|
| 실제 효과가 없는데 효과가 있다고 판단 | 제1종 오류 |
| 실제 효과가 있는데 효과가 없다고 판단할 근거밖에 얻지 못함 | 제2종 오류 |
| 실제 효과가 있고 효과를 발견 | 올바른 판단 |
| 실제 효과가 없고 H₀를 기각하지 않음 | 올바른 판단 |

# **3. p-value의 의미와 올바른 해석**

> ## **3-1 ) p-value란**

`p-value`는

**귀무가설이 참이라고 가정했을 때, 현재 관측된 검정통계량과 같거나 귀무가설에 더 불리한 극단적인 결과가 나타날 확률**이다.

쉽게 표현하면

```text
H₀가 맞다고 가정
        ↓
지금 같은 결과가 얼마나 드문가?
        ↓
그 정도를 나타낸 값 = p-value
```

따라서

```text
p-value가 작다
→ 현재 데이터가 H₀ 아래에서 보기 드문 결과
→ H₀에 반하는 통계적 증거가 강해짐
```

이라고 이해할 수 있다.

<br>

> ## **3-2 ) p-value와 α의 판단 규칙**

일반적인 판단 규칙은 다음과 같다.

```text
p-value ≤ α
→ H₀ 기각

p-value > α
→ H₀를 기각할 근거가 부족
```

예를 들어

```text
α = 0.05
p-value = 0.018
```

이라면

```text
0.018 < 0.05
```

이므로 귀무가설을 기각한다.

<br>

> ## **3-3 ) p-value가 작은 경우**

농구 슈팅 훈련 프로그램의 효과를 검정했다고 하자.

```text
H₀ : 훈련 전후 평균 슈팅 성공률에 차이가 없다.
H₁ : 평균 슈팅 성공률에 차이가 있다.

α = 0.05
p-value = 0.012
```

```text
0.012 < 0.05
```

따라서

```text
H₀ 기각
```

이며 다음과 같이 해석한다.

```text
"평균 슈팅 성공률에 차이가 있다고 볼
통계적 근거가 있다."
```

<br>

> ## **3-4 ) p-value가 큰 경우**

이번에는

```text
α = 0.05
p-value = 0.21
```

이라고 하자.

```text
0.21 > 0.05
```

따라서 귀무가설을 기각하지 못한다.

하지만 다음과 같이 표현하면 안 된다.

```text
X "훈련 효과가 없다."
X "H₀가 참이다."
X "두 집단은 완전히 같다."
```

올바른 표현은 다음과 같다.

```text
O "현재 데이터만으로는 차이가 있다고
   판단할 충분한 통계적 근거가 없다."
```

**귀무가설을 기각하지 못했다는 것과 귀무가설이 참임을 증명했다는 것은 다른 의미**이다.

<br>

> ## **3-5 ) p-value의 대표적인 오해**

| 잘못된 해석 | 올바른 해석 |
|---|---|
| `p = 0.03`이면 H₀가 참일 확률이 3% | X |
| `p = 0.03`이면 H₁이 참일 확률이 97% | X |
| p-value가 크면 차이가 없다는 것이 증명됨 | X |
| p-value가 작으면 효과 크기도 반드시 큼 | X |
| p-value는 H₀ 아래에서 현재와 같거나 더 극단적인 결과의 확률 | O |

특히 다음 차이를 기억해야 한다.

```text
P(데이터 | H₀)
```

와

```text
P(H₀ | 데이터)
```

는 전혀 다른 개념이다.

p-value는 첫 번째와 관련된 값이지, **귀무가설 자체가 참일 확률을 직접 계산하는 값이 아니다.**

<br>

> ## **3-6 ) 여러 p-value 판단하기**

[ python : code ] "두 가지 스포츠 훈련 프로그램의 p-value를 유의수준과 비교"

```python
alpha = 0.05

training_a_p = 0.018
training_b_p = 0.124

if training_a_p <= alpha:
    print("훈련 A: H0 기각")
    print("통계적으로 유의한 차이가 있습니다.")
else:
    print("훈련 A: H0를 기각할 근거가 부족합니다.")

if training_b_p <= alpha:
    print("훈련 B: H0 기각")
    print("통계적으로 유의한 차이가 있습니다.")
else:
    print("훈련 B: H0를 기각할 근거가 부족합니다.")
```

[ Result ]

```text
훈련 A: H0 기각
통계적으로 유의한 차이가 있습니다.
훈련 B: H0를 기각할 근거가 부족합니다.
```

### 결과 해석

| 프로그램 | p-value | 판단 | 해석 |
|---|---:|---|---|
| 훈련 A | 0.018 | H₀ 기각 | 차이가 있다고 볼 통계적 근거가 있음 |
| 훈련 B | 0.124 | H₀ 기각 못함 | 현재 자료로는 차이의 근거가 충분하지 않음 |

# **4. 양측검정과 단측검정**

가설검정에서는 **어떤 방향의 차이를 확인하려는지**에 따라 양측검정과 단측검정을 구분한다.

<br>

> ## **4-1 ) 양측검정 Two-sided Test**

양측검정은 기준보다 크거나 작은 방향을 구분하지 않고 **단순히 값이 달라졌는지** 확인한다.

예를 들어 기존 선수들의 평균 훈련 시간이 `30분`이라고 하자.

훈련 시스템 도입 이후 평균 훈련 시간이 달라졌는지 확인하려면

```text
H₀ : μ = 30
H₁ : μ ≠ 30
```

으로 설정한다.

```text
               H₀
               │
← 차이 있음 ── 30 ── 차이 있음 →
```

즉, `30보다 작아져도 차이`, `30보다 커져도 차이`로 판단한다.

<br>

> ## **4-2 ) 단측검정 One-sided Test**

단측검정은 **특정 방향의 변화만 관심이 있을 때** 사용한다.

예를 들어 새로운 체력훈련 프로그램의 목적이 평균 운동 지속시간을 증가시키는 것이라면

```text
H₀ : μ ≤ 30
H₁ : μ > 30
```

처럼 설정할 수 있다.

반대로 평균 회복시간을 감소시키는 것이 목표라면

```text
H₀ : μ ≥ 10
H₁ : μ < 10
```

과 같이 설정한다.

<br>

> ## **4-3 ) 양측검정과 단측검정 비교**

| 구분 | 양측검정 | 단측검정 |
|---|---|---|
| 목적 | 값이 다른지 확인 | 특정 방향으로 변화했는지 확인 |
| H₁ | `μ ≠ μ₀` | `μ > μ₀` 또는 `μ < μ₀` |
| 관심 방향 | 양쪽 | 한쪽 |
| 기각역 | 양쪽 꼬리 | 한쪽 꼬리 |
| SciPy | `two-sided` | `greater`, `less` |
| 선택 시점 | 데이터 확인 전 | 데이터 확인 전 |

<br>

> ## **4-4 ) 같은 데이터로 양측검정과 단측검정 비교**

기존 평균 운동시간이 `30분`이라고 하자.

[ python : code ] "훈련 후 평균 운동시간이 달라졌는지와 증가했는지를 각각 검정"

```python
from scipy import stats
import numpy as np

training_time = [
    32, 34, 29, 35, 33,
    31, 36, 32, 34, 33
]

two_sided = stats.ttest_1samp(
    training_time,
    popmean=30,
    alternative="two-sided"
)

greater = stats.ttest_1samp(
    training_time,
    popmean=30,
    alternative="greater"
)

print(f"표본 평균: {np.mean(training_time):.1f}분")
print(f"양측검정 p-value: {two_sided.pvalue:.4f}")
print(f"단측검정 p-value: {greater.pvalue:.4f}")
```

[ Result ]

```text
표본 평균: 32.9분
양측검정 p-value: 0.0014
단측검정 p-value: 0.0007
```

### 양측검정

```text
H₀ : μ = 30
H₁ : μ ≠ 30

p = 0.0014 < 0.05
→ H₀ 기각
```

평균 운동시간이 기존 `30분`과 다르다고 볼 통계적 근거가 있다.

### 단측검정

```text
H₀ : μ ≤ 30
H₁ : μ > 30

p = 0.0007 < 0.05
→ H₀ 기각
```

평균 운동시간이 기존 `30분`보다 증가했다고 볼 통계적 근거가 있다.

같은 데이터라도 **어떤 가설을 검정하는지에 따라 p-value가 달라질 수 있다.**

<br>

> ## **4-5 ) 단측검정 방향 설정 방법**

SciPy의 `ttest_1samp()`에서는 `alternative`로 검정 방향을 설정한다.

| `alternative` | 대립가설 | 의미 |
|---|---|---|
| `"two-sided"` | `μ ≠ μ₀` | 기준과 다른가? |
| `"greater"` | `μ > μ₀` | 기준보다 큰가? |
| `"less"` | `μ < μ₀` | 기준보다 작은가? |

<br>

> ## **4-6 ) 회복시간이 감소했는지 단측검정**

기존 운동 후 평균 회복시간이 `10분`이고 새로운 회복 프로그램의 목표가 **회복시간 단축**이라고 하자.

```text
H₀ : 평균 회복시간 ≥ 10분
H₁ : 평균 회복시간 < 10분
```

따라서 `less`를 사용한다.

[ python : code ] "운동 후 평균 회복시간이 기존 10분보다 감소했는지 단측 t-검정"

```python
from scipy import stats
import numpy as np

recovery_time = [
    9.2, 8.7, 9.5, 8.9, 9.1,
    9.4, 8.8, 9.0, 9.3, 8.6
]

result = stats.ttest_1samp(
    recovery_time,
    popmean=10,
    alternative="less"
)

print(f"평균 회복시간: {np.mean(recovery_time):.2f}분")
print(f"t-statistic: {result.statistic:.3f}")
print(f"p-value: {result.pvalue:.6f}")
```

[ Result ]

```text
평균 회복시간: 9.05분
t-statistic: -9.922
p-value: 0.000002
```

`p-value < 0.05`이므로 귀무가설을 기각한다.

따라서

```text
"새로운 회복 프로그램 적용 후
평균 회복시간이 기존 10분보다 감소했다고 볼
통계적 근거가 있다."
```

라고 해석할 수 있다.

<br>

> ## **4-7 ) 결과를 본 뒤 단측검정으로 바꾸면 안 되는 이유**

다음과 같은 분석은 잘못된 방법이다.

```text
처음에는 양측검정
        ↓
p-value가 생각보다 큼
        ↓
데이터를 보니 평균이 증가함
        ↓
greater 단측검정으로 변경
        ↓
p-value 감소
```

단측검정은 **p-value를 작게 만들기 위한 방법이 아니다.**

연구 질문을 설정할 때부터 관심 방향이 명확해야 한다.

```text
분석 목적 결정
      ↓
H₀ / H₁ 결정
      ↓
양측 / 단측 결정
      ↓
데이터 분석
```

이 순서가 중요하다.

# **5. 가설검정 Python 실전 흐름**

> ## **5-1 ) 하나의 코드로 가설검정 수행하기**

다음은 스포츠과학 실험에서 새로운 플라이오메트릭 훈련 후 점프 높이가 기존 `50cm`와 다른지 분석하는 전체 과정이다.

[ python : code ] "단일표본 t-검정부터 p-value 판단까지 수행하는 전체 가설검정 코드"

```python
from scipy import stats
import numpy as np

# 1. 표본 데이터
jump_height = [
    52, 55, 49, 57, 54,
    51, 56, 53, 50, 55
]

# 2. 기준값과 유의수준
population_mean = 50
alpha = 0.05

# 3. 가설검정
result = stats.ttest_1samp(
    jump_height,
    popmean=population_mean,
    alternative="two-sided"
)

# 4. 결과 출력
print(f"표본 평균: {np.mean(jump_height):.1f}cm")
print(f"t-statistic: {result.statistic:.3f}")
print(f"p-value: {result.pvalue:.4f}")

# 5. 통계적 판단
if result.pvalue <= alpha:
    print("귀무가설을 기각합니다.")
    print("평균 점프 높이가 50cm와 다르다고 볼 통계적 근거가 있습니다.")
else:
    print("귀무가설을 기각할 근거가 부족합니다.")
```

[ Result ]

```text
표본 평균: 53.2cm
t-statistic: 3.807
p-value: 0.0042
귀무가설을 기각합니다.
평균 점프 높이가 50cm와 다르다고 볼 통계적 근거가 있습니다.
```

### 주요 코드 해석

| 코드 | 의미 |
|---|---|
| `stats.ttest_1samp()` | 하나의 표본 평균을 특정 기준 평균과 비교 |
| `popmean=50` | 비교 기준인 모집단 평균을 50으로 설정 |
| `alternative="two-sided"` | 기준값과 다른지를 양측검정 |
| `result.statistic` | 계산된 t 검정통계량 |
| `result.pvalue` | 계산된 p-value |
| `alpha = 0.05` | 유의수준을 5%로 설정 |
| `pvalue <= alpha` | 귀무가설 기각 여부 판단 |

### 결과 해석

표본 평균은 `53.2cm`로 기존 `50cm`보다 높다.

하지만 평균값의 차이만 보고 결론을 내리는 것이 아니라

```text
p-value = 0.0042
```

를 확인한다.

```text
0.0042 < 0.05
```

이므로 귀무가설을 기각한다.

따라서 모집단의 평균 점프 높이가 기존 `50cm`와 다르다고 판단할 **통계적 근거가 있다.**

### 전체 흐름도

```text
[연구 질문]
훈련 후 점프 높이가 달라졌는가?
        ↓
[가설 설정]
H₀ : μ = 50
H₁ : μ ≠ 50
        ↓
[유의수준 설정]
α = 0.05
        ↓
[검정 선택]
단일표본 t-검정
        ↓
[검정 수행]
ttest_1samp()
        ↓
[p-value 계산]
0.0042
        ↓
[p-value ≤ α ?]
       /   \
     Yes    No
      ↓      ↓
 H₀ 기각   H₀ 기각 근거 부족
      ↓
[최종 해석]
50cm와 다르다고 볼
통계적 근거가 있음
```

<br>

# **6. 주요 개념 비교**

> ## **6-1 ) 가설검정 핵심 용어**

| 개념 | 의미 |
|---|---|
| 표본(Sample) | 전체 모집단 중 실제 분석한 일부 데이터 |
| 가설검정 | 표본에서 관찰된 차이가 우연인지 판단하는 통계적 방법 |
| 귀무가설 `H₀` | 일반적으로 차이 또는 효과가 없다는 기본 가설 |
| 대립가설 `H₁` | 차이 또는 효과가 있다는 가설 |
| 유의수준 `α` | 제1종 오류를 통제하기 위해 사전에 정하는 기준 |
| p-value | H₀ 아래에서 현재와 같거나 더 극단적인 결과가 나타날 확률 |
| 제1종 오류 | 실제 H₀가 참인데 H₀를 기각 |
| 제2종 오류 | 실제 H₀가 거짓인데 H₀를 기각하지 못함 |
| 검정력 | 실제 차이가 있을 때 이를 발견할 확률 `1-β` |
| 양측검정 | 양쪽 방향의 차이를 모두 확인 |
| 단측검정 | 특정 한 방향의 차이만 확인 |

<br>

> ## **6-2 ) 자주 헷갈리는 표현**

| 표현 | 판단 |
|---|---|
| `p < 0.05`이므로 H₀를 기각한다 | O |
| `p > 0.05`이므로 H₀가 참이다 | X |
| `p > 0.05`이므로 H₀를 기각할 근거가 부족하다 | O |

| 결과를 확인한 뒤 양측검정을 단측검정으로 변경한다 | X |

# **7. Advanced 추가 학습**

> ## **7-1 ) 통계적 유의성과 실제 효과 크기는 다르다**

`p-value < 0.05`라고 해서 반드시 효과가 매우 크거나 실무적으로 중요한 것은 아니다.

표본이 매우 많으면 작은 차이도 통계적으로 유의하게 나타날 수 있다.

따라서 실제 분석에서는 p-value와 함께 **효과크기(Effect Size)**도 확인하는 것이 좋다.

```text
p-value
→ 차이가 있다고 볼 통계적 근거가 있는가?

Effect Size
→ 그 차이가 실제로 얼마나 큰가?
```

<br>

> ## **7-2 ) 신뢰구간 Confidence Interval**

신뢰구간은 모집단의 효과가 어느 범위에 있을지 추정하는 데 도움을 준다.

가설검정에서 단순히

```text
유의하다 / 유의하지 않다
```

만 확인하기보다, 추정값과 신뢰구간을 함께 보면 효과의 크기와 불확실성을 더 잘 이해할 수 있다.

<br>

> ## **7-3 ) t-검정의 가정**

단일표본 t-검정을 사용할 때는 데이터가 적절한 조건을 만족하는지도 확인해야 한다.

대표적으로 다음을 생각할 수 있다.

```text
관측값이 서로 독립적인가?
심각한 이상치가 존재하지 않는가?
표본이 작다면 모집단 분포가 지나치게 비정상적이지 않은가?
```

검정 방법은 데이터의 형태와 연구 설계에 따라 달라질 수 있다.

# **8. 핵심정리**

- **가설검정**은 표본에서 관찰된 차이가 단순한 우연인지, 실제 차이라고 볼 통계적 근거가 있는지 판단하는 과정이다.
- **귀무가설 `H₀`**은 일반적으로 차이나 효과가 없다는 기본 가설이다.
- **대립가설 `H₁`**은 차이나 효과가 있다는 가설이다.
- 가설검정은 먼저 `H₀`가 참이라고 가정하고 현재의 데이터가 그 가정과 얼마나 잘 맞는지 확인한다.
- `p-value`는 **H₀가 참일 때 현재와 같거나 더 극단적인 결과가 나타날 확률**과 관련된 값이다.
- `p-value`는 **H₀가 참일 확률이 아니다.**
- 일반적으로 `p-value ≤ α`이면 `H₀`를 기각한다.
- `p-value > α`이면 `H₀`가 참이라고 결론 내리는 것이 아니라 **H₀를 기각할 근거가 부족하다**고 판단한다.
- **유의수준 `α`**는 제1종 오류를 통제하기 위해 검정 전에 미리 정하는 기준이다.
- **제1종 오류**는 실제 차이가 없는데 차이가 있다고 판단하는 오류이다.
- **제2종 오류**는 실제 차이가 있는데 이를 발견하지 못하는 오류이다.
- 제2종 오류의 확률을 `β`, 실제 효과를 발견할 확률인 검정력을 `1-β`라고 한다.
- `α`를 무조건 작게 설정한다고 모든 오류가 함께 줄어드는 것은 아니다.
- **양측검정**은 기준보다 크거나 작은 두 방향의 차이를 모두 검정한다.
- **단측검정**은 특정 방향의 차이만 검정한다.
- `scipy.stats.ttest_1samp()`의 `alternative="two-sided"`는 양측검정, `"greater"`와 `"less"`는 단측검정에 사용한다.
- 검정 방향은 **데이터 결과를 보기 전에 연구 목적을 기준으로 결정**해야 한다.
- 통계적으로 유의하다는 것과 실제 효과가 크다는 것은 다른 개념이므로 이후에는 **효과크기와 신뢰구간**도 함께 확인하는 것이 좋다.

```text
[ 가설검정 핵심 흐름 ]

연구 질문 설정
      ↓
H₀ / H₁ 설정
      ↓
양측 / 단측 결정
      ↓
유의수준 α 설정
      ↓
적절한 통계검정 선택
      ↓
검정통계량과 p-value 계산
      ↓
p-value와 α 비교
      ↓
 ┌─────────────────────┐
 │                     │
p ≤ α                 p > α
 │                     │
 ↓                     ↓
H₀ 기각        H₀를 기각할 근거 부족
 │                     │
 └──────────┬──────────┘
            ↓
      결과를 문맥에 맞게 해석
            ↓
 효과크기 / 신뢰구간까지 추가 확인
```
