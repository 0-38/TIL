# **1. A/B 테스트의 기본 구조**

> ## **1-1 ) A/B 테스트란?**

A/B 테스트는 기존 방식과 새로운 방식을 서로 다른 그룹에 적용하고 **목표 지표의 차이를 비교하는 실험 방법**이다.

스포츠 분야에서는 다음과 같이 적용할 수 있다.

```text
핸드볼
기존 슈팅 코칭
vs
Pose Estimator 기반 슈팅 자세 피드백

테니스
기존 서브 훈련
vs
관절각도 기반 서브 피드백

배드민턴
기존 풋워크 훈련
vs
이동경로 시각화 훈련

양궁
기존 점수 피드백
vs
자세 정렬 피드백
```

기본 구조는 다음과 같다.

```text
전체 실험 대상
        ↓
랜덤 할당
     ↙      ↘
A 그룹      B 그룹
Control     Treatment
     ↓          ↓
기존 방법     새로운 방법
     ↘          ↙
      목표 지표 비교
            ↓
      통계적 검정
            ↓
      효과 크기 확인
            ↓
      실제 의미 판단
```

A/B 테스트에서 중요한 것은 단순히

```text
B 평균 > A 평균
```

을 확인하는 것이 아니다.

실험 목적을 먼저 정의하고, 그 목적을 실제 데이터로 나타내는 **목표 지표(Metric)** 를 정한 뒤 공정한 조건에서 비교해야 한다.

<br>

> ## **1-2 ) 대조군과 실험군**

A/B 테스트에서는 두 그룹을 다음과 같이 구분한다.

| 구분 | 의미 | 스포츠 예시 |
| --- | --- | --- |
| `Control` | 기존 방식을 사용하는 대조군 | 기존 핸드볼 슈팅 코칭 |
| `Treatment` | 새로운 방법을 적용하는 실험군 | Pose 기반 관절각도 피드백 |

예를 들어 핸드볼 슈팅 훈련을 비교한다면

```text
A 그룹
→ 기존 슈팅 코칭

B 그룹
→ 기존 코칭
   +
   Pose Estimator 자세 피드백
```

으로 설정할 수 있다.

확인하려는 것이 Pose 피드백의 효과라면 가능한 한 **Pose 피드백 여부만 다르게 하고 다른 조건은 동일하게 유지하는 것**이 중요하다.

<br>

> ## **1-3 ) 실험 목표 설정**

A/B 테스트를 설계할 때 가장 먼저 결정해야 하는 것은

> **무엇을 확인하기 위한 실험인가?**

이다.

예를 들어 테니스 서브 훈련이라면

```text
새로운 관절각도 피드백을 제공했을 때
첫 서브 성공률에 차이가 나타나는가?
```

처럼 정의할 수 있다.

핸드볼에서는

```text
Pose Estimator 기반 슈팅 피드백이
평균 공 속도에 차이를 만드는가?
```

와 같이 설정할 수 있다.

즉,

```text
실험 목표
        ↓
무엇을 측정해야 하는지 결정
        ↓
목표 지표
```

로 연결된다.

<br>

> ## **1-4 ) 목표 지표 Metric**

목표 지표는 **실험의 결과를 데이터로 측정하기 위해 정의한 값**이다.

스포츠에서는 다음과 같은 지표를 사용할 수 있다.

| 실험 목적 | 목표 지표 예시 |
| --- | --- |
| 슈팅 성능 향상 | 평균 공 속도 |
| 서브 정확도 향상 | 첫 서브 성공률 |
| 양궁 정확도 향상 | 10점 명중률 |
| 풋워크 향상 | 셔틀 도달시간 |
| Pose 성능 개선 | 관절각도 MAE |
| 펜싱 런지 동작 개선 | 평균 런지 속도 |

예를 들어 양궁에서 자세 피드백의 효과를 확인하려는 경우 단순히

```text
피드백 화면을 본 횟수
```

를 보는 것보다

```text
10점 명중률
평균 점수
```

처럼 실제 경기력과 직접 연결되는 지표가 더 적절하다.

<br>

> ## **1-5 ) 가설 설정**

A/B 테스트 결과는 가설검정의 프레임워크를 이용하여 분석할 수 있다.

예를 들어 테니스 첫 서브 성공률을 비교한다면

```text
H₀
→ 기존 코칭과 새로운 코칭의
   첫 서브 성공률에 차이가 없다.

H₁
→ 두 코칭 방법의
   첫 서브 성공률에 차이가 있다.
```

핸드볼 평균 슈팅 속도라면

```text
H₀
→ 두 그룹의 평균 슈팅 속도에 차이가 없다.

H₁
→ 두 그룹의 평균 슈팅 속도에 차이가 있다.
```

라고 설정할 수 있다.

<br>

> ## **1-6 ) A/B 테스트는 통계검정 이름이 아니다**

A/B 테스트 자체는 `t-test`나 `z-test` 같은 특정 검정의 이름이 아니다.

```text
A/B 테스트
→ 실험을 설계하고
   데이터를 수집하는 전체 과정
```

이고,

수집한 데이터에 따라 통계검정이 달라진다.

```text
평균 공 속도
→ 연속형 데이터
→ 독립표본 t-test 등

10점 성공 여부
→ 성공 / 실패
→ 비율 비교 검정

평균 반응시간
→ 연속형 데이터
→ 평균 비교 검정
```

따라서

> **A/B 테스트는 실험 설계이고, 통계검정은 그 실험 결과를 분석하는 방법이다.**

# **2. 랜덤 할당과 공정한 비교**

> ## **2-1 ) 랜덤 할당이 필요한 이유**

새로운 훈련법을 다음과 같이 배정한다고 생각해보자.

```text
A 그룹
→ 초보 선수
→ 기존 훈련

B 그룹
→ 상급 선수
→ 새로운 훈련
```

실험 후 B 그룹의 성적이 더 좋았다면

```text
새로운 훈련 때문인가?

또는

원래 B 그룹 선수의 실력이 높았기 때문인가?
```

를 구분하기 어렵다.

따라서 실험 대상 선수를 **랜덤하게 A와 B 그룹에 배정**한다.

```text
전체 선수
        ↓
Random Assignment
     ↙          ↘
A 그룹          B 그룹
기존 방법        새로운 방법
```

랜덤 할당은

```text
경력
체력
신장
포지션
기존 경기력
기술 수준
```

과 같은 특성이 특정 그룹에 의도적으로 몰리는 것을 줄이는 역할을 한다.

<br>

> ## **2-2 ) 랜덤 할당과 랜덤 샘플링**

둘은 서로 다른 개념이다.

```text
랜덤 샘플링
모집단
   ↓
연구에 참여할 표본 선택
```

```text
랜덤 할당
이미 선정된 실험 대상
   ↓
A / B 그룹에 배정
```

| 구분 | 의미 |
| --- | --- |
| Random Sampling | 누구를 연구에 포함할 것인가 |
| Random Assignment | 포함된 대상을 어느 실험군에 배정할 것인가 |

A/B 테스트에서 특히 중요한 것은 **Random Assignment**이다.

<br>

> ## **2-3 ) 랜덤 할당을 했다고 완전히 동일해지는 것은 아니다**

랜덤 배정했다고 해서

```text
A 평균 경력 = B 평균 경력

A 평균 신장 = B 평균 신장

A 평균 체력 = B 평균 체력
```

처럼 모든 값이 정확하게 같아지는 것은 아니다.

특히 스포츠 연구처럼 선수 수가 적다면 우연에 의해 차이가 발생할 수 있다.

랜덤화의 핵심은

> **특정 특성을 의도적으로 한 그룹에 몰아넣지 않는 것**

이다.

<br>

> ## **2-4 ) Python으로 선수 랜덤 할당**

[Python : code] "핸드볼 선수 20명을 A/B 그룹에 랜덤 배정"

```python
import numpy as np
import pandas as pd

rng = np.random.default_rng(42)

players = pd.DataFrame({
    "player_id": np.arange(1, 21)
})

players["group"] = rng.choice(
    ["A", "B"],
    size=len(players)
)

print(players.head(10))

print()
print(players["group"].value_counts())
```

[ Result ]

```text
   player_id group
0          1     A
1          2     B
2          3     B
3          4     A
4          5     A
5          6     B
6          7     A
7          8     B
8          9     A
9         10     A

B    12
A     8
```

랜덤 할당이라고 해서 반드시 정확히 `10:10`이 되는 것은 아니다.

```text
Random
→ 각 선수가 확률적으로 배정됨

Equal Size
→ 그룹 인원을 정확하게 같게 만드는 것
```

은 서로 다른 개념이다.

<br>

> ## **2-5 ) 같은 기간에 비교해야 하는 이유**

다음처럼 실험한다고 생각해보자.

```text
1월
→ 기존 훈련

→ 새로운 훈련
```

2월 기록이 좋아졌다고 해서 새로운 훈련 때문이라고 바로 해석하기 어렵다.

```text
피로도
회복 상태
날씨
```

따라서 가능한 경우

```text

→ 새로운 훈련
```

형태로 운영하면 시간에 따른 외부 요인을 두 그룹이 함께 경험하게 할 수 있다.

<br>

> ## **2-6 ) 한 번에 하나의 주요 조건만 다르게**

테니스 코칭 효과를 확인하는데 다음처럼 실험했다고 생각해보자.


# **4. A/B 테스트 결과 분석**

> ## **4-1 ) 평균 지표라면 평균 비교**

핸드볼 실험 결과가 다음과 같다고 가정한다.

```text
A 그룹
→ 기존 코칭

B 그룹
→ Pose 피드백
```

각 선수의 평균 슈팅 속도는 다음과 같다.

```python
speed_a = [78, 80, 79, 81, 77, 82, 80, 79, 81, 78]

speed_b = [82, 83, 81, 84, 82, 85, 83, 82, 84, 83]
```

[Python : code] "핸드볼 평균 슈팅 속도의 A/B 테스트"

```python
import numpy as np
from scipy import stats

speed_a = np.array(
    [78, 80, 79, 81, 77, 82, 80, 79, 81, 78]
)

speed_b = np.array(
    [82, 83, 81, 84, 82, 85, 83, 82, 84, 83]
)

mean_a = speed_a.mean()
mean_b = speed_b.mean()

t_stat, p_value = stats.ttest_ind(
    speed_a,
    speed_b,
    equal_var=False
)

print(f"A 평균: {mean_a:.1f} km/h")
print(f"B 평균: {mean_b:.1f} km/h")
print(f"평균 차이: {mean_b - mean_a:.1f} km/h")

print(f"t 통계량: {t_stat:.3f}")
print(f"p-value: {p_value:.6f}")
```

[ Result ]

```text
A 평균: 79.5 km/h
B 평균: 82.9 km/h
평균 차이: 3.4 km/h

t 통계량: -5.421
p-value: 0.000048
```

유의수준을 `0.05`로 설정했다면

```text
p-value < 0.05
        ↓
귀무가설 기각
```

따라서

> **두 그룹의 평균 슈팅 속도에 차이가 있다고 볼 통계적 근거가 있다.**

라고 해석할 수 있다.

<br>

> ## **4-2 ) 성공률이라면 비율 비교**

양궁 실험 결과가 다음과 같다고 생각해보자.

| 그룹 | 총 발사 | 10점 |
| --- | ---: | ---: |
| A | 500 | 300 |
| B | 500 | 340 |

명중률은

```text
A
= 300 / 500
= 60%

B
= 340 / 500
= 68%
```

이다.

차이는

```text
68% - 60%
= 8%p
```

이다.

[Python : code] "양궁 10점 명중률의 두 비율 z-검정"

```python
import numpy as np

from statsmodels.stats.proportion import proportions_ztest

success = np.array([300, 340])
attempts = np.array([500, 500])

z_stat, p_value = proportions_ztest(
    count=success,
    nobs=attempts
)

rate_a = success[0] / attempts[0]
rate_b = success[1] / attempts[1]

print(f"A 명중률: {rate_a:.1%}")
print(f"B 명중률: {rate_b:.1%}")
print(f"절대 차이: {(rate_b - rate_a) * 100:.1f}%p")

print(f"z 통계량: {z_stat:.3f}")
print(f"p-value: {p_value:.4f}")
```

[ Result ]

```text
A 명중률: 60.0%
B 명중률: 68.0%
절대 차이: 8.0%p

z 통계량: -2.635
p-value: 0.0084
```

따라서

```text
p-value = 0.0084

0.0084 < 0.05
        ↓
귀무가설 기각
```

으로 두 조건의 10점 명중률에 차이가 있다고 볼 통계적 근거가 있다.

단, 같은 선수가 여러 번 발사한 데이터라면 각 발사가 완전히 독립인지 별도로 고려해야 한다.

# **5. 통계적 유의성과 효과의 크기**

> ## **5-1 ) p-value가 작으면 무조건 좋은 결과일까?**

다음과 같은 결과를 생각해보자.

```text
A 평균 슈팅 속도
→ 80.0 km/h

B 평균 슈팅 속도
→ 80.2 km/h

p-value
→ 0.01
```

통계적으로는 차이가 있다고 볼 근거가 있을 수 있다.

하지만 실제 차이는

```text
0.2 km/h
```

뿐이다.

만약 새로운 시스템을 도입하려면

```text
최소 3 km/h 이상의 향상
```

이 필요하다고 정해놓았다면 이 결과는 실질적으로 중요하지 않을 수 있다.

따라서 반드시

```text
통계적 유의성
+
효과의 크기
+
실제 의미
```

를 함께 확인해야 한다.

<br>

> ## **5-2 ) 통계적 유의성**

통계적 유의성은

```text
현재 관찰된 차이가
우연한 표본 변동만으로 설명하기 어려운가?
```

를 판단하는 것과 관련된다.

대표적으로

```text
p-value < α
```

를 이용한다.

<br>

> ## **5-3 ) 효과의 크기**

효과의 크기는 실제로 두 그룹 사이에서 어느 정도의 차이가 발생했는지를 나타낸다.

```text
핸드볼
→ +3.4 km/h

배드민턴
→ -0.05초

양궁
→ +8%p

테니스
→ +6%p

펜싱
→ 런지 속도 +0.3 m/s
```

처럼 실제 단위로 표현할 수 있다.

<br>

> ## **5-4 ) 실질적 유의성**

실질적 유의성은 그 차이가 **스포츠 현장에서 실제로 의미가 있는지**를 판단하는 것이다.

예를 들어

```text
p-value = 0.001

하지만

런지 속도 차이 = 0.01 m/s
```

라면 통계적으로는 유의하더라도 실제 펜싱 경기에서 의미가 매우 작을 수 있다.

반대로

```text
런지 속도 +0.3 m/s
```

처럼 실제 경기 수행에 의미 있는 차이가 나타났다면 현장 적용 가치가 더 클 수 있다.

# **6. %p와 상대적 변화**

> ## **6-1 ) 두 표현은 다르다**

양궁 명중률이

```text
60% → 68%
```

이 되었다고 하자.

절대 차이는

```text
68% - 60%
= 8%p
```

이다.

상대적 변화는

```text
(68 - 60) / 60 × 100

≈ 13.3%
```

이다.

따라서

```text
명중률이 8%p 증가했다.
```

와

```text
명중률이 약 13.3% 증가했다.
```

는 서로 다른 의미이다.

| 표현 | 의미 |
| --- | --- |
| `%p` | 두 비율의 절대적인 차이 |
| `% 변화` | 기존 값을 기준으로 한 상대적인 변화 |

<br>

> ## **6-2 ) 테니스 예시**

첫 서브 성공률이

```text
A = 50%

B = 60%
```

이라면

```text
절대 차이
= 10%p
```

이지만 상대적인 증가는

```text
(60 - 50) / 50 × 100

= 20%
```

이다.

# **8. 스포츠 실험 설계 시 주의할 점**

> ## **8-1 ) 반복측정 문제**

스포츠에서는 한 선수가 여러 번 수행하는 경우가 많다.

예를 들어 펜싱 선수 한 명이

```text
런지 100회
```

를 수행했다고 해서

```text
독립된 선수 100명
```

과 같은 것은 아니다.

같은 선수의 반복 수행은 서로 연관될 수 있기 때문이다.

```text
선수 A
 ↓
런지 1
런지 2
런지 3
...
```

따라서 **선수 단위와 시도 단위를 구분**해야 한다.

<br>

> ## **8-2 ) 학습효과**

한 선수가 A와 B 조건을 모두 경험한다면 먼저 수행한 조건의 학습효과가 다음 조건에 남을 수 있다.

```text
A 훈련
        ↓
기술 학습
        ↓
B 조건에서도
영향 지속
```

이를 Carryover Effect와 연결해서 생각할 수 있다.

<br>

> ## **8-3 ) 피로효과**

다음과 같이 고정된 순서로 실험하면

```text
A 조건
→ 먼저 수행

B 조건
→ 나중에 수행
```

B에서 기록이 낮은 이유가 훈련 방식이 아니라 **피로 때문일 수도 있다.**

<br>

> ## **8-4 ) Pose Estimator의 측정오차**

Pose 기반 피드백을 비교한다면

```text
카메라 위치
프레임 속도
조명
가림
Keypoint Confidence
영상 해상도
```

같은 측정 조건도 두 그룹에서 가능한 한 동일해야 한다.

# **9. Advanced 추가 학습**

> ## **9-1 ) 가드레일 지표**

핵심 지표가 좋아져도 다른 중요한 지표가 나빠질 수 있다.

예를 들어 펜싱 Pose 피드백이

```text
런지 속도
+0.3 m/s
```

를 만들었지만

```text
공격 성공률
-8%p
```

가 되었다면 단순히 성공이라고 판단하기 어렵다.

따라서

```text
Primary Metric
→ 평균 런지 속도

Guardrail Metric
→ 공격 성공률
```

처럼 설정할 수 있다.

<br>

> ## **9-2 ) 층화 랜덤화**

선수 수가 적다면 일반 랜덤화만으로 그룹의 기존 실력이 크게 달라질 수 있다.

예를 들어

```text
상급 선수
중급 선수
초급 선수
```

로 먼저 나눈 후 각 수준 안에서 A/B를 랜덤 배정할 수 있다.

```text
실력 수준으로 층화
        ↓
각 층에서 A/B 랜덤 배정
```

이를 **층화 랜덤화(Stratified Randomization)** 라고 한다.

# **10. 핵심정리**

> ## **10-1 ) A/B 테스트 핵심**

A/B 테스트는

> **기존 방식과 새로운 방식을 서로 다른 그룹에 적용하고 결과 지표를 비교하여 새로운 변화의 효과를 평가하는 실험 방법**

이다.

```text
Control
vs
Treatment
```

의 구조를 가진다.

<br>

> ## **10-2 ) 좋은 A/B 테스트의 조건**

```text
실험 목적 명확
        ↓
목표 지표 명확
        ↓
A / B 조건 정의
        ↓
랜덤 할당
        ↓
확인하려는 변화 이외
조건 통제
        ↓
같은 기간에 실험
```

이 중요하다.

<br>

> ## **10-3 ) 랜덤 할당 핵심**

랜덤 할당은

```text
경력
성별
신체조건
기술 수준
기존 경기력
```

같은 특성이 특정 그룹에 체계적으로 치우치는 것을 줄이는 방법이다.

```text
Random Assignment
≠
두 그룹이 완전히 동일함
```

이라는 점도 기억해야 한다.

<br>

> ## **10-4 ) 실험 결과 해석의 세 가지 기준**

A/B 테스트 결과는 다음 세 가지를 함께 본다.

| 기준 | 질문 |
| --- | --- |
| 통계적 유의성 | 차이가 우연이라고 보기 어려운가? |
| 효과의 크기 | 실제 차이는 얼마나 큰가? |
| 실질적 의미 | 실제 현장에서 중요한 차이인가? |

즉,

```text
p-value가 작다
        ↓
무조건 적용
```

이 아니다.

```text
p-value
+
실제 차이
+
현장적 의미
```

를 함께 판단한다.

<br>

> ## **10-5 ) 스포츠 A/B 테스트 전체 연결**

| 종목 | Control | Treatment | 목표 지표 |
| --- | --- | --- | --- |
| 핸드볼 | 기존 슈팅 코칭 | Pose 슈팅 피드백 | 평균 공 속도 |
| 테니스 | 기존 서브 코칭 | 관절각도 피드백 | 첫 서브 성공률 |
| 배드민턴 | 기존 풋워크 | 이동경로 피드백 | 셔틀 도달시간 |
| 양궁 | 기존 점수 피드백 | 자세 정렬 피드백 | 10점 명중률 |
| 펜싱 | 기존 런지 코칭 | Pose 관절각도 피드백 | 평균 런지 속도 |
| Pose Estimation | 기존 모델 | 새로운 모델 | 관절각도 MAE |

<br>

> ## **10-6 ) 가장 중요한 전체 흐름**

```text
새로운 방법을
검증하고 싶음
        ↓
실험 목표 설정
        ↓
목표 지표 설정
        ↓
Control / Treatment 설정
        ↓
H₀ / H₁ 설정
        ↓
랜덤 할당
        ↓
동일한 조건에서 실험
        ↓
데이터 수집
        ↓
적절한 통계검정 선택
        ↓
p-value 확인
        ↓
효과 크기 확인
        ↓
실질적인 의미 확인
        ↓
최종 의사결정
```

**한 문장으로 정리하면**

> **A/B 테스트는 실험 대상을 대조군과 실험군에 랜덤하게 배정하고 확인하려는 조건 이외의 요소를 가능한 한 동일하게 유지한 뒤, 목표 지표의 차이를 통계적 유의성·효과의 크기·실질적 의미와 함께 해석하여 새로운 방법의 효과를 평가하는 실험 설계 과정이다.**
