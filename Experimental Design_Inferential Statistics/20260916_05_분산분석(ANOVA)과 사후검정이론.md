# **1. 세 집단 이상의 평균 비교와 ANOVA**

> ## **1-1 ) 두 집단과 세 집단 이상의 평균 비교**

평균을 비교할 때는 **비교하려는 집단의 수**에 따라 사용할 수 있는 통계 검정이 달라진다.

| 비교 상황 | 대표적인 검정 | 스포츠 예시 |
| --- | --- | --- |
| 하나의 표본 평균과 기준값 비교 | `One-sample t-test` | 선수 평균 안정시 심박수가 기준값 60과 다른가? |
| 독립된 두 집단의 평균 비교 | `Independent t-test` | 남자 선수와 여자 선수의 평균 점프 높이가 다른가? |
| 동일 대상의 전·후 평균 비교 | `Paired t-test` | 운동처방 전·후 평균 체지방률이 다른가? |
| 세 집단 이상의 평균 비교 | `ANOVA` | 세 가지 훈련 프로그램의 평균 기록이 다른가? |

예를 들어 세 가지 스프린트 훈련 방법을 비교한다고 생각해보자.

```text
훈련 방법 A
훈련 방법 B
훈련 방법 C
        ↓
100m 평균 기록 비교
        ↓
세 집단 이상의 평균 비교
        ↓
ANOVA
```

두 집단의 평균을 비교한다면 t-검정을 사용할 수 있지만, 세 집단 이상이라면 **ANOVA(Analysis of Variance, 분산분석)** 를 사용할 수 있다.

<br>

> ## **1-2 ) 세 집단을 t-검정으로 반복해서 비교하면 안 되는 이유**

세 집단 `A`, `B`, `C`를 t-검정으로 비교한다면 다음과 같이 검정을 여러 번 실시해야 한다.

```text
A vs B

A vs C

B vs C
```

이렇게 가설검정을 반복하면 **제1종 오류(Type I Error)가 전체적으로 증가할 가능성**이 있다.

제1종 오류란

```text
실제로 집단의 차이가 없음
        ↓
그런데 검정 결과
"차이가 있다"고 판단
        ↓
제1종 오류
```

를 의미한다.

따라서

```text
세 집단 이상
        ↓
t-test를 여러 번 반복
        ↓
제1종 오류 증가 가능성
        ↓
ANOVA를 이용하여
전체 집단을 한 번에 비교
```

하는 것이 기본적인 접근이다.

<br>

> ## **1-3 ) 일원배치 분산분석 One-way ANOVA**

`One-way ANOVA`는 **하나의 요인(Factor)을 기준으로 나뉜 세 집단 이상의 평균을 비교하는 방법**이다.

예를 들어 운동 강도에 따라 세 집단을 나누었다고 생각해보자.

```text
Factor
→ 운동 강도

Level
→ 저강도
→ 중강도
→ 고강도

비교하려는 값
→ 최대산소섭취량 증가량
```

집단을 나누는 기준이 `운동 강도`라는 하나의 요인이므로 **One-way ANOVA**에 해당한다.

다양한 스포츠 분야에서는 다음과 같이 사용할 수 있다.

| Factor | Group | 비교할 종속변수 |
| --- | --- | --- |
| 스프린트 훈련법 | A / B / C | 100m 기록 |
| 운동처방 강도 | 저강도 / 중강도 / 고강도 | VO₂max |
| 축구 포지션 | 공격수 / 미드필더 / 수비수 | 평균 이동거리 |
| 보행 재활 프로그램 | A / B / C | 평균 보행속도 |
| 양궁 훈련 방법 | A / B / C | 평균 득점 |

<br>

> ## **1-4 ) ANOVA의 가설 설정**

세 집단의 평균을 각각

```text
μA
μB
μC
```

라고 하자.

ANOVA의 귀무가설은 다음과 같다.

```text
H₀ : μA = μB = μC
```

즉,

> **모든 집단의 평균이 같다.**

대립가설은 다음과 같다.

```text
H₁ : 적어도 하나의 집단 평균은 다르다.
```

여기서 중요한 점은 대립가설이

```text
μA ≠ μB ≠ μC
```

라는 뜻은 아니라는 것이다.

예를 들어

```text
A와 C 평균은 비슷함

하지만

B 평균만 다름
```

이어도 ANOVA 결과는 유의할 수 있다.

따라서 ANOVA는

```text
모든 집단의 평균이 같은가?
        ↓
아니다.
        ↓
적어도 하나가 다르다.
```

까지만 판단한다.

**어떤 집단끼리 차이가 있는지는 ANOVA만으로 알 수 없다.**

<br>

> ## **1-5 ) 스프린트 훈련법 ANOVA 예제**

세 가지 훈련 방법을 적용한 선수들의 100m 기록을 비교한다고 가정한다.

```python
training_a = [10.8, 10.7, 10.9, 10.6, 10.8]
training_b = [10.4, 10.5, 10.3, 10.4, 10.2]
training_c = [10.9, 11.0, 10.8, 10.9, 11.1]
```

가설은 다음과 같다.

```text
H₀
→ 세 훈련법의 평균 100m 기록은 같다.

H₁
→ 적어도 하나의 훈련법의 평균 기록은 다르다.
```

[Python : code] "세 가지 스프린트 훈련법의 평균 기록 ANOVA 검정"

```python
from scipy import stats

training_a = [10.8, 10.7, 10.9, 10.6, 10.8]
training_b = [10.4, 10.5, 10.3, 10.4, 10.2]
training_c = [10.9, 11.0, 10.8, 10.9, 11.1]

f_stat, p_value = stats.f_oneway(
    training_a,
    training_b,
    training_c
)

print(f"F 통계량: {f_stat:.3f}")
print(f"p-value: {p_value:.6f}")
```

[ Result ]

```text
F 통계량: 33.897
p-value: 0.000012
```

유의수준을 `0.05`로 설정하면

```text
p-value = 0.000012

0.000012 < 0.05
        ↓
귀무가설 기각
```

따라서

> **세 가지 스프린트 훈련법의 평균 100m 기록이 모두 같지는 않다고 볼 통계적 근거가 있다.**

하지만 ANOVA만으로는

```text
A와 B?
A와 C?
B와 C?
```

중 어디에서 차이가 발생했는지는 알 수 없다.

만약 집단 간 정확한 차이를 판별하고 싶으면 사후분석(사후 검정)을 추가로 실시한다.

> 사후 검정에는 `LSD`, `Duncan`, `Tukey`, `Scheffe` 검정이 존재한다.

# **2. ANOVA 결과와 F 통계량**

> ## **2-1 ) 평균을 비교하는데 왜 이름이 분산분석일까?**

ANOVA의 목적은 여러 집단의 **평균 차이**를 확인하는 것이다.

하지만 평균값을 단순히 서로 빼서 비교하는 것이 아니라 **데이터의 변동(Variance)을 이용하여 평균의 차이가 충분히 큰지 판단**한다.

ANOVA에서는 크게 두 가지 변동을 비교한다.

```text
전체 데이터의 변동
        ↓

집단 간 변동
Between-group Variation

        VS

집단 내 변동
Within-group Variation
```

<br>

> ## **2-2 ) 집단 간 변동 Between-group Variation**

집단 간 변동은

> **각 집단의 평균이 서로 얼마나 차이가 나는가?**

와 관련되어 있다.

예를 들어 세 집단의 평균이 다음과 같다고 생각해보자.

```text
Group A 평균 = 50
Group B 평균 = 51
Group C 평균 = 49
```

평균의 차이가 매우 작다.

```text
집단 평균이 비슷함
        ↓
집단 간 변동 작음
```

반대로

```text
Group A 평균 = 50
Group B 평균 = 70
Group C 평균 = 90
```

이라면

```text
집단 평균 차이가 큼
        ↓
집단 간 변동 큼
```

이라고 볼 수 있다.

<br>

> ## **2-3 ) 집단 내 변동 Within-group Variation**

집단 내 변동은

> **같은 집단 안에서 각각의 데이터가 얼마나 퍼져 있는가?**

와 관련되어 있다.

다음과 같은 선수 기록이 있다고 생각해보자.

```text
Group A

10.7
10.8
10.8
10.9
10.8
```

평균 근처에 기록이 모여 있다.

```text
데이터가 비슷함
        ↓
집단 내 변동 작음
```

반대로

```text
Group B

9.8
10.3
10.8
11.5
12.0
```

처럼 기록이 크게 흩어져 있다면

```text
집단 내부 차이가 큼
        ↓
집단 내 변동 큼
```

이라고 볼 수 있다.

두 변동의 차이는 다음과 같다.

| 구분 | 의미 | 값이 클 때 |
| --- | --- | --- |
| `Between-group` | 집단 평균끼리 떨어진 정도 | 집단 평균 차이가 큼 **(집단 간)** |
| `Within-group` | 같은 집단의 데이터가 흩어진 정도 | 개인차·잡음이 큼 **(집단 내)** |

<br>

> ## **2-4 ) F 통계량의 의미**

ANOVA에서는 **집단 간 변동과 집단 내 변동을 비교하기 위해 F 통계량(F-statistic)** 을 사용한다.

개념적으로 다음과 같이 생각할 수 있다.

```text
       집단 간 변동
F ≈ ───────────────
       집단 내 변동
```

조금 더 정확하게 표현하면 다음과 같다.

```text
     MS Between
F = ───────────
     MS Within
```

여기서 `MS`는 `Mean Square`를 의미한다.

초보 단계에서는 세부 공식을 계산하는 것보다 다음 관계를 이해하는 것이 중요하다.

```text
집단 평균 차이 ↑
        ↓
집단 간 변동 ↑

각 집단 내부의 변동 ↓
        ↓
집단 내 변동 ↓

        ↓

F 통계량 ↑
```

즉,

```text
집단 간 차이가 크고
집단 내부 차이가 작을수록

        ↓

집단의 평균 차이가
더 뚜렷하게 나타남
```

이라고 이해할 수 있다.

<br>

> ## **2-5 ) F 통계량이 크면 무조건 유의한가?**

F 통계량이 클수록 집단 간 평균 차이가 상대적으로 크게 나타나는 경향은 있다.

하지만

```text
F가 몇 이상이면 무조건 유의하다.
```

처럼 고정된 기준을 사용해서는 안 된다.

F 분포는 다음과 같은 조건에 영향을 받기 때문이다.

```text
집단 수
표본 크기
자유도
```

따라서 실제 가설검정에서는

```text
F 통계량 계산
        ↓
F 분포에서 p-value 계산
        ↓
p-value와 유의수준 비교
        ↓
귀무가설 기각 여부 판단
```

의 순서로 해석한다.

<br>

> ## **2-6 ) p-value를 이용한 ANOVA 결과 판단**

유의수준을 `α = 0.05`로 설정했다고 가정한다.

```text
p-value < 0.05
        ↓
귀무가설 기각
        ↓
적어도 하나의 집단 평균이
다르다고 볼 통계적 근거가 있음
```

반대로

```text
p-value >= 0.05
        ↓
귀무가설을 기각할 근거 부족
        ↓
집단 평균의 차이가 있다고
판단할 충분한 통계적 근거 없음
```

여기서 주의할 것은

```text
p-value >= 0.05

→ 모든 집단 평균이 완전히 같다.
```

라고 표현하지 않는 것이다.

더 정확한 표현은

> **모든 집단의 평균이 같다는 귀무가설을 기각할 충분한 통계적 근거가 없다.**

이다.

<br>

> ## **2-7 ) 보행 재활 프로그램 ANOVA 예제**

세 가지 보행 재활 프로그램을 적용한 후 보행속도 `m/s`를 측정했다고 가정한다.

[Python : code] "세 가지 보행 재활 프로그램의 평균 보행속도 ANOVA 검정"

```python
from scipy import stats

rehab_a = [1.10, 1.12, 1.08, 1.11, 1.09, 1.13]
rehab_b = [1.18, 1.20, 1.17, 1.19, 1.21, 1.18]
rehab_c = [1.11, 1.13, 1.10, 1.12, 1.14, 1.11]

f_stat, p_value = stats.f_oneway(
    rehab_a,
    rehab_b,
    rehab_c
)

print(f"F 통계량: {f_stat:.3f}")
print(f"p-value: {p_value:.8f}")
```

[ Result ]

```text
F 통계량: 46.043
p-value: 0.00000040
```

해석 과정은 다음과 같다.

```text
p-value ≈ 0.00000040
        ↓
0.00000040 < 0.05
        ↓
귀무가설 기각
        ↓
세 재활 프로그램의 평균 보행속도가
모두 같지는 않다고 볼 통계적 근거가 있음
```

하지만 이 결과만으로는 어떤 재활 프로그램 사이에 차이가 있는지는 알 수 없다.

# **3. ANOVA와 사후 검정**

> ## **3-1 ) ANOVA의 한계**

ANOVA에서 유의한 결과가 나왔다고 생각해보자.

```text
p-value < 0.05
        ↓
귀무가설 기각
        ↓
적어도 하나의 집단 평균이 다름
```

하지만 ANOVA는 다음 질문에는 답해주지 않는다.

```text
A와 B가 다른가?

A와 C가 다른가?

B와 C가 다른가?
```

따라서 ANOVA 이후 **어떤 집단끼리 차이가 있는지 구체적으로 확인하기 위한 검정**이 필요하다.

이를 **사후 검정(Post-hoc test)** 이라고 한다.

<br>

> ## **3-2 ) ANOVA와 사후 검정의 역할 차이**

| 구분 | ANOVA | 사후 검정 |
| --- | --- | --- |
| 목적 | 전체 집단 평균에 차이가 있는지 확인 | 어느 집단 사이에서 차이가 있는지 확인 |
| 질문 | 적어도 하나의 평균이 다른가? | A-B, A-C, B-C 중 어디가 다른가? |
| 수행 시점 | 먼저 수행 | 일반적으로 ANOVA가 유의한 후 수행 |
| 대표 방법 | `stats.f_oneway()` | `Tukey HSD` |

전체 과정은 다음과 같다.

```text
세 집단 이상의 평균 비교
        ↓
ANOVA
        ↓
p-value < 0.05 ?
        ↓
       Yes
        ↓
사후 검정
        ↓
A vs B
A vs C
B vs C
        ↓
어떤 집단끼리 다른지 확인
```

<br>

> ## **3-3 ) 왜 사후 검정에서도 그냥 t-검정을 반복하지 않을까?**

ANOVA 이후

```text
A vs B
A vs C
B vs C
```

를 일반적인 t-검정으로 반복하면 다시 **다중 비교(Multiple Comparisons)** 문제가 발생한다.

```text
검정 횟수 증가
        ↓
우연히 유의한 결과가 발생할
전체적인 확률 증가
        ↓
제1종 오류 증가
```

따라서 다중 비교에 따른 오류 증가를 조정하는 사후 검정 방법을 사용한다.

대표적인 방법이 **Tukey HSD**이다.

<br>

> ## **3-4 ) Tukey HSD**

`Tukey HSD`는 여러 집단의 평균을 **두 집단씩 비교하면서 다중 비교에 따른 제1종 오류 증가를 조정하는 사후 검정 방법**이다.

예를 들어 세 집단이라면

```text
A vs B
A vs C
B vs C
```

를 각각 비교한다.

Python에서는 다음 함수를 사용할 수 있다.

```python
from statsmodels.stats.multicomp import pairwise_tukeyhsd
```

주요 인수는 다음과 같다.

| 코드 | 의미 |
| --- | --- |
| `endog=values` | 비교하려는 실제 측정값 |
| `groups=groups` | 각 측정값이 어떤 집단인지 나타내는 그룹 정보 |
| `alpha=0.05` | 유의수준 |

<br>

> ## **3-5 ) Tukey HSD 결과에서 확인할 값**

Tukey HSD의 결과는 다음과 같은 형태로 나타난다.

```text
group1
group2
meandiff
p-adj
lower
upper
reject
```

각 값의 의미는 다음과 같다.

| 결과 | 의미 |
| --- | --- |
| `group1` | 첫 번째 비교 집단 |
| `group2` | 두 번째 비교 집단 |
| `meandiff` | 두 집단 평균 차이 |
| `p-adj` | 다중 비교를 조정한 p-value |
| `lower` | 평균 차이 신뢰구간 하한 |
| `upper` | 평균 차이 신뢰구간 상한 |
| `reject` | 두 집단 평균이 같다는 귀무가설 기각 여부 |

특히 초보 단계에서는 `p-adj`와 `reject`를 중심으로 보면 된다.

```text
reject = True
        ↓
두 집단 평균이 같다는
귀무가설 기각
        ↓
두 집단의 평균에 차이가 있다고
볼 통계적 근거가 있음
```

반대로

```text
reject = False
        ↓
귀무가설 기각 근거 부족
        ↓
두 집단 평균의 차이를
확인할 충분한 통계적 근거 없음
```

<br>

> ## **3-6 ) 양궁 훈련법 Tukey HSD 예제**

세 가지 양궁 훈련 프로그램에 따른 평균 득점을 비교한다고 가정한다.

```python
archery_a = [8.7, 8.9, 8.8, 9.0, 8.6, 8.9]
archery_b = [9.2, 9.3, 9.1, 9.4, 9.2, 9.3]
archery_c = [8.8, 8.9, 8.7, 9.0, 8.9, 8.8]
```

먼저 ANOVA를 수행한다.

[Python : code] "세 가지 양궁 훈련법의 평균 득점 ANOVA 검정"

```python
from scipy import stats

archery_a = [8.7, 8.9, 8.8, 9.0, 8.6, 8.9]
archery_b = [9.2, 9.3, 9.1, 9.4, 9.2, 9.3]
archery_c = [8.8, 8.9, 8.7, 9.0, 8.9, 8.8]

f_stat, p_value = stats.f_oneway(
    archery_a,
    archery_b,
    archery_c
)

print(f"F 통계량: {f_stat:.3f}")
print(f"p-value: {p_value:.6f}")
```

[ Result ]

```text
F 통계량: 23.969
p-value: 0.000021
```

따라서

```text
0.000021 < 0.05
        ↓
귀무가설 기각
        ↓
세 훈련법의 평균 점수가
모두 같지는 않음
```

이라고 판단할 수 있다.

이제 어느 훈련법끼리 차이가 있는지 Tukey HSD로 확인한다.

[Python : code] "Tukey HSD를 이용한 양궁 훈련법 사후 검정"

```python
from statsmodels.stats.multicomp import pairwise_tukeyhsd

values = archery_a + archery_b + archery_c

groups = (
    ["A"] * len(archery_a)
    + ["B"] * len(archery_b)
    + ["C"] * len(archery_c)
)

tukey_result = pairwise_tukeyhsd(
    endog=values,
    groups=groups,
    alpha=0.05
)

print(tukey_result)
```

[ Result ]

```text
Multiple Comparison of Means - Tukey HSD, FWER=0.05
====================================================
group1 group2 meandiff p-adj   lower   upper  reject
----------------------------------------------------
     A      B   0.4333 0.0000  0.2524  0.6143   True
     A      C   0.0333 0.8824 -0.1476  0.2143  False
     B      C  -0.4000 0.0001 -0.5809 -0.2191   True
----------------------------------------------------
```

결과를 정리하면 다음과 같다.

| 비교 | `p-adj` | `reject` | 해석 |
| --- | ---: | --- | --- |
| A - B | 0.0000 | `True` | A와 B의 평균 득점에 유의한 차이가 있음 |
| A - C | 0.8824 | `False` | A와 C의 평균 차이를 확인할 충분한 근거가 없음 |
| B - C | 0.0001 | `True` | B와 C의 평균 득점에 유의한 차이가 있음 |

즉,

```text
A ≈ C

하지만

B는 A와 다름
B는 C와 다름
```

이라고 해석할 수 있다.

따라서 **훈련법 B의 평균 양궁 득점이 A와 C와 다르게 나타났다고 볼 수 있다.**

# **4. ANOVA → Tukey HSD 전체 분석 실습**

> ## **4-1 ) 보행 재활 프로그램 분석 문제**

세 가지 재활 프로그램 `A`, `B`, `C`가 환자의 보행속도에 서로 다른 효과를 보이는지 분석한다고 가정한다.

```text
독립변수
→ 재활 프로그램

집단
→ A / B / C

종속변수
→ 보행속도(m/s)
```

분석 목적은 두 단계로 나눌 수 있다.

```text
1단계
세 프로그램의 평균 보행속도가
전체적으로 다른가?

        ↓

ANOVA

        ↓

2단계
차이가 있다면
구체적으로 어느 프로그램끼리 다른가?

        ↓

Tukey HSD
```

<br>

> ## **4-2 ) ANOVA와 Tukey HSD를 한 번에 수행하기**

[Python : code] "보행 재활 프로그램 ANOVA 및 Tukey HSD 전체 분석"

```python
from scipy import stats
from statsmodels.stats.multicomp import pairwise_tukeyhsd

# 세 가지 보행 재활 프로그램
rehab_a = [1.10, 1.12, 1.08, 1.11, 1.09, 1.13]
rehab_b = [1.18, 1.20, 1.17, 1.19, 1.21, 1.18]
rehab_c = [1.11, 1.13, 1.10, 1.12, 1.14, 1.11]

# -------------------------
# 1. ANOVA
# -------------------------

f_stat, p_value = stats.f_oneway(
    rehab_a,
    rehab_b,
    rehab_c
)

print(f"F 통계량: {f_stat:.3f}")
print(f"p-value: {p_value:.8f}")

# -------------------------
# 2. ANOVA 결과 판단
# -------------------------

alpha = 0.05

if p_value < alpha:

    print("\nANOVA 결과: 귀무가설 기각")
    print("사후 검정을 수행합니다.\n")

    # Tukey HSD 데이터 구성
    values = rehab_a + rehab_b + rehab_c

    groups = (
        ["A"] * len(rehab_a)
        + ["B"] * len(rehab_b)
        + ["C"] * len(rehab_c)
    )

    # -------------------------
    # 3. Tukey HSD
    # -------------------------

    tukey_result = pairwise_tukeyhsd(
        endog=values,
        groups=groups,
        alpha=0.05
    )

    print(tukey_result)

else:

    print("\nANOVA 결과: 귀무가설을 기각할 근거가 부족합니다.")
```

[ Result ]

```text

p-value: 0.00000040

ANOVA 결과: 귀무가설 기각
사후 검정을 수행합니다.

Multiple Comparison of Means - Tukey HSD, FWER=0.05
====================================================
group1 group2 meandiff p-adj   lower   upper  reject
----------------------------------------------------
     A      B   0.0833 0.0000  0.0591  0.1076   True
     A      C   0.0133 0.3516 -0.0109  0.0376  False
     B      C  -0.0700 0.0000 -0.0942 -0.0458   True
----------------------------------------------------
```

# **5. ANOVA 결과 해석 시 주의할 점**

> ## **5-1 ) ANOVA가 유의하면 모든 집단이 서로 다른 것은 아니다**

다음 해석은 잘못된 해석이다.

```text
ANOVA p-value < 0.05

→ A, B, C가 모두 서로 다르다.
```

ANOVA가 알려주는 것은

```text
모든 집단 평균이 같다.
        ↓
이 가설을 기각
        ↓
적어도 하나는 다르다.
```

까지이다.

실제 결과는 다음과 같을 수도 있다.

```text
A = C

A ≠ B

B ≠ C
```

따라서 어떤 집단이 다른지는 **사후 검정**으로 확인해야 한다.

<br>

> ## **5-2 ) p-value가 0.05보다 크면 평균이 완전히 같다는 뜻이 아니다**

다음과 같이 표현하는 것은 피하는 것이 좋다.

```text
p-value > 0.05

→ 세 집단의 평균이 같다.
```

더 정확한 해석은 다음과 같다.

```text
p-value >= 0.05
        ↓
귀무가설을 기각할 근거 부족
        ↓
집단 평균에 차이가 있다고 판단할
충분한 통계적 근거가 없음
```

즉, **차이가 없다는 사실을 증명한 것이 아니라 차이가 있다고 결론 내릴 충분한 증거를 얻지 못한 것**이다.

<br>

> ## **5-3 ) ANOVA가 유의하지 않으면 사후 검정을 해야 할까?**

일반적인 ANOVA 분석 흐름에서는

```text
ANOVA
        ↓
유의하지 않음
        ↓
일반적으로 사후 검정을 진행하지 않음
```

으로 진행한다.

그 이유는 ANOVA에서 전체적인 평균 차이에 대한 근거를 확인하지 못했기 때문이다.

반대로

```text
ANOVA
        ↓
유의함
        ↓
사후 검정
```

을 수행한다.

따라서 초보 단계에서는 다음 순서로 기억하면 된다.

```text
ANOVA 먼저
        ↓
p-value < 0.05 확인
        ↓
유의하다면
        ↓
Tukey HSD
```

<br>

> ## **5-4 ) t-test와 ANOVA 비교**

| 구분 | t-test | ANOVA |
| --- | --- | --- |
| 주요 목적 | 평균 비교 | 평균 비교 |
| 대표적인 집단 수 | 주로 두 집단 | 세 집단 이상 |
| 주요 통계량 | `t` 통계량 | `F` 통계량 |
| 판단 방법 | p-value와 유의수준 비교 | p-value와 유의수준 비교 |
| 세부 집단 차이 | 두 집단 자체를 비교 | ANOVA만으로는 알 수 없음 |
| 추가 분석 | 상황에 따라 다름 | 유의하면 사후 검정 |

<br>

> ## **5-5 ) ANOVA와 Tukey HSD 역할 정리**

| 단계 | 질문 | 방법 |
| --- | --- | --- |
| 1 | 세 집단의 평균이 전체적으로 다른가? | `ANOVA` |
| 2 | ANOVA 결과가 통계적으로 유의한가? | `p-value` |
| 3 | 구체적으로 어느 집단이 다른가? | `Tukey HSD` |
| 4 | 각 집단의 차이가 유의한가? | `p-adj`, `reject` |

# **6. Advanced 추가 학습**

> ## **6-1 ) ANOVA의 기본 가정**

일반적인 One-way ANOVA를 적용할 때는 다음과 같은 조건을 함께 생각해야 한다.

| 가정 | 의미 |
| --- | --- |
| 독립성 | 각 관측값이 서로 독립적이어야 함 |
| 정규성 | 각 집단의 데이터 또는 오차가 정규분포에 크게 어긋나지 않아야 함 |
| 등분산성 | 각 집단의 분산이 비슷해야 함 |

초보 단계에서는

```text
ANOVA라고 해서
무조건 stats.f_oneway()부터 실행하는 것이 아니라

        ↓

데이터 구조와 기본 가정도
함께 확인해야 한다.
```

정도로 기억하면 된다.

<br>

> ## **6-2 ) 등분산성이 만족되지 않는다면?**

집단별 분산의 차이가 큰 경우에는 일반적인 ANOVA 대신 **Welch ANOVA**를 고려할 수 있다.

```text
일반 ANOVA
→ 집단 분산이 비슷하다는 가정을 사용

Welch ANOVA
→ 집단 분산이 서로 다른 상황에 더 적합할 수 있음
```

즉,

```text
분산이 비슷함
→ 일반 One-way ANOVA

분산 차이가 큼
→ Welch ANOVA 고려
```

라고 이해할 수 있다.

<br>

> ## **6-3 ) 정규성 가정이 적절하지 않다면?**

데이터가 매우 비정규적이거나 이상치가 심하고 ANOVA의 가정을 적용하기 어려운 경우에는 **Kruskal-Wallis 검정**과 같은 비모수 방법을 고려할 수 있다.

```text
One-way ANOVA
→ 평균과 분산을 이용하는 모수 검정

Kruskal-Wallis
→ 순위를 이용하는 비모수 검정
```

무조건 하나를 선택하는 것이 아니라 **데이터의 특성에 맞는 검정을 선택하는 것이 중요하다.**

# **7. 핵심정리**

> ## **7-1 ) 세 집단 이상의 평균 비교**

집단 수에 따라 평균 비교 방법을 먼저 생각할 수 있다.

```text
두 집단 평균 비교
        ↓
t-test

세 집단 이상의 평균 비교
        ↓
ANOVA
```

여러 집단을 단순히 t-검정으로 반복해서 비교하면 **다중 비교로 인한 제1종 오류가 증가할 수 있기 때문에 ANOVA를 사용한다.**

<br>

> ## **7-2 ) ANOVA의 가설**

ANOVA의 가설은 다음과 같다.

```text
H₀
→ 모든 집단의 평균이 같다.

H₁
→ 적어도 하나의 집단 평균이 다르다.
```

따라서

```text
p-value < 0.05
        ↓
귀무가설 기각
        ↓
적어도 하나의 집단 평균이
다르다고 볼 통계적 근거가 있음
```

이다.

ANOVA가 유의하다고 해서 **모든 집단이 서로 다르다는 뜻은 아니다.**

<br>

> ## **7-3 ) F 통계량 핵심**

F 통계량은 **집단 간 변동과 집단 내 변동을 비교하는 통계량**이다.

```text
     집단 간 변동
F ≈ ─────────────
     집단 내 변동
```

따라서 일반적으로

```text
집단 간 차이 ↑

집단 내 변동 ↓

        ↓

F 통계량 ↑
```

의 관계를 생각할 수 있다.

하지만 F값 자체만 보고 결론을 내리는 것이 아니라 **F 통계량을 이용해 계산된 p-value와 유의수준을 비교하여 판단**한다.

<br>

> ## **7-4 ) 사후 검정 핵심**

ANOVA는

```text
"적어도 하나가 다르다."
```

까지만 알려준다.

어떤 집단이 다른지를 확인하려면 사후 검정을 사용한다.

```text
ANOVA
        ↓
p-value < 0.05
        ↓
사후 검정
        ↓
Tukey HSD
        ↓
A vs B
A vs C
B vs C
```

Tukey HSD에서는 특히 `reject`를 확인할 수 있다.

```text
reject = True
→ 두 집단의 평균 차이가 있다고
   볼 통계적 근거가 있음

reject = False
→ 두 집단의 평균 차이를 확인할
   충분한 통계적 근거가 없음
```

<br>

> ## **7-5 ) 전체 분석 흐름**

세 집단 이상의 평균을 비교할 때 전체 흐름은 다음과 같다.

```text
[연구 문제 정의]

세 집단 이상의 평균을
비교하려고 하는가?
        ↓
One-way ANOVA
        ↓
가설 설정
        ↓
H₀ : 모든 평균이 같다.
H₁ : 적어도 하나는 다르다.
        ↓
F 통계량 계산
        ↓
p-value 계산
        ↓
p-value < 0.05 ?
        ↓
   ┌────┴────┐
   │         │
  Yes        No
   │         │
   ↓         ↓
귀무가설    귀무가설을
기각        기각할 근거 부족
   │
   ↓
적어도 하나의
평균이 다름
   │
   ↓
Tukey HSD
   │
   ↓
각 집단 조합 비교
   │
   ↓
reject 확인
   │
   ↓
구체적으로 어떤 집단이
다른지 해석
```

최종적으로 가장 중요한 것은 다음의 차이를 이해하는 것이다.

| 개념 | 핵심 질문 |
| --- | --- |
| `t-test` | 두 집단의 평균이 다른가? |
| `ANOVA` | 세 집단 이상의 평균 중 적어도 하나가 다른가? |
| `F 통계량` | 집단 간 차이가 집단 내부 변동보다 얼마나 큰가? |
| `p-value` | 관찰된 차이를 귀무가설 아래에서 보기 어려운가? |
| `Tukey HSD` | 구체적으로 어떤 집단끼리 다른가? |

따라서 ANOVA 분석에서는 단순히

```text
"p-value가 0.05보다 작으므로 차이가 있습니다."
```

에서 끝나는 것이 아니라

```text
왜 ANOVA를 사용했는가?
        ↓
귀무가설과 대립가설은 무엇인가?
        ↓
F 통계량은 무엇을 비교하는가?
        ↓
ANOVA 결과는 유의한가?
        ↓
어떤 집단이 다른지는 어떻게 확인하는가?
        ↓
Tukey HSD 결과를 어떻게 해석하는가?
```

의 흐름으로 이해하는 것이 중요하다.

**ANOVA → 유의성 확인 → 사후 검정 → 집단별 차이 해석**

이 전체 흐름을 하나로 연결해서 기억해야 한다.

# **1. 사후검정(Post-hoc Test)**

> ## **1-1 ) 사후검정의 의미**

사후검정(Post-hoc Test)은 **ANOVA에서 집단 간 평균 차이가 유의하게 나타난 이후, 구체적으로 어떤 집단 사이에서 차이가 발생했는지 확인하기 위한 추가 검정**이다.

```text
ANOVA
        ↓
p-value < 0.05
        ↓
적어도 하나의 집단 평균이 다름
        ↓
그런데 어떤 집단이 다른지는 모름
        ↓
사후검정
        ↓
A vs B
A vs C
B vs C
```

예를 들어 세 가지 역도 훈련 프로그램의 평균 최대근력에 차이가 있다는 ANOVA 결과가 나왔다고 하더라도 ANOVA만으로는

```text
프로그램 A와 B가 다른가?

프로그램 A와 C가 다른가?

프로그램 B와 C가 다른가?
```

를 알 수 없다.

따라서 사후검정을 이용하여 구체적인 집단의 차이를 확인한다.

<br>

> ## **1-2 ) 대표적인 사후검정 한 줄 정리**

| 사후검정 | 한 줄 의미 |
| --- | --- |
| `Bonferroni` | 여러 쌍을 비교할 때 **유의수준을 비교 횟수만큼 엄격하게 조정**하여 제1종 오류를 강하게 통제하는 방법 |
| `Scheffé` | 단순한 두 집단 비교뿐 아니라 **여러 집단 평균의 다양한 조합까지 폭넓게 비교**할 수 있는 보수적인 방법 |
| `Duncan` | 평균의 순서를 이용하여 **인접한 집단부터 단계적으로 비교하는 다중범위검정**으로, 유의한 차이가 비교적 쉽게 나타날 수 있는 방법 |
| `Dunnett` | **하나의 대조군을 기준으로 여러 실험군을 각각 비교**할 때 사용하는 방법 |
| `Tukey HSD` | **모든 집단의 두 집단 조합을 서로 비교**하면서 전체 제1종 오류를 통제하는 대표적인 사후검정 |

<br>

> ## **1-3 ) 사후검정 선택의 핵심 질문**

사후검정은 모두 같은 목적을 가진 것이 아니다.

```text
무엇을 비교하고 싶은가?
        ↓

모든 집단을 서로 비교?
→ Tukey

하나의 대조군과 나머지만 비교?
→ Dunnett

제1종 오류를 매우 엄격하게 통제?
→ Bonferroni

두 집단뿐 아니라
여러 평균의 조합까지 비교?
→ Scheffé

평균 순서를 단계적으로 비교?
→ Duncan
```

# **2. Bonferroni**

> ## **2-1 ) Bonferroni의 의미**

`Bonferroni` 방법은 여러 집단을 반복해서 비교할 때 발생하는 **다중비교에 따른 제1종 오류 증가를 줄이기 위해 유의수준을 더 엄격하게 조정하는 방법**이다.

핵심은 다음과 같다.

```text
전체 유의수준 α
        ↓
비교 횟수로 나눔
        ↓
각 검정에서 사용할
더 작은 유의수준 설정
```

계산식은 다음과 같다.

```text
Bonferroni α
= 전체 α / 비교 횟수
```

예를 들어 세 집단을 비교한다고 하자.

```text
A vs B
A vs C
B vs C

총 비교 횟수 = 3
```

전체 유의수준이

```text
α = 0.05
```

라면

```text
각 비교의 α

= 0.05 / 3

≈ 0.0167
```

이 된다.

따라서 각 비교의 p-value가 `0.0167`보다 작아야 유의하다고 판단한다.

<br>

> ## **2-2 ) Bonferroni 스포츠 예시**

세 가지 핸드볼 슈팅 훈련의 평균 공 속도를 비교했다고 가정한다.

```text
A
→ 일반 슈팅 훈련

B
→ 근력 중심 훈련

C
→ Pose Estimator 기반
   관절각도 피드백 훈련
```

ANOVA 결과가 유의하여 세 집단을 서로 비교하려고 한다.

```text
A vs B
A vs C
B vs C
```

비교가 총 `3개`이므로

```text
Bonferroni α
= 0.05 / 3
≈ 0.0167
```

이다.

예를 들어

| 비교 | p-value | Bonferroni 기준 `0.0167` | 결과 |
| --- | ---: | ---: | --- |
| A vs B | `0.030` | 0.0167 | 유의하지 않음 |
| A vs C | `0.004` | 0.0167 | 유의 |
| B vs C | `0.010` | 0.0167 | 유의 |

일반적인 `0.05` 기준에서는 `A vs B`도 유의해 보이지만 Bonferroni에서는 유의하지 않다.

```text
비교 횟수 증가
        ↓
유의수준 더욱 엄격
        ↓
제1종 오류 감소

하지만

실제 차이를 발견하기도 어려워짐
        ↓
검정력 감소
```

따라서 Bonferroni는 **비교가 많아질수록 지나치게 보수적이 될 수 있다는 단점**이 있다.


<br><br>

# **3. Scheffé**

> ## **3-1 ) Scheffé의 의미**

`Scheffé` 검정은 ANOVA 결과가 유의한 경우 사용할 수 있는 사후검정으로, **단순한 두 집단 비교뿐 아니라 여러 집단 평균을 조합한 다양한 대비(contrast)까지 검정할 수 있는 방법**이다.

예를 들어 세 집단이 있다면 단순하게

```text
A vs B
A vs C
B vs C
```

만 보는 것이 아니라

```text
A

vs

B와 C의 평균
```

같은 비교도 가능하다.

따라서 매우 유연하지만 그만큼 **보수적인 검정**에 해당한다.

<br>

> ## **3-2 ) Scheffé 스포츠 예시**

역도 훈련 프로그램을 다음과 같이 구성했다고 하자.

```text
A
→ 일반 근력 훈련

B
→ 파워 중심 훈련

C
→ 속도 기반 훈련
```

단순히

```text
A vs B
```

만 비교하는 것이 아니라

```text
일반 훈련 A

vs

특수 훈련 B와 C의 평균
```

처럼 연구자가 관심 있는 **여러 평균의 조합**을 비교하고 싶다면 Scheffé를 고려할 수 있다.

또한 집단별 표본 수가 같지 않아도 사용할 수 있다.

```text
A = 15명
B = 12명
C = 18명

→ 적용 가능
```


<br><br>

---

# **4. Duncan**

> ## **4-1 ) Duncan의 의미**

`Duncan's Multiple Range Test`는 집단 평균을 크기 순서대로 정렬한 뒤 **평균 사이의 거리에 따라 다른 기준을 사용하여 단계적으로 비교하는 다중범위검정**이다.

```text
집단 평균 정렬

A < B < C < D
        ↓
인접한 평균부터
단계적으로 비교
```

Duncan은 다른 보수적인 사후검정에 비해 **유의한 차이를 발견하기 쉬운 편**이다.

그만큼 제1종 오류를 상대적으로 엄격하게 통제하지 못한다는 단점이 있다.

따라서 결과를 해석할 때 주의해야 한다.

<br>

> ## **4-2 ) Duncan 스포츠 예시**

네 가지 배드민턴 풋워크 훈련 후 평균 반응시간이 다음과 같다고 가정한다.

```text
A = 0.48초
B = 0.45초
C = 0.41초
D = 0.39초
```

Duncan 방법에서는 평균을 순서대로 배열하여

```text
D < C < B < A
```

와 같은 서열을 만든 뒤 단계적으로 집단 차이를 확인한다.

즉,

> **여러 훈련 방법 사이에서 평균의 서열 관계를 세분화하여 확인하려는 경우 사용할 수 있지만 제1종 오류 위험이 상대적으로 크기 때문에 결과를 신중하게 해석해야 한다.**


<br><br>

# **5. Dunnett**

> ## **5-1 ) Dunnett의 의미**

`Dunnett` 검정은 **특정 하나의 대조군(Control)을 기준으로 여러 실험군(Treatment)을 비교**하는 사후검정이다.

모든 집단을 서로 비교하지 않는다.

예를 들어

```text
Control = A

Treatment = B
Treatment = C
Treatment = D
```

라면

```text
A vs B
A vs C
A vs D
```

만 비교한다.

다음 비교는 하지 않는다.

```text
B vs C
B vs D
C vs D
```

따라서 연구 목적이 **기존 방법과 새로운 방법들의 차이**를 확인하는 것이라면 효율적이다.

<br>

> ## **5-2 ) Dunnett 스포츠 예시**

양궁 훈련을 다음과 같이 설계했다고 하자.

```text
A
→ 기존 훈련
→ Control

B
→ 근력 훈련

C
→ 시각적 자세 피드백

D
→ Pose Estimator 실시간 피드백
```

연구 질문이

> **새로운 세 훈련 방법이 기존 훈련보다 평균 명중률을 높이는가?**

라면 필요한 비교는

```text
기존 A vs 근력 B

기존 A vs 시각 피드백 C

기존 A vs Pose 피드백 D
```

이다.

이때 B, C, D끼리 서로 비교할 필요가 없다면 **Dunnett 검정이 적합한 선택이 될 수 있다.**

모든 쌍을 비교하지 않기 때문에 목적에 맞는 경우 Tukey보다 검정력을 효율적으로 사용할 수 있다.


<br><br>

---

# **6. Tukey HSD**

> ## **6-1 ) Tukey HSD의 의미**

`Tukey HSD(Honestly Significant Difference)`는 **모든 집단을 두 집단씩 비교하면서 전체적인 제1종 오류를 통제하는 대표적인 사후검정 방법**이다.

세 집단이라면

```text
A vs B

A vs C

B vs C
```

를 모두 비교한다.

네 집단이라면

```text
A vs B
A vs C
A vs D
B vs C
B vs D
C vs D
```

를 비교한다.

따라서

> **특정 대조군만 보는 것이 아니라 모든 집단의 평균 차이가 궁금할 때**

사용하기 좋다.

<br>

> ## **6-2 ) Tukey의 표본 수**

기본적인 Tukey HSD는 균형잡힌 표본에서 설명하기 쉽지만, 실제로 집단별 표본 수가 다를 때는 **Tukey-Kramer 방법**으로 확장하여 비교할 수 있다.

```text
표본 수 동일
→ Tukey HSD

표본 수 다름
→ Tukey-Kramer 방식으로 확장 가능
```

다만 일반적인 Tukey 계열 검정에서는 **독립성 및 등분산성 등의 ANOVA 가정**을 함께 고려해야 한다.

<br>

> ## **6-3 ) 펜싱 훈련 프로그램 Tukey 예시**

펜싱 런지 훈련 방법을 다음과 같이 구성했다고 하자.

```text
A
→ 기존 훈련

B
→ 저항 밴드 훈련

C
→ Pose 기반 무릎관절 각도 피드백
```

연구 목적이

```text
A와 B도 궁금하고

A와 C도 궁금하고

B와 C도 궁금하다.
```

라면 Tukey가 적절하다.

예를 들어 결과가

```text
A vs B
→ reject = False

A vs C
→ reject = True

B vs C
→ reject = True
```

라면

```text
A와 B
→ 유의한 차이를 확인하지 못함

A와 C
→ 유의한 평균 차이

B와 C
→ 유의한 평균 차이
```

로 해석할 수 있다.


<br><br>

# **7. 사후검정 차이 비교**

> ## **7-1 ) 스포츠·운동역학 예시로 비교**

| 사후검정 | 핵심 목적 | 스포츠·운동역학 예시 | 모든 쌍 비교 | 특징 |
| --- | --- | --- | --- | --- |
| `Bonferroni` | 여러 비교에서 제1종 오류를 강하게 통제 | 핸드볼의 3가지 슈팅 훈련을 `A-B`, `A-C`, `B-C` t-test로 비교 | 가능 | 단순하고 널리 사용되지만 비교가 많으면 검정력 감소 |
| `Scheffé` | 두 집단 비교뿐 아니라 여러 평균의 조합까지 비교 | 역도에서 `일반 훈련`과 `파워+속도 훈련의 평균`을 비교 | 가능 | 매우 유연하지만 보수적 |
| `Duncan` | 평균을 순서대로 배열해 단계적으로 차이 확인 | 배드민턴 풋워크 훈련별 반응시간의 서열 비교 | 가능 | 차이를 쉽게 탐지하지만 제1종 오류에 상대적으로 취약 |
| `Dunnett` | 하나의 대조군과 여러 실험군 비교 | 기존 양궁 훈련과 3가지 신규 훈련을 각각 비교 | 아니오 | Control과 Treatment 비교에 효율적 |
| `Tukey HSD` | 모든 집단의 평균을 두 집단씩 비교 | 펜싱 3가지 런지 훈련의 모든 조합 비교 | 예 | 전체 쌍대비교에 대표적으로 사용 |

<br>

> ## **7-2 ) 상황별 선택 방법**

```text
ANOVA 결과 유의
        ↓
구체적으로 어떤 비교가 필요한가?
        ↓
┌─────────────────────────────┐
│ 모든 집단을 서로 비교       │
│ → Tukey                     │
└─────────────────────────────┘

┌─────────────────────────────┐
│ 하나의 기존 방법과          │
│ 여러 새로운 방법 비교       │
│ → Dunnett                   │
└─────────────────────────────┘

┌─────────────────────────────┐
│ 여러 개의 개별 검정을       │
│ 단순하고 엄격하게 보정      │
│ → Bonferroni                │
└─────────────────────────────┘

┌─────────────────────────────┐
│ 단순 쌍뿐 아니라 여러       │
│ 평균 조합까지 비교          │
│ → Scheffé                   │
└─────────────────────────────┘

┌─────────────────────────────┐
│ 평균의 순서와 단계적인      │
│ 차이를 탐색                 │
│ → Duncan                    │
└─────────────────────────────┘
```

<br>

> ## **7-3 ) 같은 운동역학 연구에서 방법이 달라지는 예**

네 가지 역도 기술 피드백 방법을 비교한다고 가정한다.

```text
A
→ 기존 코칭

B
→ 무릎관절 각도 피드백

C
→ 고관절 각도 피드백

D
→ 바벨 궤적 피드백
```

연구 질문에 따라 사후검정이 달라질 수 있다.

| 연구 질문 | 적합하게 고려할 방법 |
| --- | --- |
| `A, B, C, D 중 모든 집단의 차이가 궁금하다.` | `Tukey` |
| `기존 방법 A와 B, C, D의 차이만 궁금하다.` | `Dunnett` |
| `미리 정한 몇 개의 비교에 강한 오류 보정을 하고 싶다.` | `Bonferroni` |
| `B와 C의 평균을 합친 그룹과 A를 비교하는 등 복잡한 대비도 궁금하다.` | `Scheffé` |
| `평균 기록의 순서를 중심으로 차이를 탐색하고 싶다.` | `Duncan` |

# **8. Advanced 추가 학습**

> ## **8-1 ) 사후검정은 ANOVA 가정과 함께 선택해야 한다**

사후검정을 단순히 이름만 보고 선택하면 안 된다.

먼저 ANOVA에서

```text
독립성
정규성
등분산성
```

등을 확인해야 한다.

특히 등분산성이 크게 위반된 경우에는

```text
일반 One-way ANOVA
        ↓
Welch ANOVA 고려
```

할 수 있으며, 이후 사후검정 역시 `Games-Howell`과 같은 방법을 고려할 수 있다.

```text
등분산성 만족
→ Tukey 등 고려

등분산성 만족 어려움
→ Welch ANOVA
→ Games-Howell 고려
```

<br>

> ## **8-2 ) 비교 횟수 계산**

집단이 `k`개이고 모든 집단을 두 개씩 비교한다면 비교 개수는 다음과 같다.

```text
k(k - 1)
────────
   2
```

예를 들어

```text
3집단
→ 3개 비교

4집단
→ 6개 비교

5집단
→ 10개 비교

10집단
→ 45개 비교
```

따라서 Bonferroni는 집단 수가 증가할수록 유의수준이 매우 작아진다.

예를 들어 5개 집단이면

```text
비교 횟수 = 10

Bonferroni α
= 0.05 / 10
= 0.005
```

가 되어 실제 차이를 발견하기가 더 어려워질 수 있다.

# **9. 핵심정리**

> ## **9-1 ) 사후검정 전체 흐름**

```text
3집단 이상의 평균 비교
        ↓
ANOVA
        ↓
p-value < 0.05
        ↓
귀무가설 기각
        ↓
적어도 하나의 평균이 다름
        ↓
하지만 어디가 다른지 모름
        ↓
사후검정
```

<br>

> ## **9-2 ) 각 사후검정 한 줄 핵심**

```text
Bonferroni
→ 유의수준을 비교 횟수만큼 나누어
   제1종 오류를 엄격하게 통제

Scheffé
→ 모든 쌍뿐 아니라
   여러 평균의 조합까지 비교 가능

Duncan
→ 평균 순서에 따라 단계적으로 비교하며
   차이가 비교적 쉽게 나타날 수 있음

Dunnett
→ 하나의 Control을 기준으로
   여러 Treatment와 비교

Tukey
→ 모든 집단의 쌍대 평균 차이를
   한 번에 비교
```

<br>

> ## **9-3 ) 가장 중요한 차이**

| 목적 | 우선 생각할 사후검정 |
| --- | --- |
| 모든 집단을 서로 비교 | `Tukey` |
| 대조군 하나와 여러 실험군 비교 | `Dunnett` |
| 매우 간단하고 엄격한 다중비교 보정 | `Bonferroni` |
| 복잡한 평균 조합까지 비교 | `Scheffé` |
| 평균의 단계적·서열적 차이 탐색 | `Duncan` |

따라서

```text
"어떤 사후검정이 가장 좋은가?"
```

보다

```text
어떤 집단들을 비교하려는가?
        ↓
모든 쌍인가?
        ↓
대조군과 실험군만인가?
        ↓
복잡한 평균 조합인가?
        ↓
제1종 오류를 얼마나 엄격하게
통제할 것인가?
        ↓
데이터가 ANOVA의 가정을
만족하는가?
```

를 먼저 판단해야 한다.

**한 문장으로 정리하면**

> **사후검정은 ANOVA에서 전체 집단의 평균 차이를 확인한 뒤 구체적으로 어느 집단 사이에서 차이가 발생했는지를 확인하는 방법이며, Tukey는 모든 쌍, Dunnett는 대조군과 실험군, Bonferroni는 엄격한 다중비교 보정, Scheffé는 다양한 평균 조합, Duncan은 단계적 평균 비교에 특징이 있다.**
