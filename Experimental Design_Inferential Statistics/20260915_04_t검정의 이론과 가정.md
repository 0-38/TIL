# **1. t-검정의 기본 원리와 t분포**

`t-검정(t-test)`은 **평균의 차이가 단순한 표본 변동 때문에 발생한 것인지, 통계적으로 의미 있는 차이라고 볼 수 있는지 판단하는 가설검정 방법**이다.

예를 들어 새로운 근력 훈련을 받은 선수들의 평균 점프 높이가 기존 기준보다 `3cm` 높게 나타났다고 하자.

단순히

```text
평균이 3cm 높다
→ 훈련 효과가 있다
```

라고 판단할 수는 없다.

선수마다 기록의 변동이 존재하기 때문에 다음 두 가지를 함께 고려해야 한다.

```text
평균 차이
+
데이터의 변동성
```

t-검정에서는 이를 이용하여 **t 통계량(t-statistic)** 을 계산한다.

<br>

> ## **1-1 ) t 통계량의 의미**

t 통계량은 쉽게 말하면

```text
관찰된 평균 차이가
표본 데이터의 불확실성에 비해
얼마나 큰가?
```

를 나타내는 값이다.

기본적인 구조는 다음과 같이 이해할 수 있다.

```text
             관찰된 평균 차이
t = ─────────────────────────────
          평균 차이의 표준오차
```

즉,

```text
평균 차이 ↑
→ |t| 증가

데이터 변동성 ↑
→ 표준오차 증가
→ |t| 감소

표본 크기 ↑
→ 표준오차 감소
→ |t| 증가 가능
```

한다.

`t`의 절댓값이 클수록 귀무가설에서 예상되는 값과 표본 결과의 차이가 상대적으로 크다는 의미이다.

단, **t 통계량 자체만으로 최종 결론을 내리는 것이 아니라 t분포를 이용해 계산한 p-value를 함께 사용한다.**

<br>

> ## **1-2 ) t분포란**

`t분포(t-distribution)`는 평균에 관한 가설검정에서 사용하는 확률분포이다.

정규분포와 비슷하게 가운데가 높고 양쪽으로 꼬리가 있는 형태지만, 일반적으로 정규분포보다 꼬리가 두껍다.

```text
               t = 0
                 │
              ___│___
            /         \
          /             \
________/                 \________
```

특히 모집단의 표준편차를 알지 못하고 **표본의 표준편차를 이용해 모집단 평균을 추론할 때 발생하는 추가적인 불확실성**을 반영한다.

표본 크기가 커지면 t분포는 점점 표준정규분포와 비슷해진다.

<br>

> ## **1-3 ) 자유도 df**

t분포의 모양은 **자유도(Degrees of Freedom, df)**에 따라 달라진다.

단일표본 t-검정의 자유도는 일반적으로

```text
df = n - 1
```

이다.

예를 들어 선수 `10명`을 분석하면

```text
df = 10 - 1
   = 9
```

가 된다.

자유도가 작으면 t분포의 꼬리가 상대적으로 두껍고, 자유도가 커질수록 정규분포와 가까워진다.

<br>

> ## **1-4 ) t-검정의 종류**

비교하려는 데이터 구조에 따라 t-검정의 종류가 달라진다.

| 분석 상황 | 검정 방법 | SciPy 함수 |
|---|---|---|
| 하나의 집단 평균과 기준값 비교 | 단일표본 t-검정 | `stats.ttest_1samp()` |
| 서로 다른 두 집단 평균 비교 | 독립표본 t-검정 | `stats.ttest_ind()` |
| 같은 대상의 전후 평균 비교 | 대응표본 t-검정 | `stats.ttest_rel()` |

예를 들어

```text
선수 평균 점프 높이 vs 기준 50cm (평균 기준)
→ 단일표본 t-검정

훈련 A 선수 vs 훈련 B 선수 (평균 기준)
→ 독립표본 t-검정

같은 선수의 재활 전 vs 재활 후 (평균 기준)
→ 대응표본 t-검정
```

으로 구분할 수 있다.

<br>

> ## **1-5 ) t-검정의 공통 판단 흐름**

어떤 종류의 t-검정을 사용하더라도 기본적인 가설검정의 과정은 같다.

```text
연구 질문 설정
      ↓
H₀ / H₁ 설정
      ↓
유의수준 α 설정
      ↓
데이터 구조에 맞는 t-검정 선택
      ↓
t-statistic 계산
      ↓
t분포를 이용해 p-value 계산
      ↓
p-value와 α 비교
      ↓
┌────────────────────────────┐
│ p ≤ α → H₀ 기각           │
│ p > α → H₀ 기각 근거 부족 │
└────────────────────────────┘
      ↓
연구 문제에 맞게 결과 해석
```

# **2. 단일표본 t-검정**

> ## **2-1 ) 단일표본 t-검정이란**

**단일표본 t-검정(One-sample t-test)**은 하나의 표본 평균을 이미 정해진 특정 기준값과 비교할 때 사용한다.

예를 들어 스포츠과학센터에서 선수들의 기존 평균 점프 높이를 `50cm`로 관리하고 있다고 하자.

새로운 근력 프로그램에 참여한 선수들의 평균 점프 높이가 기존 `50cm`와 다른지 확인한다면

```text
하나의 표본
vs
기준값 50cm
```

구조이므로 단일표본 t-검정을 사용한다.

가설은 다음과 같이 설정할 수 있다.

```text
H₀ : μ = 50
H₁ : μ ≠ 50
```

<br>

> ## **2-2 ) 단일표본 t 통계량**

단일표본 t 통계량은 다음 구조를 가진다.

```text
     표본평균 - 기준 평균
t = ───────────────────
         s / √n
```

여기서

| 기호 | 의미 |
|---|---|
| `x̄` | 표본 평균 |
| `μ₀` | 귀무가설에서의 기준 평균 |
| `s` | 표본 표준편차 |
| `n` | 표본 크기 |
| `s / √n` | 표준오차 |

즉, **표본 평균과 기준 평균의 차이가 표준오차의 몇 배인지** 나타낸다고 이해할 수 있다.

<br>

> ## **2-3 ) 단일표본 t-검정 예제**

[ python : code ] "근력 프로그램 참가 선수의 평균 점프 높이가 기존 기준 50cm와 다른지 검정"

```python
import numpy as np
from scipy import stats

jump_height = [
    52, 54, 51, 55, 53,
    50, 56, 52, 54, 53
]

result = stats.ttest_1samp(jump_height, popmean=50)

print(f"표본 평균: {np.mean(jump_height):.1f}cm")
print(f"t 통계량: {result.statistic:.3f}")
print(f"p-value: {result.pvalue:.6f}")
print(f"자유도: {result.df}")
```

[ Result ]

```text
표본 평균: 53.0cm
t 통계량: 5.196
p-value: 0.000567
자유도: 9
```

### 결과 해석

가설은 다음과 같다.

```text
H₀ : 평균 점프 높이 = 50cm
H₁ : 평균 점프 높이 ≠ 50cm
```

유의수준을 `α = 0.05`라고 하면

```text
p-value = 0.000567

0.000567 < 0.05
```

이므로 귀무가설을 기각한다.

따라서

```text
새로운 근력 프로그램 참가 선수들의
평균 점프 높이가 기존 50cm와 다르다고 볼
통계적 근거가 있다.
```

라고 해석할 수 있다.

<br>

> ## **2-4 ) t 통계량의 방향**

이번 결과는

```text
t = +5.196
```

이다.

양수인 이유는

```text
표본 평균 53cm
>
기준 평균 50cm
```

이기 때문이다.

반대로 표본 평균이 기준보다 작다면 t 통계량은 음수가 될 수 있다.

```text
t > 0
→ 표본 평균이 기준보다 높은 방향

t < 0
→ 표본 평균이 기준보다 낮은 방향
```

단, 양측검정에서는 주로 **차이의 존재 여부**를 판단하므로 t값의 방향과 함께 p-value를 확인한다.

# **3. 독립표본 t-검정**

> ## **3-1 ) 독립표본 t-검정이란**

**독립표본 t-검정(Independent Samples t-test)** 은 서로 다른 두 집단의 평균을 비교할 때 사용한다.

예를 들어

```text
훈련 프로그램 A 선수 10명
vs
훈련 프로그램 B 선수 10명
```

처럼 두 집단의 구성원이 서로 다르면 독립된 표본이다.

가설은 일반적으로 다음과 같다.

```text
H₀ : μA = μB
H₁ : μA ≠ μB
```

또는

```text
H₀ : μA - μB = 0
H₁ : μA - μB ≠ 0
```

으로 표현할 수 있다.

<br>

> ## **3-2 ) 독립표본 t-검정 예제**

두 가지 스프린트 훈련을 받은 서로 다른 선수들의 최고속도를 비교한다고 하자.

[ python : code ] "서로 다른 두 스프린트 훈련 그룹의 평균 최고속도를 Welch t-검정으로 비교"

```python
import numpy as np
from scipy import stats

group_a = [
    31.2, 30.8, 31.5, 30.9, 31.1,
    31.4, 30.7, 31.0, 31.3, 30.9
]

group_b = [
    32.0, 31.8, 32.2, 31.7, 32.1,
    31.9, 32.3, 31.6, 32.0, 31.8
]

result = stats.ttest_ind(
    group_a,
    group_b,
    equal_var=False
)

print(f"A 그룹 평균: {np.mean(group_a):.2f} km/h")
print(f"B 그룹 평균: {np.mean(group_b):.2f} km/h")
print(f"t 통계량: {result.statistic:.3f}")
print(f"p-value: {result.pvalue:.8f}")
```

[ Result ]

```text
A 그룹 평균: 31.08 km/h
B 그룹 평균: 31.94 km/h
t 통계량: -7.851
p-value: 0.00000040
```

### 결과 해석

```text
H₀ : 두 훈련 그룹의 평균 최고속도는 같다.
H₁ : 두 훈련 그룹의 평균 최고속도는 다르다.
```

결과는

```text
p-value < 0.05
```

이므로 귀무가설을 기각한다.

따라서 두 훈련 그룹의 평균 최고속도가 다르다고 볼 통계적 근거가 있다.

`t`가 음수인 이유는 코드를

```python
stats.ttest_ind(group_a, group_b)
```

순서로 입력했으며

```text
A 평균 < B 평균
```

이기 때문이다.

<br>

> ## **3-3 ) Student's t-test와 Welch's t-test**

독립표본 t-검정에는 대표적으로 두 가지 방식이 있다.

| 구분 | Student's t-test | Welch's t-test |
|---|---|---|
| 두 집단 독립성 | 필요 | 필요 |
| 정규성 | 고려 | 고려 |
| 등분산성 | 가정함 | 가정하지 않음 |
| 분산 처리 | 공통 분산 사용 | 각 집단 분산을 따로 반영 |
| 자유도 | `n1 + n2 - 2` | Welch 방식으로 보정 |
| SciPy | `equal_var=True` | `equal_var=False` |

Python에서는

```python
stats.ttest_ind(
    group_a,
    group_b,
    equal_var=True
)
```

이면 Student's t-test,

```python
stats.ttest_ind(
    group_a,
    group_b,
    equal_var=False
)
```

이면 Welch's t-test가 된다.

<br>

> ## **3-4 ) 어떤 방법을 선택할까**

두 집단의 분산이 같다고 보기 어렵거나 확신이 없다면 **Welch's t-test**를 사용하는 것이 실용적인 선택이 될 수 있다.

Welch 검정은 분산이 다른 상황에 더 안전하며, 분산이 비슷한 경우에도 대체로 안정적으로 사용할 수 있다.

따라서

```text
서로 다른 두 그룹 평균 비교
        ↓
독립표본 t-검정
        ↓
등분산 가정을 사용?
       /       \
     Yes       No / 불확실
      ↓              ↓
 Student          Welch
 t-test           t-test
```

로 생각할 수 있다.

# **4. 대응표본 t-검정**

> ## **4-1 ) 대응표본 t-검정이란**

**대응표본 t-검정(Paired Samples t-test)**은 같은 대상을 두 번 측정하거나 서로 짝지어진 데이터의 평균 차이를 검정할 때 사용한다.

예를 들어 보행 재활 프로그램 전후에 같은 환자의 보행 속도를 측정했다고 하자.

```text
대상 1 : 재활 전 ↔ 재활 후
대상 2 : 재활 전 ↔ 재활 후
대상 3 : 재활 전 ↔ 재활 후
...
```

두 데이터는 독립된 집단이 아니라 **한 사람 안에서 서로 연결되어 있다.**

<br>

> ## **4-2 ) 실제로 검정하는 것은 차이값의 평균**

대응표본 t-검정의 핵심은 전후 데이터 자체를 서로 독립된 두 그룹처럼 비교하는 것이 아니다.

각 사람의 차이를 먼저 생각한다.

```text
d₁ = After₁ - Before₁
d₂ = After₂ - Before₂
d₃ = After₃ - Before₃
...
```

그리고

```text
H₀ : 평균 차이 = 0
H₁ : 평균 차이 ≠ 0
```

인지 검정한다.

따라서 대응표본 t-검정은 본질적으로 **짝지어진 차이값에 대한 단일표본 t-검정**이라고 이해할 수도 있다.

<br>

> ## **4-3 ) 대응표본 t-검정 예제**

[ python : code ] "같은 대상의 재활 프로그램 전후 보행 속도 차이를 대응표본 t-검정으로 분석"

```python
import numpy as np
from scipy import stats

before = np.array([
    1.08, 1.12, 1.00, 1.15, 1.05,
    1.10, 1.03, 1.09, 1.07, 1.11
])

after = np.array([
    1.16, 1.18, 1.09, 1.22, 1.13,
    1.17, 1.11, 1.16, 1.15, 1.19
])

result = stats.ttest_rel(
    before,
    after
)

print(f"재활 전 평균: {before.mean():.3f} m/s")
print(f"재활 후 평균: {after.mean():.3f} m/s")
print(f"평균 변화량: {(after - before).mean():.3f} m/s")
print(f"t 통계량: {result.statistic:.3f}")
print(f"p-value: {result.pvalue:.10f}")
```

[ Result ]

```text
재활 전 평균: 1.080 m/s
재활 후 평균: 1.156 m/s
평균 변화량: 0.076 m/s
t 통계량: -28.500
p-value: 0.0000000004
```

### 결과 해석

```text
H₀ : 재활 전후 평균 보행 속도 차이 = 0
H₁ : 재활 전후 평균 보행 속도 차이 ≠ 0
```

`p-value < 0.05`이므로 귀무가설을 기각한다.

따라서 재활 프로그램 전후의 평균 보행 속도가 다르다고 볼 통계적 근거가 있다.

평균적으로는

```text
1.156 - 1.080
= 0.076 m/s
```

만큼 증가했다.

<br>

> ## **4-4 ) 독립표본과 대응표본 t-검정 비교**

| 구분 | 독립표본 t-검정 | 대응표본 t-검정 |
|---|---|---|
| 대상 | 서로 다른 두 집단 | 같은 대상의 두 측정 |
| 관측값 관계 | 독립 | 서로 짝지어짐 |
| 검정 핵심 | 두 모집단 평균 차이 | 짝지어진 차이값의 평균 |
| 예시 | 훈련 A 선수 vs 훈련 B 선수 | 동일 선수 훈련 전후 |
| SciPy | `ttest_ind()` | `ttest_rel()` |
| 정규성에서 주목할 값 | 각 집단 분포 | **차이값 분포** |

# **5. t-검정의 주요 가정**

t-검정을 사용할 때는 단순히 함수를 실행하기보다 **분석 구조에 맞는 가정이 적절한지 확인해야 한다.**

대표적으로 다음 세 가지를 확인한다.

```text
① 독립성
② 정규성
③ 등분산성
```

다만 모든 종류의 t-검정에 세 가정을 동일하게 적용하는 것은 아니다.

<br>

> ## **5-1 ) 독립성 Independence**

독립성은 한 관측값이 다른 관측값에 구조적으로 영향을 받거나 중복되지 않는다는 의미이다.

예를 들어 훈련 A와 B 그룹을 비교하는 독립표본 t-검정에서

```text
선수 A가 그룹 A와 그룹 B에 동시에 포함
```

된다면 독립성 문제가 발생할 수 있다.

독립성은 `Shapiro-Wilk`처럼 별도의 검정을 실행해 판단하기보다 **연구 설계와 데이터 수집 과정을 통해 확인하는 것이 중요하다.**

예를 들어

```text
서로 다른 선수들을 무작위로 두 그룹에 배정
→ 독립성 확보에 적절

같은 선수의 전후 기록
→ 서로 독립이 아님
→ 대응표본 t-검정 사용
```

으로 판단한다.

<br>

> ## **5-2 ) 정규성 Normality**

정규성은 분석 대상이 되는 분포가 정규분포에서 심하게 벗어나지 않는지 확인하는 가정이다.

대표적으로 `Shapiro-Wilk Test`를 사용할 수 있다.

Shapiro-Wilk 검정의 가설은

```text
H₀ : 정규분포를 따른다.
H₁ : 정규분포를 따르지 않는다.
```

이다.

일반적으로

```text
p-value > 0.05
→ 정규성을 위반한다고 볼 근거가 부족

p-value ≤ 0.05
→ 정규성 위반을 의심
```

으로 해석한다.

하지만 정규성 검정의 p-value 하나만 기계적으로 판단해서는 안 된다.

```text
Shapiro-Wilk
+
히스토그램
+
Q-Q Plot
+
이상치
+
표본 크기
```

등을 함께 확인하는 것이 좋다.

<br>

> ## **5-3 ) 대응표본 t-검정의 정규성**

대응표본에서는 매우 중요한 차이가 있다.

정규성을 확인할 때 핵심은

```text
Before 데이터의 정규성
After 데이터의 정규성
```

을 따로 보는 것보다

```text
Difference = After - Before
```

즉, **차이값의 분포**이다.

[ python : code ] "재활 전후 보행 속도 차이값의 정규성을 Shapiro-Wilk 검정으로 확인"

```python
from scipy import stats
import numpy as np

before = np.array([
    1.08, 1.12, 1.00, 1.15, 1.05,
    1.10, 1.03, 1.09, 1.07, 1.11
])

after = np.array([
    1.16, 1.18, 1.09, 1.22, 1.13,
    1.17, 1.11, 1.16, 1.15, 1.19
])

difference = after - before

result = stats.shapiro(difference)

print("차이값:", np.round(difference, 2))
print(f"Shapiro p-value: {result.pvalue:.3f}")
```

[ Result ]

```text
차이값: [0.08 0.06 0.09 0.07 0.08 0.07 0.08 0.07 0.08 0.08]
Shapiro p-value: 0.172
```

```text
0.172 > 0.05
```

이므로 이 표본에서는 차이값이 정규분포를 따르지 않는다고 판단할 충분한 근거가 없다.

<br>

> ## **5-4 ) 등분산성 Homogeneity of Variance**

등분산성은 독립된 두 집단의 분산이 비슷하다는 가정이다.

대표적으로 `Levene Test`를 사용할 수 있다.

```text
H₀ : 두 그룹의 분산이 같다.
H₁ : 두 그룹의 분산이 다르다.
```

일반적으로

```text
p-value > 0.05
→ 등분산성을 기각할 근거 부족

p-value ≤ 0.05
→ 등분산성을 가정하기 어려움
```

으로 해석할 수 있다.

<br>

> ## **5-5 ) 정규성과 등분산성 함께 확인**

[ python : code ] "두 스프린트 훈련 그룹의 정규성과 등분산성을 확인"

```python
from scipy import stats

group_a = [
    31.2, 30.8, 31.5, 30.9, 31.1,
    31.4, 30.7, 31.0, 31.3, 30.9
]

group_b = [
    32.0, 31.8, 32.2, 31.7, 32.1,
    31.9, 32.3, 31.6, 32.0, 31.8
]

shapiro_a = stats.shapiro(group_a)
shapiro_b = stats.shapiro(group_b)
levene = stats.levene(group_a, group_b)

print(f"A 그룹 Shapiro p-value: {shapiro_a.pvalue:.3f}")
print(f"B 그룹 Shapiro p-value: {shapiro_b.pvalue:.3f}")
print(f"Levene p-value: {levene.pvalue:.3f}")
```

[ Result ]

```text
A 그룹 Shapiro p-value: 0.828
B 그룹 Shapiro p-value: 0.953
Levene p-value: 0.484
```

### 결과 해석

정규성 검정 결과

```text
A 그룹: 0.828 > 0.05
B 그룹: 0.953 > 0.05
```

이므로 두 집단 모두 정규성을 위반한다고 볼 충분한 근거가 없다.

등분산성 검정 결과도

```text
0.484 > 0.05
```

이므로 두 집단의 분산이 다르다고 볼 충분한 근거가 없다.

따라서 이 예시 데이터에서는 Student's t-test를 고려할 수 있다.

다만 실무에서는 분산이 같은지 확신하기 어렵다면 Welch's t-test를 기본적으로 사용하는 선택도 가능하다.

# **6. t-검정별 가정 비교**

> ## **6-1 ) 검정마다 확인해야 하는 가정**

| 검정 | 독립성 | 정규성 | 등분산성 |
|---|---|---|---|
| 단일표본 t-검정 | 관측값 간 독립 | 표본 모집단의 정규성 고려 | 해당 없음 |
| Student 독립표본 t | 두 집단 및 관측값 독립 | 각 집단의 정규성 고려 | 필요 |
| Welch 독립표본 t | 두 집단 및 관측값 독립 | 각 집단의 정규성 고려 | 필요 없음 |
| 대응표본 t | 각 쌍이 다른 쌍과 독립 | **차이값의 정규성** | 해당 없음 |

특히 다음 두 가지를 기억하는 것이 중요하다.

```text
Welch's t-test
→ 등분산성을 요구하지 않음

Paired t-test
→ 차이값의 정규성이 중요
```

<br>

> ## **6-2 ) 가정이 만족되지 않으면 분석을 중단해야 하는가**

그렇지 않다.

가정이 적절하지 않을 경우 어떤 가정이 문제인지 확인하고 대안을 고려한다.

```text
독립 2집단
+
등분산성 문제
        ↓
Welch's t-test 고려
```

분포가 심하게 비정규적이고 표본도 작거나 극단적인 이상치가 존재한다면 연구 설계와 데이터 특성을 확인한 뒤 비모수 방법을 고려할 수 있다.

| 상황 | 고려 가능한 방법 |
|---|---|
| 독립된 두 집단의 비모수 비교 | Mann–Whitney U 검정 |
| 대응된 두 집단의 비모수 비교 | Wilcoxon signed-rank 검정 |

하지만

```text
Shapiro p < 0.05
→ 무조건 t-test 사용 금지
```

라고 기계적으로 판단하는 것은 적절하지 않다.

표본 크기, 이상치, 분포 형태, t-검정의 강건성 등을 함께 고려해야 한다.

# **8. t-검정 전체 실전 분석**

> ## **8-1 ) 두 훈련 프로그램 비교 전체 과정**

이번에는 두 스프린트 프로그램을 비교한다고 가정한다.

분석 과정은 단순히 `ttest_ind()`만 실행하는 것이 아니라 다음과 같이 진행할 수 있다.

[ python : code ] "두 독립 훈련 그룹의 가정을 확인하고 Welch t-검정까지 수행하는 전체 분석"

```python
import numpy as np
from scipy import stats

group_a = np.array([
    31.2, 30.8, 31.5, 30.9, 31.1,
    31.4, 30.7, 31.0, 31.3, 30.9
])

group_b = np.array([
    32.0, 31.8, 32.2, 31.7, 32.1,
    31.9, 32.3, 31.6, 32.0, 31.8
])

alpha = 0.05

# 1. 기술통계
print(f"A 평균: {group_a.mean():.2f}")
print(f"B 평균: {group_b.mean():.2f}")

# 2. 정규성 확인
shapiro_a = stats.shapiro(group_a)
shapiro_b = stats.shapiro(group_b)

# 3. 등분산성 확인
levene = stats.levene(group_a, group_b)

print(f"A 정규성 p-value: {shapiro_a.pvalue:.3f}")
print(f"B 정규성 p-value: {shapiro_b.pvalue:.3f}")
print(f"등분산성 p-value: {levene.pvalue:.3f}")

# 4. Welch's t-test
result = stats.ttest_ind(
    group_a,
    group_b,
    equal_var=False
)

print(f"t 통계량: {result.statistic:.3f}")
print(f"p-value: {result.pvalue:.8f}")

# 5. 결과 판단
if result.pvalue < alpha:
    print("귀무가설을 기각합니다.")
    print("두 훈련 그룹의 평균 최고속도가 다르다고 볼 통계적 근거가 있습니다.")
else:
    print("귀무가설을 기각할 근거가 부족합니다.")
```

[ Result ]

```text
A 평균: 31.08
B 평균: 31.94
A 정규성 p-value: 0.828
B 정규성 p-value: 0.953
등분산성 p-value: 0.484
t 통계량: -7.851
p-value: 0.00000040
귀무가설을 기각합니다.
두 훈련 그룹의 평균 최고속도가 다르다고 볼 통계적 근거가 있습니다.
```

### 코드 결과 해석

1. A 그룹의 평균 최고속도는 `31.08 km/h`이다.
2. B 그룹은 `31.94 km/h`로 A 그룹보다 높다.
3. 두 그룹의 Shapiro-Wilk p-value가 모두 `0.05`보다 크다.
4. Levene 검정 역시 `p = 0.484`로 등분산성을 위반한다고 볼 근거가 부족하다.
5. Welch's t-test에서 `p-value < 0.05`가 나타났다.
6. 따라서 두 훈련 그룹의 평균 최고속도가 다르다고 볼 통계적 근거가 있다.

### 전체 분석 흐름도

```text

                ↓

                ↓

                ↓

Shapiro-Wilk
                ↓
[등분산성 확인]
Levene Test
                ↓
[독립표본 t-test 선택]
                ↓
분산이 같다고 확신?
       /              \
     Yes             No/불확실
      ↓                  ↓
 Student              Welch
 t-test               t-test
       \                /
        ↓              ↓
```

# **9. t-검정 결과 해석 시 주의사항**

> ## **9-1 ) p-value만으로 효과의 크기를 알 수 없다**

`t-test`에서

```text
p-value < 0.05
```

가 나왔다고 해서 두 집단의 차이가 반드시 큰 것은 아니다.

p-value는 **통계적으로 차이가 있다고 볼 근거가 있는지** 알려주지만 효과가 얼마나 큰지는 직접 알려주지 않는다.

따라서 실제 분석에서는 필요에 따라

```text
평균 차이
Cohen's d
신뢰구간
```

등도 함께 확인한다.

<br>

> ## **9-2 ) 유의하지 않음은 동일하다는 뜻이 아니다**

```text
p-value > 0.05
```

라면

```text
X 두 평균이 완전히 같다.
```

가 아니라

```text
O 현재 표본에서는 평균 차이가 있다고 판단할
  충분한 통계적 근거가 없다.
```

라고 표현해야 한다.

<br>

> ## **9-3 ) 평균만 비교하지 말고 데이터의 분포를 확인한다**

다음 두 그룹이 있다고 하자.

```text
A 평균 = 30
B 평균 = 30
```

평균은 같지만 실제 데이터의 퍼짐이나 이상치 구조는 완전히 다를 수 있다.

따라서 t-검정 이전에

```text
평균
중앙값
표준편차
히스토그램
Box Plot
이상치
```

등을 함께 살펴보는 것이 좋다.

# **10. Advanced 추가 학습**

> ## **10-1 ) 신뢰구간**

t-검정 결과와 함께 평균 차이에 대한 **신뢰구간(Confidence Interval)**을 확인하면 차이가 어느 범위에 있을지 파악할 수 있다.

```text
p-value
→ 차이가 있다고 볼 근거가 있는가?

신뢰구간
→ 그 차이가 어느 정도 범위에 있는가?
```

둘을 함께 보는 것이 결과 해석에 더 유용하다.

<br>

> ## **10-2 ) 효과 크기 Cohen's d**

통계적으로 유의하더라도 실제 차이가 작을 수 있으므로 효과 크기를 함께 확인할 수 있다.

```text
독립표본 t-test
→ 두 그룹 평균 차이의 Cohen's d

대응표본 t-test
→ 차이값을 기반으로 한 효과 크기
```

즉, `p-value`와 효과 크기는 서로 다른 정보를 제공한다.

<br>

> ## **10-3 ) Welch 검정**

독립표본 평균 비교에서는 분산이 같다는 확신이 없을 경우 Welch 검정을 기본 선택으로 고려할 수 있다.

```python
stats.ttest_ind(
    group_a,
    group_b,
    equal_var=False
)
```

Welch 검정은 두 집단의 분산과 표본 크기가 다를 때도 사용할 수 있도록 자유도를 보정한다.

# **11. 핵심정리**

- **t-검정(t-test)**은 평균의 차이가 통계적으로 유의한지 확인하는 대표적인 가설검정 방법이다.
- t-검정에서는 평균 차이와 데이터 변동성을 이용해 **t 통계량**을 계산한다.
- t 통계량은 쉽게 말하면 **관찰된 평균 차이가 표준오차의 몇 배 정도 되는지** 나타낸다.
- `|t|`가 커질수록 귀무가설에서 예상되는 값과 표본 결과의 차이가 상대적으로 커진다.
- t-검정에서는 **t분포**를 이용하여 t 통계량에 대응하는 p-value를 계산한다.
- t분포는 정규분포와 비슷하지만 표본 추정의 불확실성을 반영하여 꼬리가 상대적으로 두껍다.
- 자유도 `df`는 t분포의 형태를 결정하며 단일표본 t-검정에서는 일반적으로 `n-1`이다.
- 하나의 표본 평균과 기준값을 비교할 때는 **단일표본 t-검정**을 사용한다.
- 단일표본 t-검정은 `stats.ttest_1samp()`로 수행할 수 있다.
- 서로 다른 두 집단의 평균을 비교할 때는 **독립표본 t-검정**을 사용한다.
- 독립표본 t-검정은 `stats.ttest_ind()`로 수행한다.
- `equal_var=True`는 등분산을 가정하는 **Student's t-test**이다.
- `equal_var=False`는 등분산을 가정하지 않는 **Welch's t-test**이다.
- 분산이 다른 경우나 등분산 여부가 확실하지 않은 경우 Welch t-검정을 고려할 수 있다.
- 같은 대상을 두 번 측정한 평균을 비교할 때는 **대응표본 t-검정**을 사용한다.
- 대응표본 t-검정은 `stats.ttest_rel()`을 사용한다.
- 대응표본 t-검정은 실제로 **각 쌍의 차이값 평균이 0인지 검정하는 방식**으로 이해할 수 있다.
- t-검정에서는 데이터 구조에 따라 **독립성, 정규성, 등분산성** 등의 가정을 확인한다.
- 독립성은 주로 데이터 수집 과정과 연구 설계를 통해 확인한다.
- 정규성은 Shapiro-Wilk 검정, 히스토그램, Q-Q Plot 등을 통해 확인할 수 있다.
- 대응표본 t-검정에서는 원본 두 집단 각각보다 **차이값의 정규성**이 중요하다.
- 등분산성은 독립표본 Student's t-test에서 중요한 가정이며 Levene 검정 등으로 확인할 수 있다.
- 가정이 만족되지 않는다고 해서 반드시 분석을 중단하는 것은 아니며 Welch 검정이나 상황에 맞는 비모수 방법 등을 검토할 수 있다.
- `p-value < α`이면 귀무가설을 기각하지만, 이것이 효과의 크기가 크다는 뜻은 아니다.
- `p-value ≥ α`라고 해서 두 평균이 동일하다고 증명되는 것도 아니다.
- 실제 분석에서는 p-value뿐 아니라 **평균 차이, 효과 크기, 신뢰구간, 데이터 분포** 등을 함께 확인하는 것이 좋다.

```text
[ t-검정 핵심 선택 흐름 ]

평균 차이를 검정한다
        ↓
비교 구조 확인
        ↓
┌──────────────────────────────────┐
│ 기준값 vs 하나의 표본           │
│ → One-sample t-test              │
│ → ttest_1samp()                  │
├──────────────────────────────────┤
│ 서로 다른 두 그룹               │
│ → Independent t-test             │
│ → ttest_ind()                    │
│ → Student 또는 Welch             │
├──────────────────────────────────┤
│ 같은 대상의 두 측정             │
│ → Paired t-test                  │
│ → ttest_rel()                    │
└──────────────────────────────────┘
        ↓
독립성 확인
        ↓
정규성 확인
        ↓
필요한 경우 등분산성 확인
        ↓
t 통계량 + p-value
        ↓
p-value와 α 비교
        ↓
통계적 결론
        ↓
효과크기 + 신뢰구간까지 해석
```
