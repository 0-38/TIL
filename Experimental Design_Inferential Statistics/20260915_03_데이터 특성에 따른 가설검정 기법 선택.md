# **1. 분석 목적과 데이터 특성 확인**

가설검정에서는 **검정 방법의 이름을 먼저 정하는 것이 아니라, 무엇을 분석하려는지와 데이터가 어떤 구조인지 먼저 확인해야 한다.**

같은 숫자형 데이터를 분석하더라도 서로 다른 두 집단을 비교하는지, 같은 대상을 전후로 비교하는지에 따라 사용할 검정이 달라진다.

```text
무엇을 확인하려는가?
        ↓
차이를 확인하는가?
관계를 확인하는가?
        ↓
데이터 유형은?
        ↓
그룹은 몇 개인가?
        ↓
독립된 데이터인가?
대응된 데이터인가?
        ↓
검정 가정 확인
        ↓
적절한 검정 방법 선택
```

<br>

> ## **1-1 ) 먼저 확인해야 하는 4가지**

| 확인 항목 | 의미 | 스포츠 예시 |
|---|---|---|
| 분석 목적 | 차이 또는 관계 중 무엇을 확인하는가 | 두 훈련법의 평균 기록 차이 |
| 데이터 유형 | 연속형인지 범주형인지 | 기록시간은 연속형, 포지션은 범주형 |
| 그룹 수 | 비교 대상이 몇 그룹인가 | 2개 훈련 그룹, 3개 포지션 그룹 |
| 데이터 관계 | 독립된 대상인지 같은 대상의 반복측정인지 | 서로 다른 선수 vs 동일 선수 전후 |

예를 들어 다음 질문들은 모두 가설검정을 사용할 수 있지만 데이터 구조가 서로 다르다.

```text
질문 1
훈련 A 선수와 훈련 B 선수의 평균 스프린트 속도가 다른가?
→ 연속형 + 서로 다른 두 그룹

질문 2
같은 선수의 훈련 전후 점프 높이가 다른가?
→ 연속형 + 동일 대상의 전후 측정

질문 3
축구·농구·배구 선수의 평균 점프 높이가 다른가?
→ 연속형 + 세 그룹 이상

질문 4
선수 포지션과 부상 발생 여부에 관계가 있는가?
→ 범주형 + 범주형

질문 5
훈련 부하와 심박수는 함께 증가하는가?
→ 연속형 + 연속형
```

<br>

> ## **1-2 ) 연속형 데이터와 범주형 데이터**

검정법을 선택할 때 데이터 유형을 구분하는 것이 중요하다.

| 데이터 유형 | 의미 | 스포츠 예시 |
|---|---|---|
| 연속형 | 수치로 측정되는 값 | 체중, 점프 높이, 속도, 심박수 |
| 범주형 | 특정 범주로 구분되는 값 | 포지션, 성별, 부상 여부, 팀 |
| 순서형 | 순서가 있는 범주 | 통증 등급, 운동 강도 단계 |

예를 들어

```text
스프린트 속도
→ 31.2 km/h
→ 연속형

부상 여부
→ 부상 / 비부상
→ 범주형
```

이다.

<br>

> ## **1-3 ) 독립된 데이터와 대응된 데이터**

두 집단을 비교한다고 해서 항상 같은 t-검정을 사용하는 것은 아니다.

### 독립된 데이터

서로 다른 사람이나 대상을 비교하는 경우이다.

```text
A 훈련 프로그램 선수 20명

vs

B 훈련 프로그램 선수 20명
```

각 그룹의 선수가 서로 다르므로 **독립된 두 집단**이다.

### 대응된 데이터

같은 대상을 두 번 측정하거나 서로 짝을 이루는 데이터이다.

```text
선수 A
훈련 전 → 훈련 후

선수 B
훈련 전 → 훈련 후

선수 C
훈련 전 → 훈련 후
```

같은 선수를 반복 측정했으므로 **대응된 데이터**이다.

| 구분 | 독립 데이터 | 대응 데이터 |
|---|---|---|
| 대상 | 서로 다른 대상 | 같은 대상 |
| 예시 | 남자 선수 vs 여자 선수 | 동일 선수 훈련 전후 |
| 관측값 관계 | 서로 독립 | 서로 연결됨 |
| 대표 검정 | 독립표본 t-검정 | 대응표본 t-검정 |

# **2. 검정 방법의 가정 확인**

통계적 검정은 데이터를 분석할 때 몇 가지 조건을 전제로 한다.

이러한 조건을 **검정의 가정(Assumption)** 이라고 한다.

평균을 비교하는 t-검정과 ANOVA에서는 대표적으로 다음을 확인한다.

```text
정규성
등분산성
독립성
```

검정의 가정이 만족되지 않는다고 해서 항상 분석을 중단해야 하는 것은 아니다.

어떤 가정이 문제가 되는지 확인한 뒤 **다른 설정이나 다른 검정 방법을 선택할 수 있다.**

<br>

> ## **2-1 ) 정규성 Normality**

정규성은 데이터가 정규분포에서 심하게 벗어나지 않는지를 확인하는 것이다. - 평균을 중심으로 많이 벗어나는가?

```text
        *
      * * *
    * * * * *
  * * * * * * *
-------------------
        평균
```

반대로 이상치가 많거나 한쪽으로 크게 치우친 경우에는 정규성 가정을 의심할 수 있다.

```text
* * * * * *
          *
             *
                    *
```

정규성은 히스토그램, Q-Q Plot 등을 통해 시각적으로 확인할 수도 있고 `Shapiro-Wilk Test`와 같은 방법을 사용할 수도 있다.

<br>

> ## **2-2 ) Shapiro-Wilk 검정**

Shapiro-Wilk 검정의 가설은 다음과 같다.

```text
H₀ : 데이터가 정규분포를 따른다.
H₁ : 데이터가 정규분포를 따르지 않는다.
```

따라서 일반적으로

```text
p-value > 0.05
→ 정규성을 기각할 근거가 부족

p-value ≤ 0.05
→ 정규성 가정을 의심
```

으로 해석한다.

단, 정규성 검정의 p-value만 기계적으로 판단하기보다 **표본 크기, Q-Q Plot, 이상치 등도 함께 확인하는 것이 좋다.**

<br>

> ## **2-3 ) 등분산성 Homogeneity of Variance**

등분산성은 비교하는 그룹의 **분산이 비슷한가**를 확인하는 가정이다.

예를 들어

```text
A 선수 그룹
28 29 30 30 31 32

B 선수 그룹
27 28 30 31 32 33
```

처럼 퍼짐이 비슷하다면 등분산성을 가정하기 쉽다.

반면

```text
A 그룹
29 30 30 30 31

B 그룹
20 24 30 37 45
```

처럼 한 그룹의 변동이 훨씬 크다면 등분산성을 의심할 수 있다.

<br>

> ## **2-4 ) Levene 검정**

두 집단 이상의 분산이 같은지 확인하는 대표적인 방법 중 하나가 `Levene Test`이다.

가설은 다음과 같다.

```text
H₀ : 그룹들의 분산이 같다.
H₁ : 그룹들의 분산이 다르다.
```

일반적으로

```text
p-value > 0.05
→ 등분산성을 기각할 근거가 부족

p-value ≤ 0.05
→ 등분산성을 가정하기 어려움
```

으로 해석할 수 있다.

<br>

> ## **2-5 ) 정규성과 등분산성 확인 예제**

훈련 A와 훈련 B 선수들의 최고 스프린트 속도를 비교한다고 하자.

[ python : code ] "독립표본 t-검정 전에 정규성과 등분산성을 확인하는 방법"

```python
import numpy as np
from scipy import stats

group_a = np.array([
    31.2, 30.8, 31.5, 30.9, 31.1,
    31.4, 30.7, 31.0, 31.3, 30.9
])

group_b = np.array([
    32.0, 31.8, 32.2, 31.7, 32.1,
    31.9, 32.3, 31.6, 32.0, 31.8
])

# 정규성 검정
shapiro_a = stats.shapiro(group_a)
shapiro_b = stats.shapiro(group_b)

# 등분산성 검정
levene = stats.levene(group_a, group_b)

print(f"A 그룹 Shapiro p-value: {shapiro_a.pvalue:.3f}")
print(f"B 그룹 Shapiro p-value: {shapiro_b.pvalue:.3f}")
print(f"Levene p-value: {levene.pvalue:.3f}")
```

정규성과 등분산성 가정에 대한 가설은 다음과 같다.

```
정규성 가설
- 귀무가설 : 두 그룹의 평균은 동일할 것이다.
- 대립가설 : 두 그룹의 평균은 동일하지 않을 것이다.

등분산성 가설
- 귀무가설 : 두 그룹의 분산은 동일할 것이다.
- 대립가설 : 두 그룹의 분산은 동일하지 않을 것이다.
```

[ Result ]

```text
A 그룹 Shapiro p-value: 0.828
B 그룹 Shapiro p-value: 0.953
Levene p-value: 0.484
```

### 결과 해석

정규성에 대한 결과는 다음과 같다.
```text
A 그룹
0.828 > 0.05

B 그룹
0.953 > 0.05
```

두 그룹 모두 정규성을 기각할 근거가 부족하다.

또한

등분산성 가정에 대한 결과는 다음과 같다.

```text
Levene p-value = 0.484 > 0.05
```

이므로 두 그룹의 분산이 다르다고 볼 통계적 근거도 부족하다.

따라서 이 예제에서는 독립표본 t-검정을 고려할 수 있다.

<br>

> ## **2-6 ) 등분산성이 만족되지 않으면 Welch's t-test**

두 집단의 분산이 크게 다르다고 해서 평균 비교 자체를 포기해야 하는 것은 아니다.

독립표본 t-검정에서는 **Welch's t-test**를 사용할 수 있다.

SciPy에서는 다음처럼 설정한다.

```python
stats.ttest_ind(
    group_a,
    group_b,
    equal_var=False
)
```

`equal_var=False`가 핵심이다.

[ python : code ] "두 그룹의 분산이 다를 때 Welch's t-검정을 사용하는 방법"

```python
import numpy as np
from scipy import stats

group_a = np.array([
    10.1, 10.4, 9.9, 10.2, 10.3,
    10.0, 10.2, 10.1, 10.4, 9.8
])

group_b = np.array([
    8.0, 9.5, 11.2, 7.4, 12.6,
    10.8, 6.9, 13.1, 9.0, 11.7
])

levene = stats.levene(group_a, group_b)

result = stats.ttest_ind(
    group_a,
    group_b,
    equal_var=False
)

print(f"Levene p-value: {levene.pvalue:.6f}")
print(f"Welch t-statistic: {result.statistic:.3f}")
print(f"Welch p-value: {result.pvalue:.3f}")
```

[ Result ]

```text
Levene p-value: 0.000033
Welch t-statistic: 0.173
Welch p-value: 0.866
```

### 결과 해석

```text
Levene p-value < 0.05
```

이므로 두 그룹의 등분산성을 가정하기 어렵다.

따라서 등분산을 가정하는 일반적인 Student's t-test보다

```python
equal_var=False
```

를 사용하는 **Welch's t-test**를 고려할 수 있다.

Welch 검정의 결과는

```text
p-value = 0.866 > 0.05
```

이므로 이 예제에서는 두 그룹 평균이 다르다고 볼 충분한 통계적 근거가 없다.

# **3. 데이터 특성에 따른 검정 방법 선택**

검정 방법을 선택할 때는 다음 순서로 접근할 수 있다.

```text
무엇을 분석하는가?
        ↓
┌──────────────────┐
│                  │
차이 확인        관계 확인
│                  │
↓                  ↓
연속형?          데이터 유형?
│                  │
↓                  ↓
그룹 수?      범주형/연속형
│
↓
독립 / 대응?
│
↓
검정 가정 확인
│
↓
검정법 결정
```

<br>

> ## **3-1 ) 대표적인 검정 방법 비교**

| 분석 목적 | 데이터 구조 | 대표적인 검정 |
|---|---|---|
| 한 집단 평균과 기준값 비교 | 연속형 · 한 집단 | 단일표본 t-검정 |
| 두 독립집단 평균 비교 | 연속형 · 독립 2그룹 | 독립표본 t-검정 |
| 동일 대상 전후 평균 비교 | 연속형 · 대응 2그룹 | 대응표본 t-검정 |
| 세 집단 이상 평균 비교 | 연속형 · 독립 3그룹 이상 | 일원분산분석 ANOVA |
| 두 범주형 변수 관계 | 범주형 + 범주형 | 카이제곱 독립성 검정 |
| 두 연속형 변수 관계 | 연속형 + 연속형 | Pearson 상관분석 |

<br>

> ## **3-2 ) 독립표본 t-검정**

서로 다른 두 집단의 평균을 비교할 때 사용한다.

### 스포츠 예시

```text
질문
훈련 A와 훈련 B 선수들의
평균 최고속도가 다른가?

최고속도
→ 연속형

훈련 A / 훈련 B
→ 두 그룹

서로 다른 선수
→ 독립집단

대표 검정
→ 독립표본 t-검정
```

[ python : code ] "두 훈련 그룹 선수의 평균 최고속도를 독립표본 t-검정으로 비교"

```python
from scipy import stats

group_a = [
    31.2, 30.8, 31.5, 30.9, 31.1,
    31.4, 30.7, 31.0, 31.3, 30.9
]

group_b = [
    32.0, 31.8, 32.2, 31.7, 32.1,
    31.9, 32.3, 31.6, 32.0, 31.8
]

result = stats.ttest_ind(
    group_a,
    group_b,
    equal_var=True
)

print(f"t-statistic: {result.statistic:.3f}")
print(f"p-value: {result.pvalue:.8f}")
```

[ Result ]

```text
t-statistic: -7.851
p-value: 0.00000032
```

`p-value < 0.05`이므로 이 예제에서는 두 훈련 그룹의 평균 최고속도가 다르다고 볼 통계적 근거가 있다.

<br>

> ## **3-3 ) 대응표본 t-검정**

**같은 대상의 전후 데이터를 비교할 때** 사용한다.

예를 들어 동일한 선수들의 운동 프로그램 적용 전후 걸음 수를 비교하는 경우이다.

```text
선수 1 : 전 ↔ 후
선수 2 : 전 ↔ 후
선수 3 : 전 ↔ 후
```

각 관측값이 서로 짝을 이루기 때문에 독립표본 t-검정을 사용하지 않는다.

[ python : code ] "같은 참가자의 운동 프로그램 전후 걸음 수를 대응표본 t-검정으로 비교"

```python
from scipy import stats
import numpy as np

before = np.array([
    7800, 8200, 7600, 8400, 7900,
    8100, 7700, 8000, 8300, 7500
])

after = np.array([
    8300, 8900, 8200, 9200, 8300,
    8750, 8250, 8750, 8750, 8100
])

result = stats.ttest_rel(
    before,
    after
)

print(f"운동 전 평균: {before.mean():.0f}보")
print(f"운동 후 평균: {after.mean():.0f}보")
print(f"t-statistic: {result.statistic:.3f}")
print(f"p-value: {result.pvalue:.8f}")
```

[ Result ]

```text
운동 전 평균: 7950보
운동 후 평균: 8550보
t-statistic: -14.697
p-value: 0.00000013
```

`p-value < 0.05`이므로 프로그램 전후의 평균 걸음 수가 다르다고 볼 통계적 근거가 있다.

### 중요한 점

대응표본 t-검정에서 정규성 가정은 일반적으로 **전 데이터와 후 데이터를 각각 보는 것이 아니라 두 측정값의 차이값**에 대해 생각한다.

```python
difference = after - before
```

즉,

```text
훈련 전 분포 정규성
+
훈련 후 분포 정규성
```

만 보는 것이 아니라

```text
훈련 후 - 훈련 전

차이값의 분포
```

가 중요하다.

<br>

> ## **3-4 ) ANOVA**

세 개 이상의 독립된 그룹 평균을 비교할 때 대표적으로 **ANOVA(Analysis of Variance)** 를 사용할 수 있다.

예를 들어 세 가지 운동처방 프로그램의 평균 체력점수를 비교한다고 하자.

```text
프로그램 A
프로그램 B
프로그램 C

→ 독립된 세 그룹
→ 평균 비교
→ ANOVA
```

[ python : code ] "세 가지 운동 프로그램의 평균 체력점수를 ANOVA로 비교"

```python
from scipy import stats

program_a = [70, 72, 68, 71, 69, 73, 70, 72]
program_b = [74, 75, 73, 76, 72, 74, 75, 77]
program_c = [78, 80, 77, 79, 81, 78, 82, 80]

result = stats.f_oneway(
    program_a,
    program_b,
    program_c
)

print(f"F-statistic: {result.statistic:.3f}")
print(f"p-value: {result.pvalue:.10f}")
```

[ Result ]

```text
F-statistic: 55.924
p-value: 0.0000000039
```

`p-value < 0.05`이므로

```text
H₀
세 그룹의 평균이 모두 같다.
```

라는 가설을 기각할 수 있다.

하지만 ANOVA 결과만으로

```text
A와 B가 다르다.
A와 C가 다르다.
B와 C가 다르다.
```

라고 각각 단정할 수는 없다.

ANOVA가 알려주는 것은

```text
"적어도 하나의 그룹 평균은 다르다."
```

라는 것이다.

어떤 그룹끼리 차이가 있는지는 이후 **사후검정(Post-hoc Test)** 을 통해 확인할 수 있다.

<br>

> ## **3-5 ) 카이제곱 독립성 검정**

두 범주형 변수 사이에 관계가 있는지 확인할 때 사용할 수 있다.

예를 들어

```text
선수 포지션
→ 공격수 / 미드필더 / 수비수

부상 여부
→ 부상 / 비부상
```

는 모두 범주형 데이터이다.

[ python : code ] "축구 선수의 포지션과 부상 여부가 서로 관련되어 있는지 카이제곱 검정"

```python
import numpy as np
from scipy import stats

# 행: 공격수, 미드필더, 수비수
# 열: 부상, 비부상

table = np.array([
    [18, 12],
    [10, 20],
    [6, 24]
])

chi2, p_value, dof, expected = stats.chi2_contingency(table)

print(f"chi-square: {chi2:.3f}")
print(f"p-value: {p_value:.4f}")
print(f"자유도: {dof}")
```

[ Result ]

```text
chi-square: 10.588
p-value: 0.0050
자유도: 2
```

`p-value < 0.05`이므로 이 예제에서는 **선수 포지션과 부상 여부가 서로 독립이라고 보기 어렵고, 두 변수 사이에 관계가 있다고 볼 통계적 근거가 있다.**

카이제곱 검정에서는 관측값들이 독립적인지와 함께 **기대빈도(Expected Frequency)** 가 지나치게 작은 셀이 많지 않은지도 확인하는 것이 중요하다.

<br>

> ## **3-6 ) Pearson 상관계수**

두 연속형 변수 사이의 **선형 관계**를 확인할 때 Pearson 상관계수를 사용할 수 있다.

예를 들어 러닝머신의 운동 부하와 심박수의 관계를 분석한다고 하자.

[ python : code ] "운동 부하와 심박수 사이의 선형 상관관계 확인"

```python
from scipy import stats

training_load = [
    5, 6, 7, 8, 9, 10, 11, 12
]

heart_rate = [
    118, 124, 129, 136,
    142, 149, 155, 162
]

r, p_value = stats.pearsonr(
    training_load,
    heart_rate
)

print(f"Pearson r: {r:.3f}")
print(f"p-value: {p_value:.10f}")
```

[ Result ]

```text
Pearson r: 0.999
p-value: 0.0000000007
```

`r`이 `+1`에 가까울수록 강한 양의 선형관계를 의미한다.

이 예제에서는

```text
r ≈ 0.999
```

이므로 운동 부하가 증가할수록 심박수도 증가하는 매우 강한 양의 선형관계가 나타났다.

하지만 중요한 점은

```text
상관관계 ≠ 인과관계
```

라는 것이다.

두 변수가 함께 변한다고 해서 반드시 한 변수가 다른 변수의 원인이라고 결론 내릴 수는 없다.

# **4. 검정 방법별 가정 비교**

> ## **4-1 ) 대표 검정의 주요 확인사항**

| 검정 | 데이터 구조 | 주요 확인사항 |
|---|---|---|
| 단일표본 t-검정 | 연속형 1집단 | 독립성, 정규성 |
| 독립표본 t-검정 | 연속형 독립 2집단 | 독립성, 정규성, 등분산성 |
| Welch t-검정 | 연속형 독립 2집단 | 독립성, 정규성, 등분산 가정 불필요 |
| 대응표본 t-검정 | 연속형 대응 2집단 | 쌍의 독립성, **차이값의 정규성** |
| ANOVA | 연속형 독립 3집단 이상 | 독립성, 정규성, 등분산성 |
| 카이제곱 독립성 검정 | 범주형 + 범주형 | 관측값 독립성, 기대빈도 |
| Pearson 상관분석 | 연속형 + 연속형 | 선형성, 심각한 이상치 여부 등 |

검정의 가정은 검정마다 조금씩 다르기 때문에

```text
"정규성만 통과하면 모든 검정을 사용할 수 있다."
```

라고 생각하면 안 된다.

<br>

> ## **4-2 ) 독립성이 특히 중요한 이유**

독립성은 동일한 데이터가 여러 번 중복되어 들어가거나 서로 연결된 데이터를 독립된 것처럼 처리하지 않는 것을 의미한다.

예를 들어 동일 선수의 전후 데이터를

```text
훈련 전 그룹
vs
훈련 후 그룹
```

으로 나누어 독립표본 t-검정을 하면 같은 사람이라는 관계를 무시하게 된다.

따라서

```text
같은 선수의 전후 비교
→ 대응표본 t-검정
```

을 사용해야 한다.

<br>

> ## **4-3 ) 이상치도 함께 확인**

다음과 같은 데이터가 있다고 하자.

```text
10, 11, 12, 10, 11, 12, 11, 80
```

`80`과 같은 극단적인 값은 평균과 표준편차에 큰 영향을 줄 수 있다.

따라서 검정 전에 다음도 확인하는 것이 좋다.

```text
히스토그램
Box Plot
Q-Q Plot
기술통계량
이상치
```

통계검정의 선택은 단순히 p-value 하나로 결정하기보다 **데이터의 실제 모습을 함께 확인하면서 판단해야 한다.**

# **7. 가정이 맞지 않을 때의 대응**

> ## **7-1 ) 등분산성이 만족되지 않는 경우**

```text
독립된 두 그룹
+
분산 차이가 큼
```

이라면

```text
일반 독립표본 t-test
          ↓
Welch's t-test 검토
```

할 수 있다.

즉, 가정 하나가 만족되지 않는다고 분석 전체를 포기할 필요는 없다.

<br>

> ## **7-2 ) 정규성 가정이 어려운 경우**

데이터가 매우 치우쳐 있거나 이상치가 많고 표본 크기도 작다면 정규성 가정을 적용하기 어려울 수 있다.

이 경우에는 데이터 특성과 연구 목적에 따라 **비모수검정**을 고려할 수 있다.

대표적인 대응 관계는 다음과 같다.

| 모수 검정 | 고려 가능한 비모수 대안 |
|---|---|
| 독립표본 t-검정 | Mann–Whitney U 검정 |
| 대응표본 t-검정 | Wilcoxon signed-rank 검정 |
| 일원 ANOVA | Kruskal–Wallis 검정 |
| Pearson 상관 | Spearman 순위상관 |

비모수검정이 항상 더 좋은 방법이라는 뜻은 아니다.

```text
가정이 조금 깨짐
→ 무조건 비모수검정
```

이 아니라

```text
데이터 구조
표본 크기
이상치
분포 형태
연구 질문
```

을 함께 고려해야 한다.

# **8. Advanced 추가 학습**

> ## **8-1 ) ANOVA 이후 사후검정**

ANOVA에서 유의한 결과가 나왔다고 해도 어느 그룹 사이에 차이가 있는지는 바로 알 수 없다.

```text
ANOVA
→ 적어도 한 그룹은 다름
```

이후 필요하면 `Tukey HSD`와 같은 **사후검정(Post-hoc Test)** 을 수행하여 구체적인 그룹 차이를 확인한다.

<br>

> ## **8-2 ) 작은 기대빈도와 Fisher's Exact Test**

카이제곱 검정에서는 일부 셀의 기대빈도가 너무 작으면 카이제곱 근사가 적절하지 않을 수 있다.

특히 작은 `2 × 2` 분할표에서는 상황에 따라 **Fisher's Exact Test**를 고려할 수 있다.

<br>

> ## **8-3 ) 정규성 검정만 믿지 않기**

표본이 매우 크면 Shapiro-Wilk와 같은 정규성 검정에서 작은 분포 차이도 유의하게 나타날 수 있다.

반대로 표본이 매우 작으면 실제 비정규성을 발견할 힘이 부족할 수 있다.

따라서

```text
정규성 검정 p-value
+
```

# **9. 핵심정리**

- 가설검정 방법은 **분석 목적과 데이터 특성을 먼저 확인한 뒤 선택**해야 한다.
- 검정법의 이름을 먼저 선택하고 데이터를 끼워 맞추면 안 된다.
- 검정 선택 시 **분석 목적, 데이터 유형, 그룹 수, 독립/대응 여부**를 먼저 확인한다.
- 연속형 데이터에는 속도, 심박수, 점프 높이, 기록시간 등이 있다.
- 범주형 데이터에는 포지션, 팀, 부상 여부 등이 있다.
- 서로 다른 대상을 비교하면 **독립 데이터**, 동일 대상을 반복 측정하면 **대응 데이터**이다.
- 통계적 검정에는 각각 적용을 위해 확인해야 하는 **가정(Assumption)**이 존재한다.
- 정규성은 데이터 또는 검정에 필요한 값의 분포가 정규분포에서 크게 벗어나지 않는지를 확인하는 개념이다.
- Shapiro-Wilk 검정에서 일반적으로 `p > 0.05`이면 정규성을 기각할 근거가 부족하다고 해석한다.
- 등분산성은 여러 그룹의 분산이 비슷한지를 나타낸다.
- Levene 검정에서 일반적으로 `p > 0.05`이면 등분산성을 기각할 근거가 부족하다.
- 등분산성이 만족되지 않는 독립된 두 집단의 평균 비교에서는 **Welch's t-test**를 고려할 수 있다.
- 독립된 두 그룹의 연속형 평균 비교에는 **독립표본 t-검정**을 사용할 수 있다.
- 같은 대상의 전후 평균 비교에는 **대응표본 t-검정**을 사용할 수 있다.
- 대응표본 t-검정에서는 일반적으로 각 시점의 분포보다 **두 측정값의 차이값에 대한 정규성**이 중요하다.
- 서로 다른 세 그룹 이상의 평균 비교에는 **ANOVA**를 사용할 수 있다.
- ANOVA가 유의하더라도 어떤 그룹끼리 다른지는 알 수 없으므로 필요하면 사후검정을 수행한다.
- 두 범주형 변수 사이의 관계는 **카이제곱 독립성 검정**으로 분석할 수 있다.
- 두 연속형 변수 사이의 선형 관계는 **Pearson 상관계수**로 분석할 수 있다.
- Pearson 상관관계가 있다고 해서 인과관계가 증명되는 것은 아니다.
- 검정 가정이 적절하지 않다고 해서 반드시 분석을 중단하는 것은 아니다.
- 분산 가정에 문제가 있다면 Welch 검정, 분포 가정이 어려운 경우 상황에 따라 비모수검정을 고려할 수 있다.
- 검정 선택은 p-value를 작게 만들기 위한 과정이 아니라 **연구 질문과 데이터 구조에 적합한 분석 방법을 선택하는 과정**이다.

```text
[ 검정법 선택 핵심 흐름 ]

연구 질문
    ↓
차이인가? 관계인가?
    ↓
데이터 유형 확인
    ↓
연속형 / 범주형
    ↓
그룹 수 확인
    ↓
1 / 2 / 3개 이상
    ↓
독립 / 대응 확인
    ↓
데이터 탐색
    ↓
정규성 · 등분산성 · 이상치 확인
    ↓
적절한 검정 선택
    ↓
┌─────────────────────────────┐
│ 독립표본 t-test             │
│ Welch t-test                │
│ 대응표본 t-test             │
│ ANOVA                       │
│ Chi-square                  │
│ Pearson correlation         │
└─────────────────────────────┘
    ↓
가설검정 수행
    ↓
p-value + 효과크기 + 신뢰구간
    ↓
분석 목적에 맞게 최종 해석
```
