# **1. 검정력(Power)의 개념**

가설검정에서는 `p-value`와 유의수준 `α`만 확인해서는 충분하지 않다.

실제로 차이가 존재하더라도 **표본이 너무 적거나 데이터의 변동이 크면 그 차이를 발견하지 못할 수 있기 때문**이다.

이때 실제로 존재하는 차이를 발견할 가능성을 나타내는 개념이 **검정력(Power)** 이다.

```text
제2종 오류 β
→ 실제 차이가 있는데 차이를 발견하지 못할 확률

검정력 Power
→ 실제 차이가 있을 때 차이를 발견할 확률
```

두 값의 관계는 다음과 같다.

```text
Power = 1 - β
```

예를 들어

```text
β = 0.20
```

이라면

```text
Power = 1 - 0.20
      = 0.80
```

이므로 검정력은 `80%`이다.

즉, 실제로 효과가 존재하는 상황을 반복해서 실험한다고 생각했을 때 **약 80%의 확률로 그 효과를 통계적으로 발견할 수 있도록 설계한 것**으로 이해할 수 있다.

실험 설계에서는 관례적으로 `Power = 0.80` 이상을 목표로 설정하는 경우가 많지만, 연구 목적과 비용에 따라 달라질 수 있다.

<br>

> ## **1-1 ) 제2종 오류와 검정력**

지난 두 가지 오류를 다시 연결하면 다음과 같다.

| 실제 상황 / 판단 | H₀ 기각 | H₀ 기각하지 못함 |
|---|---|---|
| 실제 H₀ 참 | 제1종 오류 `α` | 올바른 판단 |
| 실제 H₀ 거짓 | **올바른 판단 = 검정력 `1-β`** | **제2종 오류 `β`** |

예를 들어 새로운 근력 훈련 프로그램이 실제로 점프 높이를 향상시키는데 실험에서 효과를 발견하지 못했다면 **제2종 오류**가 발생한 것이다.

```text
실제 효과 있음
      ↓
검정 결과 효과를 발견하지 못함
      ↓
제2종 오류 β
```

반대로

```text
실제 효과 있음
      ↓
검정에서 효과 발견
      ↓
검정력 Power
```

이다.

<br>

> ## **1-2 ) 검정력에 영향을 주는 요인**

검정력은 하나의 요소로 결정되지 않는다.

대표적으로 다음 네 가지가 중요하다.

| 요인 | 커질 때 일반적인 검정력 변화 | 이유 |
|---|---|---|
| 효과 크기 | 증가 ↑ | 차이가 클수록 발견하기 쉬움 |
| 표본 크기 `n` | 증가 ↑ | 평균 추정이 안정적이고 표준오차가 작아짐 |
| 유의수준 `α` | 증가 ↑ | H₀를 기각하기 쉬워짐 |
| 데이터 변동성 | 감소 ↓ | 데이터가 많이 퍼질수록 차이를 구분하기 어려움 |

핵심 관계는 다음과 같다.

```text
 1. 효과 크기 ↑             2.   표본 크기 ↑       
      ↓                          ↓   
    Power ↑                    Power ↑

    
 3.   α ↑                 4.    분산 ↑
       ↓                         ↓
  H₀ 기각 기준 완화             신호와 잡음 구분 어려움
       ↓                         ↓
    Power ↑                    Power ↓                                       
```

<br>

> ## **1-3 ) 표본 크기에 따른 검정력 비교**

축구 선수에게 두 가지 근력 훈련 프로그램을 적용하고 평균 점프 높이를 비교한다고 하자.

예상 효과 크기는 `0.5`, 유의수준은 `0.05`로 동일하게 두고 그룹당 선수 수만 변경한다.

[ python : code ] "축구 근력훈련 실험에서 표본 크기에 따른 검정력 비교"

```python
from statsmodels.stats.power import TTestIndPower

analysis = TTestIndPower()

power_20 = analysis.power(
    effect_size=0.5,
    nobs1=20,
    alpha=0.05
)

power_100 = analysis.power(
    effect_size=0.5,
    nobs1=100,
    alpha=0.05
)

print(f"그룹당 20명일 때 검정력: {power_20:.3f}")
print(f"그룹당 100명일 때 검정력: {power_100:.3f}")
```

[ Result ]

```text
그룹당 20명일 때 검정력: 0.338
그룹당 100명일 때 검정력: 0.940
```

### 결과 해석

| 그룹당 표본 수 | 검정력 | 해석 |
|---:|---:|---|
| 20명 | 0.338 | 실제 효과를 발견할 가능성이 낮음 |
| 100명 | 0.940 | 실제 효과를 발견할 가능성이 높음 |

다른 조건이 같을 때 표본 크기가 `20명 → 100명`으로 증가하면서 검정력이 약 `0.338 → 0.940`으로 증가했다.

즉, **표본이 너무 작으면 실제 효과가 있어도 이를 발견하지 못할 가능성이 크다.**

<br>

> ## **1-4 ) 효과 크기에 따른 검정력 비교**

이번에는 그룹당 표본 크기를 `50명`, 유의수준을 `0.05`로 고정하고 효과 크기만 변경한다.

[ python : code ] "효과 크기에 따라 스포츠 훈련 실험의 검정력이 어떻게 달라지는지 비교"

```python
from statsmodels.stats.power import TTestIndPower

analysis = TTestIndPower()

power_small = analysis.power(
    effect_size=0.2,
    nobs1=50,
    alpha=0.05
)

power_large = analysis.power(
    effect_size=0.6,
    nobs1=50,
    alpha=0.05
)

print(f"효과 크기 0.2일 때 검정력: {power_small:.3f}")
print(f"효과 크기 0.6일 때 검정력: {power_large:.3f}")
```

[ Result ]

```text
효과 크기 0.2일 때 검정력: 0.168
효과 크기 0.6일 때 검정력: 0.844
```

효과 크기가 작으면 두 집단의 차이를 구분하기 어렵기 때문에 많은 표본이 필요하다.

```text
작은 효과
→ 발견하기 어려움
→ 낮은 Power

큰 효과
→ 발견하기 쉬움
→ 높은 Power
```

# **2. 유의수준·검정력·표본 크기의 관계**

> ## **2-1 ) 세 요소는 서로 독립적이지 않다**

실험 설계에서 다음 요소들은 서로 연결되어 있다.

```text
유의수준 α
검정력 Power
효과 크기 Effect Size
표본 크기 n
```

예를 들어 동일한 효과를 검정한다고 가정하면

```text
더 높은 검정력 필요
→ 더 많은 표본 필요
```

```text
더 작은 효과까지 발견하고 싶음
→ 더 많은 표본 필요
```

```text
α를 더 엄격하게 설정
예: 0.05 → 0.01
→ H₀ 기각이 어려워짐
→ 같은 Power를 유지하려면 더 많은 표본 필요
```

따라서 표본 크기를 단순히

```text
"100명 정도면 충분하겠지."
```

라고 임의로 결정하기보다 **실험 목적을 기준으로 사전에 계산하는 것**이 좋다.

<br>

> ## **2-2 ) 필요한 표본 크기 계산**

두 운동처방 프로그램의 평균 효과를 비교한다고 하자.

다음 조건을 목표로 설정한다.

```text
효과 크기 = 0.5
α = 0.05
Power = 0.80
양측검정
```

[ python : code ] "목표 검정력을 만족하기 위해 필요한 그룹당 표본 크기 계산"

```python
import math
from statsmodels.stats.power import TTestIndPower

analysis = TTestIndPower()

required_n = analysis.solve_power(
    effect_size=0.5,
    alpha=0.05,
    power=0.8,
    alternative="two-sided"
)

required_n = math.ceil(required_n)

print(f"그룹당 필요한 표본 수: {required_n}명")
print(f"전체 필요한 표본 수: {required_n * 2}명")
```

[ Result ]

```text
그룹당 필요한 표본 수: 64명
전체 필요한 표본 수: 128명
```

`solve_power()`의 계산값은 약 `63.77명`이지만 사람 수는 소수점으로 모집할 수 없기 때문에 **목표 검정력을 확보하려면 올림하여 64명**을 모집해야 한다.

```text
63.77명
   ↓
올림
   ↓
64명 / group
   ↓
두 그룹 총 128명
```

<br>

> ## **2-3 ) 작은 효과를 발견하려면 더 많은 표본이 필요하다**

효과 크기가 `0.3`으로 작아졌다고 하자.

[ python : code ] "작은 효과 크기 0.3을 발견하기 위해 필요한 표본 수 계산"

```python
import math
from statsmodels.stats.power import TTestIndPower

analysis = TTestIndPower()

required_n = analysis.solve_power(
    effect_size=0.3,
    alpha=0.05,
    power=0.8,
    alternative="two-sided"
)

print(f"그룹당 필요한 표본 수: {math.ceil(required_n)}명")
```

[ Result ]

```text
그룹당 필요한 표본 수: 176명
```

효과 크기가 `0.5`일 때는 그룹당 약 `64명`이 필요했지만, 효과 크기가 `0.3`으로 작아지면 그룹당 약 `176명`이 필요하다.

| 효과 크기 | α | Power | 그룹당 필요 표본 |
|---:|---:|---:|---:|
| 0.5 | 0.05 | 0.80 | 64명 |
| 0.3 | 0.05 | 0.80 | 176명 |

즉,

```text
발견하려는 차이가 작아질수록
      ↓
신호를 잡아내기 어려워짐
      ↓
더 많은 표본이 필요
```

하다.

<br>

> ## **2-4 ) 목표 검정력이 높아지면 필요한 표본도 증가한다**

이번에는 효과 크기 `0.5`, `α = 0.05`는 그대로 두고 목표 검정력을 비교한다.

[ python : code ] "목표 검정력 80%와 90%에서 필요한 표본 수 비교"

```python
import math
from statsmodels.stats.power import TTestIndPower

analysis = TTestIndPower()

n_80 = analysis.solve_power(
    effect_size=0.5,
    alpha=0.05,
    power=0.8,
    alternative="two-sided"
)

n_90 = analysis.solve_power(
    effect_size=0.5,
    alpha=0.05,
    power=0.9,
    alternative="two-sided"
)

print(f"검정력 0.80: 그룹당 {math.ceil(n_80)}명")
print(f"검정력 0.90: 그룹당 {math.ceil(n_90)}명")
```

[ Result ]

```text
검정력 0.80: 그룹당 64명
검정력 0.90: 그룹당 86명
```

| 목표 검정력 | 그룹당 표본 |
|---:|---:|
| 0.80 | 64명 |
| 0.90 | 86명 |

실제 차이를 놓칠 가능성을 더 낮추려면 더 많은 데이터를 확보해야 한다.

<br>

> ## **2-5 ) 표본 크기 결정 흐름**

```text
[어떤 차이를 발견하고 싶은가?]
            ↓
[최소 효과 크기 결정]
            ↓
[유의수준 α 결정]
            ↓
[목표 Power 결정]
            ↓
[통계 검정 방법 결정]
            ↓
[solve_power()]
            ↓
[필요한 표본 수 계산]
            ↓
[소수점이면 올림]
            ↓
[실험 대상 모집]
```

이 과정을 **사전 검정력 분석(Power Analysis)**이라고 한다.

# **3. 표본이 많으면 무조건 좋은가**

> ## **3-1 ) 검정력 측면에서는 유리하다**

표본이 증가하면 일반적으로 표준오차가 감소한다.

평균의 표준오차는 기본적으로 다음 관계를 가진다.

```text
SE = s / √n
```

따라서

```text
n 증가
   ↓
√n 증가
   ↓
표준오차 감소
   ↓
평균 추정 정밀도 증가
   ↓
작은 차이도 발견하기 쉬워짐
   ↓
Power 증가
```

한다.

<br>

> ## **3-2 ) 하지만 비용과 시간이 증가한다**

스포츠과학 실험에서는 참가자를 많이 모집할수록 다음 비용도 증가할 수 있다.

```text
선수 모집
측정 장비 사용
검사 인력
실험 시간
영상 데이터 처리
보상 비용
```

따라서 무조건 많은 표본을 수집하는 것보다 **목표 검정력을 충족할 수 있는 적절한 표본 크기를 설계하는 것**이 합리적이다.

<br>

> ## **3-3 ) 표본이 지나치게 크면 매우 작은 차이도 유의해질 수 있다**

표본이 매우 크면 실질적으로는 거의 의미 없는 작은 차이도

```text
p-value < 0.05
```

가 될 수 있다.

예를 들어 수만 명의 마라톤 데이터를 분석했다고 하자.

```text
기존 평균 기록 = 240.0분
새 훈련 평균 기록 = 239.8분

차이 = 0.2분 = 12초

p-value = 0.001
```

통계적으로는 유의할 수 있지만, 선수나 코치의 목적에 따라 `12초` 차이가 실제로 중요한지는 별도의 판단이 필요하다.

즉,

```text
표본이 큼
→ 작은 차이도 검출 가능

하지만

검출 가능
≠
실제로 중요한 효과
```

이다.

# **4. 효과 크기(Effect Size)**

> ## **4-1 ) p-value와 효과 크기는 다른 질문에 답한다**

`p-value`와 효과 크기는 서로 다른 정보를 제공한다.

| 지표 | 질문 |
|---|---|
| p-value | 차이가 있다고 볼 통계적 근거가 있는가? |
| 효과 크기 | 그 차이가 얼마나 큰가? |

예를 들어

```text
p-value = 0.001
```

이라고 해도 효과가 매우 작을 수 있다.

반대로 효과 크기가 상당히 커 보여도 표본이 매우 작으면

```text
p-value > 0.05
```

가 나타날 수 있다.

따라서 둘을 함께 확인해야 한다.

<br>

> ## **4-2 ) Cohen's d**

두 독립 집단의 평균 차이를 비교할 때 대표적으로 사용하는 표준화된 효과 크기가 **Cohen's d**이다.

기본적인 형태는 다음과 같다.

```text
              두 그룹 평균의 차이
Cohen's d = ──────────────────────
                통합 표준편차
```

수식으로 표현하면

```text
d = (M₁ - M₂) / S_pooled
```

이다.

평균 차이가 동일하더라도 데이터의 분산이 달라지면 Cohen's d도 달라진다.

<br>

> ## **4-3 ) Cohen's d 해석 기준**

일반적으로 절댓값을 기준으로 다음 기준이 자주 사용된다.

| `|Cohen's d|` | 일반적인 해석 |
|---:|---|
| 약 0.2 | 작은 효과 |
| 약 0.5 | 중간 효과 |
| 약 0.8 이상 | 큰 효과 |

다만 이 값은 **절대적인 법칙이 아니다.**

예를 들어 엘리트 스포츠에서는 아주 작은 기록 차이도 중요한 경우가 있고, 의료·재활 분야에서는 실제 임상적 기준이 따로 존재할 수 있다.

따라서 항상 분석 분야의 기준을 함께 고려해야 한다.

<br>

> ## **4-4 ) 러닝 프로그램의 Cohen's d 계산**

기존 러닝 프로그램과 새로운 러닝 프로그램의 5km 기록을 비교한다고 하자.

[ python : code ] "두 러닝 프로그램의 평균 기록 차이와 Cohen's d 계산"

```python
import numpy as np
from scipy import stats

control = np.array([
    30.1, 29.4, 31.2, 28.9, 30.5,
    29.8, 30.7, 29.6, 31.0, 30.2
])

training = np.array([
    28.7, 28.9, 29.4, 28.5, 29.1,
    28.8, 29.3, 28.6, 29.0, 28.7
])

# 평균
mean_control = np.mean(control)
mean_training = np.mean(training)

# 표준편차
std_control = np.std(control, ddof=1)
std_training = np.std(training, ddof=1)

# Pooled Standard Deviation
n1 = len(control)
n2 = len(training)

pooled_std = np.sqrt(
    ((n1 - 1) * std_control**2 +
     (n2 - 1) * std_training**2)
    / (n1 + n2 - 2)
)

# Cohen's d
cohens_d = (
    mean_training - mean_control
) / pooled_std

# 독립표본 t-검정
t_stat, p_value = stats.ttest_ind(
    training,
    control,
    equal_var=True
)

print(f"기존 프로그램 평균: {mean_control:.2f}분")
print(f"새 프로그램 평균: {mean_training:.2f}분")
print(f"평균 차이: {mean_training - mean_control:.2f}분")
print(f"Cohen's d: {cohens_d:.2f}")
print(f"p-value: {p_value:.6f}")
```

[ Result ]

```text
기존 프로그램 평균: 30.14분
새 프로그램 평균: 28.90분
평균 차이: -1.24분
Cohen's d: -2.22
p-value: 0.000099
```

### 결과 해석

새로운 프로그램의 평균 기록은 기존 프로그램보다 약 `1.24분` 짧다.

```text
평균 차이 = -1.24분
```

여기서 음수는 새 프로그램의 시간이 더 짧다는 **방향**을 나타낸다.

효과 크기는

```text
Cohen's d = -2.22
```

이며 효과의 크기를 볼 때 절댓값을 사용하면

```text
|d| = 2.22
```

이므로 일반적인 기준에서는 매우 큰 효과이다.

또한

```text
p-value = 0.000099 < 0.05
```

이므로 예시 데이터에서는 통계적으로도 유의한 차이가 있다.

```text
        ↓

```

# **5. 통계적 유의성과 실질적 유의성**

> ## **5-1 ) 통계적 유의성**

통계적 유의성(Statistical Significance)은 관찰된 차이가 **귀무가설 아래에서 우연만으로 설명하기 어려운지** 판단하는 개념이다.

일반적으로

```text
p-value < α
```

이면 통계적으로 유의하다고 표현한다.

하지만 이것만으로

```text
"중요한 효과다."
```

라고 결론 내릴 수는 없다.

<br>

> ## **5-2 ) 실질적 유의성**

실질적 유의성(Practical Significance)은 관찰된 차이가 **실제 의사결정에서 중요할 정도로 큰지**를 판단하는 것이다.

스포츠 분야에서는 다음과 같은 기준이 될 수 있다.

```text
경기력 향상 정도
기록 단축 정도
부상 위험 감소
회복시간 감소
선수 피로도
프로그램 운영 비용
훈련 시간
장비 비용
```

따라서

```text
통계적으로 차이가 있는가?
```

와

```text
실제로 사용할 가치가 있는가?
```

는 별개의 질문이다.

<br>

> ## **5-3 ) 두 유의성 비교**

| 구분 | 통계적 유의성 | 실질적 유의성 |
|---|---|---|
| 핵심 질문 | 우연이라고 보기 어려운가? | 실제로 중요한 차이인가? |
| 주요 지표 | p-value, α | 효과 크기, 실제 차이, 비용·효용 |
| 표본 크기의 영향 | 매우 큼 | 판단 기준 자체는 업무 맥락에 의존 |
| 판단 예 | `p < 0.05` | 최소 0.3초 기록 향상이 필요한가? |
| 최종 의사결정 | 이것만으로 부족 | 함께 고려해야 함 |

<br>

> ## **5-4 ) 통계적으로 유의하지만 실질적으로 의미 없는 사례**

엘리트 스프린터를 대상으로 새로운 장비를 테스트했다고 하자.

```text
기존 평균 100m 기록 = 11.00초
새 장비 평균 기록 = 10.98초

차이 = 0.02초
p-value = 0.003
```

유의수준 `0.05`에서는

```text
0.003 < 0.05
→ 통계적으로 유의
```

하다.

하지만 새로운 장비 도입 비용이 매우 높고 코칭팀이 사전에 정한 **최소 의미 있는 개선 기준이 0.10초**라면

```text
실제 개선 = 0.02초
필요한 개선 = 0.10초

0.02 < 0.10
```

이므로 실무적인 기준에서는 충분한 개선이 아닐 수 있다.

```text
통계적 유의성 O
실질적 유의성 X
```

가 동시에 가능하다.

<br>

> ## **5-5 ) 반대로 실질적 차이가 있어 보여도 통계적으로 유의하지 않을 수 있다**

예를 들어 새로운 운동처방 프로그램으로 보행 속도가 평균 `0.15 m/s` 향상되었다고 하자.

재활 현장에서 `0.15 m/s`가 중요한 변화로 간주되더라도 표본이 `5명`뿐이고 개인차가 매우 크다면

```text
p-value > 0.05
```

가 나올 수 있다.

이 경우

```text
실질적으로 중요한 차이 가능성
+
검정력이 부족한 실험
```

일 수 있으므로 단순히

```text
"효과가 없다."
```

고 결론 내리는 것은 적절하지 않다.

# **6. p-value·효과 크기·검정력을 함께 해석하기**

> ## **6-1 ) 각 지표가 알려주는 정보**

| 지표 | 알려주는 정보 |
|---|---|
| p-value | H₀에 반하는 통계적 근거가 어느 정도인가 |
| 효과 크기 | 차이가 얼마나 큰가 |
| 검정력 | 실제 차이를 발견할 능력이 어느 정도인가 |
| 표본 크기 | 분석의 정밀도와 검정력에 영향을 주는 데이터량 |
| 신뢰구간 | 효과 크기의 불확실성 범위를 보여줌 |

따라서 분석 결과를 다음처럼 한 가지 값만 보고 판단하는 것은 부족하다.

```text
p = 0.03
→ 끝
```

대신 다음처럼 생각해야 한다.

```text
p-value는?
      ↓
통계적으로 유의한가?
      ↓
효과 크기는?
      ↓
차이는 얼마나 큰가?
      ↓
신뢰구간은?
      ↓
효과 추정의 불확실성은?
      ↓
Power는 충분했는가?
      ↓
실질적인 기준을 넘는가?
      ↓
최종 의사결정
```

<br>

> ## **6-2 ) 실전 결과 해석 예시**

스포츠 영상분석 모델을 이용한 새로운 코칭 시스템의 효과를 평가했다고 가정한다.

```text
기존 선수 평균 패스 성공률 = 78.0%
새 시스템 적용 후 = 78.4%

p-value = 0.012
Cohen's d = 0.12
```

다음과 같이 해석할 수 있다.

```text
p-value = 0.012
→ 통계적으로 유의

Cohen's d = 0.12
→ 일반적인 기준에서는 매우 작은 효과

실제 증가량 = 0.4%p
→ 코칭 현장에서 의미 있는 차이인지 추가 판단 필요
```

따라서 최종 결론은

```text
"통계적으로 유의한 차이는 관찰되었으나,
효과 크기가 작으므로 실제 코칭 시스템 도입 여부는
운영 비용과 경기력 개선 기준을 추가로 고려해야 한다."
```

와 같이 작성하는 것이 적절하다.

# **7. 실험 설계 전체 흐름**

> ## **7-1 ) 분석 전에 확인해야 할 것**

실험이 끝난 뒤 p-value만 확인하기보다 **실험을 시작하기 전에 필요한 조건을 설계하는 과정**이 중요하다.

```text
① 연구 질문 설정
예: 새로운 근력훈련이 점프력을 높이는가?
        ↓
② 실질적으로 의미 있는 최소 차이 결정
예: 최소 3cm
        ↓
③ 예상 효과 크기 설정
        ↓
④ 유의수준 α 설정
예: 0.05
        ↓
⑤ 목표 Power 설정
예: 0.80
        ↓
⑥ 필요한 표본 크기 계산
        ↓
⑦ 데이터 수집
        ↓
⑧ 가설검정
        ↓
⑨ p-value 확인
        ↓
⑩ 효과 크기와 신뢰구간 확인
        ↓
⑪ 실질적 기준과 비교
        ↓
⑫ 최종 의사결정
```

<br>

> ## **7-2 ) 실험 결과 체크리스트**

| 확인 질문 | 확인 요소 |
|---|---|
| 실제 효과를 발견할 충분한 실험이었는가? | 검정력 |
| 표본이 충분했는가? | Sample Size |
| 우연이라고 보기 어려운가? | p-value |
| 차이가 얼마나 큰가? | Effect Size |
| 효과 추정이 얼마나 불확실한가? | Confidence Interval |
| 실제 현장에서 중요한가? | Practical Significance |
| 비용 대비 가치가 있는가? | 현업 기준 |

# **8. Advanced 추가 학습**

> ## **8-1 ) 최소 검출 효과 MDE**

**MDE(Minimum Detectable Effect)**는 주어진 표본 크기와 검정력에서 **통계적으로 발견할 수 있는 최소 효과 크기**를 의미한다.

```text
표본 크기가 작음
→ 큰 효과만 안정적으로 검출

표본 크기가 큼
→ 더 작은 효과까지 검출 가능
```

A/B 테스트나 스포츠 실험을 설계할 때 유용하다.

<br>

> ## **8-2 ) 최소 실질적 중요 차이**

통계검정 전에

```text
"얼마나 달라져야 실제로 중요한가?"
```

를 정해두는 것도 중요하다.

예를 들어

```text
100m 기록 최소 0.10초 단축
점프 높이 최소 3cm 증가
보행 속도 최소 0.10m/s 향상
```

처럼 실질적 기준을 먼저 정의하면 통계적으로 유의한 결과가 실제로 가치 있는지도 판단하기 쉬워진다.

<br>

> ## **8-3 ) 신뢰구간도 함께 확인하기**

효과 크기가 하나의 숫자로 추정되더라도 실제 효과에는 불확실성이 존재한다.

따라서

```text
p-value
+
Effect Size
+
Confidence Interval
```

을 함께 제시하면 결과를 더 풍부하게 해석할 수 있다.

# **9. 핵심정리**

- **검정력(Power)**은 실제 차이가 존재할 때 귀무가설을 올바르게 기각하여 그 차이를 발견할 확률이다.
- 검정력은 `1-β`이며 `β`는 제2종 오류가 발생할 확률이다.
- 제2종 오류는 **실제 차이가 존재하지만 이를 발견하지 못하는 오류**이다.
- 일반적으로 실험 설계에서는 `Power = 0.80` 정도를 많이 사용하지만 절대적인 기준은 아니다.
- 효과 크기가 커지면 일반적으로 검정력이 증가한다.
- 표본 크기가 증가하면 일반적으로 검정력이 증가한다.
- 유의수준 `α`가 커지면 귀무가설을 기각하기 쉬워져 일반적으로 검정력이 증가한다.
- 데이터의 변동성이 증가하면 차이를 구분하기 어려워져 검정력이 감소한다.
- `α`, 검정력, 효과 크기, 표본 크기는 서로 연결되어 있으므로 따로 판단해서는 안 된다.
- 더 작은 효과를 발견하려면 더 많은 표본이 필요하다.
- 더 높은 검정력을 확보하려면 더 많은 표본이 필요하다.
- 더 엄격한 유의수준을 사용하면서 같은 검정력을 유지하려면 일반적으로 더 많은 표본이 필요하다.
- `statsmodels`의 `TTestIndPower().solve_power()`를 이용하면 목표 조건에 필요한 표본 크기를 계산할 수 있다.
- 계산된 표본 수가 소수점이라면 목표 검정력을 충족하기 위해 **올림**하는 것이 안전하다.
- 표본을 무조건 많이 모으는 것은 비용과 시간이 증가하므로 목표 검정력을 충족하는 합리적인 표본 크기를 설계하는 것이 중요하다.
- 표본이 매우 크면 실질적으로 작은 차이도 통계적으로 유의해질 수 있다.
- **효과 크기(Effect Size)**는 관찰된 차이가 얼마나 큰지를 나타낸다.
- `Cohen's d`는 두 집단의 평균 차이를 통합 표준편차로 표준화한 대표적인 효과 크기이다.
- Cohen's d는 일반적으로 절댓값 기준 `0.2 = 작은 효과`, `0.5 = 중간 효과`, `0.8 이상 = 큰 효과`로 참고하지만 절대적인 규칙은 아니다.
- `p-value`는 **차이가 있다고 볼 통계적 근거**, 효과 크기는 **그 차이가 얼마나 큰지**를 알려준다.
- **통계적 유의성**과 **실질적 유의성**은 다른 개념이다.
- `p < 0.05`라고 해서 반드시 현실적으로 중요한 효과인 것은 아니다.
- 반대로 실질적으로 중요한 효과가 있어 보여도 표본이 작고 검정력이 낮으면 통계적으로 유의하지 않을 수 있다.
- 실제 분석에서는 `p-value`, 효과 크기, 검정력, 표본 크기, 신뢰구간과 실제 업무 기준을 함께 고려하는 것이 좋다.

```text
[ 실험 설계와 결과 해석의 핵심 흐름 ]

실질적으로 중요한 차이 결정
          ↓
예상 효과 크기 설정
          ↓
유의수준 α 설정
          ↓
목표 Power 설정
          ↓
필요한 표본 크기 계산
          ↓
데이터 수집
          ↓
가설검정 수행
          ↓
```
