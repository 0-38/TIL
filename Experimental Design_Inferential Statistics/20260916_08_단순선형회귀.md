# **1. 단순선형회귀의 개념과 구조**

> ## **1-1 ) 상관분석에서 회귀분석으로**

앞에서는 피어슨 상관계수를 이용하여 두 연속형 변수 사이의 **선형 관계의 방향과 정도**를 확인했다.

예를 들어 스포츠 생체역학에서는 다음과 같은 관계를 살펴볼 수 있다.

```text
핸드볼
어깨관절 각도 ↔ 공 속도

펜싱
런지 시 무릎관절 각도 ↔ 이동거리

역도
몸통 기울기 ↔ 바벨 수직속도

기계체조
어깨관절 각도 ↔ 이탈 높이

Pose Estimator
추정 관절각도 ↔ 실제 측정 관절각도
```

상관분석은

```text
두 변수가 얼마나 함께 움직이는가?
```

를 확인한다.

단순선형회귀는 여기에서 한 단계 더 나아가

```text
X가 주어졌을 때
Y를 하나의 직선으로 어떻게 표현할 수 있을까?
```

를 분석한다.

| 구분 | 상관분석 | 단순선형회귀 |
| --- | --- | --- |
| 대표 질문 | 두 변수가 얼마나 함께 움직이는가? | X를 이용해 Y를 어떻게 설명할 수 있는가? |
| 주요 결과 | 상관계수 `r` | 절편, 회귀계수, 예측값 |
| 변수 역할 | 두 변수의 관계 | 독립변수 `X`, 종속변수 `y` 구분 |
| 대표 함수 | `pearsonr()` | `LinearRegression()` |

<br>

> ## **1-2 ) 독립변수와 종속변수**

단순선형회귀에서는 두 변수의 역할을 구분한다.

```text
독립변수 X
        ↓
선형회귀 모델
        ↓
종속변수 y
```

예를 들어 핸드볼 슈팅 동작을 분석한다면

```text
X
→ 슈팅 순간 어깨관절 각도(°)

y
→ 공의 속도(km/h)
```

처럼 설정할 수 있다.

| 구분 | 의미 | 핸드볼 예시 |
| --- | --- | --- |
| 독립변수 `X` | 종속변수를 설명하는 데 사용하는 변수 | 어깨관절 각도 |
| 종속변수 `y` | 설명하거나 예측하고자 하는 결과 | 공 속도 |

단순선형회귀라는 이름에서 **단순(Simple)** 은 독립변수가 하나라는 의미이다.

```text
독립변수 1개
        ↓
Simple Linear Regression

독립변수 여러 개
        ↓
Multiple Linear Regression
```

<br>

> ## **1-3 ) 단순선형회귀식**

단순선형회귀 모델은 다음과 같은 직선으로 표현할 수 있다.

```text
ŷ = β₀ + β₁X
```

각 항의 의미는 다음과 같다.

| 기호 | 의미 |
| --- | --- |
| `X` | 독립변수 |
| `ŷ` | 모델이 예측한 종속변수 |
| `β₀` | 절편(Intercept) |
| `β₁` | 회귀계수 또는 기울기(Coefficient) |

예를 들어 다음 회귀식이 만들어졌다고 생각해보자.

```text
공 속도 = 29.24 + 0.519 × 어깨관절 각도
```

회귀계수 `0.519`는 현재 데이터 범위에서

> **어깨관절 각도가 1° 클 때 공 속도는 평균적으로 약 0.519 km/h 높은 선형 관계로 추정된다.**

라고 해석할 수 있다.

주의할 점은

```text
각도가 1° 증가했기 때문에
공 속도가 0.519 km/h 증가했다.
```

라고 인과적으로 단정하지 않는 것이다.

회귀계수 역시 기본적으로 **데이터에서 관찰된 관계**를 표현한다.

<br>

> ## **1-4 ) 절편 Intercept**

절편은

```text
X = 0
```

일 때 모델이 예측하는 `y` 값이다.

예를 들어

```text
공 속도 = 29.24 + 0.519 × 어깨관절 각도
```

라면

```text
어깨관절 각도 = 0°
        ↓
예측 공 속도 = 29.24 km/h
```

가 된다.

하지만 스포츠 생체역학에서는 `X = 0`이 실제로 의미가 없는 경우가 많다.

예를 들어 분석한 어깨관절 각도가

```text
75° ~ 110°
```

범위인데 `0°`에서의 공 속도를 해석하는 것은 실제 동작 범위를 크게 벗어난다.

따라서

> **절편은 회귀식을 구성하는 중요한 값이지만 항상 실제적인 의미를 갖는 것은 아니다.**

라는 점을 기억해야 한다.

<br>

> ## **1-5 ) 핸드볼 어깨관절 각도와 공 속도 회귀분석**

핸드볼 슈팅 순간의 어깨관절 각도와 공 속도를 측정했다고 가정한다.

```python
shoulder_angle = [75, 80, 85, 90, 95, 100, 105, 110]
ball_speed = [68, 71, 73, 76, 79, 81, 84, 86]
```

[Python : code] "핸드볼 어깨관절 각도를 이용한 공 속도 단순선형회귀"

```python
import numpy as np
from sklearn.linear_model import LinearRegression

shoulder_angle = np.array(
    [75, 80, 85, 90, 95, 100, 105, 110]
)

ball_speed = np.array(
    [68, 71, 73, 76, 79, 81, 84, 86]
)

X = shoulder_angle.reshape(-1, 1)
y = ball_speed

model = LinearRegression()
model.fit(X, y)

print(f"절편: {model.intercept_:.3f}")
print(f"회귀계수: {model.coef_[0]:.3f}")
```

[ Result ]

```text
절편: 29.238
회귀계수: 0.519
```

따라서 회귀식은 약

```text
공 속도
= 29.238 + 0.519 × 어깨관절 각도
```

이다.

회귀계수가 양수이므로

```text
어깨관절 각도 ↑
        ↓
공 속도도 높아지는
양의 선형 관계
```

가 나타난다.

현재 관측 범위에서는 어깨관절 각도가 `1°` 클 때 공 속도가 평균적으로 약 `0.519 km/h` 높은 관계로 추정된다.

<br>

> ## **1-6 ) reshape(-1, 1)을 사용하는 이유**

`scikit-learn`의 `LinearRegression`은 독립변수 `X`를 일반적으로 2차원 형태로 입력받는다.

원래 배열이

```python
[75, 80, 85, 90]
```

라면 shape은

```text
(4,)
```

이다.

`reshape(-1, 1)`을 적용하면

```python
[
 [75],
 [80],
 [85],
 [90]
]
```

형태가 되어

```text
(4, 1)
```

이 된다.

즉,

```python
X = shoulder_angle.reshape(-1, 1)
```

은

```text
4개의 관측값
×
1개의 독립변수
```

형태로 변환한다는 의미이다.

# **2. 최소제곱법과 잔차**

> ## **2-1 ) 회귀선은 어떻게 결정할까?**

실제 데이터에 직선을 그을 수 있는 방법은 매우 많다.

```text
선수 데이터
   •
       •
          •
              •

가능한 직선
──────────────

또 다른 직선
────────────

또 다른 직선
──────────
```

그렇다면 어떤 직선을 선택해야 할까?

선형회귀에서는 일반적으로 **실제값과 예측값의 차이를 가능한 작게 만드는 직선**을 찾는다.

이때 사용하는 대표적인 방법이 **최소제곱법(Least Squares Method)** 이다.

<br>

> ## **2-2 ) 잔차 Residual**

실제 측정값과 모델의 예측값의 차이를 **잔차(Residual)** 라고 한다.

```text
잔차 = 실제값 - 예측값
```

기호로 표현하면

```text
e = y - ŷ
```

이다.

예를 들어 핸드볼 선수의 실제 공 속도가

```text
실제값 = 79 km/h
```

이고 모델 예측값이

```text
예측값 = 78.5 km/h
```

라면

```text
잔차
= 79 - 78.5
= 0.5
```

이다.

잔차의 부호는 다음과 같이 해석할 수 있다.

| 잔차 | 의미 |
| --- | --- |
| `잔차 > 0` | 실제값이 예측값보다 큼 |
| `잔차 < 0` | 실제값이 예측값보다 작음 |
| `잔차 ≈ 0` | 예측값과 실제값이 비슷함 |

<br>

> ## **2-3 ) 왜 잔차를 제곱할까?**

잔차를 단순히 모두 더하면 문제가 발생할 수 있다.

```text
잔차

+3
-3
+2
-2
```

를 더하면

```text
0
```

이 된다.

하지만 실제로 모델의 오차가 없는 것은 아니다.

따라서 오차의 부호가 서로 상쇄되지 않도록 제곱한다.

```text
잔차
        ↓
잔차²
        ↓
모든 잔차²을 합함
        ↓
SSE
```

이를 다음과 같이 표현한다.

```text
SSE = Σ(y - ŷ)²
```

<br>

> ## **2-4 ) 최소제곱법 Least Squares**

최소제곱법은

> **잔차 제곱의 합이 가장 작은 회귀선을 선택하는 방법**

이다.

```text
여러 후보 직선
        ↓
각 직선의 예측값 계산
        ↓
실제값 - 예측값
        ↓
잔차 계산
        ↓
잔차²
        ↓
전부 합함
        ↓
SSE 계산
        ↓
SSE가 가장 작은 직선 선택
```

즉,

```text
SSE 최소
        ↓
가장 적절한 절편 β₀
+
가장 적절한 기울기 β₁
```

를 찾는 과정이다.

<br>

> ## **2-5 ) Pose Estimator 관절각도 보정 예제**

Pose Estimator로 측정한 무릎관절 각도와 모션캡처 장비에서 얻은 기준 관절각도를 비교한다고 가정한다.

```text
X
→ Pose Estimator가 추정한 무릎각도

y
→ 기준 장비에서 측정한 무릎각도
```

이러한 단순 예제에서는 두 측정값 사이의 선형 관계를 모델링하여 **보정 관계**를 탐색할 수 있다.

[Python : code] "Pose Estimator 무릎관절 각도와 기준 관절각도의 단순선형회귀"

```python
import numpy as np
from sklearn.linear_model import LinearRegression

pose_angle = np.array(
    [72, 80, 88, 96, 104, 112, 120, 128]
)

reference_angle = np.array(
    [70, 79, 86, 95, 101, 110, 118, 126]
)

X = pose_angle.reshape(-1, 1)
y = reference_angle

model = LinearRegression()
model.fit(X, y)

y_pred = model.predict(X)
residuals = y - y_pred

print(f"절편: {model.intercept_:.3f}")
print(f"회귀계수: {model.coef_[0]:.3f}")

print("예측값:", np.round(y_pred, 2))
print("잔차:", np.round(residuals, 2))
```

[ Result ]

```text
절편: -0.833
회귀계수: 0.990

예측값:
[ 70.42  78.33  86.25  94.17 102.08 110.   117.92 125.83]

잔차:
[-0.42  0.67 -0.25  0.83 -1.08  0.    0.08  0.17]
```

회귀식은 약

```text
기준 관절각도
= -0.833 + 0.990 × Pose 추정각도
```

이다.

회귀계수가 거의 `1`에 가깝다는 것은 이 예제 데이터에서 Pose Estimator의 추정각도가 증가할수록 기준 측정각도도 거의 비슷한 크기로 증가하는 선형 관계를 보였다는 의미이다.

다만 실제 Pose Estimation 성능 검증에서는 단순 회귀계수만 보는 것이 아니라

```text
MAE
RMSE
관절별 오차
카메라 위치
가림(Occlusion)
신뢰도
동작 속도
```

등도 함께 확인하는 것이 필요하다.

# **3. 결정계수 R²와 모델의 설명력**

> ## **3-1 ) 회귀계수가 있다고 좋은 모델은 아니다**

회귀계수를 구하면

```text
X가 달라질 때
y가 평균적으로 어떻게 달라지는가?
```

를 표현할 수 있다.

하지만 회귀계수만으로는

```text
이 직선이 실제 데이터를
얼마나 잘 설명하는가?
```

를 알기 어렵다.

이를 확인하기 위해 사용할 수 있는 대표적인 값이 **결정계수(R²)** 이다.

<br>

> ## **3-2 ) SST : 전체 변동**

`SST(Total Sum of Squares)`는 실제 `y`값이 평균으로부터 얼마나 퍼져 있는지를 나타낸다.

```text
SST = Σ(y - ȳ)²
```

개념적으로

```text
실제값
        ↓
전체 평균과 비교
        ↓
얼마나 흩어져 있는가?
        ↓
SST
```

이다.

즉, 모델을 만들기 전 종속변수가 가지고 있던 **전체 변동**이라고 생각할 수 있다.

<br>

> ## **3-3 ) SSE : 모델이 설명하지 못한 변동**

`SSE(Sum of Squared Errors)`는

```text
실제값 - 예측값
```

인 잔차를 제곱해서 모두 더한 값이다.

```text
SSE = Σ(y - ŷ)²
```

따라서

```text
SSE 큼
→ 실제값과 예측값의 차이가 큼

SSE 작음
→ 실제값과 예측값이 비교적 가까움
```

이라고 생각할 수 있다.

<br>

> ## **3-4 ) 결정계수 공식**

결정계수는 다음과 같이 계산할 수 있다.

```text
           SSE
R² = 1 - ─────
           SST
```

예를 들어

```text
SST = 100

SSE = 20
```

이라면

```text
R²
= 1 - 20 / 100
= 0.80
```

이다.

즉,

> **현재 데이터에서 종속변수 변동의 약 80%를 현재 선형회귀 모델이 설명한다.**

라고 해석할 수 있다.

<br>

> ## **3-5 ) 핸드볼 데이터의 SST, SSE, R² 직접 계산**

앞에서 사용한 핸드볼 데이터를 이용해 계산해보자.

[Python : code] "핸드볼 회귀모델의 SST, SSE, 결정계수 직접 계산"

```python
import numpy as np
from sklearn.linear_model import LinearRegression

shoulder_angle = np.array(
    [75, 80, 85, 90, 95, 100, 105, 110]
)

ball_speed = np.array(
    [68, 71, 73, 76, 79, 81, 84, 86]
)

X = shoulder_angle.reshape(-1, 1)
y = ball_speed

model = LinearRegression()
model.fit(X, y)

y_pred = model.predict(X)

# 전체 변동
sst = np.sum((y - y.mean()) ** 2)

# 모델이 설명하지 못한 변동
sse = np.sum((y - y_pred) ** 2)

# 결정계수
r2 = 1 - (sse / sst)

print(f"SST: {sst:.3f}")
print(f"SSE: {sse:.3f}")
print(f"R²: {r2:.3f}")
```

[ Result ]

```text
SST: 283.500
SSE: 0.619
R²: 0.998
```

이 예제에서는

```text
R² ≈ 0.998
```

이므로 현재 데이터에서 **공 속도의 변동 중 약 99.8%가 어깨관절 각도를 이용한 이 선형모델과 연결되어 설명된다**고 볼 수 있다.

다만 이 데이터는 학습을 위한 인위적인 소규모 예제이므로 실제 핸드볼 투구에서 이 정도의 설명력이 일반적으로 나타난다는 의미는 아니다.

실제 투구 속도에는

```text
어깨 회전속도
팔꿈치 신전속도
손목 속도
몸통 회전
하지 지면반력
선수의 근력
기술 수준
```

등 다양한 요소가 함께 영향을 줄 수 있다.

<br>

> ## **3-6 ) 펜싱 무릎관절 각도와 런지 거리 예제**

펜싱 런지 동작의 전방 무릎관절 각도와 런지 이동거리를 측정했다고 가정한다.

```python
knee_angle = [70, 75, 80, 85, 90, 95, 100, 105]
```


라고 할 수 있다.

이라는 뜻은 아니다.

# **4. 잔차를 이용한 모델 적합성 평가**

> ## **4-1 ) R²만 높으면 좋은 모델일까?**

결정계수가 높으면 현재 데이터의 변동을 선형회귀 모델이 많이 설명하고 있다는 의미이다.

하지만

```text
R²가 높다
        ↓
무조건 좋은 모델이다.
```

라고 판단하면 안 된다.

선형회귀가 놓치고 있는 **구조적인 패턴**이 존재할 수 있기 때문이다.

이를 확인하기 위해 **잔차 그래프(Residual Plot)** 를 살펴본다.

<br>

> ## **4-2 ) 좋은 잔차 분포의 기본적인 모습**

잔차 그래프에서는

```text
X축
→ 독립변수 또는 예측값

Y축
→ 잔차
```

를 놓을 수 있다.

기본적으로 선형모델이 관계를 적절하게 표현한다면 잔차가

```text
         •
   •           •
──────── 0 ─────────
      •        •
  •               •
```

처럼 `0` 주변에 **뚜렷한 구조 없이 흩어지는 모습**을 기대한다.

반대로

```text
•                 •
  •             •
    •         •
      • • •
──────── 0 ────────
```

처럼 곡선 패턴이 나타난다면

```text
실제 관계는 비선형인데
직선 모델을 사용했을 가능성
```

을 생각할 수 있다.

<br>

> ## **4-3 ) 역도 몸통 기울기와 바벨 수직속도 예제**

역도 동작에서 특정 구간의 몸통 기울기와 바벨 수직속도를 측정했다고 가정한다.

[Python : code] "역도 몸통 기울기와 바벨 수직속도의 회귀 및 잔차 분석"

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression

trunk_angle = np.array(
    [20, 25, 30, 35, 40, 45, 50, 55]
)

bar_velocity = np.array(
    [1.42, 1.39, 1.34, 1.30, 1.25, 1.21, 1.15, 1.10]
)

X = trunk_angle.reshape(-1, 1)
y = bar_velocity

model = LinearRegression()
model.fit(X, y)

y_pred = model.predict(X)
residuals = y - y_pred

print(f"절편: {model.intercept_:.3f}")
print(f"회귀계수: {model.coef_[0]:.4f}")
print(f"R²: {model.score(X, y):.3f}")

print("잔차:")
print(np.round(residuals, 3))

plt.scatter(trunk_angle, residuals)
plt.axhline(0, linestyle="--")

plt.xlabel("Trunk Angle (degree)")
plt.ylabel("Residual")
plt.title("Weightlifting Residual Plot")

plt.show()
```

[ Result ]

```text
절편: 1.616
회귀계수: -0.0092
R²: 0.996

잔차:
[-0.012  0.005  0.001  0.007  0.003  0.009 -0.005 -0.008]
```

회귀계수가 음수이므로 이 예제 데이터에서는

```text
몸통 기울기 ↑
        ↓
바벨 수직속도 ↓
```

형태의 음의 선형 관계가 나타난다.

잔차 역시 `0` 근처의 매우 작은 값으로 나타나므로 이 단순 예제에서는 직선 모델이 데이터를 잘 표현하고 있다.

단, 실제 역도 동작에서 몸통 각도와 바벨 속도 관계는 동작 국면, 중량, 선수 기술 등의 영향을 받기 때문에 이런 단순 관계만으로 운동역학적 원인을 판단해서는 안 된다.

<br>

> ## **4-4 ) R²가 높아도 잔차에 곡선 패턴이 나타나는 경우**

기계체조 철봉 동작에서 이탈 순간의 어깨관절 각도와 신체 중심의 이탈 높이를 분석한다고 가정한다.

다음 예제는 값이 계속 증가하지만 증가 폭도 점차 커지는 **곡선 관계**를 의도적으로 만든 데이터이다.

[Python : code] "기계체조 관절각도의 비선형 관계를 선형회귀로 분석"

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression

shoulder_angle = np.array(
    [70, 80, 90, 100, 110, 120, 130, 140, 150, 160]
)

release_height = np.array(
    [0.80, 0.88, 0.98, 1.10, 1.24,
     1.40, 1.59, 1.81, 2.06, 2.34]
)

X = shoulder_angle.reshape(-1, 1)
y = release_height

model = LinearRegression()
model.fit(X, y)

y_pred = model.predict(X)
residuals = y - y_pred

print(f"회귀계수: {model.coef_[0]:.4f}")
print(f"R²: {model.score(X, y):.3f}")

print("잔차:")
print(np.round(residuals, 3))

plt.scatter(shoulder_angle, residuals)
plt.axhline(0, linestyle="--")

plt.xlabel("Shoulder Angle (degree)")
plt.ylabel("Residual")
plt.title("Gymnastics Residual Plot")

plt.show()
```

[ Result ]

```text
회귀계수: 0.0169
R²: 0.966

잔차:
[ 0.141  0.052 -0.017 -0.066 -0.095
 -0.105 -0.084 -0.033  0.048  0.159]
```

여기서 중요한 점은

```text
R² = 0.966
```

이라는 상당히 높은 값이다.

R²만 보면

```text
선형모델이 매우 좋아 보임
```

이라고 판단할 수 있다.

하지만 잔차를 순서대로 보면

```text
양수
   ↓
음수
   ↓
다시 양수
```

라는 **U자 형태의 구조적인 패턴**이 나타난다.

```text
R² 높음
        ↓
하지만
        ↓
잔차에 곡선 패턴 존재
        ↓
실제 관계에 비선형성이
있을 가능성
```

따라서

> **R²가 높더라도 잔차 그래프에서 구조적인 패턴이 나타난다면 단순한 직선 모델이 데이터 관계를 충분히 표현하는지 다시 검토해야 한다.**

라는 점이 중요하다.

<br>

> ## **4-5 ) 잔차 그래프에서 확인할 패턴**

| 잔차 형태 | 생각할 수 있는 문제 |
| --- | --- |
| `0` 주변에 무작위로 분포 | 선형 관계가 비교적 적절할 가능성 |
| U자 또는 곡선 패턴 | 비선형 관계 가능성 |
| X가 증가할수록 퍼짐 증가 | 등분산성 문제 가능성 |
| 특정 관측치만 매우 멀리 위치 | 이상치 가능성 |
| 일정 방향으로 연속적으로 나타남 | 독립성 문제 가능성 |

즉, 잔차는 단순한 오차 숫자가 아니라

> **현재 모델이 어떤 관계를 놓치고 있는지를 확인하는 중요한 진단 도구**

이다.

따라서 실제 현상은 하나의 관절각도만으로 완전히 설명되기 어렵다.

# **6. 단순선형회귀 결과 해석 시 주의사항**

> ## **6-1 ) 회귀계수는 인과관계를 의미하지 않는다**

예를 들어

```text
어깨관절 각도 ↑
        ↓
공 속도 ↑
```

라는 양의 회귀계수가 나타났다고 해도

```text
어깨관절 각도를 강제로 증가시키면
공 속도가 반드시 증가한다.
```

라고 해석하면 안 된다.

다음 변수들이 동시에 영향을 줄 수 있다.

```text
관절 각속도
근력
투구 기술
몸통 회전
하지 추진력
선수 숙련도
```

즉, 회귀분석도 기본적으로 **관계와 예측 모델을 표현하는 방법**이지 자동으로 인과관계를 증명하는 방법은 아니다.

<br>

> ## **6-2 ) 관측 범위 밖의 예측에 주의**

핸드볼 데이터가

```text
어깨관절 각도
75° ~ 110°
```

에서 측정되었다고 하자.

이 모델을 이용해

```text
160°
```

에서의 공 속도를 예측하는 것은 위험할 수 있다.

이를 **외삽(Extrapolation)** 이라고 한다.

```text
학습한 범위 안에서 예측
→ 보간에 가까움

학습 범위를 크게 벗어나 예측
→ 외삽
→ 신뢰하기 어려울 수 있음
```

특히 인체 관절 움직임은 생체역학적 제한이 있기 때문에 관측 범위를 벗어난 직선 관계가 계속 유지된다고 가정하면 안 된다.

<br>

> ## **6-3 ) R²가 높다고 실제 예측력이 반드시 좋은 것은 아니다**

같은 데이터로 모델을 학습하고 평가하면 R²가 높게 나타날 수 있다.

실제 새로운 선수나 새로운 영상에 대한 예측력을 평가하려면

```text
Train Data
        ↓
모델 학습

Test Data
        ↓
새로운 데이터에서 평가
```

과 같은 분리가 필요할 수 있다.

따라서

```text
현재 데이터 설명력
```

과

```text
새로운 데이터에 대한 예측 성능
```

은 구분해야 한다.


<br><br>

# **7. Advanced 추가 학습**

> ## **7-1 ) MAE와 RMSE**

스포츠 영상에서 Pose Estimator의 관절각도 오차를 평가한다면 `R²`뿐 아니라 실제 오차의 크기도 중요하다.

대표적으로

```text
MAE
→ 오차 절댓값의 평균

RMSE
→ 오차 제곱 평균의 제곱근
```

을 사용할 수 있다.

예를 들어

```text
R² = 0.95
```

라고 하더라도

```text
관절각도 RMSE = 15°
```

라면 실제 자세 분석 목적에서는 오차가 클 수 있다.

따라서

```text
R²
+
MAE
+
RMSE
```

를 함께 확인하는 것이 유용하다.

<br>

> ## **7-2 ) 다중선형회귀**

실제 스포츠 동작은 하나의 변수만으로 결정되지 않는 경우가 많다.

핸드볼 공 속도를 분석한다면

```text
어깨관절 각도
팔꿈치 각도
몸통 회전속도
손목 속도
하지 지면반력
```

등 여러 변수를 함께 사용할 수 있다.

```text
X₁ + X₂ + X₃ + ...
        ↓
Multiple Linear Regression
        ↓
y
```

이것이 이후 학습할 수 있는 **다중선형회귀**로 연결된다.

<br>

> ## **7-3 ) Pose Estimator 데이터에서는 측정오차도 확인**

Pose Estimator가 생성한 관절각도는 실제 관절각도 그 자체가 아니라 **영상에서 추정된 값**이다.

따라서 실제 분석에서는

```text
카메라 각도
카메라 거리
프레임 속도
해상도
관절 가림
Keypoint Confidence
2D / 3D Pose 여부
```

에 따라 오차가 달라질 수 있다.

따라서 회귀모델의 성능뿐 아니라 **입력 데이터의 측정 신뢰도**도 함께 확인해야 한다.

# **8. 핵심정리**

> ## **8-1 ) 단순선형회귀 핵심**

단순선형회귀는 하나의 독립변수와 하나의 종속변수 사이의 관계를 직선으로 표현한다.

```text
ŷ = β₀ + β₁X
```

여기서

```text
β₀
→ 절편

β₁
→ 회귀계수
```

이다.

| 개념 | 의미 |
| --- | --- |
| 독립변수 `X` | 설명에 사용하는 변수 |
| 종속변수 `y` | 설명하거나 예측하려는 변수 |
| 절편 | `X = 0`일 때 예측값 |
| 회귀계수 | `X`가 1단위 달라질 때 `y`가 평균적으로 얼마나 달라지는지 표현 |

<br>

> ## **8-2 ) 최소제곱법 핵심**

회귀선은 실제값과 예측값의 차이를 이용하여 결정한다.

```text
실제값 y
-
예측값 ŷ
        ↓
잔차
        ↓
잔차²
        ↓
모두 합함
        ↓
SSE
```

최소제곱법은

> **SSE가 가장 작아지는 절편과 회귀계수를 찾는 방법**

이다.

<br>

> ## **8-3 ) R² 핵심**

결정계수는 모델의 설명력을 확인하는 대표적인 지표이다.

```text
           SSE
R² = 1 - ─────
           SST
```

| 값 | 의미 |
| --- | --- |
| `SST` | 종속변수의 전체 변동 |
| `SSE` | 모델이 설명하지 못한 변동 |
| `R²` | 현재 모델이 설명하는 변동의 정도 |

예를 들어

```text
R² = 0.80
```

이라면 현재 데이터에서 종속변수 변동의 약 80%를 현재 회귀모델이 설명한다고 해석할 수 있다.

<br>

> ## **8-4 ) 잔차 핵심**

잔차는

```text
Residual
= 실제값 - 예측값
```

이다.

잔차 그래프에서는 단순히 오차가 작은지만 보는 것이 아니라 **구조적인 패턴이 존재하는지** 확인한다.

```text
0 주변에 무작위 분포
→ 선형모델이 비교적 적절할 가능성

곡선 패턴
→ 비선형 관계 가능성

깔때기 형태
→ 오차 분산이 일정하지 않을 가능성

특정 점만 멀리 떨어짐
→ 이상치 가능성
```

<br>

> ## **8-5 ) 회귀계수 · R² · 잔차의 역할 비교**

| 분석 결과 | 확인하는 질문 |
| --- | --- |
| 회귀계수 | X와 y가 어떤 방향과 크기의 선형 관계를 보이는가? |
| 예측값 | X가 주어졌을 때 모델은 y를 얼마라고 예측하는가? |
| R² | 모델이 y의 변동을 얼마나 설명하는가? |
| 잔차 | 모델이 놓치고 있는 패턴은 없는가? |
| SSE | 설명하지 못한 전체 오차가 얼마나 남았는가? |

따라서 하나만 확인하면 안 된다.

```text
회귀계수
        ↓
관계 해석

R²
        ↓
설명력 확인

잔차
        ↓
모델 적합성 확인
```

<br>

> ## **8-6 ) 스포츠 생체역학에서의 전체 분석 흐름**

```text
[스포츠 동작 영상 또는 센서 데이터]
        ↓
Pose Estimator / Motion Capture
        ↓
관절 Keypoint
        ↓
관절각도 계산
        ↓
연구 문제 정의
        ↓
예:
어깨각도로 공 속도를 설명할 수 있는가?
        ↓
독립변수 X 설정
        ↓
종속변수 y 설정
        ↓
산점도 확인
        ↓
선형 관계 가능성 확인
        ↓
LinearRegression()
        ↓
model.fit()
        ↓
최소제곱법
        ↓
회귀식 생성
        ↓
ŷ = β₀ + β₁X
        ↓
회귀계수 해석
        ↓
model.predict()
        ↓
예측값 계산
        ↓
실제값 - 예측값
        ↓
잔차
        ↓
R² 계산
        ↓
잔차 그래프 확인
        ↓
┌─────────────────────────────┐
│ 회귀계수 → 관계             │
│ R² → 설명력                 │
│ 잔차 → 모델 적합성          │
└─────────────────────────────┘
        ↓
모델을 종합적으로 평가
```

스포츠 생체역학 예제로 연결하면 다음과 같다.

| 종목 | 독립변수 `X` 예시 | 종속변수 `y` 예시 |
| --- | --- | --- |
| 핸드볼 | 어깨관절 각도 | 공 속도 |
| 펜싱 | 런지 무릎관절 각도 | 런지 거리 |
| 역도 | 몸통 기울기 | 바벨 수직속도 |
| 기계체조 | 어깨관절 각도 | 이탈 높이 |
| 태권도 | 고관절 각도 | 발차기 속도 |
| 육상 | 무릎관절 각도 | 보폭 |
| 보행 분석 | 고관절 신전각 | 보행속도 |
| Pose Estimation | 추정 관절각도 | 기준 장비 관절각도 |

결국 단순선형회귀에서 가장 중요한 흐름은

```text
X와 y 설정
        ↓
산점도 확인
        ↓
회귀모델 구축
        ↓
회귀계수 해석
        ↓
예측값 계산
        ↓
R² 확인
        ↓
잔차 확인
        ↓
모델이 데이터를
적절하게 표현하는지 판단
```

으로 기억하면 된다.

**한 문장으로 정리하면**

> **단순선형회귀는 하나의 독립변수와 종속변수 사이의 관계를 최소제곱법으로 하나의 직선으로 표현하며, 회귀계수로 관계를 해석하고 R²로 설명력을 확인한 뒤 잔차를 통해 선형모델이 놓치고 있는 구조적인 패턴이 없는지를 함께 평가하는 방법이다.**
