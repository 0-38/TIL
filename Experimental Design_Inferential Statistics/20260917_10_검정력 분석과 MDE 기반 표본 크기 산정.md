# **1. 검정력 분석과 MDE**

> ## **1-1 ) 왜 실험 전에 표본 크기를 계산할까?**

A/B 테스트나 스포츠 실험에서는 실험이 끝난 후 통계검정을 수행하는 것뿐만 아니라 **실험을 시작하기 전에 어느 정도의 표본이 필요한지 결정하는 과정**이 중요하다.

예를 들어 펜싱에서 새로운 Pose 기반 런지 피드백을 적용한다고 생각해보자.

```text
A 그룹
→ 기존 런지 기술 코칭

B 그룹
→ Pose Estimator 기반
   무릎·고관절 관절각도 피드백
```

이번 실험의 핵심 지표를 다음과 같이 정의할 수 있다.

```text
런지 공격 완료시간

= 전방 이동을 시작한 시점부터
  검 끝이 표적에 접촉한 시점까지
  걸린 시간

단위
= ms
```

현재 평균 런지 공격 완료시간이 `700 ms`라고 하자.

새로운 코칭을 적용했을 때 어느 정도의 차이까지 탐지하고 싶은지에 따라 필요한 표본 수가 달라진다.

```text
700 ms → 620 ms
차이 = 80 ms

700 ms → 650 ms
차이 = 50 ms

700 ms → 670 ms
차이 = 30 ms
```

일반적으로 큰 차이는 비교적 쉽게 발견할 수 있지만 작은 차이는 선수 간 자연적인 변동과 구분하기 어렵다.

```text
큰 효과
→ 탐지하기 쉬움
→ 필요한 표본 ↓

작은 효과
→ 자연적인 변동과 구분하기 어려움
→ 필요한 표본 ↑
```

이때 실험에서 **최소한 이 정도의 차이는 탐지하고 싶다**고 사전에 설정하는 값이 `MDE`이다.

<br>

> ## **1-2 ) MDE Minimum Detectable Effect**

`MDE(Minimum Detectable Effect)`는 **설정한 유의수준과 검정력에서 실험을 통해 탐지하고자 하는 최소한의 효과 크기**이다.

예를 들어

```text
Baseline
→ 평균 런지 공격 완료시간 700 ms

MDE
→ 50 ms

탐지하려는 차이
→ 약 700 ms vs 650 ms
```

로 설정할 수 있다.

즉,

> **런지 공격 완료시간에서 실제로 50 ms 정도의 차이가 존재한다면 이를 탐지할 수 있도록 실험을 설계하겠다.**

라는 의미이다.

MDE가 `50 ms`라고 해서 실제 실험 결과가 반드시 `50 ms` 차이로 나타난다는 뜻은 아니다.

```text
MDE
≠
실험 결과 예측값
```

MDE는 **실험 전에 어느 정도의 차이까지 발견할 수 있도록 설계할 것인지 정하는 기준**이다.

<br>

> ## **1-3 ) MDE는 어떻게 결정할까?**

MDE는 무조건 작게 설정하는 것이 좋은 것은 아니다.

예를 들어 새로운 펜싱 Pose 피드백 시스템을 사용하는 데 시간과 비용이 많이 필요한 상황을 생각해보자.

```text
런지 공격 완료시간
700 ms → 698 ms

차이
= 2 ms
```

정도의 변화는 통계적으로 측정할 수 있더라도 실제 경기 수행에서 큰 의미가 없을 수 있다.

반면

```text
700 ms → 650 ms

차이
= 50 ms
```

정도의 차이라면 코칭 방법을 변경할 가치가 있는지 검토할 수 있다.

따라서 MDE는 다음을 함께 고려하여 설정한다.

```text
통계적으로 탐지 가능한 차이

+

스포츠 현장에서 의미 있는 차이

+

경기 수행에 미치는 영향

+

실험 비용

+

모집 가능한 선수 수
```

즉, MDE는 Python이 자동으로 정해주는 값이 아니라 **연구자가 실제 의사결정에서 중요하다고 생각하는 최소 효과를 사전에 정의하는 값**이다.

<br>

> ## **1-4 ) 비율형 지표에서는 `%p`와 상대적 `%`를 구분한다**

양궁에서 다음과 같은 지표를 사용한다고 하자.

```text
70m 10점 명중률

= 70m 거리에서 발사한 전체 화살 중
  10점 링에 적중한 화살의 비율
```

현재 10점 명중률이

```text
60%
```

이고 새로운 자세 피드백 후

```text
68%
```

가 되었다면 절대적인 차이는

```text
68% - 60%
= 8%p
```

이다.

반면 상대적 변화는

```text
(68 - 60) / 60 × 100

≈ 13.3%
```

이다.

| 표현 | 의미 |
| --- | --- |
| `8%p 증가` | 명중률 자체가 60% → 68% |
| `약 13.3% 증가` | 기존 60%를 기준으로 상대적으로 약 13.3% 증가 |

따라서 비율형 지표의 MDE는

```text
MDE = 절대 8%p
```

처럼 명확하게 표현하는 것이 좋다.

<br>

> ## **1-5 ) 유의수준 α**

유의수준 `α`는 **실제로 차이가 없는데 차이가 있다고 잘못 판단하는 제1종 오류(Type I Error)** 와 관련된 기준이다.

예를 들어 테니스에서 다음 지표를 비교한다고 하자.

```text
첫 서브 인 성공률

= 전체 첫 서브 시도 중
  서비스 박스 안에 정상적으로 들어간
  첫 서브의 비율
```

실제로는

```text
A 그룹 = 60%

B 그룹 = 60%

→ 실제 차이 없음
```

인데 표본에서는 우연히

```text
A = 58%

B = 65%
```

가 관찰될 수 있다.

이 결과를 보고 새로운 훈련의 효과가 있다고 판단하면 제1종 오류가 된다.

```text
실제로 차이 없음
        ↓
표본에서는 우연히 차이가 관찰됨
        ↓
차이가 있다고 잘못 판단
        ↓
제1종 오류
```

예를 들어

```text
α = 0.05
```

로 설정하면 귀무가설이 실제로 참일 때 이를 잘못 기각하는 오류를 `5%` 수준으로 설정하여 검정한다는 의미이다.

<br>

> ## **1-6 ) 검정력 Power**

이번에는 실제로 우리가 탐지하고자 하는 차이가 존재한다고 하자.

```text
A 그룹 첫 서브 인 성공률
= 55%

B 그룹 첫 서브 인 성공률
= 63%

실제 차이
= 8%p
```

실제로 차이가 있더라도 표본이 너무 적거나 데이터 변동이 크다면 이를 발견하지 못할 수 있다.

```text
실제로 차이가 있음
        ↓
표본이 부족하거나 변동성이 큼
        ↓
차이를 발견하지 못함
        ↓
제2종 오류
```

제2종 오류의 확률을 `β`라고 하고 검정력은 다음과 같다.

```text
Power = 1 - β
```

예를 들어

```text
Power = 0.80
```

이라면

```text
실제로 MDE 정도의 차이가 존재할 때
→ 이를 발견할 확률 80%

β = 0.20
→ 실제 차이를 발견하지 못할 확률 20%
```

로 이해할 수 있다.

<br>

> ## **1-7 ) 검정력 분석의 네 가지 요소**

검정력 분석에서는 다음 네 요소가 서로 연결되어 있다.

```text
효과크기

유의수준 α

검정력 Power

표본 크기 Sample Size
```

일반적으로 세 가지를 설정하면 나머지 하나를 계산할 수 있다.

| 요소 | 핵심 질문 |
| --- | --- |
| MDE / 효과크기 | 어느 정도의 차이까지 탐지하고 싶은가? |
| `α` | 제1종 오류를 어느 수준으로 설정할 것인가? |
| Power | 실제 차이를 얼마나 높은 확률로 발견할 것인가? |
| Sample Size | 이 조건을 만족하려면 몇 개의 표본이 필요한가? |

A/B 테스트에서는 일반적으로

```text
MDE 설정
+
α 설정
+
Power 설정
        ↓
필요한 표본 크기 계산
```

의 순서로 사용한다.

# **2. MDE · 유의수준 · 검정력과 표본 크기의 관계**

> ## **2-1 ) MDE가 작아지면 표본은 증가한다**

펜싱 런지 공격 완료시간을 예로 들어보자.

```text
실험 A
MDE = 80 ms

실험 B
MDE = 50 ms

실험 C
MDE = 30 ms
```

`30 ms`의 작은 차이는 `80 ms`의 차이보다 선수의 자연적인 수행 변동과 구분하기 어렵다.

```text
MDE ↓
        ↓
더 작은 차이까지 탐지
        ↓
자연적인 변동과 구분하기 어려움
        ↓
필요 표본 ↑
```

반대로

```text
MDE ↑
→ 큰 차이만 탐지
→ 필요 표본 ↓
```

이다.

<br>

> ## **2-2 ) 유의수준 α가 작아지면 표본은 증가한다**

다음 두 조건을 비교해보자.

```text
조건 A
α = 0.05

조건 B
α = 0.01
```

`α = 0.01`은 제1종 오류를 더 낮은 수준으로 설정하는 것이므로 차이가 있다고 판단하기 위한 기준이 더 엄격해진다.

```text
α ↓
        ↓
제1종 오류를 더 엄격하게 통제
        ↓
귀무가설을 기각하기 어려워짐
        ↓
같은 효과를 탐지하려면
더 많은 표본 필요
```

따라서

```text
α ↓
→ 표본 크기 ↑
```

이다.

<br>

> ## **2-3 ) 검정력을 높이면 표본은 증가한다**

```text
조건 A
Power = 0.80

조건 B
Power = 0.90
```

검정력을 높이면 실제 차이가 존재할 때 이를 놓칠 가능성을 줄이는 방향으로 실험을 설계하게 된다.

```text
Power = 0.80
→ β = 0.20

Power = 0.90
→ β = 0.10
```

따라서

```text
Power ↑
→ 실제 효과를 발견할 가능성 ↑
→ 필요 표본 ↑
```

이다.

<br>

> ## **2-4 ) 데이터 변동성이 커져도 표본이 증가한다**

연속형 스포츠 지표에서는 데이터의 변동성도 중요하다.

예를 들어 두 펜싱 실험 모두 평균 차이가 `50 ms`라고 하자.

```text
상황 A

런지 공격 완료시간
대부분 650~750 ms

→ 선수 간 변동 작음
```

```text
상황 B

런지 공격 완료시간
500~900 ms까지 크게 분산

→ 선수 간 변동 큼
```

같은 `50 ms` 차이라도 상황 B에서 탐지하기가 더 어렵다.

```text
데이터 변동성 ↑
→ 효과와 자연적인 변동을 구분하기 어려움
→ 필요 표본 ↑
```

<br>

> ## **2-5 ) 전체 관계 정리**

| 조건 변화 | 의미 | 필요한 표본 |
| --- | --- | ---: |
| `MDE ↓` | 더 작은 차이까지 탐지 | 증가 |
| `MDE ↑` | 큰 차이만 탐지 | 감소 |
| `α ↓` | 제1종 오류를 더 엄격하게 통제 | 증가 |
| `Power ↑` | 실제 차이를 발견할 가능성을 높임 | 증가 |
| `SD ↑` | 데이터 변동성 증가 | 증가 |

전체적으로

```text
더 작은 차이까지 탐지하고 싶고

        +

잘못 차이가 있다고 판단할 위험은
더 낮추고 싶고

        +

실제 차이는
더 높은 확률로 발견하고 싶다면

        ↓

더 많은 표본이 필요
```

하다고 이해할 수 있다.

<br>

> ## **2-6 ) MDE를 무조건 작게 설정하면 안 되는 이유**

예를 들어 실제로 모집 가능한 펜싱 선수가 `30명`뿐인데

```text
런지 공격 완료시간의
5 ms 차이까지 반드시 탐지하겠다.
```

라고 설정한다면 현실적으로 필요한 표본을 확보하지 못할 수 있다.

따라서

```text
실제로 의미 있는 효과인가?

+

해당 표본을 모집할 수 있는가?

+

실험 기간을 유지할 수 있는가?

+

측정 조건을 안정적으로 유지할 수 있는가?
```

를 함께 고려해야 한다.

# **3. 비율형 지표의 표본 크기 계산**

> ## **3-1 ) 양궁 70m 10점 명중률**

양궁에서 Pose 기반 자세 정렬 피드백이 명중률에 영향을 주는지 확인한다고 하자.

```text
Control
→ 기존 코칭

Treatment
→ Pose Estimator 기반
   어깨·팔꿈치 정렬 피드백
```

목표 지표는 다음과 같다.

```text
70m 10점 명중률

= 70m에서 발사한 전체 화살 중
  10점 링에 적중한 화살 비율
```

실험 조건을 다음과 같이 설정한다.

```text
Baseline = 60%

MDE = 8%p

Target = 68%

α = 0.05

Power = 0.80
```

<br>

> ## **3-2 ) Python으로 표본 크기 계산**

[Python : code] "양궁 70m 10점 명중률 차이의 표본 크기 계산"

```python
import math

from statsmodels.stats.power import NormalIndPower
from statsmodels.stats.proportion import proportion_effectsize

baseline = 0.60
mde = 0.08
target = baseline + mde

effect_size = abs(
    proportion_effectsize(
        baseline,
        target
    )
)

analysis = NormalIndPower()

sample_size = analysis.solve_power(
    effect_size=effect_size,
    alpha=0.05,
    power=0.80,
    ratio=1.0,
    alternative="two-sided"
)

sample_size = math.ceil(sample_size)

print(f"효과크기: {effect_size:.3f}")
print(f"그룹당 필요 표본: {sample_size}")
print(f"전체 필요 표본: {sample_size * 2}")
```

[ Result ]

```text
효과크기: 0.167
그룹당 필요 표본: 564
전체 필요 표본: 1128
```

단순 독립 2집단 비율 비교를 가정하면 그룹당 약 `564개`의 독립 관측이 필요하다.

하지만 여기서 중요한 점이 있다.

```text
화살 564발
≠
독립된 선수 564명
```

한 선수가 반복해서 화살을 발사한다면 동일 선수의 관측값은 서로 관련되어 있을 수 있다.

따라서 실제 연구에서는

```text
선수 수

발사 횟수

선수별 반복측정

선수 내 상관
```

을 고려해야 한다.

<br>

> ## **3-3 ) 테니스 첫 서브 인 성공률**

목표 지표를 다음과 같이 정의한다.

```text
첫 서브 인 성공률

= 서비스 박스 안에 들어간 첫 서브 수
  /
  전체 첫 서브 시도 수
```

실험 조건은

```text
Baseline = 55%

MDE = 8%p

Target = 63%

α = 0.05

Power = 0.80
```

이다.

[Python : code] "테니스 첫 서브 인 성공률의 표본 크기 계산"

```python
import math

from statsmodels.stats.power import NormalIndPower
from statsmodels.stats.proportion import proportion_effectsize

baseline = 0.55
target = 0.63

effect_size = abs(
    proportion_effectsize(
        baseline,
        target
    )
)

analysis = NormalIndPower()

sample_size = analysis.solve_power(
    effect_size=effect_size,
    alpha=0.05,
    power=0.80,
    ratio=1.0,
    alternative="two-sided"
)

print(
    "그룹당 필요 표본:",
    math.ceil(sample_size)
)
```

[ Result ]

```text
그룹당 필요 표본: 592
```

여기에서도

```text
서브 592회
≠
독립된 선수 592명
```

이라는 점을 주의해야 한다.

# **4. 연속형 지표의 표본 크기 계산**

> ## **4-1 ) 연속형 스포츠 변수를 구체적으로 정의하기**

연속형 변수는 단순히 `속도`, `시간`, `각도`라고 적기보다 **어떤 동작의 어느 시점에서 측정하는 값인지 구체화**하는 것이 좋다.

| 종목 | 구체적인 변수 | 측정 정의 | 단위 |
| --- | --- | --- | --- |
| 핸드볼 | 7m 스탠딩 슈팅 릴리스 속도 | 공이 손에서 떨어지는 순간의 공 이동속도 | `km/h` |
| 배드민턴 | 전방 네트 지점 셔틀 도달시간 | 센터 베이스에서 이동 시작 후 라켓이 셔틀에 접촉하기까지의 시간 | `s` |
| 펜싱 | 런지 공격 완료시간 | 전방 이동 시작부터 검 끝의 표적 접촉까지의 시간 | `ms` |
| 펜싱 | 최대 런지 시 전방 무릎 굴곡각 | 런지가 가장 깊어진 순간 앞다리 대퇴와 하퇴가 이루는 각도 | `°` |
| 펜싱 | 최대 전방 신체중심 속도 | 런지 중 신체중심의 전방 방향 최대 이동속도 | `m/s` |
| 펜싱 | 앞발 착지 시 최대 수직지면반력 | 런지 착지 구간에서 앞발에 발생한 최대 수직지면반력 | `N` 또는 `BW` |
| Pose Estimation | 최대 런지 시 전방 무릎 굴곡각 MAE | 기준각과 Pose 추정각의 절대오차 평균 | `°` |

<br>

> ## **4-2 ) 연속형 변수에서는 표준편차가 필요하다**

연속형 변수에서는 MDE만으로 표본 크기를 결정하지 않는다.

예를 들어 펜싱에서

```text
MDE
= 런지 공격 완료시간 50 ms
```

라고 설정했다고 하자.

이때 선수들의 런지 공격 완료시간 표준편차가

```text
SD = 100 ms
```

라면 표준화 효과크기를 계산할 수 있다.

<br>

> ## **4-3 ) Cohen's d**

연속형 변수의 단순한 두 집단 비교에서는 다음과 같이 효과크기를 정의할 수 있다.

```text
            MDE
Cohen's d = ───
             SD
```

펜싱 예제에서는

```text
MDE = 50 ms

SD = 100 ms
```

이므로

```text
d
= 50 / 100
= 0.50
```

이다.

즉, 우리가 탐지하려는 차이가 데이터 표준편차의 `0.5배`라는 의미이다.

<br>

> ## **4-4 ) 펜싱 런지 공격 완료시간 표본 크기 계산**

실험 조건을 다음과 같이 설정해보자.

```text
Primary Metric
→ 런지 공격 완료시간

Baseline
→ 700 ms

MDE
→ 50 ms

SD
→ 100 ms

α
→ 0.05

Power
→ 0.80
```

[Python : code] "펜싱 런지 공격 완료시간의 필요 표본 계산"

```python
import math

from statsmodels.stats.power import TTestIndPower

mde = 50
std = 100

effect_size = mde / std

analysis = TTestIndPower()

sample_size = analysis.solve_power(
    effect_size=effect_size,
    alpha=0.05,
    power=0.80,
    ratio=1.0,
    alternative="two-sided"
)

sample_size = math.ceil(sample_size)

print(f"Cohen's d: {effect_size:.2f}")
print(f"그룹당 필요 선수: {sample_size}명")
print(f"전체 필요 선수: {sample_size * 2}명")
```

[ Result ]

```text
Cohen's d: 0.50
그룹당 필요 선수: 64명
전체 필요 선수: 128명
```

따라서 단순한 독립 2집단 설계에서는

```text
Control
→ 64명

Treatment
→ 64명

총
→ 128명
```

이 필요하다.

<br>

> ## **4-5 ) MDE에 따라 표본이 얼마나 달라질까?**

표준편차를 `100 ms`로 동일하게 유지하고 MDE만 변경해보자.

[Python : code] "펜싱 런지 공격 완료시간 MDE별 필요 표본 비교"

```python
import math

from statsmodels.stats.power import TTestIndPower

std = 100

analysis = TTestIndPower()

for mde in [80, 50, 30, 25]:

    effect_size = mde / std

    sample_size = analysis.solve_power(
        effect_size=effect_size,
        alpha=0.05,
        power=0.80,
        ratio=1.0,
        alternative="two-sided"
    )

    print(
        f"MDE {mde} ms"
        f" → 그룹당 {math.ceil(sample_size)}명"
    )
```

[ Result ]

```text
MDE 80 ms → 그룹당 26명
MDE 50 ms → 그룹당 64명
MDE 30 ms → 그룹당 176명
MDE 25 ms → 그룹당 253명
```

| MDE | Cohen's d | 그룹당 필요 선수 |
| ---: | ---: | ---: |
| 80 ms | 0.80 | 26명 |
| 50 ms | 0.50 | 64명 |
| 30 ms | 0.30 | 176명 |
| 25 ms | 0.25 | 253명 |

MDE가 작아질수록 필요한 표본이 빠르게 증가한다.

```text
큰 차이만 탐지
80 ms
→ 26명

더 작은 차이 탐지
25 ms
→ 253명
```

> ## **4-6 ) matplotlib으로 MDE와 표본 크기의 관계 확인**

```python

    20, 25, 30, 40,
    50, 60, 70, 80
]
```

# **5. 계산한 표본으로 실제 실험이 가능한가?**

> ## **5-1 ) 모집 가능한 선수 수 확인**

앞의 펜싱 실험에서는

```text
그룹당 64명

총 128명
```

이 필요했다.

한 주에 신규 선수 `16명`을 모집할 수 있다면

```text
128 / 16
= 8주
```

정도가 필요하다.

그렇다면 다음과 같은 문제를 함께 확인해야 한다.

```text
8주 동안
같은 측정 조건을 유지할 수 있는가?

대회 일정이 중간에 포함되는가?

선수들의 피로 상태가 변화하는가?

시즌 단계가 변화하는가?

카메라 위치와 Frame Rate를
동일하게 유지할 수 있는가?

같은 표적 거리와
같은 런지 시작 위치를 유지할 수 있는가?
```

표본 크기 계산의 목적은 단순히 숫자를 얻는 것이 아니라 **계획한 실험을 현실적으로 수행할 수 있는지 판단하는 것**이다.

<br>

> ## **5-2 ) MDE를 표본 수에 맞추기 위해 임의로 바꾸면 안 된다**

예를 들어

```text
MDE = 30 ms

→ 그룹당 176명
→ 총 352명
```

이 필요하다고 하자.

모집이 어렵다고 해서 아무런 근거 없이

```text
MDE = 100 ms
```

로 변경해서는 안 된다.

먼저

> **30 ms 정도의 차이가 실제 펜싱 경기 수행에서 중요한 차이인가?**

를 판단해야 한다.

```text
실제로 중요한 효과
        ↓
MDE 결정
        ↓
필요 표본 계산
```

이지,

```text
모집하기 편한 표본 수
        ↓
그에 맞게 MDE 변경
```

이 되어서는 안 된다.

<br>

> ## **5-3 ) 예상 탈락률**

최종 분석에 `128명`이 필요하다고 하자.

스포츠 연구에서는

```text
부상

훈련 불참

촬영 실패

센서 오류

Pose Keypoint 검출 실패

중도 탈락
```

등이 발생할 수 있다.

예상 탈락률이 `10%`라면

```text
필요 최종 표본
= 128명

예상 유지율
= 0.90

실제 모집 인원
= 128 / 0.90

≈ 143명
```

으로 모집 인원을 늘려야 한다.

따라서

```text
분석에 필요한 표본

≠

실제로 처음 모집해야 할 표본
```

일 수 있다.

# **6. A/B 테스트 전체 과정 실습**

> ## **6-1 ) 펜싱 Pose 피드백 실험 설계**

새로운 Pose 기반 런지 피드백 시스템을 개발했다고 생각해보자.

실험 목표는 다음과 같다.

> **Pose 기반 관절각도 피드백을 적용했을 때 펜싱 런지 공격 완료시간에 차이가 나타나는지 확인한다.**

목표 지표는 다음과 같이 정의한다.

```text
Primary Metric

런지 공격 완료시간(ms)
```

```text
Control
→ 기존 런지 기술 코칭
```

# **7. Pose Estimation 연구에서 표본 크기를 볼 때 주의할 점**

> ## **7-1 ) Frame 수와 선수 수는 다르다**

펜싱 선수 한 명의 런지 영상에서

```text
1,000 Frame
```

을 얻었다고 해서

```text
독립 표본
1,000개
```

라고 볼 수 없다.

```text
선수 1명
  ↓
런지 시도 1
  ↓
Frame 1
Frame 2
Frame 3
...
```

인접 Frame은 같은 선수의 같은 동작에서 나온 데이터이므로 강하게 관련되어 있다.

예를 들어

```text
선수 수
= 10명

선수당 런지
= 10회

런지당 Frame
= 100개
```

이면

```text
선수
= 10명

런지 시도
= 100회

Frame
= 10,000개
```

이지만

```text
독립 표본
= 10,000명
```

이라는 뜻은 아니다.

<br>

> ## **7-2 ) 실험 단위와 분석 단위**

반드시 다음을 구분해야 한다.

```text
실험 단위
→ 선수

반복 측정
→ 선수별 런지 시도

세부 시계열 데이터
→ 영상 Frame
```

동일한 선수에게서 여러 번 측정된 값은 서로 관련될 수 있으므로 실제 연구에서는

```text
반복측정 설계

혼합효과모형

선수별 요약값
```

> ## **8-2 ) 표본 크기 설계**

실험 전 기존 선수 자료를 확인한 결과 선수별 목표구역 적중률이 다음 정도라고 가정한다.

```text
Baseline 평균
→ 55%

선수 간 표준편차
→ 15%p
```

새로운 Pose 피드백으로 최소 `8%p` 정도의 차이는 탐지할 필요가 있다고 판단한다.

```text
Baseline
→ 55%

MDE
→ 8%p

탐지하려는 수준
→ 약 55% vs 63%

SD
→ 15%p

α
→ 0.05

Power
→ 0.80
```

여기서 `SD = 15%p`는 **선수별 목표구역 적중률의 표준편차**이다.

예를 들어

```text
선수 A
→ 45%

선수 B
→ 60%

선수 C
→ 70%

...
```

처럼 선수마다 적중률이 다르게 나타나는 변동성을 의미한다.

<br>

연속형 변수의 두 그룹 평균을 비교하므로 MDE를 표준편차로 나누어 Cohen's `d`를 계산할 수 있다.

```text
            MDE
Cohen's d = ───
             SD
```

이번 실험에서는

```text
d
= 8 / 15
≈ 0.53
```

이다.

[Python : code] "핸드볼 점프슛 목표구역 적중률 실험의 필요 표본 계산"

```python
import math

from statsmodels.stats.power import TTestIndPower

# ==========================================
# 1. 실험 설계 조건
# ==========================================

baseline = 55       # 기존 평균 적중률 (%)
mde = 8             # 탐지하려는 최소 차이 (%p)
std = 15            # 선수별 적중률 표준편차 (%p)

alpha = 0.05
power = 0.80

# ==========================================
# 2. 효과크기 계산
# ==========================================

effect_size = mde / std

print(
    "Cohen's d:",
    round(effect_size, 3)
)

# ==========================================
# 3. 필요한 표본 크기 계산
# ==========================================

analysis = TTestIndPower()

sample_size = analysis.solve_power(
    effect_size=effect_size,
    alpha=alpha,
    power=power,
    ratio=1.0,
    alternative="two-sided"
)

sample_size = math.ceil(sample_size)

print(
    "그룹당 필요 선수:",
    sample_size,
    "명"
)

print(
    "전체 필요 선수:",
    sample_size * 2,
    "명"
)
```

[ Result ]

```text
Cohen's d: 0.533

그룹당 필요 선수: 57명

전체 필요 선수: 114명
```

따라서 단순한 독립 2집단 설계를 가정하면

```text
Control
→ 57명

Treatment
→ 57명

총
→ 114명
```

의 선수가 필요하다.

> ## **8-5 ) Python으로 실험 설계부터 결과 검정까지 한 번에 진행**

아래 코드에서는

```text
실험 조건 설정
        ↓
효과크기 계산
        ↓
필요 표본 계산
        ↓
실험 결과 입력
        ↓
그룹 평균 차이 계산
        ↓
Welch 독립표본 t-검정
        ↓
p-value 해석
        ↓
MDE와 실제 관찰 차이 비교
```

를 하나의 흐름으로 진행한다.

[Python : code] "핸드볼 Pose 피드백 A/B 테스트의 실험 설계부터 결과검정까지 전체 과정"

```python
import math

from statsmodels.stats.power import TTestIndPower
from scipy import stats


# ==========================================
# 1. 실험 설계
# ==========================================

# Primary Metric
# 선수별 9m 점프슛 목표구역 적중률(%)

baseline = 55       # 기존 평균 적중률 (%)
mde = 8             # 최소 탐지 차이 (%p)
std = 15            # 선수 간 적중률 표준편차 (%p)

alpha = 0.05
power = 0.80


# ==========================================
# 2. 효과크기 계산
# ==========================================

effect_size = mde / std

print(
    "Cohen's d:",
    round(effect_size, 3)
)


# ==========================================
# 3. 필요한 표본 크기 계산
# ==========================================

analysis = TTestIndPower()

sample_size = analysis.solve_power(
    effect_size=effect_size,
    alpha=alpha,
    power=power,
    ratio=1.0,
    alternative="two-sided"
)

sample_size = math.ceil(sample_size)

print(
    "그룹당 필요 선수:",
    sample_size,
    "명"
)

print(
    "전체 필요 선수:",
    sample_size * 2,
    "명"
)


# ==========================================
# 4. 실험 결과
# ==========================================

# Control
control_mean = 55.2
control_std = 14.8
control_n = sample_size

# Treatment
treatment_mean = 64.1
treatment_std = 14.2
treatment_n = sample_size


# ==========================================
# 5. 관찰된 효과 계산
# ==========================================

difference = (
    treatment_mean
    - control_mean
)

relative_change = (
    difference
    / control_mean
    * 100
)

print(
    "\nControl 평균:",
    control_mean,
    "%"
)

print(
    "Treatment 평균:",
    treatment_mean,
    "%"
)

print(
    "절대 차이:",
    round(difference, 2),
    "%p"
)

print(
    "상대적 변화:",
    round(relative_change, 2),
    "%"
)


# ==========================================
# 6. Welch 독립표본 t-검정
# ==========================================

t_stat, p_value = stats.ttest_ind_from_stats(
    mean1=control_mean,
    std1=control_std,
    nobs1=control_n,

    mean2=treatment_mean,
    std2=treatment_std,
    nobs2=treatment_n,

    equal_var=False
)

print(
    "\nt 통계량:",
    round(t_stat, 3)
)

print(
    "p-value:",
    round(p_value, 4)
)


# ==========================================
# 7. 통계적 유의성 해석
# ==========================================

if p_value < alpha:

    print(
        "\n귀무가설을 기각합니다."
    )

    print(
        "두 그룹의 평균 목표구역 적중률에 "
        "차이가 있다는 통계적 근거가 있습니다."
    )

else:

    print(
        "\n귀무가설을 기각할 "
        "근거가 부족합니다."
    )


# ==========================================
# 8. MDE와 관찰 효과 비교
# ==========================================

if abs(difference) >= mde:

    print(
        "관찰된 차이는 사전에 설정한 "
        "MDE 이상입니다."
    )

else:

    print(
        "관찰된 차이는 사전에 설정한 "
        "MDE보다 작습니다."
    )
```

[ Result ]

```text

그룹당 필요 선수: 57명

전체 필요 선수: 114명


Control 평균: 55.2 %

Treatment 평균: 64.1 %

절대 차이: 8.9 %p

상대적 변화: 16.12 %


t 통계량: -3.276

p-value: 0.0014


귀무가설을 기각합니다.

두 그룹의 평균 목표구역 적중률에
차이가 있다는 통계적 근거가 있습니다.

관찰된 차이는 사전에 설정한
MDE 이상입니다.
```

> ## **8-7 ) Primary · Secondary · Guardrail Metric**

핸드볼 점프슛에서는 단순히 목표구역 적중률만 좋아졌다고 해서 새로운 훈련이 반드시 더 좋다고 판단할 수는 없다.

예를 들어 정확도가 증가했지만 공의 속도가 크게 감소한다면 실제 경기에서는 문제가 될 수 있다.

따라서 다음과 같이 여러 지표를 설정할 수 있다.

```text
Primary Metric

→ 선수별 9m 점프슛
   목표구역 적중률(%)
```

Primary Metric은 이번 실험에서 가장 중요하게 확인하려는 결과이다.

<br>

Secondary Metric은 **왜 적중률이 변화했는지 운동역학적으로 설명하는 보조 지표**로 사용할 수 있다.

```text
Secondary Metrics

① 공 릴리스 속도(km/h)

= 공이 슈팅 손에서
  완전히 떨어지는 순간의
  공 이동속도


② 공 릴리스 높이(cm)

= 공이 손에서 떨어지는 순간
  바닥에서 공 중심까지의
  수직거리


③ 릴리스 순간
   슈팅 팔 팔꿈치 신전각(°)

= 공이 손에서 떨어지는 Frame에서
  상완과 전완이 이루는 각도


④ 릴리스 순간
   몸통 전방 기울기각(°)

= 공이 손에서 떨어지는 Frame에서
  수직축과 몸통축이 이루는 각도


⑤ 마지막 스텝 착지부터
   공 릴리스까지의 소요시간(ms)

= 마지막 발이 지면에 접촉한 시점부터
  공이 손에서 떨어지는 시점까지의 시간
```

Guardrail Metric은 **주요 지표를 개선하는 과정에서 다른 중요한 성능이 나빠지지 않았는지 확인하는 지표**이다.

```text
Guardrail Metrics

① 골대 안 유효 슈팅 비율(%)

= 전체 슈팅 중
  골대 프레임 안으로 들어간
  슈팅의 비율


② 평균 공 릴리스 속도(km/h)

→ 정확도 향상을 위해
   공 속도가 지나치게 감소하지 않았는지 확인


③ 슈팅 동작 완료시간(ms)

= 마지막 스텝 착지부터
  공 릴리스까지 걸린 시간
```

예를 들어 Pose 피드백 이후

```text
목표구역 적중률

55% → 66%

+11%p
```

로 좋아졌다고 하자.

하지만 동시에

```text
공 릴리스 속도

82 km/h → 70 km/h

-12 km/h
```

가 되었다면 단순히 훈련이 성공했다고 판단하기 어렵다.

반대로

```text
목표구역 적중률
+11%p

공 릴리스 속도
거의 동일

슈팅 동작 완료시간
거의 동일
```

하다면 정확도를 높이면서 기존 슈팅 수행 특성을 크게 손상시키지 않았다고 해석할 근거가 더 강해진다.

전체적으로는 다음과 같이 생각할 수 있다.

```text
Primary Metric

정확도가 좋아졌는가?
        ↓
목표구역 적중률


Secondary Metrics

어떤 동작 변화 때문에
정확도가 달라졌는가?
        ↓
릴리스 높이
팔꿈치 신전각
몸통 기울기각
릴리스 속도


Guardrail Metrics

정확도를 높이는 과정에서
다른 중요한 수행능력이
나빠지지는 않았는가?
        ↓
공 속도
유효 슈팅 비율

```

# **10. Advanced 추가 학습**

> ## **10-1 ) MDE와 표본 크기의 제곱 관계**

단순한 평균 비교에서 다른 조건이 일정하다면 필요한 표본은 대략

```text
필요 표본
∝ 1 / 효과크기²
```

의 관계를 가진다.

따라서 효과크기가 절반 수준으로 작아지면 필요한 표본은 크게 증가한다.

```text
MDE ↓
        ↓
효과크기 ↓
        ↓
필요 표본 급증
```

다만 비율형 지표처럼 Baseline 자체가 분산에 영향을 주는 경우에는 정확한 표본 크기를 Python 등의 방법으로 계산하는 것이 좋다.

<br>

> ## **10-2 ) 단측검정과 양측검정**

예제에서는

```python
alternative="two-sided"
```

를 사용했다.

즉,

```text
Treatment가 더 빠름

또는

Treatment가 더 느림
```

두 방향을 모두 고려한다.

연구 가설상 단측검정이 필요한 경우도 있지만 **실험 결과를 본 뒤 유리한 방향으로 단측검정으로 변경해서는 안 된다.**

<br>

> ## **10-3 ) 반복측정 설계**

같은 선수가 A와 B를 모두 수행한다면

```text
선수 1
→ A 조건
→ B 조건
```

이므로 독립된 두 집단 설계와 다르다.

이 경우에는

```text
개인 내 차이
순서효과
피로효과
학습효과
Carryover Effect
```

를 함께 고려해야 하며 검정력 분석 역시 실제 실험 설계에 맞게 수행해야 한다.

# **11. 핵심정리**

> ## **11-1 ) MDE**

MDE는

> **설정한 유의수준과 검정력에서 탐지하고자 하는 최소 효과의 크기**

이다.

```text
Baseline
→ 현재 수준

MDE
→ 최소한 탐지하고 싶은 차이
```

펜싱 예시에서는

```text
Baseline
→ 런지 공격 완료시간 700 ms

MDE
→ 50 ms

탐지하려는 수준
→ 약 700 ms vs 650 ms
```

와 같이 정의할 수 있다.

<br>

> ## **11-2 ) 유의수준과 검정력**

```text
α
→ 제1종 오류와 관련

실제로 차이가 없는데
차이가 있다고 판단
```

```text
β
→ 제2종 오류와 관련

실제로 차이가 있는데
발견하지 못함
```

```text
Power = 1 - β

→ 실제 MDE 정도의 효과가 존재할 때
   이를 발견할 확률
```

<br>
