# [ 1. Linear Regression: Simple / Multiple Linear Regression ]

> ### 선형회귀(Linear Regression)

입력값 `X`와 출력값 `y` 사이의 **선형 관계를 학습하는 회귀 모델.**

기본식:

```text
ŷ = wx + b
```

* `x` : 입력값
* `w` : 가중치(Weight)
* `b` : 절편(Bias)
* `ŷ` : 예측값

---

### 1) Simple Linear Regression (단순 선형회귀)

**Feature 1개를 사용하여 Target 예측.**

예:

```text
공부시간 → 시험점수
광고비 → 매출
면적 → 집값
```

식:

```text
ŷ = wx + b
```

Python:

```python
from sklearn.linear_model import LinearRegression

model = LinearRegression()

model.fit(X_train, y_train)

y_pred = model.predict(X_test)
```

가중치와 절편 확인:

```python
print(model.coef_)       # Weight
print(model.intercept_)  # Bias
```

> ### 2) Multiple Linear Regression (다중 선형회귀)

**Feature 여러 개를 사용하여 Target 예측.**

예:

```text
면적
방 개수
건물 연식
역과의 거리
        ↓
      집값
```

식:

```text
ŷ = w₁x₁ + w₂x₂ + w₃x₃ + ... + b
```

행렬 표현:

```text
ŷ = XW + b
```

Python:

```python
from sklearn.linear_model import LinearRegression

model = LinearRegression()

model.fit(X_train, y_train)

y_pred = model.predict(X_test)
```

Feature별 Weight 확인:

```python
print(model.coef_)
print(model.intercept_)
```

핵심:

```text
Simple Linear Regression
→ Feature 1개

Multiple Linear Regression
→ Feature 2개 이상
```

# [ 2. 선형회귀모델 학습방법 ]

> ## 1) Loss Function (손실함수)
- 모델의 예측값과 실제값이 얼마나 차이 나는지 수치로 나타내는 함수
- 회귀에서는 일반적으로 `MSE`를 손실함수로 사용
- 손실함수의 값이 클수록 오차가 크고, 값이 작으면 오차가 작다는 의미
- 손실함수의 값을 최소화 하는 방향으로 모델을 학습시켜야 함 
- loss의 gradient 반대 방향으로 증가시키도록 시도?

```python
y_true = np.array([100, 150, 200, 250]) # 실제값

model_a = np.array([110, 145, 195, 260]) # a 모델의 예측값
model_b = np.array([120, 130, 220, 230]) # b 모델의 예측값

mse_a = np.mean((y_true - model_a) ** 2)
mse_b = np.mean((y_true - model_b) ** 2)

print(f"모델 A MSE: {mse_a:.2f}")
print(f"모델 B MSE: {mse_b:.2f}")

if mse_a < mse_b:
    print("모델 A의 Loss가 더 작습니다.")
else:
    print("모델 B의 Loss가 더 작습니다.")
```

> ## 2) Least Squared Method (최소제곱법)

- `SSE`가 가장 작아지도록 모델의 파아미터를 계산하는 방법
- 미분을 이용해 최적의 해를 수식으로 한 번에 계산

<hr style="border: 2px solid gray;">


- ### **유도**   
    ### 1. 표기 정의

```math
x=
\begin{bmatrix}
x_1\\
x_2\\
\vdots\\
x_n\\
1
\end{bmatrix}
```

```math
W=
\begin{bmatrix}
w_1\\
w_2\\
\vdots\\
w_n\\
b
\end{bmatrix}
```

입력 데이터의 마지막 원소를 항상 1로 두면 bias b도 하나의 파라미터와 같이 행렬 연산에 포함할 수 있다.

---

- **Simple Linear Regression**
```math
 \hat{y}=f(x)=W^Tx 
 ```

- **Multiple Linear Regression**
```math
\hat{y} = w_1x_1+w_2x_2+\cdots+w_nx_n+b 
```

---

전체 데이터가 m개인 경우 입력 데이터 X와 예측결과를 다음과 같이 표기 할 수 있다.

```math
X=
\begin{bmatrix}
x_{11}&x_{12}&\cdots&x_{1n}&1\\
x_{21}&x_{22}&\cdots&x_{2n}&1\\
\vdots&\vdots&\ddots&\vdots&\vdots\\
x_{m1}&x_{m2}&\cdots&x_{mn}&1
\end{bmatrix}
```

```math
\hat{Y}=XW
```

---

Least Squared Method의 목적은 실제 정답과 예측값 사이의 SSE를 최소화하는 파라미터를 찾는 것으로 다음과 같이 표현한다.

```math
\min_W ||Y-XW||^2 
```

```math
\min_W (Y-XW)^T(Y-XW) 
```

---

### 2. 식 전개

목적식을 전개하면 다음과 같이 표현할 수 있다.

```math
(Y-XW)^T(Y-XW) 
```

```math
=Y^TY - 2Y^TXW + W^TX^TXW 
```

---

목적식을 W에 대해 미분한 후 최솟값이 0이 되는 지점을 찾으면 다음과 같다.

```math
\frac{\partial}{\partial W}
\left(
(Y-XW)^T(Y-XW)
\right)
=
2X^TXW
-
2X^TY
=
0
```

```math
X^TXW=X^TY 
```

---

### 3. Closed-form Solution
- 해를 수식으로 직접 구하는 방법
- 최적의 해를 구하는 것이기 때문에 역행렬이 존재하는 경우에만 사용 가능
- feature의 개수가 많아지면 역행렬 계산 비용이 많아지기 때문에 사용하기 어려움  
-> 경사하강법 사용

X^TX의 역행렬이 존재할 경우 양 변에 역행렬을 곱해 최적의 파라미터 W는 다음과 같습니다. 

```math 
W=(X^TX)^{-1}X^TY 
```

> # <span style="color:steelblue">**2) Gradiant Descent (경사하강법)**</span>

- 손실함수의 값을 최소화하는 방향으로 모델의 파라미터를 업데이트하며 최적의 파라미터를 찾는 반복적인 최적화 알고리즘
- 손실함수가 증가하는 방향인 Gradiant를 계산한 뒤, 반대방향으로 일정한 크기만큼 이동하는 과정을 반복하여 손실을 최소화해감

- learning_rate : 한 번 parameter 업데이트 할때 얼마만큼 크게 움직일건지
- epoch : 전체 데이터를 한번 학습에 사용하는 단위

```python
import numpy as np

x = np.array([1.0, 2.0, 3.0, 4.0]) # 운동시간
y = np.array([15.0, 20.0, 25.0, 30.0]) # 칼로리

weight = 0.0
bias = 0.0

learning_rate = 0.05 # 학습률
epochs = 1000 # 학습량(에포크)

n = len(x)

for epoch in range(epochs):
    y_pred = weight * x + bias

    error = y_pred - y
    loss = np.mean(error ** 2)

    weight_gradient = (2 / n) * np.sum(error * x)
    bias_gradient = (2 / n) * np.sum(error)

    weight = weight - learning_rate * weight_gradient
    bias = bias - learning_rate * bias_gradient

print(f"Weight: {weight:.2f}")
print(f"Bias: {bias:.2f}")
print(f"Loss: {loss:.4f}")
```

- ### **적용과정**

### 1. Loss Function 정의

선형회귀에서는 일반적으로 MSE를 손실함수로 사용한다.

```math
L(W) =\frac1N\sum_{i=1}^{N} (y_i-\hat y_i)^2 
 ```

```math
L(W) = \frac1N \|Y-XW\|^2
```

---

### 2. Gradient 계산
손실함수를 파라미터 `W`에 대해 미분하면 다음과 같은 Gradient를 얻는다.

```math 
\nabla_WL=\frac{2}{N}X^T(XW-Y) 
```

---

### 3. 파라미터 업데이트

손실을 줄이기 위해 Gradient의 **반대방향**으로 파라미터를 업데이트한다.   

여기서 `η`는 `Learning Rate`로, 한 번에 파라미터를 얼마나 업데이트 할 지를 결정하는 값이다.

```math
W^{(t+1)} = W^{(t)} - \eta \nabla_WL
```

```math
W^{(t+1)} = W^{(t)} - \eta \frac{2}{N} X^T(XW-Y)
```
---

### 4. 반복 수행

위 과정을 미리 정한 `횟수(Epoch)`만큼 반복하거나, `Loss`가 충분히 작아질 때까지 반복한다.   

반복이 진행될수록 `손실함수는 감소`하고, `파라미터는 손실을 최소화`하는 값으로 수렴하여 모델을 최적화 한다.

```math
{W^{(t+1)}=W^{(t)}-\eta\frac{2}{N}X^T(XW-Y)}
```

<hr style="border: 2px solid gray;">

|용어|의미|
|---|---|
|Parameter 	|학습의 대상이 되는 값 (ex: Weight, bias)|
|Optimizer	|Gradient 기반 파라미터를 업데이트 할 때 사용하는 알고리즘 (ex: SGD)|
|Gradient	|현재 위치에서 손실함수(Loss)가 가장 빠르게 증가하는 방향과 크기를 나타내는 벡터|
|Learning Rate	|파라미터를 한 번에 얼마나 크게 업데이트할지 결정하는 값|
|Epoch	|전체 데이터를 한 번 학습에 사용하는 단위|
수렴	|파라미터 업데이트 시 손실이 거의 감소하지 않고 유지되는 상태

### [ 학습률 설정 ]
| 학습률 크기 | 특징 |

### `Gradient`
- Loss function이 가장 빠르게 증가하는 방향을 나타낸다 

- 따라서 Gradient의 반대 방향으로 파라미터를 조금씩 업데이트하면 손실이 감소한다.

- 이 과정을 반복하면 손실은 점점 작아지고, 더 이상 크게 감소하지 않는 지점으로 수렴하게 된다.

- 즉, Gradient의 반대 방향으로 조금씩 이동하는 과정을 반복하여 손실을 최소화한다.

# [ 3. 회귀 평가지표: MSE, MAE, RMSE ]

> ## MSE (Mean Squared Error, 평균제곱오차)

`MSE = (1/n) × Σ(y - ŷ)²`

> ## MAE (Mean Absolute Error, 평균절대오차)

`MAE = (1/n) × Σ|y - ŷ|`

> ## RMSE (Root Mean Squared Error, 평균제곱근오차)

`RMSE = √MSE`


[python : code]

```python
import numpy as np
from sklearn.metrics import mean_squared_error, mean_absolute_error

y_true = np.array([3.0, 5.0, 7.0, 9.0]) # 실제값
y_pred = np.array([2.8, 5.2, 6.5, 9.3]) # 예측값

mse = mean_squared_error(y_true, y_pred)
mae = mean_absolute_error(y_true, y_pred)
rmse = np.sqrt(mse)

print(f"MSE:  {mse:.4f}")
print(f"MAE:  {mae:.4f}")
print(f"RMSE: {rmse:.4f}")
```

[result]

```text
MSE:  0.1050
MAE:  0.3000
RMSE: 0.3240
```

- MSE가 크면 오차값이 클 가능성 존재
