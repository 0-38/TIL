# [ 1. GLM과 로지스틱 회귀 ]


## 일반화 선형 모델 (Generalized Linear Model, GLM)
- 선형 회귀를 더 다양한 데이터에 적용할 수 있도록 일반화 한 모델의 모음
- 선형결합의 결과를 링크 함수(Link Function)를 통해 정답의 특성에 맞는 형태로 변환하여 데이터에 선형모델을 적용할 수 있게 한다.


<br>

## 로지스틱 회귀 (Logistic Regression)

- 범주를 예측하는 모델
- **분류 (Classification)** 모델
- 각 클래스에 속할 확률을 추정하여 분류를 수행하는 모델

- 실제 용도 → **분류 모델.**

- 예:

    ```text
    구매 / 미구매
    정상 / 이상
    합격 / 불합격
    암 / 천식 / 비만
    ```

#### [ python: code ]
```python
import numpy as np
from sklearn.linear_model import LogisticRegression

X = np.array([
    [1],
    [3],
    [5],
    [10],
    [15],
    [20]
])

y = np.array([0, 0, 0, 1, 1, 1])

model = LogisticRegression() # 로지스틱 회귀 모델 객체 생성
model.fit(X, y) # 모델에 학습

new_customer = np.array([[12]]) 

probability = model.predict_proba(new_customer) # 예측 확률
prediction = model.predict(new_customer) # 예측값

print("유지 확률:", round(probability[0][0], 3))
print("이탈 확률:", round(probability[0][1], 3))
print("예측 클래스:", prediction[0])
```

#### [ Result ]

```text
유지 확률: 0.032
이탈 확률: 0.968
예측 클래스: 1
```

# [ 2. Logit, Sigmoid, Softmax ]

## 2-1) 시그모이드 함수 (Sigmoid Function)

```math
\sigma(z) = \frac{1}{1 + e^{-z}}
```

- 실수를 입력받아 0과 1 사이의 값으로 변환하는 함수

- 선형식의 결과 (Logit)를 Sigmoid 함수에 입력하여 0과 1 사이의 값으로 변환

#### [ python : code ]

```python
import numpy as np

z = 1.5     # 모델의 선형식에서 계산한 값이 이와 같다고 가정

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

logit = 1.5
probability = sigmoid(logit)

print("Logit:", logit)
print("취소 확률:", round(probability, 3))
```

#### [ Result ]
```
Logit: 1.5
취소 확률: 0.818
```
<br>

## 2-2) 로짓 (Logit)

```math
\operatorname{logit}(p)
=
\log\left(\frac{p}{1-p}\right)
=
\mathbf{w}^\top\mathbf{x}+b
```
- 0과 1 사이의 확률을 실수 전체 범위(-∞~∞)로 변환하는 함수

-  Sigmoid의 역함수

- 확률 변환 전 단계의 값

- `Logit (Log-Odds)` : 확률 p에 대해 오즈(Odds) p / 1-p에 로그를 취한 값

- 확률 자체를 선형으로 모델링하는 것이 아닌,  
확률을 Logit으로 변환한 값을 선형 모델로 표현한 뒤  
-> 마지막에 Sigmoid 함수를 적용하여 다시 확률로 변환

#### [ python : code ]
```python
import numpy as np

def logit_numpy(p):
    p = np.asarray(p)
    
    # 0 또는 1 입력 시 분모가 0이 되거나 로그 오류가 나는 것을 방지
    p = np.clip(p, 1e-15, 1 - 1e-15)
    
    return np.log(p / (1 - p)) # logit = 시그모이드에 log를 취함 

# 사용 예시
probabilities = [0.2, 0.5, 0.8]
print(logit_numpy(probabilities))
```

#### [ Result ]
```
[-1.38629436  0.          1.38629436]
```

<br>

## 2-3) 소프트맥스 함수 (Softmax Function)

```math
P(y=i)
=
\frac{e^{z_i}}
{\sum_{j=1}^{K}e^{z_j}}, \sum_{i=1}^{K}P(y=i)=1
```

- 입력값에 대해 각 클래스별 확률을 계산해주는 함수

- 결과의 합은 반드시 `1`이어야 함

- 주로 다중분류에서 각 클래스에 속할 확률로 사용  

    -> **최종 예측은 계산된 확률 중 가장 큰 값을 가진 클래스를 선택**

#### [ python : code ]
```python
import numpy as np

logits = np.array([1.0, 2.5, 0.5]) # 추천 모델이 고객에게 세 상품 카테고리에 대해 다음과 같은 값을 출력했다고 가정

exp_logits = np.exp(logits)
probabilities = exp_logits / np.sum(exp_logits)

prediction = np.argmax(probabilities)

print("각 클래스 확률:", np.round(probabilities, 3))
print("예측 클래스:", prediction)
print("확률의 합:", round(probabilities.sum(), 3))
```

#### [ Result ]
```text
각 클래스 확률: [0.164 0.736 0.1]
예측 클래스: 1
확률의 합: 1.0
```

# [ 3. Binomial vs Multinomial Logistic Regression ]

## 3-1) 이항 로지스틱 회귀 (Binomial Logistic Regression)

- **예측해야 하는 변수가 2개**일 때 사용 (클래스가 2개)

- Binary Classification ; **이진 분류**

    ```text
    0 = 유지
    1 = 이탈
    ```

<br>

## 3-2) 다항 로지스틱 회귀 (Multinomial Logistic Regression)

- **예측해야 하는 변수가 3개 이상**일 때 사용 (클래스가 3개 이상)

- Multi-class Classification ; **다중 분류**


    ```
    0 = 암
    1 = 천식
    2 = 비만
    ```

|구분|	Binomial Logistic Regression|	Multinomial Logistic Regression|
|---|---|---|
|범주 개수|	2개 |	3개 이상 |
|사용하는 함수|	`Sigmoid`|	`Softmax`|
|출력 형태|	하나의 확률값|	각 범주별 확률(합이 1)|
|예측 방법|	확률이 기준값 (0.5)이상이면 양성|	확률이 가장 큰 class 선택|

# [ 5. Loss Function - 분류 모델]

- 분류 모델은 모델이 각 클래스에 속할 확률을 계산

- 확률을 계산하기 위해 Crorss Entoropy Loss (손실함수)를 사용

- 정답 클래스에 높은 확률을 예측하면 손실이 작아지고,  
정답 클래스에 낮은 확률로 예측하면 손실이 크게 증가 

#### 1. 이진 분류 

```math
L = -\left(y \log(\hat{y}) + (1-y)\log(1-\hat{y})\right)
```

#### 2. 다중 분류

```math
L = -\sum_{i=1}^{K} y_i \log(\hat{y}_i)
```

> ## [ Cross Entropy & Maximum Likelihood Estimation ]

### 1. **M**aximum **L**ikelihood **E**stimation (최대우도법)

> **관측된 데이터가 나올 확률을 가장 크게 만드는 모델의 Parameter를 찾는 방법.**

예를 들어 고양이 사진의 실제 정답이 `고양이`일 때:

```text
Model A
고양이 확률 = 0.9

Model B
고양이 확률 = 0.2
````

실제 정답이 고양이이므로:

```text
0.9를 예측한 Model A
→ 실제 데이터가 나올 가능성을 더 높게 예측
```

즉 최대우도법의 목표:

```text
실제 정답이 발생할 확률
→ 최대화
```

수식:

$$
L(\theta)
=
P(Data \mid \theta)
$$

* $L(\theta)$ : Likelihood
* $\theta$ : 모델의 Parameter
* 목표 → $L(\theta)$ 최대화

<br>

## 2. Log Likelihood

여러 데이터의 확률은 곱셈으로 계산.

```text
0.9 × 0.8 × 0.7 × ...
```

데이터가 많아지면 값이 매우 작아질 수 있음.

따라서 `log` 사용.

$$
\log L(\theta)
$$

곱셈을 덧셈으로 변환:

$$
\log(a \times b)
=
\log a + \log b
$$

즉:

```text
Likelihood 최대화

=

Log-Likelihood 최대화
```

<br>


## 3. Cross Entropy

> **실제 정답과 모델이 예측한 확률의 차이를 측정하는 Loss Function.**

분류 문제에서 주로 사용.

예:

실제 정답:

```text
고양이
```

### 좋은 예측

```text
고양이 = 0.9
강아지 = 0.1
```

→ Cross Entropy 작음.

### 나쁜 예측

```text
고양이 = 0.1
강아지 = 0.9
```

→ Cross Entropy 큼.

즉:

```text
실제 정답의 예측 확률 ↑
→ Loss ↓

실제 정답의 예측 확률 ↓
→ Loss ↑
```

<br>


## 4. Binary Cross Entropy

이진 분류에서 사용.

예:

```text
구매 / 미구매
합격 / 불합격
정상 / 이상
```

수식:

$$
-\left[
y\log(p)
+
(1-y)\log(1-p)
\right]
$$

* $y$ : 실제 정답 (`0` 또는 `1`)
* $p$ : 모델이 예측한 확률

실제 정답이 `1`이면:

$$
-\log(p)
$$

예:

```text
정답 = 1

예측 확률 = 0.9
→ Loss 작음

예측 확률 = 0.1
→ Loss 큼
```

<br>


## 5. Cross Entropy와 최대우도법의 관계

두 개념은 서로 연결.

```text
Maximum Likelihood

실제 정답의 확률을
최대한 크게 만들기
```

반면:

```text
Cross Entropy

실제 정답의
Negative Log Probability를
최대한 작게 만들기
```

즉:

$$
Likelihood\ 최대화
$$

와

$$
Negative\ Log\ Likelihood\ 최소화
$$

는 같은 방향의 최적화.

분류 문제에서는 이 Negative Log-Likelihood가
Cross Entropy와 연결.

---

## 핵심 정리

```text
Maximum Likelihood Estimation
→ 실제 데이터가 나올 확률을 최대화
```

```text
Cross Entropy
→ 실제 정답의 예측 확률이 낮을수록 큰 Loss
```

```text
Likelihood ↑
=
Log-Likelihood ↑
=
Negative Log-Likelihood ↓
=
Cross Entropy ↓
```

### 한 줄 정리

> **최대우도법은 정답이 나올 확률을 크게 만드는 방법**,   
**Cross Entropy는 정답 확률이 낮을수록 큰 벌점을 주는 Loss Function.**
