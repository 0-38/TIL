# **[ 1. Confusion Matrix (혼동행렬) ]**

- 분류모델의 예측 결과와 실제 정답을 비교하여 정리한 표

<br>

- `TP` (True Positive) : 스팸 메일을 스팸으로 올바르게 분류한 경우
- `FP` (False Positive) : 정상 메일을 스팸으로 잘못 분류한 경우
- `FN` (False Negative) : 스팸 메일을 정상 메일로 잘못 분류한 경우
- `TN` (True Negative) : 정상 메일을 정상 메일로 올바르게 분류한 경우


<br><br>

# **[ 2. 정확도, 정밀도, 재현율, F1-score ]**

> ## 2-1) 정확도 (Accuracy)

```math
\mathrm{Accuracy}
=
\frac{TP+TN}{TP+TN+FP+FN}
```

- 전체 예측 중 올바르게 예측한 비율


> ## 2-2) 정밀도 (Precision)

```math
\mathrm{Precision}
=
\frac{TP}{TP+FP}
```

- 양성(1)이라고 예측한 것 중 실제 양성(1)인 비율

- `All Predicted 1 -> Actual 1`

> ## 2-3) 재현율 (Recall)

```math
\mathrm{Recall}
=
\frac{TP}{TP+FN}
```

- 실제 양성 중 모델이 양성으로 올바르게 찾아낸 비율

- `All Actual 1 -> Predict 1` 

> ## 2-4) F1-score
```math
F_1
=
\frac{2 \times \mathrm{Precision} \times \mathrm{Recall}}
{\mathrm{Precision}+\mathrm{Recall}}

```

- 정밀도와 재현율의 조화평균

- 정밀도와 재현율의 두 지표가 모두 높아야 높은 값을  가짐

- -> `Recall 과 Precision은 Trade-off 관계`


### [ 분류모델의 성능 지표를 사용하는 시점 ]
|지표|	답하는 질문|	언제 중요한가|중요한 업무 분야|
|---|---|---|---|
|`정확도 (Accuracy)`|	전체 예측 중 얼마나 맞추었는가?|	클래스 비율이 균형 잡혀 있을 때|
|`정밀도 (Precision)`|	양성이라고 예측한 것 중 실제 양성은 얼마나 되는가?|	거짓 양성(FP)의 비용이 클 때|의료 (암 예측)|
|`재현율 (Recall)`|	실제 양성 중 얼마나 찾아냈는가?|	거짓 음성(FN)의 비용이 클 때|
|`F1-score`|	정밀도와 재현율의 균형은 어떠한가?|	정밀도와 재현율이 모두 중요하거나 클래스가 불균형할 때|


### [ python : code ]
```python
from sklearn.metrics import (accuracy_score, precision_score, recall_score, f1_score)

# 1: 이상 거래, 0: 정상 거래
y_true = [0, 0, 0, 1, 0, 1, 0, 0, 1, 0] # Actual
y_pred = [0, 0, 0, 1, 0, 0, 0, 1, 1, 0] # Predicted

print("Accuracy:", accuracy_score(y_true, y_pred)) # 정확도
print("Precision:", precision_score(y_true, y_pred)) # 정밀도
print("Recall:", recall_score(y_true, y_pred)) # 재현율
print("F1-score:", f1_score(y_true, y_pred)) # F1-score
```

#### [Result]
```text
Accuracy: 0.8  # 전체 거래 중 80%를 올바르게 분류
Precision: 0.6666666666666666  # 모델이 이상 거래라고 판단한 거래 중 약 66.7%가 실제 이상 거래
Recall: 0.6666666666666666  # 실제 이상 거래 중 약 66.7%를 찾아냈다
F1-score: 0.6666666666666666  # Precision과 Recall을 함께 고려하여 두 지표의 균형을 확인
```

# **[ 3. ROC Curve와 AUC ]**

## Threshold(한계점)

- 임계값 : Feature를 두 그룹으로 나누기 위해 사용하는 값   
    -> 구매액이 10만원과 20만원이 있다면 약 15만원 임계값으로 사용 가능


> ## 3-1) ROC (Receiver Operating Characteristic) Curve

- Threshold을 변화시키면서 재현율(True Positive Rate)과 거짓 양성 비율(False Positive Rate)이 어떻게 변하는지를 나타낸 그래프

<br>

> ## 3-2) AUC(Area Under the Curve)
- ROC 곡선 아래의 면적을 의미 

- 값이 1에 가까울수록 양성과 음성을 더 잘 구분하는 모델

- 값이 0.5이하면 무작위로 예측하는 것과 비슷


#### [ python : code ]
```python
# AUC 값 도출 코드

from sklearn.metrics import roc_auc_score

# 1: 이탈, 0: 유지
y_true = [0, 0, 1, 1, 0, 1, 0, 1]

model_a_prob = [0.1, 0.2, 0.8, 0.9, 0.3, 0.7, 0.4, 0.85]
model_b_prob = [0.3, 0.4, 0.6, 0.7, 0.5, 0.55, 0.45, 0.65]

auc_a = roc_auc_score(y_true, model_a_prob)
auc_b = roc_auc_score(y_true, model_b_prob)

print("모델 A AUC:", auc_a)
print("모델 B AUC:", auc_b)
```

#### [ Result ]
```text
모델 A AUC: 1.0
모델 B AUC: 1.0
```

#### [ python : code ] ROC-AUC Curve 시각화 코드

```python
# ROC-AUC Curve 시각화 코드

from sklearn.metrics import roc_curve, roc_auc_score
import matplotlib.pyplot as plt

# 1. 데이터 준비
# 실제 정답
y_test = [0, 0, 1, 1, 0, 1, 0, 1, 1, 0]

# 모델이 예측한 "1일 확률"
y_pred_proba = [0.10, 0.30, 0.80, 0.70, 0.20, 0.90, 0.40, 0.75, 0.85, 0.25]


# 2. ROC Curve 계산
fpr, tpr, thresholds = roc_curve(y_test, y_pred_proba)


# 3. AUC 계산
auc_score = roc_auc_score(y_test, y_pred_proba)

print("AUC:", round(auc_score, 3))


# 4. ROC Curve 시각화
plt.figure(figsize=(8, 6))

# ROC 곡선
plt.plot(fpr,tpr,marker='o',label=f'ROC Curve (AUC = {auc_score:.3f})')

# 랜덤 분류 기준선
plt.plot([0, 1], [0, 1], linestyle='--', label='Random')

plt.xlabel('False Positive Rate')
plt.ylabel('True Positive Rate')
plt.title('ROC Curve')

plt.legend()
plt.grid()

plt.tight_layout()
plt.show()
```
#### [ Result ]
```text
AUC = 1.0
```

# **[ 4. 데이터 불균형 시 지표 선택 기준 ]**


#### [ python : code ]

```python
# 사기 거래가 1%뿐인 데이터에서 정확도 해석하기

from sklearn.metrics import accuracy_score
from sklearn.metrics import recall_score

# 정상 거래 99건 + 사기 거래 1건
y_true = [0] * 99 + [1]

# 모든 거래를 정상으로 예측
y_pred = [0] * 100

accuracy = accuracy_score(y_true, y_pred)
recall = recall_score(y_true, y_pred)

print("Accuracy:", accuracy)
print("Recall:", recall)
```

#### [ Result ]
```text
Accuracy: 0.99
Recall: 0.0
```

#### [코드 결과 해석]
```
- Accuracy만 보면 99%로 성능이 좋은 모델로 판단하게 된다.

- 하지만 Recall은 0이므로 실제 사기 거래를 한 건도 찾아내지 못했다.

- 이처럼 클래스 비율이 크게 차이 나는 불균형 데이터에서는 Accuracy 하나만 보고 모델을 평가하면 잘못된 결론을 내릴 수 있다.

- 따라서, 봐야할 중요한 오류를 먼저 생각하고 Precision, Recall, F1-score 등의 지표를 선택해야 한다.
```

- ### **불균형 데이터셋(Imbalanced Dataset)에서 성능 판단 방법**

    - 불균형 데이터에서는 높은 Accuracy가 반드시 좋은 모델을 의미하지 않으며, 모델의 성능을 과대평가할 수 있다.

    - 실제 Positive를 놓치는 FN이 중요한 문제에서는 Recall을 중요하게 확인한다.

    - FP가 중요한 문제에서는 Precision을 중요하게 확인해야한다.

    - 문제 목적에 따라 F1-score와 AUC 등의 지표도 함께 활용한다.

<br>

|상황|	우선 볼 지표|	이유|
|---|---|---|
암·질병 진단|	Recall|	실제 암·질병을 판단하지 못했을 때의 비용이 크다|
스팸·불량 필터|	Precision|	정상에 해당하는 것을 비정상이라 분류한 경우의 비용이 크다 |
