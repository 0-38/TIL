# [ 1. 군집화 (Clustering / K-Means Algorithm) ]

> ## 1-1. Clustering ; 클러스터링

- 비슷한 특징을 가진 데이터를 유사성을 기준으로 하나의 그룹으로 묶는 작업


<br>

> ## 1-2. K-Means

- 데이터를 미리 지정한 K개의 군집으로 나누어 군집간 패턴을 분석하는 알고리즘

- Clustering 기반의 군집 분석 알고리즘

- `K` = 군집의 개수 (하이퍼파라미터)


- ### **동작 원리**  
**1. 중심점 초기화**  
- K개의 중심점을 데이터 공간에 임의로 배치

**2. Cluster 할당**
 - 각 데이터를 거리 기준으로 가장 가까운 중심점의 군집(Cluster)에 할당

 - 유클리드(Euclidean) 거리를 사용하여 거리 계산

```math
d(x, y) = \sqrt{\sum_{i=1}^{n}(x_i - y_i)^2}
```

**3. 중심점 갱신**
 - 각 군집에 속한 데이터들의 평균 위치(Means)를 새로운 중심점으로 계산

**4. 반복**
 - 중심점의 위치가 거의 변하지 않을 때까지 2~3단계 반복

#### **[K-Means 알고리즘]**

#### [ python : code] **K-Means 학습 방법** 
```python
import pandas as pd
from sklearn.cluster import KMeans

customers = pd.DataFrame({
    "visit_count": [
        1, 2, 3,
        7, 8, 9,
        15, 16, 18
    ],
    "monthly_spend": [
        10, 15, 20,
        70, 80, 90,
        180, 200, 220
    ]
})

model = KMeans(n_clusters=3, random_state=42, n_init=10) # KMeans 모델 생성
# n_clusters = 군집 개수

customers["cluster"] = model.fit_predict(customers[["visit_count", "monthly_spend"]]) # 모델 학습

print(customers)
```

- ### **최적의 클러스터 개수 결정법**

**1. 엘보우 기법 (elbow)**
- Intertia Value    
: 각 클러스터의 중심에서 클러스터에 할당된 데이터 포인트간의 거리를 합산한 값  
    -> 각 데이터와 해당 군집 중심 사이의 거리 제곱합

- 값이 작을수록 "군집의 응집도가 높게 군집화가 잘되었다" 는 의미

- intertia Value의 값이 가장 급격하게 떨어지는 `k` 지점이 최적의 k다라고 가정


```python
from sklearn.datasets import make_blobs
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler
import matplotlib.pyplot as plt

# 군집 데이터 생성
X, y = make_blobs(
    n_samples=300,
    centers=4,
    cluster_std=1.0,
    random_state=42
)

# 스케일링
scaler = StandardScaler()
X = scaler.fit_transform(X)

inertias = [] # intertia 값 추가할 리스트

K = range(2, 11) # 군집 개수 설정

for k in K:
    model = KMeans(n_clusters=k, n_init=5, random_state=42)
    
    model.fit(X)
    
    inertias.append(model.inertia_)

    print(f'n_cluster: {k} | inertia : {model.inertia_:.2f}')


#  Elbow 시각화
plt.figure(figsize=(8, 5))

plt.plot(K, inertias, marker='o')

plt.xlabel('Number of Clusters (K)')
plt.ylabel('Inertia')
plt.title('Elbow Method')

plt.show()
```

```text

n_cluster: 3 | inertia : 2110.41
n_cluster: 4 | inertia : 564.91
n_cluster: 5 | inertia : 512.39

n_cluster: 7 | inertia : 408.95
n_cluster: 8 | inertia : 360.82
n_cluster: 9 | inertia : 331.84
n_cluster: 10 | inertia : 291.56
```

**2. 실루엣 계수 (silhouette)**

```math
s(i) = \frac{b(i) - a(i)}{\max(a(i), b(i))}
```

> `a(i)` : 데이터 $i$와 같은 군집에 속한 데이터들과의 평균 거리   
> `b(i)` : 데이터 $i$와 가장 가까운 다른 군집의 데이터들과의 평균 거리

- 군집화의 정답을 모를 때 군집의 응집도를 평가하는 방법

- $s(i) \approx 1$ : 같은 군집 내 데이터는 가깝고, 다른 군집과는 멀다 → 군집화가 잘 됨
- $s(i) \approx 0$ : 군집 경계에 위치
- $s(i) \approx -1$ : 다른 군집의 데이터가 더 가깝다 → 잘못 군집화되었을 가능성이 높음


#### [ python : code ] **실루엣 계수 코드**
```python 
from sklearn.datasets import make_blobs
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import silhouette_score
import matplotlib.pyplot as plt

# 군집 데이터 생성
X, y = make_blobs(
    n_samples=300,
    centers=4,
    cluster_std=1.0,
    random_state=42
)

# 스케일링
scaler = StandardScaler()
X = scaler.fit_transform(X)

# 실루엣 계수
silhouette_scores = []

K = range(2, 11)

for k in K:
    model = KMeans(n_clusters=k, random_state=42)
    
    labels = model.fit_predict(X)
    
    score = silhouette_score(X, labels)
    
    silhouette_scores.append(score)

# silhouette 시각화
plt.figure(figsize=(8, 5))

plt.plot(K, silhouette_scores, marker='o')

plt.xlabel('Number of Clusters (K)')
plt.ylabel('Silhouette Score')
plt.title('Silhouette Score by K')

plt.show()
```

# **[ 2. 차원 축소 (Dimensionality Reduction) ]**

- 차원 (dimension) : 데이터가 가진 특성(feature)의 개수  
    -> 변수가 키, 몸무게, 성별로 3개면 3차원으로 구분하며,  
        -> 여기에 소득, 나이가 더해지면 5차원이 됨

> ## 차원의 저주 (Curse of Dimensionality)

- 차원이 한 단위 증가할수록 데이터가 더 넓은 공간에 퍼지면서 희소해지고, 데이터 간 거리가 서로 비슷해져 가까운 데이터와 먼 데이터를 구분하기 어려워지는 현상

- 서로 비슷한 정보를 담은 Feature가 많으면 중복된 정보를 계속 사용하는 문제   
    -> 거리 기반 알고리즘의 성능 저하, 처리해야하는 연산량 증가

<br>

|차원이 많을 때의 문제|	설명|
|---|---|
|데이터 희소성|	차원이 증가하면서 같은 수의 데이터가 더 넓은 공간에 퍼짐|
|Feature 중복|	서로 비슷한 정보를 담고 있는 Feature가 많아질 수 있음|
|Overfitting 위험|	불필요한 Feature나 노이즈까지 학습할 가능성이 커짐|
|계산 비용 증가|	학습과 예측에 필요한 계산량이 증가함|
|시각화 어려움|	고차원 데이터를 원래 공간 그대로 사람이 이해하거나 시각화하기 어려움|
<br>

> ## PCA (Principal Component Analysis) ; 주성분 분석

- 데이터의 분산을 최대한 보존하면서 더 적은 수의 새로운 축으로 표현하는 차원축소 기법 

    -> 변수가 키, 몸무게의 2개 변수가 있으면,    
    차원축소는 각 변수의 의미는 최대한으로 살리면서 `키 X 몸무게`의 하나의 변수로 통일  

- Noise : 분석 목적과 관계가 약하거나 우연히 섞인 불필요한 변동


- ### **원리**



    - 여러 개의 변수 정보를 **적은 수의 새로운 변수(주성분)** 로 압축하는 방법
    - 데이터의 **분산이 가장 큰 방향**을 첫 번째 주성분(PC1)으로 선택
    - PC1과 겹치지 않는 방향 중 분산이 가장 큰 방향을 두 번째 주성분(PC2)으로 선택
    - 각 주성분은 기존 변수들의 **가중합**으로 만들어짐

```math
PC1 = a_1X_1 + a_2X_2 + \cdots + a_nX_n
```

    - 주성분의 개수를 줄이면 데이터의 차원을 줄일 수 있음
    - 중요한 정보는 최대한 유지하면서 시각화나 모델 학습을 쉽게 할 수 있음
    - PCA 전에 변수 단위 차이가 크면 일반적으로 `StandardScaler`로 표준화함

#### [ python : code ] **PCA Feature Engineering**
```python
# 센서 데이터
# 6개의 센서 값을 수집하고 있다. 
# 다음 데이터를 3개의 주성분으로 축소하고 PCA 적용 전후 Feature 수를 출력을 시도한다.

import pandas as pd
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

sensor_data = pd.DataFrame({
    "sensor_1": [10, 11, 13, 15, 18, 20],
    "sensor_2": [20, 22, 26, 30, 36, 40],
    "sensor_3": [5, 6, 7, 9, 11, 12],
    "sensor_4": [50, 55, 65, 75, 90, 100],
    "sensor_5": [7, 8, 10, 12, 15, 17],
    "sensor_6": [30, 33, 39, 45, 54, 60]
})

# 스케일링
scaler = StandardScaler()
sensor_data_after = scaler.fit_transform(sensor_data)

pca_model = PCA(n_components=3)
sensor_data_after = pca_model.fit_transform(sensor_data_after)

print('PCA 전 feature 수 :', sensor_data.shape[1])
print('PCA 후 feature 수 :', sensor_data_after.shape[1])
```

#### [ Result ]
```text
PCA 전 feature 수 : 6
PCA 후 feature 수 : 3
```

# **[ 3. PCA - Feature Engeneering ]**

- PCA는 서로 상관된 Feature의 정보를 적은 수의 주성분으로 압축함

- 차원이 감소하면 계산량과 Overfitting 위험을 감소시킴

- 너무 많은 차원을 제거하면 중요한 정보도 함께 손실될 수 있음

- 주성분은 원본 Feature보다 직관적으로 해석하기 어려움(PC1, PC2)

> 주성분을 원 데이터의 Feature 대신 모델의 입력으로 사용 가능   
 -> 중복된 정보를 압축하고 노이즈를 줄일 수 있음   
 -> 일반화 성능 향상에도 도움이 될 수 있음

#### [ PCA 효과 ]
|효과|	설명|
|---|---|
|계산 효율 향상|	Feature 수가 줄어 학습과 예측에 필요한 계산량이 감소|
|중복 정보 압축|	서로 상관된 Feature들을 더 적은 수의 주성분으로 표현|
|노이즈 감소|	분산이 작은 방향의 정보를 제거하여 노이즈가 줄어들 수 있음|
|과적합 완화|	차원이 감소해 과적합 위험을 줄이는 데 도움이 될 수 있음|
